# 01 企画構想立案

何を作るかを決める部門。ここで決めた「一文の企画」と「コアの面白さ」が、あとの全部門の物差しになる。

## 仕事人と呼ぶ順

1. オーナーの要望を聞く（プロデューサー）。足りなければ、ジャンル、遊ぶ人、遊ぶ場所（PC／スマホ／ブラウザ）、遊ぶ時間、作る期間、作りたい理由を聞く
2. `game-concept-ideas`（案が決まっていないとき、ひねりが欲しいとき）と `game-concept-market` を**同時に**呼ぶ
3. プロデューサーは、アイデアのありがち度の高いほうから3分の1を捨て、残りから選ぶ。市場調査の提案を合わせる
4. `game-concept-planner` に、要望・選んだ案・市場調査を渡して企画書を書かせる
5. オーナーに企画書を見せて **ゲートA**

## 作るもの

- `01_企画/企画書.md`（planner）
- `01_企画/市場調査.md`、`01_企画/アイデア出し.md`（見る担当の返事をプロデューサーが書く）

## 企画書の型

```markdown
# <仮タイトル>

## 一文の企画
<誰が>、<何をして>、<どう気持ちいい>ゲーム。

## コアの面白さ
- プレイヤーの動詞：
- そのときの気持ち：
- 1回の遊び（何秒〜何分）：

## 売り（3つまで）
1.
2.
3.

## 遊ぶ人と場所
- 遊ぶ人：
- プラットフォーム：
- 1回の遊ぶ時間／クリアまで：

## 見た目と音の第一印象
（言葉で。既存の作品名を使わない）

## 規模
| | 最小で出せる形（MVP） | 理想の形 |
|---|---|---|
| 中身 | | |
| 期間 | | |

## 似た作品との違い
（市場調査から。遊びの言葉で）

## リスク
## 未決
```

## ゲートA（オーナー）

- 一文の企画を、チームの誰が読んでも同じ遊びを思い浮かべる
- コアの面白さが、ジャンル名ではなく動詞と気持ちで書いてある
- MVPの規模が、決めた期間で作れる見込みがある
- 既存の特定のゲームの再現になっていない
- オーナーが「これを作る」と言った

## この部門に加わる仕事人

中心の仕事人（上の「呼ぶ順」）に加えて、プロジェクトに要るときに呼ぶ。`開発チーム.md` で使わないと決めた仕事人は呼ばない。

| 仕事人 | 職種 | この部門でやること |
|---|---|---|
| `game-biz-executive` | 代表取締役、エグゼクティブプロデューサー、事業責任者 | 企画が事業として成り立つか（狙う人、売り方、規模）を判定する |
| `game-biz-planning` | 経営企画担当、事業企画担当、事業開発担当、商品企画担当 | 収益の形と売る場所の案を出し、企画書の規模と合わせる |
| `game-biz-finance` | 財務担当、経理担当 | 規模ごとの費用のざっくりした見積もり |
| `game-design-creative-director` | クリエイティブディレクター | 企画の一文と第一印象が、心に残る形になっているか |
| `game-art-concept` | コンセプトアーティスト、キャラクターデザイナー、背景デザイナー、プロップデザイナー、イラストレーター、イラスト制作会社スタッフ | 企画の第一印象を伝えるイメージ（キービジュアルの案） |
| `game-story-director` | ナラティブディレクター、ナラティブデザイナー | 企画の物語の芯（テーマ、主人公の動機） |
| `game-pm-secretary` | 会議・情報管理担当、教育担当 | 文書の置き場所と目次の初版 |
| `game-loc-culturalize` | カルチャライズ担当 | 出す地域で避けるべき大きなテーマがないか |
| `game-mkt-director` | マーケティングディレクター、ブランドマネージャー | 届けたい人と、伝える一言（企画の売りから） |
| `game-mkt-copy` | コピーライター | 企画の一文を、外に向けた言葉にした案 |
| `game-sales-publisher` | パブリッシャー、セールスマネージャー、営業担当、流通管理担当 | 売る場所と地域の候補 |
| `game-sales-pricing` | 価格戦略担当 | 価格帯の候補 |
| `game-legal` | 法務担当、契約管理担当、法律事務所スタッフ | 企画に、法律に関わりそうな点（課金、くじ、年齢、個人情報）がないか |
| `game-legal-ip` | 知的財産担当、著作権管理担当、商標管理担当、ライセンス担当 | タイトルの候補が、既にある名前・商標とぶつからないかの下調べ |
