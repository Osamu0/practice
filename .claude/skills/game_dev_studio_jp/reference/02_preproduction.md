# 02 プリプロダクション

どう作るかを決める部門。面白さの骨組み、道具、見た目の方向、計画を決め、プロトタイプで確かめる問いを立てる。

## 仕事人と呼ぶ順

1. `game-preprod-designer`（デザインの柱、コアループ、スコープ、プロトの問い）
2. 柱ができたら、`game-preprod-tech` と `game-preprod-art` を**同時に**
3. 3人ぶんがそろったら `game-preprod-producer`（計画とリスク表）
4. プロデューサーが4つを照らし、食い違い（技術で無理な見た目、計画に収まらないスコープ）を直す → ゲート02

## デザインの柱

- 3つまで。短い言葉で、迷ったときに「この機能は柱に合うか」で削れるもの
- よい例：「1秒で反応、10秒で一勝負」「失敗が笑える」「迷わない、でも単純じゃない」
- 悪い例：「面白い」「爽快」（どの機能も削れない）

## コアループとメタループ

```
コアループ（数秒〜数分）：見る → 決める → 動く → 結果 → また見る
メタループ（数十分〜）：遊ぶ → 報酬 → 強くなる・解放 → もっと難しい遊び
```

- それぞれのループで、プレイヤーがやめずに続ける理由を書く

## スコープ

| 機能 | 必須／あれば／入れない | 理由 | 柱 |
|---|---|---|---|

## ゲート02

- デザインの柱、コアループ、スコープの表がある
- 技術が決まり、最小の「動く」が確かめてある
- アートの方向に、色コードと制作の数値がある
- 計画に、マイルストーンごとの終わりの条件と、削る順番がある
- プロトで確かめる問いが3つまである
