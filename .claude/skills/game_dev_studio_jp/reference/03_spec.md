# 03 仕様書作成

作るものを、実装とテストができる言葉にする部門。

## 仕事人と呼ぶ順

1. `game-spec-writer`（GDD、必須の機能の機能仕様）と `game-spec-balance`（パラメータ表）を**同時に**。数値の名前は、先に writer が仮の名前を決めて balance に渡す
2. `game-spec-review` を呼ぶ
3. 「必ず直す」を writer と balance に戻して直す → ゲート03

プロトで仕掛けが変わることが多いゲームは、03 で全部を書き切らず、必須の機能の骨だけ書いて 04 に進み、04 のあとで詳しくする。

## GDDの型

```markdown
# GDD：<タイトル>
1. 概要（一文の企画、柱、遊ぶ人、プラットフォーム）
2. コアループとメタループ
3. 操作（入力の一覧：キー、ボタン、タッチ）
4. ゲームの流れ（タイトル → … → エンディング、画面遷移）
5. 機能の一覧（機能仕様へのリンク、必須／あれば）
6. キャラ・敵・アイテムの一覧（パラメータ表へのリンク）
7. ステージ・コンテンツの一覧
8. 見た目と音（アートディレクションへのリンク）
9. UI（画面の一覧）
10. 保存（何を、いつ）
11. 未決
12. 変更履歴
```

## 機能仕様の型

```markdown
# 機能仕様：<機能名>
- 目的（どの柱のためか）：
- プレイヤーから見た動き：
- 入力：
- 状態と遷移：（表）
- 数値：（パラメータ表の名前）
- 例外・境界：（0、最大、同時、中断、死亡、ポーズ）
- 演出と音のきっかけ：
- 受け入れ条件：
  - [ ] 〇〇したら△△になる
- 未決：
- 変更履歴：
```

## パラメータ表

| 名前 | 値 | 単位 | 意味 | 理由 | 触ってよい幅 | 調整候補 |
|---|---|---|---|---|---|---|
| player.speed | 4.0 | px/frame | 歩く速さ | 1画面を3秒で渡る | 3.0〜5.0 | ○ |

## ゲート03

- 必須の機能すべてに機能仕様があり、受け入れ条件がテストできる文になっている
- パラメータ表があり、詰み・無限稼ぎ・最強の一択がないことを確かめた
- 仕様レビューの「必ず直す」が0

## この部門に加わる仕事人

中心の仕事人（上の「呼ぶ順」）に加えて、プロジェクトに要るときに呼ぶ。`開発チーム.md` で使わないと決めた仕事人は呼ばない。

| 仕事人 | 職種 | この部門でやること |
|---|---|---|
| `game-design-director` | ゲームディレクター、ディレクター | 仕様が柱に合うかを見る |
| `game-design-systems` | システムデザイナー、ゲームプレイデザイナー | 仕組みごとの機能仕様（状態、規則、相互作用、例外） |
| `game-design-combat` | コンバットデザイナー、バトルデザイナー、スキルデザイナー、キャラクター能力設計担当 | 戦闘の仕様、スキル表、キャラ能力表 |
| `game-design-economy` | 経済システムデザイナー、アイテムデザイナー | 通貨の入り口と出口の図、アイテム表、報酬表 |
| `game-design-world` | ワールドデザイナー | 地域ごとの役割、つながり、解放の条件 |
| `game-design-quest` | クエストデザイナー、イベントデザイナー | クエストの型と一覧 |
| `game-design-ai` | AIデザイナー | 敵・NPCごとの振る舞いの仕様（状態、合図、癖、難しさのつまみ） |
| `game-design-ux` | UXデザイナー、UIデザイナー、チュートリアルデザイナー | 画面遷移、ワイヤーフレーム、チュートリアルの設計 |
| `game-design-social` | ソーシャルシステムデザイナー | ソーシャル機能の仕様（つながり方、伝わる情報、守る仕組み） |
| `game-story-director` | ナラティブディレクター、ナラティブデザイナー | 物語の区切りとゲームの進行の対応表 |
| `game-loc-director` | ローカライズディレクター、翻訳コーディネーター | 出す言語と、仕様に入れる決め（文言の外出し、長さの余裕、フォント、日付や数の書き方） |
| `game-ops-analyst` | データアナリスト、ゲームアナリスト、データサイエンティスト | 記録する出来事の設計（何を、いつ、どの情報と一緒に）。個人情報は集めない形で |
