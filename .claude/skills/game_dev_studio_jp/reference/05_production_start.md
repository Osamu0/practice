# 05 本格的な開発開始

本制作に入るための土台を作る部門。ここからのコードは捨てない。

## 仕事人と呼ぶ順

1. `game-prod-architect`（設計と土台のコード、規約）
2. 土台ができたら、`game-prod-planner`（バックログ）と `game-prod-pipeline`（ビルド・テスト・アセット）を**同時に**
3. プロデューサーが、バックログの最初の山（縦切りを本番の土台に載せ直す）を確かめる → ゲート05

## バックログの型

| ID | 名前 | 部門・担当 | 依存 | 完了条件 | マイルストーン | 状態 |
|---|---|---|---|---|---|---|
| T-001 | プレイヤーの移動 | 06 game-sys-gameplay | なし | 機能仕様「移動」の受け入れ条件 | アルファ | 未着手 |

- 状態：未着手 → 作業中 → レビュー待ち → 完了
- 1タスクは1人が1回で終えられる大きさ

## ゲート05

- 土台が起動し、自動テストが1つ以上通る
- ビルド・テスト・起動のコマンドが `README.md` にある
- データ（数値、テキスト）を外から読む形になっている
- バックログが、アルファまでのタスクでマイルストーンに割り付いている
