# 06 ゲームシステム

ゲームの仕組みを本番のコードに実装する部門。07 コンテンツ、08 統合と並べて回す。

## 仕事人と呼ぶ順（タスクごと）

1. バックログから、依存のないタスクを選ぶ。担当（`game-sys-gameplay`、`game-sys-ai`、`game-sys-ui`）に渡す。同じファイルを触らないタスクは**同時に**呼ぶ（同じファイルを触るものは順に）
2. できたら `game-sys-code-review` を呼ぶ
3. 「必ず直す」を担当に戻す。通ったら、バックログの状態を「完了」にしてコミット
4. 数タスクごとに、08 の統合で通しのビルドが壊れていないか確かめる

## 実装で仕様が足りなかったとき

- 担当は勝手に決めず、未決として返す。プロデューサーが、小さなことはその場で決めて仕様に書き足す。大きなことは 03 に戻す
- 担当が決めた細かい数値は、パラメータ表に足す

## ゲート（タスクごと）

- 完了条件（機能仕様の受け入れ条件）を満たし、テストが通る
- コードレビューの「必ず直す」が0
- 通しのビルドが起動する
