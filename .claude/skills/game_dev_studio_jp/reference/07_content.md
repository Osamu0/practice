# 07 コンテンツ制作

遊ぶ中身（ステージ、物語と文言、絵、音）を作る部門。

## 仕事人と呼ぶ順

- 4人は、互いに依存しないものは**同時に**呼ぶ
- 順番の目安：シナリオの設定と用語集 → レベル（物語の区切りに合わせる）→ 絵と音（レベルとシステムで要るものの一覧から）
- システムの仕組みがないと作れないもの（新しいギミックのステージ）は、06 の該当タスクのあとに回す
- できたものは、プロデューサーが一覧（アセット一覧、サウンド一覧、テキスト）と照らし、08 の統合に渡す

## 見るところ（プロデューサー）

- レベル：教えることが1つ決まっているか。詰みがないか。想定のクリア時間が計画に合うか
- シナリオ：用語の表記ゆれ、画面に収まる長さ、遊ぶ時間と読む時間の釣り合い
- 絵：スタイルガイドの色と数値に合うか。背景とキャラが見分けられるか
- 音：操作に返す音がそろっているか。耳に刺さらないか
- 全部：権利（素材のライセンス）が一覧に書いてあるか。既存作品に似すぎていないか

必要なら `game-concept-ideas` にギミックや敵の案を出させてよい。

## ゲート

- そのマイルストーンで要るコンテンツが、一覧で「本番」か「仮（理由つき）」になっている
- 権利の欄が空のものがない
