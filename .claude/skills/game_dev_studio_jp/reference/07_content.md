# 07 コンテンツ制作

遊ぶ中身（ステージ、物語と文言、絵、音）を作る部門。

## 仕事人と呼ぶ順

- 4人は、互いに依存しないものは**同時に**呼ぶ
- 順番の目安：シナリオの設定と用語集 → レベル（物語の区切りに合わせる）→ 絵と音（レベルとシステムで要るものの一覧から）
- システムの仕組みがないと作れないもの（新しいギミックのステージ）は、06 の該当タスクのあとに回す
- できたものは、プロデューサーが一覧（アセット一覧、サウンド一覧、テキスト）と照らし、08 の統合に渡す

## 見るところ（プロデューサー）

- レベル：教えることが1つ決まっているか。詰みがないか。想定のクリア時間が計画に合うか
- シナリオ：用語の表記ゆれ、画面に収まる長さ、遊ぶ時間と読む時間の釣り合い
- 絵：スタイルガイドの色と数値に合うか。背景とキャラが見分けられるか
- 音：操作に返す音がそろっているか。耳に刺さらないか
- 全部：権利（素材のライセンス）が一覧に書いてあるか。既存作品に似すぎていないか

必要なら `game-concept-ideas` にギミックや敵の案を出させてよい。

## ゲート

- そのマイルストーンで要るコンテンツが、一覧で「本番」か「仮（理由つき）」になっている
- 権利の欄が空のものがない

## この部門に加わる仕事人

中心の仕事人（上の「呼ぶ順」）に加えて、プロジェクトに要るときに呼ぶ。`開発チーム.md` で使わないと決めた仕事人は呼ばない。

| 仕事人 | 職種 | この部門でやること |
|---|---|---|
| `game-design-director` | ゲームディレクター、ディレクター | コンテンツの流れと量を見る |
| `game-design-world` | ワールドデザイナー | レベル担当・シナリオ担当に渡す地域の設計書 |
| `game-design-quest` | クエストデザイナー、イベントデザイナー | クエストごとの設計書（目的、手順、条件、報酬、分岐、失敗） |
| `game-tech-tools` | ツールプログラマー | レベル・データ・テキストの作業を助けるツールを作る |
| `game-art-director` | アートディレクター、リードアーティスト | 資産をスタイルガイドに照らす |
| `game-art-concept` | コンセプトアーティスト、キャラクターデザイナー、背景デザイナー、プロップデザイナー、イラストレーター | キャラ・背景・小物の設定画（正面・横・色・大きさの比較） |
| `game-art-3d` | 3Dキャラクターモデラー、背景モデラー、プロップモデラー、テクスチャアーティスト、マテリアルアーティスト | 3D資産の制作と、資産一覧への登録 |
| `game-art-lighting` | ライティングアーティスト | 場面ごとの光の設計（色、向き、強さ、影） |
| `game-art-vfx` | エフェクトアーティスト、VFXアーティスト | エフェクトの一覧と制作 |
| `game-art-ui` | UIアーティスト | UIの部品（ボタン、枠、アイコン、ロゴ）の制作 |
| `game-art-technical` | テクニカルアーティスト、テクニカルアニメーター、リギングアーティスト | リグ・アニメの仕組み、資産のチェック |
| `game-anim-animator` | アニメーションディレクター、リードアニメーター、3Dアニメーター、モーションデザイナー、フェイシャルアニメーター | 動きの一覧と制作（スプライトのコマ、補間、骨のアニメ） |
| `game-story-director` | ナラティブディレクター、ナラティブデザイナー | 書き手の分担を決め、書いたものを監修する |
| `game-story-lore` | 世界観設定担当、キャラクター設定担当、ロアライター | 設定の正本（`07_コンテンツ/シナリオ/設定.md`）、ロアの文 |
| `game-story-quest-writer` | サブシナリオライター、クエストライター | クエスト・サブシナリオの文章 |
| `game-story-dialogue` | 会話ライター | 会話、かけ声、選択肢の文章 |
| `game-story-dialogue-review` | 台詞監修担当 | 書かれた台詞・文章の監修 |
| `game-audio-director` | オーディオディレクター | 音楽・効果音・声をアートディレクションの音の方向に照らす |
| `game-audio-composer` | 作曲家、編曲家 | 音楽の一覧（場面、曲調、テンポ、長さ、ループ、変化）と制作 |
| `game-audio-voice` | ボイスディレクター、音声編集担当、多言語音声制作担当 | 収録台本、声の方向、演技の指示 |
| `game-pm-manager` | プロジェクトマネージャー、プロダクションマネージャー、制作進行担当、リソースマネージャー、アシスタントディレクター | コンテンツの進み具合を一覧で見る |
| `game-loc-director` | ローカライズディレクター、翻訳コーディネーター | 用語集・キャラの口調の説明・文脈の説明を翻訳者に渡す形にする |
| `game-loc-translator` | 翻訳者、字幕制作担当 | テキストデータの翻訳 |
| `game-loc-culturalize` | カルチャライズ担当 | 絵・文・名前・記号の確かめ |
