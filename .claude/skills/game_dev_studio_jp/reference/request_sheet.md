# 依頼書

この環境で作れないもの（細かいイラストなど）を、外部の人に作ってもらうための書類。仕事人は「何を、どんな形で作ってほしいか」を書く。依頼先を選ぶこと、連絡、契約、支払い、権利の取り決めはオーナーが行う（このスキルの範囲外）。

目指すのは、**ゲームを知らない人が、依頼書だけを読んで、こちらが欲しいものを作れる**こと。読んだ人が質問しなくて済むほど、やり直しが減る。

## 置き場所と流れ

- 置き場所：`07_コンテンツ/依頼書/イラスト/<依頼ID>_<名前>.md`、まとめの一覧は `07_コンテンツ/依頼書/依頼一覧.md`
- 流れ：
  1. `game-art-concept` が依頼書を書く。ゲームの中には、同じ大きさの仮の絵を先に置いておく
  2. `game-art-director` が依頼書を見る（スタイルガイドとのずれ、抜け、あいまいなところ）
  3. プロデューサーがオーナーに渡す。オーナーが「オーナーが書く欄」を埋めて依頼する
  4. ラフ・線画・完成のそれぞれで、`game-art-director` が依頼書の「確認の基準」に照らして見る。直しの依頼の文も書く
  5. 完成が届いたら、`game-content-art` が取り込み、ゲームの画面で確かめて、資産一覧を「本番」にする

## イラスト依頼書の型

```markdown
# イラスト依頼書：<依頼ID> <名前>

## 1. ひとことで
<何の絵を、ゲームのどこで使うか。1〜2文>

## 2. このゲームについて（描く人向けの短い説明）
- どんなゲームか：<一文の企画>
- 雰囲気：<スタイルの言葉。例：やわらかい、少し不思議、明るい昼>
- この絵を見たプレイヤーに感じてほしいこと：
- 伝えてよい範囲：<物語のネタばれをどこまで伝えるか>

## 3. 描くもの
### キャラの場合
- 名前・役割：
- 年齢の感じ・体つき・身長（ほかのキャラとの比較）：
- 性格（3語）と、それが見た目に出るところ：
- 服・髪・持ち物（色コードつき。変えてはいけないもの／自由に決めてよいもの）：
- ポーズ・向き：
- 表情の差分：<例：ふつう、笑い、怒り、驚き、悲しみ>（それぞれの使う場面）
- 必ず入れる特徴（遊びの中で見分けるための形）：
### 背景の場合
- 場所・時間帯・天気：
- 画面のどこにキャラや操作の表示が重なるか（そこに大事なものを描かない）：
- 遠景・中景・近景を分けるか（スクロールで動かすなら分ける）：
### 小物・アイコン・UI用の絵の場合
- それぞれの名前と、ゲームでの意味：
- 小さく表示されても形だけで見分けられること：

## 4. 見た目の決め
- スタイルの言葉（使う言葉／使わない言葉）：<アートディレクションから>
- 色：<パレットの色コード。主役の色、背景の色、使わない色>
- 線：<太さ、色、あり／なし>
- 塗り：<例：影1段のベタ塗り、ぼかしなし>
- 光の向き：
- 参考にしてほしいもの：<添付の仮の絵・ラフ・スタイル見本のファイル名>
  （既存の作品やキャラの名前で「〇〇みたいに」とは書かない。技法と雰囲気の言葉で書く）

## 5. 技術の条件
- 画像の大きさ（px）と縦横比：
- ゲームの画面での表示の大きさ：<例：画面の高さの3分の1。この大きさで見て読めること>
- 背景の透過：<あり／なし>
- 余白：<キャラのまわりに何px>
- 形式：<PNG（透過）、元データ（レイヤーつきPSDなど）も要るか>
- レイヤー・パーツ分け：<例：アニメで動かすため、腕・頭・体を分ける>
- 差分の作り方：<例：表情だけ別レイヤー、体は共通>
- ファイル名の決め：<例：chara_hero_face_smile.png>

## 6. 納品してほしいもの
| ファイル | 数 | 段階（ラフ／線画／完成） |
|---|---|---|

## 7. 確認の基準（届いたものを、これで確かめる）
- [ ] 色が指定の色コードから大きくずれていない
- [ ] 必ず入れる特徴が入っている
- [ ] 表示の大きさに縮めても、形と表情が読める
- [ ] 大きさ・透過・余白・形式・ファイル名が条件どおり
- [ ] パーツ・差分の分け方が条件どおり
- [ ] 既存の作品のキャラや絵柄に似すぎていない

## 8. オーナーが書く欄（仕事人は空けておく）
- 依頼先：
- 締め切り：
- 予算：
- 権利・使える範囲・クレジットの書き方：
- 連絡の方法：

## 9. 添付
- <仮の絵、ラフ、スタイル見本、色見本、画面の中に置いたスクリーンショット>
```

## 書くときの決まり

- 数字にできるものは数字で書く（色コード、px、数、表示の大きさ）。「いい感じに」「おまかせ」は、自由にしてよいところにだけ使い、そう明記する
- 自由に決めてよいところと、変えてはいけないところを分けて書く
- 添付は必ず付ける。この環境で描けるもの（SVGのラフ、色見本、仮の絵をゲームの画面に置いたスクリーンショット）を書き出して、`07_コンテンツ/依頼書/イラスト/添付/` に置く
- 同じキャラの絵を何枚も頼むときは、最初に設定画（正面・横・色）を1枚頼み、それを以降の依頼書の添付にする
- 既存の作品・キャラ・実在の人物の名前で指定しない
