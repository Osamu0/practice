# 出典

工程の名前と区切り方は、スタジオによって違う。このスキルは、下の資料で共通している大まかな流れ（企画 → プリプロ → 本制作 → アルファ → ベータ → リリース候補・ゴールド → 保守）に合わせ、線の引き方は各部門のファイルで決めている。調べた日：2026-11-18。

## 工程の全体

- Game-Ace「Game development stages」 https://game-ace.com/blog/game-development-stages/
- Pingle Studio「Game development stages」 https://pinglestudio.com/blog/full-cycle-development/game-development-stages
- CG Spectrum「Game development process」 https://www.cgspectrum.com/blog/game-development-process
- Heathen「Development Phases」 https://kb.heathen.group/old-kb/guides/tips-and-tricks/fundamentals/development-phases
- Doug Pennant「Pre-Production? Alpha? What?」 https://dougpennant.substack.com/p/pre-production-alpha-what
- Unity Learn「Production and Post-release」 https://learn.unity.com/course/game-development-in-a-nutshell/tutorial/production-and-post-release

要点：プリプロでGDDとプロトタイプを作る。アルファは機能がそろった段階（仮のコンテンツは残る）とする資料が多い。ベータはコンテンツを確定して安定させる段階。ゴールドは開発ではなく検証の段階とする資料がある。アルファの線の引き方などは資料によって違う。

## ベータ版・テスト（日本語）

- Wikibooks「ゲームプログラミング/デバッグ」 https://ja.wikibooks.org/wiki/ゲームプログラミング/デバッグ

要点：外部テスターに配る前に、チーム内で通しプレイをする。外部テスターによるテストを「ベータテスト」と呼ぶ。

## 縦切り（バーティカルスライス）

- Unity Learn「Your first milestone: vertical slice」 https://learn.unity.com/course/design-and-publish-your-original-game-unity-usc-games-unlocked/unit/milestones/tutorial/your-first-milestone-vertical-slice
- Game Developer「What you should take out of pre-production」 https://www.gamedeveloper.com/game-platforms/what-you-should-take-out-of-pre-production
- Xsolla「Funding 101: The impact of the vertical slice」 https://xsolla.com/blog/funding-101-the-impact-of-the-vertical-slice

要点：ゲームの小さな一部を、プログラム・絵・音・デザインのすべてで製品に近い品質まで作ったもの。プリプロの終わりに置く資料が多い。「これ1つ」という定義はない、とする資料もある。

## わからなかったこと
