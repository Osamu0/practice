# 喘ぎ声表現スキル

## Overview

AI官能小説においてありがちな「喘ぎ声が乏しい・単調」という課題を根本解決するためのskill。即座に多様な喘ぎ声を設計・生成。

このスキルは官能小説執筆スキルの導入を前提としている。ただし日本語圏におけるNSFWコンテンツ全般に汎化しているため、成人漫画、エロゲー用スクリプトなどのスキルとの併用も推奨する。

### スキル使用の鉄則
- 喘ぎ声は「地の文の最低限＋喘ぎ声の豊富さ」で作品全体のエロさが決まる。
- 常に「キャラクターの状況（理性・快感度・物理的衝撃）」を意識。
- 記号（、・っ・…・ー・！？・〜・♡・゛）と文字の大小・ひらがな/カタカナをテンポよく変化させる。
- 好みの下品レベルを事前に決めて一貫させる（読者離れを防ぐ）。

## 1. 定義

### 喘ぎ声（あえぎごえ）
快感や絶頂時に自然に漏れる吐息まじりの声。  
単なる音ではなく、官能の高まり・快楽のピークを音で伝える要素。  
「んっ……あっ、んぁ……」「ダメっ、イッちゃう……！」のように、声量・リズム・息の荒さ・声の高さが感情を伝える。  
フェチ的魅力：征服感・羞恥心・「自分が相手を乱している」実感。

### 喘ぎ声バリエーション

#### イキ声（いきごえ）
オーガズム到達瞬間の本能的な突き抜けた声。  
「イッ……ああっ！！」「んっ、あぁあ……っ?」のように声が跳ね上がる。  
喘ぎ声全体のピークを象徴。（レベル２の絶頂表現）

#### オホ声（おほごえ）
快感極限時に漏れる特徴的な声（「おほぉぉっ♡」）。  
舌が回らず息が抜けたような崩壊音。  
アヘ声と密接に関連し、「理性が壊れていく」倒錯的な興奮を生む。（レベル３・４での前戯からセックス中盤の使用例が多い）

#### アヘ声（あへごえ）
絶頂時から絶頂後にかけて意識が飛びそうな状態・飛んだ時の壊れた喘ぎ声。  
思考・発語が崩壊し、言葉にならない音が連続。「あひいいぃぃぃっ♡♡♡」「はぁ…あ"っ…あへ……っ」「…あ゙……あへぇ……」。  
アヘ顔（白目・涙・涎）とセットで使用。漫画では吹き出しの歪み・震え線で視覚化、音声作品では息の乱れで表現。（レベル３・４での絶頂直前から絶頂終了後の使用例が多い）

#### 喘ぎ声バリエーションの使い分け
- 喘ぎ声：全般 
- イキ声：絶頂瞬間  
- オホ声：極限状態
- アヘ声：理性崩壊

## 3. ノウハウ

### 喘ぎ声の作り方5ステップ
1. シチュエーションに合った単語をリストアップ（例：嫌がる系→「ひっ」「やめて」「怖い」）
2. 単語を並び替えて基本形作成
3. 句読点（、）＋促音（っ）で息遣い
4. 母音を増やして喘ぎ声らしく
5. オプション装飾（…・゛・♡・！？）
6. 呂律崩し（ダメ→らめぇ→りゃめえぇっ♡）

#### 実例（恐怖・嫌がる系）
基本→「ひっ、いや、こわい、助けて」  
完成→「ひっ……、い、いやっ……、やあぁっ！、こ、こわいよぉ……、あ、キャアッ！？ た、たしゅけてぇ……！！」

### 応用テクニック
- **喘ぎながら話す**：セリフの間に喘ぎを挟む（「っな、そこは違、あ、だから違う穴だって……あ゙？ いっ、挿れないでっ……〜〜ッ！？」）
- **理性崩壊**：意味不明の奇声＋゛多用（「あ゙がぁぁぁぁぁあ!!」「ぬほぉぉぉぉぉぉ!!」）
- **視覚的躍動感**：ひらがな↔カタカナ、大文字↔小文字を交互に

### 喘ぎ声Tips
1. **8文字以上の連続使用を避ける**（13種：あいうえお / はひふへほ / んつっ）
2. **記号の視覚効果を活用**（……で間、――〜で余韻、！？で衝撃）
3. **状況を考慮**（理性の有無・受け入れる/我慢・物理的衝撃/自発的）
4. **絶頂時特化**：記号を多用＋絶頂宣言セリフでハイライト化。

## 喘ぎ声使用のポイント
- **レベル感を統一**：1シーン内で急にレベル4まで崩さない（違和感防止）
- **擬音併用**：上記の喘ぎ声の下に（クチュクチュ、ずぶっ、びちゃあ……）などを入れるとさらに濃厚に
