# spicy_novel_writing_jp

このリポジトリの作品づくりで、作者が直したこと・校閲で見つかったことを、作品をまたいで効くようにまとめたスキル。

- `spicy_novel_jp`：企画 → 世界観 → キャラ → アウトライン → プロット → 執筆の流れと、喘ぎ声（`references/aegigoe_skills.md`）
- `spicy_novel_vocab_jp`：性器・行為の語彙の言い換え（地の文用）
- **このスキル**：台詞と地の文の書き方、表記の選び方、執筆チームの流れ。作品ごとの文体ルールの土台

## いちばん大事なこと

1. **作者が欲しいのは、素直で、甘くて、温度の高い台詞。** AIは、含み・決め台詞・事実で語る台詞を「うまい」と思って書くが、作者は逆に直す。何を直したかの実物は `reference/author_edits.md`。迷ったらこれを見る
2. **台詞は耳で聞いて自然な話し言葉。** 書き言葉の台詞にしない（`reference/dialogue.md`）
3. **台詞も行為も、読者に説明するために書かない。** その場の二人の気持ちと欲から出たものにする（`reference/realism.md`）
4. **100点の土台がそろってから、120点を狙う。** 全部が100点で読者が満足しているところへ、その上をいくものが来るのが一番刺さる（`reference/writing_team.md`）

## スキルと作品の分担

- **スキル（ここ）**：どの作品でも同じこと
- **作品のフォルダ**：その作品だけで決めること。視点、心の声を使うか、♡・笑を使うか、喘ぎ声の強さ、キャラクターの芯、口調サンプル、声の区別、作品の芯、本文メモ（一覧は `reference/work_setup.md`）
- 作品の `文体ルール.md` は、「作品ごとに決めること」と、このスキルとの違いだけを書く。スキルにあることを写さない
- 作品とスキルがぶつかったら、作品のほうを優先する

## してはいけないこと

- 実在の人物・団体を書かない。外部の作品を参考にするときは、書き方と言葉づかいだけを抜き出し、人物・設定・出来事・文章は使わない
- 同じ文字を5文字以上続けない（特に喘ぎ声）
