# 作者の直し（100点の見本）

> 校閲まで通したAIの完成稿を、作者が自分で直したときの直し方の型。ルールの言葉より、この型のほうが正確に100点を示している。台詞を書く・直す前に、一度読む。
> 例文は、どの作品にも寄らないように書いたもの（女、男）。型だけを見る。例文の言葉や状況は使わない。

## 数で見た傾向

作者は、台詞を足すより、温度を上げる方向に直した。直したあとは、直す前と比べて次のようになった。

| | 直す前（AI・校閲済み） | 直したあと（作者） |
|---|---|---|
| ♡ | 少ない | 2倍以上 |
| 語尾の「笑」 | ほぼない | よく出る |
| 疑問形で投げる台詞 | 少ない | 増える |
| 台詞の数・地の文の量 | ― | ほぼ同じか、少し減る |

AIは校閲まで通しても、作者から見ると温度が低い。

### 地の文：細かい動作の書き足しを削る

- 服を体に当てて、鏡をのぞいて、別の服に持ち替えて、また戻して、首をかしげる → 削除
- 「背中がシーツから浮いて、つま先がシーツをかいた。」→ 削除
- 地の文の読点を減らす（「通りから一本入ったところの、ガラス張りの店だった。」→「通りから一本入ったところのガラス張りの店だった。」）

## ここから言えること

- AIは、気の利いた言い回し（含み、謎かけ、決め台詞、事実で語る）を「うまい台詞」だと思って書く。作者が欲しいのは逆で、素直で、甘くて、温度の高い台詞
- AIは、台詞の外側（細かい動作、理由、状況）を書き足す。作者は削る
- 「♡を使ってよい」と書くだけでは、AIは控えめにしか使わない。上の傾向くらいの量と温度が100点
- 見るのは言葉の中身。表記（台詞末の「。」など）は、作品の表記ルールでそろえる
