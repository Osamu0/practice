# 台詞

## 1. 台詞は話し言葉で書く

台詞は、正しい日本語として読める形ではなく、耳で聞いて自然な形で書く。口調サンプルは読みやすく整えてあることが多いので、本文ではこの形に崩す。

| 書き言葉の台詞（×） | 話し言葉の台詞（○） |
|---|---|
| 文法の切れ目で読点を打つ（「ここの、おいしそう」「靴、そこでいいよ」） | 息の切れ目にだけ打つ（「ここのおいしそう」「靴そこでいいよー」） |
| 断片を並べた電報のような台詞（「ホテル。駅の反対側。歩いて十分」） | 一息のふつうの文（「歩いて十分のところにホテルとってるよ」） |
| 助詞をきちんと入れる（「私の半歩うしろを歩いていた」） | 話すときに抜ける助詞は抜く（「前か後ろ歩いてた」） |
| いきなり中身から話す | 感動詞や反応から入る（「え！　知らない」「ん？　メニュー見てれば？」「ねえねえ」） |
| 平らな語尾で言い切る | 伸ばす（「言ってよー」）、上げる（「〜しよ？」「〜でしょ？」）、言いさす（「時間…あるもんね」） |

- **長さの使い分け**：ふだんの会話は、ふくらませてよい（一言添える、反応を入れる）。行為中は短く、素直に（×「上、乗りたい。自分で、する」→○「上、乗りたい♡」）
- **長い台詞もある**：好きなものの話、ずっと思っていたことは、ひと息に長くしゃべってよい。長くても説明くさくせず、言いよどみと話し言葉のまま
- **整いすぎない**：言いよどみ、言い直し、相づち、相手の言葉にかぶせるツッコミを残す
- **言いよどみを読点の連打で表しすぎない**（×「すいません、ちゃんと、洗ってきたんです、けど……」）。詰まるのは一か所、多くて二か所まで。あとは「え」「あ」「いや」と言い直しで見せる
- 書き終えたら、台詞だけを声に出すつもりで読み直す。息が続かない、言いにくい、読み上げ調になるところは直す

## 2. 台詞の温度

> 実物は `author_edits.md`。

- 事実・理由・段取りより、気持ちで返す
- 含み・謎かけより、素直に言う
- 謝る・遠慮するより、気持ちよさと勢いで言う
- 素っ気ない短い返しには、温度（♡、笑、伸ばし、疑問形）を足す
- 気持ちは理由で言わず、相手に向ける言葉で言う（×「〜だったから、かわいかった」→○「すごいかわいいもん」）
- 言い切りより、相手に投げる言い方（「〜しよ？」「〜でしょ？」「〜して？♡」）
- その場の素直な反応を入れる（「んー！　おいしいー！」「ほんと？　じゃあ、そうしよ！」）
- 男も甘く、少しいじわるに（「わざとじゃないよ？♡」「僕が動いてあげる♡」「やめないからっ♡」）。言い訳や理由より、甘さと勢い

## 3. 声の区別

名前を隠しても、誰の台詞かわかるようにする。作品ごとに、人ごとの次の項目を決めて、作品の文体ルールか口調サンプルに書く。

| 項目 | 例 |
|---|---|
| 基本の距離 | タメ口／敬語／混ざる |
| 語尾の癖 | 「〜もん」「〜の！」「…かも」／「〜じゃん」「〜だしね」 |
| 入り方 | 「ねえ」「ほら」／「え」「あ」「いや」 |
| 反応の速さと長さ | 一音で返す／長く甘く返す |
| 崩れ方 | ♡と卑語が出る／敬語が抜け落ちる／呂律が回らなくなる |
| ♡・笑の量 | よく使う／ほとんど使わない |

- くだけた語尾や「笑」「ー」「♡」を、全員が同じように使わない
- 二人だけの話では、二人の語尾が同じにならないようにする

## 4. ♡と笑

- 作品で使うと決めたら、台詞の語尾や途中に「笑」「♡」をつけてよい。軽口・からかい・照れには「笑」、甘え・誘い・エロい場面には「♡」
- **♡の量は決めない。その場の雰囲気と、女の子の状況で考える。** どれだけ甘えているか、感じているか、崩れているか
  - 甘く崩れている最中は、一語ごとについても、♡♡と重なってもいい
  - まだ余裕があるとき、表の顔のときは少なく、または使わない
  - 甘える性格・小悪魔のキャラは、ふつうの会話でも♡を使う。ツンとしたキャラは、ふつうの会話では使わず、乱れたときだけ出る。量でキャラを見せてよい
  - 同じ場面でずっと同じ量にしない。状況が変わったら量も変わる
- ♡はピークだけのものではない。甘い場面なら会話の段階から使う

## 5. 「…」「……」「、、、」

- 言いよどみや詰まりには、「、、、」も「…」「……」も使える（「えと、、、」「勘弁してくれ、、、」「すいません…ちょっと…」）。どちらにするかは、その場の言いにくさや間の感じで選ぶ。決まった使い分けはしない
- ただし、一人の台詞の中や近い台詞で、記号を混ぜすぎない（「えと、、、…それで……」のようにしない）
- 「…」と「……」は混ざってよい
- 「…………」だけの台詞は使ってよい（固まる、言葉が出ない、気まずい、にらみ合う）。ただしAIっぽい型にしない。無言の「……」で内心をにおわせて、余韻で場面を締める使い方をくり返さない（`ai_tells.md`）

## 6. 口でする行為の音

- キス、舐める、吸う、咥える、フェラ、えずきの音は、台詞の中に混ぜてよい。音と、名前と、短い言葉が交互に来る（例：女「んちゅ♡　ちゅ♡　れろぉ♡　（相手の名前）♡　すき♡」）
- 独立した行にしてもよい。場面で使い分ける（`sounds.md`）

## 7. 表記（作品で選ぶもの）

> 作品ごとに選んで、作品の文体ルールに書く。迷ったら下の既定。

| 項目 | 既定 |
|---|---|
| 台詞の前の名前 | つける（例：女の名前「……」） |
| 「（笑）」（かっこつき） | 使わない |
| 台詞の最後の「。」 | つけない |
| 台詞の途中の「？」「！」のあと | 全角スペースを一つ入れる |
| 「笑」「♡」のあと | 「。」はつけない。途中なら全角スペースで区切る |
| 話す人が替わるとき | 台詞と台詞のあいだに空行 |
| LINE | 名前『』 |
| 心の声 | 名前（　）（使う作品だけ。`inner_voice.md`） |
