# 作者の直しをルールに戻す

> 作者が本文を直したとき、読んで感想をくれたときに、それを次の章・次の作品に効かせるやり方。

## 作者が本文を直したとき

1. 作者版をそのまま本文に入れる（誤記だけ直す）
2. AI版と作者版の差分を取る（`git diff --word-diff`）
3. 差分を「直しの型」に分ける（事実→気持ち、含み→素直、電報→一息、温度を足す、削る、など）。数も数える（♡、笑、？、台詞の長さ、地の文の量）
4. 型ごとに、それがこの作品だけのことか、どの作品でも同じことかを決める
   - どの作品でも同じ → このスキルに足す（`author_edits.md` に実例、`dialogue.md` などにルール）
   - この作品だけ → 作品の `文体ルール.md` に足す
   - 迷ったら作品側に置く。一つの作品の好みをスキルに入れると、ほかの作品が引っぱられる
5. 足したルールを、校閲のどの担当が見るかも決める

## 作者が感想をくれたとき

- 「冷めた」「違う」と言われたところは、場所と理由を聞かずに推測で直さない。どこで、何が、を確かめる
- 作者の言葉がたとえ話や感覚のときは、こちらの理解を言葉にして返し、合っているか確かめてからルールにする
- 一度言われたことは、ルールにして残す。同じことを二度言わせない

## 外部の作品を参考にするとき

- 書き方と言葉づかいだけを抜き出す。人物、設定、出来事、文章は使わない。実在の人物を扱う作品なら、なおさら名前も残さない
- 例文は、このリポジトリの架空のキャラか記号で書き直す
- 今のルールとぶつかるところは表にして、作者に決めてもらう
