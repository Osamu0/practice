# 地の文

## 1. 基本

- モノローグっぽい地の文を書かない。登場人物の頭の中の声に聞こえる、体言止めや現在形の短い断片（×「少し、しょっぱい。」「あの人の匂いがする。」「さっきから、よく笑う。」）は、三人称の文として言い切る（○「少ししょっぱい味がした。」「あの人の匂いがした。」）
- 登場人物の感じ方を地の文でなぞる書き方を避ける（「〜のに、もう〜」「〜に気づいて」）
- 読点を打ちすぎない（下の「8. 読点」）
- 細かい動作を書き足しすぎない（物を持ち替える、首をかしげる、つま先がシーツをかく）。作者は削る
- 台詞を見ればわかることを、地の文で言い直さない
- 位置関係を説明しない。動作、感覚、台詞の中で自然に伝える（×「AはBの背後に膝立ちになり、CはBの右側に座っている。」）
- 何が起きているかより先に、どう感じているかが伝わるように書く

## 2. 何を書いて、何を書かないか

| 種類 | 扱い |
|---|---|
| 動作 | 残す（何が起きているかわかるように） |
| 体の反応 | 残す（エロの核） |
| 感じる感覚（熱さ、ぬめり、締めつけ） | 残す |
| 五感（匂い、温度、音） | 量を絞って残す。並べて説明しない |
| 状況・場所の説明 | 最小限 |
| 比喩 | 少なく。使うときは強く短く（「針金でも入っているかのように」） |

## 3. エロの地の文

- 地の文は短く、台詞・喘ぎ声・行為音を多めに
- 指や舌の動きは、どこを、どう、まで具体的に書く（「中指で付け根をくすぐるように転がし、入口を揺らすように動かす」の型）
- 感触は一つだけ添える（ぬるぬる、熱い、重い）
- なぜ気持ちいいのかを、一言だけ書いてよい（泡がローションの代わりになっている、など）
- 語彙は直接的に。同じものを指す言葉を毎回同じにしない（`spicy_novel_vocab_jp`）。台詞では言い換えない
- 生々しい細部（汗で髪が額に貼りつく、太ももが震える、垂れてくるもの、シーツの濡れ）を要所に一つずつ

## 4. 表の顔との落差

- ふだんの顔（歌声、テレビ、気の強さ、上品さ）と今の姿の差を、要所で一回だけ地の文が言葉にしてよい（「ふだんのあの〜からは想像もできないほど」「ふだんなら死んでもしないはずの〜を、今はためらいなく」の型）
- 毎回は書かない。一番効くところにとっておく

## 5. 語り手の声（作品で選ぶ）

- 三人称の語り手が、登場人物を短くからかう・ツッコむ書き方がある（「この場合、変なのはAのほうである」「ある意味いつもどおりである」）。コメディ寄りの作品で効く
- この声があるときは、語り手が気持ちや理屈を説明してもよい。説明くさい説明（感情の要約）と、語り手の味のある説明は別物。前者は `ai_tells.md` のとおり避ける
- エロの場面で、恥ずかしいはずのことになぜ今は興奮しているのか、を語り手が踏みこんで書くのも、この声の一つ（「させられている、というのも自分への言い訳だとわかっていた」）
- 使うかどうかは作品で決める

## 6. 段落と場面

- 段落は短く（一〜二文）。台詞と地の文を細かく交互に
- 場面は区切り線（`---` など）で切る。切ったあと、場所や時間を一行で置く
- 時間を飛ばすときは、時刻の見出しや、台詞だけの短い場面をいくつも並べる早送りが使える
- 激しいピークのあと、気の抜けたオチで抜く締め方がある（笑いで終わる）。余韻の一文で締めるより、作品に合えばこちら

## 7. 現実の小さなこと

- 体位を変えるときに抜けて入れ直す、髪が口に入る、汗で滑る、思わず二人で笑う
- 事後：ティッシュ、シャワー、シーツの染み、腰が立たない、声がかすれる、水を回し飲みする
- 萎えない程度に。一場面に一つか二つまで

## 8. 読点

> 地の文の読点は、読む人の息つぎのために打つ。文法の切れ目ごとには打たない。

| 打たない | ×の例 | ○の例 |
|---|---|---|
| 主語（〜が、〜は）のあと。特に短い文 | 「ズボンの中が、じんと重くなる。」「まいが先に、部屋に上がった。」 | 「ズボンの中がじんと重くなる。」「まいが先に部屋に上がった。」 |
| 修飾のつながりの途中 | 「お腹側の、ざらりとした天井」「二日目の、夕方」 | 「お腹側のざらりとした天井」「二日目の夕方」 |
| 目的語・場所のあと、すぐ短い動詞が来るとき | 「根元に、指が触れる。」「後ろに、〇〇が来ていた。」 | 「根元に指が触れる。」「後ろに〇〇が来ていた。」 |
| 副詞のあと（強調したいところ以外） | 「一気に、根元まで来た。」「すぐに、呼び出しが来た。」 | 「一気に根元まで来た。」 |

- 目安：短い文（30字くらいまで）は読点0〜1つ。長い文でも2つまで
- 打つところ：長い文の意味の切れ目、読み違えを防ぎたいところ、わざと間を作りたいところ
- わざとの間は残してよい（「何度も、何度も」「びくん、びくんと」）。ただし同じ場面でくり返さない
- 書いたあと、短い文に読点が2つ以上ある文と、主語のあとだけで切っている文を探して、外せるものは外す

## 9. 行為中の地の文の量

> 地の文で補いすぎない。行為の場面は、台詞・喘ぎ声・擬音が主役。地の文は、音と台詞だけではわからないこと（何を、どこに、見た目、感触）だけを書く。

- **目安**：行為の場面で、地の文が台詞と喘ぎ声より多くならないようにする。地の文の段落は、続けて2つまで。3つ以上続いたら、どれかを台詞か喘ぎ声にできないか考える
- **台詞の反応を地の文で書き足さない**：台詞のたびに「その声だけで、奥がきゅっと締まった」と反応を足すと、毎回同じ形になる。反応は、次の喘ぎ声や台詞で見せる。地の文で書くのは、一番効くところの一回だけ
- **擬音のあとで、同じことを言い直さない**：射精の音のあとに「熱いものが次々に弾けた」、潮の音のあとに「何かが噴き出した」と書かない。音でわからないこと（どこに、どんな見た目か）だけを書く
- **相手の気持ちを、地の文で読み取って書かない**：「痛くないように気をつけているのがわかった」のような、相手の内心の解説は、相手の台詞か行動で見せる
- **感じていることを地の文で長く書かない**：中の形がわかる、奥まで届いている、などは、短くまとめるか、本人の喘ぎ声に回す
  - **回すときは、喘ぎ声のエロさを落とさない。** 地の文の中身をそのまま台詞にすると、行為中に状況を説明する台詞になって冷める（×まい「かたいのも、先っぽのとこも、ぜんぶわかる……♡」）。回すのは、崩れた短い言葉と声だけ（○まい「おっき……っ♡　ん゛……かた、ぃ……♡」）
  - 喘ぎ声に回すと説明くさくなるなら、回さずに地の文を一文に縮めるほうを採る（○「少し身じろぎしただけで、中の形がわかった。」）
  - 地の文を減らすことが目的ではない。台詞・喘ぎ声・擬音が一番エロく聞こえる形が目的
- **動作は短く、まとめて**：「身体を起こして、脚のあいだにぺたんと座る。」のような段取りの地の文が続くなら、一文にまとめるか、台詞で流す
- 地の文を長く書いていいのは、場面の入り（場所、格好、空気）と、一番効かせたい一瞬（落差、体の本当の状態）
