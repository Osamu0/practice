# 100点と120点

> 本文を書く手順（メンバーの呼び方）は、スキル `spicy_novel_writing_team_jp`。

## 100点：読者の体験で決める

一行ずつの満点（減点がどこにもない状態）ではない。読者として通して読んだときの体験で決める。

1. **冷める瞬間が一度もない**（必須）：通して読んで、「ここ変」「こんなこと言わない」「説明くさい」で物語から引き戻されるところがない。ここは減点で見る
2. **作品の芯に届いている**：読み終わったとき、その作品の読後感（抜けた、甘く幸せ、など）に届いている。エロさ、温度、その人らしさは、ここで見る
3. **通し読みで判定する**：つなぎの台詞や地の文が普通でも、流れの中で効いていればいい。逆に、一行一行が整っていても、通して読んで冷めるなら100点ではない

- 「作者が直さなくていい」は、100点の**結果**であって目的ではない。作者が直すのは、読んでいて冷めたところ、温度が足りないところ
- 減点をなくすことだけを目指さない。危ないところを削って角のない文章にすると、温度が下がって芯に届かない
- 全編を同じ密度で磨かない。見せ場とつなぎを分ける

### いちばん大きいのは台詞

冷める瞬間のほとんどは、台詞で起きる。台詞は100点を決めるいちばん大きい部品なので、地の文より先に、いちばん時間をかけて見る。

- **ちゃんと話し言葉になっているか**：耳で聞いて自然か。書き言葉の読点、電報、助詞の入れすぎ、平らな言い切りになっていないか（`dialogue.md`）
- **変な話し言葉になっていないか**：話し言葉にしようとして、かえって不自然になっていないか（`dialogue.md` の「変な話し言葉」）
- **変な話し方・言い回しになっていないか**：その人がその場で本当に言う言い方か。理由の並べ立て、実況、段取り、含み、決め台詞になっていないか（`realism.md`、`author_edits.md`、`ai_tells.md`）
- **温度が足りているか**：素直で、甘くて、相手に投げる言い方か（`author_edits.md`）

## 120点

- 全部が100点で、読者がもう満足しているところへ、その満足の上をいくものが不意に来る。予想を裏切る話ではなく、期待を上回る話
  - ここが頂点だと思ったところから、もう一段深く行く
  - 落ち着いた優しい声のまま、限界の相手をもう一段先へ連れていく一言（「うん。でも、もう一回だけイってみようか」の型）
  - 外では余裕、心の声では崩れている、体はとっくに限界、の三つのずれ
  - 誰も書かないような、生々しい細部が一つ
  - 激しいピークのあとの、気の抜けたオチ
- 100点がそろっていないと、120点は効かない。前の粗が気になって、読者が満足していないから。**先に100点の土台（文体ルール、口調サンプル、文体サンプル）を作者と固める**
- 120点を予告しない。100点の流れのまま、ふいに来る
