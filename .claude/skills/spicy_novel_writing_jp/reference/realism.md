# 台詞と行為をリアルにする

> 根っこは一つ。台詞や行為を「読者に説明するため」に書かない。その場の二人の気持ちと欲から出たものにする。

| やらないこと | 例（×） | 代わりに |
|---|---|---|
| 理由や状況を並べて台詞にする | 「ワイン飲んで、腕組まれてたら、そうなる」「洗面所から、ずっと（我慢してた）」 | 気持ちそのもので返す（エロい、かわいい、欲しい、気持ちいい） |
| 相手の体の反応を口で報告する（実況） | 「自分から押しつけてる」「二回目」「腰、勝手に回ってる」 | からかう、褒める、求める言葉にする。様子は地の文と行為で見せる |
| 言い切りと一問一答で会話を組む | 「二十分くらい」「できる。」「じゃあ、どうしたいの」 | 疑問形で返してもいい。疑問形に答えなくても会話は成り立つ。言葉の代わりに行為で返してもいい |
| 事務的・段取りの台詞 | 「拭いたら入れたい」「さっきのは指。今度は口」 | 勢い・欲しさ・甘さのある言葉にする。段取りは地の文で流すか、書かない |
| 設定や前振りを「使わなきゃ」で書く | 夜につなげる「脱がせやすそう」、敏感なところだから毎回触る | 小道具は回収しなくていい。敏感なところは、効かせたい場面にとっておく |
| プロットに書いてあるから言わせる | 我慢できないはずの人に「シャワー浴びてから」 | その人がその場で本当にしそうなことを優先する。プロットとぶつかるときは、エロくてリアルなほうを採る |
| 場面の目的からずれる | 洗いっこが手マンだけ／ピロートークで世間話と行為を分けて並べる | その場面が何のためにあるかを先に決めて、台詞も行為もそこから出す |
| 場所を説明するための言葉を使う | 「くびれ」（カリのこと） | 実際の呼び方にする（カリ、亀頭、裏筋、おっぱい） |
| 進行・紹介を段取りとして書く | 司会や紹介の台詞で、番号や手順を毎回読み上げる | 楽しく短く。紹介したらすぐ中身へ |

## 行為の組み立て

- 行為を順番に一つずつこなす流れにしない。キスも、触るのも、舐めるのも、しごくのも、同時に、行ったり来たりしながら起きる
  - キスしながら胸を揉む／咥えながら、相手の手が胸や頭にある／入れたままキス／体位はつながったまま移る、抜けて慌てて入れ直すこともある／出したあと萎える前にまた手が伸びる／休憩の会話の途中でまた始まってしまう
- 物理的に無理な体勢にしない。一人の手や口が同時に二か所にある、のような矛盾を出さない。体位と動きを合わせる（バックで「突き上げる」としない）
- 行為中も二人が話す。喘ぎ声だけで進めない
