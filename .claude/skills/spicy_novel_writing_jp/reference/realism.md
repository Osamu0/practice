# 台詞と行為をリアルにする

> 根っこは一つ。台詞や行為を「読者に説明するため」に書かない。その場の二人の気持ちと欲から出たものにする。

| やらないこと | 例（×） | 代わりに |
|---|---|---|
| 理由や状況を並べて台詞にする | 「ワイン飲んで、腕組まれてたら、そうなる」「洗面所から、ずっと（我慢してた）」 | 気持ちそのもので返す（エロい、かわいい、欲しい、気持ちいい） |
| 相手の体の反応を口で報告する（実況） | 「自分から押しつけてる」「二回目」「腰、勝手に回ってる」 | からかう、褒める、求める言葉にする。様子は地の文と行為で見せる |
| 言い切りと一問一答で会話を組む | 「二十分くらい」「できる。」「じゃあ、どうしたいの」 | 疑問形で返してもいい。疑問形に答えなくても会話は成り立つ。言葉の代わりに行為で返してもいい |
| 事務的・段取りの台詞 | 「拭いたら入れたい」「さっきのは指。今度は口」 | 勢い・欲しさ・甘さのある言葉にする。段取りは地の文で流すか、書かない |
| 設定や前振りを「使わなきゃ」で書く | 夜につなげる「脱がせやすそう」、敏感なところだから毎回触る | 小道具は回収しなくていい。敏感なところは、効かせたい場面にとっておく |
| プロットに書いてあるから言わせる | 我慢できないはずの人に「シャワー浴びてから」 | その人がその場で本当にしそうなことを優先する。プロットとぶつかるときは、エロくてリアルなほうを採る |
| 場面の目的からずれる | 洗いっこが手マンだけ／ピロートークで世間話と行為を分けて並べる | その場面が何のためにあるかを先に決めて、台詞も行為もそこから出す |
| 場所を説明するための言葉を使う | 「くびれ」（カリのこと） | 実際の呼び方にする（カリ、亀頭、裏筋、おっぱい） |
| 進行・紹介を段取りとして書く | 司会や紹介の台詞で、番号や手順を毎回読み上げる | 楽しく短く。紹介したらすぐ中身へ |

## 行為の組み立て

- 行為を順番に一つずつこなす流れにしない。キスも、触るのも、舐めるのも、しごくのも、同時に、行ったり来たりしながら起きる
  - キスしながら胸を揉む／咥えながら、相手の手が胸や頭にある／入れたままキス／体位はつながったまま移る、抜けて慌てて入れ直すこともある／出したあと萎える前にまた手が伸びる／休憩の会話の途中でまた始まってしまう
- 物理的に無理な体勢にしない。一人の手や口が同時に二か所にある、のような矛盾を出さない。体位と動きを合わせる（バックで「突き上げる」としない）
- 行為中も二人が話す。喘ぎ声だけで進めない

## 場面を頭の中で再生しながら書く（作者の直し）

> 作者の言葉：「人間は想像をしながら同時に物語を描ける。考えてから書くんじゃなくて、書きながら考える。大まかな流れは考えるけど、書きながら脳内で補完する」

- 大まかな流れ（プロット）は先に決める。でも、台詞と反応は、プロットの項目から組み立てない
- 一行ずつ、その瞬間を頭の中で再生してから書く。誰がどこにいて、何が見えていて、手はどこにあって、次の一秒に何が起きるか。その場にいる人の口から、そのとき本当に出る言葉だけを書く
- 再生していると、項目にない小さなことが出てくる（手が止まる、仲間同士で顔を見合わせる、変な間で笑う）。それを拾う。拾ったものが、いちばん自然に読める
- 見えていないことは言わせない。たとえば、半分しか勃っていないことは、大きくなっていくのを見るまで、その場の女の子にはわからない
- 驚きや感想は、相手への実況より、仲間同士の小声のほうが自然なことがある（○「……ねえ」「……うん」「……やばくない？」「やばい」）
- 味や感触は、そのとき口に入っているものを考えて書く。咥えはじめは我慢汁なので「しょっぱ」でいい。出したあとの竿は精液と相手の汁にまみれているので、同じ「しょっぱ」にはならない（まざっている別の子の味のほうが気になる、など）
- 決まった言葉（「あっつ」）に逃げない。その場面で本当に気になることを言わせる


## 台詞の一本ずつにも、想像を働かせる（作者の直し）

> 作者の言葉：「想像力を働かせるってのは場面だけに限った話じゃない」

場面の絵が見えていても、台詞を「キャラらしさを見せる」「ツッコミで笑いを足す」「読者に背景を伝える」ために書くと、書き手の考えが透けて見える。台詞を書く前に、一本ずつ次を確かめる。

| 確かめること | ×（作者が引っかかった例） | なぜ変か |
|---|---|---|
| 今の体で、その言葉が出るか | 咥えていた人が「私の口から出てきたんだけど」 | 口を離したのは喋るため。出てきたことを言う理由がない |
| 自分のした行動と合っているか | 選ばれたくてお尻を並べた人が、ほかの人が選ばれて「知ってた」 | 知っていたなら、なぜ並べたのか |
| エロの流れから外れていないか | 「その状態で並んでるの、ちょっと面白いんだけど笑」 | 場をいじるコメントで、欲しい気持ちから出ていない。ツッコミやかけ合いの笑いは、流れを止めない量だけ |
| 地の文が読者への説明になっていないか | 「歌番組で横一列に並んでいる四人が」 | 表の顔を読者に伝えようとしている。〇〇（男）の目に入っているのは、推しが尻を向けて全部見えている壮観。その目で見たものを書く |

- 台詞は、その人がその瞬間に欲しいもの・感じているものから出す。気の利いた返し、オチ、キャラの紹介になる台詞は削る
- 迷ったら、その台詞を消して読む。流れが止まらず、エロが濃くなるなら、要らなかった台詞
