# 擬音（行為音）と喘ぎ声

> 行為音も、喘ぎ声と同じように、表記で激しさがわかるようにする。

## 置き方

- 擬音（行為音）は、独立した行に置く（抽送、水音、挿入、射精、体がぶつかる音、道具、潮、きしみ など）。地の文より一段深く下げる作品が多い（作品の表記で決める）
- 口でする行為の音（キス、舐める、吸う、咥える、フェラ、えずき）は、台詞の中に混ぜてよい。独立した行にしてもよい。場面で使い分ける（`dialogue.md`）

## 喘ぎ声

- 喘ぎ声のレベルと作り方は `spicy_novel_jp` の `references/aegigoe_skills.md`
- 喘いでいる最中に、自分の声を説明させない
- ずっと同じレベルにしない。その都度の感じ方で決める
- 下の型の例は、♡を外して書いてある。♡をつけるかどうか、どれだけつけるかは、雰囲気と女の子の状況で決める（`dialogue.md`）

### 喘ぎ声の型

> 状況ごとに、声の形が違う。同じ「イく」でも、場面で変える。

| 状況 | 声の形 | 例 |
|---|---|---|
| 何かをしながら、気持ちよさが漏れはじめる（洗う、舐める、こすりつける） | 息だけの短い声に、照れ笑いが混ざる | ふぅ　ふわ　はぁ　へへ…… |
| 匂いを嗅ぐ、一人でいじりはじめる | 小さな「ぉ」、吸いこむ息 | すぅぅ……ぉ……ぉ゛ |
| 声を抑えて、小さくイく | 頭に小さい「ぁ」「ぃ」がつく。息が言葉より先に漏れる | ぁぃく……いく……ぁっ、ぃく…… |
| ゆっくり入れられて、こらえる | 長く押しつぶした声 | うぅううう……ッ！ |
| 一番奥まで届いた瞬間 | 低く詰まった声 | ぐうぅぅっ |
| 浅く小刻みに突かれる | 短い「お」「あ」の連打に、訴えが混ざる | おっ　おっ　あっ　だめっ |
| 本気で感じはじめる | 母音に濁点。音が濁って詰まる | ん゛ん゛ッ　あ゛っ　お゛っ　ぅお゛お゛ッッ |
| 言葉まで崩れる | 言葉の一文字ずつに濁点がつく。名前にもつく | き゛も゛ち゛ぃ　ま゛って　い゛く゛い゛く゛ |
| 呂律が回らない | 言葉の音が別の音にすり替わる | や゛へ゛て（やめて）　ひんじゃう（死んじゃう） |
| 痛み・不意の衝撃（叩かれる、急に奥） | 「い」の高い悲鳴 | ぃぎいぃッッ！！ |
| 優しく焦らされる、触れるか触れないか | 細く高い声 | ひぃっ　ひぃ　んい…… |
| 口がふさがっている（咥えている、口に出される） | 閉じた口の、濁った「ん」 | ん゛ん゛ッッ！？　ん゛ッ　ん゛〜〜っ　ん゛…… |
| 喉の奥まで | 喉が詰まる音 | ぐぶぶ……　んぐっ |
| 何度もイって、低く感情のない声になる | 喘ぎではなく、うめくような低い声。語尾が「ぐ」に落ちる | あー、やばい……いぐ……もうむり、いぐ……ぁいぐっ……ぐぅっ……ぐっ…… |
| 深くイく（声も出ない） | 途切れ途切れ。間が長い | ……あっ……ぐッッ、、、……ぃぐ……いっ…………ぐ、、、 |
| 上りつめて叫ぶ | 「いく」を重ねて、最後は言葉にならない伸ばし | いくっ、いくいくいくッッ……〜〜〜〜ッッ！！ |
| イったあと | 重い息をくり返す | はふぅぅっ……ふぅぅ……ふぅぅ……　はっ、はっ、はっ |

### 喘ぎの中に混ざる言葉

- 訴え：「まって」「だめ」「イったばっか」「いまイった」「もれる」
- 体で何が起きているか（幼い言葉で）：「おなかつぶれる」「おくつぶれる」「あたまばかになる」「カリカリしちゃだめ」
- 甘え・駄々：「やだぁ」「もっとぉ」「ちゅーしたい」「抜かないで」
- 限界を越えたとき：謝る・懇願する（「ごめんなさい」「ゆるしてください」「もうやめて」「しんじゃう」）。何に謝っているのかわからない、と地の文が添えてもいい
- 崩れた敬語：ふだん敬語を使わない相手にも、イく瞬間だけ敬語が出る（「い゛き゛ま゛すッッ」）。従ってしまっている落差になる

### 声と地の文の組み合わせ

- ふだんの声（歌声、テレビの声、凛とした声）と比べて、低く、感情のない声でイく、という落差を、地の文で一回だけ書く
- 深くイったときは、声が途切れたことを、相手の一言で拾ってもいい（「今、深くイったね」）
- 同じ文字を5文字以上続けない。伸ばしの「〜」や「ッ」も、4つまでに収める

### 強さの使い分け

| 強さ | 行為音 | 喘ぎ声 |
|---|---|---|
| 基本（実用ポルノ） | 全角。♡なし。短めから中くらい | ♡は少し |
| 盛り上がり | 長くする。連打する | ♡が増える |
| ハードコア・ピーク | 長く連打。♡や半角カナも混ぜる | 半角カナ＋濁点、♡♡ |

- 半角カナは強い記号。理性が飛んだ瞬間や連続絶頂など、ピークに絞る。
- 喘ぎ声が半角になったら、行為音も半角にする（全体の速さがそろう）。
- 甘めの話（デートなど）では、♡の行為音は控える。

### 長さと組み立て方

- 抽送、水音、フェラの音、電マの振動、射精のように、続いている行為の音は長めに書く（1行に5〜10音くらいを連ねる。途中で強い音を混ぜたり、表記を崩したりして変化をつける。例：ずちゅっ、ずちゅっ、ずちゅっ、ずちゅっ、ずちゅんっ）。
- キスの一回、びくんっ、ぷしゃっ、のような単発の音は短いままでいい。
- 同じ場面の中で段階を上げていく（ふつう → 激しい → 連打）。
- 1行の詰め方でも速さを出す（ゆっくりのときは1行に1音、激しいときは1行に音を詰める）。
- 同じ文字を5文字以上続けない（ヴヴヴヴッは4文字まで）。
- 地の文で、行為音を説明しない。音と地の文で同じことを二度書かない（×「手首が鳴る。」＋「ぎちっ」、×「透明な汁が噴き出した。」＋「ぷしゃっ」）。
- 地の文は、音だけではわからないこと（何を、どこに、見た目、感触）だけを書く。音が何の音かは、直前の行為でわかるようにする（「ローターを、クリに押し当てる。」→「ぶぶぶ……ブブブッ」）。
- 続けて起きる音は、1行にまとめていい（抜いてあふれる：「ぬぽっ……とろぉ……」）。
