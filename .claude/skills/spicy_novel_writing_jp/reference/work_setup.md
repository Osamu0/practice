# 作品ごとに決めること

> 新しい作品を始めるとき、作品の `文体ルール.md` に、この一覧の答えを書く。スキルにあることは写さない。

| 項目 | 選ぶもの | 例 |
|---|---|---|
| 作品の芯 | 読後感、ジャンル、いちばん大事にすること | 「抜けた」／甘く幸せ／堕ちる |
| 視点 | 三人称で誰に寄せるか。場面ごとに切り替えるか | ヒロインの側から／男の側から／場面ごとに切り替え（切り替えは区切り線で） |
| 心の声 | 使うか。使うなら誰の | なし／男だけ／二人とも（`inner_voice.md`） |
| 語り手の声 | 語り手がからかう・ツッコむか | なし／あり（`narration.md`） |
| ♡・笑 | 使うか。誰がよく使うか | まいはよく使う、男は使わない |
| 「、、、」 | 言いよどみに使うか | 使わない／使う |
| 喘ぎ声の強さ | 基本のレベル、ピークのレベル、ハードコアの出し方 | 場面で固定しない／基本2〜3、ピーク3〜4 |
| 擬音の表記 | 下げ方、半角カナを使うか | 地の文より一段深く下げる |
| 表記 | `dialogue.md` の「表記」の既定から変えるところ | 台詞末の「。」をつける、など |
| 声の区別 | 人ごとの距離、語尾の癖、入り方、崩れ方、♡・笑の量 | 表にして書く（`dialogue.md`） |
| 男の台詞の温度 | 余裕・勢い・受け身など | 余裕のある甘やかし／受け身の童貞 |
| キャラクター | 芯、口調サンプル | 口調サンプルは性格から作る。性格と口調は一緒に決める |
| 校閲 | 足す担当 | 120点担当、など |

## 作るものの順番

1. 企画・設定・キャラクター・口調サンプル（`spicy_novel_jp`）
2. 作品の文体ルール（この一覧）
3. 文体サンプル：物語とは別の場面で、型をいくつか見せる。作者に読んでもらって直し、「これなら100点」になるまでくり返す
4. アウトライン、プロット、本文（`writing_team.md`）
