# 執筆チーム（本文を書く流れ）

> `novel_idol`・`novel_shinomiya` の執筆チームをまとめたもの。目的は、読者が「ここが変」と引っかかって興奮が冷めないように、作者の手直しのいらない100点で出すこと。その上で、120点を狙う。

## 100点と120点

- **100点**：台詞、行為、音、地の文のどれも、引っかかりなく、エロく、その人らしい。作者が読んで直すところがない
- **120点**：全部が100点で、読者がもう満足しているところへ、その満足の上をいくものが不意に来る。予想を裏切る話ではなく、期待を上回る話
  - ここが頂点だと思ったところから、もう一段深く行く
  - 落ち着いた優しい声のまま、限界の相手をもう一段先へ連れていく一言（「うん。でも、もう一回だけイってみようか」の型）
  - 外では余裕、心の声では崩れている、体はとっくに限界、の三つのずれ
  - 誰も書かないような、生々しい細部が一つ
  - 激しいピークのあとの、気の抜けたオチ
- 100点がそろっていないと、120点は効かない。前の粗が気になって、読者が満足していないから。**先に100点の土台（文体ルール、口調サンプル、文体サンプル）を作者と固める**
- 120点を予告しない。100点の流れのまま、ふいに来る

## 流れ（1章ごと）

1. **プロット**：編集長が書く。場面ごとの空気、主導権、気持ちの向き、ゴール、必ず入れるものを書く。何をするか、どの順番か、何を言うかは書きすぎない。台詞の例は草案にとどめる（書くと役者・執筆がそのまま使う）
2. **掛け合い**：役者（女役・男役）が、場面ごとに台詞の掛け合いをする（下）
3. **執筆**：掛け合いを土台に初稿を書く
4. **校閲**：校閲担当が同時に初稿を読み、指摘を返す（ファイルは書き換えない）
5. **120点の工程**：100点に届いた初稿で、場面ごとに「満足の上をいく」ものを探して足す
6. **編集長**：指摘をまとめて直す。最後に通して読む。本文メモを書き足して、コミットする

## 掛け合い

- 役者は別々のエージェントにして、記憶を分ける。相手の次の一言を知らないまま返すので、一人で両方書くより「こう言われたから、こう返す」が本当に起きる
- 役者が読むもの：その場面のプロット、自分のキャラの設定と口調サンプル、作品の文体ルールと、このスキルの `dialogue.md`・`realism.md`
- 役者が返すもの（一手）：台詞を1〜3つ（話し言葉で、名前はつけない）と、短いト書き（誰が何をしたかだけ）。心の声を使う作品では、心の声を一つ添えてよい。説明や解説は書かない
- 返すとき、まずその場で自然な100点の返しを考え、同じ流れのまま、それより刺さる返しがないかを探す。あればそちらを出す
- 監督（編集長）：場面のはじめに、その役者から見た状況を渡す。相手の一手をそのまま渡す（相手の考えは渡さない）。必要なときだけ、相手に見えないメモで方向を出す（空気、主導権、ゴール）。細かい指示はしない
- 執筆への渡し方：掛け合いの記録を渡す。執筆は台詞をなるべくそのまま使い、ト書きを地の文と行為音に起こし、五感と細かい動きを足す

## 執筆

- 作品の資料（企画、設定、アウトライン、プロット、口調サンプル、文体ルール、本文メモ、書いた章）と、このスキルの必要なファイルを読んでから書く
- 文体サンプルは、書きはじめる前に読むだけ。見ながら書かない（地の文・台詞・擬音の並びを写してしまう）
- 書き終えたら一度通して読む。台詞だけは、声に出すつもりでもう一度読む
- 本文で新しく決めた細かい事実を、最後に箇条書きで返す

## 校閲の役割

| 担当 | 見るもの |
|---|---|
| 整合 | 設定・プロットとの食い違い。一つの場面の中の食い違い（体勢、手や口の位置、服、誰がどこにいるか）。物理的に無理な体勢。視点の揺れ。キャラの芯からのずれ |
| 文章 | 誤用、日本語としておかしい文、説明調、近くで同じ言葉・擬音の重なり、表記、行為音のルール（`sounds.md`） |
| キャラ・口調 | 口調サンプルとキャラ設定に合っているか。話し言葉か。名前を隠しても誰かわかるか。台詞の温度（`author_edits.md`） |
| エロ | 行為が混ざりあっているか（順番にこなしていないか）。ラリーの長さと緩急。喘ぎ声のレベルが状況に合っているか。五感と生々しさ |
| AIっぽさ | `ai_tells.md`。ただし甘さと感情を削る方向に直さない |
| 読者 | その場の二人なら本当にそう言うか、そうするか。冷めるところはないか。その章だけで抜けるか |

- 指摘ごとに、行番号、該当の文（そのまま引用）、何が問題か、直し案を書く。重さを付ける（必ず直す／直したほうがいい）。自分の役割の範囲に絞る。問題がなければ「なし」
- 作品によって、校閲を足してよい（例：120点担当）

## 編集長

- 校閲の指摘を見比べて、採るものを決める。ぶつかるときは、作品の設定・文体ルールに近いほうを採る
- 作者には、仕上がった本文と、あとの章に効く事実だけを短く伝える
- 作者の直しや感想は `feedback_loop.md` のとおりルールに戻す
