# spicy_novel_writing_team_jp

本文を、役割を分けたメンバーで書くための手順。メンバーは `.claude/agents/` に最初から雇ってある。作品ごとに執筆チームを作り直さない。作品のフォルダには、その作品だけの違い（`reference/work_team.md` の項目）だけを書く。

- 文体（台詞、地の文、擬音、喘ぎ声、AIっぽさ）：`spicy_novel_writing_jp`
- 企画 → 設定 → アウトライン → プロット：`spicy_novel_jp`
- **このスキル**：編集長（メインのClaude）が、メンバーを呼んで本文を仕上げる手順

目的は、読者が「ここが変」と引っかかって興奮が冷めないように、作者の手直しのいらない100点で出すこと。その上で120点を狙う（`spicy_novel_writing_jp` の考え方）。

## メンバー

| エージェント | 役割 | 書き換えるか |
|---|---|---|
| `novel-actor-female` | 掛け合いの女役 | しない（一手を返すだけ） |
| `novel-actor-male` | 掛け合いの男役 | しない（一手を返すだけ） |
| `novel-writer` | 初稿を書く。編集長に頼まれた場面の書き直し | 本文ファイルを書く |
| `novel-review-consistency` | 校閲・整合 | しない |
| `novel-review-prose` | 校閲・文章 | しない |
| `novel-review-voice` | 校閲・キャラ口調 | しない |
| `novel-review-erotic` | 校閲・エロ | しない |
| `novel-review-ai-tells` | 校閲・AIっぽさ | しない |
| `novel-review-reader` | 校閲・読者 | しない |
| `novel-plus120` | 100点の初稿で、満足の上をいくものを探す | しない（案を返す） |
| `novel-ideas` | ネタ出し（作品で使うと決めたときだけ） | しない |

## 流れ（1章・1話ごと）

1. **準備**：作品の `執筆チーム.md` を読む（なければ `reference/work_team.md` の既定で動く）。その章のプロットがあるか確かめる。なければ `spicy_novel_jp` でプロットを作る（場面ごとの空気、主導権、気持ちの向き、ゴール、必ず入れるもの。台詞の例は書きすぎない）
2. **ネタ出し**（作品で使うときだけ）：`novel-ideas` を呼ぶ。編集長は、ありがち度の高いほうから3分の1を捨てて、プロットに足すものを選ぶ
3. **掛け合い**：場面ごとに、女役と男役を交互に呼ぶ（`reference/kakeai.md`）。記録を場面ごとにファイルに残す
4. **執筆**：`novel-writer` に、掛け合いの記録と資料を渡して初稿を書かせる
5. **校閲**：校閲6人を**同時に**呼ぶ（`reference/review.md`）。ファイルは書き換えさせない
6. **編集長の直し**：指摘をまとめて直す。指摘が多いとき、場面ごと書き直したほうがいいときは、その場面だけ `novel-writer` に戻す（必要なら、その場面の掛け合いからやり直す）
7. **120点**：100点に届いたら、`novel-plus120` を呼ぶ。案から、芯を外さず満足の上をいくものだけを採って入れる。入れたところは、校閲の観点で編集長が見直す
8. **仕上げ**：編集長が通して読む。作品の本文メモに章ごとのメモを書き足す。コミットする
9. **作者へ**：作品の決め（`work_team.md` の「作者に見せるもの」）に従って渡す。作者の直しや感想は `spicy_novel_writing_jp` の `reference/feedback_loop.md` でルールに戻す

## 既存の本文を直すとき

- 直す観点（読点、地の文の量、喘ぎ声、温度など）を決めて、`novel-writer` に場面ごとに直させる。台詞の往復が薄く、地の文で補っている場面は、その場面だけ掛け合いで台詞を作り直してから書き直させる
- 直したあと、校閲を呼ぶ。観点に関係する校閲だけでもよい
- 直した結果と、直さなかった理由（わざとの読点など）を、作品の記録に残す

## 呼ぶときの渡し方（全員共通）

- **作品のフォルダ**と、**その章のファイル**のパスを渡す。メンバーは、`work_team.md` の「読むもの」に書いた資料を自分で読む
- 作品の `執筆チーム.md` の、そのメンバーに関係する追加の観点を渡す
- 編集長の考え（ほかのメンバーの指摘、相手の役者の考え、120点の狙い）は、必要なもの以外渡さない
- 返してほしい形を伝える（メンバーのファイルに書いてある形）
