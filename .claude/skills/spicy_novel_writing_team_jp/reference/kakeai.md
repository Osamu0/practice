# 掛け合い（監督：編集長）

> 台詞を、一人で両方書くのではなく、女役と男役がそれぞれの役として相手の言葉に返すことで作る。相手の次の一言を知らないまま返すので、「こう言われたから、こう返す」が本当に起きる。一人で両方書くと、両方の考えを知ったうえで都合よく組み立ててしまい、反応を地の文で補うことになる。

## 役者

- `novel-actor-female`（女役）と `novel-actor-male`（男役）。別々に呼んで、記憶を分ける
- 同じ場面の中では、同じ役者を続けて使う（SendMessage で続ける）。場面が変わったら、新しく呼んでもよい
- 一人の役者が知っているのは、自分の役と、監督が伝えた相手の台詞・見える動きだけ。相手が何を考えているか、相手への監督のメモは知らない

## 監督がすること

1. **場面のはじめ**：その役者から見た状況を渡す（場所、格好、それまでの流れ、自分の気持ち、場面のゴール）。どちらが先に動くかを決める
2. **一手ずつ**：相手の一手（台詞とト書き）を、そのまま渡す。相手の考えや監督のメモは渡さない
3. **監督のメモ**：必要なときだけ、相手に見えない形で方向を出す。出すのは、場面の空気、主導権、気持ちの向き、ゴール、「必ず入れるもの」が抜けそうなとき。何をするか・何を言うかの細かい指示はしない
4. **モブ**：名前のない人物（同僚、スタッフなど）は、監督が書いてよい。短く、その人らしい一言で
5. **区切り**：場面のゴールに着いたら区切る。長くなりすぎたら、監督のメモでゴールに向けて寄せる

## 役者が返すもの（一手）

- 台詞を1〜3つ（話し言葉で。名前はつけない）と、短いト書き（誰が何をしたかだけ）
- 心の声を使う作品では、心の声を一つ添えてよい
- 説明や解説は書かない

## 記録

- 場面ごとに、作品のフォルダのプロットの近く（例：`プロット/〇〇_掛け合い.md`）に残す
- 形：

```
## 場面1：（場所）

### 1 （役の名前）
（ト書き）
「台詞」
「台詞」

### 2 （役の名前）
（ト書き）
「台詞」
```

- 区切りごとにコミットしてよい（長い掛け合いが途中で切れても、続きから再開できるように）

## 執筆への渡し方

- 掛け合いの記録を渡す。執筆は台詞をなるべくそのまま使い、ト書きを地の文と行為音に起こし、五感と細かい動きを足す
- 同じ人の台詞が続くところは、地の文を挟むかまとめる
- 喘ぎ声の強さと形は、執筆が `spicy_novel_writing_jp` の `sounds.md` と `aegigoe_skills.md` に合わせる
