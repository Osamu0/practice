# 作品の `執筆チーム.md` に書くこと

> 作品ごとに執筆チームを作り直さない。チームは `.claude/agents/` に雇ってある。作品の `執筆チーム.md` には、この作品だけの違いを書く。書いていない項目は、下の既定で動く。

| 項目 | 書くこと | 既定 |
|---|---|---|
| 読むもの | メンバーが読む作品の資料（企画、設定、キャラ、アウトライン、プロット、口調サンプル、文体ルール、文体サンプル、本文メモ、前の章、行為リストなど）のパス | 作品のフォルダにある企画・設定・アウトライン・その章のプロット・口調サンプル・文体ルール・本文メモと、直前の1〜2章の本文 |
| 章の単位とファイル名 | 「話」「章」「本目」、本文とプロットと掛け合いの置き場所 | `本文/`、`プロット/`、`プロット/〇〇_掛け合い.md` |
| 役ありの本 | 役を演じる章があるか。あるなら、役になりきる・本人の人柄を持ちこまない（引き継ぐのは体だけ）・メタ発言をしない | 役なし |
| 校閲に足す観点 | 作品ならではの観点を、どの校閲が見るか（例：堕ちの段階はキャラ口調とエロ、女の性欲発散はエロ、表と裏の落差はエロ） | なし |
| 作品の文体ルールの受け持ち | 作品の `文体ルール.md` の節ごとの担当 | 作品の文体ルール全部を、文章とキャラ口調が見る |
| 足す・外すメンバー | ネタ出しを使うか、校閲を足すか、120点を使うか | ネタ出しなし、120点あり |
| 作者に見せるもの | プロットや掛け合いを作者に見せるか、本文だけを渡すか | プロットは作者と決める。掛け合いの記録と校閲の指摘は見せない |
| 一章の立ち位置 | 各章が単体で抜けるべきか（オムニバス）、連載として続くか | 連載（前の章との整合を強く見る） |
