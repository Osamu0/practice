## 一文の企画
iPhone を縦に持った1人のプレイヤーが、手紙の国のまん中に立つ大ポストに四方から群がるシミ（紙を食う虫とインクのにじみ）を指で切り払い、稼いだ切手で買った封書を次の便の戦場で切り開けて、中から出た便り人（自動で戦う仲間）とまじない葉書で守りを厚くしていく。何もない指一本の守りが、封を切るたびににぎやかな陣に変わっていき、大ポストが倒れても、押してもらった消印で強くなって、前の配達より遠くの便まで届くのが気持ちいいゲーム。

## この作品の言葉（用語の対応）
オーナーの言葉と、この作品の言葉。02 で確定する（`開発チーム.md` の「表記」は企画書の用語待ち）。

| オーナーの言葉 | この作品の言葉 | 中身 |
|---|---|---|
| 防衛対象の塔 | **大ポスト** | 手紙の国のまん中に立つ、国じゅうの手紙をあずかる大きなポスト。倒れると配達が終わる |
| モンスター（敵） | **シミ** | 紙を食う虫（紙魚）と、こぼれたインクのにじみ。四方の紙の端から湧いて、大ポストをかじりに来る |
| 自分自身の攻撃 | **指のナイフ** | プレイヤーの指は、封を切るペーパーナイフ。シミも封書も、これで切る |
| お金 | **切手** | シミを払うと落ちる。窓口で封書を買うのに使う。配達が終わると消える |
| ショップ | **窓口** | 便と便のあいだに開く郵便の窓口。封書を買う |
| パック | **封書** | 封蝋で閉じた手紙。窓口では開けられない（受け付けるだけ）。次の便で戦場に配達されて落ちてくる |
| パックを開ける | **封を切る** | 戦場の封書を指のナイフで切ると、封蝋が割れて中身が飛び出す |
| 仲間 | **便り人（たよりびと）** | 封書から出てくる、切り紙の住人。1人ずつ攻め方と力が違い、自動でシミを払う |
| 魔法の書 | **まじない葉書** | 封書から出てくる、一筆書きのまじないが書かれた葉書。特別な効果を起こす |
| 戦闘1回 | **便（びん）** | 第1便、第2便…と数える。1便が終わると窓口が開く |
| 挑戦1回（塔が壊れるまで） | **配達** | 第1便から、大ポストが倒れるまでのひと続き |
| 持ち越すポイント | **消印（けしいん）** | 便を生き延びるたびに押してもらえる。配達が終わっても消えない |
| 強化の画面 | **消印帳** | 消印を使って、便り人・まじない葉書・指のナイフ・大ポストを強くする |
| 図鑑 | **宛名帳** | 出会った便り人とまじない葉書の一覧 |
| レア度 | **封蝋の色** | 薄い赤 → 青 → 緑 → 紫 → 金（色の段数は 03 で決める）。封蝋が厚いほど封を切るのに手間がかかる |

## コアの面白さ
- **プレイヤーの動詞**
  - **切る**：画面を押さえて、指のナイフでシミを切る。最初の数便は、これしかできない
  - **開ける**：戦場に落ちてきた封書を切る。シミを切る手を止めて封を切るので、開封そのものが戦いの中の判断になる
  - **買う**：窓口で、切手を何通の封書に、どの封蝋の封書に使うかを選ぶ
  - **合わせる**：便り人の自動の攻めと、自分の指を組み合わせる。便り人が苦手な方向や、硬いシミを自分で受け持つ
  - **使う**：まじない葉書の効果を、いちばん効くときに起こす（いつ起こすかは未決 #7）
  - **押してもらう・書き足す**：倒れたら消印をもらい、消印帳で強くして、また第1便から配達に出る
- **そのときの気持ち**
  - 第1便：指一本で四方を守る。「手が足りない」「間に合わない」
  - 封書が落ちてくる：「シミを切るか、封を切るか」。切ればきっと楽になるが、その間に大ポストがかじられる
  - 封蝋が割れる：「何が出た？」。出た便り人がすぐ隣のシミに向かっていく。出たものがその場で戦力になる
  - 便り人が増える：自分が触っていない方向でシミが払われていく。「陣ができてきた」。指は、いちばん危ないところだけに向けられるようになる
  - まじない葉書：押し寄せた群れを一度にひっくり返す。「ここで使ってよかった」
  - 大ポストが倒れる：「あと1便だった」。でも消印がたまっていて、何を書き足せば次はもっと遠くまで行けるかが見えている。「もう一回」
- **1回の遊び**（見積もり）
  - 1便：60〜120秒
  - 窓口：10〜30秒（何を買うかを選ぶだけ。待たない）
  - 1配達：最初は5〜10分。消印で強くなるほど長くなり、数十分になる
  - 消印帳：1〜3分
  - 配達と消印帳がくり返し続くので、何時間でも続けられる。便の途中でやめても、その場から戻れるようにする（保存の形は 02・03 で決める）

### 1便の流れ（オーナーの①〜⑤を、この作品の言葉で）
1. 戦場の中心に大ポスト。四方の紙の端からシミが湧いて、大ポストに向かって歩いてくる（①）
2. プレイヤーは指のナイフでシミを切る。第1便は便り人がいないので、指だけで守る（①）
3. 前の窓口で買った封書が、便の始まりと途中に戦場へ配達されて落ちてくる（②）。窓口では開かない
4. 落ちた封書を指で切ると封が開き、便り人かまじない葉書が飛び出す（③）。便り人はその場所に立って、自動でシミを払いはじめる
5. 便り人が増えるほど、守れる方向と攻め方が変わる（④）。プレイヤーは、便り人の手が届かないところを指で受け持つ
6. 便を生き延びると消印がもらえ、窓口が開く。切手で次の便の封書を買う（②）
7. 大ポストが倒れたら配達は終わり。便り人は宛名帳に残るが、戦場からはいなくなる。たまった消印で消印帳を書き足し、また第1便から配達に出る（⑤）。「前の配達の便の数」をこえるのが目あて

### 指で切る形（iPhone 縦持ち）
オーナーの「カーソルを敵に重ねて攻撃」は、iPhone では「指で押さえたところを攻撃」になる。指が敵や封書を隠す問題への手当てを、既定の形として決める（提案。02・04 のプロトタイプで確かめる）。

- **押さえている間、切り続ける**：画面を押さえているあいだ、指のナイフはその場所を一定の間隔で切り続ける。何時間も遊ぶので、連打させない（連打は指が疲れる）
- **切る輪は指の少し上**：切る場所は、指の真下ではなく、指の少し上に出る輪（切る輪）にする。輪の中のシミを切る。指の下に隠れたシミではなく、目で見えている場所を切れる。どれだけ上にずらすかは設定で変えられるようにする（ずらさない、も選べる）
- **切る輪を大きめに**：輪は見た目より少し大きく当たる。小さなシミを指先でぴったり狙わせない
- **隠れたものの印**：指の下や輪の外の近くに封書があるときは、その封書の封蝋の色を、輪のふちに小さな印で出す。「指の下に金の封書がある」がわかる
- **大事な数字は上に**：大ポストの残りの丈夫さ、便の番号、切手は画面の上の端にまとめる。指と手のひらで隠れる下の端には、何も大事なものを置かない
- **縦長の戦場**：縦持ちの画面は上下に長いので、上下から来るシミは遠く、左右から来るシミは近い。左右からはすぐ届く、上下からは数は多いが遠い、という方向の違いを、遊びの差として使う（提案。03 で決める）
- **振動は使えない**：iOS Safari は振動に対応しないので（市場調査 5）、切ったときの手ごたえは、絵（封蝋のかけら、シミが散る）と音で出す

## 売り（3つまで）
1. **封を切るのも戦いのうち**。封書は戦場に落ちてくる。開けるには、シミを切っている指をそちらに向けなければならない。「いま切るか、あとで切るか」を、戦いの真ん中で決める
2. **指一本の守りが、封を切るたびに陣になる**。1人ずつ攻め方の違う便り人が、開けた場所に立って自動で戦う。自分の指と便り人の自動の攻めを合わせて、四方を守る形が、配達ごとに毎回違う
3. **倒れても、前より遠くへ。待たない・払わない**。大ポストが倒れても、消印で強くなって、すぐ次の配達に出られる。スタミナ、待ち時間、回数制限、課金はない（市場調査 2・提案2）

## 遊ぶ人と場所
- **遊ぶ人**：まずオーナー本人。そのうえで、封を開ける一瞬が好きで、守りの陣が少しずつ育つのが好きで、「あと1便」をくり返すのが好きな人。片手で、空き時間にも、長い時間にも遊ぶ
- **プラットフォーム**：iPhone のブラウザ（Safari）。縦持ち・片手。1人用・オフライン・課金なし・保存は端末内（既定。`開発チーム.md`）。ホーム画面に置くWebアプリとして使うのを想定する（届け方は 02 で決める）
- **1回の遊ぶ時間／クリアまで**：1回は数分〜何時間でも。終わり（エンディング）を置くかは未決 #6。置くなら、MVPは「決めた便の数まで届く」まで（見積もり：数時間〜十数時間）、理想の形はもっと先まで（見積もり：数十時間以上）

### 要素を開ける順番（提案）
最初の数分は「切る」だけにする（市場調査の提案3：要素は段階的に開ける）。

| いつ（見積もり） | 開く要素 |
|---|---|
| 第1配達の第1便 | 大ポスト、シミ、指のナイフ |
| 第1配達の第1便のあと | 窓口、封書1種（薄い赤）。次の便で封書が落ちてきて、初めて封を切る |
| 第1配達の後半 | まじない葉書、封蝋の色が2つめ |
| 最初に倒れたとき | 消印と消印帳 |
| 2〜5回めの配達 | 封蝋の色が増える、便り人の種類が増える、窓口の品が増える |
| そのあと | 硬いシミ、大きなシミ、方向のくせのある群れ。消印帳の奥の項目 |

### 入れないもの（市場調査の提案2）
- スタミナ、待ち時間、日ごとの回数制限
- 課金、広告（課金なしが既定。未決 #10）
- 配達のやり直しのたびの手作業：窓口で毎回同じ買い物をさせない。「前と同じものを買う」ボタンなどを早めに渡す（市場調査 3：転生後の買い直しが嫌われる）

### 数の伸び（インクリメンタルの部分）
- 配達の中では、便が進むほどシミの数と硬さが伸び、切手と便り人の力も伸びる
- 配達をまたいでは、消印帳の書き足しで、指のナイフ、便り人、まじない葉書、大ポストの丈夫さが伸びる
- 前の配達より遠くへ行くほど、もらえる消印が増える。登り直し（第1便から前の便まで）は、強くなるほど短く感じられるようにする（市場調査 3：好かれる転生は「登り直しが短くなる」）
- 数がどこまで桁で伸びるか（何桁まで行くか）は 03 で `game-design-economy`・`game-spec-balance` が決める。JS の数は約1e308まで（市場調査 5）
- 留守のあいだ（ブラウザを閉じているあいだ）に何かが進むかは未決 #8。指で守る遊びなので、便は留守のあいだには進めない、が担当の意見

## 見た目と音の第一印象
世界観はオーナー未決（#4）。前の版の推し「封蝋の手紙の国」を土台にして書いた。ほかの案は前の版から残した。

1. **封蝋の手紙の国**（推す）
   - 生成りの紙でできた国。まん中に、赤い大きなポスト（大ポスト）。紙のふちは少し焦げたように暗く、そこからシミが湧く
   - シミは、紙を食う銀色の小さな虫と、黒や藍のインクのにじみ。にじみは広がりながら寄ってくる。切ると紙に吸い込まれて消える
   - 封書は、封蝋で閉じた封筒。空から郵便の羽根のようにひらひら落ちてくる。封蝋の色と厚さで、何が入っていそうかがひと目でわかる。切ると蝋がぱきっと割れ、かけらが散る
   - 便り人は、切り紙や押し花のような平たい紙の住人。郵便の道具を手にしている（スタンプ、糊、はさみ、定規、赤いペン など。どの道具でどう攻めるかは 02・03）。開いた封筒から、立ち上がるように出てくる
   - まじない葉書は、一筆書きの模様が光る葉書。使うと、模様が戦場に大きく広がる
   - 色：生成りの紙の地に、濃い封蝋の色。シミは黒・藍・銀で、地と便り人からはっきり分かれる。小さな画面でも形と色で見分けられる
   - 音：紙のこすれ、はさみの音、封蝋が割れる音、小さな鐘（便の始まりと終わり）、消印を押す「ぽん」。BGM は木管と小さな打楽器の軽い曲を、便が進むほど厚くしていく（提案。02 で `game-preprod-art`・audio が決める）
   - 推す理由：「窓口で受け付けた封書が、次の便で配達されて落ちてくる」「戦場で封を切る」「消印で強くなる」が、郵便という一つの決まりごとで全部説明できる。オーナーの流れ②（買ったパックはその場で開けず、次の戦闘で出る）に、世界の中の理由がつく
2. **お菓子の袋の国**
   - 包み紙の袋が降ってきて、中からお菓子の住人が出る。敵は虫歯の虫やカビ
   - 明るく親しみやすいが、「なぜ店で開けないか」の理由がつけにくい
3. **星くずの袋が降る夜空**
   - 夜空のまん中の灯台を守る。星の袋が流れてきて、割れると星座の住人が出る
   - 「封蝋の色＝レア度」の代わりに星の明るさで見せられ、レアの光が映える。ただ、暗い画面に小さな物が多いと縦の画面で読みにくくなるおそれがある

どの案も、既存の作品の名前、キャラ、絵柄、音楽には寄せない。キービジュアルを作るなら `game-art-concept` に頼む（プロデューサーの判断）。

## 任意のひねり（候補。必須にしない）
前に提案した追加の仕掛け。①〜⑤の流れはこれがなくても成り立つ。どれを入れるかはオーナーが決める（未決 #11）。入れるなら、02・04 で1つずつ確かめる。

| 候補 | 入れるとよくなること | 重くなること |
|---|---|---|
| 指でなぞって切る | なぞった線の上のシミと封書をまとめて切れ、「一筆で払った」の手ごたえが出る | 押さえる・なぞるの区別と当たり判定の作りが増え、縦の画面で指が画面を広く隠す |
| 封書の落とし先を選ぶ | 窓口で「北に落とす」などを選べ、便り人の置き場所が作戦になる | 窓口の画面と判断が増え、窓口の時間が長くなる |
| ハズレ・重複がレンガの壁になる | 引きが悪くても壁としてシミを遅らせ、外れの損が消える | 壁の置き場所、通り道の計算、絵が増え、縦の画面に物が増える |
| 連鎖開封（封蝋のかけらで周りの封書も開く） | 封書が固まって落ちたとき一度に開き、見せ場になる | 「封を切る判断」が薄れることがあり、演出の重なりで読みにくくなる |
| シミも封書を狙う | 封書を守るか、先に切るかの判断が濃くなる | 封書を失う外れ方が生まれ（課金なしでも嫌な外れ）、シミの動きの作りが増える |
| 配達をやり直すたびに規則が1つ開く | くり返しに新しさが出て、「取り切ったあとの退屈」を延ばせる（市場調査 2・3） | 規則ごとに作る量と釣り合いを見る量が増え、MVPには重い |

## リスク
- **既存作と並べて見られる**：仕掛けがほぼ同じ作品が発売されたばかり（進行表）。→ 名前・用語・キャラ・絵・音楽・進み方の作りを借りない。02 以降で、その作品の画面や用語に寄っていないかを `game-design-creative-director`・`game-art-director` が見る。オーナーが遊ぶためのゲームなので、外に出すかは別の話（外に出すことはこのチームではしない）
- **指が疲れる・画面を隠す**：何時間も押さえ続けることになる。→ 押さえっぱなしで切れる形、切る輪のずらし、大事な数字を上に。それでも、配達が長くなると指を動かし続けるのがつらいおそれ。指のナイフの自動化を消印帳に入れるかは未決 #9（入れると放置に寄り、指で守る気持ちよさが薄れる）
- **縦の小さな画面で読めない**：四方からのシミ、落ちてくる封書、便り人、葉書の効果、数字が重なる。→ 封蝋の色、シミの色を地から分ける、ふつうの数字はまとめる。iPhone の縦持ちで読めて押せるかを、プロトタイプで最初に確かめる
- **序盤が苦しすぎる**：第1便は指だけなので、手が足りない感じが「つらい」に寄るおそれ（市場調査 2：序盤が遅いは不満になる）。→ 第1便は短く、封書が来るまでを早く
- **桁のインフレが破綻する**：シミの硬さ、便り人の力、切手、消印が同時に伸びる。費用は指数・生産は線形で、後半の伸びが弱く感じられるおそれ（市場調査 3）。→ 03 で曲線を作る
- **くり返しの退屈**（市場調査 2・3：取り切ったあとの退屈、同じ転生のくり返し）：→ 便り人の組み合わせで毎回陣が違うこと、消印帳の奥の層。足りなければ任意のひねり「規則が1つ開く」
- **運の偏りで負ける**（市場調査 2）：封書の中身の引きが悪い配達は、すぐ倒れる。→ 消印帳で底上げ。重複の扱い（担当の提案：同じ便り人が重なると、その便り人が強くなる）は 03 で決める
- **iPhone のブラウザの保存と音**（市場調査 5）：Safari の保存領域の扱いは報告が食い違う。iOS 26 以降のホーム画面のWebアプリで Web Audio が鳴らない報告がある。振動は使えない。→ 書き出し・読み込みのバックアップを必須にする。保存と音は 02 で最初に確かめる
