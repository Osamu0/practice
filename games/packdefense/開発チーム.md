# 開発チーム：packdefense（仮）

| 項目 | 決め |
|---|---|
| 規模 | ふつう（近道は使わない） |
| 技術の決め | iPhone のブラウザが主。オフライン・1人用・保存は端末内を既定とする（技術選定で決める） |
| 使う仕事人 | 中心の35人＋監修（design-director、creative-director、tech-director、art-director、audio-director、story-dialogue-review）＋ design-systems、design-combat、design-economy、design-ai、design-ux、tech-engine、tech-platform、tech-performance、art-concept、art-ui、art-vfx、anim-animator、story-director、story-lore、audio-composer、audio-engineer、pm-manager、pm-secretary、qa-lead、qa-automation、qa-usability、qa-load-compat（端末・ブラウザの互換性のみ）、ops-analyst（端末内の記録のみ） |
| 使わない仕事人 | tech-network、tech-backend、tech-security、ops-infra（サーバーなしの間）、art-3d（2Dの間）、design-social、audio-voice、loc-*（言語が決まるまで保留）、rnd-engineer（要るときだけ） |
| 足す観点 | 全員：iPhone 縦持ちで読めて押せるか。game-design-economy・game-spec-balance：インクリメンタルの数の伸び（桁のインフレ）が破綻しないか、放置と操作の釣り合い。game-concept-*：ガチャ・パック開封の射幸性を、課金なしで気持ちよさに変える形 |
| オーナーに見せるもの | ゲートA〜Dで要約と、iPhone のブラウザで開けるビルド |
| 表記 | 企画書の用語（企画書ができるまで未決） |
