## 2. スタイル（言葉で決める）

### 2.1 使う言葉／使わない言葉（対）
| 使う | 使わない |
|---|---|
| 図解、設計図、製図（どこがつながっているか見える） | 写実の、絵画のような描き込み |
| 細い白の主線、手で引いた製図のようなわずかな揺らぎ | 太い縁取りの線、均一すぎる機械の線 |
| 藍の地を残す余白、平らな差し色 | グラデーション、光沢 |
| 紙に焼いた線（にじまず、光らない） | 発光、ネオン、グロー、光るホログラム、SF の操作盤 |
| 素材の手ざわりは線で（木目1本、縄のより、真鍮の照り1本、石の丸み、鉄の鋲、火打ち石の割れ面） | 金属の質感表現、ハイライトの多用、細かいテクスチャ |
| 静か、余白、一画面に要るものだけ | にぎやか、詰め込み、飾りの模様、寸法の数字の飾り |
| 古びる（ひび、欠け、線の途切れ、差し色の褪せ） | 汚し（泥・血・汚れのテクスチャ）、写真の青焼きのしみ |
| 人と一族のものだけ暖かい色の面（当主、肖像、家の印） | 画面の全部を暖色・寒色の片方にそろえる |
| 少しのおかしみ（転ぶ、飛ばされる、煤ける） | 暗すぎる、グロテスク、流血 |
| 止まった絵として読める（1手ごとに止まる） | 常に揺れる・ちらつく画面 |
| どこの国とも決めない職人の道具と服（前掛け、布の帽子、革の手袋） | 特定の時代・国の衣装や建物の写し |

既存の特定の作品の絵柄・キャラ・ロゴは写さない。参考にするのは「青焼きの設計図」「線画に平らな色」「図解」「木版のような単純化」といった一般の技法の言葉まで。

### 2.2 形の言葉（何がどの形か）
| もの | 形 | ねらい |
|---|---|---|
| 当主 | 丸みのある縦長、2頭身半。頭が大きく、顔の向きが分かる。**山吹と淡山吹で塗った面**、主線 2.5px | 盤面のどこにいても一番に目に入る（2.5 の順位1） |
| 部品 | 幾何の形（四角、丸、直線）。**中は地の藍、白線で描き、素材の色を面積の 1/3 まで差す**。つなぎ目は縁の小さな丸（つなぎ点）で必ず描く | 組んだ道具が「どの部品をどこでつないだか」形で読める |
| 発明品 | 部品の絵をそのまま組んだ見た目（企画書のとおり）。別の絵に描き替えない | 絵の数が部品の数で済む。設計図と見た目が一致する |
| 敵（谷の災いが生んだ物） | **濃藍のベタ塗り＋白い縁 2px**、左右非対称、縁がにじむ。目は白で2つ（大きさを変える） | 画面で「暗い塊」は敵だけ。当主（明るい面）と明るさが逆になり、色なしでも分かれる |
| 災いの主 | 3×3マス以上の大きな濃藍のにじみ（白い縁）。代ごとに盤面ににじみが広がる | 「災いが進む」が絵で見える |
| 先祖の跡（墓、遺品、据えた仕掛け） | 低く横長、ひび・欠け。**退紅の線**と家の印（下の 2.4）が付く | 「うちの一族のもの」と一目で分かる |
| 地形 | 地面の縁は 2px の線、地層は横の短い線の重なり、崖は縦のかすれ線。中は塗らずに藍の地 | 背景を静かにして、上に乗る物を立てる |
| UI | 札・図面の付箋・判子の形。四角に近く、角は小さく丸める | 工房の図面台の上の道具に見える |

### 2.3 線・質感・光
- 線：主線は白線 `#EAF0F2`。太さに ±15% の揺らぎ。揺らぎは物ごとに種（シード）で決め、毎フレーム変えない（ちらつかない）
- 主線の太さの差で順位をつける：当主 **2.5px**、部品・墓・敵の縁 **2px**、地面の縁 **2px（背景の線の色）**、地層・遠景 **1px（地層の色）**
- 質感：藍の地に白の薄いノイズ（紙の繊維）。強さは地の明るさの ±3% まで。盤面のマスの上には出さない。「くっきり」（3.4）では出さない
- 光：光源は左上に1つ、固定。影は右下に落ち影（ずらし 2px、濃藍 `#0E1A28` の不透明度 35%）。動く光・時間帯の光・発光は使わない
- 塗り：1つの物に平らな色は2色まで（差し色＋その影色1つ）。B の影色は差し色の各値 ×0.8（3.3 の素材の表）

### 2.4 一族と継承の見せ方
- **家の印**：一族ごとに、丸・菱・四角の枠の中に単純な図形（線3本まで）を組んだ印をコードで作る。**退紅の線**で描く。墓、遺品、据えた仕掛け、帳面の表紙に付ける。実在の家紋・団体の印は写さない
- **肖像（顔の部品の組み合わせ）**：輪郭4、目6、眉4、鼻3、口4、髪型8、髪色8、肌の色5。子は親の部品の一部を受け継ぎ、少し変わる（どれをどれだけ継ぐかは仕様）。肖像は藍の地の上に白い主線で描き、肌・髪は 3.3 の色で塗る（暖かい面を許す）
- **癖の見た目**：癖ごとに小さな印（16px）を1つ。肖像の横と帳面に出す。体つきで癖を表すことはしない（誤解とステレオタイプを避ける）
- **古びの段**（部品・墓・仕掛け。`規則の計算.md` 4.6 の傷みの段 0／1／2 と同じ）：**形で見せる。褪せは補助**

| 段 | ひび（内線） | 欠け（輪郭） | 主線 | 差し色（補助） |
|---|---|---|---|---|
| 0 新しい | 0本 | なし | 切れ目なし | そのまま |
| 1 傷み | 1本 | **1か所**（角か縁を三角にえぐる） | 切れ目なし | 彩度 −30% |
| 2 壊れかけ | 2本 | **2か所** | **切れ目 2か所**（各 3px） | 彩度 −60%、明るさ −15% |

- 欠けの深さ：48 の絵で **5px**、24 の絵で **3px**（24 の絵はひびを描かないので、欠けが段の手がかりになる）。56 の絵は 48 と同じ形を拡大
- 欠けの位置：つなぎ点と重ねない（つなぎ点は縁の中点、欠けは角寄り）。部品ごとに種で決め、毎回同じ場所
- 確かめ：白黒・24px でも 0／1／2 の段が読み分けられる（影絵でも欠けの数が見える）

### 2.5 見せる順位（B の「全部白線」への答え）
上の段ほど強く見せる。下の段の物は、上の段の物より太い線・明るい面・強い色を持たない。

| 順位 | もの | 見せ方（ほかと分ける手がかり） |
|---|---|---|
| 1 | 当主 | 盤面で**唯一の大きな明るい塗りの面**（山吹＋淡山吹）。主線 2.5px。山吹の面を持つのは当主だけ（印の山吹は線と小さな足あとだけ） |
| 2 | 危険・敵 | 危険＝朱の斜線と「！」。敵＝**画面で唯一の暗い塊**（濃藍のベタ＋白い縁） |
| 3 | 次の1手の印（3種） | 線だけ（2px）、面を塗らない。色と線の種類（実線・点線・破線）で3つを分ける |
| 4 | 部品・墓・仕掛け | 白線 2px、中は地の藍。素材の差し色は面積の 1/3 まで、彩度は当主の山吹より低い |
| 5 | 地形・遠景・マス目 | 地面の縁だけ背景の線 2px、地層・遠景は地層の色 1px、マス目は罫 1px |

## 3. 色（色コード）

コントラスト比は WCAG 2.x の相対輝度の式（sRGB を線形にして 0.2126R＋0.7152G＋0.0722B）で計算した。この作業の環境ではスクリプトを動かせなかったので**手計算**（小数第2位に ±0.05 ほどの誤差がありうる）。04 で道具を使って測り直す。
基準：文字は **4.5:1 以上**（20px 太字・24px 以上の大きな文字は 3:1 以上）、図形の印は **3:1 以上**。3:1 に足りない色は、**必ず白線・形・模様と組んで**使い、単独で意味を持たせない。

## 4. 画面の読みやすさと、制作の数値

### 4.1 画面の大きさ（縦持ち）
- 基準の大きさ：**幅 360 × 高さ 640（CSS px）**。これより小さい端末は想定しない（最小の幅 360）
- 幅が広い端末：盤面と作業台は真ん中に置き、左右は藍の地。拡大はしない（マスは最大 56px まで）
- 縦が長い端末：増えた高さは**画面の上（盤面の上）に足す**。親指の届く下側の配置は動かさない
- 描くときは端末の画素の密度（devicePixelRatio、最大 3）に合わせ、絵がぼけないようにする
- PC：縦長の枠（360〜430 幅）を画面の真ん中に出す。操作はマウスで同じ

- 盤面の上に文字は置かない。数字を読まないと分からない表示はしない（重さは丸の数、傷みは欠けとひびの数）
- 説明の帯は1行（全角 20 字まで）。それより長い説明は帳面を開いて読む
- 説明の帯で危険を言うとき：**字は白線**、前に朱の「！」の三角、帯の左端に朱の斜線の帯。朱の 16px の字は使わない（ふつうの表示で 4.5:1 に足りないため）
- 指で隠れる問題：ドラッグ中の部品は指の **上 56px** に浮かせて描き、置く先のマスを枠 3px で示す
- 背景（地形）は灰藍と沈藍だけにして、上に乗る物（当主・部品・敵・印）より必ず弱くする（2.5 の順位5）
- 掟の効果（雨の線、風の流線）は盤面の上で不透明度 25% まで（くっきり 15%）。印より強くしない

## 5. UIの方向

- 形：札・図面の付箋・判子。角の丸みは 4px。ふつうのボタンは浅藍の地に白線の縁 2px、押すと 1px 下がって落ち影が消える
- **確定**：画面で唯一の**白い面のボタン**（地 白線、字 濃藍 20px 太字）。危険な手のときは地が朱になり、前に「！」、左端に斜線の帯。何も選んでいないときは押せない形（浅藍＋斜線、縁と字は灰藍）
- 押せない：灰藍＋斜線（灰色にするだけにしない）
- 選択中：罫の下塗り＋白線の枠 3px＋四隅のかぎ
- 大きさ：タップできる物はすべて **48×48px 以上**。主ボタン（確定）は **高さ 64px・幅 160px 以上**、親指の帯に置く
- 置き場所：ボタンは画面の下半分（基準で y 392 より下）。上の帯は見るだけ。盤面のマスのタップは例外だが、盤面の上の段（y 52〜150 あたり）は片手の親指が届きにくい。行き先を棚の選択肢からも選べる形を UX に提案。左手・右手の切り替え（左右反転）も UX に提案
- 確定の一押し：手を選ぶ→説明の帯に結果が出る→確定、の2段
- 字：本文・UI はゴシック体、帳面・年表・掟の名前は明朝体（書き物の感じ）。大きさは本文 **16px**、補足 **14px**、最小 **12px**（小印の中の文字だけ）、見出し **20px**。行の高さ 1.6。数字は幅のそろった字形。暗い地の白い字はにじんで太って見えるので、本文は太字にしない（くっきりの補足 14px だけ太字）
- フォントは自由に使えるライセンスのものから選ぶ（選ぶのは art-ui、条件の確認はオーナー）。日本語のフォントは大きいので、使う字だけに絞って読み込む（技術選定と合わせる）
- 画面の情報量：1画面の文字は帳面の外では3行まで。帳面・年表・図鑑は読むための画面なので、図面帳のページとして文字を多く置いてよい
- 帳面：図面帳のページをめくる見た目（横に送る）。ページの数に限りがあることを、空きページの数で見せる
- 設定：表示（ふつう／くっきり）、動きを減らす、左右反転、音

## 6. 音の方向（声なし）

### 6.1 全体の決め
- 音がなくても遊べる（電車で音を消して遊ぶ前提）。音の情報は、すべて絵でも出す。音は2番目の手がかり
- 楽器：木の打楽器（木琴のような柔らかい音）、撥弦（指ではじく弦）、木管の笛、櫛の歯をはじく小箱の音（オルゴールのような）、低い弓の弦を少し。電子音の派手な音は使わない（B の見た目が冷たく寄るぶん、音は木と弦で温かくする）
- 質感：部屋の中で鳴っている近い音。残響は短め（小さな木の工房）。谷の場面だけ少し広い
- **一族の旋律**：8音の短い旋律を年代記の始めに1つ決め、代が替わるたびに1か所を変える（1音、楽器、テンポのどれか）。当主の癖で少し変わる（例：せっかち→少し速い）。どう変えるかの規則は audio-composer と決める
- 音の大きさの目安：全体 −16 LUFS、BGM は効果音より 6dB ほど下。効果音は短く、頭の無音 10ms 以下
- 同じ小段に出来事がいくつも重なったら、同じ種類の音は1回にまとめ、違う種類は 30ms ずつずらす（音が団子にならない）

### 6.2 場面ごと
| 場面 | テンポ（BPM） | 楽器・音 | 感じ |
|---|---|---|---|
| 工房（組む・予行） | 72〜84 | 撥弦と木琴、薄く。木槌・ばねの音が主役 | 落ち着いて考えられる |
| 谷の地図 | 曲は薄く 60〜70、環境音が中心 | 風、水、遠くの鳥。代が進むと墓や仕掛けの小さな音が増える | さびしい谷が、にぎやかになる |
| 挑む（課題） | 90〜100 | 木の打楽器で拍をはっきり、笛の短い句 | 一手ずつ前へ進む。1手の再生と拍は合わせない（待たせない） |
| 災いの主 | 108〜120 | 低い弓の弦、太鼓のような低い打音 | 重い、でも暗すぎない |
| 遺す・墓 | 56〜64 | 一族の旋律を小箱の音でひとつだけ | 託す。悲しすぎない |
| 継ぐ・代替わり | 短い節（4〜8小節） | 一族の旋律の変奏 | 「同じ家の、新しい一代」 |
| 年表・図鑑 | 曲なし、または工房の曲を小さく | ページをめくる紙の音 | 読む |

### 6.3 効果音（規則ごとに音を分ける）
`規則の計算.md` 9章の出来事と対にした。素材で音を変えるもの（持つ・置く、壊れる）は、素材6のうち木・縄布・金属（真鍮と鉄）・石（石と火打ち石）の **4つの質感** に分ける案（数は audio-director が決める）。
| きっかけ（出来事） | 音の質感 |
|---|---|
| 部品を持つ・置く | 木の「こと」、置くと少し低い「こつ」。金属は「かち」、石は「ごつ」、縄布は「ぱさ」 |
| つなぐ | 縄を結ぶ短いきしみ、金具の「かち」 |
| 確定 | 木槌の「こん」1回 |
| 取り消し | 紙をめくる短い音 |
| **ずれた** | 板が台の上をこする短い「ずずっ」（150〜250ms、終わりに少しピッチが下がる）。積み重なった物が一緒に動くときは、その上に小さな「かた」を1回。落ちる前触れなので、「ごとっ」より軽く・短く |
| 落ちた／止まった | 低い木の「ごとっ」、落ちる前に短い風切り |
| 当たった（壊した、追い払った） | 重い「どすっ」。追い払ったときは、そのあとに敵の逃げる短い布ずれ |
| **壊れた（傷みが1段進む）** | 素材の割れる音を短く1回：木「ぱきっ」、金属「きんっ」（少し濁る）、石「がちっ」、縄布「ぶつっ」。強すぎない（失敗の音にしない。古びの印が増えただけ） |
| **壊れた（傷みの最大をこえて消えた）** | 上の割れる音＋小さな破片が散る「からから」（300ms ほど）。先祖の仕掛けが消えるときは、そのあとに一族の旋律の1音を小箱の音で小さく |
| 縮んだ／打ち出した | ばねの「びよん」、ピッチが上がる |
| 火がついた／燃え移った | ぱちぱちの雑音、燃え移るたびに「ぽっ」 |
| 燃え尽きた／火が消えた | 燃え尽きた：ぱちぱちが細くなって止む。火が消えた（濡れて）：短い「じゅっ」 |
| 張った／釣り合いで動いた／引いた／切れた | 縄がぴんと張るきしみ。切れたは「ぷつん」 |
| 濡れた | 小さなしずく「ぴちょ」1回（長雨の環境音とは別） |
| 谷底へ消えた | 遠ざかる風切りだけ。着く音は鳴らさない（見えない先へ消えた） |
| 課題が解けた | 短い上がる3音（木琴）。仕掛けが動いた瞬間の「かちり」と重ねる |
| 危険の手を選んだ | 低い2音、短く |
| 死 | 一族の旋律の最初の2音だけ、少しずれて |
