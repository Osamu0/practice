# 機能仕様：作業台と設計図（組む、つなぎ点、試し場、設計図を開く）

書いた人：game-spec-writer（2026-11-18）。プロトの初版。04 の Q1（組んで試すのが縦持ち片手で2〜4分で気持ちいいか）で確かめて直す前提。
画面の数値（マスの px、帯の位置）はアートディレクション 4.2・4.3 を正にする（計画.md 6章 #1）。

- 目的（どの柱のためか）：
  - 柱3：作業台は1画面に入り、親指だけで組める。組んですぐ、同じ規則で試せる
  - 柱1：組んだものが「設計図」として残り、帳面で子に渡る。子は自分の棚と癖で組み直す
  - 柱2：試し場は本番と同じ規則。決まった正解の形はない
- プレイヤーから見た動き：下の棚から部品を親指で作業台へ置く。隣り合った部品はつなぎ点で自動でつながり、組んだ形がそのまま道具の見た目になる。「試す」で同じ場所が試し場に切り替わり、平ら・崖・割れ目から選んだ地面の上で道具を1手ずつ動かせる。年月は使わない。よければ「組み上げる」で道具になり、持って挑む

---

## 1. いつ開けるか
- 谷の地図の「工房」から
- 課題に入ったあと、挑む前の「見る」画面から（`挑む.md` 1章）
- **挑む（1手目を確定したあと）の間は開けない**。挑む中は、持っている道具と部品だけで解く（試すのがただなので、挑む中に組み直せると、挑むの手の重みがなくなるため）

## 2. 画面（基準 360×640。アートディレクション 4.2 の割り付けを使う）

| 帯 | 作業台のとき | 試し場のとき |
|---|---|---|
| 上の帯 | 代・年・掟の札（見るだけ） | 同じ |
| 盤面の場所 | 作業台（枠 288×288。マス＝288÷作業台の大きさ） | 試し場（`trial.size`、マス 48px） |
| 説明の帯 | 選んだ部品の名前・系統・素材、置けない理由 | 次の1手で起きること |
| 手の棚 | 部品の棚（持っている部品。系統ごとに並ぶ）／「帳面」「この代の設計図」の札 | 試しの物（人形、試しの重り、火種を打つ） |
| 親指の帯 | 組み上げる（主ボタン）、ひとつ戻す、試す（切り替え）、メニュー | 送る（1手）、続けて動かす、最初に戻す、組む（切り替え） |

- 作業台と試し場は**同じ場所で切り替える**（計画.md 6章 #4。幅 360 では横に並ばない）。切り替えても作業台の中身は消えない
- ボタンは全部、親指の帯と手の棚（y 392 より下）。タップできる物は 48×48px 以上（アート 5）

## 3. 作業台の大きさ（計画.md 6章 #3）

- 基本：`bench.size.base` ×同じ数（正方形）
- 一代目の最初の課題まで：`bench.size.firstGen`（デザインの柱の最初の5分：狭め）
- 癖・掟・解放で広がる・狭まる量は**足し合わせ**、結果を `bench.size.min` 以上 `bench.size.max` 以下に止める
  - `bench.size.max` は **6（固定）**：7×7 はマスが 41px になり指に小さい（アート 4.3）。balance でも変えない
  - `bench.size.min` は **3（固定の案）**
- マスの大きさ：4×4＝72px、5×5＝56px（枠 280）、6×6＝48px、3×3＝96px（アート 4.3 の式）
- 大きさが変わるのは、**代の始め（継ぐとき）、解放のとき、一代目が初めて課題を解いた（その結果の画面を閉じた）とき**だけ。ほかの一生の途中では変わらない
  - 一代目は `bench.size.firstGen` で始まり、初めて課題を解いた結果の画面を閉じたときに `bench.size.base`（一代目は癖・掟がないので足しなし）になる。引き返した・死んだでは変わらない
  - 代の始めの作業台は空で始まる（前の当主の作業台に置いた部品は棚の部品とみなす（7章）ので、墓の遺品になる：`継承の一周.md` 5章）。だから大きさが変わって中身が入らなくなることは、代の始めには起きない

## 4. 組む操作

| 操作 | 入力（タッチ／マウス） | 結果 |
|---|---|---|
| 置く | 棚の部品を作業台のマスへドラッグ。または棚の部品をタップ→マスをタップ | 空いたマスに置く。棚の数が1減る。ドラッグ中は部品を指の上 56px に浮かせ、置く先のマスを枠 3px で示す（アート 4.5） |
| 選ぶ | 置いた部品をタップ | 選択中になる（アート 3.3「選択中」：罫の下塗り＋白線の枠 3px＋四隅のかぎ）。説明の帯に名前・系統・素材・重さの丸（`部品と素材.md` 3.1） |
| 向きを変える | 選択中の部品をもう一度タップ | 時計回りに90度。向きがあるのはばね系だけ（MVP）。向きのない部品は変わらない |
| 動かす | 置いた部品を別の空いたマスへドラッグ | そのマスへ動く |
| 外す | 置いた部品を棚へドラッグ。または選んで「棚に戻す」（説明の帯の横の札） | 棚へ戻る |
| ひとつ戻す | 親指の帯 | この作業台を開いてからの操作を1つ前に戻す（置く・選ぶ以外の全部：置く、動かす、向き、外す、設計図を開く）。回数に限りなし |
| 組み上げる | 親指の帯（主ボタン） | 6章 |

- 2本指・長押し・回転のつまみは使わない（柱3）
- **つなぎ点**：部品の辺の中点にある点（作業台では直径 6px、アート 4.3）。部品ごとにどの辺にあるかは `部品と素材.md`。**隣り合った2つの部品の、向かい合う辺の両方につなぎ点があれば、自動でつながる**。つながった辺には結び目の印を出す
- つながった部品のまとまりが「組」（`規則の計算.md` 2.1）。1つの道具に、つながっていない組が2つ以上あってもよい（そのときは同じ相対位置のまま一緒に置かれる）
- つなぎを自分で切る操作は、MVPの初版には入れない（未決）

## 5. 試し場（予行）

- 作業台の中身を、そのまま道具として試し場に置いて動かす
- 試し場の盤面：`trial.size`。**地形を3つから選べる**（M1。平らだけだと、予行で外れることがなく、Q1 が測れないため）：

| 地形 | 形 |
|---|---|
| 平ら | いちばん下の段が全部地面、ほかは空き |
| 崖 | いちばん下の段は、西から `trial.cliffColumn` 列目までが地面。それより東の列は地面がなく、下の外は谷底（物は落ちて消える） |
| 割れ目 | いちばん下の段は地面。ただし `trial.cliffColumn` 列目より東の `trial.gapWidth` 列だけ地面がなく（谷底へ抜ける）、その東はまた地面（割れ目の場所は `trial.cliffColumn` を使う案） |

  - 選ぶ：試し場の手の棚に地形の札（平ら・崖・割れ目）を出す。押せるのは「置いたところ」（1手目の前）だけ。選ぶと道具は `trial.startColumn` の位置に置き直される（「最初に戻す」と同じ）
  - **初めの地形**：課題の「見る」から工房を開いたときは、その課題の型に近いもの。どれが近いかは課題の場所のデータに持たせる（07 の場所の仕様で場所ごとに決める）。決まるまでの案：渡る＝割れ目、ほかの型＝平ら。谷の地図から工房を開いたときは平ら
  - 選んだ地形は、工房を閉じるまで覚える（保存しない。試し場は保存しない：`保存.md`）
  - **本番の地形・敵・墓・仕掛けは入れない**。試し場の地形はこの3つの型だけで、課題の場所の盤面を写さない（デザインの柱。試すのがただなので、本番を写すと挑むの重みがなくなる）
- 置く位置：道具の外形の左下が、西から `trial.startColumn` 列目、地面のすぐ上に来るように置く。1手目の前なら、道具をドラッグして置く位置を変えられる
- 当主は試し場にいない。かわりに「試しの物」を棚から置ける（数は限りなし）：
  - **人形**：重さ・硬さ・燃えやすさが今の当主と同じ物（板に乗ったら、ずれるかを見られる）
  - **試しの重り**：石の重りと同じ値の物。好きな列の上から落とせる
  - **火種を打つ**：道具の中の火種の部品をタップすると火がつく
- 動かし方：「送る」で1手（起きた小段ごとに止まる。もう一度で次の小段）、「続けて動かす」で何も動かなくなるか `trial.maxTurns` 手まで続けて動かす、「最初に戻す」で置いたときに戻す
- 規則・癖・掟：**本番と同じ規則の芯**を使う。今の当主の癖（組み上げたときに焼き込む効きも、試し場では今の当主のものとして入れる）と、今の代の掟が効く
- 試し場ではいくら動かしても、年月は進まず、部品も減らない（燃え尽きた部品も作業台では残る）
- 試し場の結果は保存しない（`保存.md`）。作業台の中身は保存する

## 6. 組み上げる（道具にする）

- 作業台に部品が1つ以上あり、持ち物の道具の数が `leader.carryTools` 未満のときだけ押せる。押せないときは押せない形（アート 3.3）で、理由を説明の帯に出す
- 押すと：
  1. 作業台の部品が棚から抜け、1つの**道具**になって持ち物に入る
  2. 今の当主の癖の効きのうち、道具に効くもの（`規則の計算.md` 6章の口A）を道具に焼き込む。道具には作った当主の印が付く
     - 癖で傷みが足されて壊れかけ（2）をこえる部品（例：怪力で、傷み2の軽い部品）は、組み上げたときに消える（`継承の一周.md` 7章）。作業台では、組み上げると消える部品に危険の印（アート 3.3「危険」）を出し、選ぶと説明の帯に理由を出す。試し場ではその部品はないものとして動く
  3. **この代の設計図**に1枚足す（7章）
  4. 癖で年月がかかるとき（例：几帳面 `trait.meticulous.buildYears`）は谷暦を進める（当主の年齢も同じだけ進む：`継承の一周.md` 1.1）
  5. 作業台は空になる
  6. **年齢の確かめ**（縦切りから。4. で年が進んだときだけ：`継承の一周.md` 1.2・1.3）：
     - 年齢 ≧ `life.span` なら寿命で一生を終える。工房を閉じて遺すへ進む（谷の地図にも見るにも戻らない）。いま組み上げた道具は持ち物にあるので墓の遺品に入り、3. で足した設計図は遺すで書ける。墓は年代記で最後に1手目を確定した課題の場所に建つ
     - そうでなく、二代目以降で年齢 ≧ `life.oldAge` に入ったばかりなら、老いの知らせを出し、「続ける」で作業台（空）に戻る。老いの癖の口A は、このあとに組み上げる道具から焼き込む（いま組み上げた道具には入らない）。作業台の大きさは変わらない（老いの癖は口D を使わない）
     - 年が進まない当主（几帳面などでない）では確かめない
- **組み上げるボタンの寿命の知らせ**（縦切りから。柱3）：作業台に部品が1つ以上あり、年齢 ＋ 今の当主の組み上げの年（`trait.meticulous.buildYears` など。年のかかる癖がなければ 0）≧ `life.span` のとき、組み上げるボタンを危険の形（アート 3.3「危険」：朱の地＋「！」＋斜線の帯。`挑む.md` 4.1 と同じ）にし、説明の帯に「組み上げると寿命に届く」を出す（字は白線、前に朱の「！」：アート 4.5）
  - **押せる**（止めない）。押したときにほかの確かめの画面は出さない（`挑む.md` C-06 と同じく、危険の形を見たうえで1回で進む）
  - 押せない条件（持ち物の道具が `leader.carryTools`、作業台が空）のときは、押せない形が先
- 持ち物の道具を「ばらす」と、部品が全部棚に戻る（自分の代に組んだ道具は、ばらしても部品は減らない）。挑む前ならいつでもばらせる
- **棚があふれるとき**（M6）：ばらす（工房）、直す（工房。`継承の一周.md` 5章）、結果のばらす（`谷と一生の流れ.md` 3章）、遺品を取り戻す（`継承の一周.md` 5章）で、棚の部品が `leader.carryParts` をこえるときは、**置いていく部品を選ぶまで先へ進まない**（置いていく選びの画面を出し、ほかの操作はできない）
  - 置いていく部品は**失われる**（盤面にも墓にも工房にも残らない）
  - 選ぶ画面には、こえた数と、置いていく部品の候補（棚の全部）を出す。選び終えるまで「決める」は押せない形（アート 3.3）
  - 遺品を取り戻すは、`継承の一周.md` 5章のとおり持てる分だけを取り戻す（入らない分は墓に残り、失われない）ので、ふつうはあふれない。あふれる形が出たら（例：取り戻した遺品の道具をその場でばらす操作を足したとき）、この決まりに従う
  - 置いていく選びは保存の区切り（`保存.md` 1章「工房で直す・ばらす」）の前に終える。途中で閉じたら、ばらす前に戻る
- 道具の名前は自動でつける（文の型は story 担当、07）。名前を打ち込む入力は MVP に入れない（キーボードが片手の操作をふさぐため）

## 7. 設計図

- 設計図に書くもの：作業台の大きさ、部品（id、位置、向き）、名前、作った当主、代、谷暦。**癖の効き、傷み、焼き込んだ値は書かない**（形だけ）
- 設計図の置き場所は2つ：
  - **この代の設計図**：組み上げるたびに自動で増える。その当主が生きている間だけ開ける。死ぬ・隠居するときに、ここから帳面に書くものを選ぶ（`継承の一周.md`）
  - **帳面**：家の帳面。先祖が書き残した設計図。代をまたいで残る
- **開く**：棚の「帳面」「この代の設計図」の札から設計図を選ぶと、作業台の中身と入れかわる（前の中身は「ひとつ戻す」で戻せる）。棚の部品はそのまま減らない（組み上げるまでは棚にあるとみなす）
  - 設計図の部品が棚にあれば、そのマスに置く
  - **同じ id の部品が棚に2つ以上あるときの選び方**：傷みの小さい順 → 同じなら番号の小さい順に使う。設計図の中で同じ id の部品を置く順は、設計図のマスの基本の順（下の段から、西から：`規則の計算.md` 5.1 決まり3）。先祖の癖が焼き込まれた部品（ばらす前の遺品の道具の部品）は棚にないので選ばれない
  - 棚にない部品は、そのマスに**足りない部品**（押せない形：アート 3.3。部品の形を灰藍の線と斜線で描く）として出す。足りない部品をタップすると、棚の中で同じ系統の部品が先頭に並び、タップした部品で代えられる。代えたら、その部品の値で動く
  - 設計図の大きさが今の作業台より大きいときは、作業台の左下を合わせて開き、入らなかった部品は棚の端に「入らなかった部品」として足りない部品と同じ見た目で出す
  - 足りない部品・入らなかった部品は、道具には入らない。試し場・組み上げるでは、ないものとして扱う
- 帳面は一代目にはまだ何もない（札は押せない形：アート 3.3）

## 10. 例外・境界
- **0**：作業台が空なら、試す・組み上げるは押せない。棚が空なら、棚に「部品がない」と出す（帳面は開ける：足りない部品として形が見える）
- **最大**：作業台はどの足し方でも 6×6 をこえない。癖・掟・解放の足しが全部重なっても 6×6
- **部品の上限**：組み上げた道具の部品は棚から抜けるので、`leader.carryParts` の数え方に入らない（数えるのは棚の部品だけ。未決：道具の部品も数えるか）
- **中断**：作業台の操作は1つごとに保存する（`保存.md`）。アプリが閉じても、開き直すと同じ作業台の中身から始まる。「ひとつ戻す」の履歴は保存しない（開き直したら戻せない）
- **試し場で谷底へ落ちた物**：試し場から消える。「最初に戻す」で戻る
- **死亡**：作業台・試し場では当主は死なない（人形は壊れても何も起きない）。ただし縦切りからは、組み上げで年が進んで寿命に届くと、工房で一生が終わる（6章の 6.）
- **中断**（寿命）：組み上げと年齢の確かめは1つの操作で、組み上げの保存のときに寿命・老いも決まって保存される。老いの知らせ・遺すの途中で閉じたら、開き直すとその画面から（`継承の一周.md` 11章）
- **ポーズ**：試し場の「続けて動かす」は、画面をタップすると止まる

## 11. 演出と音のきっかけ
- 部品を持つ・置く：木の「こと」・「こつ」（素材で変える）。つながったとき：金具の「かち」／縄のきしみ（アート 6.3）
- 作業台⇄試し場の切り替え：紙をめくる短い音（案）、画面は 200ms 以内で切り替える（案。UX と決める）
- 試し場の動きは `規則の計算.md` 9章の出来事どおり（挑むと同じ見せ方）
- 組み上げる：木槌の「こん」（確定と同じ音）

## 12. 受け入れ条件
- [ ] B-01 棚の部品を作業台の空いたマスへドラッグして離すと、そのマスに部品が置かれ、棚の数が1減る。棚の部品をタップしてからマスをタップしても同じになる
- [ ] B-02 部品が置いてあるマスに別の部品を置こうとすると置かれず、棚の数も変わらず、説明の帯に置けない理由が出る
- [ ] B-03 隣り合った2つの部品の向かい合う辺の両方につなぎ点があると、置いた時点でつながり、結び目の印が出る。片方にしかなければ、つながらない
- [ ] B-04 選択中のばねをもう一度タップすると、向きが時計回りに90度変わる。板をもう一度タップしても何も変わらない
- [ ] B-05 「ひとつ戻す」を押すと、最後の操作（置く、動かす、向き、外す、設計図を開く）の前の中身に戻る。続けて押すと、この作業台を開いたときの中身まで戻れる
- [ ] B-06 `bench.size.base` が5で、作業台を広げる癖と掟と解放の足しが合計で+3になっても、作業台は 6×6 になる
- [ ] B-07 作業台が5×5のとき、作業台のマスは 56px（枠 280px）、6×6のとき 48px で描かれる（基準 360×640）
- [ ] B-08 「試す」を押すと、作業台と同じ場所に試し場が出て、作業台の中身が道具として地面の上に置かれる。「組む」を押すと、作業台の中身が試す前と同じに戻っている
- [ ] B-09 同じ道具・同じ今の癖と掟で、試し場で動かした結果と、挑むで同じ地形（平ら・崖・割れ目のそれぞれと同じ形の盤面）に置いて同じ手を打った結果が、マスごとに一致する
- [ ] B-10 試し場でいくら動かしても、谷暦と棚の部品の数は変わらない
- [ ] B-11 試し場の「続けて動かす」は、何も動かない手になるか `trial.maxTurns` 手で止まる
- [ ] B-12 持ち物の道具が `leader.carryTools` 個のとき、「組み上げる」は押せない形で出て、押しても何も起きず理由が出る
- [ ] B-13 「組み上げる」を押すと、作業台の部品が棚から抜けて持ち物の道具が1つ増え、この代の設計図が1枚増え、作業台が空になる
- [ ] B-14 帳面の設計図を開いたとき、棚にない部品は足りない部品の形で出て、タップすると同じ系統の棚の部品が先頭に並ぶ。それをタップすると、その部品で置きかわる
- [ ] B-15 6×6 の設計図を5×5の作業台で開くと、左下を合わせて置かれ、入らなかった部品が棚の端に「入らなかった部品」として出る
- [ ] B-16 設計図には癖の効き・傷みが書かれず、同じ設計図を癖の違う当主が組み上げると、焼き込む値が組み上げた当主の癖のものになる
- [ ] B-17 挑むで1手目を確定したあとは、作業台を開く道がどの画面にもない
- [ ] B-18 作業台に部品を置いた直後にアプリを閉じて開き直すと、同じ作業台の中身が出る
- [ ] B-19 基準 360×640 で、作業台・試し場のどのボタンも y 392 より下にあり、48×48px 以上ある
- [ ] B-20 試し場で地形の札「崖」を選ぶと、いちばん下の段の `trial.cliffColumn` 列目より東に地面がなくなり、そこへ動いた物は谷底へ落ちて試し場から消える。「割れ目」を選ぶと、`trial.cliffColumn` 列目より東の `trial.gapWidth` 列だけ地面がない。1手目を送ったあとは地形の札が押せない形になる。試し場に敵・墓・課題の場所の仕掛けは出ない
- [ ] B-21 型が「渡る」の課題の「見る」から工房を開いて「試す」を押すと、初めの地形が割れ目になっている（場所のデータで決めた地形があればそれ）。谷の地図から開いたときは平ら
- [ ] B-22 一代目の作業台は `bench.size.firstGen` で始まり、初めて課題を解いた結果の画面を閉じたときに `bench.size.base` になる。引き返しただけでは変わらない
- [ ] B-23 棚が `leader.carryParts` 個のときに部品3つの道具をばらすと、置いていく部品を選ぶ画面が出て、3つ選ぶまでほかの操作ができない。選んだ部品は棚にも盤面にも墓にもなくなる
- [ ] B-24 棚に同じ id の部品が、傷み1（番号5）・傷み0（番号9）・傷み0（番号7）の3つあり、その id を1つ使う設計図を開くと、傷み0・番号7の部品が置かれる
- [ ] B-25 （縦切りから）年齢 ＋ `trait.meticulous.buildYears` ≧ `life.span` の几帳面の当主が作業台に部品を置くと、組み上げるボタンが危険の形になり、説明の帯に「組み上げると寿命に届く」が出る。押すと確かめの画面なしで組み上がり、工房が閉じて遺すの画面になる。いま組み上げた道具は墓の遺品に、設計図は遺すの一覧にある。年齢 ＋ `trait.meticulous.buildYears` < `life.span` ならボタンはふつうの形で、組み上げると作業台（空）に戻る
- [ ] B-26 （縦切りから）几帳面でない当主（組み上げで年が進まない）では、年齢が `life.span` の1年前でも組み上げるボタンは危険の形にならず、組み上げても谷暦・年齢は変わらない
- [ ] B-27 （縦切りから）二代目以降の几帳面の当主が組み上げて年齢が `life.oldAge` 以上（`life.span` 未満）になると、老いの知らせが出て、「続ける」で空の作業台に戻る。作業台の大きさは組み上げる前と同じ。いま組み上げた道具には老いの癖の口A が焼き込まれておらず、次に組み上げた道具には焼き込まれる
