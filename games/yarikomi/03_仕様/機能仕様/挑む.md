# 機能仕様：挑む（当主の手、確定、次の1手の印、1手の再生、課題の条件）

書いた人：game-spec-writer（2026-11-18）。プロトの初版。04 の Q1 と縦切りで確かめて直す。
1手の中で盤面がどう進むかは `規則の計算.md`。この仕様は、プレイヤーが手を選んで確定し、結果を見るまでを受け持つ。

- 目的（どの柱のためか）：
  - 柱3：片手の親指で手を選び、確定の一押しで決め、1手ずつ止まる動きで理由が読める。次の手で起きることは盤面の印で前もって見える
  - 柱2：専用の戦闘の計算はない。敵も規則で動く物で、道具で解く
- プレイヤーから見た動き：課題の場所の盤面を見て、下の棚の札（進む、置く、使う、拾う、待つ）で当主の手を選ぶ。行き先は盤面のマスをタップしても、棚の候補を押してもよい。選ぶと盤面に「この手で何が起きるか」の印が出る。確定を押すと、当主→物→敵の順に1段ずつ動く。確定した手は戻せない

---

## 1. 課題に入る（見る）
- 谷の地図で課題の場所を選ぶと、「見る」画面になる：課題の盤面（`board.size`）、掟が効いている物の印、墓（タップで年表の一文）、残っている仕掛け、課題の型と条件の札
- 「見る」から行けるところ：工房（作業台。`作業台と設計図.md`）、挑む（当主が盤面の入口のマスに立つ）、谷の地図へ戻る（年月は使わない）
- 挑むの**1手目を確定した時点で、課題に挑んだことになる**（作業台は開けなくなり、出るには「引き返す」が要る）

## 2. 画面（基準 360×640。アートディレクション 4.2）
| 帯 | 中身 |
|---|---|
| 上の帯（0〜44） | 代・谷暦・掟の札・課題の型（見るだけ） |
| 盤面（52〜388） | 7×7 マス、48px |
| 説明の帯（392〜436） | 選んだ手と、次の1手で起きることを1行（全角20字まで） |
| 手の棚（440〜560） | 手の札（進む、置く、使う、拾う、待つ、帳面）。札を選ぶと、その手の候補の小札に入れかわる |
| 親指の帯（568〜632） | 確定（主ボタン。高さ64・幅160以上）、選び直す、送る（1手送りの入・切）、メニュー |

- 縦が長い端末では、増えた高さは盤面の上に足す（親指の帯の位置は動かさない）
- 盤面の上の段（y 52〜150 あたり）は親指が届きにくいので、**どの候補も手の棚の小札から選べる**（計画.md 6章 #6）

## 3. 当主の手（札）
1手で選べるのは、次のどれか1つ。

| 札 | 対象・行き先 | できる条件 | 結果（段1） |
|---|---|---|---|
| 進む | 西か東の隣のマス（下の「入る」「登る」「押す」の候補） | 下の 3.1 | 当主が候補の行き先のマスへ動く。真下に支えのないマスに入った当主は、その手の 2-5 で落ちる |
| 置く | 持っている道具1つ、または棚の部品1つと、置く位置 | 道具の全部のマスが盤の中で空き・水、かつ道具のマスのどれかが当主の4方向の隣 | 道具が盤面の物になる。その手の段2から規則を受ける。真下が地面のマスの杭は固定物になる |
| 使う | 当主の4方向の隣の、火種の部品か縄の端 | 火種：燃えていない。縄の端：`規則の計算.md` 4.5 の引く条件 | 火種に火がつく／縄の先の組を1マス引く |
| 拾う | 当主の4方向の隣の、部品1つだけの組、自分が置いた道具、墓（遺品） | 燃えていない。固定でない（杭は打ったあとも拾える：案）。棚は `leader.carryParts`、道具は `leader.carryTools` まで | 棚か持ち物に入る。墓なら、その墓の遺品を全部取り戻す（`継承の一周.md` 5章） |
| 待つ | — | いつでも | 当主は何もしない |
| 帳面 | — | いつでも（手ではない） | 帳面を読む画面を開く。手数は進まない |

- 先祖が据えた仕掛けは、挑む中は拾えない（結果の画面でばらせる。`谷と一生の流れ.md`）
- 候補の並べ方：盤面の下の段から、西から（`規則の計算.md` 5.1 の基本の順と同じ）。手の棚の小札は、この順で「前」「次」で送れる
- 「待つ」はいつでも選べるので、選べる手が1つもない状態は起きない

### 3.1 「進む」の候補（入る・登る・押す）
当主が (x, y) にいて、西か東の隣の列を x′（x−1 か x+1）とする。どれも手の始めの盤面で決める（`規則の計算.md` 5.3 #16）。「支えのある」は `規則の計算.md` 2.2 の支え。

| 候補 | できる条件 | 行き先 | 結果 |
|---|---|---|---|
| 入る | (x′, y) が空きか水 | (x′, y) | 当主が (x′, y) に入る |
| 登る | (x′, y) が地面、固定物（墓、打った杭とその組）、または支えのある組（敵を除く。下の注記）のマス。かつ、(x′, y−k) が空きになる k が 1〜`leader.climbHeight` にあり（いちばん小さい k を使う）、(x′, y−1)〜(x′, y−k+1) がどれも地面・固定物・支えのある組（敵を除く）で、当主の頭の上 (x, y−1)〜(x, y−k) がどれも空き | (x′, y−k) | 当主が (x′, y−k) に入る。登った先の真下は物か地面なので、その手の 2-5 では落ちない（2-4 で下の組がずれれば一緒に動く） |
| 押す | (x′, y) に固定でない組があり、組の重さ ≤ `leader.pushWeight`、組の全部のマスを同じ向きに1マス動かす先が、どれも空きか水 | (x′, y) | 組が1マス動き、当主はあいた (x′, y) に入る |

- **物の隣では「押す」と「登る」が別の候補**になる。両方の条件を満たすときは、両方が候補に出る（どちらが起きるか分からない手は作らない）
  - 盤面では行き先のマスが違う（押す＝組のあったマス、登る＝組の上のマス）ので、行き先のマスをタップすればどちらか1つに決まる
  - 手の棚の小札は「→ 押す」「→ 登る」（西なら「←」）のように、向きと候補の名前を分けて出す
- 支えのない組（宙にある組）の上には登れない。押すは、組に支えがあってもなくても条件どおり
- **敵は登る足場にならない**：敵の組（`規則の計算.md` 2.1。敵はそれ1つで1つの組）は、支えがあっても、上の表の「登る」の「支えのある組」に数えない（(x′, y) にも、途中の (x′, y−1)〜(x′, y−k+1) にも）。敵の隣で出るのは「押す」（条件を満たすとき）だけ
  - 理由：敵の上に乗れると、敵が歩くと当主が支えを失って落ち、敵が踏み台にもなる。敵を「道具で解く相手」にしておくため、今は登れないにする（パラメータ表 13.4）
  - 敵の上に載った物（板など。敵に支えられていて支えのある組）は、足場になる。ただし上の表のとおり、(x′, y) と途中のマスに敵があると登れないので、その物に登れるのは、当主がその物と同じ高さ（(x′, y) がその物のマス）にいるときだけ
  - **未決**：敵に登れるようにするか（敵ごとに変えるかも含む）は、game-design-ai が 06（敵の仕様）で見直す（12章）
- `leader.climbHeight` より高い段差（登る先の空きが `leader.climbHeight` 段より上にしかない）は、登るの候補に出ない
- 入る・登る・押すのどれも満たさない向きには、進むの候補は出ない。盤の外（壁）のマスは、空きとしても物としても数えない（x′ が盤の外の向き、y−k が盤の上の外になる登るは、候補に出ない）

## 4. 選ぶ → 確定の流れと、次の1手の印

### 4.1 流れ
1. 手の札をタップ → 候補のマスが盤面に出て（当主の色の丸）、手の棚が候補の小札（←、→、道具の絵など）に入れかわる
2. 盤面の候補のマスをタップするか、小札をタップ → **選んだ手**になる。盤面に次の1手の印、説明の帯に1行
3. **確定**を押す → 1手を計算して保存し（`保存.md`）、1手の再生を始める
4. 再生が終わると、次の手を選べる

- **選び直す**（スタイル見本の「戻す」の名前を変えた。計画.md 6章 #7）：確定の前だけ押せる。選んだ札・候補を消して、1. の前に戻す。確定した手を戻す操作は**どこにもない**
- 何も選んでいないとき、確定は押せない（薄墨＋斜線）
- **危険な手**：選んだ手の印の計算で、当主が死ぬ・自分の道具の部品が壊れる・荷が壊れるときは、次の形で出す。もう一度の確かめの画面は出さない（案。確定の一押しで防ぐ：アート 5）
  - 確定の札：地が朱、字は濃藍、字の前に「！」の三角（濃藍）、札の左端に斜線の帯（アート 3.3「確定（危険な手）」、5章）
  - 説明の帯：「この手で死ぬ」などの文を、**字は白線**のまま出し、前に朱の「！」の三角、帯の左端に朱の斜線の帯を付ける（アート 4.5。朱の 16px の字は使わない）

### 4.2 次の1手の印
- 計算：`規則の計算.md` 7章（盤面の写しで選んだ手を1手進めて比べる。本番と同じ関数）
- 何も選んでいないときは、「待つ」を選んだときの印を出す（当主が何もしなくても起きることが見える）
- 出す印（形はアートディレクション 3.2、色は見た目B のパレット 3.3「印3種」と「危険」。色の値はアートの文書を正とし、ここには書き写さない）：

| 印 | 何を見せるか | 形 | 色（B） |
|---|---|---|---|
| 当主の次の1手 | 当主の動く先 | 足あとと、行き先のマスの丸、実線 | 山吹（行き先のマスは山吹の下塗り：アート 3.3「選ぶ・押す」） |
| 道具・物の次の動き | 動いた先の物の影（半透明）と矢印 | 点線 | 白線 |
| 敵の次の手 | 敵の行き先 | 「く」の字の爪あと、破線 | 藤 |
| 危険 | この手で死ぬ・壊れるマス | 三角の「！」とマスの斜線 | 朱 |

- 1画面に同時に出すのは、この4種類まで。2手以上先の予測は出さない（アート 4.3）
- 印と、確定したあとの実際の動きは必ず一致する（`規則の計算.md` R-26）

## 5. 1手の再生
- 順：段1 当主 → 段2 の小段（2-1〜2-5）のうち何かが起きたもの → 段3 敵・谷の動き（`規則の計算.md` 3章）
- 1つの段・小段の時間：`playback.stepMs`、早送りでは `playback.fastStepMs`。段・小段の間に `playback.gapMs` 止める（アート 4.4）
- **送る**（1手送り）を入にしていると、段・小段ごとに止まり、盤面をタップすると次へ進む
- 送るが切のとき、再生中に盤面をタップすると、その手の終わりまで飛ばす（待たされないため）
- 再生は見せ方だけで、計算は確定のときに終わっている。再生を飛ばしても結果は同じ

## 6. 課題の条件と終わり
条件は**手の終わり（段3 のあと）だけ**で判定する（`規則の計算.md` 5.3 #20）。中身は課題の場所ごとに決める（場所の仕様、07）。ここでは型ごとの判定の骨を決める。

| 型 | 解けた | もう解けない（引き返すしかない） |
|---|---|---|
| 渡る | 当主がゴールのマスにいる | — |
| 運ぶ | 荷がゴールのマスにある | 荷が壊れた、盤から消えた |
| 壊す | 的が壊れた | — |
| 守る | 守る物が `challenge.<場所>.protectTurns` 手のあいだ壊れずに残った | 守る物が壊れた、消えた |
| 開ける | 未決（`規則の計算.md` 12章） | 未決 |
| 追い払う | 盤に敵がいない | — |

- 「もう解けない」になったら、説明の帯にそう出し、引き返すを勧める（自動では終わらせない。手は打てる）
- 課題の終わり方は3つ：

| 終わり方 | きっかけ | 年月 | 次の画面 |
|---|---|---|---|
| 解けた | 手の終わりに条件を満たした | `challenge.yearsCost` 進む | 結果（`谷と一生の流れ.md`） |
| 引き返す | メニューの「引き返す」→ 確かめの一押し | `challenge.retreatYearsCost` 進む | 谷の地図。置いた道具は盤面に残り、次に来たときもそこにある（案） |
| 死んだ | 手の途中で当主が死んだ | 進まない（死んだ年＝今の谷暦） | 遺す（`継承の一周.md`） |

- 手数の上限：`challenge.turnLimit`（未決。プロトでは上限なし）
- 当主の体力：`leader.hp`。敵が当主のマスへ入る動きをしたら体力が1減り、0で死ぬ（敵はそのマスに入らず手前で止まる）。MVPの案は「一度で死ぬ」だが、値は未決

## 7. 状態と遷移
| 今の状態 | きっかけ | 次の状態 |
|---|---|---|
| 見る | 挑む | 手を選ぶ（何も選んでいない） |
| 手を選ぶ（何も選んでいない） | 札をタップ | 候補を選ぶ |
| 候補を選ぶ | 候補をタップ | 手を選んだ（印が出る） |
| 候補を選ぶ／手を選んだ | 別の札をタップ | 候補を選ぶ（その札） |
| 候補を選ぶ／手を選んだ | 選び直す | 手を選ぶ（何も選んでいない） |
| 手を選んだ | 確定 | 再生（計算と保存はここで終わっている） |
| 再生 | 最後の段が終わった／飛ばした | 手を選ぶ（何も選んでいない）、または課題の終わり |
| 手を選ぶ（どれでも） | メニュー → 引き返す → 確かめ | 谷の地図 |
| 再生 | 当主が死んだ手の再生が終わった | 遺す |
| 再生 | 条件を満たした手の再生が終わった | 結果 |

## 8. 数値（`パラメータの名前.md`）
`board.size`、`leader.climbHeight`、`leader.pushWeight`、`leader.pullWeight`、`leader.carryParts`、`leader.carryTools`、`leader.hp`、`playback.stepMs`、`playback.fastStepMs`、`playback.gapMs`、`challenge.yearsCost`、`challenge.retreatYearsCost`、`challenge.turnLimit`、`challenge.<場所>.protectTurns`。

## 9. 例外・境界
- **候補が0の札**：押せない形（薄墨＋斜線）。押すと理由を説明の帯に出す
- **同時**：盤面の同じマスに候補が2つ以上あるとき（置く位置など）、タップでは基本の順で先の候補が選ばれ、小札の「次」で次の候補に送れる
- **中断**：確定と同時に計算と保存をする。再生の途中でアプリが閉じたら、開き直すと再生を飛ばした状態（次の手を選ぶ）から始まる（計画.md 6章 #8）
- **死亡**：死んだ小段で計算を止め、その手の再生が終わったら遺すへ（自動。プレイヤーの操作は要らない）
- **ポーズ**：ターン制で時間の制限はない。メニューを開いている間は何も進まない
- **縦が短い端末**：基準 360×640 より小さい端末は想定しない（アート 4.1）
- **PC**：マウスで同じ操作。キーの割り当ては未決（あれば）

## 10. 演出と音のきっかけ
- 札・候補のタップ：短い木の音（案）。確定：木槌の「こん」。選び直す：紙をめくる短い音（アート 6.3 の「取り消し」）
- 危険な手を選んだ：低い2音
- 1手の再生の動きと音：`規則の計算.md` 9章の出来事ごと（アート 4.4、6.3）
- 解けた：上がる3音＋仕掛けの「かちり」。死：一族の旋律の最初の2音（アート 6.3）

## 11. 受け入れ条件
- [ ] C-01 手の札をタップすると、その手の候補のマスが盤面に出て、同じ候補が手の棚の小札にも出る。盤面のマスをタップしても小札をタップしても、同じ手が選ばれる
- [ ] C-02 手を選ぶと、確定を押す前に、盤面に次の1手の印（当主の動く先、物の動き、敵の次の手、危険のうち起きるもの）が出て、説明の帯に1行（全角20字まで）が出る
- [ ] C-03 何も選んでいないときは確定が押せず、盤面には「待つ」の場合の印が出る
- [ ] C-04 「選び直す」を押すと、選んだ手が消え、盤面と記録は選ぶ前と同じになる
- [ ] C-05 確定したあとは、どの画面のどの操作でも、その手の前の盤面に戻らない（「選び直す」は再生中・再生後に押せない）
- [ ] C-06 当主が死ぬ手を選ぶと、確定の札の地が朱になって「！」の三角と左端の斜線の帯が付き、説明の帯には白線の字の文の前に朱の「！」の三角、帯の左端に朱の斜線の帯が出る（説明の帯の字は朱にならない）。確定を1回押すとその手が進む（ほかの確かめの画面は出ない）
- [ ] C-07 確定した手の結果が、選んだときの印（動く物と行き先、死ぬか）と一致する
- [ ] C-08 再生は 段1 → 段2 の起きた小段 → 段3 の順で、1つあたり `playback.stepMs`、間に `playback.gapMs` 止まる。送るが入のときは、段・小段ごとに止まり、タップで次へ進む
- [ ] C-09 送るが切のとき、再生中に盤面をタップすると、その手の終わりの盤面になり、結果は飛ばさないときと同じになる
- [ ] C-10 重さが `leader.pushWeight` 以下の組の隣で、その向きの「進む」の「押す」を確定すると、組が1マス押されて当主が1マス進む。重さがそれより大きい組の向きには「押す」の候補が出ない
- [ ] C-11 隣のマスが地面、固定物（墓、打った杭の組）、または支えのある組（敵を除く）のマスで、その上 `leader.climbHeight` 段以内に空きがあり、当主の頭の上も空いていると、「進む」に「登る」の候補が出て、確定すると当主はその空きのマスに入り、その手では落ちない。地面・固定物・支えのある組の3つのどれでも同じに登れる。登る先の空きが `leader.climbHeight` 段より上にしかないとき、隣の組に支えがないとき、頭の上がふさがっているときは「登る」の候補が出ない
- [ ] C-20 押せる重さの、支えのある組の隣で、その上に登れるときは、同じ向きに「押す」と「登る」の2つの候補が出る。盤面では「押す」は組のあったマス、「登る」は組の上のマスが行き先として別々に出て、手の棚には別の小札が出る。どちらを確定しても、選んだほうだけが起きる（押すを選んで当主が組の上に乗ること、登るを選んで組が動くことはない）
- [ ] C-21 平らな地面の上に置いた板1枚（支えのある組）の西の隣に当主が立ち、「進む」の「登る」で東を確定すると、当主は板の真上のマスに入り、その手の終わりにもそのマスにいる。板の真下を空きにして支えのない形にした盤面（縄もない。テストで盤面を直に作る）では、その板への「登る」の候補が出ない
- [ ] C-22 平らな地面の上に立つ敵（支えのある組）の西の隣に当主が立つと、東の「進む」に「登る」の候補が出ない。敵の重さが `leader.pushWeight` 以下で押し出す先が空きなら「押す」の候補だけが出る。重さがそれより大きければ、東には進むの候補が出ない。敵の真上が空きでも、同じに「登る」は出ない
- [ ] C-12 「置く」の候補は、道具の全部のマスが空き・水で、道具のどれかのマスが当主の4方向の隣にある位置だけになる

- [ ] C-15 運ぶの課題で荷が盤から消えると、説明の帯に「もう解けない」と出て引き返すを勧めるが、手は打ち続けられる
