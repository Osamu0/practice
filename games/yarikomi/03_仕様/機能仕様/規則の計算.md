## 1. 盤面とマス

- 盤面は**横から見た断面**のマス目。重いものは下へ落ちる
- 座標は (x, y)。x は西（左）から東（右）へ 0〜W−1、y は上から下へ 0〜H−1
- 課題の盤面の大きさ：`board.size`（プロトと縦切りでは 7×7 に固定。スクロールしない。理由は GDD 11章 #2）
- 盤の外：
  - 西・東・上の外は**壁**。物は出られない。壁にふさがれた動きはそこで止まる
  - 下の外は**谷底**。下へ出た物は盤から消える（失われる）。当主なら死ぬ（死に方「谷底へ落ちる」）
- マスの地（地形）は3つ（MVPの初版）：

| 地形 | 物が入れるか | 上の物を支えるか | そのほか |
|---|---|---|---|
| 空き | 入れる | 支えない | — |
| 地面 | 入れない | 支える | 壊れない、燃えない、押せない |
| 水 | 入れる | 支えない | 入った物は濡れる。燃えている物は消える（4.4）。当主は息の手数を数える（4.2） |

- **1つのマスに物は1つまで**。縄は物ではなく、マスを取らない（4.5）
- 火・濡れは物の「状態」で、マスを取らない

## 2. 物

盤面に乗るもの。どれも同じ規則を受ける（専用の戦闘の計算はない）。

| 物 | 説明 | 持つ値 |
|---|---|---|
| 部品 | 道具の材料。MVPの部品は**すべて1マス**（`部品と素材.md`） | 重さ、燃えやすさ、燃え尽きの手数、硬さ、傷みの段、（ばね系）強さと向き、（縄系）長さ |
| 当主 | プレイヤーが動かす1人 | `leader.*`（重さ、硬さ、燃えやすさ ほか） |
| 敵 | 谷の災いが生んだ物。決まった振る舞いで動く（振る舞いは敵の仕様、game-design-ai） | 敵ごとの重さ、硬さ、燃えやすさ |
| 荷・的 | 「運ぶ」「壊す」課題の物。課題の場所ごとに決める | 場所ごとの重さ、硬さ、燃えやすさ |
| 墓 | 先祖の死んだ場所に建つ（`継承の一周.md`） | **固定物**：動かない、支える、押せない、燃えない、壊れない |

共通の値：
- **番号**：物が生まれた順の整数。年代記を通して増えるだけで、使い回さない。並べる順の最後の決め手に使う
- **重さ**：整数（0以上）。濡れや癖で足される（4.1）
- **燃えやすさ**：整数。0は燃えない
- **硬さ**：整数。上に落ちてきた・投げ当てられた組の重さがこれ以上なら壊れる（4.6）
- **落ちた距離**：続けて落ちたマスの数。止まったら0に戻す（4.2）
- **固定**：地面に打った杭（真下が地面のマスに置いた杭）と、その杭につなぎ点でつながった組の全部、墓。規則で動かない、押せない（固定の組の中の滑車が、滑車として働く：4.5）

### 2.1 組（くみ）
- つなぎ点でつながった部品のまとまりを**組**という。組は1つの硬い物として動く（形は変わらない）
- 部品1つだけでも組。当主・敵・荷・的・墓は、それ1つで1つの組（部品と硬くはつながらない）
- 組の重さ＝組の中の物の重さの和
- 部品が消える（燃え尽きる、壊れる）と、つながりを数え直し、組が分かれることがある。分かれた組は、もとの組が「この手でもう動いた」なら、それを受け継ぐ（5章 #22）
- 縄は組を硬くはつながない。縄でつながった2つの組は、別の組のまま（4.5）

### 2.2 支え
組が**支えられている**とは、次のどれかが成り立つこと：
1. 組のマスのどれか1つの真下が、地面、固定物、または（その時点で）支えられているほかの組
2. 張った縄で、固定物か支えられている組から吊られている（4.5）

ずれる（4.1）と落ちる（4.2）は、この「支え」で決まる。水は支えない。

## 3. 1手の進み方（段）

当主が1手を確定すると、次の順で盤面を進める。各段・各小段のあとで盤面を確定し、次の小段はその盤面から始める（同時に決めるのは 2-1 の燃えるだけ）。

| 段 | 小段 | 何をするか | 規則 |
|---|---|---|---|
| 段1 当主 | — | 当主の手（進む・置く・使う・拾う・待つ）を行う。手の始めの盤面で決める | `挑む.md` 3章 |
| 段2 物の規則 | 2-1 燃える | 燃え尽き・燃え移りを**同時に**決める | 4.4 |
| | 2-2 弾む | 前の手で縮んだばねが、乗った組を打ち出す | 4.3 |
| | 2-3 引っぱる | 滑車をはさんだ縄の釣り合いで組を動かす | 4.5 |
| | 2-4 ずれる | 支えのある組が、重さの釣り合いでずれる | 4.1 |
| | 2-5 落ちる | 支えのない組が落ちる。当たる・縮む・水・谷底もここ | 4.2、4.3 |
| 段3 敵と谷 | 3-1 敵 | 敵が番号の小さい順に、振る舞いの1歩を行う | 敵の仕様 |
| | 3-2 谷の動き | 課題の場所が持つ決まった動き（あれば。場所の仕様で） | 場所の仕様 |
| 手の終わり | — | 課題の条件を判定する。手数を1足す。記録に足す | `挑む.md` 5章 |

- 段2・段3で**何も起きなかった小段は、見せるときに飛ばす**（計算は同じ）。1手送りでは、起きた小段ごとに止まる
- 当主が死んだら、**その小段の終わりで手の計算を止める**（あとの小段、段3、条件の判定はしない）
- 1手の計算は、確定した手と盤面だけで決まる。時間、端末、描画の速さは結果を変えない

## 4. 規則5つ

### 4.1 重さ
物の重さ＝物の値 ＋ 濡れの足し（掟しだい、6章）＋ 癖の足し（6章）。組の重さ＝中の物の重さの和。
重さが効くところ：ずれる（下）、弾む距離（4.3）、当たる（4.2、4.3）、縄の釣り合い（4.5）、当主が押す・引く（`挑む.md`）。

**ずれる（2-4）**：てこと釣り合いを、マス目で読める形にしたもの。
- 対象：固定でなく、2-4 の時点で支えのある組で、この手でまだ動いていない組
- 支えの列：組のマスのうち、真下が地面・固定物・ほかの支えのある組であるマスの x。いちばん西を xW、いちばん東を xE とする
- 列の重さ load(x)：組の x の列のマスの重さの和 ＋ その列で組の上に積み重なった物の重さ（組のその列のいちばん上のマスの真上から上へ、物が途切れるまで。その物が組に支えられているものに限る）
- 東へずれるか：
  - 東へ倒す力 M東 ＝ Σ（x ＞ xE の列）load(x) ×（x − xE）
  - 戻す力 R東 ＝ Σ（x ＜ xE の列）load(x) ×（xE − x）
  - M東 ＞ R東 なら東へずれる
- 西へずれるか：同じ式を西に向けて（M西 ＝ Σ（x ＜ xW）load(x) ×（xW − x）、R西 ＝ Σ（x ＞ xW）load(x) ×（x − xW）、M西 ＞ R西）
- 東と西が両方成り立つとき・どちらも成り立たないときは、ずれない。等しいときもずれない（釣り合い）
- ずれる動き：組と、load に数えた積み重なった物を、まとめて1マスだけ東（西）へ動かす。行き先のどれか1マスでも、地面・壁・ほかの物でふさがれていたら、ずれない
- ずれた組と、一緒に動いた物は、この手ではもう動かない。次の手で支えがなければ落ちる
- 例：崖から東へ張り出した板の東の端に当主が乗ると、M東 が増えて板が当主ごと東へずれ、次の手で落ちる。板の西の端に重りを載せると R東 が増えてずれない（デザインの柱の最初の5分の「重りで板の端を押さえて渡る」）

### 4.2 落ちる（2-5）
- 対象：固定でなく、この手でまだ動いていない組で、支えのない組
- 回す順：基本の順（5章 決まり3。下の段の組から）
- 動き：1マスずつ下へ、1手で最大 `rule.fall.cellsPerTurn` マス。1マス進むたびに支えを見直し、支えができたら止まる。張った縄でも止まる（4.5）
- **落ちた距離**：落ちた1マスごとに1足す。2-5 の終わりに支えがある組は0に戻す。水のマスに入ったら0に戻す。打ち出されたら0から数え直す（4.3）
- **当たる**：落ちて止まったとき、落ちた距離が `rule.impact.minFall` 以上で、真下で止めた物 X が地面・固定物・ばねの押す面（4.3）でなく、組の重さ ≥ X の硬さ なら、X が壊れる（4.6）
- **当主が落ちて止まったとき**：落ちた距離が `leader.fallDeathHeight` 以上なら死ぬ（死に方「落ちて死ぬ」）。水のマスで止まったときは数えない
- **当主の上に落ちたとき**：上の「当たる」で X が当主なら、組の重さ ≥ `leader.hardness` で当主は死ぬ（死に方「下敷き」）
- **水**：水のマスに入った物は濡れる（4.4）。水の中でも支えはないので底まで落ちる。当主が水のマスに `leader.breathTurns` 手続けていたら死ぬ（死に方「おぼれる」）
- **谷底**：下の外へ出た組は盤から消える。消えた物は、その手のあとの小段に出てこない

### 4.3 弾む（縮むは 2-5・2-2、打ち出すは 2-2）
- ばね系の部品は**向き**（上・東・西・下）を持つ。向きの側の面を**押す面**という。向きは作業台で決める（`作業台と設計図.md`）
- **縮む**：規則の動き（2-2 の打ち出し、2-5 の落ちる）で進んでいる組 G が、別の組にあるばね S の押す面に向かって進み、S にふさがれて止まったとき、S は縮み、G を覚える
  - このとき「当たる」は起きない。G の落ちた距離は0に戻す
  - 当主の手（段1）で押し当てても縮まない（規則の動きだけ）
  - 1つの G が同じ手に2つのばねで止まったら、番号の小さいばねだけが覚える
- **打ち出す**：次の手の 2-2 で、縮んだ S の押す面の隣に G のマスがまだあれば、G を S の向きへ動かす
  - **弾む距離 ＝ max(0, Sの強さ − Gの重さ)** マス。重さは 2-2 の始めの値。S の強さは `part.<id>.springPower`（癖・掟の足しを含む）
  - 1マスずつ動かし、ふさがれたら止まる。1マス以上動いてから物 X にふさがれ、G の重さ ≥ X の硬さ なら X が壊れる（投げ当て、4.6）。ふさいだのが別のばねの押す面なら、そのばねが縮む
  - 弾む距離が0なら動かない（重すぎて弾まない）
  - 打ち出したあと S は戻る。G の落ちた距離は0から数え直す
  - 打ち出された G は、この手ではもう動かない（2-5 で落ちない）。次の手から、支えがなければ落ちる
  - 縮んだあと、次の手の 2-2 までに G か S が動いた・消えた・壊れたら、打ち出さずに S は戻る

### 4.4 燃える（2-1）
- 物は**燃えやすさ**（0は燃えない）を持つ。燃えている物は**残りの手数**を持つ
- 火がつくのは3つ：
  1. 当主の手「使う」で火種の部品（火打ち石、火打ち金）を打つ（段1。その手の 2-1 から燃えている物として数える）
  2. 火種の部品が当たる・投げ当てで止まったとき（4.2、4.3。次の手の 2-1 から数える）
  3. 燃え移る（下）
- 2-1 の計算（**小段の始めの盤面の写しで、全部を同時に決める**）：
  1. 写しで燃えている物は、残りの手数を1減らす。0になったら**燃え尽きる**
  2. 写しで燃えている物の4方向の隣にある物で、燃えやすさ＞0、濡れていない、燃えていない、水のマスにない物に火がつく。残りの手数はその物の `part.<id>.burnTurns`（当主・敵・荷は別、下）
  3. 1と2は同じ写しで決める。燃え尽きる手でも、隣には移る。2つの火から同じ物に移っても、つくのは1回
- 燃え尽きたとき：部品は組から消える（組が分かれることがある）。荷・的は壊れる扱い（4.6）。縄は切れる（4.5）
- 当主：燃えやすさ `leader.flammability` が0より大きければ、火がついた時点で死ぬ（死に方「火に巻かれる」）
- 敵：燃えやすさが0より大きい敵は、火がついた時点で追い払われる（盤から消える）
- 水：燃えている物が水のマスに入ったら、その時点で火は消える。濡れた物は燃え移らない
- **濡れ**：物の状態。水のマスに入る、または掟（例：長雨）でつく。その課題の間は乾かない

### 4.5 引っぱる（縄。2-3、2-5、段1）
- 縄系の部品は2つの**端**を持つ。端は部品のつなぎ点、または盤面の物（荷など）につながる
- 縄は**長さ**（`part.<id>.ropeLength`）を持つ。縄は物ではなく、マスを取らない。物の動きをふさがない
- 滑車（縄系の部品）があると、縄は 端A → 滑車 → 端B と通る。滑車は固定物（杭、地面）に付いているときだけ滑車として働く
- 縄の長さの数え方：端どうしのマンハッタン距離（滑車があれば A→滑車 と 滑車→B の和）。この距離が長さに等しいとき**張っている**という
- **張ったら止まる**：どの規則の動きでも、縄の距離が長さをこえる動きは、こえる手前で止まる。縄の先の組を引きずることはない（引きずるのは釣り合いと当主の引くだけ）
- **吊る**：張った縄の端の組 G が、もう一方の端（滑車があれば滑車）より下にあり、もう一方が固定物・支えのある組・滑車なら、G は支えられている（2.2）
- **釣り合い（2-3）**：滑車をはさんで両端に組 A・B があり、縄が張っていて、A・B の少なくとも一方に縄のほかの支えがないとき：
  - 重さ A ＞ 重さ B なら、A を1マス下へ、B を1マス滑車の方へ動かす（B が A より重ければ逆）。重さは 2-3 の始めの値
  - 重さが等しければ動かない（両方吊られる）
  - どちらかの行き先がふさがっていたら、両方とも動かない
  - 動いた A・B は、この手ではもう動かない
- **当主が引く（段1）**：当主の手「使う」で、当主の隣のマスにある縄の端を引くと、もう一方の端の組が1マス、縄に沿って当主の方へ動く。条件：その組の重さ ≤ `leader.pullWeight`、行き先が空き、固定でない
- **燃える**：縄の通るマス（端と端、滑車を結ぶ直線のマス）のどれかが、2-1 の写しで燃えている物の隣なら、縄に火がつく。燃え尽きたら縄は**切れる**。切れた縄は、同じ手の 2-3・2-5 からないものとして計算する

### 4.6 壊れる（共通）
当たる（4.2）・投げ当て（4.3）の結果。壊れたものによって：

| 壊れたもの | どうなるか |
|---|---|
| 部品 | 傷みの段に `rule.impact.wearAdd` を足す。傷みの段が最大（壊れかけ＝2。アートの3段）をこえたら消える |
| 敵 | 追い払われる（盤から消える） |
| 荷・的 | 壊れる（「壊す」課題の的なら条件を満たす。「運ぶ」課題の荷なら失敗の条件。課題の仕様で） |
| 当主 | 死ぬ |
| 墓、地面 | 壊れない |

- 壊れかけ（傷みの段2）の部品は、力がかかる（当たる・当てる、押す面で受ける・打ち出す、張った縄の端になる）たびに壊れる扱いになる。つまり、もう一度で消える

## 5. ぶつかったときの順番の表

### 5.1 共通の決まり（どの行もこれに従う）
1. **小段は表の順に1つずつ行い、小段ごとに盤面を確定する**。同時に決めるのは 2-1 燃えるだけ
2. **1つの組は、1手の段2で1回だけ動く**。先に動かした小段が取る。掟が足す動き（例：大風の流れ）は、同じ動きの続きとして数える
3. **基本の順**：小段の中で物を回す順は「組のいちばん下のマスの y が大きい順（下から）→ 同じなら、いちばん西のマスの x が小さい順（西から）→ 同じなら、組の中のいちばん小さい番号の順」。ばね・縄を回す順は、その部品の番号の小さい順
4. 動きは**1マスずつ**進め、1マスごとに、ふさがり・支え・縄の張りを見る
5. 当主が死んだら、その小段の終わりで手を止める
6. 値（重さ、強さ）は、その小段の始めの値を使う
7. 整数だけで計算する。割り算は使わない（使うときは切り捨てと決めて、この表に書く）

### 5.2 規則どうしの組み合わせ（5つの規則の全部の組み合わせに行がある）

| # | ぶつかるもの | 起きうること | 決め | 確かめる例（受け入れ条件 R-xx と対応） |
|---|---|---|---|---|
| 1 | 落ちる × 落ちる | 2つの組が同じマスへ落ちる／積み重なった組が落ちる | 基本の順で先の組が入り、あとの組はその上で止まる。積み重なった組は下から順に落ちるので、一緒に1マスずつ落ちる | R-05 |
| 2 | 弾む × 弾む | 2つのばねが同じ手に打ち出し、同じマスへ向かう／打ち出された組が別のばねで止まる | ばねの番号の小さい順に打ち出す。あとの組はふさがれて止まる。別のばねの押す面で止まったら、そのばねが縮む（打ち出しは次の手） | R-11 |
| 3 | 燃える × 燃える | 2つの火から同じ物へ燃え移る／燃え尽きる手の火 | 写しで同時に決める。つくのは1回。燃え尽きる火も、その手には隣へ移る | R-13 |

| 9 | 重さ × 引っぱる | 滑車をはさんだ2つの組 | 重い側が1マス下がり、軽い側が1マス上がる。等しければ止まる。重さは 2-3 の始めの値 | R-16 |
| 10 | 落ちる × 弾む | 落ちてばねに乗る | ばねの押す面で止まると縮む（当たらない、落ちた距離0）。次の手の 2-2 で打ち出す。打ち出された手は落ちない | R-08 |
| 11 | 落ちる × 燃える | 燃えたまま落ちる／落ちて火の隣に来る | 燃えている組も落ちる。燃え移りは 2-1 の写しで決めるので、2-5 で火の隣に来た物には次の手で火がつく。燃えたまま水に入ったら、その時点で消える | R-15 |
| 12 | 落ちる × 引っぱる | 縄で吊られた物／縄に余りがある物 | 張った縄で吊られた組は支えがあるので落ちない。余りのある縄は、張るまでは止めない（張ったマスで止まる）。2-3 で動いた組は 2-5 で落ちない | R-18 |
| 13 | 弾む × 燃える | 燃えているばね／打ち出しの途中の火 | 金属のばねは燃えない（燃えやすさ0）。燃えている木のばねも打ち出す。打ち出しの途中には燃え移らない（燃え移りは 2-1 だけ） | R-13 |
| 14 | 弾む × 引っぱる | 縄につながった組を打ち出す | 打ち出しの途中で縄が張ったら、そこで止まる。縄の先の組は引きずらない | R-19 |
| 15 | 燃える × 引っぱる | 縄が燃え尽きる | 縄は 2-1 で切れる。同じ手の 2-3・2-5 では切れた縄はないものとする（吊られていた組は同じ手に落ちる） | R-20 |

## 6. 掟と癖の差し込み口

掟（代ごと）と癖（当主ごと）は、規則の芯に次の4つの口からだけ効く。新しい小段や、確率は足さない（柱2）。

| 口 | 何を変えるか | 掟の例（案） | 癖の例（案） |
|---|---|---|---|
| A 値 | 物・部品の値（重さ、燃えやすさ、強さ、長さ）に足す・引く | 長雨：素材が木・縄・布の物は濡れて始まり、重さに `law.longRain.wetWeightAdd` を足す | せっかち：その当主が組んだばねの強さに `trait.hasty.springPowerAdd` を足す |
| B 続きの動き | 決まった小段の動きが終わった組に、続きの動きを足す（同じ動きの続きとして数える） | 大風：2-2 の打ち出しと 2-5 の落ちるで動いた組を、そのあと東へ最大 `law.strongWind.driftCells` マス、1マスずつ流す | （MVPではなし） |
| C 当主の値 | `leader.*` に足す・引く | （MVPではなし） | 怪力：`leader.pushWeight`・`leader.pullWeight` に足す |
| D 盤の外 | 拾える部品の表、作業台の大きさ など規則の外 | 鉄が採れない：拾える部品の表から素材＝鉄を外す | 几帳面：作業台の大きさに `trait.meticulous.benchSizeAdd` を足す |

- 癖の効きは、**その当主が組んだ道具に、組み上げたときに焼き込む**（口A）か、**当主自身に効く**（口C・D）。谷に据えた仕掛け・遺品は、作った当主の癖のまま。設計図には癖の効きを書かない（だから、子が組み直すと子の癖になる）。詳しくは `継承の一周.md`
- 掟は、その代の間、盤面の全部の物に効く（先祖の仕掛けにも効く）

## 7. 次の1手の印の計算
- 盤面の写しに、選んだ手を本番と同じ関数で1手進め、手の前と後を比べて出す（確認版の `preview()` と同じ考え）。印と実際は必ず一致する
- 計算が返すもの：動いた物（どこからどこへ、どの小段で）、起きた出来事（7章の下の表）、当主が死ぬか、壊れる物
- 2手以上先は計算しない・見せない（アートディレクション 4.3）
- 画面での見せ方は `挑む.md` 4章

## 8. 決定的であるための決まり（技術選定 4.2 をこの仕様の決めにする）
- `src/core/` では `Math.random`、`Date`、`performance.now`、DOM を使わない
- 数は整数だけ。三角関数・平方根は使わない
- 回す順は 5.1 の基本の順だけ。オブジェクトのキーの並び・Set の並びに頼らない
- 乱数はシード付きの sfc32 だけで、使うのは「年代記・代・課題の始まりに引くもの」（掟、拾える部品、子の候補）だけ。手の計算の中では乱数を使わない
- 乱数の流れは用途ごとに分ける（例：`シード + "/代3/掟"`）

## 9. 演出と音のきっかけ
計算は、起きたことを**出来事**の列で返す（小段、物の番号、マス、種類）。画面はこれを見て動きと音を出す。音・演出の中身はアートディレクション 4.4・6.3。

| 出来事 | 小段 | 音のきっかけ（アート 6.3） |
|---|---|---|
| ずれた | 2-4 | 木のきしみ（案。アートに無いので audio に渡す） |
| 落ちた／止まった | 2-5 | 重さ・落ちる「ごとっ」 |
| 当たった（壊した、追い払った） | 2-5、2-2 | 重さ・落ちる、壊れる音（案） |
| 縮んだ／打ち出した | 2-5、2-2 | 弾む「びよん」 |
| 火がついた／燃え移った／燃え尽きた／火が消えた | 2-1、2-5 | 燃える「ぱちぱち」「ぽっ」 |
| 張った／釣り合いで動いた／引いた／切れた | 2-3、段1 | 引っぱる「きしみ」 |
| 濡れた | 2-5 | （案：水の音） |
| 谷底へ消えた | 2-5 | （案） |
| 当主が死んだ（死に方つき） | どこでも | 死 |
| 条件を満たした | 手の終わり | 課題が解けた |

出来事の列は、年表の一文（死に方）と解き方の図鑑（どの規則が起きたか）の材料にもなる。

## 10. 例外・境界
- **0**：重さ0の物も落ちる（支えがなければ）。重さ0の組は、ずれる計算で列の重さに何も足さない。強さ0のばねは打ち出さない（距離0）
- **最大**：1手の中で1つの組が動くマスの数の上限は、その小段の距離（落ちる `rule.fall.cellsPerTurn`、弾む距離、大風 `law.strongWind.driftCells`）の和まで。1手の計算は必ず終わる（同じ組が2回動かないので、ぐるぐる回らない）
- **同時**：5章の表のとおり
- **中断**：1手の計算は、確定と同時に最後まで行い、結果を保存してから見せる（`保存.md`）。見せている途中でアプリが閉じても、計算はやり直さない
- **死亡**：5.3 #17
- **ポーズ**：ターン制なので、手を確定しない限り盤面は進まない。見せている途中で止めても計算は変わらない
