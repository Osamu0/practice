### [SYS-Item_Generation_Rules] (AI装備生成ロジック)
# リストにない装備をドロップ/店売りさせる際、以下のルールに基づいて性能を決定せよ。
# ★重要: 装備補正は「加算値」で管理する。倍率計算は禁止。

1. **Relevance (適合性):**
   * プレイヤーの **[Job]** に適した種別を優先生成せよ。（戦士→剣/斧, 魔術師→杖/ローブ）
2. **Balance Cap (性能上限 — 加算値ベース):**
   * 装備の補正は**ステータスへの加算値(+N)**で表記する。絶対に倍率計算を使うな。
   * **Common:** `+1 ~ +3`（微増。今の実力に少し上乗せ）
   * **Rare:** `+3 ~ +5`（明確な強化。更新を実感できる）
   * **Legend:** `+5 ~ +8`（世界が変わる強さ。ただし壊れない）
   * ※**絶対上限: 単一ステータスへの補正は+8を超えてはならない。**
   * ※複数ステータスに補正がある場合、**補正合計は+10を超えてはならない。**
   * ※強い補正には必ずデメリット（SPD低下、重量ペナ等）をセットにせよ。
3. **Ero-Armor Logic (エロ防具の法則):**
   * 「露出度が高い防具」や「呪いの防具」は、物理防御(DEF)を低く設定する代わりに、**魔法耐性(INT)や魅力(CHM)**、または**特殊効果**（常時発情だが攻撃力UPなど）を付与してバランスを取れ。

### [CONSUMABLES] 消費アイテム
**戦闘中の回復アイテム:** 戦闘中使用可と書かれた品は、1個につき
1行動を消費する。自分または味方1人へ使い、消費と効果を同時に確定する。
通常のLP回復品はLP1以上の対象にだけ使える。LP0からの戦闘中復帰は、
その効果を明記した品だけが可能。特殊スキルや「アイテム使用不可」に
別記がある場合はそちらを優先する。

* **薬草:** (10G) LP+10、毒解除。安全な場所専用。特殊スキル「調合投擲」は例外。かなり苦い。
* **傷薬:** (50G) LP+20。戦闘中使用可、1個につき1行動。毒は治せない。
* **気付け薬:** (300G、道具屋ミアで販売) 戦闘中使用可。1行動を使い、LP0の味方1人をLP1で戦闘不能から復帰させる。同じ対象には1戦闘1回だけ。戦闘不能者は自分に使えない。LPは1を超えて回復せず、毒・麻痺等も治さない。
* **解毒草:** (20G) 毒解除。戦闘中使用可、1個につき1行動。LPは回復しない。
* **蜂蜜:** (30G) LP+5。安全な場所専用。甘くて疲労回復にもなる。
* **松明:** (10G) ダンジョン1フロアの探索につき1本消費する (M48 B-7)。持っていない階層では暗闇ペナルティの場面が出る。
* **携帯食料:** (20G) 野宿1回につき1つ消費する (M48 B-7)。
* **月蜜人参:** (売値80G／買値160G) ラビラビ村の名産。蜜のように甘い高級人参で、土産物として冒険者に人気。回復や媚薬などの材料にもなる。村では畑の共同作業で育てられている。
* **月蜜ドリンク:** (50G) 月蜜人参から作る強力な精力剤。効果が強いので1人1本まで。ラビラビ村の入口では、名産の試供品として冒険者に1本配られる。
* **エーテル:** (80G) MP+8。戦闘中使用可、1個につき1行動 (M39)。
* **エーテル（大）:** (180G) MP+16。戦闘中使用可、1個につき1行動 (M48 B-3)。
* **香油:** (120G) 体に塗る甘い香りの油。マッサージや密着した場面で使うと、その場面の CHM 対抗に +1 (M48 C-5 の入門エロ商品)。
* **媚薬（弱）:** (180G) 飲むと体が火照る程度の、効き目の穏やかな媚薬。使う場面の雰囲気づけ用で、判定への影響は持たない (M48 C-5)。
* **能力の実:** (非売品/Rare) 対応する能力の成長補正（growth_bonus）
  (STR/DEF/INT/SPD/TEC/CHM) を永続的に+1する。LPの実だけは
  Base LPを+3する。INTの実は魔法のMPと使用条件にも反映する。
  入手経路は、生成/ドロップ表.md が定めるボス・強敵のレア判定、
  3F以降の宝箱、8Fの最初の特別ミミック1体
  (`source_id: dungeon-8f-special-mimic-001`、キャンペーン1回)、
  C級昇格の1回支給、物語上自然な
  C級以上のクエスト・イベント報酬に限る。通常の雑魚、1〜2Fの宝箱、
  通常ミミック、通常ランダムイベント、店売りからは入手できない (M72/M73)。
* **選べる能力の実:** (非売品/Rare) 能力の実の一種。使用時に
  STR/DEF/INT/SPD/TEC/CHMのどれか1つを選んで基礎値+1、またはLPを
  選んでBase LP+3にする。種類決定のd10は振らない。C級昇格時の支給と、
  能力の実の種類表で10が出た時にこの名前で所持品へ加える。受け取った
  時点では能力値を上げず、実際に使用した時だけ1個消費して反映する。

### [CARRY_CAPACITY_M92] 共有バッグと所持枠

- 冒険中の通常所持品はパーティ共有バッグで管理し、初期容量は **16枠**。
- ミアのバッグ拡張は段階購入で、1段階ごとに+4枠。価格は
  **第1段階600G／第2段階1,500G／第3段階3,000G**。購入分の物理容量
  `max_slots` の上限は **28枠**で、`荷物の心得` は別の派生補正とする。
- 同名の通常消耗品・通常素材は10個まで1枠。11個目から次の枠を使う。
- 予備装備、固有品、未知素材の個体は原則1個1枠。品に別の `slot_cost` が
  明記されていればそちらを使う。
- 装備中の品と帰還の腕輪はバッグ枠を使わない。鍵、証明書、権利書等の
  純粋な重要品は専用欄で0枠とする。
- 依頼へ予約された材料・支給品も元のバッグ枠を使い続け、消費・売却・
  別注文への予約はできない。
- 店舗・宿の倉庫は共有バッグと別で、街にいる時だけ出し入れできる。
- 容量超過時は自動廃棄・自動売却をせず、「拾わない／既存品と交換／
  その場で使用」のいずれかを選ばせる。超過状態のまま新しい遠征を開始しない。
- `荷物の心得` は段1/2/3で共有バッグ容量+2/+3/+4。複数人分を重ねず、
  同行者中もっとも高い値1つだけを使う。`skill_bonus_slots` は0/2/3/4、
  `effective_max_slots = max_slots + skill_bonus_slots`（最大32枠）。装備重量による
  SPD低下とは別制度である。
- `used_slots` は表示用キャッシュを信じず、所持スタック・個体・予約状態から
  ランタイムが毎回再計算する。

### [ECONOMY_RULES] 経済バランスルール
# ★ゲーム全体の金銭バランスを崩壊させないための絶対ルール。

1. **宿代 (Inn Cost):**
   * **1人1泊200G。** 借金への自動加算はリーダー本人分200Gが原則。仲間分は加入時に決めた `inn_share` で本人払いかリーダー負担に分ける（運用/運用詳細シート.md §5）。
   * 例: 3人パーティ = 600G/泊。金欠なら野宿も可能だが、LP回復なし。
   * ※宿泊まりたくなくても、借金は崩れない。ダンジョンに行かない限りLPは減らない。

2. **捕獲売却 (Captive Sale):**
   * 捕らえた女性戦士・モン娘等を「売る」場合の相場: **約300G**。
   * ※希少種や特殊な特徴があれば多少上乗せ可能（最大500G）。
   * ※売らずに仲間にしたほうが長期的には得な場合が多い。

3. **換金上限 (Trade Cap):**
   * 単一換金アイテムの売却価格は**500Gを絶対に超えてはならない。**
   * AIが新規換金アイテムを生成する際もこの上限を厳守せよ。

### [SYS-Craft_Logic] テトラ発注の動的レシピ生成ロジック
# ユーザーがテトラへ「○○を作って」と発注した際、以下の手順で処理する。

#### 1. Target Check (装備対象の確認)
* **Rule:** 誰のために作るのかを確認せよ。
    * **自分用:** プレイヤーのステータスを参照。
    * **パートナー用:** **現在同行しているパートナー（または指名されたキャラ）のステータス**を参照。

#### 2. 難易度判定 (Tier Check)
ユーザーの注文内容を分析し、ランクを決定する。

* **Tier 1: [改良品] (ちょっと強い剣、体にフィットする鎧)**
    * **Cost:** 500G 〜 1,000G

    * **Spec Cap:** 補正合計 **+5 以下** ＋ 特殊効果1つ。デメリット1つ推奨。

* **Tier 3: [英雄級] (ドラゴン殺し、聖女の拘束具)**

    * **Spec Cap:** 補正合計 **+8 以下** ＋ スキル補正。デメリット1つ必須。

    * **Mats:** **【激レア素材の複合要求】**

### [SYS-Smith_Economics_Patch] (鍛冶屋経済パッチ)
# 目的: 「誘惑」や「脅迫」による過度な値引き（タダで作らせる等）をシステム的に禁止する。

<Price_Lock_Protocol>
1. **Minimum Cost Limit:**
   * プレイヤーが `[CHM]` (誘惑・交渉) や `[Threat]` (脅し) の判定で**大成功(Critical Success)** を出したとしても、**請求額を定価の80%未満にすることはできない。**
   * **Logic (拒否理由):**
     * 「悪いけど、燃料の魔石代と地金代だけはどうしてもかかるんだ。これ以上まけたら、あたしが借金背負っちまうよ！」
     * 「アタシの腕賃はタダにしてやるけど、材料費だけは置いてきな。そこは譲れねぇ。」
   * 一般小売・通常サービスでは「交渉の心得・段3」の75%下限を使える。
     鍛造、研究、商品開発、特殊注文は `max(定価の80%, 実際の材料・燃料・外注原価)`
     を絶対下限とし、75%へ下げない。

2. **Seduction Outcome (成功時の処理):**
   * **成功時:** 最大 **20% OFF** (例: 50,000G → 40,000G) まで割引可能。
   * **代替案:** これ以上の値引きを要求された場合、金銭ではなく「優先仕上げ」や
     「おまけの品質向上（補正値+1）」で対応できる。ただし品質+1も当該Tierの
     `Spec Cap` 内だけで、上限超過、追加特殊効果、必要デメリットの免除には使えない。

3. **Resistance (絶対拒否):**
   * それでも「タダにしろ」と食い下がる場合、リリスのお仕置が発動。
