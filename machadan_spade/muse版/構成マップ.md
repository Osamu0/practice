# マチャダン スペード Muse版 — 現行構成マップ

旧構成との対応表ではなく、配布後に Muse が実際に使う本番構成を示します。
過去の置き場所を実行時ルートとして参照してはいけません。

## 制御層

| ファイル | 役割 | 正本性 |
|---|---|---|
| `運用/正本レジストリ.yaml` | 分野→正本・補助・廃止資料の対応、再照合手順 | 正本 |
| `運用/決定台帳.yaml` | 現在有効な主要決定と置換関係 | 正本 |
| `運用/ルーティング表.yaml` | 場面→必須・条件付き資料の機械可読ルート | 正本 |
| `運用/ルーティング表.md` | ルーティングの人間向け表示 | 生成ビュー |
| `ナレッジ索引.md` | 現行配布ファイルの役割一覧 | 生成ビュー |
| `tools/anchors.json` | 明示ID・見出し・ハッシュから作る節索引 | 生成キャッシュ |

## ナレッジ層

| フォルダ | 主な内容 | 読み方 |
|---|---|---|
| `運用/` | 常時規則、数値、戦闘、判定、魔法、スキル、クエスト、店舗・商品開発 | 場面パックが指定した資料を読む |
| `文章/` | 文体カード、語彙辞書、女×女の作法 | 該当文体の時だけ読む |
| `世界/` | 世界・施設・階層・アイテム・依頼 | 対象施設・対象カテゴリの節を読む |
| `生成/` | 遭遇、敵、モブ、ドロップ、捕獲 | 生成・戦闘・報酬時に読む |
| `人格/` | キャラクターごとの設定と声 | 登場キャラは原則ファイル全文を読む |
| `チェキュン/` | テキストプロンプト手順とプリセット | 専用パックでのみ読む |

町・村・建物の物理構造は`世界/舞台構造.json`に一本化する。
`世界/Locations.md`は施設の既存機能・利用条件、`世界/舞台資料集.md`は構造正本の人間向け表示。
通常のcontextには、対象施設の部屋と接続を省略せず、親の町・村は短い街路案内だけ添える。
全施設分を毎回読まず、構造を知ることと発見・立入・移動の成立を区別する。

地方の生活・統治・交易・暦・葬送は`世界/地方世界設定.json`に置き、
`世界/地方世界資料集.md`を人間向けに生成する。通常は日付と対象都市の短い案内だけを読み、
移動、商談、政治、文化、葬送を扱う時にテーマを指定して該当節を追加する。

## 状態層

| パス | 内容 | 配布更新時 |
|---|---|---|
| `saves/*.yaml` | キャンペーンの唯一の可変正本 | 保持・移行。置換禁止 |
| `saves/_history/` | コミット済みセーブの世代 | 保持 |
| `state/inventory/` | モブ・イベント等の可変在庫 | 保持。存在しなければ初期化 |
| `state/locks/` | 同時書込防止 | 実行時生成。配布しない |

現在、旧在庫ファイルが本番資料内に残る場合でも、移行後の可変正本は
`state/inventory/` 側です。本番資料は規則と初期データとして扱います。

## ツール層

| ツール | 責務 |
|---|---|
| `tools/machadan_runtime.py prepare-context` | 場面ルートから一時コンテキストを構成し、参照元とハッシュを付ける |
| `tools/check_knowledge.py` | 参照、正本、索引、スキーマ、禁止混入を検証・安全な範囲だけ修復する |
| `tools/extract_anchors.py` | 安定した節IDを抽出し `anchors.json` を再生成する |
| `tools/machadan_runtime.py` | セーブv3検証、世代バックアップ、原子的コミット、旧セーブ移行、可変在庫、読取専用ステータス表示を扱う |
| `tools/status_dashboard_template.html` | MUSEでLP/MPを常時表示し、能力・装備・状態・所持品をタップ展開する読取専用HUD |
| `tools/combat_balance_probe.py` | 敵と人数別構成の極端な即死・無傷帯を再現可能に検出する診断モデル |
| `tools/dice.py` | 固定テープから出目を取得する |

実際の同梱ツール名は `ナレッジ索引.md` と配布マニフェストを正とします。
存在しないツールを推測で呼びません。

## 変更時の原則

- 同じ確定値を複数の正本へ手入力しない。
- 補助資料が値を再掲する場合は、正本IDと改訂番号を併記する。
- 可変状態をナレッジMarkdownへ書き戻さない。
- 索引類は手で直さず、正本から再生成する。
- 検証が一件でも失敗した配布物は有効化しない。
