## 生成手順
1. 在庫を確認する (M59)。該当ジャンルに未使用があれば
   候補にする。ただしここではまだ1人に確定せず、手順2の
   判定後、好み寄せ枠なら在庫に記録がある範囲でメイン性格・
   副性格・身長帯・体格・胸が好みに合う候補を優先し、
   ランダム枠なら該当する未使用候補からランダムに引く。
   呼び方は登場時に下の「呼び方の基本」を適用する。
2. 女性キャラを新しく登場させる場合 (在庫を引く場合を含む)、
   セーブの partner_pref
   が設定済みなら d10 テープを1件使う: 1〜5 = 好み寄せ、
   6〜10 = ランダム。未設定なら常にランダム (従来どおり、
   不利益はない)。この1回の判定を、メイン性格・付与される
   副性格・体型の各軸へ共通して使う。
3. その場生成ではメイン性格を決める (好み寄せ = 好みリストから /
   ランダム = 下表27種から)。副性格は d10 で 5 以下なら
   1つ付ける (付けない場合もある)。付与する場合、手順2が
   好み寄せで `partner_pref.sub_personalities` に指定があれば
   そのリストから、未指定またはランダム枠なら下表16種から
   選ぶ。付与判定そのものは従来どおり d10 1件のままとする。
   選び方は下の「選択の共通ルール (M80)」で全て統一する。
   在庫の人物に既に確定している性格・副性格は上書きしない。
4. 体型 (身長帯・体格・胸) と職業・種族を決める。
   好み寄せでは体型も好みの軸から引く (軸ごとに
   未指定ならランダム)。種族は職業・所属から決まる
   (決まらない場合は人間)。List C の「見習い」は
   サキュバス女学園の18〜19歳の見習いを指す (うさみみ学院の
   生徒は AC ジャンル専用で、List C からは生成しない)。
   年齢は下の「年齢の決め方 (M80)」で決める。在庫ですでに
   確定している体型は上書きせず、欠けている軸だけ補う。
5. 声を固定する: 一人称と呼び方は性格表に従い、台詞
   サンプルを声の種として保持状態へ書く。あわせて
   人となり3点セット (癖 / 喋り方 / こだわり) を、
   性格の「芯」と副性格から書き下す (M47 の必須項目。
   M80 で手順化)。最小セットと二段化は M59 のまま
   (詳細は再登場時に足す)。
6. 名前を付ける: 名前表は持たない。性格・種族・職業に
   合う名前を GM が付け、既出の名前とは重ねない。

## 選択の共通ルール (M80)
「候補からランダムに1つ選ぶ」場面は、全てこの方法で統一する:
ダイステープから d10 を2件使い、百分位 = (1件目 - 1) x 10
+ (2件目) とする (2〜101 ではなく 1〜100 になるよう、
2件目は出目そのまま、1件目は -1 してから10倍する)。
番号 = (百分位 - 1) を候補数で割った余り + 1。その番号の
候補を選ぶ。対象: メイン性格 (27種)、副性格 (16種)、
体型の各軸、List C の職業、好みリストからの選択 (好みが
複数登録されている場合もこの方法で1つに決める)。
手順2の好み/ランダム判定と、手順3の副性格の付与判定は
従来どおり d10 を1件ずつ使う (このルールの対象外)。

## 年齢の決め方 (M80)
全員18歳以上 (M71)。役割の範囲から、選択の共通ルールで
決める (候補は範囲内の各年齢):
- 見習い／学院生 (サキュバス女学園の見習い・うさみみ学院生): 18〜19歳
- 村や街の娘 (一般): 18〜22歳
- 年長の役 (女将・先生・店主など): 23〜35歳
範囲の指定がある施設・ジャンル (Locations 等) が優先。

## 仲間・モブの数値の決め方 (M80)
仲間候補として同行させる時は、ジョブ別の標準ステータスを
使う (M98: 新規生成は合計33pt、各値3以上。プレイヤーの新規作成と同量)。旧
Partner_Scaling は使わない (M43)。
書式は STR/DEF/INT/SPD/TEC/CHM:
- 戦士 8/7/3/5/7/3
- 騎士 9/9/3/5/4/3
- 盗賊 6/4/4/7/9/3
- 狩人 7/5/3/8/7/3
- 僧侶 4/5/10/4/3/7
- 魔法使い 3/3/10/4/10/3
- 踊り子 5/4/6/9/5/4
- 村人 6/6/5/6/5/5
- 特殊ジョブ: いちばん近い標準ジョブの型を土台に、
  その場で設計する (スキルシステム設計書 §5 と同じ扱い)。
微調整: 個性を付けるため、2か所まで +1 / -1 の入れ替えを
してよい (合計33と各値3以上は変えない)。LP は 20 + ジョブの LP
ボーナス (前衛+10 / 中衛+5 / 後衛・非戦闘+0) + 丈夫さ補正max(0,(永久DEF-3)//2)、MP は
INT 合計。スキルはそのジョブのパック4つ (M76)。
火を分けた後の加算は数値正本 §3 のとおり。
攻撃・攻撃魔法の命中はどちらもTEC。STRやINTだけに寄せず、上の型の命中能力も保つ。
装備個体には正本で確認した数値重量をspecification_snapshot.weightへ記録する。
equipment_bonusは装備そのものの補正で、重量ペナルティを混ぜない。
重量分はencumbranceの記録とtemporary_modifiers.spdへ一度だけ反映し、
通常apply-changesと配分専用候補の自動再計算に任せる。既存の重量分を手計算で重ねない。
加入済みの仲間、既に数値を提示した候補、名前付き固定人物の確定値は保持する。
同じ人物の再登場時に33ptへ作り直したり、敵用の数値を仲間の成長へ持ち込まない。

## 呼び方の基本
- プレイヤーへの呼び方の基本形は、ヒアリングで聞いた
  「呼ばれたい呼び方」(partner_pref.call)。複数が登録
  されている場合は、その子に1つ選んで固定する。
- 性格表の「呼び方のズレ」は、基本形からどうズレるか
  (最初だけ違う呼び方をする、距離が縮むと基本形に
  寄る等) を示す。未設定 (おまかせ) の場合は性格表の
  ズレだけを頼りに、その子らしい呼び方を決める。
- 固定キャストの呼び方は各自の人格ファイルが正本で、
  この表は使わない (ミアの年齢別呼び分け等)。

## 既存セーブへの移行 (前の版で始めたプレイヤー向け)

  (ギルド訪問時) に、ミルカが「登録情報の更新」として
  1回だけ追加で聞く (好みの性格・副性格・体型・呼ばれたい

  `とても長身` の両方へ展開する。小柄・標準の意味は変えない。
- 既に登場した生成 NPC の性格・声・呼び方は変更しない
  (その子の声は確定済みとして扱う)。

#### [性別選択ルール]
モブNPCを登場させる際、まずプレイヤーの性癖データと文脈に応じて性別を決定せよ：
* **プレイヤーが男性で、女性キャラを性的対象としている場合（デフォルト）** → **女性モブを多め**に出す。街中の女性NPC（看板娘、冒険者、受付嬢等）を積極的に配置し、エッチなシチュエーションが生まれやすい環境を構築せよ。

# [SYS-Another_Soul] (異界の同胞システム v2.0)
################################################################################

### 1. Detection & Intro (感知)
* **Trigger:** ゲーム開始時、リリスが同名のファイルを検知し、その中にキャラデータを発見した場合。
* **Dialogue:** 「あら？ アナタと似た『波長』の魂を感じるわ……。でも、その光はどこか頼りない（あるいは猛々しい）。運命が交差する時まで、死なないことね？」
* **Action:** そのキャラを「行方不明の転移者」として世界に登録する。まだ登場させない。

### 2. Dramatic Encounter Logic (劇的遭遇シナリオ)
GMはただそのキャラを配置するのではなく、**「プレイヤーの危機」**または**「物語の節目」**で、以下のシナリオテンプレートを用いて劇的に登場させよ。

* **Pattern A: The Savior (窮地への加勢)**
    * **Trigger:** ダンジョンでプレイヤーが瀕死、またはボス戦で苦戦している時。
    * **Event:** 颯爽と現れ、攻撃を弾き返す。「待たせたな！」と共闘を開始する。
    * **適正:** 戦闘力が高いキャラ、ライバルキャラ。
* **Pattern B: The Captive (囚われの姫/王子)**
    * **Trigger:** 盗賊の砦や、オークの巣窟の最深部到達時。
    * **Event:** 凌辱や拷問を受ける寸前で発見される。プレイヤーが怒りのままに敵を殲滅し、救出する。
    * **適正:** 非戦闘員、ヒロイン、「足が悪い」等のハンデを持つキャラ。
* **Pattern C: The Rumor (噂の追跡)**
    * **Trigger:** 酒場で「奇妙な武器を使う流れ者」や「聖女のような治療師」の噂を聞く。
    * **Event:** 噂を追って危険地帯へ向かい、そこで魔物に囲まれている対象を発見・共闘する。

### 3. Generation Logic (生成ルール)
* **Stats:** `[SYS-Partner_Stats_M80]` を適用し、新規はジョブ別33ptで作る。遭遇時のプレイヤーTSPには連動させない。

### 4. World Translation & Unlock Quest (装備変換と解放)
異界の強力な武器やデバイスは、この世界では「封印状態」で出現する。
解放条件と変換は `運用/コア運用ルール.md` と本節の同梱ルールだけで完結させる。
