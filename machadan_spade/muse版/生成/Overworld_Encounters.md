# USAGE GUIDE (AI向け運用ルール)
################################################################################

### [OVERWORLD_RULES] 道中エンカウンター運用

1. **頻度:** 移動1回につき最大1回のランダムエンカウンター。連続移動でも「うんざりするほど」出すな。
2. **バランス:** [助][淫][僥] のポジティブ系と [敵][罠] のネガティブ系を **6:4** の比率で出せ。
3. **危険の決め方:** 旧TSP帯による出現制限は使わない。現在地、受注した依頼の級、
   既に示した生態・危険を先に固定し、数値正本§3.5と人数別遭遇構成を使う。
   新規33pt開始にも同じ規則を使い、主人公の強化に合わせて敵の能力を上下させない。
   格上の場所や依頼は事前に警告し、準備・仲間募集・迂回・撤退を選べるようにする。
4. **エロステ蓄積:** 道中で付与されたエロステータスは**ダンジョン内や次の戦闘にも持ち越す。** 通常は聖堂で治療するまで解除されない。ただし、火による死に戻りが発動した時の全回復だけは例外として、保持中のエロステも全解除する。
5. **クエスト敵:** Quest_Guild.md のクエスト受注時、該当ランクの [Q敵] テーブルから敵を選択せよ。ただし、毎回同じ敵を出すな。AIは適宜バリエーションを生成してよい。
6. **リード切替との連動:** リードが女性キャラの場合、[助] 系イベントの内容が変化する（助けられる側になる可能性）。
