# ドロップ表 (M41 確定)

どのモンスターが何を落とすかの正本。素材の価格と用途は
世界/Item_Database.md の [MATERIALS] を参照。

## 一般則
- 戦闘に勝利した時、敵ごとに主ドロップを判定する。
  雑魚・強敵は d10 で 5以下なら 1個。ボスは確定で 1個
  (希少素材の枠)。複数体で出現した場合は1体ごとに判定。
- 人間型の敵 (駆け出しの女冒険者、女傭兵、猫獣人の女盗賊)
  は素材でなく金品を落とす: 1d6 x 10G。
- 宝箱の通常素材と中身の階層制限は `世界/Dungeon_Data.md` の
  `[Rogue Loot System]` が正。能力の実を含む時の二次表と固定テープの
  消費順は、下の「能力の実の供給」で同じ内容を明記する。

## 能力の実の供給 (M72/M73)

### ボス・強敵のレア判定
- 主ドロップとは別枠で、**同じ個体につき1回だけ**判定する。判定した
  `source_id` と成功・外れの双方をセーブの
  `world_state.growth_state.resolutions` へ追記し、同じ個体を振り直さない。
- **ボス (M108):** 各階のボスを安定キー `boss-f1`〜`boss-f9` で追跡する。その入手元から一度実を得るまではd10で8以上（30%）、獲得後は9以上（20%）で能力の実×1。新規resolutionに `rule_version: 2, source_key: boss-f<階>` を保存し、復活後も初回扱いへ戻さない。対象は次の9体だけ。
  1F はぐれ狼／2F 沼蛇の女王／3F スライムクイーン／4F オーク族長／
  5F キラービー・クイーン／6F 蜘蛛女アラクネ／7F ミノタウロスの長／
  8F エルダーリッチ／9F サキュバスクイーン。
- **強敵:** d10 で10なら能力の実×1 (10%)。対象は次の5体だけ。
  4F 女傭兵／7F 闇の騎士／7F オーガ・バーサーカー／
  7F 堕ちた女聖騎士／7F アイアンゴーレム。
- `[Unique]`、`[Rare]`、`[MOB_GIRL]`、深層の敵、奇襲持ちというだけでは
  強敵扱いにしない。上の一覧にない敵と雑魚には、このレア判定を行わない。
- **ボス天井:** 初獲得前の抽選だけを対象に、3回連続外れたら次の対象抽選はレア判定d10を消費せず実×1を確定し、種類d10だけを使う。成功後は外れ数を0へ戻す。獲得済み入手元の20%再取得抽選は天井を使わず、初獲得前の外れ数を増減しない。強敵・宝箱等も増減しない。
- ボスは一度ダンジョンから出ると新潜行で復活する。同じ潜行中に再戦せず、撃破済み階では自分から向かわなければ遭遇しない。新個体への置換や関係の初期化はしない。
- ボスの戦利品は `dungeon_memory` の日別・階別 `boss-loot` で一日一回。取得済みの同日に再撃破しても実の追加判定は行わない。翌日以降の新潜行で補充。滞在したままの日またぎでは補充しない。
- 既存の旧resolutionは履歴として保持し、新規ボス判定にだけM108を適用する。最後の撃破と結び付く旧獲得記録は移行時に安定入手元へ引き継ぐ。特定できない古い記録を推測で他の階へ割り当てない。

### 宝箱
- 宝箱1個につき中身の結果は1つだけ。まず固定テープから階層判定のd6を
  1件消費し、RARE/JACKPOTになった時だけ二次表のd10を1件消費する。
- **1〜2F:** 能力の実は出ない。d6の5〜6もCOMMON上位へ差し替える。
- **3〜4F:** d6の5〜6をRAREとして扱い、二次d10で
  1〜2=能力の実×1／3〜4=換金アイテム／5〜7=少し良い装備／
  8〜10=回復セット。
- **5F以降:** d6の5は上と同じRARE表。d6の6はJACKPOT表とし、
  二次d10で1〜2=能力の実×2／3〜10=強力な魔導具。どちらの結果でも
  JACKPOTの敵遭遇率上昇ペナルティは適用する。
- 宝箱から能力の実が出る確率は3〜4Fで1箱あたり約6.7% (期待0.067個)、
  5F以降も出現率は約6.7% (×2枠を含む期待0.10個)。RARE/JACKPOTを
  引くだけで能力の実が確定する旧解釈は使わない。
- キャンペーン最初の8Fミミック1体だけを特別個体とし、固定
  `source_id: dungeon-8f-special-mimic-001` を使う。この同一個体の
  初回撃破時だけ、能力の実×2を宝箱二次表・ボス/強敵判定とは別枠で
  確定し、付与と同じコミットでresolutionを1件記録する。既に同source_idが
  記録済みなら再付与しない。逃走等で未決着なら同じ特別個体として扱い、
  解決後に現れる通常ミミックは能力の実なし。ミミックに追加レア判定は行わない。

### 種類の決定
- 能力の実が実際に出た個数ぶん、固定テープからd10を1件ずつ消費する:
  1〜2 STR / 3〜4 DEF / 5 SPD / 6 TEC / 7 CHM / 8 INT / 9 LP /
  10 `選べる能力の実`。×2なら2件を独立に引き、各1個の種類を決める。
- 消費順は、宝箱なら **階層d6 → 必要時の二次d10 → 個数ぶんの種類d10**、
  通常のボス・強敵なら **レア判定d10 → 成功時だけ種類d10**。ボス天井の
  確定時はレア判定d10を飛ばし、種類d10だけを消費する。C級昇格で支給する
  `選べる能力の実` は種類が指定済みなのでダイスを消費しない。

## 素材側から見た入手経路の確認
- ネズミの毛皮: ダンジョンのネズミ系イベントと宝箱のみ
  (戦闘ドロップには対応する敵がいない。安価な素材として
  店で買える: 売値5G の2倍 = 10G)。
- 獣肉/オークの肉: オーク兵とオーク族長から副次ドロップ
  (主ドロップ判定に失敗した場合、その半分の確率で肉)。
- 全ての希少素材にボス確定枠がある (製作の詰み防止)。
