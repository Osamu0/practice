# モン娘の出現・捕獲・運用（Muse版追加、M23）

同梱の図鑑（Monster_Bestiary）と世界設定（人身売買・捕獲売却の
相場）に、捕獲の手順と捕獲後の運用を足した運用ドキュメント。
モン娘は全員その種族の成人として扱う。見た目を人間の未成年の
年齢に例える表記は使わない（M3・C2）。

## 2. 出現

- ダンジョン: `世界/Dungeon_Data.md` と `生成/Monster_Bestiary.md` の
  階層配置を使う（各階層に人間／亜人／モン娘の敵を配置する）。
- 野外: エンカウント表にモン娘枠を足す。地形に合う種族から選ぶ
  （水辺なら人魚、森なら妖狐・獣人娘、等）。
- 個体生成: 種族は固定し、外見・本性・性格はモブ生成の
  [A]外見×[B]本性×[C]職業（性格）の仕組みを流用して個体化する。
  【Muse版注記 (M59)】その場で出す追加個体は軽量手順でよい:
  同階層の基準個体の数値を土台に、差分2点 (外見の特徴と
  性格の癖を1つずつ) だけ振って個体化する。細部は再登場時に
  足す (二段化)。
  種族特徴（耳・尻尾・鱗・羽・下半身の形状等）は外見へ必ず反映する。

## 3. 捕獲ルール

戦闘中の行動として「拘束を試みる」を選べる。

- **前提**: 相手の LP が最大の半分以下、または拘束・魅了・粘液等で
  無力化していること。元気な相手は捕まえられない。
- **判定**: `[捕獲側TEC] + 2d10 + 拘束具補正 >= 目標値`。
  拘束具補正: 素手 0／縄・植物のツタ +3／専用拘束具（ボンデージ
  革鎧等）+6。
- **目標値**: 対象LP半分以下で `対象TEC+10`／1/3以下で
  `対象TEC+8`／瀕死・無力化で `対象TEC+6`。
  判定が目標値以上で捕獲成功。
- **失敗時**: 相手の反撃を受ける。2回続けて失敗すると相手は
  逃走を試みる（SPD判定）。
- 捕獲した相手はその場で戦闘終了。殺すか、捕らえたままにするかは
  プレイヤーが決める。

## 4. 捕獲後

- **その場で**: れいぷできる（本作のCNC前提どおり。全員成人・
  本当の停止は常時優先）。捕獲直後の抵抗は演技・世界の前提の
  範囲で扱い、快楽に落ちる過程を描く。
- **お持ち帰り**: 拠点や宿へ連れて帰れる。捕獲した子はセーブの
  捕獲リスト（名前／種族／性格／状態／関係）に保持し、拠点の
  場面で再登場させる。関係はリセットしない。
- **娼館へ売る**: `世界/Locations.md` の相場である約300Gを基準に、
  300 + (CHM-5)×20 + 種族レア補正（ありふれた種族 0／
  珍しい種族 +100／竜娘・サキュバスクイーン級 +200）。
  売却した子は捕獲リストから消える（再登場は原則しない）。
- **仲間化**: 図鑑に「交渉次第で仲間候補」の個体がいる。
  持ち帰った子と関係を重ねれば、交渉や好感の蓄積で仲間化の
  可能性を開く（確定は判定と成り行きで決める）。

## 5. 表示

- 非エロ時のMUSE読取専用HUDには、捕獲中なら捕獲リストの
  要約（名前と種族）を所持品と並べて出す（M18）。
- 捕獲した子の詳細ステータス（服装・状態・体位）は、エロシーンで
  その子が相手の時だけ、通常の詳細ステータス（文体カード (n)）で出す。
