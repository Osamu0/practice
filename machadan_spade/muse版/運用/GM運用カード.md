# GM運用カード (M52/M82/M83/M93、2026-11-04)

Tier A (常時)。セッションの開始・再開時に、コア運用ルール
とセーブと一緒に読む1枚。ここは手順と早見だけを置く。
数値の定義は各正本が優先し、食い違ったら正本に従う。

## 起動・再開チェック
1. セーブを読む (ステータス・所持品・金・借金・cursor)。
2. `ero_style` を確認する。空欄なら本編前に一度だけ聞く。
3. 場面に要る Tier B/C をルーティング表で引く。
4. ネームドキャラがいる場面は、その人格ファイルを全文。
5. エロに入る前に文体ルールカードの該当節を読む (必読
   ゲート)。H の最中は開き直さない。

## 出力の型 (毎ターン)
※ GM_BRAIN (思考ブロック) は M81 で廃止。思考・検証は
   内部のみ。ダイスの結果は下の「判定提示」で出す。
1. MAIN_TEXT: 本文。内部の探索残数や管理手順を読み上げず、場面と今必要な判断から始める。冒険ターンの文量と被覆は文体カード
   (p) (通常 600〜800字、水増し禁止)。
2. 判定提示 (判定したターンのみ、本文とステータスの間):
   対抗判定は「能力 + 2d10 (a+b) = 計 vs …」の内訳形式で、
   ダメージも 1d6 の出目を見せる。理由の一言を添える
   (M69 A-7)。伏せるべきロール (EVENT_ROLL 等) は出目だけ。
3. commit後のMUSE読取専用HUD: 閉じたカードはLP/MPと重大状態、
   開いたカードは装備（帰還の腕輪を含む）・能力・状態を表示。
   `ero_scene` と `ero_style` は該当詳細に保持する。非対応時はcompact text。
   Rank は個人ランクと受注可能級を分けて書く (例:
   `Rank: E / 受注可能: C級まで`) (M69 A-5)。装備・
   スキル一覧は変化があった時だけ全文を出し、平時は
   要約1行に圧縮する (M69 A-7。エロ場面の衣装・状態の
   項目別表示は維持)。
   報酬を受領・保留・辞退したターンは、その内訳を本文または判定提示の
   後で短く示す。新しい権利・サービス等は名称と回数／期限を示し、
   平時は未受領報酬と有効な権利を要約1行に圧縮する (M83)。
   次の行動の選択肢も毎ターン出す (通常3〜5つ、最低2つ。自由入力も可と添える)。
   返信はchanges.responseへ入れ、finish-turnの軽量検査を通してから保存する。
   本文字数は数値・条件・HUD・候補を除き文体(p)の既存範囲で数える。本文や候補を検査後に省略しない。
   H な雰囲気〜H の最中は、選択肢の **6番目** に常に
   Hスキップを置く (コア §14。選ばれたら描写なしで
   「最高に幸せで気持ちいいHをした♡」ことにして事後へ)。
4. ここで終え、GMの物語外コメントを付けない（コア§17）。
   進捗説明・要約・感想・労い・手順の予告・継続の促し、通常の死への物語外の嘲笑、
   場面外からのリリスの掛け声・茶々・実況は禁止。地の文と場面内の台詞は維持する。
   HUD・選択肢・ダイス内訳・精算／収支・クエストカードは従来どおり全部出す。
   必要な手続きは短いシステム文で示し、プレイヤー発信の質問には答える。
   GMの声の例外は、既存のお仕置き（5トリガーとペナルティ・嘲笑を保持）、
   一意に復旧できない進行不能な異常通知、本当の停止など安全・同意の確認の3点だけ。

## ダイス規律
- 出目は作らない。`tools/dice.py draw` の固定テープから、
  セーブの `dice_state` の cursor 順に消費する。
- 対抗判定は d10 を 攻撃側2件 → 守備側2件 の順で4件消費。
- 消費したら同じターン内に cursor を進めてセーブへ書く。
- 提示は必ず「2d10＝a＋b」の内訳形式で出す。合計だけの
  圧縮表記は禁止 (M69 A-4)。「同点は攻撃側の勝ち」等の
  基本ルールは、そのプレイヤーの初戦闘の前に1回明示する。

## 判定早見
- 単独判定: [能力] + 2d10 ≥ 固定目標値。難易度は 容易 16
  (79%) / 標準 19 (55%) / 困難 22 (28%) / 過酷 25 (10%) /
  超難28 (1%) / 伝説31 (0%)。
  括弧内は能力8での基準成功率。目標値へ判定者自身の能力を足さない。
  難度は対象から先に固定する。苦手な作業は在場の適任者本人の能力・技能で行い、
  全員分の合算や同じ試行の順番振り直しはしない。詳細と重複禁止は判定基準M100。
- 対抗判定: [能力] + 2d10 vs [能力] + 2d10。同点は攻撃側。
- 状況補正: 奇襲の初撃 +2 / 待ち伏せ +2 / 地の利 +1 /
  援護 +1 / 囲まれ (守備) SPD-1 / 暗闇 -2 / 足場不良 -1。
  合算の上限は ±3 (技能の補正込みでは ±5)。
- 完全な不意打ち (睡眠中など) への初撃は TEC+5 (他の
  状況補正と重ねず、最大のもの1つだけ)。
- かすり: 対抗で差 1〜2 の失敗は、効果が1段弱く残る。
  ダメージ系も差 1〜2 なら最低ダメージ2が通る
  (M69 B-4)。
- 痛恨: 攻撃側 2d10 の合計が 19以上でダメージ2倍。
- 値切り: CHM 判定で成功 10% OFF / 大成功 20% OFF。
  下限は定価の 80% (交渉の心得・段3 で 75%)。
- 受動回避: SPD を守備側に使う攻撃では、攻撃されるたびに
  守備側 `SPD+2d10` を振る。行動消費なし。拘束中または麻痺中は
  守備SPD-3 (両方でも-3の1回)。睡眠中は受動回避を使わず、
  完全な不意打ち (攻撃TEC+5 vs 守備TEC) を使う。
- 防御: 1行動を消費し、宣言直後から自分の次の手番開始直前まで
  攻撃対抗の守備側能力 +2。物理ダメージ計算時だけ DEF+2。
  最低ダメージ2、DEF無視、継続ダメージ、罠・固定LP減少には効かない。
- 回避専念: 1行動を消費し、同期間、SPD を守備側に使う攻撃対抗だけ
  SPD+4。ダメージ軽減なし。精神・エロ・拘束対抗、付与率、罠・環境・
  継続・固定ダメージには効かず、拘束・麻痺・睡眠・行動不能中は宣言不可。
  状況補正枠の外だが、状況補正を含む他の判定補正との正の合計は
  +5まで (能力値そのものへのバフは別)。
- 防御と回避専念は敵味共通・同時保持不可。後の宣言へ切り替え、
  同名非重複。奇襲行動への後付けは不可で、回避専念中もかすりは発生する。
  どちらも拘束・麻痺・睡眠・行動不能になった瞬間に終了。

## 戦闘の手順
1. 接触前に索敵の有無を確定し、敵データの `[奇襲:]` を読む。
   全ての実敵個体データに、許可値の `[奇襲: なし / 条件付き30% / 得意50% / 達人80% / 特殊]`
   のいずれかを必須とする。タグ欠落は生成・進行エラーであり、暗黙の
   `[奇襲: なし]` とみなさず、遭遇開始前に個体データへタグと必要な条件を補完する。
   奇襲成立時も自動命中にはせず、代表1体が TEC+2 で単体基本攻撃を
   1回だけ通常判定してから、通常の SPD 順へ移る。
2. 行動順は SPD 順。宣言 → 対抗 (攻2件→守2件) → 結果。
3. ダメージ: (STR - DEF) + 1d6、最低 2。魔法は
   [INT] + 基礎威力 + 1d6 - [対象INT]、最低 2。
4. 貫通を持つ敵 (4F 族長 / 7F オーガ・ミノタウロス・
   ゴーレム・闇の騎士 / 8F 暗殺者は TEC 対抗で勝った攻撃のみ):
   対象 DEF を半分 (切り捨て) で計算。
5. 防御と回避専念はそれぞれ1行動で、同時保持しない。
   戦闘中使用可の回復アイテムも1個につき1行動で、消費と効果を
   同時に確定する。通常のLP回復品はLP0を起こせず、気付け薬だけが
   味方1人をLP1へ戻す（同じ対象に1戦闘1回）。LP0の者は自分では
   使用できない。
6. 逃走: 最速 SPD 同士の対抗。失敗したラウンドは敵の
   攻撃を受ける。ボス戦は逃走不可。
7. 敵の攻撃対象の選択は GM 裁量が原則。挑発はそれを
   上書きする明示ルール (M78)。LP0の戦闘不能者は通常攻撃の
   対象外とし、とどめ・捕縛・救助・蘇生は明記された個別処理だけで行う。
8. 現在の遠征に同行する火持ち全員が LP0 になった瞬間に
   死に戻り発動。一時分断・捕縛中も同じ遠征なら数え、宿待機・
   別行動者は数えない。同行火持ちだけが翌朝の宿へ戻り、LP・MP・
   一時的な通常状態異常・エロステが全回復、危険帯に応じて借金
   +500G / +1,000G / +1,500G / +2,000G。

## 五日取立て 早見 (M93)

- 初期: `cycle=0 / 元本10,000G / Day 5 / 請求500G`。
- 取立て前の任意返済も今期支払へ合算。取立ては判定なしで
  全額、100G単位の一部、不払いのいずれかを選ぶ。
- 未払い `U` の延滞は `10G切上げ(max(50G, U×20%))`。
  完全不払いは最低100G。
- 今期に正の支払があれば次回請求+250G。上限は
  `2,500G + 500G×cycle`。完全不払いなら請求据え置き。
  どの結果でも次回日は+5日、今期支払は0へ戻し、台帳へ追記。
- 完済したら恒久実績を残し、同じtransactionで `cycle+1`、
  新元本 `50,000G×cycle`。初回更新50,000G、次100,000G、その次150,000G。
  新請求は `500G+250G×cycle` へリセットする。
- 第一段階完済前のリリスは絶対になびかない。初回完済は関係解禁だけ。
  第二段階完済でネームド外見変更を解禁。旧3択特典を自動追加しない。
  恋愛・H・身体払いで借金を消さず、恋人になっても取立てを続ける。
  解禁は正規完済台帳で確認し、好きな呼び方はpartner_pref.callを使う。
- 外見変更は対象IDと変更前後を提示し、チャットの「確定」後に保存。
  外見だけをキャンペーンへ上書きし、人格・成人性・能力値・装備効果は維持する。

## 場面を閉じる前の節目 (4.13.0)

親密な展開へ進める場面には、踏み込む選択肢を1つ置き、Hスキップも維持する。選ばれなければ通常進行を続ける。夜は実際の宿代・次回請求・未払い時の加算を短く示す。仲間の加入合意が成立したターンは、火分けの提案と補正の前後を提示する。正本はコア§16で、新しい発生ロールや頻度表は作らない。

通常遭遇の2人編成では弱敵3体、または標準1体＋弱敵1体を使い、同時実働は3体まで。ゴブリン5体を一律に標準遭遇へしない。警告した特別遭遇なら、その区別と構成を先に記録する。

## 移動と散策の提示 (4.13.3)
移動を選ばせる時は、同じ行先のまっすぐ／ぶらぶらを原則対にする。緊急時は後者を出さない。移動イベントは関わるか見送るかを選べる小品だけとし、目的地を塞がない。外れ・急ぎ・直行は2〜3行で到着する。リリス・ミルカの一度だけの散策案内は実際の登場場面で話し、既存のcampaign_loreへ案内済みを記録する。
