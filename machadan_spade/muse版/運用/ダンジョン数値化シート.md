# ダンジョン数値化シート (M35/M90/M101/M413 現行)

Dungeon_Data.md の割合・文章表記を最終システム (2d10対抗) の式に
落とした現行正本。ここに記載した M35 仕様を使う。

## 共通ルール
- 状態付与判定: 各データの % 表記は d10 テープで判定する (30% = 3以下、
  50% = 5以下、80% = 8以下)。% の書いていない付与は原則 30%
  (3以下) を標準とする。
- **深層の看板技 (M90)**: 6F以降でも状態付与へ一律+10ptは行わない。
  個体データで「看板技」と明記した技だけ基本値+10ptを含む。本シートに
  記載した最終%へ、もう一度+10ptしてはならない。SPD補正は従来どおり
  最終閾値へ適用する。
- **付与判定への SPD 補正 (M48 B-4追補)**: 付与の閾値は、対象の
  SPD で補正する。SPD 15〜19 なら閾値 -1、SPD 20以上 なら -2、
  SPD 5以下 なら +1 (閾値は最低1・最大9)。速い相手は状態異常を
  「避ける」ことができ、遅くて硬いだけの相手は受けやすい、と
  いう線引き。毒・麻痺・拘束・混乱など全ての付与に適用する。
- **毒の性質**: 毒の継続ダメージ (LP-3〜4/ターン) は DEF を
  無視する。硬さでは防げない圧力として働く。解毒は薬草 (10G、
  解毒作用あり)・解毒草・エレナの治療で可能なので、詰み要素
  にはならない。機械・石造・亡霊系の体を持つ敵 (ゴーレム、
  リッチ等) は毒が無効。
- **未修飾のスタン判定 (M90):** 「スタン判定」とだけ書かれた命中技は、
  命中後30%で付与し、上記の対象SPD閾値補正を使う。スタンは対象の次の
  標準行動1回を失わせ、その手番終了時に解除する。麻痺と重なっても
  同じ手番に失う行動は1回だけ。盾打ち・ミノタウロスの突進が該当する。
- 物理耐性: ダメージを50%カットする。最低2保証は
  カット後の値に適用する。
- 拘束: 締め付け等の継続ダメージは本シートの個別値どおり。脱出は
  標準行動1回を使い、[自STR] + 2d10 vs [敵STR] + 2d10 の対抗
  (1ターンに1回試行可)。拘束中に禁止される行動と個別の行動不能は
  `Combat_Logic_Detail.md` を参照する。
  失敗するたび、その拘束からの次回以降の脱出へ累積+3。隣接する意識ある
  味方は標準行動で援護し、その1回へさらに+3できる。全体拘束技は
  連続ラウンドに使用できない。
- **奇襲プロファイル**: 全ての敵は個体データに次のいずれかを持つ。
  - `[奇襲: なし]`: ランダム奇襲を行わない。
  - `[奇襲: 条件付き30%]`: 個体データに書かれた地形・潜伏・
    偽装等の条件を満たす時だけ、d10 で3以下。
  - `[奇襲: 得意50%]`: d10 で5以下。影潜みが該当する。
  - `[奇襲: 達人80%]`: d10 で8以下。ダークエルフの暗殺者が
    該当する。
  - `[奇襲: 特殊]`: d10 ではなく、個別データの明記条件で決める。
    未看破のミミックが該当する。
- 敵集団では、条件を満たす奇襲可能な敵の中で最も高い閾値を
  1回だけ判定する。成立時の奇襲行動は、そのプロファイルを
  持つ個体が行う。奇襲なしの強敵に初撃だけ代行させない。
- 索敵に成功した遭遇では敵のランダム奇襲は無効。索敵失敗は
  通常閾値、索敵せず突入した「油断」は閾値 +2。銃声等の個別補正も
  含め、奇襲閾値の上限は9。これらの補正は
  `[奇襲: なし]` を奇襲可能には変えない。
- **敵の奇襲成立後**: 通常の SPD 順より先に、奇襲可能な敵の代表1体が
  単体への基本攻撃1回を行う。命中判定は通常どおり
  `[TEC] + 2d10 vs [SPD] + 2d10`、奇襲側 TEC +2。回避不可ではない。
  2回攻撃・連撃・全体攻撃・召喚・捕縛・即死級の特殊技は使わない。
  これは代表の第1ラウンド標準行動を前倒ししたもので、その後の通常SPD順では
  代表を行動済みにする。追加行動ではない。
- **味方から仕掛ける奇襲**: 相手を先に発見し、まだ未発見で、
  具体的な潜伏手段がある時だけ、味方代表の
  `[SPD] + 2d10 vs 敵代表の [INT] + 2d10` を行う (同点は仕掛け側)。
  疾風脚の +2 (段2は+3) はこの SPD 側に加える。成功時は味方代表が
  上記と同じ奇襲行動を1回行う。失敗は通常開始であり、
  失敗だけで敵の奇襲を自動成立させない。敵の条件が別に成立し、
  索敵等で無効化されていなければ、敵側の d10 判定は別に行う。
  疾風脚・段3の先制攻撃と奇襲行動が同時に成立した場合は、
  同じ1回の初撃として扱い、2回に増やさない。奇襲を行った味方代表も
  第1ラウンドの通常手番では行動済みになる。
- 召喚: 召喚は標準行動1回を消費する。LP閾値は無料発動ではなく、閾値通過後の
  次の本人の手番から選べる召喚機会である。個別の同時上限・総数上限と、
  `Combat_Logic_Detail.md` の同時実働敵数上限を超えない。召喚と同じ標準行動で
  攻撃・全体技・別の召喚は行わない。召喚された個体は次ラウンドのSPD順から
  行動し、召喚と同時の無料攻撃や割り込みを行わない。敵味共通とする。

## 階層別
- 1F ゴブリンの小兵: 視認した孤立者や負傷者へ集中し、囲みを狙う。
  列移動・側面移動は既定の標準行動を消費する。囲みを描くだけで
  追加攻撃や未定義の命中補正を得ない。
- 1F 大コウモリ: 通常攻撃の命中後、付与判定30%（対象SPDの閾値補正あり）で
  DEF-1の一時デバフ。非累積で、同じ対象への再成功でも-2以下にせず、戦闘終了時に解除する。
  装備品の補正や耐久そのものを永続的に壊す効果ではない。
- 1F 駆け出しの女冒険者: 攻撃魔法は基本位階の魔弾（MP2・基礎威力3）。
  最終INT8なのでMP上限8、満タンから最大4回で、命中はTEC対SPD。
  消費を記録し、不足後は通常攻撃・防御・交渉・撤退から選ぶ。
  未記載の高位魔法や無料の連射を追加しない。仲間になる時は敵用数値を
  引き継がず、既定の新規仲間基準へ変換する。
- 1F 毒ガエル: 本来は 2F の敵だが、**1F の水場エリアにも少数が
  出現する** (M48 B-4追補)。1F 時点の DEF 積みへの牽制役。
  スペックと毒 (命中時 30%、LP-3/ターン) は 2F と同じ。
- 1F はぐれ狼「痛恨の一撃」: 命中判定で攻撃側 2d10 の合計が
  19 以上なら痛恨 (ダメージ2倍)。獣として匂い・出血・孤立へ反応し、
  正確なLP、未使用スキル、鞄の中身は知らない。交戦前に深い爪痕や
  獲物を仕留める動きを示し、軽装では痛恨が致命傷になり得ると警告する。
  準備・薬・仲間募集・引き返す選択を提示し、対峙後に手加減や即興の増援をしない。
- 2F 毒ガエル: 命中時 30% で毒 (LP-3/ターン、解毒まで)。
  シャーマンのバフ: 生存中、他のゴブリン全員に STR+1 / TEC+1。
  沼蛇の女王: 命中時50%で猛毒 (LP-4/ターン)。締め付けは拘束
  (LP-3/ターン)。
- 3F 装備劣化: 酸の命中時 30% で、対象の装備1つの補正 -1
  (累積する。街の鍛冶屋で修理するまで戻らない)。
  スライムクイーン: 分裂召喚 (小型スライム STR10/DEF7/INT3/SPD6/TEC6/CHM0/
  LP10 をLP66%/33%通過後の手番に各1体、同時・総数とも最大2体)。召喚は
  標準行動を使い、召喚したラウンドは全体酸を使えない。物理耐性は50%。
  全体酸攻撃は各対象へ `攻撃INT+1d6-対象INT` (最低2)。
- 4F オーク兵タフネス: LP50% 以下で STR+3 (`生成/Monster_Bestiary.md` の個体能力どおり)。
  オーク族長: 戦闘開始時のお供は1人0体/2人弱敵1体/3人弱敵2体まで。LP30% 以下で
  「怒号」= 味方全員の全ステ +1 (1回のみ)。
  毒蛾の鱗粉: 全員に付与判定 30%、毒は LP-3/ターン (Bestiary の「猛毒 LP-4」表記は採用しない。M79)。
- 5F 暗闇: その階層では全員の命中判定 TEC-2 (状況補正)。
  影潜み: `[奇襲: 得意50%]`。アシッドジェリー: 命中時、武器の STR 補正
  -1 (累積、修理まで)。キラービークイーン: 2回攻撃。麻痺毒は
  同一対象へ1ラウンド1回だけ付与判定30%。ワーカービー召喚
  (STR12/DEF5/INT3/SPD12/TEC10/CHM1/LP10) は標準行動を使い、LP75%/50%/25%の
  通過後に各1回まで、同時・総数とも最大2体。
- 6F ラミアの締め付け: 拘束中 LP-5/ターン。アルラウネ: ツタは
  全員に拘束付与判定50% (看板技+10pt込み) で、連続ラウンド使用不可。
  花粉は混乱付与判定30% (混乱の効果は Combat_Logic の50%味方攻撃)。
  アラクネの糸は全員に拘束付与判定50% (看板技+10pt込み) で、連続ラウンド
  使用不可。毒牙は命中時30%で毒 (LP-4/ターン)。
- 7F 兜割り・突進等の貫通: 物理ダメージ計算時、対象DEFを半分
  (切り捨て)として `STR-DEF半分+1d6` (最低2)。完全なDEF無視ではない。
  M101: オーガの大振りとミノタウロスの突進は、まず標準行動1回で予告し、
  次の本人の標準行動1回で単体へ発動する。発動または中断後の本人2手番は再予告不可。
  予告時に届く範囲と動きを示し、防御・回避専念・遮蔽・妨害・撤退を選べるようにする。
  その間の通常打撃は貫通せず、スタンも付かない。ミノタウロスの突進命中時だけ、
  共通の未修飾スタン判定を行う。闇の騎士・ゴーレム・オーク族長の貫通は従来どおり。
  発狂: オーガはLP50%以下でSTR+6、ミノタウロスはLP30%以下でSTR+10。
  いずれも1回だけで、ラウンドごとに加算しない。「倍増」表記は採用しない。
  爆発魔法陣: 事前に紋様と熱を兆候として提示し、INT/困難で発見、TEC/困難で
  解除、または迂回できる。作動時は対象の現在LPを半分 (端数切上げ、最低1) にし、
  装備の数値や所持品は破壊しない。
- 8F ミミック: `[奇襲: 特殊]`。罠発見で看破せずに宝箱として
  開けた場合だけ奇襲成立。開けた者へ単体の基本噛みつき1回を
  TEC+2 の通常命中判定で行い、回避不可にしない。事前に看破した時は
  奇襲なしで通常開始。
  噛みつきの STR は 数値正本 §4 の最終値 (30、M90適用後) を使う。
  ハイウィザードのメテオ: 1手番を使って詠唱開始し、次の本人の手番に
  もう1標準行動で発動。各対象へ `攻撃INT+1d6-対象INT` (最低2)。詠唱中に
  最大LPの25%以上の累積ダメージを受けると中断する。完全遮蔽を確保した対象は
  最終ダメージ半減 (端数切上げ)。発動・中断後は本人の2手番が終わるまで
  再詠唱不可。詠唱開始時にMP14を消費し、中断でも戻さない。MP上限は実効INT。
  MP不足後は物理等の既定行動へ移り、未記載の無料単体魔法を追加しない。
  完全遮蔽へ隠れるには標準行動1回を使い、そこから攻撃・魔法を行えば遮蔽は終わる。
  遮蔽が現地にあるかも交戦前に示し、常時無償の半減にしない。
  ダークエルフは遭遇階級「強敵」。通常の2回攻撃は貫通せず、
  毒ナイフは同一対象へ1ラウンド1回だけ命中時30%
  (毒の継続ダメージは共通ルールのLP-3/ターン。M79)。2回攻撃に代えて
  命中TEC-2の単発「急所狙い」を使え、命中時だけ対象DEF半分。使用した次の
  本人の手番には再使用できず、奇襲行動では選べない。
  先制率 80% は `[奇襲: 達人80%]` (d10で8以下) に読み替える。
  ゴールデンスライム: 物理ダメージは命中判定で攻撃側2d10がゾロ目の時だけ
  通る (それ以外は0)。痛恨だけでは無効を越えず、ゾロ目かつ痛恨なら通った
  ダメージを2倍にする。魔法ダメージは通常どおり。3ラウンド目終了時に逃走。
  エルダーリッチ: メテオは同上（MP14）。余ったMPでは、明記された魔弾T1
  （MP2・基礎威力3）も使える。本人の手番終了時にLP+5回復するが、炎属性か
  光属性のダメージを初めて受けると再生核が壊れ、以後その戦闘中の再生は停止する。
  目の前で火を見せるだけでは止まらない。偵察成功時または最初の再生を見た直後に、
  炎・光で核を壊せる兆候を明示する。「隷属の呪い」は標準行動とMP4を使い、
  単体へ `リッチINT+2d10 vs 対象INT+2d10`。成功すると対象の次の標準行動だけを、
  リッチが観測済みかつ届く味方への基本攻撃1回へ置き換える。自傷、アイテム、
  回数制スキル、未観測の能力は使わせない。対象の手番前に隣接する味方が
  標準行動で同じINT対抗に勝てば解除できる。解決または解除後、リッチの手番を
  2回終えるまで再使用不可で、次の使用では直前と同じ対象を選べない。
- 9F サキュバスクイーン: 召喚は標準行動を使い、2手番に1回まで。
  MP6で数値正本§4の「夢魔の影」を1体だけ出す。7〜8Fの術者や強敵へ置き換えない。
  同時存在は1体、戦闘中の総数は2体まで。召喚個体も同時実働敵数へ数える。
  MP上限はINT21。魔法・精神技・召喚の消費を共有し、不足時は通常の物理行動へ移る。
  **茨の鞭:** 標準行動1回で全体を薙ぐ動作を予告し、次の本人の標準行動1回で発動。
  各対象へ通常のTEC対SPD、命中時に `(STR-DEF)+1d6`、出血の付与判定。
  発動・中断後の本人2手番は再予告不可。予告・鞭・召喚・精神技を同じ行動で重ねない。
  **強制絶頂／魅了の瞳:** ともに標準行動1回・MP4、CHM対対象INT。前者は成功時LP-15と
  次の標準行動1回喪失、後者は次の標準行動だけ観測済みの届く基本攻撃1回へ置換する。
  自傷・魔法・回数制技・アイテムを使わせない。共通の状態付与は別判定のまま。
  両技は共有待機し、成功・失敗を問わず使った後の本人2手番はどちらも使えない。
  次回は直前と同じ対象を選ばず、効果終了後に本人が通常行動を1回終えるまでは
  同じ術者からの支配・行動喪失を再付与しない。同じ手番の行動喪失は重複しても1回。
  鞭以外の通常物理攻撃は単体で、全体攻撃や出血を自動で付けない。

## 睡眠の運用 (M77)
スリープクラウド等の範囲睡眠が暴れないための共通ルール。
単体の「眠り」にも同じく適用する。
- 睡眠中の対象は行動できない。**ダメージを受けたら、その
  攻撃の解決後に即座に目覚める**。味方は1行動を使って
  揺すり起こせる (確実に起きる)。大きな音や強い衝撃でも
  起きる (GM判断)。
- 眠っている対象への攻撃は、命中側の TEC に **+5**
  (完全な不意打ちとして扱う)。ただしダメージ式は通常
  どおりで、即死や無条件の致命傷にはならない。
- **再睡眠への耐性**: 一度睡眠から目覚めた対象は、その
  戦闘の間、睡眠の付与閾値が **-3** される (連鎖睡眠の
  防止)。
- **ボス・強敵**: 睡眠の付与閾値に **-2** (SPD補正とは
  別枠。閾値の合計補正は最低1まで)。
- 持続は魔法側の定義どおり (ティア別の状態最大持続が
  上限: T2まで1ターン / T3〜T4は2ターン / T5は3ターン)。

## エロ攻撃とエロステ付与 (M57 で現行式へ変換)
Combat_Logic_Detail の [Ero_Attack_Rule] と同じ現行式を用いる。
- エロ攻撃の成否: [敵CHM] + 2d10 vs [対象INT] + 2d10 の
  対抗 (同点は攻撃側 = エロ攻撃が通る)。
- 通ったら付与判定: d10 で 5以下 (50%) を基本とし、
  共通ルールの対象 SPD 補正を適用する。付ける状態は
  その敵の [EroAtk効果] の指定どおり。
- 感度上昇中の対象: 付与の閾値に +3 (ほぼ確定)。
  淫紋の対象: エロ攻撃は対抗をスキップして付与判定へ
  進む (必中)。感度上昇中のキャラがエロ攻撃を受けた時
  の LP-3 の追加ダメージは本シートの確定値どおり。
- エロ攻撃自体は LP ダメージを持たない (エロステの
  付与が本体)。エロステの効果・蓄積・解除は
  Combat_Logic_Detail の [Ero_Status_List] と
  [Ero_Accumulation]、全解除は聖堂の 300G (運用詳細
  シート §1) が正本。

## M413 攻撃性と数値同期
