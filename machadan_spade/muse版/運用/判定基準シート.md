# 判定基準シート (M37/M82/M84/M100 現行)

非戦闘判定の目標値と、戦闘の状況補正の基準。M37 を基礎に、
生産依頼の運用 M82 と固定目標値化 M84 を反映した現行正本。

## 大成功の定義 (M55 で明文化)
成功した上で、その判定の 2d10 の合計が 19以上 なら
「大成功」とする (痛恨と同じ出目の線)。値切りの 20% OFF
など、「大成功で」と書かれた効果は全てこの定義で判定する。
対抗判定では使わない (勝敗のみ)。

## 単独判定の標準形
[能力] + 2d10 >= 目標値 で成功。目標値は難易度で決める
(能力は行動ごとに固定)。目標値は判定者の能力値から算出せず、
次の固定値を使う。成功率の目安は能力8の場合であり、能力・装備・
成長・状況補正が高いほど実際の成功率も上がる:

| 難易度 | 目標値 | 成功率の目安 |
|---|---|---|
| 容易 | 16 | 79% |
| 標準 | 19 | 55% |
| 困難 | 22 | 28% |
| 過酷 | 25 | 10% |
| 超難 | 28 | 1% |
| 伝説 | 31 | 0% |

超難・伝説は、複雑な古代機構や稀少な完全成果のための固定難度。
主人公の成長に合わせて同じ鍵や仕事の目標値を引き上げない。
深層の普通の扉、日常の買い物などは、従来の容易・標準のままでよい。

**専門家の見通し:** 装備・火・適用できる技能等を足した判定側の合計が
12 / 16 / 20なら、超難28への成功率は15% / 45% / 79%、
伝説31へは3% / 21% / 55%。専門知識で難度を下げた場合は、その変更後の
目標値で計算する。成長や準備は効くが、最高難度まで一律に自動成功にはしない。

## 仲間への委任と難度の固定 (M100)
- 判定前に対象、方法、実行者1人、使う能力、難度、失敗の危険を決める。
  人物の強さを見て難度を後から上下させない。成功が明白で危険もない行動は振らない。
- 苦手な作業は、その場にいて実際に手・道具・時間を使える仲間へ任せられる。
  その仲間本人の実効能力と有効な技能で1回判定し、消耗品や行動も本人のものを使う。
  控え・宿待機・別の場所の人物を、その場の実行者にはしない。
- 「鍵を開ける」などパーティとしての指示なら、適任者が自然に引き受けてよい。
  主人公本人がすると明言された場合は、その意思を守る。判定表示には担当者を添える。
- 全員の能力を足さず、失敗後に全員が順番に同じ判定を振らない。
  別の道具・新情報・別の方法、または実際の時間や材料の負担で状況が変わった時だけ
  新しい試行を認める。戦闘中の援護は既存の標準行動と補正上限を使う。
- 同じ専門性を根拠とする「職業タグの難度1段低下」と「同分野の技能加算」は
  両方を足さず、どちらか有利な1つを使う。技能自体の複数効果は明記どおり。
  別根拠の関係・道具・地形は併用できるが、状況補正部分は±3、技能等を含む
  判定補正の正の合計は+5まで。装備・火・実による能力値そのものの増加は別枠。
- 実力上、出目の最大でも成功しない時は、振る前に難しさを伝え、適任者・道具・
  調査・迂回・不完全な成果を提示する。重要手掛かりや唯一の主線出口を1回の失敗で消さない。

| 作業の例 | 事前に固定する難度 | 失敗時にも残す進路 |
|---|---|---|
| 旧遺構の基本銘文を読む | INT19 | 核となる手掛かりを得て、細部は別の調査へ |
| 壊れた制御盤を無損傷で直す | INTまたはTEC22。方法で先に選ぶ | 時間・材料・仕上がりの妥協 |
| 暗所の二重連動罠 | 発見INT22・解除TEC25 | 印を付けて迂回、道具の準備、適任者へ委任 |
| 多重の古代封印を扱う | 方法に応じINTまたはTEC28 | 専門家への依頼や別の解除手段 |
| 神代の装置を完全復元する | INTまたはTEC31 | 完全成果や追加遺物を逃しても本筋は進む |

例が深層に似合うことと、階層だけで全作業をその難度へ変えることは区別する。
難度1段の順序は16→19→22→25→28→31。容易より下は判定不要、伝説より上が
必要なら具体的な準備・共同作業の条件にし、無限に目標値を増やさない。

## 行動ごとの能力と難易度
- 罠の発見: INT / 標準 (5F 以降は困難)
- 罠の解除: TEC / 標準
- 索敵・偵察: INT か TEC / 標準
- 隠密・尾行: SPD / 相手がいる場合は対抗、環境だけなら標準
- 登攀・跳躍・力仕事: STR か SPD / 標準 (状況で上下)
- 知識・解読・鑑定: INT / 標準〜過酷 (対象の希少さで選ぶ)
- 値切り: CHM / 標準。成功で 10% OFF、判定の 2d10 合計が
  19 以上なら 20% OFF。下限は定価の 80% (現行の価格ロック)。
  対人の交渉・誘惑は従来どおり CHM 対抗。
- 精神攻撃・魅了への抵抗 (環境・罠系): INT / 困難。
  相手がいる場合は対抗式 (M33)。
- 生体宝箱の愛撫: TEC / 標準。
- 拘束からの脱出: STR 対抗 (M35)。
- 生産依頼の要望聞き出し・納品交渉: CHM / 標準。
- 生産依頼の設計・原因分析・発明: INT / 標準〜困難。
- 精密加工・調合・縫製・組立: TEC / 標準〜困難。
- 鍛造・大型構造物の加工: STR / 標準〜困難。

生産依頼では一場面で判定を連打せず、調査・試作・実演のうち
重要なもの最大2回を目安にする。失敗は同じ判定の再試行ではなく、
費用・日数・性能・見た目の妥協や別案の選択へ変換する (M82)。

## 索敵と奇襲の連携
- 戦闘前に索敵できる時間と状況がある場合、パーティの代表1人が
  **INT か TEC / 標準 (19)** で判定する。1遭遇に1回だけで、
  同じ場所で成功するまで振り直さない。
- 成功: 敵の気配、おおよその数、その敵の
  `[奇襲: なし / 条件付き30% / 得意50% / 達人80% / 特殊]`
  を開示する。その遭遇の敵によるランダム奇襲は無効になる。
  正確なステータスや弱点までは開示しない。
- 失敗: それだけで奇襲は確定しない。敵の奇襲タグと条件を
  確認し、該当する敵だけ通常の閾値で判定する。
- 索敵せずに突入した場合は「油断」とし、奇襲可能な敵の閾値に
  **+2** する (最大9)。ただし、`[奇襲: なし]` を奇襲可能には
  変えない。

## 味方側が奇襲を仕掛ける時
- 索敵成功などで相手を先に発見し、まだ相手に発見されておらず、
  隠れ場所・誘導・待ち伏せ等の具体的な手段がある時だけ
  仕掛けられる。
- 成立判定は、味方代表の **SPD + 2d10** vs 敵代表の
  **INT + 2d10**。同点は仕掛け側の成功。敵代表は見張りや
  周囲を警戒する個体とし、不明な時は敵集団で最も INT の高い者。
- スキル「疾風脚」の +2 (段2は +3) は、この味方代表の
  SPD 側に加える。奇襲成立後の命中判定へ二重に加えない。
- 成功したら、味方代表1人が下記の奇襲行動を1回行う。
  失敗したら通常開始とする。ただし、索敵成功などで無効化されて
  いない敵側の奇襲条件が別に成立しているなら、敵側の
  d10 奇襲判定は別に行う。味方の失敗だけを理由に、
  敵の奇襲を自動成立させない。

## 奇襲成立後の「奇襲行動」
- 通常の SPD 順を決める前に、奇襲側の代表1人が
  **単体への基本攻撃1回**を行う。命中は通常どおり
  `[TEC] + 2d10 vs [SPD] + 2d10` で判定し、奇襲側の TEC に
  **+2**。回避不可ではない。
- 奇襲行動では、2回攻撃・連撃・全体攻撃・召喚・捕縛・即死級の
  特殊技を使わない。解決後は通常の SPD 順で戦闘を開始する。
- 複数人が別々に奇襲行動したり、奇襲と待ち伏せの初回補正を
  重ねたりしない。「完全な不意打ち」の TEC+5 は睡眠中等だけの
  別ルールであり、通常の奇襲には使わない。

## 受動回避と「回避専念」
- **受動回避**: 通常の攻撃判定にある守備側の
  `[SPD] + 2d10` そのもの。攻撃されるたびに解決し、行動を消費しない。
  拘束中または麻痺中は守備側 SPD **-3** (両方でも-3の1回だけ)。
  睡眠中は受動回避を使わず、下記の完全な不意打ちを使う。
- **回避専念**: 1行動を消費し、宣言直後から次の自分の手番開始直前まで、
  **SPD を守備側に使う攻撃対抗だけ SPD +4**。判定なしで発動し、
  ダメージは軽減しない。
- 精神・エロ・拘束の対抗には、守備側能力が INT・CHM・STR・SPD の
  いずれであっても効かない。状態付与率、罠・環境、継続ダメージ、
  固定LP減少にも効かない。拘束・麻痺・睡眠・
  行動不能中は宣言できず、回避専念中にそのいずれかになった
  瞬間に回避専念は終了する。
- 回避専念 +4 は通常の状況補正 ±3 枠の外。ただし、回避専念と
  状況補正を含むその他の「判定補正」の正の合計は **+5 まで**。
  装備・魔法等が
  SPD の能力値そのものを上げる効果は別に扱う。
- 「防御中」と「回避専念中」は同時に保持できない。後から宣言した方へ
  切り替え、前の効果は終了。同名効果は重ならない。奇襲行動の前に
  未宣言なら、後付けで回避専念を適用しない。敵味共通の基本行動。
- 防御中も、拘束・麻痺・睡眠・行動不能のいずれかになった
  瞬間に終了する。
- 回避専念中も、差1〜2の失敗は下記の「かすり」で通常どおり解決する。
- **選び分け**: 防御は攻撃対抗の守備側能力+2と物理DEF+2で広く受ける。
  回避専念は SPD 対抗だけ+4で命中そのものをより避けやすいが、
  命中後のダメージ軽減はない。

## LP0の対象選択
- LP0の者は戦闘不能で、通常攻撃の対象外。LPは0未満にせず、
  通常攻撃を重ねてとどめの代わりにしない。
- LP0の者へのとどめ・捕縛・救助・蘇生は、それを明記した個別行動、
  アイテム、スキル、場面ルールで別に処理する。

## 捕獲判定 (2d10 化)
[TEC] + 2d10 + 拘束具補正 >= 目標値 で成功。
- 拘束具補正: 素手 0 / 縄・ツタ +3 / 専用拘束具 +6
- 目標値: 対象 LP 半分以下で TEC+10 / 1/3 以下で TEC+8 /
  瀕死・無力化で TEC+6
- 前提・失敗時の反撃・2回失敗で逃走試行は
  `生成/モン娘_捕獲と運用.md` §3どおり。

## 旧 1d6 固定判定の読み替え
- 能力を使う判定 (例: SPD+1d6 >= 10 の回避) は、上記の単独判定
  (標準) に読み替える。
- 確率イベント (例: 1d6>=4 で気づかれる) は d10 で判定する
  (1d6>=4 は 50% なので 5以下、1d6>=5 は 33% なので 3以下)。

## 戦闘の状況補正 (能力側へ加算、合計は ±3 まで)
- 奇襲の初撃: TEC +2
- 待ち伏せ・準備した罠: 初回のみ TEC +2
- 地の利 (高所・足場の優位): TEC +1
- 援護 (仲間が行動を消費して宣言): 対象の TEC +1
- 囲まれ (3体以上に隣接): 守備側 SPD -1
- 暗闇 (5F の新要素): 全員 TEC -2
- 足場不良・悪天候: TEC -1
- 油断 (索敵せず突入): 奇襲可能な敵の奇襲判定の閾値 +2
  (最大9。`[奇襲: なし]` は変化しない)
状況補正は「テキスト入力による工夫」を数値に変えるための表。
宣言と状況が噛み合う時だけ適用し、重ねがけは ±3 で止める。

## 完全な不意打ち (M48 B-2)
- 睡眠中・完全な無警戒の相手への初撃は、命中側 **TEC +5**。
  これは状況補正の合算上限 (±3) の例外で、他の状況補正とは
  合算せず、最も大きいもの1つだけを適用する。
- 寝ている相手は SPD で回避しない (対抗は通常どおり TEC 同士、
  守備側は TEC のみで受ける)。睡眠になった瞬間に防御中・
  回避専念中は終了し、受動回避の SPD や回避専念+4は使わない。

## 部分効果「かすり」(M48 B-2、M69 B-4 で改訂)
- 対抗判定で **差1〜2の失敗** は「かすり」として、狙った効果の
  1段弱い形が残る (全か無かにしない)。例: 目くらまし完全失敗
  → かすりなら次ラウンドだけ相手の命中 -2。拘束 → 移動不可
  だけ。状態付与 → 持続が次ターンまで。
- **ダメージ系も対象に含める (M69 B-4)**: 差1〜2のミスなら、
  かすりとして **最低ダメージ2だけは通る** (既存の最低2
  保証と同水準)。差3以上の失敗は従来どおり当たらない。

## 戦闘クエストの推奨人数の物差し (M69 B-3)
ボード生成時の GM の目安表 (厳密な計算式ではない)。
敵の総LPと、敵の1ラウンド総ダメージ (主火力 x 頭数) を、
想定パーティ (人数・総LP・1ラウンド総ダメージ) と比べて
3段階に分ける。

| 危険度 | 目安 |
|---|---|
| 適正 | 敵の総LP が想定パーティの1ラウンド総ダメージ x3 以内、かつ敵の1ラウンド総ダメージがパーティ総LPの 1/4 以内 |
| 際どい | 上記のどちらか一方を超える |
| 過剰 | 両方を超える。または敵の1ラウンド総ダメージがパーティ総LPの 1/2 以上 |

- ボード表記は「推奨: ◯人〜」+ 危険度の一言 (適正 /
  際どい / 過剰) をセットにする (Quest_Guild の
  Muse版注記 M69 B-3)。
- 「過剰」は受注禁止ではない。観察・駆逐・交渉でも
  満額査定になりうる現行の評価軸とセットで、受注時に
  その旨を伝えるための表示である。
