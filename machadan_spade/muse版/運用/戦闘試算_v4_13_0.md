# 戦闘試算・全敵変更表 v4.13.0

## 結論と比較条件

敵を長く耐える壁から、短い間に攻めてくる相手へ調整した。判定・物理/魔法ダメージ・痛恨・最低2・装備上限の式は変更しない。全40個体の最終値を数値正本・Bestiary・ダンジョン数値化シートで同期した。希少逃走型のゴールデンスライムは全数値を据え置いた。

1Fの道中2戦とボスを続ける2人の比較で、無準備は約5%、準備は約83%が突破する。無準備でも道中が無傷になる比較ではなく、道中・戦闘間回復・ボスへLP/MPと消耗品を引き継いだ。プレイ中の出目や敵の判断をこの率へ合わせる命令ではない。

この試算は第3回320ターンの実測を再生したものではない。同じ能力・装備・方針を固定し、敵数値と回復品だけを前後比較するオフラインモデル。旧版の勝率が実測より低くなる経路もあるため、過去のテストで危険がなかった事実を否定したり、新版の全プレイを保証したりしない。

## 1. 再現方法

```bash
python3 -B tools/balance_v413.py --trials 1200 --individual-trials 250 --seed 413006 --output /absolute/path/result.json
```

各経路・前後それぞれ1,200回（20ケース、計24,000経路）、各個体・前後それぞれ250回（計20,000単独戦）を集計した。固定テープをゲームで消費せず独立乱数で分析する。元の式の実装を共用し、整数の能力値・装備・各回の状態で判定する。全経路のタイムアウト率もJSONに記録した。

既定のROUND60を越えた比較は勝利と数えない。金スライムの逃走は撃破と数えず個別表の逃走率に分離した。勝率の小数点以下は標本誤差を含み、1,200回で最も広い95%区間の目安は±2.8ポイント。100%表示も安全保証ではない。

## 7. 計算モデルの限界と判断が必要な既存差異

- 固定の代表配分・購入装備・少量の能力の実を明記したオフライン試算。自動成長や入場条件ではない。
- 1〜8Fは通常・強敵戦2回＋ボス、9Fはクイーン戦のみの比較経路。実プレイに戦闘ノルマを設けない。逃走判断・全地形・全自作技能・実機の文体は対象外。
- 各戦闘でLP/MP/消耗品を引継ぎ、戦闘回数制限のある技能だけ回復。戦闘間の火によるLP1蘇生と有償の回復を明示。
- 回復の試算では戦闘間の癒しd6だけ3を固定して控えめに見積もる。戦闘中と他の判定は独立ダイス。
- 精神主体のUniqueは通常攻撃と3手番に1回の行動妨害を試算上の方針とする。原本に使用頻度が未定義のため実ゲームの新規確定仕様にはしない。
- 通常遭遇で双方が認識している状態から開始する。奇襲・5Fの暗闇・全ての敵AI・自作技能を網羅した保証ではない。召喚・毒・拘束・連撃・物理耐性・全体魔法・再生対策は扱う。
- 新しい確率をゲームに追加せず、シミュレーションの結果で実プレイの出目や敵判断を操作しない。

- 敵AIは観測済みの回復役・負傷者を狙い、メテオの遮蔽には味方の実行動を使う。回り道・全ての支援反応・咆哮の行動裁定・自作スキルの全パターンは網羅しない。連続比較には治療する安全な間合いがあると仮定する。
- 原本に頻度が書かれていない精神主体Uniqueの行動間隔、ラミアの拘束の選び方はモデルの方針であり、新しいゲームルールではない。実MUSEでの再試行が必要。
- ドブネズミには固定戦闘カタログの数値がなく、実際の6ラウンド戦のログも未添付。推測の新敵で再現済みとはしない。
- 投げナイフの最低1と一般物理式の最低2は既存の差異。式の変更は禁止なので今回は変更しない。
- 装備の単一能力+8と合計+10、Tier4の合計+10は両立する。上限の衝突とは扱わず、今回も変更しない。
- 2F沼蛇のBestiaryは蛇の皮、主ドロップ正本は蛇の鱗。監査では後者を採用、本文は保持。Tier2の火炎瓶は例示だけで固定の価格・入手先が未定義。
