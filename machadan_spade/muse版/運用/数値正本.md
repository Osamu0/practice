## 借金の段階と固有解禁 (M103/M104)

| 完済する契約 | 開始元本 | 完済特典 | 完済直後の次契約 |
|---|---:|---|---:|
| 第一段階 (index 0) | 10,000G | リリスとの恋愛・親密な関係の解禁だけ | 50,000G |
| 第二段階 (index 1) | 50,000G | リリスとネームドの外見・体型変更 | 100,000G |
| 第三段階以降 | 50,000G × index | 新特典の自動追加なし。解禁済み権利を維持 | 50,000G × (index + 1) |

開始元本と現在残高は別。宿代・死に戻り・延滞の既定加算も含め、現在契約を
全額完済して初めて次段階へ進む。毎5日の取立額は元本全体とは別で、既定の
500G開始・正の支払周期ごと+250G・上限2,500G+500G×indexを維持する。
恋愛・親密さや外見変更で免除・減額しない。途中で好感度に応じた任意増額もしない。
解禁根拠は連続した正規完済台帳。第一段階前のリリスへの口説き・CHM・高好感度・
部屋契約・身体払いは例外にならない。初期点火・非性的介抱・他NPCの関係は対象外。
外見変更は第二段階完済後、プレイヤーの指定とチャットの「確定」で現在キャンペーンへ
適用する。成人性・人格・人物ID・能力値・装備効果は維持し、人格正本を改変しない。
詳細は運用詳細シート§8、人物の態度と初回完済場面は人格/Lilith.mdを読む。

マチャダン スペード Muse版の数値の正本。判定・戦闘・敵の数値は
全てこのファイルの値を使う。個別ルールの詳細は、このファイルの各節と

## 1. 判定の基本
- ダイスは固定テープから消費する (M28)。GM は出目を作らない。
- 対抗判定: [能力] + 2d10 vs [能力] + 2d10、攻撃側が以上で成功
  (M33)。+1 は約 +6.6pt、帯は ±13。
- 単独判定: [能力] + 2d10 >= 固定目標値。難易度は容易 16 / 標準 19 /
  困難 22 / 過酷 25 / 超難 28 / 伝説 31 (M84/M100)。目標値へ判定者自身の能力を足さない。
  成功率の基準 (79% / 55% / 28% / 10% / 1% / 0%) は能力8の場合。
  難度は対象と作業から事前に決め、同じ作業を成長に連動して難しくしない。
  仲間へ任せる時は実行者本人の能力・技能で1回判定する。全員分を加算したり、
  失敗後に同じ試行を順番に繰り返さない。専門性の重複と具体例は判定基準シートM100を使う。
- ダメージ: (STR - DEF) + 1d6、最低 2。
- 痛恨: 命中判定で攻撃側 2d10 の合計が 19 以上なら ダメージ2倍
  (M35)。
- 受動回避: SPD を守備側に使う通常の攻撃判定の
  守備側 `SPD + 2d10`。行動消費なし。拘束中または麻痺中は
  守備側SPD-3 (両方でも-3の1回)。睡眠中は受動回避でなく、
  完全な不意打ち (攻撃側TEC+5、守備側TEC) を使う。
- 防御: 1行動を消費し、次の自分の手番開始直前まで攻撃対抗の
  守備側能力 +2 (通常・攻撃魔法は SPD、エロ・精神攻撃は INT)、
  物理ダメージ計算時の DEF +2。DEF無視・継続ダメージ・罠・
  固定LP減少・状態付与率には効かず、連続宣言で重ならない。
- 回避専念: 1行動を消費し、次の自分の手番開始直前まで、
  SPD を守備側に使う攻撃対抗だけ SPD +4。ダメージ軽減なし。
  精神・エロ・拘束の対抗は守備側能力にかかわらず無効。
  状態付与率、罠・環境・継続・固定ダメージにも無効。
  拘束・麻痺・睡眠・行動不能中は宣言不可。+4 は状況補正 ±3 枠の外だが、
  状況補正を含むその他の判定補正との正の合計は+5まで。
  SPD の能力値そのものを上げるバフは別扱い。
- 防御と回避専念は敵味共通の基本行動で、同時保持不可。後の宣言へ
  切り替え、同名は重ならない。奇襲前の未宣言状態を後付けしない。
  回避専念中も差1〜2の「かすり」は通常どおり。防御中・回避専念中の
  いずれも、拘束・麻痺・睡眠・行動不能になった瞬間に終了する。
- 回復アイテム: 戦闘中使用可の品は1個につき1行動。通常のLP回復品は
  LP1以上だけを対象とし、LP0の味方は気付け薬（300G、LP1復帰、
  同じ対象に1戦闘1回）だけで起こせる。LP0の者は自分では使用できない。
  薬草・蜂蜜は安全な場所専用。通常の回復魔法もLP1以上だけを対象とし、
  LP0復帰効果の自作は禁止。
- LP0の者は通常攻撃の対象外で、LPは0未満にしない。とどめ・捕縛・
  救助・蘇生は、明記された個別行動・アイテム・スキル・場面ルールで処理する。
- 状態付与などの確率は d10 で判定 (30% = 3以下 等、M35)。
- 「スタン判定」とだけ書かれた命中技は命中後30% (対象SPDで閾値補正)で、
  次の本人の標準行動1回を失わせる。麻痺と重なっても同じ手番の行動喪失は1回。
- 敵の奇襲は全員一律ではなく、個体の
  `[奇襲: なし / 条件付き30% / 得意50% / 達人80% / 特殊]` に従う。
  成立時は代表1体が TEC+2 で通常命中判定を行う単体基本攻撃1回。
  回避不可攻撃ではない。詳細は M35。
- 状況補正は M37 の表で能力側へ加算 (合計 ±3 まで)。
- **ラウンドと手番 (M90):** ラウンドは全戦闘参加者が原則1回ずつ
  手番を終えるまで。各手番は標準行動1回を持ち、反応は個別に明記された
  効果だけが使える。継続ダメージはその状態を受けている本人の手番終了時に
  1回だけ処理する。同名の継続状態は加算せず、強い値へ上書きし、同値なら
  残り時間だけ更新する。
- **複数回攻撃 (M90):** 1回の標準行動として解決し、各攻撃ごとに
  命中判定とダメージを行う。同じ技に付く毒・麻痺等の付与判定は、
  同一対象へ1ラウンド1回まで。召喚も標準行動を消費し、個別上限を超えない。
- **奇襲の行動消費 (M90):** 奇襲行動を行った者は、第1ラウンドの
  標準行動を既に使用済みとして扱う。奇襲は初手を前倒しするもので、
  追加行動ではない。

## 2. プレイヤー
- 新規初期値 (M98): Base ALL 3 + ボーナス 15pt = 合計 33pt、LP 20。
  火の補正は別枠なので、一人の火持ちなら6能力の実効合計は装備前51pt、
  LP上限は無職32・前衛職42に、下記の永久DEF由来の丈夫さを加える。MP上限は実効INT。
- 旧版で確定した各5・45ptの初期配分、加入済み仲間、名前付き固定人物、
  獲得済みの成長は保持する。更新だけを理由に一律減算・再配分しない。
  配分途中の旧セーブはonboarding-statusのallocation_budgetを使い、
  未着手の新規作成と新たな生成仲間だけ33ptを基準にする。
- 装備補正の上限: 単一 +8、複数合計 +10。
- 重量制 (M30): SPD ペナルティ = max(0, 装備重量合計 - STR合計)。
- 成長は能力の実 (+1、LPの実は +3) とイベントで明記された成長のみ。
  戦闘外の落ち着いて使える場面で使用する。通常能力の実は対象のgrowth_bonusへ+1、LPの実はbase_lpへ+3を記録し、
  出生時の配分記録を作り替えない。
  `選べる能力の実`は使用時に通常6能力のどれか+1またはBase LP+3を
  選ぶ。獲得時には能力を上げず、使用時に1個消費する。
- 初期配分・能力の実の使用・ギルドの再訓練は共通の＋／−ウィジェットを使う。
  操作中は下書きで、チャットの「確定」後だけ検証付き候補を作って保存する。
  再訓練は100G・半日、初期分と成長分を含む恒久6能力の全ポイントを振り直す。
  各3以上・現在の恒久6能力合計を維持する。装備・火・一時効果はポイントに戻さない。
  LPの実で育てたBase LPは別枠で残し、6能力へ換算しない。転職そのものと再訓練は区別する。
- **丈夫さとLP (M102):** `stat_lp_bonus = max(0, (base_stats.DEF + growth_bonus.DEF - 3) // 2)`。
  永久DEFが3なら0、5なら+1、7なら+2。装備・火・一時効果のDEFは計算から除く。
  最大LPは `base_lp + stat_lp_bonus + job_lp_bonus + fire_lp_bonus + temporary_lp_bonus`。
  Base LPは初期20にLPの実等の既定の永続成長を加えた値を保持する。
  MP上限は再配分後の実効INT。再訓練時の現在LP/MPは旧現在値と新上限の小さい方。
  再訓練の往復で回復・蘇生・LP成長の二重加算をしない。初期作成だけ満タンで開始する。
- **C級到達保証:** ガストンの認可で個人ランクが初めてCになった時、
  `選べる能力の実`×1の受取権を1回だけ発生させる。その場または次回の
  ギルド訪問で受け取りを提示し、保留も可。受取時だけ所持品へ加える。
- **ダンジョン供給 (M108):** 各階のボスから実を初めて得るまでは30%、その入手元からの再取得は20%で固定。初獲得前だけボス連続外れ3回後の次回確定を維持し、再取得は外れ数を増減せず天井なし。強敵5体の10%と宝箱表は別枠。ボスは帰還後の新潜行で同じ個体として復活するが、戦利品・実抽選は各階一日一回。確定配置の実はキャンペーン一回限り。詳細と日次の記録は `世界/Dungeon_Data.md` §1、対象とダイス順は `生成/ドロップ表.md`。
- **宝箱供給:** 1〜2Fからは出ない。3〜4Fはd6の5〜6をRAREとし、
  二次d10の1〜2で1個。5F以降はd6の5のRAREで同じ判定、d6の6の
  JACKPOTは二次d10の1〜2で2個。各宝箱の中身結果は1つだけで、
  RARE/JACKPOTを引いただけでは実を確定しない。8Fミミックの2個は
  固定source_idの最初の特別個体1体だけのキャンペーン1回枠で、通常個体は実なし。
- **クエスト・イベント供給:** M83の自然さ条件を満たす時だけ候補にする。
  C/B級のd10=10とイベント10件に1件程度は頻度上限であり、自動追加命令
  ではない。A級も確定報酬にせず、依頼者の所持と物語上の理由がある時だけ
  候補にできる。
- 実の種類は、実際に出た個数ぶんドロップ表のd10表で独立に決める。
  ボス天井ではレア判定d10を消費せず種類d10だけを消費し、C級昇格支給は
  最初から選べる実なのでダイスを消費しない。

## 3. リリスの火 (M32)
- 全ステ加算: **現在の遠征へ同行して出発した火持ち** 1人 +3 / 2人 +2 /
  3人 +1 / 4人以上 +0。
- LP ボーナス: +12 / +8 / +5 / +3。
- 正式メンバー = 火を分けている者。死に戻りは、現在の遠征に同行する
  火持ち全員が LP0 になった瞬間に発動する。一時分断・捕縛中でも
  同じ遠征なら含み、宿待機・別行動・別遠征中の火持ちは含めない。
  火の受け渡しは接触状態でのみ。能力補正人数は遠征開始時に同行者だけで
  スナップショットし、帰還まで固定する。宿待機・別遠征中の火持ちは
  数えない。街中で遠征外の場面は、その場で行動を共にする火持ちだけを数える。
- 戦闘不能の火持ち仲間は、火持ちが1分間触れ続ければ LP1 で復活。
- **死に戻りの対価:** 発動地点の危険帯に応じて、発動1回につき借金を
  加算する。F/E/D級または1〜2Fは **+500G**、C級または3〜4Fは
  **+1,000G**、B級または5〜6Fは **+1,500G**、A級または7〜9Fは
  **+2,000G**。クエストと階層が併存する時は高い方、無級・不明は
  +500Gとし、後から高い帯へ推定し直さない。遠征を終了し、
  翌朝の宿で同行火持ちの LP・MP、一時的な通常状態異常、`ero_status`
  を全回復する。この料金以外の宿代・治療費、所持金半減、所持品・装備
  ロスト、心的外傷判定はない。永続変化、独立した呪い、呪い装備、
  装備劣化、消費済みの品、関係と進行は巻き戻さない。ソロは本人=
  同行火持ち全員なので発動する。

## 3.5 難易度目標と公平性 (M90)
十分な事前情報を得て、表示された推奨人数・推奨役割を満たし、同階層帯の
装備を持つパーティを基準とする。敵は勝利と全滅を本気で狙い、観察済みの
回復役・孤立者・負傷者へ集中する。GMは出目や敵判断を接待目的で曲げない。

| 場面 | 誰か1人以上がLP0 | 同行火持ち全員LP0（死に戻り） |
|---|---:|---:|
| 日常・簡単な依頼 | 5〜15% | 0〜3% |
| 標準戦闘 | 20〜30% | 5〜10% |
| 困難・強敵 | 35〜50% | 12〜20% |
| 階層ボス初見 | 50〜70% | 20〜30% |
| 最終ボス初見 | 65〜85% | 30〜45% |

警告を無視した格上挑戦、推奨人数不足、必須対策なしでは上限を超えてよい。
ただし、非前衛の最大LPの60%以上を一撃で奪う技は原則1手前に兆候を見せ、
75%以上を奪い得る技には防御・遮蔽・中断・かばう・消耗品・撤退のいずれか
少なくとも1つの有効な対処を用意する。敵の狡猾さは正当な難しさであり、
未観察の所持品や正確な能力値を読むこと、ルール外補正、無告知の確定即死で
代用しない。

**永久能力のBase TSP（base_stats＋growth_bonusの6能力合計。LP・火・装備を除く）:**
**成長参考帯 (新規33pt開始):** 成長資源の実供給に合わせ、
1〜2F 33〜36、3〜4F 35〜39、5〜6F 37〜42、7〜8F 40〜46、9F 43〜50は、
繰り返しの依頼・潜行も行った個人の成長参考帯とする。直行時の保証値ではない。
能力の実は共有資源で、全員がこの上限まで育つとは仮定しない。M101の控えめな
比較では9Fでも3人合計10個（LP実を含む）、各人の通常能力は+3点程度を用いた。
これは成長の自動付与・到達条件ではない。旧45pt開始ではそれぞれ+12で読み、
実際に得た能力の実と明記された成長だけを記録する。
TSPだけでなく、同階層帯の装備、スキル段、状態対策、推奨役割を同時に確認する。

## 5. 別軸の敵の見立て (物理モデル外の検証)
- ラミアダンサー: エロ攻撃で3種付与まで約8ターン、物理では
  その前に倒れる。締め付けが本命で適正。
- スライムクイーン: 物理耐性50%。分裂はLP 66%/33%通過時の最大2体で、
  召喚は行動を消費する。分裂と全体酸を同じラウンドに使わない。
- エルダーリッチ: メテオは §6 の魔法式で処理する (詠唱つき)。

## 6. 魔法ダメージ (M38)
[攻撃INT] + 1d6 - [対象INT] (最低2)。全体魔法は各対象に
この式を適用する。詠唱と中断は M35 のとおり。

## 7. 銃器・遠隔武器 (M40)
- 遠隔の命中: [TEC] + 2d10 vs [SPD] + 2d10。接敵した相手へ
  の射撃は -2、ライフル/マシンガンは更に -2。
- 銃ダメージ: [火力] + 1d6 - [対象DEF÷2] (最低2)。装填は
  1行動。発砲した戦闘では味方の奇襲は成立せず、発砲後は
  そのダンジョン滞在中、奇襲可能かつ条件を満たす敵の
  奇襲判定の閾値 +1 (上限9)。`[奇襲: なし]` は変化しない。
- リボルバー: 火力9 / 装弾6 / 片手 / 重量4。製作 2,500G +
  黒鉄のインゴット×1 + 鉄鉱石×3 + 魔石の欠片×2、3日。
- ライフル: 火力12 / 装弾5 / 両手 / 重量6。製作 4,500G +
  黒鉄のインゴット×2 + 鉄鉱石×3 + 高純度の魔石×1、5日。
- マシンガン: 火力10 / 装弾30 / 両手 / 重量11。1攻撃で
  弾3発消費・命中判定3回。製作 16,000G + 黒鉄の
  インゴット×4 + 高純度の魔石×3 + 巨人の骨×1、14日。
- 実包: 全銃共通、6発 30G (テトラ専売)。弾数はセーブ管理。
- 弓: ダメージは通常の物理式。短弓 250G / 重量2、長弓
  400G / 重量3 (近接命中 -2)。矢は 10本 20G、戦闘後に
  使った分の半分を回収できる。
  (銃の接続: 製作期間は初回のみ、修理は製作費の10%で
  テトラのみ、買い戻しは製作費の50%、仲間も使用可で
  弾は共有。詳細は銃器・遠隔武器設計書 §7。)

## 8. 魔法 (M39/M44)
- 最大MP = INT合計 (装備・火込み)。宿で全回復、エーテル
  (80G) で MP+8、大 (180G) で MP+16、野宿で半分まで回復 (運用詳細シート)。
- 階位の門 (INT合計): T1=7 / T2=11 / T3=15 / T4=19 /
  T5=23。魔法のセット上限は役割別 (M76): 非術士2 /
  混成4 / 魔法職6 / 専門職8。習得に上限はなく枠外は控え。
  魔法にも段がある (段2で基礎威力・回復+1、段3でさらに
  +1 か副次効果)。
- 攻撃魔法: 命中は TEC vs SPD の対抗 (魔法システム設計書 §3)。ダメージ = [INT] + 基礎威力
  + 1d6 - [対象INT] (最低2)。回復 = [INT] + 基礎回復
  + 1d6 (命中判定なし)。範囲魔法は全て詠唱制。
- 上限表 (基礎威力/基礎回復/MP帯/状態の最大持続):
  T1 3/5/1-3/1T、T2 5/8/3-5/1T、T3 6/12/5-8/2T、
  T4 8/16/8-12/2T、T5 10/22/12-18/3T。
- T2 以上の攻撃魔法は副次効果を持つ (火球=炎上 +3、氷槍=
  鈍足、雷霆=痛恨条件低下。M48 B-3)。T1 の魔弾は素の効率が
  担当で、MP 効率の逆転を防ぐための線引き。
- 標準魔法15種と自作魔法・触媒・召喚 (T3〜、上限と集中
  ルール) の全文は 運用/魔法システム設計書.md が正本。
  運用の細部 (バフの上書き、敵術者のMP、魔導書の再入荷等)
  は同書 §12。

## 9. スキル (M76 現行正本)
- ジョブを決めた時点でパック4つが付く。以後は追加で
  習得できる (M76)。セット上限: 技4 / パッシブ3 / 技能4。
  習得したスキルは消えず、枠外は控え (再セット 100G)。
- 位階と天井 (段1): 基本 = 判定 ±3 / ダメージ ±3、
  上級 = ±4 / ±5、奥義 = ±5 / ±7。段の強化後は天井
  +1 まで。技は1ターン1つまで、必ず使用回数つき。
  補正の合算上限は ±5。
- 価格: 追加習得は 基本 300G / 上級 1,000G / 奥義
  2,000G、自作は位階別 (500G〜)。強化: 段2 = 800G /
  段3 = 2,500G (訓練 半日、奥義の取得は1日)。
- 強撃 (戦士): 対象が無力状態 (拘束・睡眠・完全な
  不意打ち。段2 で怯み・転倒も) の時は命中ペナルティ
  が消える (M69 B-2)。
- 全文は 運用/スキルシステム設計書.md が正本。
