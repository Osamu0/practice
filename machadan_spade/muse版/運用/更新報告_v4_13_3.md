# 更新報告 v4.13.3 — 移動イベントと街の散策

基準：最新正式版v4.13.2。2026-11-06。
添付指示書の移動拡張に加え、今回のユーザー発言「目的なく街をぶらつく時は高確率」を優先して街・村の散策を80％とした。

## M51の新旧条件

| 行動 | 旧版 | 今回 |
|---|---|---|
| 緊急の移動 | 目的移動は抽選なし | 抽選なし。本人の急ぐ指示、実際の期限・追跡・救助・逃走の時間圧、病人等の搬送だけ |
| 本人が選んだ直行 | 目的移動は抽選なし | 抽選なし |
| スタイル未指定の目的移動 | 抽選なし | d10で2以下、20％ |
| 目的地までぶらぶら歩く | 目的移動は抽選なし | d10で4以下、40％ |
| **街・村を目的なくぶらつく** | d10で4以下、40％ | **d10で8以下、80％**。追加依頼を優先 |
| 道中の目的なし散策、非移動の休憩・暇つぶし等 | 40％ | 40％を維持 |
| ダンジョン内 | M51対象外 | 対象外のまま、専用探索を維持 |

対象行動1回につき発生d10を1件。当選時だけ直後のd10で既存の種別表を引く。固定テープ・cursorを使い、結果と位置はrandom_event_roll等に記録して通常のログと同じ保存へまとめる。表示は各 `d10 = <出目>` だけ。
クエストがあるだけで緊急扱いにせず、曖昧なら通常20％。宝や報酬を必ず得るという意味の80％ではない。

## 選択肢と小さな出来事

- 移動を選ぶ場面では、原則として同じ行先の「まっすぐ／ぶらぶら」を対で示す。緊急時にはぶらぶらを出さず、戦闘・交渉等の全候補へ機械的に対を増やさない。
- 移動イベントは通り過ぎられる出来事だけ。関わるか見送るかはプレイヤーが選び、見送れば目的地へ着ける。関わっても1〜3ターンの小品で、元の用事やクエストを乗っ取らない。
- 移動イベントは既存のM51種別表・Overworldの素材・C-7の風景から生成し、EV在庫を消費しない。非移動の日常行動とダンジョンの在庫経路は維持する。
- M51が出た場面にC-7を重ねず、M47の受注時判定とも混同しない。出来事への返答・見送り・元の移動の続きで再抽選しない。
- 外れ・急ぎ・直行は構造に合う2〜3行の移動描写で到着する。前版の650字下限で移動だけを水増ししない。到着後の本編も描く場合は通常の字数・文体を使う。

## NPCによる散策の案内

リリスは宿の初外出時等、ミルカは初回登録後等に、各一度だけ場面内で話す。既存の固定脚本本文は変えず、脚本終了後に短いひとことを補足する。

リリス：
「色んなところを、特に目的もなく適当にぶらついてみるのも面白いわよ♡　きっと世界が{{confirmed_call}}を放っておかないでしょうね♡」
呼称は既存の確定呼称で置換し、恋心を明かす台詞にはしない。

ミルカ：
「この街も何かと色々なことが起きますからね。目的もなくぶらついてみるだけでも、小さな事件やお宝、新しい出会いに出くわすことがありますよ。」

実際に話した時だけ、既存campaign_loreの散策案内_Lilith_000／散策案内_Milka_004へ人物IDとtold:trueを記録する。進行中のセーブでも次の適切な会話で使える。毎回の講義・確率の説明・場面外のGMコメントにはしない。

## 処理と保持した範囲

既存のbegin-turn／prepare-contextに移動区分を渡し、返信の確認と同じ保存処理でダイス・cursor・移動イベントの在庫不使用を確認する。追加のAI呼出しや、毎ターンの全場面総点検は設けていない。
移動区分やrandom_event_roll等の一時情報は変更JSONとcontext側で扱い、セーブの項目は追加していない。

文体カード全文（q含む）、固定テンプレート全文、既存の種別表とM51の§3以降、既存追補・イベントデッキ、数値正本、戦闘・ダンジョン規則、全4スキーマは元版と一致。
リリスとミルカは既存本文を変更せず、日常の案内だけを末尾に追記した。
