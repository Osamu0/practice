# 運用詳細シート (M43/M83/M93 確定)

治療・逃走・帰還・野宿・クエスト報酬の決定法。正本。

## 1. 治療 (ノワール大聖堂・エレナ)
- LP 回復: 1LP あたり 2G (全回復まで任意の量)。
- 戦闘不能 (LP0) からの治療: 100G + LP 回復分。
- 状態異常 (毒・麻痺など) の治療: 1つ 50G。
- エロステの全解除: 300G 定額。
- 宿 (200G/人/泊で LP・MP 全回復) との違い: 治療は MP が
  回復しない代わりに、泊まらず即座に受けられる。

## 2. 戦闘からの逃走
- パーティ全員で逃げる場合のみ。味方の最速 SPD + 2d10 vs
  敵の最速 SPD + 2d10 の対抗判定で、成功すれば戦闘終了。
- 失敗したら、そのラウンドの味方の行動は失われ、敵の
  攻撃を受ける。次のラウンドに再挑戦できる。
- ボス戦からは逃げられない。拘束されている者は逃走に
  加われない (置いていくか、拘束を解いてから)。

## 3. ダンジョンからの帰還と野宿
- **帰還の腕輪**は戦闘外なら何度でも使え、即座に安全に宿へ戻る。
  Dungeon_Data の「安全に帰還」はこの方法を指す。戦闘中は使えない。
- 徒歩で階段を上って戻るのも自由。攻略済み階で「通り抜け」を選ぶ時はDungeon_DataのPassageだけを処理し、通常の移動エンカウントを重ねない。未攻略階の徒歩移動中エンカウントはd10で2以下。旧非ボス戦3回上限は廃止。追跡・交戦中は腕輪を使えず、戦闘の逃走規則で退避を試みる。
- 帰還の水晶 (800G / 消耗品): **戦闘中でも使える** (消費・
  有料である代わりに、ピンチからの緊急脱出が利く)。使うと
  即座に街へ帰還できる。ミアとネルの店で買える。
  (2026-11-02 ユーザー決定で M43 初版の「300G・戦闘中不可」から変更)
- 野宿: **パーティ共有で1潜行に1回まで**。階層を移動しても回数は
  復活しない。LP は回復せず、MP は最大値の
  半分まで回復する。野宿の途中で d10 を振り、3以下なら
  敵の襲撃。これは遭遇発生だけを決め、奇襲の自動成立ではない。
  奇襲は襲撃個体の `[奇襲:]` と環境条件を満たす時だけ別に判定する。
- **松明と食料の消費 (M48 B-7)**: 松明はダンジョン1フロアの
  探索につき1本消費する。持っていない階層では暗闇ペナルティ
  (TEC -2) が掛かる場面が出る。携帯食料は野宿1回につき1つ
  消費する。食料なしで野宿すると MP の回復は最大値の1/4まで
  に落ちる。重い飢え判定は入れない (消費の見える化だけ)。

## 4. クエスト報酬の価値目安と精算

### 4.1 M43式は「有償依頼の目標報酬価値」

- 有償依頼をカード化する時、GM が d10 テープで目標価値を決める:
  目標報酬価値 = 範囲の下限 + (d10 の出目 - 1) x 刻み。
  F級: 80 + x7 / E級: 200 + x11 / D級: 400 + x22 /
  C級: 800 + x44 / B級: 3,000 + x777 / A級: 8,000 + x444。
  討伐系の通常ドロップは別会計。
- M83により、この値は「必ず同額の現金を払う式」ではない。金、品物、
  素材、権利、施設利用、割引、サービス、協力、紹介、情報など、依頼者が
  実際に提供できる報酬全体を考える目安である。
- 報酬の種類数に下限・上限はない。無報酬、単一報酬、複合報酬、全種類
  を含む報酬のどれも可能で、物語の自然さを最優先する。
- 善意・無償と明示された依頼、または経済的対価を約束しない個人的な
  頼みでは、目標価値ロールを消費しない。受注前に無報酬と伝える。
- 価値帯を満たすために、貧しい依頼者へ現金を持たせたり、権限のない
  人物へ利用権を発行させたりしない。目安より少ない時は正直に提示する。
- **ギルド級との対応 (M80 で正本化。第2回テストプレイで
  実際に使った対応を正式化した)**: ギルドE級 = F級式
  (80 + x7) / D級 = E級式 (200 + x11) / C級 = C級式
  (800 + x44) / B級 = B級式 (3,000 + x777) / A級 =
  A級式 (8,000 + x444)。D級式 (400 + x22) はギルド級に
  対応させず、級のない臨時仕事の出来高の目安として使う。
  経済的対価のあるイベントクエストだけ、親クエストの
  ギルド級に対応する式を目標価値に使う。無報酬なら振らない (M47/M83)。

### 4.2 報酬構成

- 金成分がある場合、その金額と他の経済的成分を合わせて目標価値を
  参照する。ただし権利・紹介・情報など、価格化が不自然なものへ無理に
  金額を付けない。
- アイテムは Item_Database の価格・売値、サービスは通常料金があれば
  目安にする。材料費、旅費、依頼人の支給品、預かり品の返却は報酬に
  算入しない。
- 報酬成分は、提供者が実際に所有・実行・発行できるものだけ。権利、
  割引、サービス、紹介は対象・場所・回数または期間・条件を限定する。
- 感謝の台詞や好感度変化は報酬価値へ足さない。具体的な行為や利益に
  なる約束だけを reward_contract の component にする。

### 4.3 提示・受取・保留

- 掲示・受注時に、約束された報酬成分、獲得条件、受取時期、受取経路を
  自然な台詞と依頼表示で伝える。報酬がない場合も明示する。
- 金成分が出来高制なら「下限G〜上限G」と表示し、精算時に確定額と
  出来高ロール (d10=X) を示す。固定の品物・権利・サービスは、秘密に
  する物語上の理由がない限り具体的に提示する。
- ギルド依頼は受付での報告精算、直接依頼は依頼人への納品・現地確認、
  生産依頼は支給・前金と納品後残額などを既定例とする。これは強制
  ルートではなく、カードの delivery_plan と合意が正本。
- 獲得済みで受取意思があるが、まだ渡せない成分は
  `world_state.pending_rewards` へ移す。クエスト自体は閉じる。
- プレイヤーは全部、一部、または全報酬を辞退できる。辞退した成分は
  `declined` とし、保留にも所持品にも入れない。辞退への機械的
  ペナルティはない。
- 受領時は `settlement_id/component_id` を照合し、金・品・権利等の実体
  反映、delivered/declined、保留削除、`world_state.reward_ledger`
  への追記を同じ候補セーブで一括確定する。台帳は追記専用で、
  既存成分の消去・書換え・同一IDの再追加をしない。
- delivered成分は反映先の前後ハッシュを `effect` に持ち、金は
  amountと所持金差分も一致させる。台帳だけまたは実体だけの反映にしない。
  ハッシュは候補作成後に runtime の `reward-effect` で取得する。
  itemsは `added_items`、即時の役務・情報等は
  `appended_log_entries` の品名・数量または行番号・行ハッシュも写す。
- 権利・割引・後日サービス等は `entitlements` に
  `source_settlement_id/source_component_id` を保持し、台帳の delivered
  成分と1対1にする。使用済み・期限切れ・取消後もレコードを消さず、
  statusと残回数だけを更新する。

## 6. 自由潜行の収益の考え方 (M48 B-5)
- クエストを伴わない潜行の主収入は **素材の売却** (ドロップ表
  の主ドロップ + 人間型の落とす金)。GM は潜行の成果を提示する
  時、素材の売値をその場で明示する (A-6 と連動)。
- 目安 (GM の運営感覚用。保証値ではない): 1F の潜行1日で
  100〜250G 相当、2F で 200〜400G、3F 以降は階層ごとに
  +100G 程度。クエスト1件分に届かない日があってもよいが、
  「丸一日で数十G」にはならないよう出現とドロップで調整する。

## 5. 宿代の扱い (M69 A-2 で改訂。旧 M48 A-2 を置換)
- 宿代は1人1泊 200G。借金に加算されるのは
  **リーダー本人の分 (200G) のみ** を原則とする。
- 仲間は勧誘時に分担方式を決め、セーブへ記録する
  (`inn_share: self / leader`)。
  - `self`: 就寝時に本人の所持金から自動で引く。
    **現金が不足したら、不足分だけがリーダーの借金に
    回り、その場で必ず一言明示する** (黙って全額を
    借金に倒すことを禁止)。
  - `leader`: リーダーが持ち、借金に加算される。
- プレイヤー本人の分を現金で払う場合は、プレイヤーが
  明示した時だけ可とし、ステータス欄に「宿代 ◯◯G を
  現金で支払い」と必ず明記する。
- 就寝ターンのステータスには宿代の内訳を1行で出す
  (誰が・どう払ったか)。夜ごとに方式が変わることを
  禁止する。説明なしに借金加算と現金払いが混ざる
  運用も禁止。

## 7. お金と時間の細目 (M55 で明文化)
- **装備・アイテムの売却**: 購入価格の 50% が相場
  (素材は Item_Database の売値どおり。銃は M40 の
  買い戻し 50% と同じ線)。換金アイテムの上限 500G は
  Item_Database の規定どおり。
- **分け前の端数**: 報酬や戦利品を折半する時、端数は
  プレイヤー側へ切り上げる。
- **時間の進みの目安**: 街の用事1件・ダンジョン1フロアの
  探索は それぞれ約半日、街と村の往復は 半日〜1日。
  訓練・習得・製作の日数は各規定どおり。これは通常探索等の目安で、
  場面の都合で前後してよい。攻略済み階の通り抜けはM413の3回=1時間帯を使う。時間帯は GM が場面転換で
  宣言する (M44)。

## 8. リリスの五日取立てと段階解禁 (M93/M103/M104)

### 8.1 返済期間と通常返済

- 初期契約は元本10,000G、契約周期 `contract_cycle_index=0`、
  初回取立日は **Day 5**、初回請求額は **500G** とする。
  以後は直前の取立日から必ず5日後に来る。
- ギルド受付または宿の帳場では、手持ち現金からいつでも
  **100G単位**で任意返済できる。借金残高が100G未満なら、
  完済に必要な端数だけを払える。借金残高を超える前払いと、
  次の契約への返済繰越はできない。
- 取立て間の任意返済も、その期間の `cycle_paid` へ加える。
  返済額は同時に所持金から引き、借金元本から減らす。
- クエスト報告時は「完済まで、現在の主ランク帯で約何件分」
  を要約してよい。毎ターン全履歴を表示せず、通常HUDには
  `借金残高 / 次回取立日 / 今回請求額` だけを圧縮表示する。

### 8.2 Day 5ごとの取立て

- 時間を進める処理が `next_collection_day` をまたぐ場合、まず
  その日に止めて `collection_pending=true` にする。戦闘、報酬精算、
  Hシーン等の原子的な場面の途中では割り込まず、その場面が終わった
  直後にリリス本人または影・鏡・夢への投影が現れる。取立てを解決する
  まで、それ以上の日付を進める行動は開始できない。
- 取立てにダイス判定は使わない。プレイヤーは次から明示して選ぶ。
  1. **全額支払う**: 今回請求の残額を払い、さらに任意の追加返済も可。
  2. **一部だけ払う**: 100G単位で払える額を指定する。
  3. **今回は払わない**: 現金を温存し、延滞加算を受ける。
  全額不足でも、一部払いまたは不払いは正規の戦略であり、所持品没収、
  依頼停止、関係値低下、強制的な身体払いへ置き換えない。
- 今期請求額を `D`、前回取立て後から今回までの返済合計を `P` とし、
  `U = max(0, D - min(D, P))` を未払い請求額とする。
  `U > 0` なら延滞加算は次で決め、借金元本へ一度だけ足す。

  `延滞加算 = 10G単位で切り上げ(max(50G, U x 20%))`

  `P=0` の完全不払いだけは最低100Gとする。たとえば請求750Gに
  300G払えば未払い450G・延滞90G、請求1,000Gを全く払わなければ
  延滞200Gである。
- **同じ取立周期中に1Gでも返済していれば**、次回請求額を
  **その周期に1回だけ**+250Gする。分割して2回以上支払っても
  +250Gを重ねない。
  その契約の上限は `2,500G + 500G x contract_cycle_index`
  (第一段階2,500G、第二段階3,000G、第三段階3,500G)。
  一部払いでも増える。完全不払いなら次回請求額は
  据え置く。これにより、支払いを続けるほど要求は重くなる一方、
  現金を貯めるため意図的に見送る余地も残る。
- 全額、一部、不払いのどれでも、解決後は `next_collection_day` を
  **ちょうど+5日**、`cycle_paid=0` とし、同じ日の再取立てや
  支払い結果の振り直しをしない。結果は取立台帳へ追記する。

例 (宿代等を省いた単純例):

| 取立日 | 請求 | 期間中を含む支払 | 延滞 | 次回請求 |
|---|---:|---:|---:|---:|
| Day 5 | 500G | 500G | 0G | 750G |
| Day 10 | 750G | 300G | 90G | 1,000G |
| Day 15 | 1,000G | 0G | 200G | 1,000G |

### 8.3 完済と、終わらない更新契約

- 借金元本が0になった瞬間、その契約を完済として台帳へ残す。
  初回完済は恋愛・物語上の恒久実績であり、その後に新しい借金が
  生じても `world_state.goals.debt_clear` や解禁済みの関係を取り消さない。
- ただしリリスは、恋人・愛人・伴侶になっていても借金だけは免除しない。
  完済と同じ取引で `contract_cycle_index` を1増やし、次の元本を

  `初期元本=10,000G。更新後の新元本=50,000G x contract_cycle_index`

  として自動契約する。第一段階完済後は第二段階50,000G、続いて
  第三段階100,000G、第四段階150,000G。宿代・死に戻り・延滞の既定加算は別。
  リリスにとって借金は主人公と自分を結ぶもの。好意が深まるほど手放したくなく、
  後の更新契約を大きくする。更新時に次の額を明示し、好感度だけを理由に
  返済途中の元本を増額したり、既定外の利息を足したりはしない。
- 更新直後の請求額は `500G + 250G x contract_cycle_index` にリセットし、
  次回取立日は更新日の5日後とする。旧契約で増えた請求額や余剰返済を
  新契約へ持ち越さない。
- 取立日より前でも任意返済によって元本が0になったら、その日に
  早期完済と更新契約を同じtransactionで確定する。旧元本を超える
  返済額は受け取らず、新契約の元本や今期返済へ充当しない。
- **第一段階完済の特典はリリスとの恋愛・親密な関係の解禁だけ。**
  完済前はCHM判定、口説き、好感度、贈り物、夢、スイートルーム、罰や身体払いの
  名目でもリリスは絶対になびかない。内心の一目惚れは未公開の裏設定として保持し、
  初期の火授与・非性的な介抱・冗談は許す。かわす時の呼び方は`partner_pref.call`を使う。
  完済した場面で初めて隠していた強い好意を露わにする。親密な関係を受けるかは
  プレイヤーが選び、拒否や保留で特典・好意を取り消さない。
- **第二段階50,000Gの契約を完済した特典は、リリスとネームドの外見・体型変更。**
  初回完済時点、累計支払額50,000G、取立ての回数、部分払だけでは解禁しない。
  第三段階以降に新しい特典を自動で作らない。旧3択の事業投資・調達網・緊急回収を
  完済のたびに追加する仕組みは、この段階解禁へ置き換える。

### 8.4 外見変更の範囲と確定

- 解禁だけでは誰の姿も変えない。プレイヤーが対象人物と変更内容を指定し、
  変更前後を確認してチャットで「確定」と答えてから適用する。元の姿へ戻すこともできる。
- 変更は現在のキャンペーンの`world_state.appearance_customization`へ保存する。
  人格正本を直接書き換えず、当該人物を読む時だけ該当する外見上書きを添える。
  対象は人格正本に登録されたネームドID。別キャンペーンへ持ち越さない。
- 成人としての年齢・成人性、人物ID、名前、人格、口調、記憶、関係、職業、
  能力、LP/MP、装備の所有と効果は変えない。衣装は見た目の変更だけで、
  新しい防具や追加能力を無料入手した扱いにはしない。
- 外見変更そのものは恋愛成立・同意・加入の代わりにならない。
  対象ごとの好み・交渉・反応は人格に従って物語として描く。

### 8.5 保存と原子的更新

- `debt_state` は最低限、契約ID、周期番号、元本、次回取立日、今回請求、
  今期返済額、取立保留、支払回数、完済実績、解禁表示、追記専用台帳を持つ。
  互換表示の `player.debt` と元本は必ず一致させる。
- 返済では所持金減少・元本減少・今期返済加算を、取立解決では延滞・
  次回日・次回請求・台帳追記を、完済では旧契約完了・新元本・段階解禁を、
  それぞれ一つのtransactionで確定する。片側だけの更新は禁止する。
- 解禁は連続した正規完済台帳から導出する。`debt_clear`、会話ログ、好感度、
  解禁フラグだけの書換えでは権利を得られない。解禁済み権利は次の借金で失わない。
- リリスとの恋愛、好感度、H、身体的な奉仕は返済額を自動で減らさない。
  娼館等で明示された仕事の正規報酬を受け取り、その現金を返済するのは可。
- **収支の見える化**: 就寝→翌朝の節目だけ、「昨日: 報酬 +◯◯G /
  宿代 +◯◯G (借金) / 返済 −◯◯G」の1行を出す。毎ターンには出さない。

## 9. 死に戻りの精算と時間 (M90)

- 現在の遠征に同行する火持ち全員が LP0 になると発動し、その遠征を
  終了して翌朝のぬれねずみ亭へ場面を移す。一時分断・捕縛中でも同じ
  遠征なら発動判定へ含める。宿待機・別行動・別遠征の火持ちは含めない。
- 発動1回につき、発動時の危険帯に応じて借金へ加える。F/E/D級または
  ダンジョン1〜2Fは500G、C級または3〜4Fは1,000G、B級または
  5〜6Fは1,500G、A級または7〜9Fは2,000G。クエストと階層が

  治療・翌朝までの強制休養を含むため、同じ場面転換で通常宿代、

  弾薬、装備劣化、関係、進行状態は巻き戻さない。心的外傷判定と
  「死の恐怖」は発生しない。

  LP0の非火持ちは、その戦闘終了までに救助されなければ死亡する。
