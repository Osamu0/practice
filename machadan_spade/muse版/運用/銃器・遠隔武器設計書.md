# 銃器・遠隔武器設計書 (M40 確定)

アステリアの武器プロフィール (装弾・弾薬プール・騒音・
最小射程) を参考に、マチャダンの式へ落とした遠隔武器の
設計。このファイルを M40 の現行正本として使う。

## 1. 銃という技術の位置づけ
- 銃はこの世界の標準技術ではない。街の店にも敵にもない。
- プレイヤーが仕組みを鍛冶屋のテトラに伝えると、彼女が
  特注で製作する。伝授は1回きりのイベントで判定はなし
  (知識はプレイヤーのもの)。製作には費用・素材・日数が
  かかり、特に上位の銃は高額になる。
- 弾もテトラ製の専用品で、買うたびに弾数を管理する。

## 2. 共通ルール (遠隔武器)
- 命中: [TEC] + 2d10 vs [SPD] + 2d10 (通常攻撃と同じ)。
  痛恨 (2d10合計19以上で威力2倍) も同じ。
- 近接 (接敵) した相手への射撃は命中 -2。ライフルと
  マシンガンは更に -2 (長い銃身が邪魔になる)。
- 守備側が遮蔽物に隠れている場合は状況補正 (M37) で処理。
- 装填: 弾を使い切ったら 1行動で装填する。戦闘外は自由。
  装填中の弾数はセーブに武器ごとに記録する。
- 騒音: 発砲した戦闘では味方の奇襲は成立しない。発砲後は
  そのダンジョン滞在中、敵の奇襲判定の閾値 +1 (警戒)。
  この +1 は `[奇襲: 条件付き30% / 得意50% / 達人80%]` のうち
  条件を満たす敵にだけ適用し、閾値の上限は9。
  `[奇襲: なし]` を奇襲可能には変えない。

## 3. 銃のダメージ
- 銃は STR を使わない。ダメージ = [火力] + 1d6
  - [対象DEF ÷ 2 (切り捨て)]、最低2。火薬の貫通力として
  防具を半分だけ効かせる。
- マシンガン: 1回の攻撃で弾を3発消費し、命中判定を3回
  行う (各命中が通常の銃ダメージ)。外れても弾は消費する。

## 4. 銃カタログ (全てテトラ特注)
- リボルバー: 製作 2,500G + 黒鉄のインゴット×1 +
  鉄鉱石×3 + 魔石の欠片×2、3日。
  片手 / 装弾6 / 火力9 / 重量4。
- ライフル: 製作 4,500G + 黒鉄のインゴット×2 +
  鉄鉱石×3 + 高純度の魔石×1、5日。
  両手 / 装弾5 / 火力12 / 重量6。
- マシンガン: 製作 16,000G + 黒鉄のインゴット×4 +
  高純度の魔石×3 + 巨人の骨×1、14日。
  両手 / 装弾30 / 火力10 (3連射) / 重量11。
- 実包 (全銃共通の規格弾): 6発 30G。テトラの店でのみ
  販売。所持弾数はセーブの所持品に記録する。
- 素材は `世界/Item_Database.md` の [MATERIALS] にある既存素材を使う (黒鉄の
  インゴット、高純度の魔石、鉄鉱石、魔石の欠片、巨人の骨)。

## 5. 弓 (既存の遠隔武器として整備)
- ダメージは通常の物理式 ((STR-DEF)+1d6)。TEC で狙い、
  STR で引く、が本作の弓の形。
- 短弓: 250G / 重量2。長弓: 400G / 重量3、近接命中 -2。
- 矢: 10本 20G の消耗品。戦闘後、使った矢の半分 (切り
  捨て) を回収できる。ダンジョンのドロップにも出る。

## 6. やらないこと
- 銃は NPC・敵には流通させない (テトラとプレイヤーだけ
  の技術)。自動小銃や大砲等の更に上の火器は作らない
  (マシンガンが上限)。
- 弾の口径は分けず、全銃で実包を共通にする (管理を
  1種類に絞る)。

## 7. 接続の確定事項 (2026-11-02)
- 鍛造システムとの関係: 銃は [SYS-Craft_Logic] の Tier
  判定の対象外とし、「銃器レシピ」という専用枠で扱う。
  価格・素材・日数はこの設計書の表が優先する。
- 製作期間: 日数がかかるのは各型の初回製作 (試作) のみ。
  同型の再製作は即日で完成する。注文は同時に2件まで。
- 修理: 酸による装備劣化 (M35) は銃にも適用される。
  修理はテトラのみ、費用は製作費の 10%、即日。
- 売却: 銃はテトラだけが製作費の 50% で買い戻す。
  ミアは素性の知れない技術品を扱わない。
- 装備枠: 銃は武器枠を使う (他の武器と同時装備不可)。
  リボルバーが片手でも、触媒との同時持ちはできない。
- 仲間: 仲間も銃を使える (命中は本人の TEC)。弾は
  パーティ共有のプールから消費する。
- 弾の内訳: 実包はテトラが火薬から調合した完成品として
  売る。素材の内訳は問わない。
- 殴打: 弾がない時の銃での殴打は通常の物理式で、武器
  補正は付かない。
- 暴発・ジャムのルールは設けない (本作の判定にファンブル
  がないことと揃える)。
