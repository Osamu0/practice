# 魔法システム設計書 (M39/M96 確定、2026-11-04 役割分離)

プレイヤー側の魔法の完全設計。アステリアの魔法・自作魔法の
枠組み (ティア制・上限表・作成テンプレート) をマチャダンの
数値系 (2d10対抗、M38 の魔法ダメージ式、能力の実の成長) に
移植した現行正本。このファイルに記載した M44 仕様を使う。

## 1. 基本
- MP: 最大MP = INT合計 (装備・リリスの火込み)。現在MPはセーブ
  に記録する。宿屋に泊まると全回復。エーテル (80G) は MP+8。大 (180G) は MP+16。
- 魔法は誰でも唱えられるが、階位ごとに必要な INT合計があり、
  実用になるのは INT を伸ばした者だけ (習得ゲートは INT のみ)。
- 魔法のセット上限 (同時に使える数) は、ジョブプロフィールの
  `magic_role` だけで決まる (M76、アステリア式)。`noncaster`: 2 /
  `hybrid`: 4 / `caster`: 6 / `specialist`: 8。
  `combat_role` (前衛・後衛・非戦闘) と INT の高さは魔法枠を
  自動変更しない。INT はあくまで階位の習得・使用ゲートである。
  `magic_role` を変える時は転職または明示的な再訓練として
  セーブへ記録し、職業名から推測し直さない。
  習得自体に上限はなく、枠外の魔法は「控え」として残る。
  再セットは まどろみ堂 か宿での休息時に 100G。
- 行動: 戦闘中、魔法は通常攻撃と同じく1行動を使う。

## 3. 式
- 攻撃魔法の命中: [TEC] + 2d10 vs [SPD] + 2d10 (M33 と同じ)。
  痛恨 (2d10合計19以上で威力2倍) も同じ (M35)。
- 攻撃魔法のダメージ: [INT] + 基礎威力 + 1d6 - [対象INT]、
  最低2 (M38 の拡張。基礎威力0の素の魔力攻撃は M38 の式その
  もの)。敵の魔法も同じ式で処理する (敵の基礎威力は個別指定
  がなければ 0。メテオ等の固有技は Dungeon 側の指定どおり)。
- 回復魔法: [INT] + 基礎回復 + 1d6 を回復する。味方への魔法は
  命中判定なし。ただし通常の回復魔法はLP1以上の対象にだけ使え、
  LP0から戦闘不能を解除しない。LP0の戦闘中復帰は気付け薬の役目とする。
- 範囲魔法 (対象が2体以上、または全体) は全て詠唱1ターン
  → 次ターン発動。詠唱中にそのラウンドで LP の 25% 以上の
  ダメージを受けると中断 (M35 と同じ)。単体魔法は即時。
- 魔法による状態付与は、命中後に M35 の付与判定 (d10) を行う。
  魔法でエロステータスは付与しない (エロ攻撃専用の仕組みの
  まま)。魅了系は混乱として扱う。
- 持続中の敵魔法・呪いの解除は INT 対抗 (M33) で行う。

## 4. 標準魔法 (初期カタログ)
攻撃:
- 魔弾 T1 MP2 単体 基礎威力3。最も基本の攻撃魔法。
- 火球 T2 MP4 単体 基礎威力5、炎属性。**炎上**: 命中した敵は次のターン開始時に追加で3ダメージを受ける (M48 B-3。T2以上の攻撃魔法は基礎威力に加えて副次効果を持つ、が原則。氷槍の鈍足・雷霆の痛恨条件低下も同原則)。
- 氷槍 T3 MP6 単体 基礎威力6、命中後に付与判定 (30%) で
  SPD-2 (2ターン)。
- 雷霆 T4 MP9 単体 基礎威力8、痛恨の条件が 18以上に下がる。
- メテオ T5 MP14 全体 (詠唱) 基礎威力6、全ての敵へ。
回復・支援:
- 癒し T1 MP2 単体 基礎回復5。
- 大癒し T3 MP6 単体 基礎回復12。
- 解毒 T1 MP1 単体 毒を治す。
- 解呪 T2 MP3 単体 状態異常を1つ解除 (エロステは除く。
  エロステの通常の解除は聖堂の専管。火による死に戻りが発動した時の
  全回復だけは例外として、保持中のエロステも全解除する)。
- 守りの風 T2 MP4 単体 DEF+2 (3ターン)。
- 疾風 T3 MP5 単体 SPD+2 (3ターン)。
妨害・その他:
- 眠り T2 MP4 単体 命中後に付与判定 (50%) で睡眠 (1ターン
  行動不能、攻撃を受けると起きる)。
- スリープクラウド T4 MP9 全体 (詠唱) 付与判定 (40%) で
  睡眠 (最大2ターン)。対策は睡眠の運用ルール全体で担保
  する (M77: ダメージで目覚める/味方が起こせる/再睡眠への
  耐性/ボス・強敵への閾値 -2/詠唱の中断リスク)。
- 混乱の霧 T4 MP10 全体 (詠唱) 付与判定 (30%) で混乱 (2ターン)。
- 光 T1 MP1 探索用。その場を明るくする (5F の暗闇ペナルティ
  をその戦闘中だけ無効化)。
- 探知 T1 MP1 探索用。近くの罠・隠し扉の有無が分かる
  (発見判定の代わりに確実に有無だけを知る。解除は別途必要)。

## 5. 習得
- 魔導書: 1冊に1つの標準魔法が収録されている。購入または
  入手後、その魔法の必要INTを満たしていれば街で読んで習得
  できる (魔法枠を使う)。魔導書は消費されない (売ることも
  できるが、覚えた魔法は残る)。
- 魔法の古文書 (450G): 中身の分からない魔導書。魔女の店で
  解読すると、その時点で到達可能な階位の標準魔法1つが判明
  する (解読料 100G)。自分で解読する場合は INT の単独判定
  (困難、M84)。
- クエスト報酬・ダンジョンのドロップにも魔導書が出る
  (階位は階層に連動: 1-2F は T1、3-4F は T2、5-6F は T3、
  7F以降は T4、T5 はクエスト報酬と店の特注のみ)。
- 仲間も同じルールで標準魔法を使う (INT と枠はそのキャラの
  値)。敵の術者は標準魔法+固有技。
- 登録時の初期魔法 (M76): `caster` と `specialist` は、必要INTを
  満たす標準魔法を2つ習得済みで始める (魔法使いは「魔弾」+
  もう1つを本人が選択、僧侶は「癒し」+もう1つを選択)。
  `hybrid` は初期パックに明記された場合だけT1を1つ、`noncaster` は
  初期魔法なし。後衛であるだけの踊り子や、非戦闘の村人へ自動で
  魔法を付与しない。後からの魔導書習得は全役割で可能だが、上限は
  それぞれの `magic_role` に従う。

## 6. 自作魔法 (創作)
魔女の店でのみ行う「研究」で作る。アステリアの作成
テンプレートをそのまま使う:
- 名前・色・形・音・由来は完全自由。
- 主効果は1つだけ。副次効果は最大1つ (数値は主効果の半分
  以下)。制約か対処法を最低1つ付ける (例: 詠唱が必要 /
  特定の天候では使えない / 自分も反動を受ける 等)。
- 階位は現在の INT合計で到達可能な範囲まで。MP は階位の
  帯の中。基礎威力・基礎回復・持続は §2 の上限表を超えない。
- 対象・射程・範囲を具体的に決める。範囲魔法は詠唱必須。
- 作れないもの: 鍵や扉を無条件に開ける効果、恒久的な能力
  上昇、人格や同意を書き換える効果、物語の固定結果、
  死者の蘇生、LP0から戦闘不能を解除する魔法。召喚は §11 の
  専用ルールでのみ作れる。
- 研究料: T1 200G / T2 500G / T3 1,000G / T4 2,000G /
  T5 4,000G。1回の訪問で1つまで。完成した魔法は魔法枠を
  1つ使う。自作魔法は本人専用で、他人に教えられない。
- 却下や相談だけでは料金は発生しない。最終形と料金を提示
  し、本人が了承してから完成させる。
- 調整と代償 (M76): 本人が上限表を超える強さを求めたら、
  意向の方向で作る代わりに代償を付ける (MP増/LPコスト/
  反動/発動条件/回数制限/使用後の疲労/借金加算 など)。
  強さに合わせて敵や世界の作りを調整することはしない。
  《魔法の種》は導入しない (料金のみで作れる)。

## 6b. 魔法の強化 (段) (M76)
- 魔法にもスキルと同じ段 (1〜3) がある。段2: 基礎威力・
  基礎回復 +1。段3: さらに +1、または副次効果を1つ追加
  (定義に明記した方)。
- 強化料は 段2 = 800G / 段3 = 2,500G、まどろみ堂での
  研究・訓練で半日。MP や階位の門は変わらない。
- 段は魔法ごとにセーブへ記録し、控えへ移っても保持する。

## 7. 触媒 (魔法武器)
杖・ロッド・オーブ・魔導書は「触媒」として扱う。INT補正は
通常の装備上限 (単一+8/合計+10) の内側。触媒には追加で
「魔法バフ」が付くことがあり、系統ごとに最も大きい1つだけ
が効く (重ねがけしない):
- 威力系: 攻撃魔法の基礎威力 +1〜+2。
- 命中系: 攻撃魔法の命中判定 +1。
- 効率系: 魔法の消費MP -1 (最低1)。
- 安定系: 詠唱の中断条件が LP25% → 35% に緩む。
既存品の具体化:
- 樫の杖 (50G / STR+1 / INT+1 / 重量2) バフなし。
- ルビーロッド (350G / STR+2 / INT+4 / 重量3) 威力系:
  炎属性の魔法だけ基礎威力 +2。
新規品 (魔女の店とドロップ):
- ミスリルロッド (900G / STR+2 / INT+5 / 重量2) 効率系。
- 魔導書「星見の書」 (1,600G / INT+5 / 重量3) 命中系。
  両手が塞がる (触媒は片手扱いだが、この本は両手持ち)。
- 賢者のオーブ (4,500G / INT+8 / 重量2) 威力系 +1、
  かつ安定系。Legend 扱い。

## 8. やらないこと (意図的な除外)
- 召喚は §11 の制約つきでのみ実装する (永続する仲間には
  ならない。仲間はリリスの火の仕組みが専管)。
- フィールド魔法・儀式魔法の枠組みは作らない (探索の粒度
  に合わない)。範囲魔法は詠唱ルールで代替する。
- MP以外のリソース (詠唱時間の細分化、成分材料) は増やさない。

## 9. 魔女の店「まどろみ堂」
場所: 中央広場から入る裏路地の奥。看板は傾いている。
魔導書・触媒・魔法の消耗品を売る、この街で唯一の魔法専門店。
自作魔法の研究と古文書の解読もここで受ける。

## 11. 召喚魔法 (制約つき)
呼び出した存在は永続しない。戦いの間だけの助っ人で、
仲間 (リリスの火) とは別物として扱う。

- 階位: T3 から。標準魔法として T3「精霊のしもべ」、
  T4「炎の戦鬼」、T5「星屑の巨像」を用意する。自作も可
  (名前・姿・属性の演出は自由、役割は攻撃型/壁型/支援型
  から選ぶ)。
- 持続: T3 は 3ターン、T4 は 4ターン、T5 は戦闘終了まで。
  いずれも戦闘が終われば消える。街や探索中は呼び出せない。
- 強さの上限:
  | 階位 | MP | 持続 | TSP上限 | LP上限 |
  |---|---|---|---|---|
  | T3 | 8 | 3ターン | 40 | 20 |
  | T4 | 12 | 4ターン | 52 | 26 |
  | T5 | 18 | 戦闘終了まで | 65 | 32 |
  ステータスの配分は役割に応じて行い、1つの能力が術者の
  対応能力を超えることはない。LP が 0 になれば消滅する。
- 同時に出せるのは 1体だけ。呼び直しは前の召喚が消えて
  から。召喚獣は火を持てず、捕獲もされず、エロ攻撃の
  対象にもならない (実体のない構成体として扱う)。
- 集中 (強い召喚の代償): T4 と T5 の召喚を維持している間、
  術者は操作に集中するため攻撃と魔法ができない (移動、
  アイテム使用、防御、会話は可)。さらに術者がダメージを
  受けたラウンドは INT の単独判定 (標準、M84) を行い、
  失敗すると召喚が霧散する。T3 の召喚は集中不要だが
  上限の範囲で弱い。
- 敵の召喚 (スライムの分裂、ワーカービー等) は従来どおり
  モンスター側の固有能力で、このルールとは別に扱う。

## 12. 運用の確定事項 (2026-11-02 穴埋め)
- 召喚獣の行動権: 召喚獣は独立した行動を1つ持ち、行動順は
  術者の直後に処理する。集中 (T4/T5) の制約は術者側に
  だけかかる。
- 街の時間帯: 朝/昼/夕/夜の4区分で、GM が場面転換ごとに
  宣言する (セーブの time_of_day に記録)。ダンジョンから
  帰還した時は経過後の時間帯を保ち、夕へ巻き戻さない。宿に泊まったら翌朝。プレイヤーの宣言で
  時間を進めることもできる。ダイスでは決めない。
- ネルの寝落ち: 朝は d10 で 2以下なら二度寝中 (昼3以下/
  夕5以下/夜8以下は従来どおり)。起こして買い物できる。
  好感度や判定への数値影響はない (寝ぼけた応対は演出のみ)。
- ダンジョン内の MP 回復: 野宿1回で最大値の半分まで回復
  する (LP は回復しない)。野宿はパーティ共有で1潜行1回までで、
  階層移動で回数は復活しない。途中で
  襲撃判定がある (詳細は運用詳細シート)。
- 魔導書の使い回し: 1冊で何人でも学べる。ただし習得には
  街で半日かける。本を売っても魔法は残る。店の在庫は
  3冊までで、売れた後の再入荷は日替わりで d10 の5以下
  (M76 で緩和)。
- 古文書の解読: 判明する魔法は、拾った階層に対応する
  階位の中から GM が選ぶ (未習得を優先)。その階位の魔法
  を全て習得済みなら解読料は返金され、古文書は既知の
  写本として 300G で売却できる。
- バフの重ねがけ: 同じ系統は重ねがけ不可 (新しい方で
  上書きし、持続は数え直す)。異なる系統は共存できる。
  持続は唱えたターンを1ターン目として数える。味方への
  バフは命中判定なし (自動成功)。
- 敵術者の MP: 敵も MP = INT合計 を持ち、同じ消費で
  魔法を使う。尽きたら物理や通常行動に移る。MP は GM が
  内部で管理する。
- 火の分け直しと MP: 火の付け替えで MP 上限が下がったら、
  現在 MP は新しい上限で切り捨てる。上限が上がっても
  現在 MP は増えない。
