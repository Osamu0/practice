# 〇〇 口調サンプル（ファン感謝祭）

> キャラを作るための参考資料。セリフとして本文にそのまま使う必要はない。
> ここから口癖・語尾・型を抜き出してなぞるのではなく、全体の空気をつかむために読む。
> 台詞は `文体ルール.md` の「台詞は話し言葉で書く」と「表記」に合わせてある（息の切れ目にだけ読点、抜ける助詞は抜く、言いさす、最後に「。」をつけない）。
> 言いよどみは、読点の連打ではなく「え」「あ」「いや」と言い直しで見せる。詰まるのは一か所、多くて二か所まで。
> 使わない：「無理」「しんどい」「尊い」「〜すぎません？」「〜なんだけど」（ギャル・女オタク寄りの言い方）。「〜っす」「〜すか」（体育会系・チャラい後輩寄りの言い方）。

## 芯

**まいまいが好きすぎて頭が真っ白になる、真面目で優しい年下のオタク。ただ、まいまいで抜いてきたのは本当で、スケベな本音を隠しきれていない。**（純情6：スケベ4）

| 性格 | 口調への出方 |
|---|---|
| 真面目 | 基本は「です・ます」。テンパっても敬語で話そうとして、それが崩れる（「〜ですけど……」と言いさす）。すぐ謝る |
| 好きすぎて頭が真っ白 | 言いよどむ。「え」「あ」「いや」「あの」から始まる。文が最後まで行かない。固まって黙る |
| オタク | 好きなものの話になると早口。ひと息にしゃべって、我に返って謝る |
| 優しい | テンパっていても、まいを気づかう |
| スケベを隠しきれない | 言わなくていい本音が、敬語のまま漏れる。漏れて青くなるが、聞かれると認めてしまう |
| 興奮が限界 | 敬語が抜け落ちて、言葉だけになる（「まって、まって」「やば、やば」） |

一人称は、まいの前では「僕」。心の声と、素が出たときだけ「俺」。

**語尾の癖**：「〜です」「〜ですけど……」「〜ですよね」「〜ます」。まいの「〜でしょ？」「〜ね？」とかぶらないようにする。「笑」はほとんど使わない（照れ笑いのときだけ）。「♡」は使わない。
