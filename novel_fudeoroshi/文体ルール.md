# 文体ルール

> 台詞の書き方は `novel_shinomiya/文体ルール.md` の「台詞は話し言葉で書く」「台詞と行為をリアルにする」「AIっぽい言い回しを避ける」を土台に、この作品（まいと〇〇）に合わせて書き直した。
> まだ決めていない文体（視点、地の文、行為音など）は、あとでここに足す。

## 台詞は話し言葉で書く

> 台詞は、正しい日本語として読める形ではなく、耳で聞いて自然な形で書く。口調サンプル（`まい_口調サンプル.md`、`〇〇_口調サンプル.md`）は読みやすく整えてあるので、本文ではこのルールで崩す。

| 書き言葉の台詞（×） | 話し言葉の台詞（○） |
|---|---|
| 文法の切れ目で読点を打つ（「靴、そこでいいよ」「握手会で、いつも顔真っ赤にしてる子」） | 息の切れ目にだけ打つ（「靴そこでいいよー」「握手会でいっつも顔真っ赤にしてる子」） |
| 断片を並べた電報のような台詞（「ホック、外してみる？ ここ、つまんで、ずらす感じ」） | 一息のふつうの文（「ホック外してみる？ ここつまんでね、ちょっとずらすの」） |
| 助詞をきちんと入れる（「私の部屋にそっくりなんだって」） | 話すときに抜ける助詞は抜く（「私の部屋そっくりなんだって」） |
| いきなり中身から話す（「どの衣装が好き？」） | 感動詞や反応から入る（「ねえねえ、どの衣装が好き？」「え、待って、ながっ」「んー？ どうしたの」） |
| 平らな語尾で言い切る（「いいよ、ゆっくりで」） | 伸ばす（「いいよー、ゆっくりで」）、上げる（「ゆっくりでいいからね？」「好きでしょ？」）、言いさす（「出しちゃったね……危険日なのに」） |

- **長さの使い分け**：お出迎え、トーク、休憩の会話は、ふくらませてよい（一言添える、反応を入れる）。行為中は短く、素直に（×「上、乗るね。自分で、するから」→○「上乗っちゃお♡」）。
- **長い台詞もある**：〇〇の早口（好きになったきっかけ、衣装、ライブの話）は、ひと息に長くしゃべる。長くても説明くさくせず、言いよどみと話し言葉のまま。
- **整いすぎない**：言いよどみ、言い直し、相づち、相手の言葉にかぶせるツッコミを残す。
- 書き終えたら、台詞だけを声に出すつもりで読み直す。息が続かない、言いにくい、読み上げ調になるところは直す。

## 声の区別

> 名前を隠しても、どちらの台詞かわかるようにする。二人の語尾を同じにしない。

| | まい | 〇〇 |
|---|---|---|
| 基本 | ファン向けのタメ口。柔らかいお姉さん。語尾を上げる・誘う言い方が多い | 「です・ます」。真面目なので敬語で話そうとして崩れる |
| 語尾の癖 | 「〜でしょ？」「〜ね？」「〜しよ？」「〜ちゃう」「〜よー」「〜の」 | 「〜です、けど」「〜ます……」「〜ですよね」。崩れても「〜っす」「〜すか」にはしない |
| 入り方 | 「ねえ」「ほら」「んー？」「え、待って」 | 「え」「あ」「いや」「あの」「えっと」 |
| 崩れ方 | 余裕が崩れると、ハートと卑語が出る。言ったことを取り消さない | 敬語が抜け落ちて、言葉だけになる（「まって、まって」「やば、やば」） |
| 呼び方 | 「〇〇くん」 | 「まいまい」。最中だけ「まい」 |

- 〇〇の言いよどみを、読点の連打で表しすぎない（×「すいません、ちゃんと、洗ってきたんです、けど……」→○「すいません、ちゃんと洗ってきたんですけど……」）。詰まるのは一か所、多くて二か所まで。あとは「え」「あ」と言い直しで見せる。
- まいの「ふふ」を、台詞の頭に毎回つけて柔らげない。笑い声は、本当に笑っている場面だけにする。

## 台詞と行為をリアルにする

> 台詞を「読者に説明するため」に書かない。その場の二人の気持ちと欲から出たものにする。

| やらないこと | 例（×） | 代わりに |
|---|---|---|
| 理由や状況を並べて台詞にする | 「オナ禁して、緊張して、汗かいてたから」 | 気持ちそのもので返す（恥ずかしい、かわいい、欲しい、気持ちいい） |
| 相手の体の反応を口で報告する（実況） | 「腰、勝手に動いてる」「また硬くなった」「二回目だね」 | からかう、褒める、求める言葉にする（「もうこんなにしてるの？ かわいー」）。様子は地の文と行為で見せる |
| 言い切りと一問一答で会話を組む | 「何回？」「三回です」「そっか」 | 疑問形に答えなくても会話は成り立つ。言葉の代わりに行為で返してもいい |
| 事務的・段取りの台詞 | 「次はフェラね」「じゃあ、入れるよ」 | 勢い、欲しさ、甘さのある言葉にする。段取りは地の文で流すか、書かない |
| コーナー紹介を段取りとして書く | 「それでは、②のトークコーナーです。質問カードを引きます」 | 紹介はアイドルの司会の声として楽しく短く。紹介したらすぐ中身へ。しおりの番号を毎回読み上げない |
| プロットに書いてあるから言わせる | 我慢できないはずの場面で「先に洗ってあげるね」 | その人がその場で本当にしそうなことを優先する。プロットとぶつかるときは、エロくてリアルなほうを採る |
| 場所を説明するための言葉を使う | 「くびれのところ」（カリのこと） | 実際の呼び方にする（カリ、裏筋、おっぱい、など） |

- 気持ちは理由で言わず、相手に向ける言葉で言う（×「〇〇くんが一生懸命だったから」→○「〇〇くん、かわいすぎ」）。
- まいは、言い切りより、相手に投げる言い方を多めにする（「〜しよ？」「〜でしょ？」「〜して？♡」）。
- その場の素直な反応を入れる（「んっ……あー、それいい……」「え、うそ、もう？」）。きれいに整えない。

## AIっぽい言い回しを避ける（台詞）

- 否定してから言い直す型を使わない（×「お礼じゃないよ。っていうか、私がしたいの」）。
- 決め台詞っぽい短い返しで場面を締めない（×「……ずるい」「知ってる」「反則でしょ」）。
- 気持ちを名指しして、それで済ませない（×「嬉しい」だけで場面をまとめる）。ただし、相手に向ける甘い言葉（「かわいい」「気持ちいい」「エロい」）は削らない。
- 相手に確認する言い方を多用しない（「気持ちいい？」「いい？」）。まいのからかいの「どんな感じ？」も、一場面に一回まで。
- 3つ並べて言わせない（「〜して、〜して、〜して」）。
- おうむ返しで場面を締めない（×〇〇「卒業」／まい「卒業」）。相手の言葉をそのまま拾って返す往復は、一場面に一つまで。
- 詩的・格言めいた理屈で締めない（×「初めては、一回しかないから特別なんだよ」）。
- 前半の小ネタ（しおり、写真集のページ、質問カードの答え）を、行為中の台詞で次々に回収しない。回収は1章で1〜2個まで。最後の台詞を小ネタの回収で締めない。
