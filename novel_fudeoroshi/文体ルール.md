# 文体ルール

> 文体の土台は、スキル `spicy_novel_writing_jp`（`.claude/skills/spicy_novel_writing_jp/`）。台詞の話し言葉と温度、リアルにする、AIっぽさ、地の文、擬音と口の音、♡の量、「……」の台詞、心の声、執筆チームは、スキルのとおり。
> ここには、この作品だけで決めたことと、スキルとの違いだけを書く（スキルの `reference/work_setup.md` の一覧に沿う）。
> まだ決めていないもの（視点、喘ぎ声の具体、擬音の下げ方など）は、あとで足す。

## 作品ごとに決めたこと

| 項目 | この作品 |
|---|---|
| 作品の芯 | ファン感謝祭。〇〇にとって一生忘れられない最高の思い出。読後感は甘く、幸せ。まいは最後までアイドル |
| 視点 | 未定 |
| 心の声 | 二人とも書いてよい。まいは、外では余裕のお姉さんの顔のまま、心の声では崩れている、のずれに使う。〇〇は「あのまいまいが」の実感と、表の仕事で知っていたことの答え合わせに使う |
| 語り手の声 | 未定 |
| ♡・笑 | まいはどちらもよく使う。〇〇は「笑」をほとんど使わず（照れ笑いのときだけ）、「♡」は使わない |
| 「、、、」 | 未定 |
| 喘ぎ声 | 場面で固定しない。その都度、まいがどれだけ感じているかで決める（レベル1〜4すべて可） |
| 表記 | スキルの既定のまま（台詞の前に名前、「（笑）」なし、台詞末の「。」なし、「？」「！」のあとに全角スペース） |
| 男の台詞の温度 | 受け身の童貞。主導はまい（スキルの「男は落ち着いて言い切る」型は〇〇には使わない。まいの小悪魔の余裕のほうに使える） |

## 声の区別

| | まい | 〇〇 |
|---|---|---|
| 基本 | ファン向けのタメ口。柔らかいお姉さん。語尾を上げる・誘う言い方が多い | 「です・ます」。真面目なので敬語で話そうとして崩れる |
| 語尾の癖 | 「〜でしょ？」「〜ね？」「〜しよ？」「〜ちゃう」「〜よー」「〜の」 | 「〜ですけど……」「〜ます……」「〜ですよね」。崩れても「〜っす」「〜すか」にはしない |
| 入り方 | 「ねえ」「ほら」「んー？」「え、待って」 | 「え」「あ」「いや」「あの」「えっと」 |
| 崩れ方 | 余裕が崩れると、♡と卑語が出る。言ったことを取り消さない | 敬語が抜け落ちて、言葉だけになる（「まって、まって」「やば、やば」） |
| 呼び方 | 「〇〇くん」 | 「まいまい」。最中だけ「まい」 |
| 心の声の一人称 | 「私」「まい」 | 「俺」（外では「僕」） |

- まいの「ふふ」を、台詞の頭に毎回つけて柔らげない。
- 〇〇の早口（好きになったきっかけ、衣装、ライブの話）は、ひと息に長くしゃべる。

## この作品だけの注意

- コーナー紹介を段取りとして書かない（×「それでは、②のトークコーナーです。質問カードを引きます」）。紹介はアイドルの司会の声として楽しく短く。紹介したらすぐ中身へ。しおりの番号を毎回読み上げない。
- 感謝の言葉は〇〇個人に向ける（「〇〇くんみたいなファン」「ファンのみんな」と一般化しない）。
- お出迎え、コーナー紹介、アイドルとしての言葉、お見送りには、下品な言葉を混ぜない。
- 前半の小ネタ（しおり、写真集のページ、質問カードの答え）を、行為中の台詞で次々に回収しない。
