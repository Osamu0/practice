# 設定資料

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。実在のグループやメンバーの名前・特徴は使いません。
> 『桜ヶ丘40』（`novel_idol`）の別世界線。本編の出来事は、この世界では起きていない。

## 作品の芯

- **最高の思い出**：〇〇にとって、一生忘れられない一日にする。読後感は甘く、幸せ
- **アイドルらしさを残す**：まいは最初から最後までアイドル。脱いでも、乱れても、ファンを大事にする「推し」のまま。素の女の子に戻りきらない
- **甘やかし寄りの小悪魔**：まいが主導して、〇〇の初めてを一つずつ奪う。優しく導きつつ、からかって反応を楽しむ
- **まいも楽しむ**：仕事として慣れているが、義務ではない。まい自身のやりたいプレイ・シチュエーションも入れる

## アイドルらしさの出し方

> 全部を毎回入れるのではなく、場面に合うものを選ぶ。

- **迎え方**：玄関で「感謝祭へようこそ」。握手会と同じ笑顔、同じ声
- **握手会の続き**：最初の「初めて」（手をつなぐ）は、握手会の握手から始める。「いつも来てくれてるよね、知ってるよ」と認知を伝える
- **ファンへの言葉**：「いつも応援ありがとう」「〇〇くんのおかげで頑張れてる」を、行為の途中にも混ぜる
- **ステージ衣装**：まいが自分で選んで着替える。〇〇がライブで一番好きだった衣装を当てる、など
- **私だけのライブ**：リビングで一曲だけ歌って踊る。ペンライトを振らせる。そのまま衣装で
- **レス**：ライブのレス（指差し、ウインク、投げキス）を、至近距離で、ベッドの上でやる
- **アイドルの決め台詞**：自己紹介のフレーズや、ライブのコール＆レスポンスを、エロの中で使う（〇〇が返してしまう）
- **サイン・チェキ**：帰り際にサイン。チェキは撮るが持ち帰れない、など
- **表の顔とのつながり**：テレビで見ている笑顔のまま、していることがエロい。〇〇の心の声に「あのまいまいが」の実感を何度か戻す

## まいのやりたいこと

> まい自身がしたいプレイ・シチュエーション。仕事のためではなく、まいが楽しみにしている。〇〇の「初めて」と重ねて入れる。採用するものはアウトラインで決める。

| やりたいこと | 理由・空気 |
|---|---|
| 童貞の子の「初めての顔」を見ること | 感謝祭で一番の楽しみ。入れた瞬間の顔、イった瞬間の顔をじっと見る |
| ステージ衣装のまますること | アイドルの自分のまま抱かれたい。衣装を汚す背徳感 |
| 全身鏡の前で、後ろから | 自分がアイドルの顔のまま乱れるところを、〇〇と一緒に見たい |
| ファンに名前を呼び捨てにされること | ふだんは「まいまい」としか呼ばれない。最中に「まい」と呼ばれたい |
| 我慢しないで、中に出してもらうこと | 感謝祭だから、ファンに全部あげたい |
| 自分のライブ映像を流しながら | テレビにライブを流して、その前でする。画面の自分と、今の自分 |
| お風呂で洗いっこ | 甘やかしたい。泡で遊ぶ、そのまま |
