# アウトライン

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> 設定は `企画メモ.md`、文体は同ファイルの「文体」の節と `文体サンプル.md` を参照。

## プロットの形

各話のプロットは、場面ごとに次の5つを書く（スキルの5セクション形式より軽くしている）。
- **流れ**：場面で起きることを、順番に
- **決め台詞**：確定させる台詞（伏線になる台詞や、決め台詞）。ほかの台詞は本文で自由に書く
- **エロの中身**：体位、行為、喘ぎ声のレベル
- **位置関係**：誰がどこにいて、どちらを向いて、手や口が何をしているか。書く側の確認用で、本文では説明しない
- **感情の流れ**：その場面で、女の子の気持ちがどう動くか

## 第1部 まい編

### 堕ち方の考え方

初回で堕ちて、もう戻らない。そのあとは、堕ちた先でさらに深まっていく。

- **初回**：最初は照れて、お姉さんぶって余裕を見せようとする。でも途中で崩れて、最後はレベル4まで行く。ここで堕ちる
- **事後**：男の前では、もう表に戻らない。恥ずかしがるとしても、それは堕ちた子の照れであって、元のまいに戻るわけではない
- **2回目以降**：堕ちるための回ではなく、堕ちたまいが、さらに淫らになっていく回（自分から誘うようになる、知らなかったことを覚えていく、場所や状況が大胆になる、など）
- 表（仕事やファンの前）では、これまでどおり取り繕う（`企画メモ.md` の「堕ちたあとの姿」のルールのまま）

### 話の並び（全5話くらい。話数は仮）

各話の文字数はそろえなくていい。話の区切りは内容で決める。

| 話 | 内容 | まいの状態 |
|---|---|---|
| 1 | 握手会。1回目でなぜかハメられたくなり、2回目で連絡先を渡す | 表のまま。内心だけ揺れている |
| 2 | 連絡を取り合い、会う約束をする | 表のまま。LINEで少しだけ素が出る |
| 3 | 初回。人目につきにくい店で会い、「バレるかも」という口実で、近くのまいの家へ移る。照れや余裕が途中で崩れ、最後はレベル4まで | ここで堕ちる |
| 4〜5 | 堕ちたまいが、回ごとにさらに淫らになっていく（2話くらい） | 男の前では、もう戻らない |

### 会う場所

- 初回（3話）はまいの家（店から近い）。2回目以降は〇〇の部屋（ゆの編で、まいが〇〇の部屋に入るところをゆのが見るため）。移る理由は物語で決める（候補：まいの家はマネージャーやメンバーが来ることがあって落ち着かない、〇〇の家も近い、など）

### ゆの編への橋渡し（4〜5話の中に置いておく）

- まいが〇〇の部屋に通っている（ゆのが跡をつけて、部屋に入るところを見るため）
- まいと〇〇のLINEのやりとりが増えている（ゆのがチラッと見るため）
- 仕事中のまいの調子がよさそう。表では取り繕っているので、メンバーにはただ「最近いい感じ」に見える（ゆのが気になるきっかけ）

## 第2部 ゆの編

- **まい編からの時間**：数週間くらい

### 堕ち方の考え方

見てから堕ちるまでに、溜めを2段階つくる。まいの「一気に堕ちる」とは違う堕ち方にする。

1. **跡をつけた日**：まいが〇〇の部屋に入るのと、出てくるのを見る。その日は何もせずに帰る
2. **それから何日か**：見たものが頭から離れない
3. **仕事の合間**：我慢できずに、短い時間を見つけて〇〇の部屋へ行き、ピンポンする。手や口まで行くが、次の仕事の時間が来て、名残惜しく帰る
4. **その夜**：仕事が終わってすぐ戻ってきて、堕ちる

堕ちたあとは、まいと同じく、男の前ではもう戻らない。

### まいとゆのがお互いを知る流れ（5〜6話の中）

1. ゆのが、まいに打ち明ける（「実は、見てしまった」「私も〇〇くんと」）。おとなしく見えて内面は受け身ではないので、自分から言いに行く（理由：〇〇とのことが好きになってしまって、その話をできる相手がほしくなる。いるとしたら、同じ秘密を持っているまいだけ）
2. まいが一瞬焦る。理由は嫉妬ではなく、アイドルとしての秘密（グループの顔が一般のファンと関係を持っていること）をメンバーに知られたから
3. 打ち明けたゆのも同じ秘密を抱えているとわかって、まいは安心する
4. 秘密を共有した共犯になる → 3人で一緒にするようになる（そのきっかけは未定。物語で決めてもいい）

- 修羅場にはしない。嫉妬ではないので、取り合いにならない
- この共犯関係が、第3部の「2人で作戦を立てる」につながる

## 第3部 あおい編

- **ゆの編からの時間**：数週間〜数か月（どちらでもいい）

### 堕ち方の考え方

あおいの弱点は、褒められると照れて、うれしさを隠しきれないこと。まいとゆのは同期なのでそれを知っていて、力ずくではなく、褒めて、照れさせて、隠しきれなくさせる。あおいにとっての「堕ちる」は、正面から言えなかった本音を、照れずに言ってしまうこと。

一晩の中で、3人がかりで段階的に崩されて堕ちる（まいは初回で一気に、ゆのは2段階の溜めのあと自分から戻って堕ちる、のと区別する）。

**役割**
| 役 | すること |
|---|---|
| まいとゆの（サポート役） | あおいを崩していく。お酒、褒め言葉、愛撫、自分たちが乱れて見せる見本で、あおいの照れや控えめさを少しずつはがす。具体的には、飲みに誘ってお酒をすすめる、話題をそっちへ持っていく、安心させる（「大丈夫だよ」）、褒める、両側から抱きしめる・服を脱がせる・耳や首筋や胸に触れる・キスをする、〇〇が入るときに身体を支える・脚を開かせる、本番の最中に表情を見て声をかける・照れを煽る |
| 〇〇 | トドメを刺す。2人が崩したところに本番で入って、あおいが抑えていたものを決壊させる |
| あおい | 最後の一言を自分で言う。罠にかけられて始まっても、最後の一言は自分のものなので、無理やりだったという後味が残らない |

**お酒の線**：少しゆるむ程度。酔いつぶれさせたり、意識がない状態にしたりはしない。あおいは最後まで状況がわかっている。

### 流れ

1. **作戦**：まいとゆのが作戦を立てる。人見知りのあおいが来なくならないように、〇〇は奥の部屋で待たせることにする（読者は〇〇が奥にいることを、この場面で知る）
2. **3人で飲む**：まいの部屋で、同期3人の飲み会。あおいはリラックスしている
3. **〇〇が出てくる**：酔いが少し回ったころ、奥から〇〇が出てくる。まいが「実は最初からいたの。言ったら来ないと思って」と正直に明かす。あおいは「……いや、普通に言ってよ」
4. **知り合いとして加わる**：ファンだとわかると、あおいは丁寧に挨拶する。4人で飲み続けるうちに、まいとゆのが表の顔を崩していき、場の空気が変わっていく
5. **2人が崩す**：まいとゆのが、あおいの両側から触れながら、耳元で褒める。照れ隠しが追いつかなくなる
6. **〇〇がトドメを刺す**：控えめな声が抑えきれなくなり、〇〇への敬語も崩れる。自分に期待しすぎない性格なので、どこかで「まあ、いいか」と力が抜ける
7. **本音を言う**：照れも冗談もなしで、正面から「……もっと、して」。ここで堕ちる

| 2 | まいとゆのが、誰にするか考えて、作戦を立てる（流れの1） |
| 3 | 3人で飲む → 〇〇が出てくる → 4人で飲むうちに空気が変わる（流れの2〜4） |
| 4 | 2人が崩す → 〇〇がトドメ → 本音を言って堕ちる（流れの5〜7） |
| 5〜6 | 堕ちたあおい（2話くらい） |

### めい編への橋渡し（5〜6話の中に置いておく）

- 〇〇の部屋にアイドル3人が出入りするのは人目がやばい（5話のあおいの一言）→ 会う場所を散らす。〇〇の部屋、まいの家、ゆのの家、あおいの家と毎回変え、ときどき仕事の場でも会う（めいが仕事の場で目撃するため）
- 仕事の場は、握手会の最中のイベント会場（大きな展示施設やホール）の、共用の備品倉庫や物置。〇〇は、ファンとして会場に来ていて、握手の合間に、一般の側から裏の通路を通って入る。メンバーは休憩の時間に控室を抜けて、そこで〇〇と落ち合う
- 握手会ではメンバーごとに休憩の時間がずれるので、その休憩の時間を使って1人ずつ抜ける、という決まりをつくる。同時にいなくなると怪しまれるため（めいが目撃するのが、ゆの1人の番になるため）

## 第4部 めい編

- **あおい編からの時間**：数週間〜数か月（どちらでもいい）
- **めいが現場を目撃する場所**：仕事の場
- **仕事の場の形**：握手会の最中のイベント会場（大きな展示施設やホール）の、共用の備品倉庫や物置。〇〇は、ファンとして会場に来ていて、握手の合間に、一般の側から裏の通路を通って入る。メンバーは休憩の時間に控室を抜けて、そこで〇〇と落ち合う
- **3人の動き**：メンバーごとに休憩の時間がずれるのを使って、3人は1人ずつ抜けて、倉庫で〇〇と落ち合う、と決めている。めいが目撃するのは、そのうちの1人の番
- **倉庫の場面の体勢**：狭いので、立ちバック、壁や棚に手をつく、抱え上げる、などが中心。棚の高さや広さは、プロットで決めておく（物理的に無理な体勢にしない）
- **めいが目撃するのは**：ゆのの番。気づいて、めいを中に入れるのもゆの

### 堕ち方の考え方

ゆのが手ほどきしながら、めいが見られる側に回る（「後輩が先輩に導かれて堕ちる」と「見る側から、見られる側へ」の組み合わせ）。

- ゆのが先輩として、〇〇とのやり方をめいに教えながら進める（「こうするといいよ」「大丈夫、ゆっくりでいいから」）。めいは、教わったとおりに素直にやってみる
- さっきまで隠れて見ていためいが、今度はゆのに見られながら〇〇とする。素直な反応が全部顔に出る子なので、それを先輩に見られる恥ずかしさが、そのまま快感になる
- 見て堕ちたゆのが、今度は見ていた子を引き入れて教える側に回る。第2部と第4部が対になる
- **先輩に混じる**：いきなり〇〇と2人きりになるのではなく、ゆのと〇〇がしているところに、めいが加わる（ゆの・めい・〇〇の3人）。先輩と一緒だから飛び込める
  1. ゆのに「おいで」と声をかけられ、めいは自分から中に入る。ゆのは手取り足取り教えるのではなく、場所を空けて、ときどき一言かけるくらい
  2. 1回目の休憩：めいは、ゆのの横に並んで、ゆののしていることを見て真似しながら〇〇に触れる。ゆのと交互に咥え、少しだけ挿入したところで、休憩の終わりが来て、それぞれのレーンに戻る
  3. めいは握手会に戻るが、我慢できずに、すぐに理由をつけて（衣装を直す、など）レーンを離れ、一人で倉庫に戻る
  4. 2回目：ゆのはいない。めいが、ゆのを見て覚えたことを自分でやってみて、〇〇と最後まで行き、ここで堕ちる
- 1回目は、ゆのがすぐ隣にいるので、めいの素直な反応は、全部いちばん近くで見られる
- めいは隠れてオナニーを始めていたくらいなので、怖がらない。恥ずかしさはあっても、期待と欲しい気持ちが勝っている
- めいの性の経験は「詰めすぎない」のまま（混じる形なら、処女でなくても「先輩に混じって教わる」が成り立つ）
- **オナニーを始めるきっかけ**：憧れの先輩の、知らない顔。いつも穏やかで優しいゆのが、見たことのない顔で乱れている。胸がざわついて、目が離せなくなり、そのまま始めてしまう（理由は軽く添える程度）

## 第5部以降

4人がそろってからの話。

- **第4部からの時間**：数か月。めいが加わってからも、何か月も経っている
- **4人の状態**：4人とも、とっくに堕ちきっている。〇〇がいるのが当たり前の毎日になっている
- **会い方**：〇〇の部屋、それぞれの家、ときどき握手会の倉庫。〇〇は、4人の家に通い慣れている。2人や3人で会う日もある。4人同時はまだ（「アブノーマル」に取っておく）
- **〇〇**：遠慮はもうない。4人の呼び方は、「ちゃん」と呼び捨てを自然に行き来する
