# 番外編 洗ってないちんぽ 1話：まい

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> 番外編の共通の決まりは `アウトライン.md` の「番外編 洗ってないちんぽ」を参照。

まいは長いツアーで二週間会えない。出発の前の夜、まいが「帰ってくるまで、洗わないで」とねだる。〇〇は約束を守る。帰ってきたまいの前に出てくるのは、カリ首にびっしりチンカスがこびりつき、吐き気がこみあげるほどの激臭を放つちんぽ。まいは面倒見のいいお姉さんの芯のまま、それを全部「きれいにしてあげる」ことに溺れる。

- **まい**：完堕ち。尽くすこと、奉仕することに溺れる。「まいが、きれいにしてあげる」。えずいても、えずいても、やめない
- **〇〇**：タメ口。二週間、言われたとおり洗わずにいた。恥ずかしさと、まいがどうするのか見たい欲

## 場面1：約束

- **流れ**：二週間のツアーに出る前の夜、〇〇の部屋。事後、まいが〇〇のちんぽを握ったまま、「ね、帰ってくるまで、洗わないで」とねだる。「お風呂は入っていいけど、ここだけは、だめ」。〇〇は笑って冗談だと思うが、まいは本気で、指切りまでする。ツアー中、まいは毎晩LINEで『洗ってない？』と聞いてくる。〇〇は『洗ってない』と返すたびに、下着の中の匂いが強くなっていくのを自分でも感じる
- **決め台詞**：まい「帰ってくるまで、ここだけ、洗わないで」（方向。言い回しは本文で調整する）
- **エロの中身**：事後の手コキで余韻。ツアー中のLINE
- **位置関係**：〇〇のベッド
- **感情の流れ**：（まい）二週間も会えないのがつらい → 帰ってきたときの楽しみがほしい （〇〇）冗談だと思った → 本気だった → 毎日、自分の匂いが変わっていく

## 場面2：二週間ぶり

- **流れ**：ツアー最終日の夜、まいがキャリーケースを引いたまま〇〇の部屋に来る。玄関でまずキスをして、まいはすぐにしゃがむ。下着の上からもう匂う。下ろした瞬間、むわっと立ちのぼる激臭。まいは一瞬、顔をそむけて「う゛っ……」とえずく。目に涙がにじむ。カリ首の溝に、白く黄ばんだチンカスがびっしり、皮の内側にも層になってこびりついている。まいは涙目のまま、それでも鼻を近づける。もう一度えずく。それなのに、脚のあいだがどろどろに濡れていく。「くさい……♡　くさすぎる……♡　でも、これ、まいのために、ためてくれたんだ……♡」
- **決め台詞**：まい「……ちゃんと、まもってくれたんだ……♡」（方向）
- **エロの中身**：激臭への反応（えずき、涙、それでも嗅ぐ）。チンカスの描写（色、こびりつき方、層）。匂いだけで濡れる
- **位置関係**：狭い玄関。まいがしゃがみ、〇〇は立ったまま
- **感情の流れ**：（まい）会いたかった → 激臭にえずく → 約束を守ってくれたのがうれしい → 匂いに負けていく （〇〇）引かれるかと思った → まいまいが、えずきながら、鼻を寄せてくる

## 場面3：きれいにしてあげる

- **流れ**：まいは〇〇をベッドの縁に座らせて、脚のあいだに膝をつく。「まいが、ぜんぶ、きれいにしてあげるね」。舌の先で、カリ首の溝のチンカスを少しずつこそげ取る。舌に乗った白いかすを、口を開けて〇〇に見せてから、味わって飲みこむ。こみあげるえずきを、何度も飲みこむ。溝を一周、もう一周。皮の内側も、指でめくって舐め取る。竿、玉の裏、根元の毛の中まで。全部きれいになると、「ぴかぴか」と笑って、そのまま喉の奥まで咥える。〇〇はまいの口の中に出す。まいは、チンカスの残りと一緒に精液を飲みこむ
- **決め台詞**：まい「まいが、ぜんぶ、きれいにしてあげるね……♡」（方向）
- **エロの中身**：舌でチンカスをこそげ取る（カリ首の溝、皮の内側、竿、玉の裏、根元）。舌に乗せて見せる、味わう、飲みこむ。えずきをこらえる。お掃除が終わってからの喉奥フェラ、口内射精、ごっくん。喘ぎ声は咥えたままのくぐもった声、レベル3
- **位置関係**：〇〇がベッドの縁に座り、まいが床に膝をつく
- **感情の流れ**：（まい）尽くしたい → 汚いものを、まいの口で → えずいても、やめたくない → きれいにできたのがうれしい → 味がもっとほしい （〇〇）まいまいの舌が、自分の汚れを、一つ残らず

## 場面4：ごほうび

- **流れ**：きれいにしたちんぽで、まいはベッドに仰向けになって脚を開く。「ごほうび、ちょうだい」。正常位、まいは脚を絡めて抜かせない。二週間ぶんを、抜かずに何度も中に出す。最後にまいは、〇〇の首に腕を回して、耳もとで「また、ためてね」とささやく
- **決め台詞**：なし（例：まい「……また、ためてね……♡」）
- **エロの中身**：正常位（だいしゅきホールド）、抜かずの連続中出し、連続絶頂。喘ぎ声はレベル4
- **位置関係**：〇〇のベッド。まいが仰向け、〇〇が上から
- **感情の流れ**：（まい）尽くしたあとに、めちゃくちゃにされる → 次も、ためてほしい （〇〇）また二週間、我慢するのか、と思うのに、もう楽しみになっている
