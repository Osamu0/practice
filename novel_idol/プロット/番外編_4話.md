# 番外編 洗ってないちんぽ 4話：めい

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> 番外編の共通の決まりは `アウトライン.md` の「番外編 洗ってないちんぽ」を参照。

先輩たちから「洗ってないちんぽ」の話を聞いた後輩のめいが、素直に「めいも、やってみたいです」と言い出す。初めての激臭に、めいは本気でえずいて涙と鼻水まで出す。それでも「やってみます」の前向きさで、全部受けとめようとする。考えながら話すので一文がまとまらず、崩れると博多弁が混ざる。

- **めい**：完堕ち。素直さは、何でも受け入れて全部顔に出すほうへ。「やってみます」は、どんなことでも試したがるに。前向きさは、もっと気持ちよくなろうとする向上心に。一人称は「私」と「めい」。〇〇を「〇〇さん」と呼ぶ。博多弁が混ざる（濃くしすぎない）
- **〇〇**：タメ口。めいのまっすぐさに、調子に乗る。わざと聞く、言わせる

## 場面1：めいも、やってみたいです

- **流れ**：めいの家（または〇〇の部屋）。めいが〇〇の腕にくっついて、もじもじしながら切り出す。「あの、こないだ、まいさんたちが話してて……その、洗ってない、っていうの……」「めいも、やってみたいです」。〇〇が「くさいよ？　ほんとに」と言うと、めいは「がんばります……！」。一週間後に会う約束をする
- **決め台詞**：めい「めいも、やってみたいです……！」（方向）
- **エロの中身**：なし（めいの素直なおねだり、キス）
- **位置関係**：めいの家のソファ
- **感情の流れ**：（めい）先輩たちの話を聞いて、ずっと気になってた → 言えた （〇〇）めいちゃんが、目をきらきらさせて

## 場面2：はじめての匂い

- **流れ**：一週間後、〇〇の部屋。めいは正座して、〇〇がズボンを下ろすのを待っている。下着を下ろした瞬間、激臭がめいの顔を直撃する。めいは「ぅ゛っ……！？」と口を押さえて、本気でえずく。涙と鼻水まで出る。「く、くさか……っ、なんこれ……っ」（博多弁）。カリ首にびっしりの黄ばんだチンカスを、めいは涙目で見つめる。〇〇が「やめとく？」と聞くと、めいはぶんぶんと首を振る。「や、やります……っ、めい、やってみます……っ」。もう一度、鼻を近づける。えずく。三回目で、めいの目の色が変わる。「……あれ……？　なんか……くさいのに……」。脚のあいだが、どろどろに濡れてくる
- **決め台詞**：めい「……くさいのに……なんか、すき、かも……」（方向）
- **エロの中身**：初めての激臭への反応（本気のえずき、涙、鼻水）。チンカスの描写。三回目で、匂いに目覚める。喘ぎ声はなし〜レベル1
- **位置関係**：〇〇がベッドの縁に座り、めいが床に正座
- **感情の流れ**：（めい）ドキドキ → 想像以上の匂いに、えずく → でも、やめたくない → くさいのに、すき （〇〇）めいちゃんが、泣きながら、がんばってる

## 場面3：おいしい、です

- **流れ**：〇〇が「舐めてみる？」と聞くと、めいは「は、はい……っ」とうなずく。舌の先で、おそるおそるチンカスに触れる。えずく。もう一度。舌に乗ったかすを、口の中で転がす。「……しょっぱい……苦い……」。飲みこもうとして、えずいて、涙を流しながら、それでも飲みこむ。「……のめ、ました……」。〇〇が頭を撫でてほめると、めいはうれしそうに笑って、次のかすへ舌を伸ばす。だんだん、えずく間隔が長くなっていく。最後には夢中で舐め回している。「おいしい、です……♡　〇〇さんの、くさいの、おいしか……♡」
- **決め台詞**：めい「おいしい、です……♡」（方向）
- **エロの中身**：チンカスを舌で舐め取る（おそるおそる → 夢中）、えずきながら飲みこむ、〇〇にほめられる。だんだん慣れていく過程。そのままフェラ、パイズリ（めいのFカップでちんぽを挟んで、谷間に残ったかすも舐め取る）。喘ぎ声はくぐもった声
- **位置関係**：場面2と同じ → めいが膝立ちになって、胸でちんぽを挟む
- **感情の流れ**：（めい）こわい → できた → ほめられてうれしい → もっと → おいしい （〇〇）めいちゃんが、自分の汚れで、どんどん覚えていく

## 場面4：めいの中で

- **流れ**：きれいになったちんぽで、めいは自分から仰向けになって脚を開く。「めいの中も、〇〇さんの匂いにしてください……♡」。正常位、Fカップが大きく揺れる。考えながら話すめいの言葉が、どんどんまとまらなくなって、博多弁まじりの淫語になる。〇〇が「イく」と言った瞬間、まとまらない一文すら作れなくなって、博多弁まじりの絶叫になる。中出し。事後、めいは〇〇の胸に顔を埋めて、匂いを嗅ぎながら「……つぎは、もっと長く、ためてほしいです」と言う
- **決め台詞**：なし（例：めい「……つぎは、もっと長く、ためてほしいです……」）
- **エロの中身**：正常位（Fカップが揺れる）、中出し、連続絶頂。博多弁まじりの淫語と絶叫。喘ぎ声はレベル4
- **位置関係**：めいがベッドに仰向け、〇〇が上から
- **感情の流れ**：（めい）全部受けとめたい → 匂いも中も、〇〇さんで → もっと長く （〇〇）めいちゃんの向上心が、ここまで
