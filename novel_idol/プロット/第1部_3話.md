# 第1部 まい編 3話：初回

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。

## この話のまい

性格は変わらない。変わるのは動き方。3話のまいは、表の性格のまま、「ハメられたい」という欲に向かって動いている。

- **聞き上手**：〇〇の話を楽しそうに聞く。でも、頭の片隅ではずっと「この人に」と考えている
- **包容力・面倒見のよさ**：気弱な〇〇は自分からは動かない、とわかっている。だから、緊張をほぐして、場を運んで、そういう空気まで自分で連れていく
- **甘える寂しがり**：〇〇の前でだけ、少しずつ出てしまう
- **お姉さんぶった余裕**：実は余裕ではなく、欲や緊張を隠すための表の顔

まいのリードは、からかいの余裕から来るのではなく、「ハメられたい」という目的から来る。からかいは、全体で1回くらいの味付けに留める。心の声では、表の落ち着きと裏腹に、欲でいっぱいの本音が出る。

## 場面1：店で会う

- **流れ**：休みの日。まいが指定した、個室のある落ち着いた店。まいは帽子と眼鏡で変装している。〇〇は緊張でガチガチの敬語。まいは〇〇の話を楽しそうに聞いて、よく笑う。〇〇が古参だとわかると、昔のことを懐かしそうに聞く
- **決め台詞**：なし
- **エロの中身**：なし。まいの心の声で、〇〇の手や口元ばかり見てしまう
- **位置関係**：個室で、テーブルを挟んで向かい合う
- **感情の流れ**：（まい）楽しく話しながら、内心はずっと〇〇を意識している （〇〇）夢みたいで、まともに目が見られない

## 場面2：まいの家へ

- **流れ**：隣の個室の客が、まいの名前を出して噂話をしているのが聞こえる。まいはそれを口実に、近くの自分の家に誘う
- **決め台詞**：まいの誘いの一言（未定。案：A「ここ、バレるかも。……うち、近いんだけど」／B「……ねえ、出よっか。うち、すぐそこだから」／C「ここじゃ落ち着かないね。……うち来る？」）
- **エロの中身**：なし
- **位置関係**：個室
- **感情の流れ**：（まい）口実ができて、内心ほっとしている （〇〇）事態についていけない

## 場面3：部屋を案内する

- **流れ**：まいの部屋に入る。まいは「散らかってるけど」と言いながら、軽く部屋を案内する。立ち尽くす〇〇を「座って、座って」と気づかい、お茶を出す。案内の途中、少し開いていたベッドルームのドアから、ベッドの上に電マが転がっているのがチラッと見える。〇〇は見なかったふりをするが、内心では興奮が止まらない。まいは気づいていない
- **決め台詞**：なし
- **エロの中身**：電マが見える。〇〇の内心の興奮。まいは、自分の部屋に〇〇がいることに内心で昂っている
- **位置関係**：玄関 → リビング。ベッドルームの前を通るときに、ドアの隙間から
- **感情の流れ**：（〇〇）緊張 → 電マを見てしまう → あのしのまいさんが、と頭がいっぱいになる （まい）包容力のあるお姉さんとして、〇〇の緊張をほぐそうとする。内心は昂っている

電マを見たことを、あとで回収するかどうかは未定。

## 場面4：写真集の話から

- **流れ**：リビングのソファで、並んで話す。古参の〇〇が、まいの写真集を持っていると話す。まいは素直にうれしそうに「ほんと？　どこが好き？」と聞いて、自分の写真集を出してきて、一緒にめくる。〇〇が好きなページを語るのを、まいは照れながら聞く。話しているうちに、水着や下着のエロいページに差しかかる。まいのほうが先に我慢できなくなる。ずっと誰にも出せなかった欲や甘えが、〇〇の前で出てしまって、自分からキスをする
- **決め台詞**：なし
- **エロの中身**：写真集のエロいページ。キス
- **位置関係**：ソファに並んで座り、写真集を2人の膝の上に広げる。ページをめくるうちに、まいが〇〇に寄りかかる
- **感情の流れ**：（まい）うれしい → 褒められて照れる → 昂ってくる → 我慢できずにキス （〇〇）本人の前で、本人のエロいページを見る恥ずかしさと興奮

## 場面5：前戯

- **流れ**：ベッドへ。〇〇は「さ、触ってもいいですか」と確かめながら、おそるおそる触れる。まいは照れる。下着の中がもう濡れていることに〇〇が気づき、まいは顔を赤くする。まいは自分から〇〇のズボンを下ろす。〇〇のモノが思っていたより大きいことに、一瞬言葉を失う。フェラをする
- **決め台詞**：なし
- **エロの中身**：愛撫、手マン、フェラ。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの上。最初は並んで座る → まいが仰向け、〇〇が横から触れる → まいがベッドの下に膝をつき、ベッドの縁に座った〇〇にフェラ
- **感情の流れ**：（まい）照れ → 濡れているのを知られて恥ずかしい → 自分から求める → 大きさに驚く

- **決め台詞**：なし
- **エロの中身**：正常位。喘ぎ声はレベル2〜3
- **位置関係**：まいが仰向け、〇〇が上から覆いかぶさる
- **感情の流れ**：（まい）余裕を保とうとする → 保てなくなっていく

## 場面7：崩れていく

- **流れ**：〇〇は一度出しても萎えない。まいは自分から上に乗る。でも、自分で動くと奥に当たりすぎて、すぐに腰が止まってしまう。〇〇が下から突き上げる。まいは崩れて、自分でも言ったことのない下品な言葉を口にしながら、何度もイく。最後は、レベル4まで行く
- **決め台詞**：堕ちる瞬間の一言（未定。案：A「〇〇くんの……ちんぽじゃないと、もう、だめ……♡」／B「もっと……っ、もっと犯して……っ♡　〇〇くんので、めちゃくちゃにして……♡」／C「やだ、やめないで……っ♡　ずっと、こうしてて……♡」。Bは1話の心の声「この人に、めちゃくちゃにされたい」が声に出る形）
- **エロの中身**：騎乗位 → 〇〇の下からの突き上げ → バック。中出し。連続絶頂。喘ぎ声はレベル3 → 4
- **位置関係**：〇〇が仰向け、まいが跨がる → まいが前に倒れ込み、〇〇が下から抱えて突き上げる → まいが四つん這いになり、〇〇が後ろから
- **感情の流れ**：（まい）自分で動きたい → 動けない → 気持ちよさに負ける → 自分から求める → 堕ちる
