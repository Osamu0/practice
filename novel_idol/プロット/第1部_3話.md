# 第1部 まい編 3話：初回

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。

## この話のまい

性格は変わらない。変わるのは動き方。3話のまいは、表の性格のまま、「ハメられたい」という欲に向かって動いている。

- **聞き上手**：〇〇の話を楽しそうに聞く。でも、頭の片隅ではずっと「この人に」と考えている
- **包容力・面倒見のよさ**：〇〇はファンとしての遠慮から、自分からは誘ってこない、とわかっている。だから、緊張をほぐして、場を運んで、そういう空気まで自分で連れていく
- **甘える寂しがり**：〇〇の前でだけ、少しずつ出てしまう
- **お姉さんぶった余裕**：実は余裕ではなく、欲や緊張を隠すための表の顔

まいのリードは、からかいの余裕から来るのではなく、「ハメられたい」という目的から来る。からかいは、全体で1回くらいの味付けに留める。心の声では、表の落ち着きと裏腹に、欲でいっぱいの本音が出る。

この話の終わりで、まいは**ほぼ完堕ち**に届く（`企画メモ.md` の「深まり方と完堕ち」）。前の性格は、崩れたあとに一瞬照れるくらいしか残らない。次の4話からは完堕ちしている。

〇〇は敬語でおそるおそる。行為の中で、気持ちがあふれてタメ口が混じりはじめる。

## 場面1：カフェで会う

- **流れ**：休みの日の昼。まいが指定した、路地の奥の小さなカフェ。奥の窓際の席。まいは帽子と眼鏡で変装している。〇〇は緊張でガチガチの敬語。まいは〇〇の話を楽しそうに聞いて、よく笑う。まだお互いに緊張していて、話は軽いもの（仕事、休みの日のこと）
- **決め台詞**：なし
- **エロの中身**：なし。まいの心の声で、〇〇の手や口元ばかり見てしまう（握手で触れた手）
- **位置関係**：奥の窓際の席。小さなテーブルを挟んで向かい合う
- **感情の流れ**：（まい）楽しく話しながら、内心はずっと〇〇を意識している （〇〇）夢みたいで、まともに目が見られない

## 場面2：まいの家へ

- **流れ**：近くの席の客が、こちらをちらちら見て「あれ、篠宮まいじゃない？」とひそひそ話しているのが聞こえる。まいはそれを口実に、近くの自分の家に誘う
- **決め台詞**：まいの誘い「ここ、バレるかも。……うち、近いんだけど。来る？」（AとCの組み合わせ。言い回しは前後のセリフに合わせて本文で調整する）
- **エロの中身**：なし
- **位置関係**：カフェの席
- **感情の流れ**：（まい）口実ができて、内心ほっとしている （〇〇）事態についていけない

## 場面3：部屋を案内する

- **流れ**：まいの部屋に入る。広くてきれいなマンションで、窓からの眺めもいい。〇〇は、トップアイドルはいい家に住んでいるんだと実感する。ファンとして、本人の家に来るなんて夢のまた夢だったのに、と現実感がない。まいは「散らかってるけど」と言いながら、軽く部屋を案内する。立ち尽くす〇〇を「座って、座って」と気づかう。それから冷蔵庫からワインを出して「飲もっか」と言う（まいも、少し飲まないと落ち着かない気分）。案内の途中、少し開いていたベッドルームのドアから、ベッドの上に電マが転がっているのがチラッと見える。〇〇は見なかったふりをするが、内心では興奮が止まらない。まいは気づいていない
- **決め台詞**：なし
- **エロの中身**：電マが見える。〇〇の内心の興奮。まいは、自分の部屋に〇〇がいることに内心で昂っている
- **位置関係**：玄関 → リビング。ベッドルームの前を通るときに、ドアの隙間から
- **感情の流れ**：（〇〇）いい家だという驚きと、本人の家にいる現実感のなさ → 緊張 → 電マを見てしまう → あのまいまいが、と頭がいっぱいになる （まい）包容力のあるお姉さんとして、〇〇の緊張をほぐそうとする。内心は昂っている

電マは、場面5でベッドルームに入ったときに回収する。

## 場面4：お酒を飲みながら、写真集の話から

- **流れ**：リビングのソファで、ワインを飲みながら並んで話す。お酒が入って、カフェより話が深くなる。〇〇が古参だとわかると、まいは昔のことを懐かしそうに聞く（最初の握手会、推しのきっかけ）。古参の〇〇が、まいの写真集を持っていると話す。まいは素直にうれしそうに「ほんと？　どこが好き？」と聞いて、自分の写真集を出してきて、一緒にめくる。〇〇が好きなページを語るのを、まいは照れながら聞く。話しているうちに、水着や下着のエロいページに差しかかる。まいのほうが先に我慢できなくなる。ずっと誰にも出せなかった欲や甘えが、〇〇の前で出てしまって、自分からキスをする
- **決め台詞**：なし
- **エロの中身**：写真集のエロいページ。キス（ワインの味）。お酒は少しゆるむ程度で、酔いつぶれない
- **位置関係**：ソファに並んで座り、ローテーブルにワインのグラス。写真集を2人の膝の上に広げる。ページをめくるうちに、まいが〇〇に寄りかかる
- **感情の流れ**：（まい）お酒で少し気が楽になる → 昔の話がうれしい → 褒められて照れる → 昂ってくる → 我慢できずにキス （〇〇）本人の前で、本人のエロいページを見る恥ずかしさと興奮

## 場面5：前戯

- **流れ**：ベッドルームへ。入ったところで、まいがベッドの上の電マに気づき、慌てて片付ける。〇〇は、さっき見ていたことは言わずに知らないふりをして、まいの焦った反応を内心ドキドキしながら楽しむ。ベッドへ。〇〇は「さ、触ってもいいですか」と確かめながら、おそるおそる触れる。まいは照れる。下着の中がもう濡れていることに〇〇が気づき、まいは顔を赤くする。まいは自分から〇〇のズボンを下ろす。〇〇のちんぽが思っていたより大きいことに、一瞬言葉を失う。目が離れない。匂いに、頭がぼうっとする。お姉さんぶった顔のまま、気づけば自分から咥えている（ちんぽへの服従の最初の芽。本人はまだ自覚していない）
- **決め台詞**：なし
- **エロの中身**：キス（軽いキス → ディープ）、首筋と鎖骨へのキス、乳首を舐める・吸う、手マン、クンニ（〇〇はおそるおそる。まいは初めて舐められる恥ずかしさで顔を覆う）、フェラ。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの上。最初は並んで座る → まいが仰向け、〇〇が横から触れる → まいがベッドの下に膝をつき、ベッドの縁に座った〇〇にフェラ
- **感情の流れ**：（まい）電マに気づいて焦る → 照れ → 濡れているのを知られて恥ずかしい → 自分から求める → 大きさに驚く → 目が離れない、気づいたら咥えている （〇〇）知らないふりをしながら、まいの焦りを内心で楽しむ → 写真集で何回も想像した唇が、自分のちんぽを咥えている

## 場面6：挿入（正常位）

- **流れ**：まいから「入れて」と求める。正常位で、ゆっくり入る。大きさに、まいのお姉さんぶった余裕が崩れ始める。〇〇は「まいまい」と呼びながら、遠慮がちに動く。でも気持ちがあふれて、ところどころ敬語が抜ける（「やば、まいまいの中……」）
- **決め台詞**：なし
- **エロの中身**：正常位（まいが〇〇の腰に脚を絡めて、奥まで引き寄せる）。喘ぎ声はレベル2〜3
- **位置関係**：まいが仰向け、〇〇が上から覆いかぶさる
- **感情の流れ**：（まい）余裕を保とうとする → 保てなくなっていく

## 場面7：崩れていく

- **流れ**：〇〇は一度出しても萎えない。まだ硬いままのちんぽを見て、まいの目がとろんとする。まいは自分から上に乗る。でも、自分で動くと奥に当たりすぎて、すぐに腰が止まってしまう。〇〇が下から突き上げる。まいは崩れて、自分でも言ったことのない下品な言葉を口にしながら、何度もイく。最後は、レベル4まで行く。ここで、ほぼ完堕ち
- **決め台詞**：堕ちる瞬間「もっと……っ、もっと犯して……っ♡　〇〇くんので、めちゃくちゃにして……♡」（1話の心の声「この人に、めちゃくちゃにされたい」が声に出る形）
- **エロの中身**：騎乗位 → 〇〇の下からの突き上げ → バック。中出し。連続絶頂。喘ぎ声はレベル3 → 4
- **位置関係**：〇〇が仰向け、まいが跨がる → まいが前に倒れ込み、〇〇が下から抱えて突き上げる → まいが四つん這いになり、〇〇が後ろから
- **感情の流れ**：（まい）自分で動きたい → 動けない → 気持ちよさに負ける → このちんぽには勝てない → 自分から求める → ほぼ完堕ち

## 場面8：事後

- **流れ**：ベッドの上。まいは一瞬だけ照れて〇〇の胸に顔をうずめるが、すぐに〇〇のちんぽに手が伸びる（もう、元のまいには戻らない）。明後日から地方ロケで、何日か東京にいないと話す。〇〇が寂しそうにすると、まいは「電話する」と言い、少し考えてから「……テレビ電話」と言い直す。それから「帰ってきたら、次は〇〇くんの家に行きたいな」
- **決め台詞**：なし
- **エロの中身**：余韻。萎えないちんぽを、話しながら手で触っている
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（まい）一瞬照れる → 満たされているのに、まだ欲しい。もう、このちんぽじゃないとだめ （〇〇）夢じゃない → 何日も会えない
- **ねらい**：4話（地方ロケ中のテレビ電話）と5話（初めて〇〇の部屋へ）への引き
