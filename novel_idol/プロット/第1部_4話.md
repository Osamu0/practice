# 第1部 まい編 4話：テレビ電話

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

完堕ちしたまいの1話目。3話の二日後から、地方ロケで3〜4日、東京を離れる。会えないあいだ、まいは夜ごとホテルの部屋から、自分から見せたくてテレビ電話をかけてくる。会えないぶん、画面越しに恥も外聞もなくなっていく。

- **まい**：完堕ち。表（ロケ、カメラの前、メンバーの前）では完璧な表の顔。裏（テレビ電話）では、画面に〇〇のちんぽが映った瞬間に崩れる。日を追うごとにエスカレートする。ちんぽの前の台詞は、隣の部屋を気にして声を殺そうとしながら、ハードコアに崩れていく
- **〇〇**：敬語とタメ口が混じる。画面越しに、お願いの形で求めるようになる（「もっと近くで」「見せて」）。調子に乗る芽。心の声では、テレビで見てきた顔が、画面の中で自分のためだけに崩れていく実感
- **隣の部屋**：ほのか。ほのかは何も気づいていない（第2部への小さな種）
- **橋渡し**：LINEが増えている／仕事中のまいの調子がよさそう

## 場面1：ロケ1日目（表）

- **流れ**：地方の町でのロケ。食べ歩きや名所めぐりで、まいはカメラの前でよく笑い、メンバーに話を振り、地元の人にも気さくに話しかける。合間にスマホを見ると、〇〇から『ロケ、がんばってね』。まいは何気ない顔で返す。ちひろに「まいまい、今日テンション高くない？」と言われ、「空気がおいしいからかな」とかわす。ほのかが、その横顔をなんとなく見ている
- **決め台詞**：なし
- **エロの中身**：なし。まいの心の声で、夜のことを考えて疼く（下着の中が湿っている）
- **位置関係**：ロケ先の町。まい、ほのか、ちひろ、ほかに1〜2人。スタッフとカメラ
- **感情の流れ**：（まい）表の顔を完璧に保つ → 合間に〇〇のことを考えてしまう → 夜が待ち遠しい
- **橋渡し**：仕事中のまいの調子がよさそう

## 場面2：1日目の夜、最初のテレビ電話

- **流れ**：ホテルの一人部屋。〇〇は自分の部屋で、まいからのLINE『いま、電話できる？』『テレビ電話がいい』を受ける。画面に、ホテルのバスローブ姿のまい。最初は今日のロケの話。でもまいはすぐに、ローブの合わせ目を自分でゆるめる。「見せたかったの」。〇〇が勃っているのに気づくと「見せて」とねだる。〇〇のちんぽが画面に映った瞬間、まいの目つきが変わり、言葉が崩れる（最初の、画面越しの切り替わり）。二人とも画面の前でひとりでする。隣はほのかの部屋なので、まいは声を殺そうとするが、抑えきれない
- **決め台詞**：まい（ちんぽが画面に映った瞬間）「……あ。〇〇くんの、おちんぽ……」（方向。言い回しは本文で調整する）
- **エロの中身**：テレビ電話でのオナニーの見せ合い。まいは指で（電マはまだ出さない）。〇〇は手で。画面越しに同時にイく。喘ぎ声はレベル2〜3（声を殺している）
- **位置関係**：まいはホテルのベッドの上、スマホを枕に立てかける。〇〇は自分のベッドで、スマホを片手に
- **感情の流れ**：（まい）声が聞きたいだけのつもり → 見せたい → ちんぽが映った瞬間に崩れる → 隣を気にする → 抑えきれない （〇〇）テレビで見てきた顔が、画面の中で自分のためだけに → 何度も想像したことが、画面越しに本物になる

## 場面3：2日目の夜、エスカレート

- **流れ**：まいは、荷物に電マを入れてきていた（ロケのあいだも、こうするつもりだった）。今夜は最初から下着だけ。まいが自分から脚を開いて、スマホを近づけて広げて見せる。〇〇は「もっと近くで」「そのまま、見せて」とお願いの形で頼む（調子に乗る芽）。まいはうれしそうに応える。電マを当てながら、画面の〇〇のちんぽに話しかけるように淫語を言う。途中で、ほのかから『まいちゃん、起きてる？』『明日の集合、七時やって』とLINEが届く。まいは電マを当てたまま、片手で『りょうかい！おやすみ〜』と返し、また画面に戻る
- **決め台詞**：なし
- **エロの中身**：くぱぁ（自分で広げて、スマホを近づけて見せる）。電マでのオナニー、潮吹き。〇〇はまいに合わせて手でする。喘ぎ声はレベル3。台詞はちんぽの前のハードコア（隣を気にして、ささやき声で崩れる）。一人称に「まい」が混じりはじめる
- **位置関係**：まいはホテルのベッドの上で脚を開き、片手でスマホを股のあいだに近づける → スマホを立てかけて、両手で電マ。〇〇は自分のベッド
- **感情の流れ**：（まい）見せたい → 近くで見られてうれしい → ほのかのLINEに表の顔で返す → すぐに戻る （〇〇）画面いっぱいの、まいまいのおまんこ → もっと見たい、と口に出せる

## 場面4：3日目の昼、ロケの合間

- **流れ**：ロケの休憩中。まいはロケ先の施設のトイレの個室に入り、声を殺して〇〇にテレビ電話をかける。〇〇は会社の昼休みで、会社のトイレの個室で受ける。時間は数分しかない。まいはスカートをたくしあげ、指でイくところだけを見せる。「夜まで、我慢できなかった」。電話を切ったあと、まいは鏡でメイクを直し、何事もなかったようにカメラの前に戻って、完璧な笑顔で食レポをする
- **決め台詞**：なし
- **エロの中身**：トイレの個室からのテレビ電話、指での短いオナニー。喘ぎ声はレベル2（声を殺し、口を手でふさぐ）
- **位置関係**：まいはロケ先のトイレの個室、便座のふたに座る。〇〇は会社のトイレの個室
- **感情の流れ**：（まい）夜まで待てない → 声を殺してイく → 何事もなかったように表に戻る （〇〇）昼休みの会社で、トップアイドルがイくところを見ている
- **表の場での漏れ**：仕事の合間の電話。ほかのメンバーやスタッフは気づかない

## 場面5：最後の夜

- **流れ**：ロケ最後の夜。明日、東京に帰る。いつものようにテレビ電話をつなぐが、今夜のまいは、イく前に〇〇の手を止めさせる。「明日まで、出さないで」「まいの中に、出して」。帰ったらそのまま〇〇の部屋に行くから、住所を送って、と言う。〇〇は寸止めのまま、住所を送る
- **決め台詞**：まい「明日まで、出さないで。……まいの中に、ちょうだい」（方向。言い回しは本文で調整する）
- **エロの中身**：テレビ電話での見せ合い。まいはイくが、〇〇は寸止め。喘ぎ声はレベル3
- **位置関係**：場面2・3と同じ
- **感情の流れ**：（まい）会いたい → 〇〇のを中に欲しい → 明日が待てない （〇〇）出したいのを我慢する → 明日、まいまいが自分の部屋に来る
- **ねらい**：5話（ロケから帰ったその夜、初めて〇〇の部屋へ）への引き
