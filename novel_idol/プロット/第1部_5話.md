# 第1部 まい編 5話：〇〇の部屋

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。

ロケから帰ってきたその夜、まいが初めて〇〇の部屋に来る。4話の寸止め（「明日まで、出さないで」）のあと。画面越しではなく、実物のちんぽを前にして、ちんぽの前の切り替わりがはっきり出る。二人とも三日ぶりなので、我慢していたぶん爆発して、とことん堕ちる。挿れる以外の行為もたっぷり入れる。

- **まい**：完堕ち。玄関に入った瞬間から求める。恥も外聞もない。ちんぽの前の台詞はハードコア（一人称は「私」と「まい」）。匂いでの発情が、この話の入口（部屋の匂い → もっと強いちんぽの匂い）
- **〇〇**：敬語とタメ口が混じる → まいにねだられて、タメ口になる。まだ調子に乗る前（わざと聞く・言わせる・焦らすは6話から）。求められるまま、欲のまま応える
- **匂い**：部屋はロケのあいだにシコりまくったせいで精液くさい。ちんぽは、それよりずっと臭い（まいに「シャワー浴びないで」と言われて、バイト帰りの汗と、昨夜からの我慢汁が乾いたまま）。部屋の匂いで発情したまいが、ちんぽの匂いでさらに崩れる、という二段にする
- **橋渡し**：〇〇の部屋に通うようになる

## 場面1：待っている〇〇

- **流れ**：〇〇の部屋。ワンルームで、まいの家の半分もない。〇〇は昼のシフトから帰ってきたところ。ロケのあいだの三日、まいのエロ写メとテレビ電話で何回もシコったので、部屋には精液の匂いがこもっている。慌ててゴミ箱のティッシュを袋にまとめて捨て、シーツを替えて、窓を開けるが、狭い部屋の匂いは抜けきらない。シャワーを浴びようとしたところで、まいからLINE『いま、新幹線』『シャワー、浴びないで待ってて』『そのままの〇〇くんがいい』。〇〇は浴びずに待つ。昨夜から出していないので、待っているだけで勃ってきて、我慢汁で下着が濡れる。何度も時計を見る。まいからLINE『いま、駅』『もうすぐ』
- **決め台詞**：なし
- **エロの中身**：なし。〇〇の心の声で、昨夜の画面のまいを思い出す。下着の中で我慢汁が乾いては、また濡れる
- **位置関係**：〇〇の部屋で一人
- **感情の流れ**：（〇〇）狭い部屋が恥ずかしい → 匂いが抜けなくて焦る → 「シャワー浴びないで」にどきっとする → まいまいがここに来る、という現実感のなさ → 待ちきれない

## 場面2：玄関で

- **流れ**：インターホンが鳴り、ドアを開けた瞬間に、まいが飛びついてキスをする。ロケのキャリーケースを持ったまま。ドアが閉まる。玄関に立ったまま、まいがすうっと息を吸って止まる。部屋の匂いに気づいて、目がとろんとする。「……すごい匂い」「これ、ぜんぶ、私の写真で？」。〇〇は真っ赤になって、何回したか白状する。まいは引くどころか、うれしそうに匂いを吸いこむ。そのまま玄関にしゃがみこみ、〇〇のズボンを下ろす。下着の上から、もう匂いが立ちのぼってくる。下着を下ろして出てきたちんぽは、部屋の匂いよりずっと濃く、むわっと臭う。その匂いを吸った瞬間に、まいの目つきが変わる（実物の前での切り替わり）。決め台詞。鼻を押しつけて匂いを嗅ぐ（先、裏筋、根元、玉）。頬ずり。ちんぽに話しかける。ちんぽにキス。舌で、乾いた我慢汁の跡を舐め取る。玉を舐めて、口に含む。それから咥える。自分から喉の奥まで呑みこもうとして、えずいても離さない。〇〇は出そうになって止める（「まいまいの中に出す約束だから」）。まいは口を離して、自分から玄関の壁に手をつき、スカートをたくしあげて「入れて」。立ちバックで、服を着たまま。三日分我慢した〇〇は、すぐに奥で出す。出された瞬間にまいも崩れてイく。共用の廊下を足音が通り、隣の部屋のドアが開く。〇〇は止まるが、まいは口を手でふさいだまま、自分から腰を押しつけて、出されたものを奥で搾り取る
- **決め台詞**：まい（ちんぽを前にして）「……ほんものだ……♡　画面じゃない、おちんぽ……♡」（方向。言い回しは本文で調整する）
- **エロの中身**：玄関での部屋の匂いへの発情 → 即尺（匂い嗅ぎ、頬ずり、キス、ちんぽに話しかける、乾いた我慢汁を舐め取る、玉舐め、玉を口に含む、咥える、自分から喉奥まで）→ 寸止め → 立ちバック（玄関の壁に手をつく。服は着たまま、下着だけずらす）→ 中出し。隣の住人の足音。喘ぎ声はレベル3（声を殺そうとして、抑えきれない）
- **位置関係**：狭い玄関。まいがしゃがみ、〇〇は立ったまま → まいが壁に両手をつき、〇〇が後ろから。キャリーケースは足元に倒れている
- **感情の流れ**：（まい）やっと会えた → 部屋の匂いで、私の写真で何回も → うれしい、発情 → ちんぽの匂いで、部屋どころじゃない → 実物を前にして崩れる → 入れてほしい → 隣の足音にも止まれない （〇〇）白状させられて恥ずかしい → まいまいが、玄関で自分の臭いちんぽに鼻を押しつけている → 我慢できない

## 場面3：部屋に入る

- **流れ**：やっと靴を脱いで、部屋に入る。まいは狭い部屋を見回して、ベッドに倒れこみ、〇〇の匂いがしみこんだ枕に顔をうずめて深く吸う。〇〇がまだ「まいまい」と呼んで、敬語とタメ口が混じる。まいが「敬語、やめて」「まいまい、っていうのも」とねだる。〇〇は照れながら「……まいちゃん」。まいは笑って「ちゃん、ついてる」「でも、いいよ。今はね」。〇〇はタメ口になる。それから、今度は〇〇がまいを脱がせる。まいも移動のあとでシャワーを浴びていない。〇〇は首筋、鎖骨、汗ばんだ胸の下を嗅いで舐める（まいは「やだ、汗かいてる」と言いながら止めない）。乳首を吸われて、まいは乳首だけでイきかける。〇〇はまいの脚のあいだに顔をうずめ、自分の出したものが垂れてくるのも構わずにクンニし、指を入れる。4話でまいが言った「〇〇くんので、しお、ふかせて」を、〇〇の指でかなえる（ベッドのシーツに大きな染み）
- **決め台詞**：なし
- **エロの中身**：ベッドでキス。まいが枕の匂いを嗅いで濡れる（匂いでの発情）→ 〇〇がまいを脱がせて、汗ばんだ身体の匂いを嗅ぐ・舐める（首筋、鎖骨、胸の下）→ 乳首責め（舐め、吸い、つまみ）→ クンニと手マンを同時に（Gスポット）→ 潮吹き。喘ぎ声はレベル3
- **位置関係**：〇〇のベッド。まいが仰向け、〇〇が上から → 〇〇がまいの脚のあいだ
- **感情の流れ**：（まい）〇〇の匂いに包まれて昂る → 呼び方が変わってうれしい → 汗の匂いを嗅がれて恥ずかしいのに、もっと → 〇〇くんので、ふいた （〇〇）ぎこちなく、呼び方と口調が変わる → 画面越しじゃない、まいちゃんの匂いと味

## 場面4：シックスナイン

- **流れ**：潮を噴いたばかりのまいが、〇〇を仰向けにして、逆向きに跨がる。目の前に、さっき出したばかりなのにまだ硬い、臭いちんぽ。まいは匂いを嗅ぎながら咥え、〇〇は下からまいのそこを舐める。お互いに責め合ううちに、まいはまたイって、咥えたまま声を漏らす。〇〇がイきそうになると、まいは口を離して「次も、なか」
- **決め台詞**：なし
- **エロの中身**：シックスナイン（女性上位）。まいはフェラ（匂いを嗅ぎながら、バキューム）、〇〇はクンニ。まいの連続絶頂。喘ぎ声はレベル3〜4（咥えたままのくぐもった声）
- **位置関係**：〇〇がベッドに仰向け、まいが逆向きに跨がって、〇〇の顔の上に腰
- **感情の流れ**：（まい）匂いと味で頭がいっぱい → 舐められながら咥えるのが気持ちよすぎる → でも、出すのは中 （〇〇）目の前で、まいちゃんのそこがひくついている

## 場面5：ベッドで

- **流れ**：まいはそのまま向きを変えて、自分から跨がる。3話では奥に当たりすぎて動けなかったが、今夜は自分から腰を打ちつける（杭打ち）。それでもすぐに崩れて、〇〇が下から突き上げる。突き上げでハメ潮。そのあと〇〇が上になり、まいは脚を〇〇の腰に絡めて、抜かせない（だいしゅきホールド）。まいはハードコアな淫語で何度も中に欲しがり、〇〇は抜かずに何度も中に出す。まいは何回イったかわからなくなる
- **決め台詞**：なし
- **エロの中身**：騎乗位（まいが自分から杭打ち）→ 下からの突き上げ、ハメ潮 → 正常位（まいが脚を絡めて、抜かせない）。抜かずの中出しを続けて。連続絶頂、イキ地獄。喘ぎ声はレベル4
- **位置関係**：〇〇が仰向け、まいが跨がる → 〇〇が上になり、まいが仰向けで〇〇の腰に脚を絡める
- **感情の流れ**：（まい）自分から取りにいく → それでも負ける → 何回出されても足りない （〇〇）「まいちゃん」と呼びながら、欲のまま

## 場面6：飲ませて

- **流れ**：何回目かのあと、まいが〇〇のものを抜かせて、脚のあいだから垂れてくる精液を指ですくって舐める。「……〇〇くんの味」。それから、まだ萎えないちんぽを、自分の胸で挟む（パイズリ）。先を咥えて、「最後は、のみたい」。〇〇はまいの口に出す。まいは全部受けとめて、口を開けて見せてから飲みこむ。そのまま、お掃除フェラ。最後まで、ちんぽから口を離したがらない
- **決め台詞**：なし
- **エロの中身**：垂れてきた精液を指ですくって舐める → パイズリフェラ → 口内射精 → 口を開けて見せる → ごっくん → お掃除フェラ。喘ぎ声はレベル3（咥えているので、くぐもった声と言葉）
- **位置関係**：〇〇がベッドの縁に座る、または仰向け。まいが〇〇の脚のあいだにうずくまる
- **感情の流れ**：（まい）中も、口も、ぜんぶ〇〇くんので満たしたい → 飲めてうれしい → まだ離れたくない （〇〇）まいまいが、自分の精液を、うれしそうに
