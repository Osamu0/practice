# 第1部 まい編 5話：久しぶりの夜

第1部の最後の話。堕ちたまいの2回目。4話（玄関で立ちバック、電マ）と重ならないようにする。最後に第2部への引きを置く。

## 場面1：番組の収録（まいの側）

- **流れ**：仕事が立て込んでいて、しばらく〇〇に会えていない。今日も、グループの冠番組の収録。まいは表の顔で、いつもどおり笑ってメンバーとやりとりする。合間にスマホを見ると、〇〇からのLINE。会えない日が続いて、我慢が限界に近い。収録が終わってすぐ、『やっと終わった。今から行っていい？』と送る
- **決め台詞**：なし
- **エロの中身**：なし。心の声で、会えない日々の疼き
- **位置関係**：スタジオ → 楽屋
- **感情の流れ**：（まい）表の顔を保つ → 合間に〇〇のことを考えてしまう → 終わった瞬間に会いに行く
- **橋渡し**：LINEが増えている／仕事中の表の顔

## 場面2：久しぶりの〇〇の部屋

- **流れ**：夜、まいが〇〇の部屋に来る。ドアが開いた瞬間に抱きつく。「ずっと会いたかった」。〇〇は、自然にタメ口で「まいちゃん」と呼ぶ。まいはうれしそうに、さらに強く抱きつく
- **決め台詞**：なし
- **エロの中身**：キス
- **位置関係**：玄関からベッド
- **感情の流れ**：（まい）会えなかったぶん、もう我慢できない （〇〇）遠慮がなくなってきた自分に気づく

## 場面3：一晩中

- **流れ**：まいが自分から下品なフェラをして、口で受け止めて飲む。〇〇は何度出しても萎えない。体位を変えながら、朝まで続く。まいは、前回よりさらに下品な言葉で、自分から求め続ける。〇〇も、遠慮せずに欲望をぶつけるようになっている
- **決め台詞**：なし
- **エロの中身**：
  - **下品なフェラ**（喉奥まではまだしない）
    - 表情：頬をすぼめて吸いつくひょっとこ顔。咥えたままの上目遣いで、涙目。表の整った笑顔との落差を出す
    - 音：擬音のルールどおり段階的に上げる（ちゅぷ…… → じゅぽっ、じゅぽっ → ぢゅるるっ、ぢゅぽぽっ → ｼﾞｭﾎﾟｼﾞｭﾎﾟｼﾞｭﾎﾟｯ）
    - 言葉：口を離した合間に、味や匂いを実況する淫語（「〇〇くんのおちんぽ、おいしい……♡」など）。咥えたままのくぐもった喘ぎ（「んむっ、んぶっ♡」）
    - 動き：強く吸いつきながら頭を前後に動かすバキューム。舌を大きく出して、先や裏筋を舐め回す。玉まで舐める。よだれを垂らしたままで、口の端から垂れて胸元まで汚れる
  - 口の中に出された精液を、口を開けて〇〇に見せてから、飲む
  - 寝バック → 種付けプレス。中出しを何度も。喘ぎ声はレベル4
  - 中出しのあと、まいが自分で広げて、溢れてくるのを〇〇に見せる
  - お掃除フェラ。そのまま、また硬くなる
- **位置関係**：〇〇がベッドの縁に座り、まいが床に膝をついてフェラ → まいがうつ伏せに寝て、〇〇が上から重なる → まいが仰向けで脚を抱え、〇〇が真上から体重をかける
- **感情の流れ**：（まい）求めても求めても足りない （〇〇）欲望のまま

## 場面4：朝

- **流れ**：朝。まいは〇〇の部屋から仕事に向かう。玄関で、名残惜しそうにキスをする
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：玄関
- **感情の流れ**：（まい）満たされて、仕事に向かう

## 場面5：楽屋（第2部への引き）

- **流れ**：その日の楽屋。まいはスマホを見て、ふっと笑う。それを、ほのかが少し離れたところから見ている。ほのかの心の声で「最近、まいちゃん、なんか楽しそう」
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：楽屋。まいとほのかが離れて座っている
- **感情の流れ**：（ほのか）なんとなく、気になる
- **ねらい**：第2部の「まいの調子がよさそうなのが気になって」への引き

この場面は第1部の最後に置く。第1部は「次はほのか」という引きで終わる。
