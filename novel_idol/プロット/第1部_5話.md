# 第1部 まい編 5話：〇〇の部屋

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

ロケから帰ってきたその夜、まいが初めて〇〇の部屋に来る。4話の寸止め（「明日まで、出さないで」）のあと。画面越しではなく、実物のちんぽを前にして、ちんぽの前の切り替わりがはっきり出る。我慢していたぶん爆発する。

- **まい**：完堕ち。玄関に入った瞬間から求める。恥も外聞もない。ちんぽの前の台詞はハードコア（一人称は「私」と「まい」）
- **〇〇**：敬語とタメ口が混じる → まいにねだられて、タメ口になる。一日我慢したちんぽを、まいが待っている
- **橋渡し**：〇〇の部屋に通うようになる

## 場面1：待っている〇〇

- **流れ**：〇〇の部屋。ワンルームで、まいの家の半分もない。ロケのあいだの3日、まいのエロ写メとテレビ電話で何回もシコったので、部屋には精液の匂いがこもっている。〇〇は慌てて掃除をして、ゴミ箱のティッシュを捨てて、シーツを替えて、窓を開けるが、狭い部屋の匂いは抜けきらない。何度も時計を見る。昨日から出していないので、待っているだけで勃ってくる。まいからLINE『いま、駅』『もうすぐ』
- **決め台詞**：なし
- **エロの中身**：なし。〇〇の心の声で、昨夜の画面のまいを思い出す
- **位置関係**：〇〇の部屋で一人
- **感情の流れ**：（〇〇）狭い部屋が恥ずかしい → 匂いが抜けなくて焦る → まいまいがここに来る、という現実感のなさ → 待ちきれない

## 場面2：玄関で

- **流れ**：インターホンが鳴り、ドアを開けた瞬間に、まいが飛びついてキスをする。ロケのキャリーケースを持ったまま。ドアが閉まると、まいはそのまま玄関にしゃがみこみ、〇〇のズボンを下ろす。出てきたちんぽを見た瞬間に、まいの目つきが変わる（実物の前での切り替わり）。まずちんぽに頬ずりして、キスをして、話しかける。それから咥える。しばらくして口を離し、自分から玄関の壁に手をついて、スカートをたくしあげる。「入れて」。立ちバックで、服を着たまま。一日我慢した〇〇は、すぐに奥で出す。共用の廊下を足音が通り、隣の部屋のドアが開く。〇〇は止まるが、まいは口を手でふさいだまま、自分から腰を押しつける
- **決め台詞**：まい（ちんぽを前にして）「……ほんものだ……♡　画面じゃない、おちんぽ……♡」（方向。言い回しは本文で調整する）
- **エロの中身**：即尺（頬ずり、キス、ちんぽに話しかける、咥える）。立ちバック（玄関の壁に手をつく。服は着たまま、下着だけずらす）。中出し。隣の住人の足音。喘ぎ声はレベル3（声を殺そうとして、抑えきれない）
- **位置関係**：狭い玄関。まいがしゃがみ、〇〇は立ったまま → まいが壁に両手をつき、〇〇が後ろから。キャリーケースは足元に倒れている
- **感情の流れ**：（まい）やっと会えた → 実物を前にして崩れる → 入れてほしい → 隣の足音にも止まれない （〇〇）まいまいが、玄関で自分のちんぽに頬ずりしている → 我慢できない

## 場面3：部屋に入る

- **流れ**：やっと靴を脱いで、部屋に入る。部屋の空気を吸った瞬間、まいの目がとろんとする。こもった精液の匂いに気づいて、「……すごい匂い」「これ、ぜんぶ、私の写真で？」と聞く。〇〇は真っ赤になって、何回したか白状する。まいは引くどころか発情して、部屋の匂いを深く吸いこむ。ベッドに倒れこんで、〇〇の匂いがしみこんだ枕に顔をうずめる。〇〇がまだ「まいまい」と呼んで、敬語とタメ口が混じる。まいが「敬語、やめて」「まいまい、っていうのも」とねだる。〇〇は照れながら「……まいちゃん」。まいは笑って「ちゃん、ついてる」「でも、いいよ。今はね」。〇〇はタメ口になる
- **決め台詞**：なし
- **エロの中身**：ベッドでキス。まいが部屋にこもった精液の匂いと、〇〇の枕の匂いを嗅いで濡れる（匂いでの発情）
- **位置関係**：〇〇のベッド
- **感情の流れ**：（まい）この部屋で、私の写真で何回も → うれしい、匂いだけで濡れる → もっと近くなりたい （〇〇）匂いを知られて恥ずかしい → 引かれていない → ぎこちなく、呼び方と口調が変わる

## 場面4：ベッドで

- **流れ**：さっき出したばかりなのに、〇〇のちんぽはまだ硬い。まいはそれを見て、うれしそうに自分から跨がる。3話では奥に当たりすぎて動けなかったが、今夜は自分から腰を打ちつける。それでもすぐに崩れて、〇〇が下から突き上げる。そのあと〇〇が上になり、まいは脚を〇〇の腰に絡めて、抜かせない。まいはハードコアな淫語で何度も中に欲しがり、〇〇は何度も中に出す
- **決め台詞**：なし
- **エロの中身**：騎乗位（まいが自分から杭打ち）→ 下からの突き上げ → 正常位（まいが脚を絡めて、抜かせない）。抜かずの中出しを続けて。連続絶頂。喘ぎ声はレベル4
- **位置関係**：〇〇が仰向け、まいが跨がる → 〇〇が上になり、まいが仰向けで〇〇の腰に脚を絡める
- **感情の流れ**：（まい）自分から取りにいく → それでも負ける → 何回出されても足りない （〇〇）「まいちゃん」と呼びながら、欲のまま

## 場面5：事後

- **流れ**：シーツはぐしょぐしょ。テーブルの飲みかけのペットボトルの水を、二人で回し飲みする。まいの声はかすれている。まいは洗面所に、自分の歯ブラシを一本置いていく（ロケの荷物に入っていたもの）。「また明日、来ていい？」。〇〇の「いつでも」に、まいは笑う。終電を過ぎていて、まいは表の通りからタクシーで帰る
- **決め台詞**：なし
- **エロの中身**：余韻
- **位置関係**：〇〇の部屋 → 玄関
- **感情の流れ**：（まい）満たされているのに、もう明日のことを考えている （〇〇）まいまいが、この部屋に通うようになる
- **橋渡し**：〇〇の部屋に通うようになる（歯ブラシが最初の一本）
