# 第1部 まい編 6話：日常

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。

第1部の最後の話。5話から数週間。会えるときは毎回会うのが当たり前になり、完堕ちが日常になっている。行き来するうちに、行為もエスカレートしている。〇〇が調子に乗りはじめる。最後に第2部への引きを置く。読者が抜けることをいちばんに、行為はたっぷり入れる。

- **まい**：完堕ち。〇〇の部屋とまいの家を行き来する。仕事の前にも後にも求める。表では完璧に笑っている。5話より恥も外聞もなくなっていて、自分から新しいことをねだる
- **〇〇**：タメ口。ちんぽの前で崩れるまいを見続けて、自信と余裕がつき、調子に乗りはじめる（わざと聞く、言わせる、焦らす、表の顔で煽る）。言い方は短い「〜て」の形まで。命令形は使わない。〇〇からも、お願いの形で持ちかける（「これ、してみたい」）
- **描かれない回**：5話のあと、まいは週に何回も〇〇の部屋に来ている。泊まる日もある。〇〇の洗面所に、歯ブラシ、メイク落とし、ヘアゴム、部屋着が増えている。来たら玄関でまず咥えるのが当たり前になっている。〇〇の部屋の匂いは、もう消えない
- **エスカレートの見せ方**：5話で初めてだったこと（喉の奥まで、ごっくん、ハメ潮、触られずにイく）が、6話では当たり前になっている。そのうえで、新しいこと（足コキ、顔射、出されたまま仕事、焦らされて言わされる、表の声のまま突かれる）が加わる
- **橋渡し**：〇〇の部屋に通っている／LINEが増えている（エロ写メとデカチンの写真のやりとり）／仕事中のまいの調子がよさそう

## 場面1：朝、〇〇の部屋

- **流れ**：まいが泊まった翌朝。目覚ましが鳴る前に、まいは〇〇の朝勃ちに気づいて、もう咥えている。〇〇が目を覚ますと、まいは咥えたまま「おはよ」と目で笑う。寝起きのちんぽの匂いを嗅いで、喉の奥まで呑みこむ（5話で初めてだったことが、もう当たり前になっている）。〇〇はまいの口に一回出す。まいは口を開けて見せてから飲む。萎えないちんぽに「まだ、かたい」と跨がる。出かける時間が迫っていても、やめない。騎乗位から、時間がないのに〇〇が下から突き上げて、まいは連続でイく。〇〇は中に出す。まいはシャワーを浴びずに、「このまま行く」と言って下着をはく。〇〇の部屋に置いてある自分の歯ブラシで歯をみがき、玄関でキスをして、仕事に出かける
- **決め台詞**：まい「……このまま、行く」（方向。言い回しは本文で調整する）
- **エロの中身**：寝起きのフェラ（朝勃ち、匂い、喉の奥まで）→ 口内射精、ごっくん → 騎乗位 → 下からの突き上げ → 中出し。出されたまま下着をはく。喘ぎ声はレベル3〜4（朝なので、時間を気にしながら）
- **位置関係**：〇〇のベッド → 洗面所 → 玄関
- **感情の流れ**：（まい）起きた瞬間から欲しい → 時間がないのにやめられない → 出されたまま仕事に行くのがうれしい （〇〇）まいまいの物が増えた部屋、自分の歯ブラシの隣のまいまいの歯ブラシ

## 場面2：楽屋（表）

- **流れ**：その日の歌番組の楽屋。まいは表の顔で、メンバーと笑っている。メイクに「まいまい、最近ほんと肌きれいだよね」と言われ、「保湿してるくらい」とかわす。ときどき、中から垂れてくる感覚に、表の顔のまま太ももを閉じる。トイレの個室で、ショーツについた〇〇の精液を指ですくって舐め、その指と、汚れたショーツの写真を〇〇に送る。『まだ、垂れてくる』『〇〇くんの』。〇〇からは、勃起したちんぽの写真が返ってくる（『今夜も、これ』）。まいは個室の中で、その写真に唇を寄せる。鏡の前に戻って、表の顔でリップを直す。ほのかが、スマホを見て笑うまいを鏡越しに見ている
- **決め台詞**：なし
- **エロの中身**：まいの心の声と、〇〇とのLINE（垂れてきた精液を舐めた指の写真、汚れたショーツの写真、〇〇のちんぽの写真）。行為はトイレの個室で、指を舐めるだけ
- **位置関係**：楽屋の鏡の前 → トイレの個室 → 鏡の前。まい、ほのか、なぎ、ほかのメンバー2〜3人
- **感情の流れ**：（まい）完璧な表の顔 → 中に残っている感覚 → 〇〇に伝えたい → 写真が返ってきて、すぐにでも欲しい → 表の顔に戻る （ほのか）なんとなく、気になる
- **表の場での漏れ**：トイレの個室からの下品なLINEと写真。誰も気づかない
- **橋渡し**：LINEが増えている（デカチンの写真は、第2部1話でほのかが見る）／仕事中のまいの調子がよさそう

## 場面3：夕飯のテーブルの下で（〇〇の部屋）

- **流れ**：その夜、仕事帰りのまいが〇〇の部屋に来る。玄関で咥えかけたまいを、〇〇が「先にごはん食べよ」と止める（〇〇が焦らす、最初の芽）。〇〇が作った焼きそばを、小さなテーブルで向かい合って食べる。まいはテレビの話をしながら、テーブルの下で、ストッキングを脱いだ足を〇〇の股間に伸ばす。足の裏で、ジーンズの上から撫でる。〇〇が箸を止めても、まいは普通の顔で「どうしたの？」と食べ続ける（表の顔の練習みたいに）。〇〇がジーンズを下ろすと、まいは両足で挟んでしごく。〇〇がたまらず「……顔に、かけたい」とお願いする。まいはうれしそうにテーブルの横に膝をついて、目を閉じ、顔を差し出す。〇〇はまいの顔に出す。まいは顔についた精液を指で集めて舐め、残りを〇〇のちんぽで顔に塗りひろげさせる。そのまま、テーブルに手をついて「ごはん、さめちゃうね」と笑いながら、自分からお尻を突き出す。立ちバックで中出し。焼きそばは冷めてしまう
- **決め台詞**：なし
- **エロの中身**：足コキ（テーブルの下で、食べながら。足の裏で撫でる → 両足で挟んでしごく）→ 顔射（〇〇のお願い）→ 顔の精液を指で集めて舐める、ちんぽで顔に塗りひろげる → テーブルに手をついての立ちバック、中出し。喘ぎ声はレベル3
- **位置関係**：小さなテーブルを挟んで向かい合って座る（まいの足が、テーブルの下で〇〇の股間に届く）→ まいがテーブルの横で膝立ち、〇〇が立つ → まいがテーブルに両手をつき、〇〇が後ろから
- **感情の流れ**：（まい）焦らされて、ちょっとくやしい → 食べながら、普通の顔で責めるのが楽しい → 顔に出されて、うれしい → ごはんより、ちんぽ （〇〇）まいまいが、普通の顔で、テーブルの下で → お願いしたら、喜んで顔を差し出してくれた

## 場面4：まいの家で

- **流れ**：別の夜、まいの家。〇〇がまいの家に来るのは3話以来。リビングのソファで、まいの出た歌番組の録画を流しながら始まる。〇〇はテレビの中で笑っているまいと、目の前のまいを見比べて、「さっきテレビで笑ってたのに、こんな顔して」と煽る（〇〇が初めて、はっきり調子に乗る）。まいはそれでさらに崩れる。最中にインターホンが鳴る。マネージャーが明日の資料を届けに来た。まいは〇〇とつながったまま、インターホン越しに表の声で応え、「ポストに入れておいてください」と頼む。〇〇は、わざとゆっくり動く。まいは声を保ったまま、太ももを震わせる。マネージャーが帰ったあと、まいは崩れきる
- **決め台詞**：〇〇「さっきテレビで笑ってたのに、こんな顔して」（方向。言い回しは本文で調整する）
- **エロの中身**：ソファで、テレビの録画を流しながら。背面座位（まいがテレビのほうを向いて、自分の映った画面を見ながら）→ インターホンの前まで移って、立ちバック（つながったままインターホンに応える。〇〇はわざとゆっくり）→ マネージャーが帰ったあと、激しく。潮吹き。中出し。喘ぎ声は、インターホンのあいだはレベル1（表の声を保つ）→ そのあとレベル4
- **位置関係**：リビングのソファ。〇〇が座り、まいが〇〇に背中を向けて跨がり、テレビのほうを向く → 壁のインターホンのモニターの前で、まいが壁に片手をつき、〇〇が後ろから
- **感情の流れ**：（まい）テレビの自分と見比べられて恥ずかしいのに、うれしい → インターホンに表の声で応える → 〇〇がわざと動いて、声を保つのがぎりぎり → 帰ったあと、崩れきる （〇〇）テレビの中のまいまいと、目の前のまいまい → 調子に乗ってみたら、まいが喜ぶ → もっと
- **バレるかもしれない緊張**：マネージャーのインターホン

## 場面5：まいの寝室で

- **流れ**：そのまま寝室へ。〇〇は、ちんぽをまいの顔の前に出して、すぐには入れない。「どこに欲しいの？」「ちゃんと言って」と、わざと聞く。まいはハードコアな淫語で、何度でも言う。〇〇は「先っぽだけね」と焦らし、入口だけを何度も出し入れする。まいが泣きそうにねだるまで待ってから、奥まで突き入れる。姿見の前で、片脚を抱えての立ちバック。姿見に、崩れたまいが映る。〇〇はまいの顎を持ち上げて、「見て」と鏡の中の顔を見せる。まいは自分のアヘ顔を見ながらイく。ベッドで種付けプレス。抜かずに何度も中に出す。最後は、まいが〇〇のものを抜いて、自分の中から出てきたものと一緒にお掃除フェラをして、もう一度咥えたまま眠そうに笑う
- **決め台詞**：なし
- **エロの中身**：焦らし（先っぽだけ、言わせる）→ 姿見の前で、片脚を抱えての立ちバック（鏡の中の自分の顔を見せられる）→ ベッドで種付けプレス。抜かずの連続中出し。連続絶頂、アヘ顔。お掃除フェラ。喘ぎ声はレベル4
- **位置関係**：まいの寝室。ベッドの上でまいが膝立ち、〇〇が前に立つ → 姿見の前で、まいが姿見に手をつき、〇〇が後ろからまいの片脚を抱える → ベッドで、まいが仰向けで脚を抱え、〇〇が真上から
- **感情の流れ**：（まい）焦らされてつらい → 言わされるのがうれしい → 入った瞬間に崩れる → 鏡の中の自分の顔で、また崩れる （〇〇）まいまいが、自分の言葉どおりに言う → 写真集の表紙の顔が、鏡の中でぐちゃぐちゃになっている
