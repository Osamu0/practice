# 第1部 まい編 6話：日常

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

第1部の最後の話。5話から数週間。会えるときは毎回会うのが当たり前になり、完堕ちが日常になっている。〇〇が調子に乗りはじめる。最後に第2部への引きを置く。

- **まい**：完堕ち。〇〇の部屋とまいの家を行き来する。仕事の前にも後にも求める。表では完璧に笑っている
- **〇〇**：タメ口。ちんぽの前で崩れるまいを見続けて、自信と余裕がつき、調子に乗りはじめる（わざと聞く、言わせる、焦らす、表の顔で煽る）。言い方は短い「〜て」の形まで。命令形は使わない
- **描かれない回**：5話のあと、まいは週に何回も〇〇の部屋に来ている。泊まる日もある。〇〇の洗面所に、歯ブラシ、メイク落とし、ヘアゴム、部屋着が増えている
- **橋渡し**：〇〇の部屋に通っている／LINEが増えている／仕事中のまいの調子がよさそう

## 場面1：朝、〇〇の部屋

- **流れ**：まいが泊まった翌朝。目覚ましが鳴る前に、まいは〇〇の朝勃ちに気づいて、もう咥えている。〇〇が起きると「おはよ」と言いながら跨がる。出かける時間が迫っていても、やめない。〇〇は中に出す。まいはシャワーを浴びずに、「このまま行く」と言って下着をはく。〇〇の部屋に置いてある自分の歯ブラシで歯をみがき、玄関でキスをして、仕事に出かける
- **決め台詞**：まい「……このまま、行く」（方向。言い回しは本文で調整する）
- **エロの中身**：寝起きのフェラ（朝勃ち）→ 騎乗位で中出し。出されたまま下着をはく。喘ぎ声はレベル3（朝なので、時間を気にしながら）
- **位置関係**：〇〇のベッド → 洗面所 → 玄関
- **感情の流れ**：（まい）起きた瞬間から欲しい → 時間がないのにやめられない → 出されたまま仕事に行くのがうれしい （〇〇）まいまいの物が増えた部屋、自分の歯ブラシの隣のまいまいの歯ブラシ

## 場面2：楽屋（表）

- **流れ**：その日の歌番組の楽屋。まいは表の顔で、メンバーと笑っている。メイクに「まいまい、最近ほんと肌きれいだよね」と言われ、「保湿してるくらい」とかわす。ときどき、中から垂れてくる感覚に、表の顔のまま太ももを閉じる。トイレの個室から〇〇にLINE『まだ、垂れてくる』『〇〇くんの』。ほのかが、スマホを見て笑うまいを鏡越しに見ている
- **決め台詞**：なし
- **エロの中身**：なし。まいの心の声と、〇〇へのLINE
- **位置関係**：楽屋の鏡の前。まい、ほのか、なぎ、ほかのメンバー2〜3人
- **感情の流れ**：（まい）完璧な表の顔 → 中に残っている感覚 → 〇〇に伝えたい （ほのか）なんとなく、気になる
- **表の場での漏れ**：トイレの個室からの下品なLINE。誰も気づかない
- **橋渡し**：LINEが増えている／仕事中のまいの調子がよさそう

## 場面3：まいの家で

- **流れ**：別の夜、まいの家。〇〇がまいの家に来るのは3話以来。リビングのソファで、まいの出た歌番組の録画を流しながら始まる。〇〇はテレビの中で笑っているまいと、目の前のまいを見比べて、「さっきテレビで笑ってたのに、こんな顔して」と煽る（〇〇が初めて調子に乗る）。まいはそれでさらに崩れる。最中にインターホンが鳴る。マネージャーが明日の資料を届けに来た。まいは〇〇とつながったまま、インターホン越しに表の声で応え、「ポストに入れておいてください」と頼む。〇〇は、わざとゆっくり動く。まいは声を保ったまま、太ももを震わせる。マネージャーが帰ったあと、まいは崩れきる
- **決め台詞**：〇〇「さっきテレビで笑ってたのに、こんな顔して」（方向。言い回しは本文で調整する）
- **エロの中身**：ソファで、テレビの録画を流しながら。背面座位（まいがテレビのほうを向いて、自分の映った画面を見ながら）→ インターホンの前まで移って、立ちバック（つながったままインターホンに応える。〇〇はわざとゆっくり）→ マネージャーが帰ったあと、激しく。中出し。喘ぎ声は、インターホンのあいだはレベル1（表の声を保つ）→ そのあとレベル4
- **位置関係**：リビングのソファ。〇〇が座り、まいが〇〇に背中を向けて跨がり、テレビのほうを向く → 壁のインターホンのモニターの前で、まいが壁に片手をつき、〇〇が後ろから
- **感情の流れ**：（まい）テレビの自分と見比べられて恥ずかしいのに、うれしい → インターホンに表の声で応える → 〇〇がわざと動いて、声を保つのがぎりぎり → 帰ったあと、崩れきる （〇〇）テレビの中のまいまいと、目の前のまいまい → 調子に乗ってみたら、まいが喜ぶ → もっと
- **バレるかもしれない緊張**：マネージャーのインターホン

## 場面4：まいの寝室で

- **流れ**：そのまま寝室へ。〇〇は、ちんぽをまいの顔の前に出して、すぐには入れない。「どこに欲しいの？」「ちゃんと言って」と、わざと聞く。まいはハードコアな淫語で、何度でも言う。〇〇は「先っぽだけね」と焦らし、まいが泣きそうにねだるまで待ってから、奥まで突き入れる。姿見に、崩れたまいが映る
- **決め台詞**：なし
- **エロの中身**：焦らし（先っぽだけ、言わせる）→ 姿見の前で、片脚を抱えての立ちバック → ベッドで種付けプレス。中出し。連続絶頂。喘ぎ声はレベル4
- **位置関係**：まいの寝室。ベッドの上でまいが膝立ち、〇〇が前に立つ → 姿見の前で、まいが姿見に手をつき、〇〇が後ろからまいの片脚を抱える → ベッドで、まいが仰向けで脚を抱え、〇〇が真上から
- **感情の流れ**：（まい）焦らされてつらい → 言わされるのがうれしい → 入った瞬間に崩れる （〇〇）まいまいが、自分の言葉どおりに言う → 写真集の表紙の顔が、鏡の中でぐちゃぐちゃになっている
