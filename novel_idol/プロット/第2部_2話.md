# 第2部 ほのか編 2話：跡をつける

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。

1話の続き、同じ日の夜。ほのかが、写真じゃない本物を初めて見る。ほのかの視点が中心。

- **見え方の線**：ほのかは、まいの数十メートル後ろ。部屋に入るところは、道の向かいの自動販売機の陰から遠くに見る。声とドアの隙間は、外廊下の突き当たりの非常階段の踊り場から（203のドアまで数メートル）。遠くからでは細かいもの（太ももの汚れ、キスマークなど）は見えない。近くで見るのは翌日の楽屋
- **非常階段**：ほのかは、外廊下を通らずに、建物の外側の非常階段から踊り場にのぼる（203の前を通らない）

## 場面1：跡をつける

- **流れ**：まいは駅まで歩いて、電車に乗る。ほのかは隣の車両から見ている。降りたのは、ほのかの知らない駅。まいは慣れた足取りで、街灯の少ない住宅街を歩いていく
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：夜の街と電車。まいの数十メートル後ろに、ほのか
- **感情の流れ**：（ほのか）何してんの、私 → でも、止まれない

## 場面2：部屋に入る

- **流れ**：まいが着いたのは、トップアイドルが住んでいるとは思えない、古いアパート。外階段をのぼって、二階の部屋のインターホンを押す。鳴り終わらないうちにドアが開き、まいは男に飛びつくようにして中へ入っていく。ほのかは道の向かいの自販機の陰から、遠くにそれを見る。男の顔は、はっきりとは見えない
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：アパートの外。ほのかは道の向かいの自動販売機の陰
- **感情の流れ**：（ほのか）こんな普通の部屋に？ → あの人が、LINEの相手

## 場面3：ドア越しの声

- **流れ**：ほのかは帰れない。建物の横の非常階段をのぼって、外廊下の突き当たりの踊り場に身を隠す。203のドアまで数メートル。薄いドアの向こうから、声が聞こえる。表では一度も聞いたことのない、まいの声。完堕ちしたまいの、ハードコアな淫語。そのあいだに、男の声も聞こえる（調子に乗った〇〇が、まいを煽っている）。ほのかはその場で濡れる。隣の部屋の住人が帰ってきて、ほのかは踊り場の奥で息を殺す
- **決め台詞**：なし（ドア越しに聞こえるまいの声と〇〇の煽りは、本文で書く。くぐもっていて途切れ途切れだが、何を言っているかはわかる）
- **エロの中身**：ドア越しの、まいの喘ぎ声（レベル4）と淫語、〇〇の煽る声。ほのかは立ち尽くして、太ももをこすり合わせる（触りはしない）
- **位置関係**：非常階段の踊り場。203のドアから数メートル
- **感情の流れ**：（ほのか）写真で見た、あれが → まいちゃん、こんな声 → 羨ましい → 動けない

## 場面4：帰り際のドアの隙間

- **流れ**：夜中、ドアが開く。まいが帰るところ。でも、まいは玄関で靴をはいたまま、しゃがみこむ。開いたドアの隙間から、ほのかの目に入る。玄関にしゃがんだまいが、〇〇のちんぽに頬ずりして、キスをして、咥えている（帰る前に、もう一回）。写真で見た、あれ。本物。グループの顔が、見たことのない顔をしている。しばらくして、まいは立ち上がり、ドアの前で〇〇と何度もキスをして、なかなか離れない。まいは外階段を降りていく。足取りがふらついていて、途中で一度、壁に手をつく
- **決め台詞**：なし
- **エロの中身**：ドアの隙間から見える、玄関でのフェラ（頬ずり、キス、咥える）。〇〇のちんぽを、ほのかが初めて実物で見る。ほのかの本能の疼き
- **位置関係**：ほのかは非常階段の踊り場。203のドアは外廊下側に開き、隙間から玄関の中が一瞬見える
- **感情の流れ**：（ほのか）写真じゃない、本物 → まいちゃんの、あんな顔 → 疼きが止まらない → 羨ましい

## 場面5：帰り道

- **流れ**：ほのかは、何もせずに帰る。終電はもうない。駅前のロータリーからタクシーに乗る。運転手に住所を聞かれて、すぐに出てこない。203という部屋番号が、頭に焼きついている。家に着くまで、下腹の疼きが消えない
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：夜道 → タクシー
- **感情の流れ**：（ほのか）見なかったことにしたい → できない → 203が頭から離れない

## 場面6：翌日の楽屋

- **流れ**：翌日の楽屋。着替えのとき、ほのかは近くで、まいの内もものキスマークと、腰に残る指の跡を見てしまう。まいの声は少しかすれている（まいは「昨日、歌いすぎた」とごまかす）。ほのかは、のど飴を渡す。それでも、その日の収録のまいは最高の出来で、また褒められている
- **決め台詞**：なし
- **エロの中身**：なし。まいの身体に残る跡。ほのかの疼き
- **位置関係**：楽屋の着替えスペース → スタジオ
- **感情の流れ**：（ほのか）昨日の、あれの跡 → それでも、こんなに輝いてる → 羨ましい
- **ねらい**：3話（何日か跡をつけ続けたあと、ピンポン）への引き
