# 第2部 ほのか編 3話：ピンポン

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。

2話は「最初の夜」。この話の冒頭は「それから何日か跡をつけ続ける」ところから始まる。

## 場面1：何日か跡をつけ続ける

- **流れ**：あの夜から、ほのかは何日か、仕事のあとにまいの跡をつけてしまう。まいは、何度も同じアパートに入っていく。そのたびに、ほのかは物陰で待って、まいが出てくるのを見届ける。やめようと思っても、やめられない
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：夜の街 → アパートの物陰
- **感情の流れ**：（ほのか）またやってしまった → 見るたびに、気になる気持ちが大きくなる → 見ているだけでは足りなくなる

## 場面2：空き時間

- **流れ**：夜の収録までに、2時間ほど空き時間ができる（〇〇は会社員なので、帰宅している夕方〜夜）。〇〇の部屋は、その日の現場から近い。ほのかは、気づくと〇〇の部屋に向かっている
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：現場 → 〇〇の部屋へ
- **感情の流れ**：（ほのか）行ったらあかん → でも、足が止まらない

## 場面3：ピンポン

- **流れ**：インターホンが鳴る。予定はなかったが、この部屋を訪ねてくるのはまいしかいないので、〇〇はまいが来たと思い込んで、うれしそうにドアを開ける。そこに立っていたのは、変装したほのか。〇〇は固まる（箱推しなので、ほのかのことも知っている）
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：〇〇の部屋の玄関。ドアを挟んで
- **感情の流れ**：（〇〇）まいちゃんだと思ったら → ほのちゃん？　なんで？

## 場面4：問い詰める

- **流れ**：ほのかは、玄関に入ってドアを閉める。丁寧語のまま、でも引かずに、まいとしていることを問い詰める。〇〇は「終わった」と焦る。バラされる、まいに迷惑がかかる、と頭が真っ白になる。ところが、ほのかの口から出たのは、責める言葉ではなかった。思わぬ展開に、〇〇はさらに固まる
- **決め台詞**：
  - 問い詰める一言「この部屋で、まいちゃんと何してるか、知ってるんです」
  - 思わぬ一言「責めに来たんやないんです。……私も、したくて」
- **エロの中身**：なし
- **位置関係**：玄関の中。ほのかがドアを背に立ち、〇〇と向かい合う
- **感情の流れ**：（ほのか）問い詰める → 本当に言いたかったことが口から出る （〇〇）焦り → 終わった → 思わぬ一言に混乱

## 場面5：手と口

- **流れ**：部屋に上がる。ほのかが、おそるおそる〇〇に触れる。〇〇もほのかに触れる。ほのかは〇〇のモノを見て、ドア越しに聞いたまいの声を思い出す。手で触れて、口に含む。〇〇は、ほのかの口の中に出してしまう。ほのかは、その味まで知ってしまう
- **決め台詞**：なし
- **エロの中身**：キス、服を着たままの愛撫（時間がないので、ほのかは脱がないまま。服の上から、そしてスカートの中へ）、手マン、手コキ、フェラ、口内射精。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの縁に並んで座る → 〇〇がベッドの縁に座ったまま、ほのかが床に膝をつく
- **感情の流れ**：（ほのか）こわい → 知りたい → 止まらない → 味まで知ってしまう

## 場面6：時間切れ

- **流れ**：ほのかのスマホに、マネージャーから「そろそろ戻って」と連絡が入る。最後まではしないまま、ほのかは名残惜しく帰る
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：〇〇の部屋の玄関
- **感情の流れ**：（ほのか）もう少しだったのに → 最後まで、できなかった

## 場面7：仕事に戻る

- **流れ**：夜の収録。ほのかは表の顔に戻って仕事をする。でも、頭の中は〇〇の部屋のことでいっぱい。収録が終わったら、もう一度行こうと決める
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：スタジオ
- **感情の流れ**：（ほのか）表の顔 → 内心は続きのことばかり
- **ねらい**：4話（その夜、戻ってきて堕ちる）への引き
