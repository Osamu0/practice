# 第2部 ほのか編 3話：ピンポン

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

2話から何日か。ほのかは跡をつけ続け、チラ見えも続く。毎晩一人でしても届かない。疼きと羨ましさが重なって、我慢できなくなる。まいが来ない日だと知って、空き時間にピンポンする。

- **ほのか**：表のまま。〇〇には丁寧語。我慢できなくなって動くが、まだ堕ちてはいない。〇〇のちんぽを前にすると、本能で目が離れない
- **〇〇**：ほのかは初対面なので敬語。手と口のあたりで、タメ口が混じりはじめる
- **前半はほのかの視点、ピンポンからは〇〇の視点**（目安。本文を書くときに決める）

## 場面1：何日か跡をつけ続ける

- **流れ**：あの夜から、ほのかは何回か、仕事のあとにまいの跡をつけてしまう。2回目からはドアの前まで行かず、道の向かいの自販機の陰から、203の窓の明かりを見ている。まいは日付が変わるころに出てくる日も、泊まる日もある。家に帰ると、毎晩一人でする。でも、何度しても届かない
- **決め台詞**：なし
- **エロの中身**：ほのかのオナニー（短く。届かない）
- **位置関係**：自販機の陰 → ほのかの部屋
- **感情の流れ**：（ほのか）またやってしまった → 見ているだけでは足りない → 届かない

## 場面2：4回目のチラ見え（〇〇の部屋の中）

- **流れ**：楽屋で、まいのスマホの画面がまた見えてしまう。まいが〇〇に送った写真。〇〇の部屋のベッドの上で、まいが撮ったもの。ほのかが外から明かりを見ていた、あの部屋の中
- **決め台詞**：なし
- **エロの中身**：なし。写真（〇〇の部屋のベッドで、事後のまい）。ほのかの疼き
- **位置関係**：楽屋
- **感情の流れ**：（ほのか）外から見ていた部屋の中で、こんなことを → 羨ましい

## 場面3：収録中の疼き

- **流れ**：昼の収録。ほのかは表の顔で仕事をしている。でも、ふとした瞬間に写真やドア越しの声を思い出してしまう。カメラの前で笑っているのに、下着が湿っている
- **決め台詞**：なし
- **エロの中身**：なし。ほのかの心の声と疼き
- **位置関係**：テレビ局のスタジオ
- **感情の流れ**：（ほのか）表の顔は保っている → でも、頭の中は → もう、限界

## 場面4：5回目のチラ見え（まいが来ない日）

- **流れ**：楽屋で、まいのスマホに〇〇からの通知。プレビューで、今夜まいが行けないことがわかる（まいはこのあと夜遅くまでドラマの撮影）
- **決め台詞**：通知のプレビュー（例。言い回しは本文で調整する）
  > 〇〇『今日は会えないのかー』
  > 〇〇『撮影がんばってね』
- **エロの中身**：なし
- **位置関係**：楽屋
- **感情の流れ**：（ほのか）今夜、まいちゃんは来ない

## 場面5：空き時間

- **流れ**：夜の収録のスタジオで機材トラブルがあり、2時間ほど空き時間ができる。〇〇は会社員なので、もう帰っている時間。テレビ局から〇〇の最寄り駅までは近い。ほのかは、気づくと〇〇の部屋に向かっている
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：テレビ局 → 電車 → 〇〇のアパート
- **感情の流れ**：（ほのか）行ったらあかん → でも、まいちゃんは来ない → 足が止まらない

## 場面6：ピンポン

- **流れ**：インターホンが鳴る。この部屋を訪ねてくるのはまいだけなので、〇〇は、撮影が早く終わったのかと思って、うれしそうにドアを開ける（「まいちゃん、来れたの――」）。そこに立っていたのは、帽子とマスクのほのか。〇〇は固まる（箱推しなので、ほのかのことも知っている）
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：〇〇の部屋の玄関。ドアを挟んで
- **感情の流れ**：（〇〇）まいちゃんだと思ったら → ほのちゃん？　なんで？

## 場面7：問い詰める

- **流れ**：ほのかは玄関に入ってドアを閉める。丁寧語のまま、でも引かずに、まいとしていることを問い詰める。LINEを見たこと、跡をつけたこと、ドア越しに声を聞いたこと、帰り際に見てしまったこと。〇〇は「終わった」と焦る。バラされる、まいに迷惑がかかる、と頭が真っ白になる。ところが、ほのかの口から出たのは、責める言葉ではなかった
- **決め台詞**：
  - 問い詰める一言「この部屋で、まいちゃんと何してるか、知ってるんです」
  - 思わぬ一言「責めに来たんやないんです。……私も、したくて」
- **エロの中身**：なし
- **位置関係**：玄関の中。ほのかがドアを背に立ち、〇〇と向かい合う
- **感情の流れ**：（ほのか）問い詰める → 本当に言いたかったことが口から出る （〇〇）焦り → 終わった → 思わぬ一言に混乱 → 〇〇の心の声：（歌番組で、まいの隣に並んでる顔だ……）

## 場面8：手と口

- **流れ**：部屋に上がる。ほのかが、おそるおそる〇〇に触れる。〇〇もほのかに触れる。〇〇がズボンを下ろすと、ほのかは写真で見て、ドアの隙間から見たちんぽを、目の前で見る。目が離れない。本能で疼く。手で触れて、口に含む。〇〇は、ほのかの口の中に出してしまう。ほのかは、その味まで知ってしまう。出したあとも、〇〇のちんぽは硬いまま
- **決め台詞**：なし
- **エロの中身**：キス、服を着たままの愛撫（時間がないので、ほのかは脱がないまま。服の上から、そしてスカートの中へ）、手マン、手コキ、フェラ、口内射精。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの縁に並んで座る → 〇〇がベッドの縁に座ったまま、ほのかが床に膝をつく
- **感情の流れ**：（ほのか）こわい → 本物が目の前に → 目が離れない → 止まらない → 味まで知ってしまう （〇〇）ほのちゃんが、自分のちんぽを咥えている

- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：〇〇の部屋の玄関
- **感情の流れ**：（ほのか）もう少しだったのに → 最後まで、できなかった

- **流れ**：夜の収録。ほのかは表の顔に戻って仕事をする。下着は湿ったまま、唇が少し腫れぼったい。頭の中は〇〇の部屋のことでいっぱい。収録が終わったら、もう一度行こうと決める
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：スタジオ
- **感情の流れ**：（ほのか）表の顔 → 内心は続きのことばかり
- **ねらい**：4話（その夜、戻ってきて、ほぼ完堕ち）への引き
