# 第2部 ほのか編 4話：その夜

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ほのかの大阪弁は `企画メモ.md` の「大阪弁の味」を参照（標準語と混ざる。乱れたときは可愛い大阪弁。「いってまう」は使わない）。

3話と同じ日の夜。ほのか編の山場で、ほのかが堕ちる。

## 場面1：2人とも悶々としている

- **流れ**：
  - **ほのか**：夜の収録。笑顔で仕事をしながら、さっきのことが頭から離れず、身体が疼いている。収録が終わると、挨拶もそこそこに〇〇の部屋へ向かう
  - **〇〇**：ほのかが帰ったあと、部屋で一人。口の中に出したこと、最後までしなかったことが頭から離れない。まさか本当に戻ってくるのか、と落ち着かない
- **決め台詞**：なし
- **エロの中身**：なし。それぞれの心の声で、悶々としている
- **位置関係**：ほのかはスタジオ → 〇〇の部屋へ。〇〇は自分の部屋
- **感情の流れ**：（ほのか）我慢の限界 → 急ぐ （〇〇）落ち着かない → 期待してしまう

## 場面2：二度目のピンポン

- **流れ**：ほのかがインターホンを押す。〇〇がドアを開けた瞬間、ほのかは何も言わずに〇〇に抱きつく。胸に顔をうずめたまま、小さな声で一言
- **決め台詞**：ほのか「……さっき、途中やったから」
- **エロの中身**：なし
- **位置関係**：玄関。ほのかが〇〇の胸に顔をうずめて抱きつく
- **感情の流れ**：（ほのか）言葉より先に身体が動く （〇〇）本当に戻ってきた

## 場面3：前戯

- **流れ**：ベッドへ。ほのかの下着は、もう濡れている。〇〇は、さっきより遠慮なく触れる。タメ口になっている。ほのかは丁寧語で喘ぎながら、自分から脚を開く
- **決め台詞**：なし
- **エロの中身**：キス、愛撫、手マン、クンニ。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの上。ほのかが仰向け、〇〇が横から
- **感情の流れ**：（ほのか）恥ずかしい → でも、止めてほしくない

## 場面4：鏡の前で

- **流れ**：玄関の壁際に立てかけてある安い姿見を、ベッドの横に持ってくる。その姿見の前で、〇〇がほのかを後ろから抱えて座らせ、そのまま挿入する。ほのかは、鏡に映る自分を見てしまう。まいを見ていた自分が、今度は自分の乱れた姿を見る。入っていくところまで、目が離せない。ステージの上で開放的になるのと同じように、ここでほのかのスイッチが入る
- **決め台詞**：なし
- **エロの中身**：背面座位。喘ぎ声はレベル2〜3
- **位置関係**：姿見の前の床。〇〇があぐらで座り、ほのかが〇〇に背中を預けて跨がる。〇〇の手は、ほのかの胸と腰。ほのかは鏡越しに、結合部と自分の顔を見る
- **感情の流れ**：（ほのか）見たくない → 見てしまう → これが、ドア越しに聞いたまいちゃんの声の正体

## 場面5：崩れる

- **流れ**：ベッドに戻り、〇〇が上から深く突く。ほのかの丁寧語が保てなくなり、標準語の中に可愛い大阪弁がこぼれるようになる（コテコテにはしない）。〇〇が初めて「ほのか」と呼び捨てにする（3話までは敬語まじりで「ほのちゃん」）。ほのかは何度もイって、レベル4まで行く
- **決め台詞**：堕ちる瞬間「すき……っ、これ、すき……♡　もう、〇〇くんのじゃないと、いややぁ……♡　ずっと、こうしててな……？」（AとBの組み合わせ。言い回しは本文で調整する）
- **エロの中身**：屈曲位（ほのかの脚を抱えて、真上から）→ 最後は正常位で密着してキスしながら（ほのかが〇〇の手を探して恋人繋ぎにし、脚を〇〇の腰に絡めて離さない。だいしゅきホールド。堕ちる瞬間の「ずっと、こうしててな……？」につながる）。中出し。連続絶頂。喘ぎ声はレベル3 → 4。イくときは「いく……っ、いっちゃう……♡」など（「いってまう」は使わない）
- **位置関係**：ほのかが仰向けで、膝を胸に抱えられ、〇〇が真上から → 〇〇がほのかに覆いかぶさり、身体を密着させる
- **感情の流れ**：（ほのか）ここまでになるとは思っていなかった → 控えめな自分がどこかへ行ってしまう → 気持ちを隠せなくなる → 堕ちる

## 場面6：事後

- **流れ**：ほのかは、〇〇の胸の中で息を整える。〇〇は、まいのことが気になって焦る。ほのかは「まいちゃんには、まだ言わんといてください」と頼む。自分から言う、という含み
- **決め台詞**：なし
- **エロの中身**：余韻
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（ほのか）満たされた → もう戻れない
- **ねらい**：5〜6話（ほのかがまいに打ち明ける）への引き
