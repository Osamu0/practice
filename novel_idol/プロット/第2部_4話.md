# 第2部 ほのか編 4話：その夜

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ほのかの大阪弁は `企画メモ.md` の「大阪弁の味」を参照（標準語と混ざる。乱れたときは可愛い大阪弁。「いってまう」は使わない）。

3話と同じ日の夜。ほのか編の山場で、ほのかがほぼ完堕ちに届く。

- **ほのか**：写真、ドアの隙間、手と口と、何度も見てきたちんぽを、やっと中に入れる。前半は丁寧語、崩れていくうちに可愛い大阪弁がこぼれる。最後に一人称の「ほの」が初めて出る。ほのかの視点が中心（〇〇の視点の場面を挟んでもいい。本文を書くときに決める）
- **〇〇**：敬語とタメ口が混じる（3話の手と口でタメ口が混じりはじめている）。山場で初めて「ほのか」と呼び捨てにする
- **呼び方の語彙**：ほのかは「おちんぽ」に偏らせず、「おちんちん」も使う

## 場面1：2人とも悶々としている

- **流れ**：
  - **ほのか**：夜の収録。笑顔で仕事をしながら、さっき口の中で感じたものが頭から離れず、身体が疼いている。収録が終わると、挨拶もそこそこに〇〇の部屋へ向かう
  - **〇〇**：ほのかが帰ったあと、部屋で一人。ほのかの口の中に出したこと、最後までしなかったことが頭から離れない。まさか本当に戻ってくるのか、と落ち着かない。出したのに、ずっと硬いまま
- **決め台詞**：なし
- **エロの中身**：なし。それぞれの心の声で、悶々としている
- **位置関係**：ほのかはスタジオ → 〇〇の部屋へ。〇〇は自分の部屋
- **感情の流れ**：（ほのか）我慢の限界 → 急ぐ （〇〇）落ち着かない → 期待してしまう

## 場面2：二度目のピンポン

- **流れ**：ほのかがインターホンを押す。〇〇がドアを開けた瞬間、ほのかは何も言わずに〇〇に抱きつく。胸に顔をうずめたまま、小さな声で一言。それから、ほのかの手が〇〇の股間に伸びる。硬いのに気づいて、ほのかの目つきが変わる
- **決め台詞**：ほのか「……さっき、途中やったから」
- **エロの中身**：玄関で、服の上からちんぽに触れる
- **位置関係**：玄関。ほのかが〇〇の胸に顔をうずめて抱きつく
- **感情の流れ**：（ほのか）言葉より先に身体が動く → また、これ （〇〇）本当に戻ってきた

## 場面3：前戯

- **流れ**：ベッドへ。ほのかの下着は、夕方からずっと湿ったまま。〇〇は、さっきより遠慮なく触れる。ほのかは丁寧語で喘ぎながら、自分から脚を開く
- **決め台詞**：なし
- **エロの中身**：キス、愛撫、手マン、クンニ。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの上。ほのかが仰向け、〇〇が横から → 脚のあいだへ
- **感情の流れ**：（ほのか）恥ずかしい → でも、止めてほしくない

## 場面4：鏡の前で

- **流れ**：玄関の壁際に立てかけてある安い姿見を、ベッドの横に持ってくる。その姿見の前で、〇〇がほのかを後ろから抱えて座らせ、そのまま挿入する。ほのかは、鏡に映る自分を見てしまう。ドアの隙間から、まいのあの顔を見ていた自分が、今度は自分の乱れた顔を見る側になる。入っていくところまで、目が離せない。ステージの上で開放的になるのと同じように、ここでほのかのスイッチが入る
- **決め台詞**：なし
- **エロの中身**：背面座位。結合部を鏡に映す。喘ぎ声はレベル2〜3
- **位置関係**：姿見の前の床。〇〇があぐらで座り、ほのかが〇〇に背中を預けて跨がる。〇〇の手は、ほのかの胸と腰。ほのかは鏡越しに、結合部と自分の顔を見る
- **感情の流れ**：（ほのか）見たくない → 見てしまう → まいちゃんのあの顔は、これやったんや → 見られたい、の芽

## 場面5：崩れる

- **流れ**：ベッドに戻り、〇〇が上から深く突く。ほのかの丁寧語が保てなくなり、標準語の中に可愛い大阪弁がこぼれる（コテコテにはしない）。〇〇が初めて「ほのか」と呼び捨てにする（それまでは「ほのちゃん」）。ほのかは何度もイって、レベル4まで行く。最後は、脚を〇〇の腰に絡めて、抜かせない。全部中に出させる
- **決め台詞**：ほぼ完堕ちに届く瞬間「すき……っ、これ、すき……♡　もう、〇〇くんのおちんちんじゃないと、いややぁ……♡　ずっと、入れといてな……？」（言い回しは本文で調整する。一人称の「ほの」を入れてもいい）
- **エロの中身**：屈曲位（ほのかの脚を抱えて、真上から）→ 正常位で密着（ほのかが脚を〇〇の腰に絡めて、抜かせない）。中出し。連続絶頂。喘ぎ声はレベル3 → 4。イくときは「いく……っ、いっちゃう……♡」など（「いってまう」は使わない）
- **位置関係**：ほのかが仰向けで、膝を胸に抱えられ、〇〇が真上から → 〇〇がほのかに覆いかぶさり、ほのかが脚を〇〇の腰に絡める
- **感情の流れ**：（ほのか）ここまでになるとは思っていなかった → 控えめな自分がどこかへ行ってしまう → このおちんちんには勝てない → ほぼ完堕ち

## 場面6：事後

- **流れ**：ほのかは、〇〇の胸の中で息を整える。一瞬だけ照れて顔を隠すが、すぐに〇〇のちんぽに手が伸びる。〇〇は、まいのことが気になって焦る。ほのかは、まいには言わないでほしいと頼む。理由は、知られたら、もうここに来られなくなるかもしれないから（恋愛の後ろめたさではない。この気持ちよさを取り上げられたくない）。〇〇はうなずく。ほのかは翌日の入り時間を気にしながら、泊まっていく
- **決め台詞**：ほのか「まいちゃんには、言わんといて」「知られたら……もう、来られへんようになるかもしれへんから」（言い回しは本文で調整する。「まだ」は入れない）
- **エロの中身**：余韻。萎えないちんぽを、話しながら手で触っている
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（ほのか）一瞬照れる → もう戻れない → まだ欲しい → これを取り上げられたくない （〇〇）ほのちゃんまで → まいちゃんには、言えない
- **ねらい**：5話（猿みたいに通う → 勃ちが悪い日 → 打ち明けることに決める）への引き
