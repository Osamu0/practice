# 第2部 ゆの編 4話：その夜

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ゆのの大阪弁は `企画メモ.md` の「大阪弁の味」を参照（標準語と混ざる。乱れたときは可愛い大阪弁。「いってまう」は使わない）。

3話と同じ日の夜。ゆの編の山場で、ゆのが堕ちる。

## 場面1：2人とも悶々としている

- **流れ**：
  - **ゆの**：夜の収録。笑顔で仕事をしながら、さっきのことが頭から離れず、身体が疼いている。収録が終わると、挨拶もそこそこに〇〇の部屋へ向かう
  - **〇〇**：ゆのが帰ったあと、部屋で一人。口の中に出したこと、最後までしなかったことが頭から離れない。まさか本当に戻ってくるのか、と落ち着かない
- **決め台詞**：なし
- **エロの中身**：なし。それぞれの心の声で、悶々としている
- **位置関係**：ゆのはスタジオ → 〇〇の部屋へ。〇〇は自分の部屋
- **感情の流れ**：（ゆの）我慢の限界 → 急ぐ （〇〇）落ち着かない → 期待してしまう

## 場面2：二度目のピンポン

- **流れ**：ゆのがインターホンを押す。〇〇がドアを開けた瞬間、ゆのは何も言わずに〇〇に抱きつく。胸に顔をうずめたまま、小さな声で一言
- **決め台詞**：ゆの「……さっき、途中やったから」
- **エロの中身**：なし
- **位置関係**：玄関。ゆのが〇〇の胸に顔をうずめて抱きつく
- **感情の流れ**：（ゆの）言葉より先に身体が動く （〇〇）本当に戻ってきた

## 場面3：前戯

- **流れ**：ベッドへ。ゆのの下着は、もう濡れている。〇〇は、さっきより遠慮なく触れる。タメ口になっている。ゆのは丁寧語で喘ぎながら、自分から脚を開く
- **決め台詞**：なし
- **エロの中身**：キス、愛撫、手マン。喘ぎ声はレベル1〜2
- **位置関係**：ベッドの上。ゆのが仰向け、〇〇が横から
- **感情の流れ**：（ゆの）恥ずかしい → でも、止めてほしくない

## 場面4：鏡の前で

- **流れ**：部屋の姿見の前で、〇〇がゆのを後ろから抱えて座らせ、そのまま挿入する。ゆのは、鏡に映る自分を見てしまう。まいを見ていた自分が、今度は自分の乱れた姿を見る。入っていくところまで、目が離せない
- **決め台詞**：なし
- **エロの中身**：背面座位。喘ぎ声はレベル2〜3
- **位置関係**：姿見の前の床。〇〇があぐらで座り、ゆのが〇〇に背中を預けて跨がる。〇〇の手は、ゆのの胸と腰。ゆのは鏡越しに、結合部と自分の顔を見る
- **感情の流れ**：（ゆの）見たくない → 見てしまう → これが、ドア越しに聞いたまいちゃんの声の正体

## 場面5：崩れる

- **流れ**：ベッドに戻り、〇〇が上から深く突く。ゆのの丁寧語が保てなくなり、標準語の中に可愛い大阪弁がこぼれるようになる（コテコテにはしない）。〇〇が初めて「ゆのちゃん」と呼ぶ。ゆのは何度もイって、レベル4まで行く
- **決め台詞**：堕ちる瞬間「すき……っ、これ、すき……♡　もう、〇〇くんのじゃないと、いややぁ……♡　ずっと、こうしててな……？」（AとBの組み合わせ。言い回しは本文で調整する）
- **エロの中身**：屈曲位（ゆのの脚を抱えて、真上から）→ 最後は正常位で密着してキスしながら。中出し。連続絶頂。喘ぎ声はレベル3 → 4。イくときは「いく……っ、いっちゃう……♡」など（「いってまう」は使わない）
- **位置関係**：ゆのが仰向けで、膝を胸に抱えられ、〇〇が真上から → 〇〇がゆのに覆いかぶさり、身体を密着させる
- **感情の流れ**：（ゆの）確かめるだけのつもりだった → それどころではなくなる → 気持ちを隠せなくなる → 堕ちる

## 場面6：事後

- **流れ**：ゆのは、〇〇の胸の中で息を整える。〇〇は、まいのことが気になって焦る。ゆのは「まいちゃんには、まだ言わんといてください」と頼む。自分から言う、という含み
- **決め台詞**：なし
- **エロの中身**：余韻
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（ゆの）満たされた → もう戻れない
- **ねらい**：5〜6話（ゆのがまいに打ち明ける）への引き
