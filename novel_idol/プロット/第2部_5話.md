# 第2部 ほのか編 5話：通う

4話から二週間ほど。完堕ちしたほのかが、猿みたいに〇〇の部屋に通う。まいも変わらず来る。〇〇は2人を別々の日に迎えていて、絶倫でも、さすがに勃ちが悪い日が出てくる。ほのかは、打ち明けることに決める。

- **ほのか**：完堕ち。来た瞬間から求める。ちんぽの前で切り替わり、ハードコアな台詞になる（可愛い大阪弁、一人称は「私」と「ほの」、「おちんちん」「おちんぽ」「ちんぽ」を混ぜる）。表では今までどおり
- **〇〇**：ほのかにはタメ口。ほのかの前でも調子に乗りはじめる。呼び方は「ほのちゃん」が基本で、山場で「ほのか」
- **まい**：この話では、ほのかのことに気づかない（気づきかける場面は入れない）

## 場面1：2人の予定（〇〇）

- **流れ**：この二週間で、ほのかは週に何回も来るようになった。まいも変わらず来る。〇〇はスマホのカレンダーに「ま」「ほ」と書いて、LINEで日にちをずらしている。空いている日がほとんどない。2トップが別々の日に自分の部屋に来る幸運に浮かれている。ただ、綱渡りでもある。ほのかの日のあと、ベッドの横に移した姿見を玄関に戻し忘れて、まいに「鏡、なんでこっちにあるの？」と聞かれ、「着替えのとき見やすくて」とごまかしたこともある
- **決め台詞**：なし
- **エロの中身**：なし。〇〇の心の声（短く）
- **位置関係**：〇〇の部屋で一人
- **感情の流れ**：（〇〇）浮かれる → 綱渡り → 身体が少しだるい

## 場面2：ほのかの夜

- **流れ**：ほのかが来る夜。ドアが閉まった瞬間に、ほのかのほうから背伸びしてキスをするのが習慣になっている。そのまま、ほのかは〇〇の前にしゃがんで、ちんぽを出す。ちんぽを前にした瞬間に切り替わる。ベッドの横の姿見の前で、ほのかが自分から〇〇に跨がる。〇〇は調子に乗りはじめる。「まいちゃんのLINE、見てたんでしょ？」「写真で見たのと、どっちがいい？」とわざと聞き、ほのかに言わせる。ほのかは喜んで言う
- **決め台詞**：なし
- **エロの中身**：玄関で即尺 → 騎乗位（ほのかが自分から。奥に押しつけたまま、腰を前後にグラインド。姿見に映る自分を見ながら）。〇〇がわざと聞いて、言わせる。連続絶頂。喘ぎ声はレベル3〜4
- **位置関係**：玄関で、ほのかがしゃがみ、〇〇は立ったまま → 姿見の前のベッドの縁で、〇〇が仰向け、ほのかが跨がる
- **感情の流れ**：（ほのか）来た瞬間から欲しい → 言わされるのがうれしい （〇〇）控えめなほのちゃんが、自分から → 調子に乗ってみたら、喜ぶ

## 場面3：まいからのLINE

- **流れ**：対面座位でつながっているとき、〇〇のスマホが鳴る。まいから『近くまで来たんだけど、寄っていい？』。〇〇は、ほのかの中に入ったまま、『ごめん、今日は会社の人と飲んでて』と嘘を返す。ほのかはそれを見ている。ほのかは、ばれたらもう来られない、とこわくなる。なのに、身体はもっと熱くなる。ほのかは、服で隠れる胸元にキスマークをつけてとねだる（ドアの隙間の夜の翌日に見た、まいの内もものキスマークを覚えている。「まいちゃん、内ももにあったやろ」「私は、ここがいい」）
- **決め台詞**：なし
- **エロの中身**：対面座位のまま。胸元へのキスマーク（衣装で隠れる位置）。中出し。ほのかの快楽寄りの甘え（「抜かんといて」「奥に、ちょうだい」など）
- **位置関係**：ベッドの上で対面座位。〇〇のスマホはベッドの上
- **感情の流れ**：（ほのか）ばれたらこわい → でも止まれない → 跡が欲しい （〇〇）焦り → 目の前のほのか

## 場面4：デカチンの写真

- **流れ**：事後。ほのかが〇〇のスマホを見て、「まいちゃんに、写真送ってるやろ」と言う。最初に車で見てしまった、あの写真のこと。「……私にも、送って」。翌日の昼、ほのかの楽屋のスマホに、〇〇からの写真が届く。ほのかはトイレの個室で、それを見る
- **決め台詞**：ほのか「……私にも、送って」
- **エロの中身**：〇〇がほのかにデカチンの写真を送る。ほのかはトイレの個室で見て疼く
- **位置関係**：〇〇のベッド → 翌日、楽屋のトイレの個室
- **感情の流れ**：（ほのか）車で見た写真が、今度は自分宛てに → 疼く
- **表の場での漏れ**：楽屋のトイレの個室で、〇〇からの写真を見る。誰も気づかない

## 場面5：勃ちが悪い日（ほのかの日）

- **流れ**：数日後、ほのかの日。いつものように玄関でしゃがんで咥えるが、〇〇のちんぽがなかなか硬くならない。〇〇は「ごめん、ちょっと疲れてて」と言う。ほのかは、口と手で一生懸命に勃たせて、なんとか最後までする。でも、いつもより回数が少ない。ほのかは、前にLINEで見たことを思い出す。まいも、よく来ている。昨日は、まいの日だったのかもしれない
- **決め台詞**：なし
- **エロの中身**：なかなか勃たないちんぽへのフェラと手コキ（ほのかが一生懸命に奉仕する）→ 騎乗位で一回。喘ぎ声はレベル3。いつもより短い
- **位置関係**：玄関 → ベッド
- **感情の流れ**：（ほのか）え？ → 一生懸命に勃たせる → 足りない → 昨日、まいちゃんやったんや （〇〇）情けない → でも、毎日のように2人が来るから

## 場面6：勃ちが悪い日（まいの日）

- **流れ**：別の日、まいの日。まいの日にも、〇〇の勃ちが悪い。まいは「最近、疲れてる？　仕事、忙しい？」と聞く。〇〇は「ちょっと決算で」とごまかす。まいは心配しながらも、物足りなさに身体をもてあます。まいはほのかのことには気づいていない
- **決め台詞**：なし
- **エロの中身**：短く。まいのフェラで勃たせて一回。喘ぎ声はレベル3
- **位置関係**：〇〇の部屋
- **感情の流れ**：（まい）心配 → 物足りない （〇〇）まいちゃんにも、隠しきれなくなってきた

## 場面7：ほのかが決める

- **流れ**：ほのかは、自分の部屋で、〇〇から届いた写真を見ながら考える。このまま、まいと別々に〇〇を奪い合っていたら、〇〇がもたない。勃ちの悪い〇〇じゃ、足りない。それなら、一緒にしたほうがいい。まいに知られたら来られなくなる、とこわかったのに、隠していても結局足りなくなる。ほのかは、まいに打ち明けることに決める。翌日の楽屋で、まいに声をかける
- **決め台詞**：ほのか「まいちゃん。……あとで、ちょっと話があるんやけど」→ まい「ん？　いいよ」
- **エロの中身**：なし
- **位置関係**：ほのかの部屋 → 翌日の楽屋
- **感情の流れ**：（ほのか）足りない → 隠していても同じ → 一緒にしたほうがいい → 言う （まい）なんだろう、くらい（何も気づいていない）
- **ねらい**：6話（打ち明ける）への引き。打ち明ける理由は、恋愛の後ろめたさや羨ましさではなく、快楽の都合
