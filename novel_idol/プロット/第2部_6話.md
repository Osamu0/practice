# 第2部 ほのか編 6話：共犯

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ほのかとまいは同期なので、ほのかはまいにタメ口で話す（関西の柔らかさが少し混ざる）。

ほのか編の最後。ほのかがまいに打ち明け、2人が共犯になって、3人でするようになる。第3部への橋渡し。このあと2か月の空きがあり、まいとほのかは〇〇に通う（1人のときが多く、ときどき2人で。〇〇の部屋と、それぞれの家を行き来する）。

- **まいとほのか**：2人とも完堕ち。裏では照れが残らない。打ち明けたあとは、すぐに恥も外聞もない猥談になる。ちんぽの前では2人ともハードコアな台詞（まいの一人称は「私」と「まい」、ほのかは「私」と「ほの」。「おちんちん」「おちんぽ」「ちんぽ」を混ぜる）
- **〇〇**：2人ともにタメ口。2人を相手に、調子に乗る（わざと聞く、言わせる、焦らす。競わせることはしない）
- **嘘のLINE**：2人とも完堕ちしているので、気にしていない。冗談まじりに話す
- **打ち明ける理由**：恋愛の後ろめたさや羨ましさではなく、快楽の都合（このままでは〇〇がもたない）

## 場面1：2人きりになる

- **流れ**：仕事のあと、まいとほのかは2人で、まいの家に寄る。まいはお茶を出す。まいは、ほのかの話が何なのか見当もついていない
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：まいの家のリビング。ソファに並んで座る
- **感情の流れ**：（ほのか）言うと決めてきた （まい）なんの話だろう

## 場面2：まいのことを言う

- **流れ**：ほのかは、まず、まいのことを知っていると切り出す。謝ってから、知っていることを言い、最後に一番言いにくいこと（跡をつけた）を言う。そのあいだに、まいの表情が変わっていく
- **決め台詞**（B→A→Cの順）：
  > ほのか「ごめん、まいちゃん。……前に、LINE見てしもて」
  > ほのか「〇〇くんって人と、会ってるよね」
  > ほのか「……まいちゃんのこと、つけてしまってん。〇〇くんの部屋まで」
- **エロの中身**：なし
- **位置関係**：ソファに並んで座ったまま。ほのかは、まいの顔を見られずに視線を外している
- **感情の流れ**：（ほのか）言ってしまった （まい）笑顔が少しずつ固まっていく

## 場面3：まいが一瞬焦る

- **流れ**：まいの顔から、いつもの笑顔が消える。グループの顔が、一般のファンと関係を持っている。それをメンバーに知られた。表の顔が崩れる、珍しい瞬間
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：ソファ
- **感情の流れ**：（まい）バレた → どうしよう

焦る理由は嫉妬ではなく、アイドルとしての秘密を知られたから。

## 場面4：ほのかも打ち明ける

- **流れ**：焦るまいを前に、ほのかは、自分も〇〇の部屋に行っていることを打ち明ける。LINEのデカチンの写真を見て、我慢できなくなって、手を出してしまった。そして、打ち明けた理由。最近、〇〇の勃ちが悪い日があること。まいは「……あ」と気づく。自分の日にもあった。2人で答え合わせをする（あの日の前の日は、ほのかだった。「会社の人と飲んでて」の日も、ほのかだった）。ほのかは「あの日な、私、〇〇くんの上におってん」と、ちょっと笑いながら言う。まいも怒らない。「えー、あのとき？」「〇〇くん、嘘へたすぎ」と冗談にして笑う。まいは力が抜けて、笑い出す。ほのかも、同じ秘密を持っている。誰にも言うはずがない
- **決め台詞**：
  - ほのか「怒ってるんちゃうよ。……私も、なんだ。〇〇くんと」（3話で〇〇に言った「責めに来たんやないんです」とくり返しにならないように、言い回しを変えている）
  - ほのか「LINEの写真見たら……我慢、できへんくなってしもて」（方向。言い回しは本文で調整する）
- **エロの中身**：なし
- **位置関係**：ソファ。まいが力の抜けた様子で、ほのかに寄りかかる
- **感情の流れ**：（まい）焦り → 勃ちが悪かったのはそういうこと → 嘘のLINEも冗談にして笑う → 力が抜ける （ほのか）言えた → 隠さなくていい相手ができた。悲しみ・怒り・嫉妬はなし。嘘のことも気にしていない

## 場面5：猥談

- **流れ**：照れは残らない。答え合わせから、そのまま恥も外聞もない猥談になる。〇〇のちんぽの形、どこが気持ちいいか、何回出されたか、届いた写真を見せ合う（同じ写真が2人に届いていた日もある）。まいは、ほのかが鏡の前でしていると聞いて、自分の日に姿見がベッドの横にあった理由に気づく（「もう、なにが『着替えのとき見やすくて』よ」）。話しているうちに2人とも濡れてくる
- **決め台詞**：まい「じゃあ、今度一緒に行こっか」（別々に奪い合うより、一晩で2人のほうがいい、という流れで）
- **エロの中身**：猥談。写真の見せ合い。2人とも濡れている（触り合うのは第3部2話に取っておく）
- **位置関係**：ソファ
- **感情の流れ**：（まい・ほのか）安堵 → 恥も外聞もない猥談 → 「あの子も、あんなふうにされてるんだ」という好奇心と昂り → 一緒に行きたい

## 場面6：3人で

- **流れ**：後日。インターホンが鳴って、〇〇はまいが来たと思ってドアを開ける。そこに、まいとほのかが並んで立っている。〇〇は、2人がお互いのことを知ったと気づいて、一瞬「終わった」と焦る。まいが「怒ってないよ」と笑い、「会社の人と飲んでたんだっけ？」とからかう。〇〇は何も言えない。2人で部屋に上がってくる。勃ちが悪い日が続いていたのに、2人が並んだだけで、〇〇のちんぽは痛いくらい硬くなる（まい「……ほら、言ったでしょ」）。〇〇は焦りから一転、浮かれて、2人を相手に調子に乗る（「どっちから入れてほしいの？」とわざと聞く、2人に言わせる、焦らす）。2人は喜んで言う。お互いがちんぽの前で崩れる姿を、初めて目の前で見る
- **決め台詞**：なし
- **エロの中身**：Wフェラ → 並べた四つん這いに交互に挿入 → 一人に挿入しているあいだ、もう一人が〇〇とキスしたり、挿入されている子の胸に触れたり。中出し。最後は、口に出された精液を、まいがほのかに口移しで分ける。2人で並んでお掃除フェラ。喘ぎ声はレベル4
- **位置関係**：〇〇がベッドの縁に座り、まいとほのかが床に並んで膝をつく → まいとほのかがベッドに並んで四つん這いになり、〇〇が交互に後ろから → 一人が仰向けで〇〇と正常位、もう一人がその横に寄り添う
- **感情の流れ**：（まい・ほのか）同期がちんぽの前で崩れる姿を見て、さらに昂る （〇〇）まいだと思ったら2人 → 終わった → 怒ってない → 2人並ぶと、勃ちが悪いどころじゃない → 調子に乗る

3話で「まいだと思ったらほのかだった」のと対にする。今度は「まいだと思ったら、まいとほのかだった」。
