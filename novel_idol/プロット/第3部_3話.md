# 第3部 なぎ編 3話：家飲み

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> なぎの話し方は `企画メモ.md` のなぎの欄（口調・口調の注意点）を参照。同期のまい・ほのかにはタメ口、初対面のファン（〇〇）には最初は丁寧に話す。

アウトラインの流れの2〜4（3人で飲む → 〇〇が出てくる → 4人で飲むうちに空気が変わる）。お酒の種類は決めない（書くときに決める）。

**お酒の線**：なぎは少しゆるむ程度。酔いつぶれたり、意識がない状態にはしない。状況はわかっていて、反応がやわらかくなっているだけ。

## 場面1：同期3人の家飲み

- **流れ**：仕事終わりに、まいの家で3人の家飲み。なぎは、同期だけの気楽な集まりだと思っている。お酒を飲みながら、仕事の話や最近のことを話す。まいとほのかは、さりげなくなぎを褒める。なぎは照れて、言葉に詰まったり、目を逸らしたりする
- **決め台詞**：なし。雰囲気の例：
  > まい「なぎちゃん、最近また可愛くなったよね」
  > なぎ「……え、なにそれ。急にどうしたの」
  > ほのか「ほんまに。肌もきれいやし」
  > なぎ「……もう、2人してやめてよ。普通に照れるから」
- **エロの中身**：なし
- **位置関係**：まいの家のリビング。ローテーブルを囲んで、ソファと床に座る。なぎを真ん中に、両側にまいとほのか
- **感情の流れ**：（なぎ）リラックスしている → 褒められて照れる （まい・ほのか）作戦どおり

## 場面2：奥の部屋の〇〇

- **流れ**：奥の部屋で、〇〇はじっと待っている。ドア越しに、3人の笑い声と、なぎの声が聞こえる。画面の中でしか知らなかった声が、すぐそこにある
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：奥の部屋で一人。ドアのそば
- **感情の流れ**：（〇〇）緊張 → 興奮が止まらない

## 場面3：〇〇が出てくる

- **流れ**：お酒が回って、なぎの頬がほんのり赤い。いつもより笑うことが増えて、反応がワンテンポ遅れている。まいが奥の部屋に声をかけて、〇〇が出てくる。なぎは一瞬ぽかんとして、それから遅れて驚く。まいが正直に明かすと、なぎは怒るより先に、ゆるく笑ってしまう
- **決め台詞**：
  > なぎ「……ん？　……え、だれ？」
  > なぎ「……え、待って。最初からいたの？」
  > まい「ごめん、実は最初からいたの。言ったら、なぎちゃん来ないと思って」
  > なぎ「……ふふ、なにそれ。普通に言ってよ……」
- **エロの中身**：なし
- **位置関係**：〇〇が奥の部屋のドアの前に立つ。3人はリビング。なぎはソファにもたれている
- **感情の流れ**：（なぎ）ぽかん → 遅れて驚く → 呆れるより先に、ゆるく笑う

## 場面4：ファンだとわかる

- **流れ**：〇〇がファンだとわかると、なぎは礼儀正しく挨拶する。丁寧だけれど、お酒で少しふわっとしている。〇〇は、なぎに丁寧に接されて、ますます緊張する
- **決め台詞**：なぎ「あ……えっと、ファンの方、なんですよね。……いつも、ありがとうございます」
- **エロの中身**：なし
- **位置関係**：〇〇が、まいに促されて、なぎの向かいに座る
- **感情の流れ**：（なぎ）戸惑いながらも、ファンには丁寧に （〇〇）なぎちゃんが、目の前で自分に話しかけている

## 場面5：空気が変わっていく

- **流れ**：4人で飲み続ける。まいとほのかが、なぎにいたずらを仕掛けて、冗談とも本気ともつかない空気にしていく。まいが「なぎちゃんも、こっちおいでよ」と、なぎを〇〇の隣に引っぱってくる。ほのかが後ろからなぎに抱きついて、耳元で褒める。まいが冗談めかして、なぎの頬にキスをする。〇〇の手を取って、なぎの太ももに置かせる。なぎは「ちょっと……なにしてんの、2人とも」と照れ笑いするが、お酒でゆるんでいて、本気で嫌がりはしない。そのうちに、まいとほのかが、なぎのすぐ横で〇〇とキスを始める。いたずらなのか、そうでないのか、有耶無耶なまま、空気が変わっていく。〇〇の手は、まだなぎの太ももの上にある。なぎの照れ笑いが、少しずつ消えていく
- **決め台詞**：なし（なぎの反応は、鋭いツッコミではなく、ゆるい照れ笑いや小さなつぶやき程度にする。例：「ちょっと……なにしてんの、2人とも」）
- **エロの中身**：いたずら（抱きつく、耳元で褒める、頬にキス、〇〇の手をなぎの太ももに置かせる）。まい・ほのかと〇〇のキス。まいとほのかの表の顔が崩れていく
- **位置関係**：〇〇がソファに座り、その隣になぎ（まいに引っぱられてくる）。ほのかはなぎの後ろから抱きつき、まいは〇〇の反対側から身を乗り出す。〇〇の手が、なぎの太ももの上
- **感情の流れ**：（なぎ）照れ笑い → いたずらだと思っている → 有耶無耶なまま、空気に飲まれていく → 照れ笑いが消える （まい・ほのか）楽しみながら、少しずつ本気にしていく

なぎはお酒でゆるんでいるが、状況はわかっていて、本気で嫌がっていない。最後の一言（4話の「……もっと、して」）は、なぎ自身のもの。
- **ねらい**：4話（2人がなぎのほうへ来て、崩していく）への引き
