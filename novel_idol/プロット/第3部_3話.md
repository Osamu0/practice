# 第3部 あおい編 3話：家飲み

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> あおいの話し方は `企画メモ.md` のあおいの欄（口調・口調の注意点）を参照。同期のまい・ゆのにはタメ口、初対面のファン（〇〇）には最初は丁寧に話す。

アウトラインの流れの2〜4（3人で飲む → 〇〇が出てくる → 4人で飲むうちに空気が変わる）。お酒の種類は決めない（書くときに決める）。

**お酒の線**：あおいは少しゆるむ程度。酔いつぶれたり、意識がない状態にはしない。状況はわかっていて、反応がやわらかくなっているだけ。

## 場面1：同期3人の家飲み

- **流れ**：仕事終わりに、まいの家で3人の家飲み。あおいは、同期だけの気楽な集まりだと思っている。お酒を飲みながら、仕事の話や最近のことを話す。まいとゆのは、さりげなくあおいを褒める。あおいは照れて、言葉に詰まったり、目を逸らしたりする
- **決め台詞**：なし。雰囲気の例：
  > まい「あおいちゃん、最近また可愛くなったよね」
  > あおい「……え、なにそれ。急にどうしたの」
  > ゆの「ほんまに。肌もきれいやし」
  > あおい「……もう、2人してやめてよ。普通に照れるから」
- **エロの中身**：なし
- **位置関係**：まいの家のリビング。ローテーブルを囲んで、ソファと床に座る。あおいを真ん中に、両側にまいとゆの
- **感情の流れ**：（あおい）リラックスしている → 褒められて照れる （まい・ゆの）作戦どおり

## 場面2：奥の部屋の〇〇

- **流れ**：奥の部屋で、〇〇はじっと待っている。ドア越しに、3人の笑い声と、あおいの声が聞こえる。画面の中でしか知らなかった声が、すぐそこにある
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：奥の部屋で一人。ドアのそば
- **感情の流れ**：（〇〇）緊張 → 興奮が止まらない

## 場面3：〇〇が出てくる

- **流れ**：お酒が回って、あおいの頬がほんのり赤い。いつもより笑うことが増えて、反応がワンテンポ遅れている。まいが奥の部屋に声をかけて、〇〇が出てくる。あおいは一瞬ぽかんとして、それから遅れて驚く。まいが正直に明かすと、あおいは怒るより先に、ゆるく笑ってしまう
- **決め台詞**：
  > あおい「……ん？　……え、だれ？」
  > あおい「……え、待って。最初からいたの？」
  > まい「ごめん、実は最初からいたの。言ったら、あおいちゃん来ないと思って」
  > あおい「……ふふ、なにそれ。普通に言ってよ……」
- **エロの中身**：なし
- **位置関係**：〇〇が奥の部屋のドアの前に立つ。3人はリビング。あおいはソファにもたれている
- **感情の流れ**：（あおい）ぽかん → 遅れて驚く → 呆れるより先に、ゆるく笑う

## 場面4：ファンだとわかる

- **流れ**：〇〇がファンだとわかると、あおいは礼儀正しく挨拶する。丁寧だけれど、お酒で少しふわっとしている。〇〇は、あおいに丁寧に接されて、ますます緊張する
- **決め台詞**：あおい「あ……えっと、ファンの方、なんですよね。……いつも、ありがとうございます」
- **エロの中身**：なし
- **位置関係**：〇〇が、まいに促されて、あおいの向かいに座る
- **感情の流れ**：（あおい）戸惑いながらも、ファンには丁寧に （〇〇）あおいちゃんが、目の前で自分に話しかけている

## 場面5：空気が変わっていく

- **流れ**：4人で飲み続ける。まいとゆのが、少しずつ〇〇との距離を縮めていく。まいが〇〇に寄りかかり、ゆのが〇〇の太ももに手を置く。やがて、あおいの目の前で、まいが〇〇にキスをする。あおいは、お酒でゆるんだまま、表で見てきた2人とはまるで違う姿を、ぼんやり見つめてしまう。驚いてはいるけれど、引いたり帰ろうとしたりはしない。照れたように小さく笑って、目が離せない。頬が熱いのが、お酒のせいなのかどうか、わからなくなっていく
- **決め台詞**：なし（あおいの反応は、鋭いツッコミではなく、ゆるい照れ笑いや小さなつぶやき程度にする。例：「……え、2人とも、なにしてんの……」）
- **エロの中身**：まいと〇〇のキス、ゆのが〇〇に触れる。まいとゆのの表の顔が崩れていく
- **位置関係**：〇〇がソファに座り、両側にまいとゆの。あおいはローテーブルを挟んだ向かいの床
- **感情の流れ**：（あおい）驚き → ぼんやり見つめる → 目が離せない → 身体が熱くなる
- **ねらい**：4話（2人があおいのほうへ来て、崩していく）への引き
