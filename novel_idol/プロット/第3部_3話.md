# 第3部 なぎ編 3話：家飲み

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> なぎの話し方は `企画メモ.md` のなぎの欄（口調・口調の注意点）を参照。同期のまい・ほのかにはタメ口、初対面のファン（〇〇）には最初は丁寧に話す。
> LINEのメッセージは、本文では『』で書く。

同期3人の家飲み。なぎが2人の調子のよさを聞き、2人ははぐらかす。ほかの話をしながらお酒が進み、なぎが気になってまた聞く。2人が答えてしまう。なぎは「2人がそこまで言うなら」。〇〇が呼ばれて来て、ちんぽを見せられ、なぎが本能で疼く。2人がなぎの目の前で頬ずりする。

- **なぎ**：表の性格のまま。お酒で少しゆるむが、状況はわかっている。話を聞いても引かず、面白がる。ファンの〇〇には丁寧。なぎの視点の場面と、〇〇の視点の場面がある（本文を書くときに決める）
- **まいとほのか**：完堕ち。なぎに聞かれるまでは、表に近い顔ではぐらかす。答えはじめたら、恥も外聞もない
- **〇〇**：なぎには敬語
- **お酒の線**：なぎは少しゆるむ程度。酔いつぶれたり、意識がない状態にはしない

## 場面1：同期3人の家飲み

- **流れ**：仕事終わり、まいの家のリビングで、3人の家飲み。ワインと、ほのかが買ってきたチーズ。なぎは、同期だけの気楽な集まりだと思っている。仕事の話、メンバーの話、最近見たもの。まいとほのかは、さりげなくなぎを褒める。なぎは照れて、言葉に詰まって、ワインを飲む
- **決め台詞**：なし。雰囲気の例：
  > まい「なぎちゃん、最近また可愛くなったよね」
  > なぎ「……え、なにそれ。急にどうしたの」
  > ほのか「ほんまに。肌もきれいやし」
  > なぎ「……もう、2人してやめてよ。普通に照れるから」
- **エロの中身**：なし
- **位置関係**：まいの家のリビング。ローテーブルを囲んで、ソファと床に座る。なぎを真ん中に、両側にまいとほのか
- **感情の流れ**：（なぎ）リラックスしている → 褒められて照れる

## 場面2：なぎが聞く、2人ははぐらかす

- **流れ**：お酒が少し回ったころ、なぎのほうから聞く。「てかさ、2人とも最近なんかすごいよね」「収録の返しとか、まい、前からうまいけど最近やばいし」「ほのかも、なんか……色っぽくなった？」「何かしてんの？」。2人は顔を見合わせて、はぐらかす（「えー、なんだろ」「よく寝てるから？」）。なぎは「ふーん」と引き下がる
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：場面1と同じ
- **感情の流れ**：（なぎ）よく見ている → はぐらかされた → 気になる （まい・ほのか）作戦どおり、まだ言わない

## 場面3：お酒が進む

- **流れ**：ほかの話をしながら、お酒が進む。ちひろの話（台本を逆に持っていた）、最近のライブ、地元の話。なぎの頬がほんのり赤くなり、いつもより笑うことが増え、反応がワンテンポ遅れる。床からソファに移って、背もたれに深くもたれる。それでも、なぎの目は、ときどき2人に戻る。2人がスマホを見て、ふっと笑うところも見ている
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：なぎはソファにもたれる。まいとほのかは両側
- **感情の流れ**：（なぎ）楽しい → 少しゆるむ → でも、やっぱり気になる

## 場面4：また聞く、答えてしまう

- **流れ**：なぎが、また聞く。今度は引き下がらない。「ねえ、さっきのやつ。ほんとは何かあるでしょ」「2人して同じ顔してスマホ見てるし」。まいとほのかは顔を見合わせて、答えてしまう。ファンの男の人のこと。その人の部屋に通っていること。そして、その人のちんぽがすごいこと。2人は恥も外聞もなく話す。なぎは驚くが、酔っているので引かない。面白がって、もっと聞く。「……え、待って。2人とも？」「ふふ、なにそれ」「そんなに？」。2人は本気で言う（「ほんまに、すごいねん」「なぎちゃんも、見たらわかるよ」）。なぎは少し考えてから、ゆるく笑って言う
- **決め台詞**：なぎ「……2人がそこまで言うなら」（方向。言い回しは本文で調整する。「見るだけね」のような一言を足してもいい）
- **エロの中身**：なし。2人の恥も外聞もない話（おちんちんの大きさ、何回出されたか）
- **位置関係**：ソファ
- **感情の流れ**：（なぎ）引き下がらない → 驚く → 酔っているので、面白がる → 2人がそこまで言うなら （まい・ほのか）聞かれたら、全部言う

## 場面5：〇〇が来る

- **流れ**：まいがLINEで〇〇を呼ぶ（『いいよ』『来て』）。〇〇は近所で待っていた。インターホンが鳴り、まいが迎えに出る。〇〇がリビングに入る。ソファに、黒髪の女の子がもたれている。赤い顔で、ゆるく笑って、こちらを見ている。ファンだとわかると、なぎは座り直して、少しふわっとしながらも丁寧に挨拶する。〇〇は、なぎに丁寧に接されて、ますます緊張する
- **決め台詞**：なぎ「あ……えっと、ファンの方、なんですよね。……いつも、ありがとうございます」
- **エロの中身**：なし
- **位置関係**：〇〇はローテーブルの向かいの床に座る。なぎはソファ、両側にまいとほのか
- **感情の流れ**：（なぎ）この人が → ファンには丁寧に （〇〇）なぎちゃんが、目の前で自分に話しかけている → 棚のいちばん手前の三冊

## 場面6：見せる

- **流れ**：まいが〇〇に「見せてあげて」と言う。〇〇はズボンを下ろす。〇〇のちんぽは、なぎを見た瞬間から硬くなっている。なぎは、目が離れない。理由もなく、身体の奥が疼く（本能）。その瞬間、まいとほのかの顔が変わる。2人はソファから降りて、〇〇の前にしゃがみこみ、なぎの目の前で、ちんぽに頬ずりする。さっきまで隣で笑っていた同期の2トップが、ちんぽに話しかけて、うっとりしている
- **決め台詞**：なし
- **エロの中身**：〇〇のちんぽ。まいとほのかの頬ずり、キス、ちんぽに話しかける（ハードコアな台詞）。なぎの本能の疼き
- **位置関係**：〇〇がローテーブルの横に立つ（または膝立ち）。まいとほのかがその前にしゃがむ。なぎはソファから、すぐ目の前で見ている
- **感情の流れ**：（なぎ）……でか → 目が離れない → 疼く → まいとほのかが、あんな顔 → もっと疼く （〇〇）なぎちゃんに見られている
- **ねらい**：4話（なぎが思わず手を伸ばす）への引き
