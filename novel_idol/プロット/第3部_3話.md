# 第3部 あすか編 3話：家飲み

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> あすかの話し方は `企画メモ.md` のあすかの欄（口調・口調の注意点）を参照。同期のまい・ななせにはタメ口、初対面のファン（〇〇）には最初は丁寧に話す。
> LINEのメッセージは、本文では『』で書く。

同期3人の家飲み。あすかが2人の調子のよさを聞き、2人ははぐらかす。ほかの話をしながらお酒が進み、あすかが気になってまた聞く。2人が答えてしまう。あすかは「2人がそこまで言うなら」。〇〇が呼ばれて来て、ちんぽを見せられ、あすかが本能で疼く。2人があすかの目の前で頬ずりする。

- **あすか**：表の性格のまま。お酒で少しゆるむが、状況はわかっている。話を聞いても引かず、面白がる。ファンの〇〇には丁寧。あすかの視点の場面と、〇〇の視点の場面がある（本文を書くときに決める）
- **まいとななせ**：完堕ち。あすかに聞かれるまでは、表に近い顔ではぐらかす。答えはじめたら、恥も外聞もない
- **〇〇**：あすかには敬語
- **お酒の線**：あすかは少しゆるむ程度。酔いつぶれたり、意識がない状態にはしない

## 場面1：同期3人の家飲み

- **流れ**：仕事終わり、あすかの家のリビングで、3人の家飲み。生活感の少ない、モノトーンのデザイナーズマンション（詳しくは第5部3話の「あすかの家」）。まいとななせは、あすかの家に来るのはほとんど初めてで、物の少なさをいじる（あすか「……別に。いらないもの置かないだけ」）。ワインと、ななせが買ってきたチーズ。あすかは、同期だけの気楽な集まりだと思っている。仕事の話、メンバーの話、最近見たもの。まいとななせは、さりげなくあすかを褒める。あすかは照れて、言葉に詰まって、ワインを飲む
- **決め台詞**：なし。雰囲気の例：
  > まい「あすかちゃん、最近また可愛くなったよね」
  > あすか「……え、なにそれ。急にどうしたの」
  > ななせ「ほんまに。肌もきれいやし」
  > あすか「……もう、2人してやめてよ。普通に照れるから」
- **エロの中身**：なし
- **位置関係**：あすかの家のリビング。ローテーブルを囲んで、ソファと床に座る。あすかを真ん中に、両側にまいとななせ
- **感情の流れ**：（あすか）リラックスしている → 褒められて照れる

## 場面2：あすかが聞く、2人ははぐらかす

- **流れ**：お酒が少し回ったころ、あすかのほうから聞く。「てかさ、2人とも最近なんかすごいよね」「収録の返しとか、まい、前からうまいけど最近やばいし」「ななせも、なんか……色っぽくなった？」「何かしてんの？」。2人は顔を見合わせて、はぐらかす（「えー、なんだろ」「よく寝てるから？」）。あすかは「ふーん」と引き下がる
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：場面1と同じ
- **感情の流れ**：（あすか）よく見ている → はぐらかされた → 気になる （まい・ななせ）作戦どおり、まだ言わない

## 場面3：お酒が進む

- **流れ**：ほかの話をしながら、お酒が進む。ちひろの話（台本を逆に持っていた）、最近のライブ、地元の話。あすかの頬がほんのり赤くなり、いつもより笑うことが増え、反応がワンテンポ遅れる。床からソファに移って、背もたれに深くもたれる。それでも、あすかの目は、ときどき2人に戻る。2人がスマホを見て、ふっと笑うところも見ている
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：あすかはソファにもたれる。まいとななせは両側
- **感情の流れ**：（あすか）楽しい → 少しゆるむ → でも、やっぱり気になる

## 場面4：また聞く、答えてしまう

- **流れ**：あすかが、また聞く。今度は引き下がらない。「ねえ、さっきのやつ。ほんとは何かあるでしょ」「2人して同じ顔してスマホ見てるし」。まいとななせは顔を見合わせて、答えてしまう。ファンの男の人のこと。その人の部屋に通っていること。そして、その人のちんぽがすごいこと。2人は恥も外聞もなく話す。あすかは驚くが、酔っているので引かない。面白がって、もっと聞く。「……え、待って。2人とも？」「ふふ、なにそれ」「そんなに？」。2人は本気で言う（「ほんまに、すごいねん」「あすかちゃんも、見たらわかるよ」）。あすかは少し考えてから、ゆるく笑って言う
- **決め台詞**：あすか「……2人がそこまで言うなら」（方向。言い回しは本文で調整する。「見るだけね」のような一言を足してもいい）
- **エロの中身**：なし。2人の恥も外聞もない話（おちんちんの大きさ、何回出されたか）
- **位置関係**：ソファ
- **感情の流れ**：（あすか）引き下がらない → 驚く → 酔っているので、面白がる → 2人がそこまで言うなら （まい・ななせ）聞かれたら、全部言う

## 場面5：〇〇が来る

- **流れ**：まいがLINEで〇〇を呼ぶ（『いいよ』『来て』）。〇〇は近所で待っていた。あすかの家のインターホンが鳴る。あすかは少し迷ってから、自分で解錠する（呼ぶのを許したのは、あすか）。まいが玄関まで迎えに出る。〇〇がリビングに入る。〇〇は、あすかの家にいることにドキドキしている。ソファに、黒髪の女の子がもたれている。赤い顔で、ゆるく笑って、こちらを見ている。ファンだとわかると、あすかは座り直して、少しふわっとしながらも丁寧に挨拶する。〇〇は、あすかに丁寧に接されて、ますます緊張する
- **決め台詞**：あすか「あ……えっと、ファンの方、なんですよね。……いつも、ありがとうございます」
- **エロの中身**：なし
- **位置関係**：〇〇はローテーブルの向かいの床に座る。あすかはソファ、両側にまいとななせ
- **感情の流れ**：（あすか）この人が → ファンには丁寧に （〇〇）あすかちゃんが、目の前で自分に話しかけている → 棚のいちばん手前の三冊

## 場面6：見せる

- **流れ**：まいが〇〇に「見せてあげて」と言う。〇〇はズボンを下ろす。〇〇のちんぽは、あすかを見た瞬間から硬くなっている。あすかは、目が離れない。理由もなく、身体の奥が疼く（本能）。その瞬間、まいとななせの顔が変わる。2人はソファから降りて、〇〇の前にしゃがみこみ、あすかの目の前で、ちんぽに頬ずりする。さっきまで隣で笑っていた同期の2トップが、ちんぽに話しかけて、うっとりしている
- **決め台詞**：なし
- **エロの中身**：〇〇のちんぽ。まいとななせの頬ずり、キス、ちんぽに話しかける（ハードコアな台詞）。あすかの本能の疼き
- **位置関係**：〇〇がローテーブルの横に立つ（または膝立ち）。まいとななせがその前にしゃがむ。あすかはソファから、すぐ目の前で見ている
- **感情の流れ**：（あすか）……でか → 目が離れない → 疼く → まいとななせが、あんな顔 → もっと疼く （〇〇）あすかちゃんに見られている
- **ねらい**：4話（あすかが思わず手を伸ばす）への引き
