# 第3部 あおい編 4話：もっと

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> あおいの話し方は `企画メモ.md` のあおいの欄を参照。〇〇への敬語は場面3で崩れ、そのあとはタメ口（呼び方は「〇〇さん」のまま）。

あおい編の山場。アウトラインの流れの5〜7（2人が崩す → 〇〇がトドメ → 本音を言って堕ちる）。3話の終わり（〇〇の手があおいの太ももの上にあり、あおいの照れ笑いが消えたところ）から続く。

**お酒の線**：あおいは少しゆるむ程度。状況はわかっていて、最後の一言は自分のもの。

## 場面1：2人が崩していく

- **流れ**：ゆのが後ろからあおいを抱いたまま、服の上から胸に触れる。まいは横から、あおいの首筋にキスをしながら、耳元で褒める。〇〇の手が、太ももからスカートの中へ。あおいは照れ隠しに冗談で返そうとするが、褒められるたびに言葉に詰まる。服を脱がされていく
- **決め台詞**：なし
- **エロの中身**：愛撫、キス、服を脱がせる。喘ぎ声はレベル1（控えめな声）
- **位置関係**：ソファ。あおいが座り、ゆのが後ろからあおいを抱いて背もたれ代わりになる。まいはあおいの右隣、〇〇は左隣
- **感情の流れ**：（あおい）照れ隠し → 言葉に詰まる → 隠しきれない

## 場面2：見られる

- **流れ**：下着を脱がされて、あおいがパイパンにしていることがわかる。まいとゆのが「かわいい」と褒め、〇〇は息をのむ。あおいは目を逸らして、照れる。〇〇がソファの前の床に膝をつき、あおいの脚のあいだに顔を埋める
- **決め台詞**：なし
- **エロの中身**：クンニ。まいとゆのは、両側からあおいの胸に触れる。喘ぎ声はレベル1〜2。控えめな声が、少しずつ抑えきれなくなる
- **位置関係**：あおいはソファに浅く座り、背中をゆのに預ける。まいが、あおいの片脚を抱えて開かせる。〇〇は床に膝をついて、正面から
- **感情の流れ**：（あおい）見られて恥ずかしい → 声が抑えられない

## 場面3：〇〇がトドメを刺す

- **流れ**：〇〇が、そのままの体勢で挿入する。まいとゆのは、あおいの身体を支えたまま、耳元でささやき続ける。あおいの控えめな声が抑えきれなくなり、〇〇への敬語も崩れる。どこかで、あおいの力がふっと抜ける。「まあ、いいか」と、取り繕うのをやめる
- **決め台詞**：なし
- **エロの中身**：ソファでの正常位（〇〇は床に膝立ち）。喘ぎ声はレベル2〜3
- **位置関係**：場面2と同じ。あおいはソファに浅く座ってゆのに背中を預け、まいが片脚を抱えている。〇〇は床に膝立ちで、正面から
- **感情の流れ**：（あおい）抑えたい → 抑えきれない → 力が抜ける

## 場面4：本音を言う

- **流れ**：床のラグに移り、〇〇が上から深く突く。まいとゆのは、両側からあおいに寄り添って、照れを煽る。あおいは、照れも冗談もなしで、正面から〇〇を見て、本音を言ってしまう。ここで堕ちる。そこから、何度もイく
- **決め台詞**：あおい「……もっと、して」
- **エロの中身**：正常位 → 〇〇があおいの脚を肩にかけて、深く。中出し。連続絶頂。喘ぎ声はレベル3 → 4
- **位置関係**：ラグの上に、あおいが仰向け。〇〇が上から。まいとゆのは、あおいの両側に寝そべって寄り添う
- **感情の流れ**：（あおい）照れ隠しが追いつかない → 正面から言ってしまう → 堕ちる

## 場面5：事後

- **流れ**：ラグの上で、4人で寝転ぶ。あおいは、まいとゆのに挟まれて、まだ余韻の中にいる。息が上がったまま、蕩けて、言葉も途切れ途切れ。もう、元のあおいには戻らない
- **決め台詞**：あおい「……おまんこ、まだ、ひくひくしてる……♡　〇〇さんの、いっぱい出てくる……」「……ちんぽ、きもちよすぎ……♡　……まだ、ほしいかも……」（言い回しは本文で調整する）
- **エロの中身**：余韻
- **位置関係**：ラグの上。あおいを真ん中に、両側にまいとゆの。〇〇はあおいの足元側
- **感情の流れ**：（あおい）蕩けている → 満たされている → まだ欲しい

事後のあおいは、照れ屋らしく斜めから濁すのではなく、堕ちた子として、蕩けたまま素直に求める。ここで一気に下品にして、堕ちた瞬間の落差を一番大きくする。ただし、あおいの気だるさと、「かも」で少しだけ濁す感じは残す。
