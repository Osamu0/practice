# 第3部 なぎ編 4話：もっと

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> なぎの話し方は `企画メモ.md` のなぎの欄を参照。〇〇への敬語は場面3で崩れ、そのあとはタメ口（呼び方は「〇〇さん」のまま）。

なぎ編の山場。3話の終わり（まいとほのかが、なぎの目の前でちんぽに頬ずりしている）から続く。なぎが思わず手を伸ばし、2人はタイミングを見て帰っていく。なぎは、自分の家で、ファンと2人きりで残される。2人きりで、〇〇がトドメを刺し、なぎが照れずに本音を言って、ほぼ完堕ちに届く。

- **なぎ**：お酒で少しゆるんでいるが、状況はわかっていて、自分で手を伸ばす。最後の一言は、なぎ自身のもの。崩れたあと、口調の反転（よくしゃべる、はしゃぐ）がほんの少しだけ顔を出す。事後は、まだ気だるさと「かも」で濁す感じが残る
- **〇〇**：敬語とタメ口が混じる。なぎの「なにその顔」のようなツッコミは、まだ完堕ちしていないなぎだけのもの
- **まいとほのか**：完堕ち。なぎが手を伸ばしたら、タイミングを見て、2人きりにする
- **呼び方の語彙**：「おちんちん」「おちんぽ」「ちんぽ」を混ぜる

## 場面1：手を伸ばす

- **流れ**：まいとほのかが、なぎの目の前で頬ずりしている。ほのかが「なぎちゃんの顔と、おんなじくらいあるで」と言う。まいが「乗せてみよっか」と、〇〇のちんぽを、なぎの顔にそっと乗せる。根元が顎に当たって、先が頭のてっぺんまで届く。なぎは「……は？　うそでしょ」と笑いかけるが、すぐに笑いが消える。鼻のすぐ上に、熱くて重いものが乗っている。匂いが、まっすぐ入ってくる。頭がぼうっとして、さらに疼く。なぎは目を閉じて、もう一度、匂いを吸ってしまう。気づいたら、なぎの手が伸びている。指先で触れる。熱い。硬い。脈打っている。なぎは何も言わずに、握る
- **決め台詞**：なし
- **エロの中身**：ちんぽをなぎの顔に乗せる（顎から頭のてっぺんまで。小顔との比較）。匂いを嗅いで、さらに疼く。なぎが自分から手を伸ばして、触れて、握る
- **位置関係**：〇〇はソファの前に立つ。まいとほのかがその前にしゃがむ。なぎはソファに浅く座り直して、身を乗り出す。〇〇のちんぽが、なぎの顔に乗る
- **感情の流れ**：（なぎ）……顔と同じとか、ありえない → 笑いが消える → 匂いで頭がぼうっとする → さらに疼く → もう一度、嗅いでしまう → 気づいたら手が伸びていた → 熱い

## 場面2：2人が帰る

- **流れ**：なぎが握ったのを見て、まいとほのかは顔を見合わせる。まいがなぎの耳元で「あとは、2人でね」とささやき、ほのかと一緒に立ち上がって、バッグを持つ。「じゃあ、私ら帰るね」「なぎちゃん、明日オフやし、ゆっくりな」。玄関のドアが閉まる音。自分の家のリビングに、なぎと〇〇が2人きりで残る。なぎは「……え、ほんとに帰るの」と言うが、手は離さない。〇〇が「……さわって、くれますか」と頼む。なぎは小さく笑って、手を動かしはじめる
- **決め台詞**：なし
- **エロの中身**：なぎの手コキ。〇〇の敬語のお願い
- **位置関係**：なぎはソファに座ったまま、前に立つ〇〇のちんぽを握る。まいとほのかは帰っていて、もういない
- **感情の流れ**：（なぎ）2人が帰って、ちょっとだけ我に返る → 自分の家に、ファンと2人きり → でも、手が離れない → まあ、いいか （〇〇）なぎちゃんの家で、なぎちゃんと、2人きり

## 場面3：口で、そして崩れる

- **流れ**：なぎは手で触っているうちに、顔を近づけて、口に含む。小さな口に収まりきらない。〇〇はソファの前に膝をつき、なぎのスカートの中に手を入れる。なぎはパイパンで、もうとろとろに濡れている。〇〇が「やば……」と言うと、なぎは目を逸らして「……見ないでよ」。〇〇が調子に乗りかけて「なぎちゃん、もうこんなに」と言うと、なぎは「……なにその顔」と返そうとするが、匂いと疼きで頭がぼうっとしていて、声に力がない。言い終わる前に、〇〇の指が入って、ツッコミが続かなくなる（まだ完堕ちしていないなぎだけのツッコミだが、もう弱い）。控えめな声が抑えきれなくなり、〇〇への敬語も崩れる
- **決め台詞**：なぎ「……なにその顔」（方向。弱く、言い切れない。言い回しは本文で調整する）
- **エロの中身**：フェラ（小さな口に収まりきらない）→ 下着を脱がせる（パイパン）→ クンニ → 手マンで初めて潮を噴く。喘ぎ声はレベル1 → 2。控えめな声が、少しずつ抑えきれなくなる
- **位置関係**：なぎはソファに浅く座る。〇〇は床に膝をつき、正面から
- **感情の流れ**：（なぎ）咥えてみたかった → 見られて恥ずかしい → ツッコもうとするが、力が入らない → ツッコめなくなる → 噴いてしまった恥ずかしさ

## 場面4：〇〇がトドメを刺す

- **流れ**：〇〇が、そのままの体勢で挿入する。大きすぎて、なぎは息が止まる。細い腰が浮く。ゆっくり奥まで入る。なぎの控えめな声が抑えきれなくなる。〇〇への敬語も、完全に崩れる。どこかで、なぎの力がふっと抜ける。「まあ、いいか」と、取り繕うのをやめる
- **決め台詞**：なし
- **エロの中身**：ソファでの正常位（〇〇は床に膝立ち）。なぎの片脚を〇〇が抱える。喘ぎ声はレベル2〜3
- **位置関係**：なぎはソファに浅く座り、背もたれに背中を預ける。〇〇は床に膝立ちで、正面から、なぎの片脚を抱えて
- **感情の流れ**：（なぎ）入らない → 入った → 抑えたい → 抑えきれない → 力が抜ける → まあ、いいか

## 場面5：本音を言う

- **流れ**：床のラグに移り、〇〇が上から深く突く。なぎは、照れも冗談もなしで、正面から〇〇を見て、本音を言ってしまう。ここで、ほぼ完堕ちに届く。そこから、何度もイく。崩れた口から、はしゃいだような声がほんの少しだけこぼれる（口調の反転の最初の芽）
- **決め台詞**：なぎ「……もっと、して」
- **エロの中身**：正常位 → 〇〇がなぎの脚を肩にかけて、深く。中出し。連続絶頂。喘ぎ声はレベル3 → 4
- **位置関係**：ラグの上に、なぎが仰向け。〇〇が上から
- **感情の流れ**：（なぎ）照れ隠しが追いつかない → 正面から言ってしまう → ほぼ完堕ち

## 場面6：事後

- **流れ**：ラグの上で、なぎは息が上がったまま、蕩けている。〇〇が「……大丈夫？」と聞く。なぎは一瞬だけ照れて目を逸らすが、すぐに、蕩けたまま素直に言う。気だるさと、「かも」で少しだけ濁す感じは残っている。ローテーブルの上で、なぎのスマホが光る。同期3人のグループLINEに、まい『どうだった？♡』、ほのか『なぎちゃん、生きてる？』。なぎはそれを見て、ふっと笑って、返事をせずにスマホを伏せ、〇〇のちんぽに手を伸ばす
- **決め台詞**：なぎ「……おまんこ、まだ、ひくひくしてる……♡　〇〇さんの、いっぱい出てくる……」「……おちんちん、きもちよすぎ……♡　……まだ、ほしいかも……」（言い回しは本文で調整する）
- **エロの中身**：余韻
- **位置関係**：なぎの家のリビングのラグの上。なぎと〇〇の2人だけ。なぎは仰向けのまま、〇〇は横に寄り添う
- **感情の流れ**：（なぎ）蕩けている → 満たされている → まだ欲しい → 2人のLINEより、こっち （〇〇）棚のいちばん手前の三冊の子が、自分のちんぽで

事後のなぎは、照れ屋らしく斜めから濁すのではなく、堕ちた子として、蕩けたまま素直に求める。ここで一気に下品にして、堕ちた瞬間の落差を一番大きくする。ただし、なぎの気だるさと、「かも」で少しだけ濁す感じは残す（次の回から反転していく）。
