# 第3部 なぎ編 5話：〇〇の部屋

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> なぎの話し方は `企画メモ.md` の「完堕ちしたあとの口調」（なぎだけは逆にする）を参照。

4話から数週間。そのあいだに、〇〇はなぎの家に何度も来ていて、なぎはもう完堕ちしている（描かれない回）。この話で、なぎが初めて〇〇の部屋に来る。

- **なぎ**：完堕ち。表（仕事、ほかのメンバーの前）では、今までどおりクールで短い。裏では口調が反転しきっている（照れない。甘く、ねっとりと、下品にとろける。べったり甘えて離れない。囁くように話す。笑い方はとろけた「ふふ……♡」。自分からちんぽを褒める）。はしゃぐ方向にはしない。ちんぽの前ではハードコアな台詞（一人称は「私」と「なぎ」、「おちんちん」「おちんぽ」「ちんぽ」を混ぜる）。なぎらしさは何も残さない。〇〇は「〇〇さん」と呼ぶ
- **〇〇**：なぎにタメ口。調子に乗っている（わざと聞く、言わせる、焦らす）。命令形は使わない
- **描かれない回**：4話のあと、〇〇はなぎの家に何度も来ている。なぎの家の大きなソファ、キッチンカウンター、広い寝室。なぎは〇〇が来ると、玄関でまずちんぽに挨拶する

## 場面1：表のなぎ

- **流れ**：雑誌の撮影の現場。なぎはいつもどおり、クールで短い。カメラマンに褒められると「……ありがとうございます」と目を逸らす。休憩中、ゆいに「なぎ、最近なんか肌つやつやじゃない？」と言われ、「……別に。寝てるだけ」。スマホを見て、ふっと口元がゆるむ。その顔は、まいやほのかと同じになっている
- **決め台詞**：なし
- **エロの中身**：なし。なぎの心の声（今夜、〇〇の部屋に行く）
- **位置関係**：撮影スタジオ。なぎ、ゆい、ほかに1〜2人、カメラマン、スタッフ
- **感情の流れ**：（なぎ）表の顔は完璧 → 頭の中は今夜のこと

## 場面2：初めての〇〇の部屋

- **流れ**：夜、なぎが〇〇の部屋に来る。ドアが閉まった瞬間に、声のトーンが変わる。〇〇の腕に絡みついて、甘く囁く。「……ここが、〇〇さんの部屋……♡」「〇〇さんの匂いがする……」。部屋の隅の棚を見つける。いちばん手前の、自分の写真集が三冊。なぎは照れずに、〇〇に身体を寄せたまま、甘い声で聞く。「……ふふ、ほんとに三冊ある……♡」「どれがいちばん好き？」「どのページで、いちばんしたの……？」。〇〇がページを開くと、なぎはそのページと同じポーズをしてみせる
- **決め台詞**：なし
- **エロの中身**：なし（写真集のページと同じポーズをしてみせるところまで）
- **位置関係**：〇〇の部屋の玄関 → 部屋の中、棚の前
- **感情の流れ**：（なぎ）〇〇さんの部屋だ → 自分の写真集 → 照れない。うれしい （〇〇）表ではあんなにクールななぎちゃんが、べったり甘えてくる → 写真集の中のなぎちゃんと、目の前のなぎちゃん

## 場面3：ちんぽの前で

- **流れ**：なぎは〇〇の前にしゃがんで、ズボンを下ろす。ちんぽが出てきた瞬間に、甘えた顔から、さらにとろけきった顔に切り替わる。自分から顔に乗せて、匂いを嗅いで、ちんぽに話しかける（「今日も、なぎの顔よりおっきい……♡」）。褒めちぎる。咥える
- **決め台詞**：なし
- **エロの中身**：ちんぽを自分の顔に乗せる、匂いを嗅ぐ、話しかける、褒めちぎる、フェラ。ハードコアな台詞
- **位置関係**：棚の前の床。〇〇は立ったまま、なぎがしゃがむ
- **感情の流れ**：（なぎ）甘えている → ちんぽを見た瞬間に切り替わる → 頭の中がちんぽだけ

## 場面4：調子に乗る〇〇

- **流れ**：ベッドへ。〇〇は調子に乗って、すぐには入れない。写真集を開いて、なぎの顔の横に置く。「この顔の子に、入れていいの？」「ちゃんと言って」とわざと聞く。なぎはもうツッコまない。喜んで、何度でも言う。〇〇は先っぽだけで焦らし、なぎが泣きそうにねだるまで待ってから、奥まで突き入れる。写真集のクールな顔と、ベッドの上で崩れていく顔
- **決め台詞**：なし
- **エロの中身**：焦らし（先っぽだけ、言わせる）→ 正常位 → 寝バック → 立ちバック（姿見の前）。中出し。連続絶頂。喘ぎ声はレベル4
- **位置関係**：〇〇のベッド。写真集が、なぎの顔の横に開いて置いてある → 姿見の前
- **感情の流れ**：（なぎ）焦らされて、言わされるのがうれしい → 入った瞬間に崩れる （〇〇）写真集の顔と、目の前の顔 → この子は、俺のちんぽの前ではこうなる

## 場面5：事後

- **流れ**：なぎは、とろけたまま、〇〇の腕にべったりくっついて離れない。甘い声で「次、いつ来ていい……？」「明日は……？」「握手会の日って、〇〇さん来る？」。〇〇は「行くよ。なぎちゃんのレーンにも並ぶ」と答える。なぎは「……ふふ。じゃあ、ちゃんと塩対応しなきゃね」と、〇〇の胸に頬をすり寄せる
- **決め台詞**：なし
- **エロの中身**：余韻
- **位置関係**：〇〇のベッド
- **感情の流れ**：（なぎ）まだ一緒にいたい → 握手会でも会える （〇〇）表のなぎちゃんと、握手会で会う
- **ねらい**：6話（握手会と、会場の倉庫）への引き
