# 第3部 なぎ編 6話：握手会の裏

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

なぎ編の最後。握手会の日。3人とも完堕ちして猿みたいになっていて、夜まで待てない。休憩の時間をずらして1人ずつ抜け、会場の共用の備品倉庫で〇〇とする。壁の向こうでは、ほかのファンが3人の握手の列に並んでいる。第4部（めい編）への橋渡し。このあと2〜3か月の空きがある。

- **背徳感**：握手会の裏で、アイドルがセックスしている。〇〇にも女の子にも、ほかのファンへの背徳感がある。女の子は、さっきまで手を握っていたファンたちのすぐ近くで崩れ、戻ってまた笑顔で手を握る。〇〇は、自分の前後に並ぶファンたちが憧れている子を、裏で抱いている
- **3人**：完堕ち。表（レーン、控室、スタッフの前）では完璧な表の顔。裏（倉庫）ではちんぽの前で崩れる。声は殺す
- **〇〇**：3人にタメ口。調子に乗っている
- **決まり**：握手会ではメンバーごとに休憩の時間がずれる。同時にいなくなると怪しまれるので、休憩の時間を使って1人ずつ抜ける（第4部で、めいが倉庫のドアを開けたとき、1人の番が終わったばかりの〇〇が1人で残っているため）

## 場面1：なぎのレーン（表）

- **流れ**：全国握手会の会場。〇〇は一般のファンとして、なぎのレーンに並ぶ。前後のファンが、なぎの話をしている（「なぎちゃん、今日も塩対応なのがいいんだよな」「たまに照れるのが最高」）。〇〇の番。表のなぎは、にこりともせずに、小さく「ありがとうございます」と言うだけ。でも、両手で握った〇〇の手を、親指でそっとなぞる。剥がされる直前に、なぎが小声で一言。〇〇の後ろのファンは、何も気づかずに「やっぱ塩だったわ」と笑っている
- **決め台詞**：なぎ（小声で）「……休憩、二時から」（方向。言い回しは本文で調整する）
- **エロの中身**：なし。握手の手、親指でなぞる
- **位置関係**：白いパーテーションで仕切られたレーン。テーブルを挟んで向かい合い、両手で握手。横に剥がしのスタッフ。〇〇の前後にファン
- **感情の流れ**：（〇〇）前後のファンが憧れている、塩対応のなぎちゃん → この子と、昨日の夜も → 背徳感 （なぎ）表の顔のまま、〇〇の手だけは離したくない

## 場面2：控室で決める

- **流れ**：休憩の控室。まい、ほのか、なぎのほかに、ほかのメンバーもいる。3人だけのLINEグループで、こっそりやりとりする。なぎ『ねえ、休憩45分あるじゃん』『〇〇さん、会場にいる』。まい『だめだよ、ここ会場だよ』と言いながら、すぐに『どこならいける？』。ほのか『裏の通路の先に、備品の倉庫ある』。同時にいなくなると怪しまれるので、休憩の時間がずれるのを使って、1人ずつ抜けることに決める。順番は、休憩の早い順。〇〇にLINEで場所を送る
- **決め台詞**：なし。LINEで、3人の口調の違い（まいは柔らかいタメ口、ほのかは関西の柔らかさが混ざる、なぎは裏では反転してはしゃいでいる）が出るようにする
- **エロの中身**：なし
- **位置関係**：控室。3人は離れた席で、それぞれスマホを見ている。ほかのメンバーが近くで雑談している
- **感情の流れ**：（3人）夜まで待てない → 会場で、という背徳に昂る

## 場面3：倉庫

- **流れ**：〇〇は、握手の合間に、一般の側から裏の通路を通って、共用の備品倉庫に入って待つ。壁の向こうから、会場のアナウンスと、ざわめき、ファンの列の声が聞こえる。3人は決めたとおり、それぞれの休憩の時間に、1人ずつ抜けてくる。最初にまい。短い時間で済ませて、レーンに戻る。ほのかが続く。最後に、なぎ。2人とも、握手会の衣装のまま。脱ぐ時間はないので、下着だけずらして挿入する。物音を立てないように、声を殺しながら。廊下を通るスタッフの足音に、身体を固くする
- **決め台詞**：なし
- **エロの中身**：この話で詳しく見せるのは、まいとなぎの2人（ほのかの番は、来て戻ったことだけ見せる）。中出し。喘ぎ声は抑えたくぐもった声（レベル2）が、抑えきれずに漏れる。ちんぽの前の台詞は、ささやき声でハードコアに崩れる
  - **まい**：グループの顔が、段ボールに囲まれた倉庫で、という落差。棚に手をついて立ちバック。壁の向こうのファンの声に、中がきゅっと締まる。声が漏れそうになって、まいが「口、ふさいで」とねだり、〇〇が手でまいの口を覆う
  - **なぎ**：倉庫に入るなり、〇〇の前にしゃがんで、ちんぽに頬ずりする（さっきレーンで塩対応した相手に）。それから棚に背中を預けて、〇〇に片脚を抱えられての立位。〇〇が「さっき、塩対応だったね」と煽る。なぎは、表の声に戻らないまま、ささやき声で崩れる
- **位置関係**：狭い倉庫。腰くらいの高さのスチール棚が両側に並び、そのあいだの通路は人ひとりがやっと通れる幅。段ボールが積まれている
  - まい：まいが棚に両手をつき、〇〇が後ろから
  - なぎ：なぎが棚に背中を預け、〇〇が正面から、なぎの片脚を抱えて
- **感情の流れ**：（まい・なぎ）すぐそこにファンがいる、スタッフがいるかもしれない → だからこそ昂る → さっき手を握ったファンたちのすぐ近くで （〇〇）自分のところに、アイドルが1人ずつやってくる → 壁の向こうに並んでいるファンたちは、この子たちに会いに来ている

## 場面4：レーンに戻る

- **流れ**：3人は、何食わぬ顔で、1人ずつ控室に戻り、休憩明けのレーンに向かう。まいは、出されたまま、ファンの手を両手で握って笑顔で話す。なぎは、さっきと同じ塩対応で、ファンに小さく「ありがとうございます」。ファンは何も知らない。〇〇は、会場の端から、それを見ている
- **決め台詞**：なし
- **エロの中身**：なし。中に残っているもの（まいとなぎの心の声）
- **位置関係**：レーン。〇〇は会場の端
- **感情の流れ**：（まい・なぎ）表の顔 → 中に残っている感覚 → ファンへの背徳感 （〇〇）何も知らないファンたち → 背徳感と興奮

## 場面5：控室に戻る（第4部への引き）

- **流れ**：なぎが控室に戻ると、休憩中の後輩のめいがいる。めいが、なぎに、どこに行っていたのか聞く。なぎは、表の顔のまま、目を逸らして答える
- **決め台詞**：
  > めい「なぎさん、どこ行ってたんですか？」
  > なぎ「……ちょっと、お手洗い」
- **エロの中身**：なし
- **位置関係**：控室。めいと、ほかのメンバーたち
- **感情の流れ**：（なぎ）表の顔に戻る （めい）何気なく聞いただけで、特に気にしていない（メンバーが大勢いるので、先輩たちが1人ずついなくなることには気づかない）
- **ねらい**：第4部（めいが、倉庫のドアを開けて、〇〇と出会う）への引き。第4部の主役のめいを、ここで初めて少しだけ出す
