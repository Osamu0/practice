# 第4部 めい編 2話：倉庫で

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。めいは〇〇（年上）に丁寧語で話す。〇〇は名乗らない（名乗る暇もなく、めいはすぐにレーンに戻らなければならない）。めいは、この男が誰なのか（スタッフなのか、関係者なのか、ファンなのか）を知らないまま、最後まで行ってしまう

1話の続き。足音が過ぎたあと、めいは素直に飛び込み、その場で最後まで行って、ほぼ完堕ちに届く。見た瞬間から間を置かずに、一気に。めいが出たあと、次の番のほのかが入ってきて、〇〇が漏らしてしまう。

- **めい**：本能のまま突き進む。恥ずかしさはあっても、欲しい気持ちが勝っている。素直な反応が、全部顔と声に出る。最後は博多弁がこぼれる
- **〇〇**：敬語。行為の中で、タメ口が混じりはじめる
- **呼び方の語彙**：「おちんちん」「おちんぽ」を混ぜる

## 場面1：さわっても、いいですか

- **流れ**：足音が遠ざかる。2人とも息を吐く。〇〇は「すみません……！」と慌ててしまおうとする。めいはそれを止めるように、素直に聞いてしまう。〇〇は敬語で戸惑いながら、うなずく
- **決め台詞**：めい「……さわっても、いいですか」（迷いながらも、自分から飛び込む）
- **エロの中身**：なし（触れる直前まで）
- **位置関係**：倉庫の通路。めいはドアに背中をつけ、〇〇はめいの正面
- **感情の流れ**：（めい）戻らなきゃいけないのに → 触ってみたい → 言ってしまった （〇〇）めいちゃんが、自分から

## 場面2：手と口

- **流れ**：めいは、おそるおそる触れる。熱い。硬い。脈打っている。素直に驚いて、声に出る。手で触っているうちに、匂いに引き寄せられるように顔を近づけて、口に含む。〇〇が思わず腰を引くと、めいは「……だめ、ですか？」と見上げる
- **決め台詞**：なし
- **エロの中身**：手コキ → フェラ（めいは素直に夢中になる）。めいの身体の反応（衣装の下で、ショーツが湿っていく）
- **位置関係**：めいが通路にしゃがみ、〇〇は立ったまま
- **感情の流れ**：（めい）熱い → もっと → 口に入れたい → 夢中 （〇〇）握手会の衣装のめーたんが、自分のちんぽを

## 場面3：入れて、ください

- **流れ**：めいが口を離して、立ち上がる。脚が震えている。自分から棚に手をついて、衣装のスカートをたくし上げる。下着だけずらす。素直に、ねだる。〇〇は、戸惑いながらも止まれない。ゆっくり入れる。大きすぎて、めいは息が止まる。壁の向こうで、握手会のアナウンスが聞こえる。めいは口を自分の手でふさぐが、抑えきれない
- **決め台詞**：めい「……入れて、ください」
- **エロの中身**：立ちバック（棚に手をつく。衣装のまま、下着だけずらす）。声を殺して。めいのFカップが、衣装の中で揺れる。喘ぎ声はレベル2 → 3
- **位置関係**：めいが腰くらいの高さのスチール棚に両手をつき、〇〇が後ろから
- **感情の流れ**：（めい）欲しい → 入ってくる → 声が出そう → 抑えきれない （〇〇）壁の向こうでは、めーたんのレーンにファンが並んでいる

## 場面4：ほぼ完堕ち

- **流れ**：〇〇が、めいを抱え上げる。めいは〇〇の首に腕を回す。奥まで届く。素直な反応が、全部顔と声に出る。博多弁がこぼれる。何度もイって、最後は中に出されて、ほぼ完堕ちに届く
- **決め台詞**：堕ちる瞬間「……すごか……♡　こんなの、しらんかった……♡　おちんちん、とまらんっ……♡　めいのなか、ずっと、きもちよか……♡」（言い回しは本文で調整する）
- **エロの中身**：立位で抱え上げる（めいは〇〇の首に腕を回し、脚を〇〇の腰に絡める）。中出し。連続絶頂。喘ぎ声はレベル3 → 4（声を殺そうとして、抑えきれない）。博多弁が少しこぼれる
- **位置関係**：〇〇が棚に背中を預けて立ち、めいを正面から抱え上げる
- **感情の流れ**：（めい）こんなの、知らない → 止まらない → ほぼ完堕ち （〇〇）めーたんが、こんな顔

## 場面5：めいが出る

- **流れ**：めいのスマホに、休憩の終わりを知らせるアラーム。めいは慌てて衣装を直す。脚がうまく立たない。中から垂れてくるのを、ティッシュで押さえて、下着をはく。出ていく前に、振り返って、ちんぽに目をやってしまう。「……また、会えますか」。〇〇が答える前に、めいは出ていく
- **決め台詞**：めい「……また、会えますか」（方向。言い回しは本文で調整する）
- **エロの中身**：中から垂れてくるもの
- **位置関係**：倉庫のドアの前
- **感情の流れ**：（めい）戻らなきゃ → 離れたくない → この人の名前も知らない （〇〇）名乗る暇もなかった。めいちゃんの連絡先も、何も知らない

## 場面6：ほのかが入ってくる

- **流れ**：少しして、次の番のほのかが入ってくる。〇〇の様子がおかしい。倉庫にこもった匂いも、いつもより濃い。ほのかに「どうしたん？」と聞かれて、〇〇は漏らしてしまう。ほのかは驚くが、完堕ちしているので怒らない。笑う。猿なので、そのままほのかの番もする
- **決め台詞**：
  > 〇〇「……さっき、めいちゃんが来て……」
  > ほのか「めいちゃんも、これ知ってしもたんや」（方向。言い回しは本文で調整する）
- **エロの中身**：ほのかの番（短く。即尺 → 立ちバック）。ほのかが「めいちゃんの、まだ残ってる」と〇〇のちんぽを舐める
- **位置関係**：倉庫
- **感情の流れ**：（ほのか）驚く → 笑う → めいちゃんも、こっち側に来た → 興奮する （〇〇）言ってしまった
- **ねらい**：3話（めいがレーンに戻る、「あの時の」）への引き。先輩たちは〇〇から知るが、めいは、先輩たちのことも、先輩たちに知られたことも、まだ知らない
