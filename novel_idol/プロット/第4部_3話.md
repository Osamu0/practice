# 第4部 めい編 3話：あの時の

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。

2話と同じ日。めいは中に出されたまま、レーンに戻って、ファンの手を握る。しばらくすると、〇〇がめいのレーンに並ぶ。めいは、倉庫のあの人が、自分の最初の握手会に来てくれていた人だと気づく（「あの時の」）。

- **めい**：表の顔は保っている。中に残っている感覚、疼き、背徳感。〇〇の連絡先は知らない
- **〇〇**：ファンとしてレーンに並ぶ。箱推しなので、昔からめいのレーンにも来ていた
- **背徳感**：めいは、さっきまでのことを思い出しながら、何も知らないファンの手を握る

## 場面1：レーンに戻る（表）

- **流れ**：めいは何事もなかったようにレーンで握手を再開する。笑顔で、ファンの一人ひとりに合わせて言葉を返す（緊張しているファンには優しく、冗談には冗談で）。でも、中から垂れてくる感覚に、ときどき太ももを閉じる。さっき倉庫で握っていたものと同じ手で、ファンの手を握っている。ファンは何も知らない
- **決め台詞**：なし
- **エロの中身**：なし。めいの心の声と、中に残っている感覚
- **位置関係**：めいのレーン。テーブルを挟んで、ファンと両手で握手。横に剥がしのスタッフ
- **感情の流れ**：（めい）表の顔 → 中に残っている → さっきの手で、ファンの手を → 背徳感 → 疼く

## 場面2：〇〇がめいのレーンに

- **流れ**：しばらくすると、めいのレーンに、あの倉庫の男が並んでいる。〇〇は、ファンとして、いつもどおり手を差し出す。めいは、表の顔で笑って握手をしながら、内心で気づく。この人、知っている。3期でデビューしたばかりのころ、最初の握手会。めいのレーンはまだ人が少なくて、緊張で手が冷たかった。そのとき、「声、いいですね」「応援してます」と言ってくれた人。それから、ずっと、ときどき来てくれていた人
- **決め台詞**：めいの心の声「（……あの時の、人やん……）」（方向。言い回しは本文で調整する）
- **エロの中身**：なし。めいの心の声で、さっきまでのことを思い出して疼く
- **位置関係**：めいのレーン。テーブルを挟んで、両手で握手
- **感情の流れ**：（めい）あの人 → あの時の人 → 最初から、来てくれていた → さっきまでのことを思い出す → 表の顔を保つ → 手を離したくない （〇〇）めいちゃんの最初の握手会、覚えてる。手が冷たかった

〇〇の推しのきっかけ（まいの最初の握手会で、手が冷たかったのに「来てくれてありがとう」と笑った）と、少し似た形にしておく。〇〇は、どのメンバーの最初も見てきた古参のファン。

## 場面3：握手の数秒

- **流れ**：数秒しかない。めいは、表の笑顔のまま、両手で握った〇〇の手を、少しだけ強く握る。小声で、素直に一言だけ言う。剥がしのスタッフに肩を叩かれて、〇〇は離れていく。〇〇の後ろのファンは、何も気づいていない
- **決め台詞**：めい（小声で）「……覚えてます。最初の握手会の」（方向。言い回しは本文で調整する）
- **エロの中身**：なし
- **位置関係**：めいのレーン
- **感情の流れ**：（めい）言いたい → 言えた → 次は、いつ会えるかわからない （〇〇）覚えてくれていた

## 場面4：控室（4話への引き）

- **流れ**：握手会のあと、控室。めいは、表の顔で、ひなたやすずと話している。でも、疼きが止まらない。連絡先も、何も知らない。少し離れた席で、ほのかが、そんなめいを見て、ふっと笑う。めいは、ほのかが知っていることを知らない
- **決め台詞**：ほのか「……めいちゃん、今日、顔赤いな」（方向。言い回しは本文で調整する）
- **エロの中身**：なし
- **位置関係**：控室。めい、ひなた、すず。少し離れて、ほのか、まい、なぎ
- **感情の流れ**：（めい）会いたい → どうしたら → ほのかさんに見られている？ （ほのか）めいちゃんも、こっち側
- **ねらい**：4話（先輩たちとお互いを知る）への引き
