# 第4部 めい編 3話：やってみます

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。

2話の続き。握手会の最中。休憩を2回使う。1回目は、ほのかに混じって。2回目は、めいが一人で倉庫に戻って、最後まで行って堕ちる。めいは、〇〇が誰なのかはまだ知らない。

めいは、隠れてオナニーを始めていたくらいなので、怖がらない。恥ずかしさはあっても、それ以上に、期待と欲しい気持ちが勝っている。

## 場面1：中に入る

- **流れ**：ほのかが、ドアの隙間に向かって声をかける。〇〇は振り向いて、めいがいることに気づき、固まる（箱推しなので、めいのことも知っている）。めいは、乱れた衣装のまま、自分から中に入ってくる。ほのかは、手を引いたりはしない。〇〇とつながったまま、めいのほうに少し場所を空けるだけ
- **決め台詞**：ほのか「……めいちゃん、おいで」／めい「……やってみます」（迷いながらも自分から飛び込む、めいらしい一言）
- **エロの中身**：なし（ほのかと〇〇はつながったまま）
- **位置関係**：倉庫の中。めいがドアから入ってきて、ほのかと〇〇のそばに来る
- **感情の流れ**：（めい）見つかった恥ずかしさ → でも、もう引き返せない → 自分から飛び込む （〇〇）めいちゃんまで？

## 場面2：1回目の休憩

- **流れ**：めいは、ほのかの横に並んで、ほのかがしていることを見ながら、同じように〇〇に触れる。ほのかは、手取り足取り教えるのではなく、ときどき一言かけるくらい。めいは、ほのかを見て真似しながら、ほのかと交互に〇〇に咥える。少しだけ、めいにも挿入する。そこで、休憩の終わりの時間が来てしまう。慌てて身支度をして、それぞれのレーンに戻る
- **決め台詞**：なし
- **エロの中身**：Wフェラ（めいはほのかを見て真似る）→ めいに少しだけ挿入。喘ぎ声はレベル1〜2。声を殺しながら
- **位置関係**：〇〇が棚に寄りかかって立ち、めいとほのかが並んで膝をつく → めいが棚に手をつき、〇〇が後ろから。ほのかはめいの横で、めいの顔を覗き込む
- **感情の流れ**：（めい）恥ずかしい → でも、ずっと欲しかった → ほのかさんの真似をして、夢中になる → 入ってきたところで、時間切れ

## 場面3：握手会に戻る

- **流れ**：めいは、何事もなかったようにレーンで握手を再開する。でも、身体の奥が疼いて、我慢できない。何人か握手したところで、スタッフに断って、レーンを離れる
- **決め台詞**：めい（スタッフに）「衣装がちょっと……直してきます」（1回目で実際に乱れているので、嘘にもならない）
- **エロの中身**：表の顔で握手をしながら、疼いている。心の声
- **位置関係**：自分のレーン。テーブルを挟んで、ファンと両手で握手
- **感情の流れ**：（めい）表の顔 → 我慢できない → 抜ける

## 場面4：めいだけ戻る

- **流れ**：めいは、一人で倉庫へ急ぐ。今度は迷わない。〇〇は、まだ倉庫に残っている。ほのかは、自分のレーンで握手を続けている
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：裏の通路 → 倉庫
- **感情の流れ**：（めい）待ちきれない

## 場面5：最後まで（めいと〇〇の2人）

- **流れ**：今度は、ほのかはいない。めいが、自分から〇〇を求める。1回目でほのかを見て覚えたことを、自分でやってみる。素直な反応が、そのまま顔と声に出る。最後まで行って、ここで堕ちる
- **決め台詞**：堕ちる瞬間「……すごか……♡　こんなの、しらんかった……♡　もっと……っ、もっと、して……っ♡　とまらんっ……♡」（AとBの組み合わせ。言い回しは本文で調整する）
- **エロの中身**：パイズリ（めいのFカップ）→ 挟みながら先を咥えるパイズリフェラ → 谷間に射精（〇〇は萎えない）→ 〇〇が棚に腰かけ、めいが向かい合って跨がる → 〇〇がめいを抱え上げる。中出し。喘ぎ声はレベル3〜4。博多弁が少しこぼれる
- **位置関係**：〇〇が棚に寄りかかって立ち、めいが膝をついてパイズリ → 〇〇が腰くらいの高さの棚に浅く腰かけ、めいが向かい合って跨がる → 〇〇が立ち上がって、めいを抱え上げる（めいは〇〇の首に腕を回す）
- **感情の流れ**：（めい）ほのかさんを見て覚えたことを、自分で → 止まらない → 堕ちる

## 場面6：戻る

- **流れ**：めいは、乱れた衣装を直して、レーンへ戻る。〇〇が誰なのかは、まだ知らないまま
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：倉庫 → 自分のレーン
- **感情の流れ**：（めい）余韻のまま、表の顔に戻る
