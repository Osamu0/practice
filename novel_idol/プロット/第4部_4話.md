# 第4部 めい編 4話：〇〇の部屋

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。めいは先輩たちには丁寧語で、「まいさん」「ほのかさん」「なぎさん」と呼ぶ。〇〇（年上）には「〇〇さん」と呼ぶ。

3話から数日。めいは〇〇の名前も連絡先も知らない。ほのかがめいに声をかけ、控室で4人がお互いを知る。めいは、初めて〇〇の部屋に行く。完堕ちしためいの1回目。

- **めい**：倉庫の日に、ほぼ完堕ちに届いている。この話から完堕ち。表では今までどおり。〇〇の部屋（裏）では、来た瞬間から求める。ちんぽの前ではハードコアな台詞（一人称は「私」と「めい」、「おちんちん」「おちんぽ」を混ぜる）。考えながら話すので一文がまとまらないのが、ちんぽの前ではさらにまとまらなくなる。博多弁が混ざる
- **〇〇**：めいにタメ口。調子に乗る（わざと聞く、言わせる、焦らす）
- **控室**：4人だけになっても、控室は仕事の場で、いつ誰が入ってくるかわからない。表と裏のあいだ。先輩たちは声を抑えて話す。なぎは反転しないが、いつものクールさでもない（下の場面3）

## 場面1：めいの数日

- **流れ**：倉庫の日から数日。めいは、仕事のあいだも、家に帰ってからも、倉庫のことが頭から離れない。名前も連絡先も知らない。ファンの人なら、次の握手会でまた会えるかもしれない。でも、それまで待てない
- **決め台詞**：なし
- **エロの中身**：短く。めいが家で一人で、倉庫のことを思い出しながら触る（すぐにやめられない）
- **位置関係**：仕事の現場 → めいの部屋
- **感情の流れ**：（めい）頭から離れない → 待てない → どうしたら

## 場面2：ほのかが声をかける

- **流れ**：仕事の合間、楽屋のトイレの前で、ほのかとめいが2人きりになる。ほのかが、小声で聞く。めいは固まる。ほのかは、ふっと笑って、自分のことを言う
- **決め台詞**：
  > ほのか「……倉庫の人、また会いたい？」
  > ほのか「私も、やねん。あの人と」（方向。言い回しは本文で調整する）
- **エロの中身**：なし
- **位置関係**：楽屋のトイレの前の廊下。ほかに人はいない
- **感情の流れ**：（めい）どうして知って → ほのかさんも？ → 力が抜ける （ほのか）めいちゃんも、こっち側

## 場面3：控室で、4人

- **流れ**：その日の仕事のあと、ほかのメンバーがはけた控室。まい、ほのか、なぎの3人が、めいを囲むように座る。3人とも〇〇と会っていること、あの人が〇〇という古参のファンであること。めいは、倉庫の男の名前を、ここで初めて知る。先輩たちは、声を抑えながらも、恥も外聞もなく話す（何回出されたか、倉庫の順番のこと）。なぎは、反転はしないが、いつものクールさでもない。口元がゆるんでいて、身を乗り出して、低い声で「……ふふ。めいも、か」「で、どうだった？」と聞いてくる。めいは、いつもクールななぎさんの、見たことのない顔に驚く。途中でスタッフがドアを開けて「お疲れさまでーす、鍵閉めますねー」と言い、4人は一瞬で表の顔に戻る。スタッフが出ていくと、また顔を寄せる。最後に、ほのかがめいに〇〇のLINEを教える
- **決め台詞**：なし。4人の口調の違い（まいは柔らかいタメ口、ほのかは関西の柔らかさ、なぎはクールでも反転でもない、ゆるんだ低い声、めいは先輩に丁寧語で、驚きがそのまま出る）が出るようにする
- **エロの中身**：なし（声を抑えた猥談）
- **位置関係**：人がはけた控室。めいを囲むように、3人が座る
- **感情の流れ**：（めい）先輩たちも → 驚き → なぎさんの見たことのない顔 → 先輩たちの秘密の輪に入れてもらえた → 〇〇さん、という名前 （先輩3人）めいちゃんも、こっち側 → 昂る

## 場面4：初めての〇〇の部屋

- **流れ**：夜、めいが一人で〇〇の部屋に来る。〇〇は、めいのLINEを受けて待っていた。ドアが閉まった瞬間に、めいは〇〇に抱きつく。それから、〇〇の前にしゃがんで、ズボンを下ろす。ちんぽが出てきた瞬間に切り替わる。頬ずりして、匂いを嗅いで、話しかける。部屋の棚に、めいの写真集とグッズも並んでいるのを見つけて、めいは「……あ、めいの」と照れずにうれしそうにする。最初の握手会のことを、短く話す（めい「覚えてました」、〇〇「俺も。手、冷たかった」）。それから、ベッドへ
- **決め台詞**：なし
- **エロの中身**：玄関で即尺（頬ずり、匂い、話しかける）→ ベッドで騎乗位（めいが自分から腰を振る。Fカップが揺れる。〇〇は下から見上げる）→ 正常位で胸を揉みしだかれ、乳首を吸われながら（めいは乳首を吸われただけでイってしまい、自分の身体に驚く）→ 中出しを続けて。〇〇は調子に乗って、わざと聞いて、言わせる。喘ぎ声はレベル4。博多弁のおねだり
- **位置関係**：〇〇の部屋の玄関で、めいがしゃがみ、〇〇は立ったまま → 〇〇のベッドで、〇〇が仰向け、めいが跨がる → めいが仰向け、〇〇が上から
- **感情の流れ**：（めい）やっと会えた → 来た瞬間から欲しい → ちんぽを見た瞬間に切り替わる → 止まらない （〇〇）最初の握手会で、手が冷たかったあの子が → 自分のちんぽの前で、こんな顔
