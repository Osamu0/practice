# 第5部 1話：まいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。

ロケの前に、1人ずつそれぞれの家で。第4部から数か月が経っている。〇〇は、まいの家にもう何度も来ていて、合鍵も持っている。〇〇に遠慮はなく、まいは堕ちきっている。初めてまいの家に来た夜（第1部3話）とは、まるで違う2人。堕ちきっているので、激しくする。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

## 場面1：合鍵で

- **流れ**：ロケの少し前。仕事帰りのまいから、『今日、うち来て』とLINEが来る。〇〇は、インターホンも押さずに、合鍵で玄関を開ける。キッチンから、まいが「おかえり」と言う。〇〇は一瞬だけ、初めてこの家に来た夜を思い出す。本人の家にいることが信じられなかった自分が、いまは「ただいま」と返している
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：玄関 → キッチン
- **感情の流れ**：（〇〇）あの夜とは、まるで違う （まい）待ってた

## 場面2：キッチンで、ディープスロート

- **流れ**：まいは、部屋着で〇〇の分のごはんを作っている。包容力のあるお姉さんらしく、〇〇の世話を焼く。でも、目が合うたびに、もう我慢できないという顔をしている。料理の途中、〇〇が後ろから抱きつくと、まいは火を止めて振り向き、キスをする。そのまま床に膝をついて、自分から〇〇のモノを喉の奥まで咥え込む
- **決め台詞**：なし
- **エロの中身**：キス → まいが自分からするディープスロート（喉の奥まで咥え込む。えずきそうになりながらも、自分から深く。涙目、よだれ）→ 口の中に出されて、飲む。喘ぎ声はくぐもった声。音は擬音のルールで段階的に（じゅぽっ → ぐぽっ、ごぽっ → ｸﾞﾎﾟｯｸﾞﾎﾟｯ）
- **位置関係**：キッチン。まいがコンロの前に立ち、〇〇が後ろから抱きつく → まいが振り向いて、キッチンの床に膝をつく。〇〇はシンクに腰を預けて立つ
- **感情の流れ**：（まい）世話を焼きたい → でも、我慢できない → 自分から、奥まで

〇〇は命令しない男なので、ディープスロートは、まいが自分から深く咥え込む形にする。

## 場面3：ソファで、まいが上から

- **流れ**：リビングの大きなソファ。今度は、まいが〇〇を押し倒して跨がる。お姉さんらしく、からかうように腰をゆっくり回し、〇〇の反応を楽しむ。でも、自分のほうが先に気持ちよくなって、からかう余裕がなくなっていく
- **決め台詞**：なし（例：まい「〇〇くん、どうしてほしい？」）
- **エロの中身**：騎乗位（ゆっくり回す → 自分で止まらなくなって、上下に激しく）。揺れる胸を〇〇が下から掴む。中出し。喘ぎ声はレベル3
- **位置関係**：リビングのソファ。〇〇が仰向けになり、まいが跨がる
- **感情の流れ**：（まい）からかいたい → 余裕がなくなる

## 場面4：窓際で、激しく

- **流れ**：初めての夜に、〇〇が眺めに驚いた窓。いまは、その眺めを気にもとめない。まいが窓に手をつき、〇〇は遠慮なく腰を掴んで、後ろから激しく打ちつける。まいはガラスに押しつけられて、胸も頬もガラスに潰れる。何度もイって、脚が震えて立っていられなくなる。それでも〇〇は止めない
- **決め台詞**：なし
- **エロの中身**：窓際での立ちバック。激しいピストン。連続絶頂、潮吹き（窓の下の床が濡れる）。中出し。喘ぎ声はレベル4（実況まじり）。外からは見えない高層階だが、ガラスに映る自分たちの姿に昂る（露出・野外は別の話に取っておくので、ここでは抑える）
- **位置関係**：リビングの大きな窓。まいがガラスに両手をつき、〇〇が後ろから腰を掴む → まいの脚が崩れて、ガラスに上半身を預けて、〇〇に腰だけを支えられる
- **感情の流れ**：（まい）壊れそう → それでも、もっと

## 場面5：ベッドで、抜かずに何度も

- **流れ**：〇〇が、崩れたまいを抱えてベッドへ運ぶ。まいは甘えた声で、めちゃくちゃにしてとねだる。〇〇は絶倫のまま、抜かずに何度も中に出す。まいはアヘ顔で、理性も呂律も崩れていく
- **決め台詞**：なし
- **エロの中身**：まんぐり返し（真上から、深く激しく突き下ろす）→ 寝バック（ベッドに押しつけて、体重をかけて）。連続絶頂、抜かずの連続中出し。アヘ顔、白目、よだれ。喘ぎ声はレベル4
- **位置関係**：まいが仰向けで、脚を顔の横まで折り曲げられ、〇〇が真上から → まいがうつ伏せで、〇〇が上から全体重をかけて重なる
- **感情の流れ**：（まい）甘えたい、めちゃくちゃにされたい → 理性が溶ける

## 場面6：冷めたごはんと、ロケの話

- **流れ**：夜中、すっかり冷めたごはんを温め直して、2人で食べる。まいは〇〇の世話を焼きながら、ロケの話をする。〇〇が本当に来るのかと笑う
- **決め台詞**：なし（例：まい「〇〇くん、本当に来るの？」）
- **エロの中身**：余韻
- **位置関係**：ダイニングテーブルで、並んで食べる
- **感情の流れ**：（まい）楽しみ
- **ねらい**：ロケ先の話への引き（ほかの3人の家の話を挟むので、軽く触れる程度）
