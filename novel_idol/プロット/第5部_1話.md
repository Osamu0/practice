# 第5部 4人の家編 1話：まいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。行為は `行為リスト.md` を参照。

ロケの前に、1人ずつそれぞれの家で（時系列は気にしすぎない）。〇〇は、まいの家にもう何度も来ていて、合鍵も持っている。〇〇に遠慮はなく、調子に乗っている。まいは完堕ちしている。ちんぽの前ではハードコアな台詞（一人称は「私」と「まい」、「おちんちん」「おちんぽ」「ちんぽ」を混ぜる）。初めてまいの家に来た夜（第1部3話）とは、まるで違う2人。

堕ちきったまいは、〇〇の前ではお姉さんの余裕を保てない。からかう余裕も、世話を焼く余裕も、すぐに崩れて、ただ欲しがる。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

## 場面1：合鍵で

- **流れ**：ロケの少し前。仕事帰りのまいから、『今日、うち来て』とLINEが来る。〇〇は、インターホンも押さずに、合鍵で玄関を開ける。キッチンから、まいが「おかえり」と言う。〇〇は一瞬だけ、初めてこの家に来た夜を思い出す。本人の家にいることが信じられなかった自分が、いまは「ただいま」と返している
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：玄関 → キッチン
- **感情の流れ**：（〇〇）あの夜とは、まるで違う （まい）待ってた

## 場面2：キッチンで、ねだるイラマチオ

- **流れ**：まいは、部屋着で〇〇の分のごはんを作っている。世話を焼こうとするが、目が合うたびに、もう我慢できないという顔をしている。〇〇が後ろから抱きつく。まいの腰に、硬いものが当たる。その瞬間、まいの顔が変わる（ちんぽの前の切り替わり）。まいは火を止めて振り向き、唾液を交わすような深いキスをする。そのまま床に膝をついて、〇〇のモノを喉の奥まで咥え込む。自分で深くするだけでは足りなくなって、〇〇の手を取って自分の頭に置かせ、「押さえて」とねだる。ねだられた〇〇は、遠慮なくまいの頭を押さえて、喉の奥まで突き入れる
- **決め台詞**：なし（例：まい「……頭、押さえて……♡」）
- **エロの中身**：唾液を交わすキス → まいが自分から喉奥まで咥える → まいがねだって、イラマチオ（〇〇が頭を押さえて、喉奥まで。手加減しない）。涙目、えずき、えずき汁が糸を引いて顎から垂れる、よだれ、メイク崩れ。喉奥に射精 → まいは口を開けて残りを〇〇に見せてから、飲む。喘ぎ声はくぐもった声。音は擬音のルールで段階的に（じゅぽっ → ぐぽっ、ごぽっ → ｸﾞﾎﾟｯｸﾞﾎﾟｯ）
- **位置関係**：キッチン。まいがコンロの前に立ち、〇〇が後ろから抱きつく → まいが振り向いて、キッチンの床に膝をつく。〇〇はシンクに腰を預けて立ち、まいの頭に両手を置く
- **感情の流れ**：（まい）世話を焼きたい → 我慢できない → 自分からでは足りない → 押さえてほしい

始まりは、まいのおねだり。ねだられたら、〇〇は手加減しない。

## 場面3：ソファで、まいが上から

- **流れ**：リビングの大きなソファ。〇〇は調子に乗って、棚からまいの写真集を取り、表紙の笑顔を開いてソファの背に立てかける。「この顔の子が、今からどうなるの？」とわざと聞いて、まいに言わせる。まいは〇〇を押し倒して、顔に跨がる。自分から腰を〇〇の口に擦りつけて、止まらなくなる。そのまま下にずれて〇〇に跨がり、騎乗位で自分から腰を打ちつける。お姉さんの余裕はどこにもなく、ただ気持ちいいところに当てようと夢中で腰を落とす
- **決め台詞**：なし
- **エロの中身**：顔面騎乗（まいが自分から擦りつける）→ 騎乗位（杭打ち。上から何度も腰を落とす）。揺れる胸を〇〇が下から掴む。中出し。喘ぎ声はレベル3
- **位置関係**：リビングのソファ。〇〇が仰向けになり、まいが顔に跨がる → まいが下にずれて、〇〇の腰に跨がる
- **感情の流れ**：（まい）欲しい → 自分で止まれない

## 場面4：窓際で、激しく

- **流れ**：初めての夜に、〇〇が眺めに驚いた窓。いまは、その眺めを気にもとめない。まいが窓に手をつき、〇〇は遠慮なく腰を掴んで、後ろから激しく打ちつける。途中で、まいの片脚を抱え上げて、さらに深く。まいはガラスに押しつけられて、胸も頬もガラスに潰れる。何度もイって、脚が震えて立っていられなくなる。それでも〇〇は止めない
- **決め台詞**：なし
- **エロの中身**：窓際での立ちバック → 片足を抱え上げての立ちバック。激しいピストン。連続絶頂、潮吹き（窓の下の床が濡れる）。中出し。喘ぎ声はレベル4（実況まじり）。外からは見えない高層階だが、ガラスに映る自分たちの姿に昂る（露出・野外は第8部に取っておくので、ここでは抑える）
- **位置関係**：リビングの大きな窓。まいがガラスに両手をつき、〇〇が後ろから腰を掴む → 〇〇がまいの片脚を抱え上げる → まいの脚が崩れて、ガラスに上半身を預けて、〇〇に腰だけを支えられる
- **感情の流れ**：（まい）壊れそう → それでも、もっと

## 場面5：ベッドで、種付けプレス

- **流れ**：〇〇が、崩れたまいを抱えてベッドへ運ぶ。まいは自分で脚を抱えて、めちゃくちゃにして、中にいっぱい出して、とねだる。〇〇は真上から体重をかけて、深く打ち下ろす。抜かずに何度も中に出す。まいはアヘ顔で、理性も呂律も崩れていく。最後の一回の前に、〇〇がお願いする。「写真集の表紙に、出したい」。まいはうれしそうにうなずき、ソファから持ってきた写真集を、自分の顔の横に置く。〇〇は抜いて、表紙のまいの笑顔に出す。まいは、表紙の自分にかかったものを、舌で舐め取る（〇〇からのお願いのエスカレート）
- **決め台詞**：なし（例：まい「……孕ませて……っ♡」）
- **エロの中身**：種付けプレス（まいが脚を顔の横まで折り曲げ、〇〇が真上から全体重で打ち下ろす）。孕ませ懇願。連続絶頂、抜かずの連続中出し。アヘ顔、白目、よだれ。喘ぎ声はレベル4。最後は写真集の表紙に射精して、まいが舐め取る
- **位置関係**：まいが仰向けで、脚を顔の横まで折り曲げ、〇〇が真上から体重をかけて重なる
- **感情の流れ**：（まい）めちゃくちゃにされたい → 理性が溶ける → 表紙の自分を汚されるのが、うれしい （〇〇）何回も開いた写真集の表紙に

## 場面6：お掃除と、冷めたごはん

- **流れ**：抜いたあと、まいはとろけた顔のまま、自分からお掃除フェラをする。夜中、すっかり冷めたごはんを温め直して、2人で食べる。まいは〇〇の世話を焼きながら、ロケの話をする。〇〇が本当に来るのかと笑う
- **決め台詞**：なし（例：まい「〇〇くん、本当に来るの？」）
- **エロの中身**：お掃除フェラ → 余韻
- **位置関係**：ベッド → ダイニングテーブルで、並んで食べる
- **感情の流れ**：（まい）満たされた → 楽しみ
- **ねらい**：ロケ先の話への引き（ほかの3人の家の話を挟むので、軽く触れる程度）
