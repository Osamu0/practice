# 第5部 1話：まいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。

ロケの前に、1人ずつそれぞれの家で。第1部3話（初回）以来の、まいの家。〇〇はもう遠慮がなく、まいは堕ちきっている。初回と比べられる形にする。堕ちきっているので、激しくする。

## 場面1：まいの家へ

- **流れ**：ロケの少し前。仕事帰りのまいから、『今日、うち来て』とLINEが来る。〇〇は、初めてまいの家に来た夜のことを思い出す。あのときは、本人の家にいることが信じられなかった。いまは、迷わずインターホンを押す
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：まいのマンションの前 → 玄関
- **感情の流れ**：（〇〇）あの夜とは違う自分

## 場面2：キッチンから

- **流れ**：まいは、部屋着で〇〇を迎える。ごはんを作って待っていた。包容力のあるお姉さんらしく、〇〇の世話を焼く。でも、目が合うたびに、もう我慢できないという顔をしている。料理の途中、〇〇が後ろから抱きつくと、まいは振り向いてキスをする。そのまま床に膝をついて、自分から〇〇のモノを喉の奥まで咥え込む
- **決め台詞**：なし
- **エロの中身**：キス → まいが自分からするディープスロート（喉の奥まで咥え込む。えずきそうになりながらも、自分から深く。涙目、よだれ）。喘ぎ声はくぐもった声。音は擬音のルールで段階的に（じゅぽっ → ぐぽっ、ごぽっ → ｸﾞﾎﾟｯｸﾞﾎﾟｯ）
- **位置関係**：キッチン。まいがコンロの前に立ち、〇〇が後ろから抱きつく → まいが振り向いて、キッチンの床に膝をつく。〇〇はシンクに腰を預けて立つ
- **感情の流れ**：（まい）世話を焼きたい → でも、我慢できない → 自分から、奥まで

〇〇は命令しない男なので、ディープスロートは、まいが自分から深く咥え込む形にする。

## 場面3：窓際で（激しく）

- **流れ**：第1部3話で、〇〇が眺めに驚いた窓。その窓際で、まいが窓に手をつく。〇〇は遠慮なく腰を掴んで、後ろから激しく打ちつける。まいはガラスに押しつけられて、胸も頬もガラスに潰れる。何度もイって、脚が震えて立っていられなくなる。それでも〇〇は止めない
- **決め台詞**：なし
- **エロの中身**：窓際での立ちバック。激しいピストン。連続絶頂、潮吹き（窓の下の床が濡れる）。中出し。喘ぎ声はレベル4（実況まじり）。外からは見えない高層階だが、ガラスに映る自分たちの姿に昂る（露出・野外は別の話に取っておくので、ここでは抑える）
- **位置関係**：リビングの大きな窓。まいがガラスに両手をつき、〇〇が後ろから腰を掴む → まいの脚が崩れて、ガラスに上半身を預けて、〇〇に腰だけを支えられる
- **感情の流れ**：（まい）壊れそう → それでも、もっと （〇〇）あの夜、眺めに驚いた窓で

## 場面4：ベッドで、抜かずに何度も

- **流れ**：〇〇が、崩れたまいを抱えてベッドへ運ぶ。まいは甘えた声で、めちゃくちゃにしてとねだる。〇〇は絶倫のまま、抜かずに何度も中に出す。まいはアヘ顔で、理性も呂律も崩れていく
- **決め台詞**：なし
- **エロの中身**：まんぐり返し（真上から、深く激しく突き下ろす）→ 寝バック（ベッドに押しつけて、体重をかけて）。抜かずの連続中出し。アヘ顔、白目、よだれ。喘ぎ声はレベル4
- **位置関係**：まいが仰向けで、脚を顔の横まで折り曲げられ、〇〇が真上から → まいがうつ伏せで、〇〇が上から全体重をかけて重なる
- **感情の流れ**：（まい）甘えたい、めちゃくちゃにされたい → 理性が溶ける

- **決め台詞**：なし（例：まい「〇〇くん、本当に来るの？」）

- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（まい）楽しみ
