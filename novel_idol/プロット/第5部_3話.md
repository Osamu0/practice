# 第5部 4人の家編 3話：なぎの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。なぎは〇〇にタメ口（呼び方は「〇〇さん」）。行為は `行為リスト.md` を参照。

ロケの前に、1人ずつそれぞれの家で（時系列は気にしすぎない）。〇〇は、なぎの家にもう何度も来ている。〇〇は調子に乗っている。

完堕ちしたなぎは、裏では口調が反転しきっている（照れない。甘く、ねっとりと、下品にとろける。べったり甘えて離れない。笑い方はとろけた「ふふ……♡」。自分からちんぽを褒める）。はしゃぐ方向にはしない。なぎらしさは何も残さない。ちんぽの前ではハードコアな台詞（一人称は「私」と「なぎ」、「おちんちん」「おちんぽ」「ちんぽ」を混ぜる）。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

**なぎの家**：洗練された、生活感の少ないモダンなデザイナーズマンション。モノトーンでまとめていて、余計なものがなく、おしゃれ。広いリビングに、キッチンカウンターと大きなソファ、形のきれいなデザイナーズチェア。リビングとは別に、広い寝室があり、大きなベッドがある。まいの家（眺めのいい高層）、ほのかの家（ナチュラルで上品）とは、また違う方向のいい家。本文では、家の説明はくどくしない（〇〇はもう見慣れている）。

## 場面1：冷蔵庫の中

- **流れ**：なぎから、甘いLINEが来る。〇〇が行くと、なぎはドアを開けた瞬間に〇〇に絡みついて、離れない。〇〇は勝手知ったる様子で冷蔵庫を開ける。余計なものがない冷蔵庫に、〇〇の好きな飲み物だけが、いつも切らさずに入っている。〇〇がそれに触れると、なぎは照れずに、背中から抱きついたまま甘く笑う
- **決め台詞**：なし（例：なぎ『今日、来て』『早く会いたい』／なぎ「……ふふ。〇〇さんのぶん、切らしたことないでしょ……♡」）
- **エロの中身**：なし
- **位置関係**：玄関 → キッチン
- **感情の流れ**：（なぎ）会えてうれしい。甘えて離れない （〇〇）表ではあんなにクールななぎちゃんが

## 場面2：ソファで、待ちきれずに

- **流れ**：〇〇がソファに座ると、なぎは〇〇の前にしゃがんでズボンを下ろす。ちんぽが出た瞬間に、甘えた顔からさらにとろけきった顔に切り替わる。顔に乗せて、匂いを嗅いで、「……今日も、なぎの顔よりおっきい……♡」と甘い声で褒める。それから、もう待てない。〇〇の前で脚を開いて、自分でいじり始める。下着をずらして、自分の指で広げて見せて、早く、とねだる。〇〇が指を入れると、なぎはすぐに腰を浮かせて、何度目かで潮を噴く
- **決め台詞**：なし（例：なぎ「……ね、はやく……っ」）
- **エロの中身**：なぎのオナニーを見せる → 自分で広げて見せるおねだり → 手マン（Gスポット）→ 潮吹き。喘ぎ声はレベル2〜3
- **位置関係**：ソファ。〇〇が座り、なぎが〇〇の正面でソファの端に浅く座って脚を開く → 〇〇がなぎの隣に移り、片手で脚を押さえて指を入れる
- **感情の流れ**：（なぎ）待てない → 見られたい → 噴いてしまう

## 場面3：キッチンカウンターで

- **流れ**：なぎをキッチンカウンターに座らせて、脚を開かせてクンニ。なぎは〇〇の頭を自分から押しつける。そのまま、カウンターに座らせたまま、〇〇が立って突く
- **決め台詞**：なし
- **エロの中身**：クンニ → カウンターに座らせての挿入（〇〇は立ったまま、正面から）。中出し。喘ぎ声はレベル3
- **位置関係**：なぎがキッチンカウンターに座り、〇〇が立って正面から（カウンターの高さが、ちょうど腰の高さ）
- **感情の流れ**：（なぎ）もっと → 崩れていく

## 場面4：デザイナーズチェアで

- **流れ**：なぎがカウンターから降りると、脚がふらつく。〇〇は、リビングのデザイナーズチェアに座り、なぎを背中から膝に乗せる。〇〇は後ろから乳首とクリを同時にいじる。なぎは自分から腰を沈めて、夢中で動かす。〇〇が「どこが気持ちいいの？」とわざと聞くと、なぎは甘くとろけた声で、全部言う
- **決め台詞**：なし
- **エロの中身**：背面座位。後ろから乳首とクリを同時に責められながら。なぎが自分から腰を動かす。喘ぎ声はレベル3〜4
- **位置関係**：リビングのデザイナーズチェア。〇〇が座り、なぎが〇〇に背中を預けて膝に跨がる（脚は〇〇の脚の外に開く）
- **感情の流れ**：（なぎ）気持ちいい → 止まらない

## 場面5：寝室のベッドで、激しく

- **流れ**：寝室の大きなベッドへ。なぎは、自分から言う。「ねえ、今日はなぎのこと、オナホみたいに使って」「〇〇さんが気持ちいいように、好きに動いて」（女の子の側から差し出すエスカレート）。なぎは、乱暴にしてほしいとねだる。〇〇は、なぎの両腕を後ろに引いて、膝立ちのまま後ろから激しく突く。なぎは、首を絞めてとねだる。〇〇は手加減せずに、なぎの首に手をかける。なぎは何度もイって崩れていく。最後は、うつ伏せに潰れたなぎを、〇〇はなぎのおねだりどおり、自分が気持ちいいようにだけ動いて使う（寝バックでの使い潰し）。なぎは使われるたびに、甘く下品な声で喜ぶ。抜いたあと、なぎがねだって、小さな顔に出す。顔じゅうが、〇〇のでいっぱいになる
- **決め台詞**：なし（例：なぎ「……もっと、乱暴にして」／なぎ「……首、しめて……っ♡」）
- **エロの中身**：両腕を後ろに引いてのバック（膝立ち）→ なぎがねだって、首絞め → なぎがねだって、寝バックでオナホみたいに使われる（〇〇が自分の気持ちいいようにだけ動く）→ 顔射。連続絶頂、抜かずの連続中出し。アヘ顔。喘ぎ声はレベル4。普段の口調が完全に崩れて、甘く、下品な言葉を叫ぶ
- **位置関係**：寝室のベッド。なぎが膝立ちで、〇〇がその後ろで膝立ちになり、なぎの両腕を後ろに引く → 〇〇が片手でなぎの首を後ろから押さえる → なぎがうつ伏せに崩れ、〇〇が上から重なる
- **感情の流れ**：（なぎ）使われたい → 乱暴にされたい → 崩れる → 使われるのがうれしい → なにも考えられない

始まりは、なぎのおねだり。ねだられたら、〇〇は手加減しない。意識が飛ぶ手前まで。

## 場面6：事後

- **流れ**：なぎは、顔と、自分の中から溢れてきた精液を指ですくって、舐める。寝室のベッドで、〇〇にもたれる。とろけたまま、甘い声でロケの話をする（「……沖縄、〇〇さんも来るんでしょ……？」「夜、なぎの番、長くしてね……♡」）。照れない
- **決め台詞**：なし
- **エロの中身**：精液を指ですくって舐める → 余韻
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（なぎ）満たされている → 甘えたまま → まだ欲しい
- **ねらい**：ロケ先の話への引き（軽く触れる程度）
