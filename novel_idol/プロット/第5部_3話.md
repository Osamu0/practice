# 第5部 3話：あおいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。あおいは〇〇にタメ口（呼び方は「〇〇さん」）。行為は `行為リスト.md` を参照。

ロケの前に、1人ずつそれぞれの家で。第4部から数か月が経っている。〇〇は、あおいの家にもう何度も来ている。この話では浴室は使わず（第3部6話で使ったため）、違う場所とプレイにする。

堕ちきったあおいは、〇〇の前では落ち着いた顔を保てない。玄関では照れ隠しを言えても、始まってしまえば、短く乾いた口調も気だるさも崩れて、甘く、下品に、自分から求める。クールなままにはしない。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

**あおいの家**：洗練された、生活感の少ないモダンなデザイナーズマンション。モノトーンでまとめていて、余計なものがなく、おしゃれ。広いリビングに、キッチンカウンターと大きなソファ、形のきれいなデザイナーズチェア。リビングとは別に、広い寝室があり、大きなベッドがある。まいの家（眺めのいい高層）、ゆのの家（ナチュラルで上品）とは、また違う方向のいい家。本文では、家の説明はくどくしない（〇〇はもう見慣れている）。

## 場面1：冷蔵庫の中

- **流れ**：あおいから、短くLINEが来る。〇〇が行くと、あおいはいつもの調子で迎える。〇〇は勝手知ったる様子で冷蔵庫を開ける。余計なものがない冷蔵庫に、〇〇の好きな飲み物だけが、いつも切らさずに入っている。〇〇がそれに触れると、あおいは目を逸らして、照れ隠しを言う
- **決め台詞**：なし（例：あおい『今日、来れる？』／あおい「……たまたま、あっただけ」）
- **エロの中身**：なし
- **位置関係**：玄関 → キッチン
- **感情の流れ**：（あおい）照れ隠し （〇〇）変わらない照れ隠しが、かわいい

## 場面2：ソファで、待ちきれずに

- **流れ**：〇〇がソファに座ると、あおいはもう待てない。〇〇の前で脚を開いて、自分でいじり始める。下着をずらして、自分の指で広げて見せて、早く、とねだる。〇〇が指を入れると、あおいはすぐに腰を浮かせて、何度目かで潮を噴く
- **決め台詞**：なし（例：あおい「……ね、はやく……っ」）
- **エロの中身**：あおいのオナニーを見せる → 自分で広げて見せるおねだり → 手マン（Gスポット）→ 潮吹き。喘ぎ声はレベル2〜3
- **位置関係**：ソファ。〇〇が座り、あおいが〇〇の正面でソファの端に浅く座って脚を開く → 〇〇があおいの隣に移り、片手で脚を押さえて指を入れる
- **感情の流れ**：（あおい）待てない → 見られたい → 噴いてしまう

## 場面3：キッチンカウンターで

- **流れ**：あおいをキッチンカウンターに座らせて、脚を開かせてクンニ。あおいは〇〇の頭を自分から押しつける。そのまま、カウンターに座らせたまま、〇〇が立って突く
- **決め台詞**：なし
- **エロの中身**：クンニ → カウンターに座らせての挿入（〇〇は立ったまま、正面から）。中出し。喘ぎ声はレベル3
- **位置関係**：あおいがキッチンカウンターに座り、〇〇が立って正面から（カウンターの高さが、ちょうど腰の高さ）
- **感情の流れ**：（あおい）もっと → 崩れていく

## 場面4：デザイナーズチェアで

- **流れ**：あおいがカウンターから降りると、脚がふらつく。〇〇は、リビングのデザイナーズチェアに座り、あおいを背中から膝に乗せる。〇〇は後ろから乳首とクリを同時にいじる。あおいは自分から腰を沈めて、夢中で動かす。普段の口調は、もうどこにもない
- **決め台詞**：なし
- **エロの中身**：背面座位。後ろから乳首とクリを同時に責められながら。あおいが自分から腰を動かす。喘ぎ声はレベル3〜4
- **位置関係**：リビングのデザイナーズチェア。〇〇が座り、あおいが〇〇に背中を預けて膝に跨がる（脚は〇〇の脚の外に開く）
- **感情の流れ**：（あおい）気持ちいい → 止まらない

## 場面5：寝室のベッドで、激しく

- **流れ**：寝室の大きなベッドへ。あおいは、乱暴にしてほしいとねだる。〇〇は、あおいの両腕を後ろに引いて、膝立ちのまま後ろから激しく突く。あおいは、首を絞めてとねだる。〇〇は手加減せずに、あおいの首に手をかける。あおいは何度もイって崩れていく。最後は、うつ伏せに潰れたあおいに、上から何度も
- **決め台詞**：なし（例：あおい「……もっと、乱暴にして」／あおい「……首、しめて……っ♡」）
- **エロの中身**：両腕を後ろに引いてのバック（膝立ち）→ あおいがねだって、首絞め → 寝バック。連続絶頂、抜かずの連続中出し。アヘ顔。喘ぎ声はレベル4。普段の口調が完全に崩れて、甘く、下品な言葉を叫ぶ
- **位置関係**：寝室のベッド。あおいが膝立ちで、〇〇がその後ろで膝立ちになり、あおいの両腕を後ろに引く → 〇〇が片手であおいの首を後ろから押さえる → あおいがうつ伏せに崩れ、〇〇が上から重なる
- **感情の流れ**：（あおい）乱暴にされたい → 崩れる → なにも考えられない

始まりは、あおいのおねだり。ねだられたら、〇〇は手加減しない。意識が飛ぶ手前まで。

## 場面6：事後

- **流れ**：あおいは、自分の中から溢れてきた精液を指ですくって、舐める。寝室のベッドで、〇〇にもたれる。少しずつ、いつもの口調が戻ってくる。ロケの話に少し触れる。さっきまでの自分が恥ずかしくて、照れ隠しの一言を、斜めから
- **決め台詞**：なし
- **エロの中身**：精液を指ですくって舐める → 余韻
- **位置関係**：ベッドで寄り添う
- **感情の流れ**：（あおい）満たされている → いつもの自分に戻りかけて、照れる
- **ねらい**：ロケ先の話への引き（軽く触れる程度）
