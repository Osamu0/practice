# 第5部 4人の家編 4話：めいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。行為は `行為リスト.md` を参照。

ロケの前に、1人ずつそれぞれの家で。第4部から数か月が経っている。めいが加わってからも何か月も経っていて、〇〇はめいの家にもう何度も来ている。めいは、最初のころの戸惑いはもうない。第5部は、この話で終わる。

堕ちきっためいは、〇〇の前では、甘えん坊がねだりっぱなしになる。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

**めいの家**：明るくて可愛い、おしゃれなマンション。白とパステルカラーでまとめている。広いリビングに、ふかふかのソファとラグ。明るいバスルーム。寝室には、クッションがたくさん並んだ大きなベッド。若い子らしい華やかさがありつつ、散らかってはいない。4人の家は、まい（眺めのいい高層）、ゆの（ナチュラルで上品）、あおい（モノトーンでモダン）、めい（明るくて可愛い）と分かれる。本文では、家の説明はくどくしない（〇〇はもう見慣れている）。

- **決め台詞**：なし

- **感情の流れ**：（めい）会えてうれしい （〇〇）いつもの出迎え

## 場面2：ソファで、乳首から

- **流れ**：ソファで、めいが〇〇にくっついて、自分から服をめくり、胸を吸ってとねだる。〇〇が乳首を舐めて、吸って、もう片方をつまむ。めいは、乳首だけでイってしまう。そのあと、めいはラグに降りて、胸で〇〇を挟み、先を咥える。最後は、顔と胸に出される。めいは、顔についた精液を指ですくって、自分で舐め取る
- **決め台詞**：なし
- **エロの中身**：乳首責め（舐め、吸い、つまみ）→ 乳首イキ → パイズリフェラ → 顔と胸に射精 → 顔の精液を自分で舐め取る。喘ぎ声はレベル2〜3
- **位置関係**：ソファ。〇〇が座り、めいが〇〇の膝に横向きに座って胸を差し出す → 〇〇がソファに座ったまま、めいがラグに膝をつく
- **感情の流れ**：（めい）吸ってほしい → イっちゃった → もっと喜ばせたい

## 場面3：バスルームで、泡で

- **流れ**：顔も胸もべとべとになったまま、めいが〇〇の手を引いてバスルームへ。シャワーで洗い流したあと、めいはボディソープを胸に泡立てて、胸で〇〇の身体を洗う。泡まみれのまま、〇〇のモノを太もものあいだと割れ目で挟んで、前後に滑らせる。そのまま、めいがねだって、立ったままつながる
- **決め台詞**：なし
- **エロの中身**：泡で胸を使っての洗い → 泡の素股 → 立ったまま、向かい合って、めいの片脚を抱えての挿入。泡で滑る。中出し。喘ぎ声はレベル3。バスルームなので声が響く
- **位置関係**：明るいバスルーム。めいが〇〇に向かい合い、胸を押しつけて洗う → めいが〇〇に背中を向けて、太ももで挟む → めいが壁に背中を預け、〇〇が正面から、めいの片脚を抱える
- **感情の流れ**：（めい）洗ってあげたい → 自分も欲しくなる → 入れてほしい

## 場面4：寝室への廊下で、駅弁

- **流れ**：バスルームを出て、濡れたままのめいが〇〇に抱きつく。〇〇は、小柄なめいを抱き上げて、つながったまま寝室へ向かう。めいは〇〇の首にしがみついて、離れない。廊下の途中で、何度も揺すり上げられる

- **位置関係**：寝室への廊下。〇〇が立ってめいを抱え上げ、めいは〇〇の首に腕を回し、脚を〇〇の腰に絡める
