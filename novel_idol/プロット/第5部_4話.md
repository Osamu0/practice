# 第5部 4話：めいの家

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> LINEのメッセージは、本文では『』で書く。めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。

ロケの前に、1人ずつそれぞれの家で。第4部から数か月が経っている。めいが加わってからも何か月も経っていて、〇〇はめいの家にもう何度も来ている。めいは、最初のころの戸惑いはもうなく、甘えるのも求めるのも、すっかり自然になっている。第5部の家の話は、この話で終わる。

骨組みは4話そろえる（`アウトライン.md` の第5部を参照）。

**めいの家**：明るくて可愛い、おしゃれなマンション。白とパステルカラーでまとめている。広いリビングに、ふかふかのソファとラグ。明るいバスルーム。寝室には、クッションがたくさん並んだ大きなベッド。若い子らしい華やかさがありつつ、散らかってはいない。4人の家は、まい（眺めのいい高層）、ゆの（ナチュラルで上品）、あおい（モノトーンでモダン）、めい（明るくて可愛い）と分かれる。本文では、家の説明はくどくしない（〇〇はもう見慣れている）。

- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：玄関 → リビング
- **感情の流れ**：（めい）会えてうれしい （〇〇）いつもの出迎え

## 場面2：ソファで、甘やかす → パイズリ

- **流れ**：ソファで、めいが〇〇に甘えてくっつく。〇〇はめいの胸に顔をうずめて、吸う。めいは、年下なのに〇〇を甘やかすように、胸を吸わせながら手で〇〇をしごく。そのあと、めいがラグに降りて、胸で〇〇を挟む。挟みながら、先を咥える。最後は、胸と顔に出される
- **決め台詞**：なし
- **エロの中身**：乳首責め、胸を吸わせながらの手コキ → パイズリ → パイズリしながらのフェラ → 胸と顔に射精。喘ぎ声はレベル2〜3
- **位置関係**：ソファ。めいが座り、〇〇がめいの膝に頭を乗せて横になる → 〇〇がソファに座り、めいがラグに膝をつく
- **感情の流れ**：（めい）甘えたい → 甘やかしたい → もっと喜ばせたい

## 場面3：バスルームで、泡で

- **流れ**：顔も胸もべとべとになったまま、めいが〇〇の手を引いてバスルームへ。シャワーで洗い流したあと、めいはボディソープを胸に泡立てて、胸で〇〇の身体を洗う。泡まみれで、そのまま立ったままつながる
- **決め台詞**：なし
- **エロの中身**：泡で胸を使っての洗い → 立ったまま、向かい合って、めいの片脚を抱えての挿入。泡で滑る。中出し。喘ぎ声はレベル3。バスルームなので声が響く
- **位置関係**：明るいバスルーム。めいが〇〇に向かい合い、胸を押しつけて洗う → めいが壁に背中を預け、〇〇が正面から、めいの片脚を抱える
- **感情の流れ**：（めい）洗ってあげたい → 自分も欲しくなる

## 場面4：寝室への廊下で、駅弁

- **流れ**：バスルームを出て、濡れたままのめいが〇〇に抱きつく。〇〇は、小柄なめいを抱き上げて、つながったまま寝室へ向かう。めいは〇〇の首にしがみついて、離れない。廊下の途中で、何度も揺すり上げられる

- **感情の流れ**：（めい）しがみついていたい → 甘えたまま、イく

- **感情の流れ**：（めい）気持ちいい → 甘えたい → もう、なんも考えられん
