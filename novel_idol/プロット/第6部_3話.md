# 第6部 ロケ編 3話：ロケ2日目の昼、あちこちで

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ほのか・なぎ・めいの話し方は、`企画メモ.md` と口調サンプルを参照。行為は `行為リスト.md` を参照。

ロケ2日目の昼。水着ではなく、本島のあちこちを回るロケ。4人は、番組が用意した夏らしいワンピースや私服のロケ衣装。〇〇は、観光客として、レンタカーで同じ場所を回る。

場所ごとに、スタッフにバレそうになる。詳しく見せるのは、ほのか（集落）、めい（アメリカンビレッジ）、なぎ（サンセットビーチ）の3人。まいは、ほかの子をかばう役で出る（まいは1日目の夜と、4話で詳しく見せる）。

野外は少しだけ。本格的な露出・野外は、第8部（アブノーマル）に取っておく。実在の場所は、ロケの舞台として出すだけにして、行為の場所は、その中の人目につかない架空の一角にする。

## 場面1：午前、集落の古民家で、ほのか

- **流れ**：午前は、古い集落を歩く体験ロケ。休憩所として、集落の古民家を借りている。表の座敷ではスタッフが休憩している。その奥の、使われていない裏の部屋。〇〇は、庭の裏手から縁側を回って入る。先に休憩に入ったほのかが、そっと来る。声が出せないので、ほのかは自分のハンカチを噛んで、声を殺す。途中で、襖の向こうからスタッフが「ほのちゃん、そこにいる？」と声をかける。ほのかは、つながったまま、ハンカチを口から外して、いつもの控えめな声で「……はい、ちょっと、休んでます」と答える。〇〇は動きを止めない
- **決め台詞**：なし（例：ほのか「……はい、ちょっと、休んでます……」）
- **エロの中身**：ワンピースをたくし上げて、下着だけ脱ぐ → 畳にうつ伏せで、脚を閉じたままの寝バック。ハンカチを噛んで声を殺す。スタッフに答える声が、震えそうになる。中出し。喘ぎ声はレベル2〜3（くぐもった声）
- **位置関係**：古民家の裏の部屋。薄暗い畳の部屋。ほのかが畳にうつ伏せになり、脚を閉じたまま、〇〇が上から重なる。襖一枚向こうが、スタッフのいる座敷
- **感情の流れ**：（ほのか）見つかったらあかん → 声をかけられて、心臓が止まりそう → それでも、とまらへん

## 場面2：昼、アメリカンビレッジで、めい

- **流れ**：昼は、美浜アメリカンビレッジで、街歩きと食べ歩きのロケ。番組は、ある店の奥のバックヤードを、休憩と着替えの場所として借りている。〇〇は、観光客にまぎれて、裏の搬入口から入る。休憩に来ためいが、段ボールの積まれた奥で〇〇に抱きつく。立ったまま、ワンピースの裾を自分で咥えて、たくし上げる。そこへ、店のスタッフが在庫を取りに入ってくる。〇〇はめいを抱えたまま、棚の陰で息を殺す。めいは、つながったまま、裾を咥えて声をこらえる。足音が遠ざかると、めいのほうが我慢できずに腰を動かす
- **決め台詞**：なし
- **エロの中身**：立ったまま、向かい合って、めいの片脚を抱えての挿入。めいはワンピースの裾を咥えて、声を殺す。裾を咥えているので、胸元まで丸見え。人が入ってきて、つながったまま動きを止める → 出ていったあと、めいが自分から腰を振る。中出し。喘ぎ声はレベル2〜3（くぐもった声）。最後に、めいが膝をついて、短くお掃除フェラ
- **位置関係**：店の奥のバックヤード。段ボールの積まれた棚のあいだ。めいが棚に背中を預けて立ち、〇〇が正面から、めいの片脚を抱える。入口からは、棚の陰になって見えない
- **感情の流れ**：（めい）時間がない → 人が来た、いかん → 行った……もう、我慢できん

## 場面3：まいがかばう

- **流れ**：めいが戻るのが遅れる。ディレクターが「めいちゃんは？」と探し始める。まいが、表の顔の笑顔で「さっき、お手洗い行くって言ってましたよ」と答えて時間をかせぐ。めいが、少し髪を乱して戻ってくる。まいは、めいの髪をさりげなく直してやり、耳元で小さく「……あとで、聞かせてね」とささやく
- **決め台詞**：なし（例：まい「さっき、お手洗い行くって言ってましたよ」）
- **エロの中身**：なし。まいの心の声で、めいの乱れた髪に、何があったか察して疼く
- **位置関係**：アメリカンビレッジの通り。撮影クルーと4人
- **感情の流れ**：（まい）表の顔でかばう → 内心は、うらやましい

## 場面4：夕方、サンセットビーチで、なぎ

- **流れ**：夕方は、サンセットビーチで、夕日を待って4人で撮影。日が沈むまでの待ち時間、なぎが「ちょっと歩いてくる」と一人で離れる。ビーチの端の、人の来ない岩場の陰で、〇〇が待っている。時間がないので、なぎはしゃがんで、〇〇のモノを咥える。途中で、ADがなぎの名前を呼びながら、こちらに歩いてくる。なぎは咥えたまま動きを止める。〇〇も息を止める。足音が遠ざかると、なぎは深く咥えて、最後まで受け止めて飲む。口元をぬぐって、いつもの顔で撮影に戻る
- **決め台詞**：なし（例：AD「なぎさーん、そろそろでーす」）
- **エロの中身**：フェラ（立ったままの〇〇に、なぎがしゃがんで）。人が近づいて、咥えたまま止まる → 遠ざかったあと、深く → 口内射精、ごっくん
- **位置関係**：サンセットビーチの端の岩場の陰。〇〇が岩に背中を預けて立ち、なぎがしゃがむ。夕日の方向には撮影クルー
- **感情の流れ**：（なぎ）待ちきれない → 呼ばれて、息が止まる → それでも、最後まで
