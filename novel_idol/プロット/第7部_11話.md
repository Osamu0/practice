# 第7部 お酒でベロベロ編 11話：朝

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> 別荘の設定、線、4人の酔い方は `第7部_1話.md` を参照。行為は `行為リスト.md` を参照。

次の朝。二日酔い → しらふに戻る → それでも、もう1回 → 帰る。第7部の締め。4人とも完堕ちしているので、昨夜のことを恥ずかしがらない。すっきりした顔で、笑い話と猥談にする。

## 場面1：二日酔いの朝

- **流れ**：昼前、5人は寝室で目を覚ます。4人とも二日酔い。頭が痛い、のどが渇いた、と言い合いながら、〇〇が持ってきた水を回し飲みする。お互いの髪の乱れや、メイクの崩れた顔を見て、笑う
- **決め台詞**：なし
- **エロの中身**：なし
- **位置関係**：寝室の大きなベッド
- **感情の流れ**：（5人）だるい → 笑ってしまう

## 場面2：散らかったリビング

- **流れ**：リビングに降りると、空き瓶と缶、脱ぎ散らかした服、くじの割り箸、止まったままのゲーム画面、ラグの染み。4人は、昨夜を少しずつ思い出しながら、恥ずかしがるより笑い出す。誰が何を言ったか、何をしたか、記憶をすり合わせるうちに、そのまま猥談になる。まいはラグの染みを指さして「これ、まいのだ」と笑い、ほのかはマイクでの実況を「全部スピーカーから聞こえてたで」とからかわれて「ほの、あんなこと言うてた？」と笑い、なぎは「……ここに、注いで、って言ったの、なぎ？　ふふ……♡」ととろけたまま笑い、めいは「わたし、みんなにキスしてました？」と聞いて、全員に「してた」と言われる。そこから、昨夜いちばん気持ちよかったのは何か、誰が何回出されたかを言い合う。〇〇は、王様ゲームの自分の命令を4人にまねされて、からかわれる
- **決め台詞**：なし（例：ほのか「全部、スピーカーから聞こえてたで」）
- **エロの中身**：なし。昨夜の記憶を、笑い話と猥談で（会話の中で、断片的に）
- **位置関係**：リビング
- **感情の流れ**：（5人）すっきりしている → 笑える → 楽しかった → また来たい

## 場面3：酔いが抜けて、朝の露天風呂

- **流れ**：水を飲んで、少し休んで、酔いが抜けてから、5人で露天風呂に入る。明るい森の中。しらふに戻った4人は、照れずに、すっきりした顔で〇〇に寄り添う。昨夜のベロベロとは違う、明るい朝の、しらふの欲しがり方。湯船で、1人ずつ、〇〇の膝の上に乗る
- **決め台詞**：なし
- **エロの中身**：湯船での対面座位を、1人ずつ順番に。しらふの、甘く、ゆっくりした形。ほかの3人は、寄り添って待つ。中出し。喘ぎ声はレベル2〜3（明るい朝の、しらふの声）
- **位置関係**：露天風呂。〇〇が湯船に座り、4人が順番に向かい合って跨がる
- **感情の流れ**：（4人）すっきりした → しらふでも、やっぱり欲しい

## 場面4：片付けて、帰る

- **流れ**：5人で、別荘を片付ける。ラグの染みを必死に拭くまい、瓶を分別するほのか、黙々と食器を洗うなぎ、ゴミ袋を抱えてうろうろするめい。チェックアウトして、車に乗る。走り出してすぐ、後部座席の3人が寝てしまう。助手席のまいも、〇〇の横で、うとうとしながら「また来ようね」と言う
- **決め台詞**：なし（例：まい「……また、来ようね」）
- **エロの中身**：なし
- **位置関係**：別荘 → 帰りの車
- **感情の流れ**：（5人）楽しかった、また （〇〇）バックミラーに映る、眠る3人
- **ねらい**：第7部の締め
