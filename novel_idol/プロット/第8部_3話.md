# 第8部 アブノーマル編 3話：まいの、初めてのアナル

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ホテルの設定と線は `第8部_1話.md` を参照。行為は `行為リスト.md` を参照。

まいのアナル。入り方は、アナルプラグを入れたまま仕事 → そのあとホテルで、初めてのアナル。

## 場面1：プラグをつけてほしい

- **流れ**：雑誌の撮影の前日、まいが〇〇に、アナルプラグを入れたまま撮影に行きたい、とねだる。前の晩、〇〇の部屋で、ローションをたっぷり使って、指で少しずつ慣らしてから、小さなプラグを入れる。まいは、初めての感覚に、甘えた声で泣きそうになる
- **決め台詞**：なし
- **エロの中身**：アナル舐め → ローションで指を1本、2本 → 小さなアナルプラグを入れる。喘ぎ声はレベル2〜3
- **位置関係**：〇〇の部屋のベッド。まいが四つん這い、〇〇が後ろから
- **感情の流れ**：（まい）こわい → 〇〇くんなら → 変な感じ → 気持ちいいかも

## 場面2：プラグをつけたまま、撮影

- **流れ**：次の日、雑誌の撮影。まいは、プラグを入れたまま、カメラの前で笑う。座るたびに、ポーズを変えるたびに、お尻の中のプラグを感じる。心の声だけが乱れていく
- **決め台詞**：なし
- **エロの中身**：プラグを入れたまま、表の笑顔で撮影。心の声
- **位置関係**：撮影スタジオ。カメラの前のまい
- **感情の流れ**：（まい）表の笑顔 → お尻のことしか考えられない

## 場面3：ホテルで、初めてのアナル

- **流れ**：撮影が終わって、ホテルへ。まいは、プラグを抜いてもらって、そのまま、〇〇のを入れてほしい、とねだる。ローションをたっぷり使って、ゆっくり、少しずつ。まいは、〇〇にしがみついて、甘えた声で泣きそうになりながら、全部受け入れる
- **決め台詞**：なし（例：まい「……お尻も、〇〇くんの、だよ……」）
- **エロの中身**：プラグを抜く → ローション → 正常位でアナルセックス（顔を見ながら、ゆっくり）→ 慣れてきたら、だんだん深く。前は〇〇の指で。アナル中出し。喘ぎ声はレベル3〜4。初めての感覚に、まいの声が今までと違う崩れ方をする
- **位置関係**：ホテルのベッド。まいが仰向けで、腰の下に枕を入れて、脚を抱える。〇〇が正面から
- **感情の流れ**：（まい）こわい → 〇〇くんの顔を見ていたい → 全部、〇〇くんのものになった
