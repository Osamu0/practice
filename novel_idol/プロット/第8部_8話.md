# 第8部 アブノーマル編 8話：診察台で、めい

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> プロットの形は `アウトライン.md` の「プロットの形」を参照。決め台詞以外の台詞は、本文で自由に書く。
> ホテルの設定と線は `第8部_1話.md` を参照。めいの話し方は、標準語に、気が緩んだときや感情が出たときだけ博多弁が少し混ざる形にする。行為は `行為リスト.md` を参照。

めいの「やってみたいこと」。ぜんぶ。診察台のある部屋で、お医者さんごっこ。道具を1つずつ、初めて試していく。最後は、ビーズから、初めてのアナル。

## 場面1：お医者さんごっこ

- **流れ**：診察台のある部屋に、めいと〇〇。めいが、部屋にあった白衣を〇〇に着せて、「先生、診てください」とねだる。めいは、診察台に乗って、脚を台に乗せる。脚が開いたまま、閉じられない
- **決め台詞**：なし（例：めい「……先生、診てください」）
- **エロの中身**：お医者さんごっこ。診察台で脚を開く
- **位置関係**：診察台。めいが仰向けで、脚を台に乗せて開く。〇〇が白衣で、脚のあいだに
- **感情の流れ**：（めい）恥ずかしい → でも、やってみたい

## 場面2：道具を、1つずつ

- **流れ**：「先生」の〇〇が、道具を1つずつ試していく。吸引玩具をクリに。乳首クリップをFカップの乳首に。バイブを中に。めいは、どれも初めてで、反応が全部素直。驚いて、声を上げて、博多弁で「なんこれ……っ」と言いながら、何度もイく
- **決め台詞**：なし
- **エロの中身**：吸引玩具（クリ）、乳首クリップ、バイブ。どれも初めて。連続絶頂。喘ぎ声はレベル3〜4。博多弁
- **位置関係**：診察台。〇〇が道具を持って
- **感情の流れ**：（めい）なんこれ → 気持ちいい → 次は

## 場面3：ビーズから

- **流れ**：最後に、〇〇がアナルビーズを見せる。めいは、少しこわがって、でも「やってみます」と言う。ローションをたっぷり使って、1粒ずつ入れていく。全部入ったら、1粒ずつ引き抜く。抜けるたびに、めいは驚いて声を上げる
- **決め台詞**：なし（例：めい「……やってみます」）
- **エロの中身**：アナル舐め → ローション → アナルビーズを1粒ずつ入れる → 1粒ずつ引き抜く。喘ぎ声はレベル3。素直な驚き
- **位置関係**：診察台。めいが脚を開いたまま
- **感情の流れ**：（めい）こわい → 変な感じ → 抜けるとき、気持ちいい

## 場面4：初めての、お尻

- **流れ**：ビーズで慣れたあと、めいが「……〇〇さんの、入れてみたい」とねだる。診察台から降りて、ベッドで。ゆっくり、少しずつ。めいは、〇〇の手を握って、素直に驚きながら、全部受け入れる
- **決め台詞**：なし
- **エロの中身**：ローション → 側位でアナルセックス（後ろから抱きしめられて、ゆっくり）→ 慣れてきたら正常位で、乳首を吸われながら。アナル中出し。喘ぎ声はレベル3〜4。博多弁がこぼれる
- **位置関係**：ホテルのベッド。2人とも横向きに寝て、〇〇が後ろから → めいが仰向けで、〇〇が正面から
- **感情の流れ**：（めい）こわい → 〇〇さんの手 → 気持ちよか → ぜんぶ、知れた
