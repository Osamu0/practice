# 企画メモ

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。実在のグループやメンバーの名前・特徴は使いません。

## 決まったこと

| 項目 | 内容 |
|---|---|
| イメージ | 国民的アイドルグループのメンバーが快楽に堕ちていく |
| 方針 | エロ100％。難しいことを考えずに読める作品。作る側も難しく考えすぎない |
| 読者の体験 | 男の夢が叶う感じ |
| ヒロイン | 4人（グループのメンバー） |
| 相手役 | ファン（1人） |
| 堕ち方 | 4人それぞれで変える |
| 分量 | 長編・連載 |
