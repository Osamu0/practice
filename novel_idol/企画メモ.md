## 書き方のルール（作品全体）

- 設定は書くための土台であって、本文で毎回描写するものではない。外見などの設定を、場面ごとに繰り返し拾って強調しない
- 「（笑）」は本文のセリフに入れない。笑っていることは、地の文や「あはは」などの声で表す

**体勢・位置関係**
- 物理的に無理な体勢にしない。複数人のときは特に、一人の手や口が同時に二か所にある、のような矛盾を出さない
- 位置関係はプロットで決めておき、本文では説明しない。動作、身体の感覚、台詞の中で、自然に伝わるようにする
  - ✕「〇〇はなぎの背後に膝立ちになり、まいはなぎの右側、ほのかは左側に座っている。」
  - ○「後ろから腰を掴まれた瞬間、両側からまいとほのかの手が伸びてきて、なぎの胸を包んだ。」
- 読者が想像するのに必要なことだけを書く。状況説明のような文にしない
- 台詞を見ればわかることを、地の文で言い直さない（✕ ほのか「さわって、いい……？」のあとに「丁寧語が、抜けていた。」）

**臨場感・感情**
- 何が起きているかより先に、どう感じているかが伝わるように書く
- 行為の中に、その子の感情（恥ずかしさ、気持ちよさ、戸惑い、求める気持ちなど）を乗せる

**台詞・言葉**
- 言い回しを自然にする。その子の口調サンプルや注意点に照らして、その子が言いそうにない言い方をさせない
- 言葉の使い方を正しくする。意味のずれた言葉や、不自然な組み合わせを使わない
- 淫語や卑語も、その場面とその子の状態に合ったものを選ぶ

**書いたあとの確認**
- 体勢の矛盾、状況説明になっている文、感情の乗っていない場面、言い回しの不自然さ、言葉の誤用がないかを見直してから出す

### 擬音（行為音）のルール

行為音も、喘ぎ声と同じように表記で激しさがわかるようにする。

**抽送（ピストン）の音**
| 段階 | 例 | 表記の工夫 |
|---|---|---|
| ゆっくり | ぬちゅ……　ぬぷ…… | ひらがな。「……」で間を空ける |
| ふつう | ずちゅっ、ずちゅっ | ひらがな＋促音「っ」 |
| 激しい | パンッ、パンッ、パンッ | カタカナにして、強く硬くする |
| もっと激しい | ばちゅっばちゅっばちゅんっ | 濁点を増やし、読点を消してつなげる |
| 限界・連打 | ﾊﾟﾝﾊﾟﾝﾊﾟﾝﾊﾟﾝﾊﾟﾝｯ | 半角カナで、細かく速い連打 |

**水音（濡れ具合）**
| 段階 | 例 | 表記の工夫 |
|---|---|---|
| 濡れ始め | くちゅ…… | 小さく短い |
| 濡れている | ぐちゅっ、ぬちゅっ | 濁点で粘りを出す |
| ぐしょぐしょ | ぐぢゅっぐぢゅぢゅっ | 小書き文字を増やして、音を細かく砕く |
| 泡立つほど | ぶちゅっ、ぐぽっ、ぢゅぽぽっ | 空気を含んだ音を混ぜる |

**挿入**
| 段階 | 例 | 表記の工夫 |
|---|---|---|
| ゆっくり沈める | ずぷ……ずぷぷ…… | 「……」で、じわじわ入る感じ |
| 一気に奥まで | ずぶぶぶっ！　ごりゅっ | 小書き文字を重ねて、！で衝撃 |
| 長いストローク | ずりゅぅ〜っ | 長音・波線で、引き抜く長さを出す |

**射精**
| 段階 | 例 | 表記の工夫 |
|---|---|---|
| ふつう | びゅるっ、びゅくっ | ひらがな |
| 大量・勢いがある | びゅるるるっ！　ドピュッ、ドプッ | 小書き文字を重ねる、カタカナ |
| 止まらない | ﾋﾞｭﾙﾙｯ、ﾋﾞｭｸﾋﾞｭｸｯ、どぷっ……どぷ…… | 半角で勢い、最後はひらがなと「……」で余韻 |

**長さ**
- 抽送、水音、フェラの音、電マの振動、射精のように、続いている行為の音は長めに書く（1行に5〜10音くらいを連ねる。途中で強い音を混ぜたり、表記を崩したりして変化をつける。例：ずちゅっ、ずちゅっ、ずちゅっ、ずちゅっ、ずちゅんっ）
- キスの一回、びくんっ、ぷしゃっ、のような単発の音は短いままでいい

**組み立て方**
- 同じ場面の中で段階を上げていく（ふつう → 激しい → 連打、のように、行為が激しくなるのに合わせて表記も変える）
- 1行の詰め方でも速さを出す（ゆっくりのときは1行に1音、激しいときは1行に音を詰める）
- 喘ぎ声と揃える（喘ぎ声が半角カナになるところでは、行為音も半角にすると、全体の速さが揃う）

## 没入とエロさを上げる書き方

> 本文を書くときに使う手法。全部を毎話入れるのではなく、その話に合うものを選ぶ。

**描かれない回（話と話のあいだ）**
- 本文に書く夜だけが、会った夜ではない。話と話のあいだに書かれない回を置き、本文ではそれを匂わせる（例：「あれから、週に二回は来るようになった」）
- 匂わせ方：慣れた動き（どこを触れば感じるか知っている、目が合っただけで体位が変わる）、二人だけの決まりごと（来たら玄関でまずキス、など）、部屋に増えていく物（歯ブラシ、ヘアゴム、部屋着、メイク落とし）、前の回の話（「この前の、あれ」）
- 効果：堕ちたあとの子が、最初から遠慮なく求められる。初めての話ばかりにならない
- 第2部以降も同じ。新しい子の話を書いているあいだも、ほかの子との回は続いている
- 決めた回数、習慣、置いていった物は `本文/これまでの本文メモ.md` に書く

**五感と生々しさ**
- におい（汗、シャンプー、精液、部屋のにおい）、味、温度、湿り気、音（ベッドのきしみ、エアコン、外の車）を、要所で一つずつ入れる。並べて説明しない
- 身体の生々しい反応：汗で髪が額に貼りつく、太ももが震える、垂れてくるもの、シーツの濡れ、肌に残る指の跡

**現実の小さなこと**
- 体位を変えるときに抜けて、慌てて入れ直す。髪が口に入る。汗で滑る。思わず二人で笑う
- 事後：ティッシュ、シャワー、シーツの染み、腰が立たない、声がかすれる、喉が渇いて水を回し飲みする
- 萎えない程度に。一話に一つか二つまで

**バレるかもしれない緊張**
- 壁の薄さ、隣の住人、共用廊下の足音、スマホの着信（マネージャーなど）、翌朝の入り時間
- 声を抑えようとする（手で口をふさぐ、枕に顔を押しつける）→ 抑えきれない

**表の顔とのつながり**
- 翌日の仕事場に残るもの：声のかすれ、歩き方、ふとした瞬間に思い出して赤くなる、メンバーやスタッフの何気ない一言
- キスマークは見えるところにつけない（アイドルなので）。そのやりとり自体を会話にする

**日常と地続きにする**
- 普通の会話（仕事の話、ご飯、テレビ）の途中で手が伸びる。ご飯を食べながら、テレビを見ながら、始まってしまう

**女の子の目線**
- 女の子が男の身体に向ける目（腕、首筋、におい、ちんこの形）も描く。求められている実感が、男にも読者にも返ってくる

**残り香**
- 帰ったあとの部屋（枕のにおい、置いていったヘアゴム、シーツの跡）、LINEで送られてくる写真

| 慣れと実感 | 慣れていくのは、口調・遠慮・動き方（敬語 → タメ口、おそるおそる → 欲望のままに）。「トップアイドルを抱いている」という実感は、慣れても消さない。興奮の中身が「信じられない、夢みたい」から「この子たちは俺だけのもの」、さらに「もっと汚したい」「全部、俺の好きにしたい」へ変わっていく（所有感）。心の声でこの実感を毎話どこかに必ず入れる。ただし毎場面ではなく、効くところに絞る（くどくしない） |
| 実感が戻るきっかけ | 表の顔を見たとき。テレビやステージで何万人に笑っている姿、握手会の列でほかのファンが噂している声、ステージ衣装・写真集・雑誌の表紙、4人がそろった顔ぶれ、など。そのあとに自分の前で崩れる顔を見て、興奮が引き戻される |
| 口調の決まり方 | 時期（何部か）ではなく、相手の子との距離と、その子の堕ち具合で決まる。初対面・まだ距離がある子には敬語。行為をするようになった、堕ちかけ〜堕ちた直後の子には、敬語とタメ口が混じる。完堕ちしている子にはタメ口で、調子に乗るのもこの子たちが相手のとき。同じ場面でも、完堕ちしたまいにはタメ口で調子に乗り、来たばかりのなぎには敬語、ということが起きる。表の顔を見るたびに興奮が戻るのは、どの段階でも同じ |
| タメ口の決まり | オラオラ系にしない。見下さない、罵らない（✕「お前」「この淫乱が」。名前で呼ぶ）。言葉で支配しない。言い方は、お願いや願望の形（「……して、くれる？」「〇〇してほしいな」）から、完堕ちした子が相手になると、短い「〜て」の形まで崩れていい（○「口、開けて」「もっと腰振って」「言って」「こっち向いて」「舌、出して」「奥に出すよ」）。「〜しろ」「〜れ」の命令形は使わない（✕「しゃぶれ」「脚開け」）。「〜て」の形なら、声を荒げていない感じが残る。ここをオラオラ系との境目にする。まだ堕ちきっていない子が相手のときは、余裕がなくて素直にこぼれる言い方にする。乱暴にねだられたら、夢中で応える（例：「まいっ、まい……っ」「止めないから……っ」）。例外は第7部の王様ゲームで王様になったときだけ（ゲームのルールとして命令する） |
| 調子に乗る | 完堕ちした子が相手のとき。怖くなる、乱暴になる方向ではなく、得意げで、欲張りで、意地悪になる方向。得意げになる（「俺のちんぽ、そんなにいい？」「さっきから、ずっと見てるよね」）。わかっているのに、わざと聞く・言わせる（「どこが気持ちいいの？」「ちゃんと言って」「誰のちんぽが欲しいの？」）。焦らす（「まだだめ」「先っぽだけね」）。欲張る（一回で終わらない、全員に、全部の穴に）。完堕ちした子は、調子に乗った〇〇をあしらわず、喜んで乗る。あしらったりツッコんだりするのは、まだ完堕ちしていない子だけ（例：「……なにその顔。ドヤってんの？」）。新しい子がまだツッコむのに、隣の完堕ちした先輩たちは喜んで従っている、という差で、先輩たちが完堕ちしていることを伝える |
| 煽る言葉 | あり。罵るのではなく、事実を突きつける形。表と裏の落差を、〇〇が言葉にして女の子に見せつける（「さっきテレビで笑ってたのに、こんな顔して」「ファンが見たらどう思うかな」「ちんぽ見ただけで、もうこんなに濡れてる」）。女の子は、それでさらに崩れる |
| 台詞の例 | 敬語の時期：「すご……柔らか……あ、すみません、つい」「さ、触っても、いいですか」「まいまいの中、やばいです……すごい、締まって……」「行きます、絶対行きます」。タメ口になりはじめ：「まい、かわいい」「ごめん、止まんない」「俺も、ずっと会いたかった」。慣れたあと：「まい、気持ちいい？」「まいのおまんこ、めっちゃ締まってる……」「おっぱい、触っていい？」「入れたい。今すぐ」「出る、中に出すよ」「かわいい。もっと見せて」「口で、してほしいな」。完堕ちした子が相手：「口、開けて」「舌、出して」「ちゃんと言って。どこに欲しいの？」「さっきテレビで笑ってたのに、こんな顔して」「まだだめ。先っぽだけね」「全員、中に出すからね」。心の声の例：〇〇（え、今、名前呼ばれた？　マジで？）〇〇（やば……まいまいのおっぱいだ。写真集で何回も見たやつ）〇〇（あったか……やば、気持ちよすぎる）〇〇（昨日テレビで笑ってた顔だ、これ） |
| 4人どうしの呼び方 | まい→ほのか「ほのか」、まい→なぎ「なぎちゃん」、まい→めい「めいちゃん」。ほのか→まい「まいちゃん」、ほのか→なぎ「なぎちゃん」、ほのか→めい「めいちゃん」。なぎ→まい「まい」、なぎ→ほのか「ほのか」。めい→先輩「まいさん」「ほのかさん」「なぎさん」 |
| 女の子からの呼ばれ方 | 男より年上の子は「〇〇くん」、年下の子は「〇〇さん」。「〇〇」と呼び捨てにする場面を入れるのもあり。同い年のほのかは「〇〇くん」 |
| 女の子の呼び方 | さん付けはしない。ちゃん付けは残す。ファンとして愛称で呼びはじめ（敬語の時期でも「まいまい」）、距離が縮まると「ちゃん」付け、ときどき呼び捨て。愛称・ちゃん付け・呼び捨てを、場面に合わせて行き来する。まい：まいまい → まいちゃん（4話で「まいって呼んで」とねだられ、照れて「まいちゃん」）／ときどき、まい。ほのか：ほのちゃん／ほのかちゃん／ほのか。なぎ：なぎちゃん／なぎ。めい：めーたん／めいちゃん／めい |

## 堕ちたあとの姿

### 快楽堕ちのイメージ

- 作品内の言葉としては「メス堕ち」ではなく「快楽堕ち」を使う
- 見せ場は、アイドルの表と裏の落差。表では国民的アイドルのまま、裏では快楽のために自分から身体を差し出している
- 恋愛より、快楽そのもの。中身は次の3つ
  - 悦楽の欲求：気持ちよくなりたい。理由が「気持ちいいから」「これがないと無理だから」になる
  - 奉仕の欲求：〇〇を気持ちよくすること自体が快感。言われる前にする
  - 自発的な服従：誰にも命令されていないのに、自分から従う
- 服従している相手は〇〇ではなく、〇〇のちんぽ。〇〇は命令も支配もしない。女の子はちんぽを前にすると逆らえず、ちんぽのために動く
- 宣言しないメス奴隷。「奴隷です」とは言わないが、ちんぽを前にした態度を見れば、そうとしか見えない
- 〇〇以外の男に気持ちが揺れる要素は入れない
- 痴女ではない。自分から跨がる・咥えるときも、責めたいからではなく、欲しくて我慢できない、ちんぽに負けているから。主導権はちんぽにある
- ちんぽへの服従が出る行動の例：見ると目が離れない、匂いだけで発情する、出てくるとまずちんぽに挨拶する（キス、頬ずり）、ちんぽに話しかける、会話の途中でも頭がちんぽに戻る、負けを認める（「勝てない」「逆らえない」。身分の宣言ではなく、負けの告白）

### 要素

- 快楽堕ちしているので、4人とも次の要素を全部持ちうる。一人に一つずつ割り振らない
  - 淫乱化（いつでも欲しい。回数・場所・時間を選ばない）
  - 依存・中毒（間があくと身体がもたない。〇〇のじゃないとイけない）
  - 身体の開発（乳首だけでイく、奥でイく、すぐ潮を噴く）
  - 奉仕好き
  - 精液好き（飲みたい、浴びたい、中に欲しい。匂いや味を求める）
  - ドM（乱暴にされたい。自分からねだる）
  - 見られたい・羞恥（恥ずかしい姿を見られるほど感じる）
  - 孕みたがり（中に出してほしい、孕ませてほしいとねだる）
- 4人の違いは、持っている要素ではなく、次の3つ
  - 出方：同じ要素でも、その子の性格と口調を通すと出方が変わる
  - 入口：最初にどの要素から目覚めたか（堕ちる話の中身で自然に決まる。縛りではない）
  - 崩れ方：口調の崩れ方（下の「完堕ちしたあとの口調」）
- プロットで、ある行為がある子に書いてあっても（例：第6部6話のなぎの首絞め）、それは「その回にその子がねだったもの」。ほかの回で、ほかの子が同じことをしてもいい

### 深まり方と完堕ち

- 快楽堕ちは、話が進むほど深まっていく。一度堕ちたら終わりではなく、回を重ねるごとに求め方が露骨になり、恥じらいが減り、気持ちよさを口にすることにためらいがなくなっていく
  - 堕ちる回（各部の山場）：ここで、ほぼ完堕ちに届く。前の性格は、ほんの少し残るだけ（崩れたあとに一瞬照れる、くらい）
  - 次の回から：完堕ち。裏では、もう前の性格に戻らない。性格そのものが変わっている。来た瞬間から求める。自分の気持ちいいところを自分で知っていて、自分から取りにいく。淫語をためらわない。ちんぽの前の切り替わりが出る
  - 部の残りの話：完堕ちした子が、エスカレートしていく
  - 秘密を共有したあと（第2部の終わり〜）：メンバー同士で〇〇とのことを平気で話す。猥談が普通の会話になる。同期が乱れる姿を見て、さらに昂る
  - 次の部の冒頭：部と部のあいだの時間で、さらにエスカレートした姿を見せる
  - 第5部以降：仕事の合間にも〇〇のことを考えて濡れているのが当たり前
- 完堕ちしても、性格の特徴は消えずに、向かう先が快楽に書き換わる（4人の見分けがつくようにするため）
  - まい：面倒見のよさは、ちんぽに尽くすほうへ。余裕のあるお姉さんが、ちんぽの前では余裕をなくす。人を支える側だった子が、欲だけで動く
  - ほのか：控えめさは消えて、欲しいものを欲しいと言う。芯の強さは、快楽への執着に。観察していた目は、見たい・見られたいに向かう
  - なぎ：いちばん大きく変わる。下の「完堕ちしたあとの口調」のとおり、芯ごとひっくり返る
  - めい：素直さは、何でも受け入れて全部顔に出すほうへ。「やってみます」は、どんなことでも試したがるに。前向きさは、もっと気持ちよくなろうとする向上心に
- 表（ステージ、ファン、仕事の場など）は、4人ともこれまでどおりの表の性格・口調のまま。変えない
- 表の場での漏れ：ほかのメンバーやファンに気づかれない形なら、あり。4人どうしの小声（「今日、出されたまま来た？」）、収録の合間に〇〇へ送る下品なLINEなど。身体に残るもの（声のかすれ、歩き方など）は「表の顔とのつながり」のとおり

### 完堕ちしたあとの口調

- 表・裏・ちんぽの前の3段階で、話し方が変わる
  - 表（仕事、ファン、ほかのメンバーの前）：これまでどおりの表の性格と口調。下品な言葉は使わない
  - 裏（〇〇とご飯を食べている、テレビを見ている、LINE、4人だけの楽屋での猥談など、ちんぽが出ていないとき）：恥も外聞もないが、理性はある。淫語を普通の声で言うし、話題もすぐそっちへ行く。ただ文はちゃんとつながっていて、冗談も言えるし、その子らしい性格も見える
  - ちんぽの前（ちんぽが出てきた、勃っているのに気づいた、匂いがした、行為の最中）：理性もない。下の「バカっぽくなる」とハードコアの台詞
  - 例（完堕ちしたなぎ）：表「……別に。普通でしょ」／裏「ねえ、昨日のやつ、まだ奥に残ってる感じするんだけど。〇〇さん、出しすぎ。……ふふ、うそ。もっと出してよかったのに」／ちんぽの前「あ、おちんぽ……♡　えへへ、おちんぽだぁ……♡　ねえねえ、もうおっきくなってる♡　なぎのこと待ってたの？　おちんぽ、えらいねぇ……♡」
- 見せ場は切り替わりの瞬間。さっきまで普通に冗談を言っていた子が、ちんぽを見た瞬間に目つきが変わり、言葉が崩れる。表から裏、裏からちんぽの前と、2段階で落ちる
- 深まり方との関係：通いはじめのころは、裏はまだほぼ普通で、ちんぽの前で崩れる。完堕ちに近づくほど、裏の会話の途中でも、ちんぽの話になると目がとろんとして、ちんぽの前の状態が少し漏れる。表は最後まで変えない
- 一人称：ふだん（表・裏）は4人とも「私」。ちんぽの前（ハードコアの台詞）では、「私」と名前の一人称を両方使う
  - なぎ：「私」と「なぎ」
  - ほのか：「私」と「ほの」
  - めい：「私」と「めい」
  - まい：「私」と「まい」
- ちんぽの前では、バカっぽくなる（頭の中がちんぽでいっぱいで、考える余地がない感じ）
  - 文が短く、単純になる。理由や前置きがなくなる（「ほしい」「いれて」「これ、すき」）
  - 言葉が幼くなる。語尾が伸びる、甘える（「ちょうだぁい」「もっとぉ」）
  - 同じことをくり返す（「おちんぽ、おちんぽ」「きもちい、きもちい」）
  - 理屈がちんぽ中心になる（「だって、おちんぽあるんだもん」で全部通る）
- 口調の芯は残す（まい・ほのか・めい）
  - まい：相手による使い分けがなくなり、幼い甘え言葉だけになる
  - ほのか：大阪弁が甘く伸びて、文が短くなる（「おちんぽ、ほしいねん……♡」）
  - めい：考えながら話すので一文がまとまらないのが、ちんぽのことで頭がいっぱいで、さらにまとまらなくなる。博多弁が混ざる
- なぎだけは逆にする。短く乾いた芯を残すとクールに見えて完堕ちに見えないので、芯ごとひっくり返す。声の調子まで甘く弾むようになり、なぎらしさは何も残さない（別人のようになること自体を見せる）
  - 口数が少ない → よくしゃべる。自分から話しかけ続ける
  - 落ち着いている → はしゃぐ。声が弾む
  - 「ふふ」と控えめに笑う → 「えへへ」「あはっ」とだらしなく笑う
  - 褒められると言葉に詰まる → 照れがない。自分からちんぽを褒めちぎる。褒めてほしがる
  - 好意を正面から言えない → 欲しい、気持ちいいを、ためらわずに全部言う
  - 例：「ねえねえ、〇〇さんのおちんぽ、今日もおっきいね♡　えへへ、ずっと待ってたんだよ？」
  - 堕ちた直後（第3部4話の事後）は、まだ気だるさと「かも」で濁す感じが残る。通ううちに反転していく

### 語彙の変化

- 表の語彙は変わらない。裏の語彙だけが段階的に変わる
- 変わる方向
  - 指す言葉：遠回し（「そこ」「あれ」）→ 直接・俗語（おまんこ、おちんぽ、おちんちん、ちんぽ、精液、ザーメン）
  - 女の子が〇〇のものを呼ぶときは、「おちんぽ」だけに偏らせず、「おちんちん」も使う（「おちんちん」は幼く甘い響きなので、ちんぽの前でバカっぽく幼くなるところに合う）。「ちんぽ」も混ぜる
  - 主語：されている → 自分がしたい・ほしい（「ちょうだい」「入れて」「飲ませて」）
  - 中身：感覚だけ（「きもちいい」）→ 具体的（「奥」「子宮」「中に出されるの」）
  - 向かう先：〇〇本人 → 〇〇のちんぽ
  - ためらい：言いよどむ、言ってから照れる → 普通の声で、日常の会話の中で言う
- 奉仕と服従は、宣言の言葉ではなく、次の言葉で見せる
  - 許可を求める：「イっていい？」「もう一回、していい？」「飲んでいい？」
  - 差し出す：「使って」「好きなとこに出して」「〇〇くんの、気持ちいいようにして」
  - 奉仕を申し出る：「先に、口でさせて」「きれいにするね」「次、なにしてほしい？」
  - 報告する：「今日、収録中ずっと濡れてた」（言われていなくても、自分で決めて守っている）
- 使わない言葉：「奴隷」「服従」「メス」「おちんぽ様」
- 例外：「ご主人様」は、女の子たちが自分たちで決めてねだる回（第8部10話のような）では使っていい

### 「すき」

- 女の子は、快楽に向けた「すき」（「おちんぽ、すき」「これ、すき」「おく、すき」「中に出されるの、すき」）も、〇〇本人への「すき」も言う
- ただし、〇〇本人への「すき」も恋愛の「すき」ではなく、「〇〇くん（のちんぽ）がすき」に近い意味で使う
- 〇〇は、箱推しとしての好きと、性的に見る目を、両方持っている（「ファンの男」の欄）。女の子はちんぽを崇め、〇〇はアイドルとしての女の子を崇めている。表の顔を見るたびに、〇〇にはファンとしての好きと「この子が、俺のちんぽの前ではああなる」という欲が同時に戻ってくる

### 行為のエスカレート

- 快楽堕ちが深まるのに合わせて、行為もエスカレートしていく。エスカレートさせるのは、お酒や道具などの外側の仕掛けではなく、女の子と〇〇の内側
- 理由は二つ
  - 足りなくなる：前と同じじゃ物足りない。だから自分から次をねだる
  - 恥も外聞もなくなる：裏では「恥ずかしいからやめておく」が効かなくなる（表では、これまでどおり保つ）
- 〇〇との循環：女の子が恥も外聞もなくなる → トップアイドルがそうなっているのを見て、〇〇が興奮して激しくなる → もっと気持ちよくなって、女の子がさらにねだる
- 〇〇からも持ちかけていい。命令ではなく、お願いや願望の形で（「これ、してみたい」）。恥も外聞もなくなった子は、それを喜んで受ける
- エスカレートの軸
  - 強さ：やさしく → 激しく（イラマチオ、首絞め、オナホ扱い）
  - 量：1〜2回 → 抜かずの連発、夜明けまで、イキ地獄
  - 身体の開発：普通にイく → 乳首だけで、奥で、すぐ噴く、アナル
  - 差し出し方：させてもらう → 「使って」→ オナホ扱いをねだる
  - 場所とリスク：家の中 → 楽屋、仕事場、外
  - 日常への侵食：会っているときだけ → 仕事中も（道具を入れたまま、出されたまま仕事へ）
  - 人数：1対1 → 2人、3人、4人同時
- 新しい子の部が始まっても、先に堕ちた子のエスカレートは止まらない。描かれない回で深まり続け、新しい子が見る先輩の姿は、前の部よりさらに深まっている

## 本文の進め方

- 第1部1話から、順に書く
- 手直しがいらない状態で出す。読んでいる途中で「ここが変」と引っかかると興奮が冷めるので、出す前に直しきる
- 書く前に、その話のプロット、キャラの欄と口調サンプル、`文体サンプル.md`、喘ぎ声と語彙のスキルを読み直す。前の話の本文も読み、呼び方・口調の段階、誰が何を知っているかをそろえる
- 書いたあと、出す前に見直す：
  - 書き方のルール、文体、喘ぎ声のルール、守る線に合っているか
  - その子が言いそうにない言い方、不自然な言い回し、言葉の誤用がないか
  - 体勢の矛盾、状況説明になっている文、感情の乗っていない場面がないか
  - 同じ言い回しや擬音の繰り返しがないか
  - 前の話との食い違い（呼び方、口調、知っていること）がないか
- 本文は `本文/` に、プロットと同じファイル名で置く
- 本文で初めて決まった細かい事実（部屋の様子、持ち物、会話で出た話、呼び方の変化など）は、`本文/これまでの本文メモ.md` に話ごとに書き足す。書く前と校閲のときに照らし合わせて、前の本文と食い違わないようにする
- 書き進めるうちに、前の本文に変なところが見つかったら、そのつど直す
- 書くときは「没入とエロさを上げる書き方」から、その話に合うものを選んで使う
