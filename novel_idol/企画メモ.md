# 企画メモ

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。実在のグループやメンバーの名前・特徴は使いません。

## 決まったこと

| 項目 | 内容 |
|---|---|
| イメージ | 国民的アイドルグループのメンバーが快楽に堕ちていく |
| 方針 | エロ100％。難しいことを考えずに読める作品。作る側も難しく考えすぎない |
| 読者の体験 | 男の夢が叶う感じ |
| ヒロイン | 4人（グループのメンバー） |
| 相手役 | ファン（1人） |
| 堕ち方 | 4人それぞれで変える |
| 分量 | 長編・連載 |
| 舞台 | 現代 |

## 書き方のルール（作品全体）

- 設定は書くための土台であって、本文で毎回描写するものではない。外見などの設定を、場面ごとに繰り返し拾って強調しない
- 「（笑）」は本文のセリフに入れない。笑っていることは、地の文や「あはは」などの声で表す

## 喘ぎ声のルール

> ヒロイン全員に適用。

- 喘いでいる最中に、自分の声を説明させない（×「こんな声」「変な声」）
- 「頭おかしくなる」「とける」のように、自分の状態を口走るのはアリ
