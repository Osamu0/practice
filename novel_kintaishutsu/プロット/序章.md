## シーン0-1：予約票

### 1. 時系列ビート
1. 閉館30分前、汐見市立中央図書館。澪はカウンターで返却本を処理している。
2. 白シャツに赤ペンを挿した長身の男が、予約票を差し出す。
3. 書名欄：夜長しずく『濡れ羽の{栞|しおり}』。電子のみの官能小説で、図書館には所蔵がない。
4. 澪は声を平坦に保ち「当館では所蔵がありません」と伝える。
5. 男は「知ってます。リクエストです。いい作家なので」と微笑む。
6. 利用者登録の住所欄に「コーポ汐見坂204」。澪の隣室。
7. 男——真壁透——が去ったあと、澪は予約票を持つ指先が冷えているのに気づく。

### 2. 台詞草案
- 透「……この人、文章はいいんですよ。濡れ場だけ、借り物みたいだけど」
- 澪「……そう、ですか。貴重なご意見として、承ります」
- 澪（モノローグ）「借り物。……知っています。だって、借りてきたんだもの。本から」

### 3. NSFW詳細
なし。

### 4. 五感指定
- **視覚**：西日に舞う埃、胸ポケットの赤ペン、予約票の几帳面な右上がりの字
- **聴覚**：閉館前の館内放送、ブックトラックの車輪の軋み
- **触覚**：予約票の薄い紙、指先の冷え
- **嗅覚**：古い紙の甘い匂い、男がまとうコーヒーと鉛筆の芯の匂い
- **内的感覚**：心臓が一拍遅れて跳ねる

### 5. 演出意図
- 透の「借り物みたい」という評価が、全編を貫く問い（本物の快楽とは何か）を提示する。
- 筆跡（右上がりの字）を読者に印象づけ、0-4での回収に繋ぐ。

## シーン0-2：壁の薄い夜

### 1. 時系列ビート
1. 深夜1時、203号室。パーカー姿の澪が執筆机でノートPCに向かう。
2. 新作の絶頂シーン。澪は癖で、書いた文を小声で読み上げてリズムを確かめる。
3. 読み上げる文：「彼女は果てた。全身が甘く痺れ、意識が白く溶けた」——読んで、眉をひそめる。
4. 「白く溶けた、って……何が？」と独りごちる。分からない。体験したことがないから。
5. 壁の向こうで、ことり、とペンを置くような音がする。澪は気づかない。
6. 澪はベッドで自分の太腿の内側に手を伸ばしかけ、やめる。「……資料、探そう」と本棚へ。

### 2. 台詞草案
- 澪（音読）「『あ、だめ……そこ、もう……っ』——だめ、ってどのくらい？　どう、だめなの……」
- 澪（モノローグ）「書けば書くほど、嘘っぽくなる」

### 3. NSFW詳細
- 性行為なし。音読される作中作の喘ぎはレベル1（「あっ……」程度）で、棒読み気味に。
- 自慰未遂：伸ばしかけてやめる。性への渇望と理性の拮抗を示すだけに留める。

### 4. 五感指定
- **視覚**：画面の白い光に浮かぶ眼鏡のレンズ、カーソルの点滅
- **聴覚**：自分の囁き声、冷蔵庫の唸り、**壁の向こうの小さな物音**
- **触覚**：パーカーの袖口、冷えた足先
- **内的感覚**：下腹の奥がかすかに疼くが、名前をつけられない

### 5. 演出意図
- 「音読癖」と「壁の薄さ」を同時に提示。読者だけが隣に聞こえていると察する。
- 澪の欠落（絶頂を知らない）を具体的な一文で示す。

## シーン0-3：鉛筆の問い

### 1. 時系列ビート
1. 翌朝、出勤前。早瀬からメールで前作の重版なしの報告と、新作の初校ゲラPDFが届く。
2. 澪は印刷したゲラをめくる。外部校正者の鉛筆書きの疑問出しが並ぶ。
3. 誤字指摘の中に一つだけ、異質な疑問出し：絶頂シーンの余白に「この絶頂、作者は体験済みですか？」
4. その横に、校正記号「イキ」——澪が削った一文を元に戻せ、という指示。削った一文は「本当は、怖かった」。
5. 筆跡は几帳面な右上がり。どこかで見た。

### 2. 台詞草案
- 澪「……失礼な」
- 澪（モノローグ）「失礼で、正しい。体験してない。だから、怖かった、なんて書いて、消した」

### 3. NSFW詳細
なし。

### 4. 五感指定
- **視覚**：鉛筆の薄い灰色の文字、「イキ」の記号
- **聴覚**：プリンタの排紙音、外のカラスの声
- **触覚**：ゲラの紙の端で指を切りそうになる
- **内的感覚**：顔が熱いのに背筋が冷たい

### 5. 演出意図
- 「イキ」を初登場させる。ここでは純粋な校正記号として、読者に意味（削除を取り消す）を説明しておく。
- 削った一文「本当は、怖かった」は第三章・終章で再び生かされる。

## シーン0-4：ゴミ捨て場の答え合わせ

### 1. 時系列ビート
1. 澪は燃えるゴミを出しにアパートの集積所へ。
2. 透がスウェット姿で段ボールを潰している。「東京」と書かれた送り状が一瞬見える（伏線）。
3. 透「おはようございます、九条さん。……いや、夜長先生？」
4. 澪は固まる。透は胸ポケットから鉛筆書きのメモ：「壁、薄いです。音読、全部聞こえてます」——同じ右上がりの字。
5. 透は自分が彼女のレーベルの外部校正者だと名乗る。
6. 澪「……今夜、お話を。口外しないでいただきたいので」。透「いいですよ。俺も、聞きたいことがある」

### 2. 台詞草案
- 透「『白く溶けた』。あれ、何が溶けるのか、俺も知りたくて」
- 澪「……っ、聞いてたんですか」
- 透「聞こえたんです。毎晩。いい声で読むから」

### 3. NSFW詳細
なし（「いい声」という言葉にだけ性的な含みを持たせる）。

### 4. 五感指定
- **視覚**：朝靄の坂道、潰された段ボール、送り状の「東京」
- **聴覚**：カラス避けネットのはためき、透の低い声
- **触覚**：ゴミ袋の持ち手が指に食い込む
- **嗅覚**：潮の匂いと、昨夜と同じコーヒーの匂い
- **内的感覚**：血の気が引いたあと、遅れて顔に血が上る

### 5. 演出意図
- 正体バレの瞬間を朝の日常に置くことで、背徳感を強める。
- 「東京」の送り状は読者が見落とす程度に描く（第三章で回収）。
- 力関係を明示：秘密も文章の弱点も、透が握っている。
