## 2. 世界観設定

### 基本ルール
- 現代日本。魔法・異能なし。技術レベルは現実と同じ。
- 舞台は架空の地方都市「{汐見|しおみ}市」。海沿いの坂の多い町。

### 舞台
| 場所 | 雰囲気・役割 |
|---|---|
| 汐見市立中央図書館 | 澪の職場。昭和築の重い建物。地下に**閉架書庫**（移動式書架、裸電球、紙と埃の匂い）。クライマックスの舞台 |
| コーポ汐見坂 203／204号室 | 築40年の木造アパート。**壁が薄い**。203が澪、204に透が越してくる。澪は執筆中に原稿を小声で**音読する癖**があり、それが隣に筒抜け |
| 澪の部屋 | 本で埋まった1K。窓際の執筆机、ノートPC、印刷したゲラの束 |
| 透の部屋 | 引っ越しの段ボールが片付かないまま（伏線：短期滞在の予定）。床に赤ペンとゲラ |

### 性に関する文化・タブー
- 現代日本の常識の範囲。
- 本作のタブーは「**覆面作家の正体バレ**」と「**職場（公共施設）での行為**」。いずれも成人同士の合意のうえで、背徳感のスパイスとして扱う。

### 世界観がエロスに与える影響（本作のギミック）
- **校正記号＝プレイの言語。** 二人のあいだでは、校正記号がそのまま合図になる。
  - **トル**（削除）＝セーフワード。澪が「トル」と言えば透は即座に止める（第一章で取り決め）。
  - **イキ**（削除を取り消して元に戻す）＝「やめないで／続けて」。読者には「イく」の掛詞として響く。
  - **ママ**（修正せずそのまま）＝「そのままでいい」。
  - **朱を入れる**＝相手を直す・書き換える。序盤は透が澪に、終章では澪が透に入れる（力関係の逆転）。
- **音読**＝羞恥の装置。自作の官能描写を、本人に読み上げさせる。

### 用語集
| 用語 | 意味 |
|---|---|
| ゲラ | 校正用の試し刷り |
| 朱入れ／赤字 | 校正者が赤ペンで入れる修正指示 |
| 疑問出し | 校正者が鉛筆で入れる「ここは正しいですか？」という問い |
| 禁帯出 | 図書館で貸出禁止の資料。館内でしか読めない。→「外に出せない秘密」の象徴 |
| 閉架書庫 | 利用者が立ち入れない保管書庫 |

| 年齢・性別 | 28歳・女性 |
| 体型 | 158cm。華奢な肩と細い腰に対し、カーディガンに隠れたDカップ。色白 |
| 髪・服装 | 黒髪ロングを低い位置でひとつ結び。黒縁眼鏡。紺のカーディガン、くるぶし丈のフレアスカート、ローヒール。部屋では大きめのグレーのパーカー |
| 性格 | 物静か、真面目、観察好き。言葉には人一倍こだわるが、自分の欲望を口にするのは苦手。追い込まれると妙に理屈っぽくなる |
| 口調・一人称 | 「私」。基本は丁寧語（「……そう、ですか」「困ります」）。動揺すると言葉が文語っぽく硬くなる |
| 行動原理 | 欲望：「本物の官能」を書きたい。目的：次作で打ち切りを回避する。弱点：経験不足（交際1人・数回のみ、人の手で達したことはない）、自分の文章を読み上げられると羞恥で崩れる |
| 性的な特徴 | 敏感：耳の縁、首筋、背骨のライン。濡れやすいが自覚がない。絶頂時に足の指を丸める癖 |
| 変化予定 | 観察する側（書く側）→ 求める側。終章では自分から透に「朱を入れ返す」。新作の結末を自分で書き換える |

### サブキャラクター
- **{早瀬|はやせ}**（35歳・女性）：澪の担当編集。電話とメールのみで登場。「次作が刺さらなければシリーズ打ち切り」と告げる、外圧役。

### 相性・力関係
- **序盤：透 ＞ 澪。** 赤を入れる者と入れられる者。透は澪の秘密と文章の弱点を両方握っている。
- **終盤：澪 ≧ 透。** 澪が透の身体に赤ペンで書き込み、彼の「東京へ戻る」予定に朱を入れる。
- 共通点：二人とも「言葉」でしか本音を言えない。だから校正記号が二人の共通言語になる。
