# 作者に言われたこと：裏オフ

> 書く前・直す前に、毎回これを頭から読む。一つ言われたことを直すときも、ほかを忘れていないかこれで確かめる。
> ここにあるのは作者の言葉と、それをどう受け取ったか。細かいルールは `文体ルール.md`、`企画メモ.md`、スキル（`spicy_novel_writing_jp` の `realism.md`、`author_edits.md`、`ai_tells.md`）にある。

## 書き方の根っこ

| 作者の言葉（要旨） | 受け取ったこと |
|---|---|
| 人間は想像しながら同時に物語を描ける。考えてから書くんじゃなくて、書きながら考える。書きながら脳内で補完する | プロットの項目を順に埋めない。場面を頭の中で流しながら書く。校閲の直し案を一行ずつ貼り替えない |
| 想像力を働かせるのは、場面だけの話じゃない | 台詞一本ずつ、その人がその瞬間の体と気持ちで本当に言うか（咥えていた人が「私の口から出てきた」と言うか、尻を並べた人が「知ってた」と言うか） |
| 確かめるのと作るのは違う | チェックで手直しするのは、物語を考えたことにならない。この話は何の話で、読者は何で抜けるかを先に考えて作る |
| 考えるってのは言いなりになるってことじゃない | 言われた一言だけを当てはめない（「壮観」と言われて尻を全部説明する、「直接的な言葉がない」と言われて全部の台詞に入れる、は言いなり）。既にあるルールと物語の中で考える |
| キャラの性格を見て「こういう人だからこうなる」はAIの思考で嫌 | 図鑑はアイドルとしての人。エロでどうなるかは決まっていない。性格から崩れ方を逆算しない。読者がシコれるか、抜けるかで考える |
| 読者はアイドルとやってると知った上で読んでいる | ポスター・テレビ・歌番組など、表の顔を思い出させる説明はいらない |
| 期待を超えてこない。考えが見え透いている、言ったことへの直し方が読める | 説明や「こう直しました」の筋道が、そのまま本文に透けないようにする。直したことの報告で、狙いを並べない |

## 本文で言われたこと

## 前からあるもの（忘れやすいもの）

- `企画メモ.md`：当たりなので4人ともガチでヨガる。悦ばせたい自分と、ヨガってしまう自分が混ざる。主導権はアイドル側。誰がつながっていても、残りは〇〇の体のどこかにいる。〇〇はまいで初めて自分から動き、ななせでは反応を見て動きを変える。〇〇は推しが自分ので崩れていくのに酔う
- `文体ルール.md`：会話劇。段取りを書かない。地の文に〇〇をほとんど出さない。相手の体を実況させない。感触の報告をしない。順番に一言ずつ実況させない。見えていないことは言わせない
- スキル `ai_tells.md`：地の文で、直後の擬音や台詞と同じことを言い直さない。決め台詞で締めない。同じ言葉のくり返し
