# 作者に言われたこと：裏オフ

> 書く前・直す前に、毎回これを頭から読む。一つ言われたことを直すときも、ほかを忘れていないかこれで確かめる。
> ここにあるのは作者の言葉と、それをどう受け取ったか。細かいルールは `文体ルール.md`、`企画メモ.md`、スキル（`spicy_novel_writing_jp` の `realism.md`、`author_edits.md`、`ai_tells.md`）にある。

## 書き方の根っこ

| 作者の言葉（要旨） | 受け取ったこと |
|---|---|
| 人間は想像しながら同時に物語を描ける。考えてから書くんじゃなくて、書きながら考える。書きながら脳内で補完する | プロットの項目を順に埋めない。場面を頭の中で流しながら書く。校閲の直し案を一行ずつ貼り替えない |
| 想像力を働かせるのは、場面だけの話じゃない | 台詞一本ずつ、その人がその瞬間の体と気持ちで本当に言うか（咥えていた人が「私の口から出てきた」と言うか、尻を並べた人が「知ってた」と言うか） |
| 確かめるのと作るのは違う | チェックで手直しするのは、物語を考えたことにならない。この話は何の話で、読者は何で抜けるかを先に考えて作る |
| 考えるってのは言いなりになるってことじゃない | 言われた一言だけを当てはめない（「壮観」と言われて尻を全部説明する、「直接的な言葉がない」と言われて全部の台詞に入れる、は言いなり）。既にあるルールと物語の中で考える |
| キャラの性格を見て「こういう人だからこうなる」はAIの思考で嫌 | 図鑑はアイドルとしての人。エロでどうなるかは決まっていない。性格から崩れ方を逆算しない。読者がシコれるか、抜けるかで考える |
| 読者はアイドルとやってると知った上で読んでいる | ポスター・テレビ・歌番組など、表の顔を思い出させる説明はいらない |
| 期待を超えてこない。考えが見え透いている、言ったことへの直し方が読める | 説明や「こう直しました」の筋道が、そのまま本文に透けないようにする。直したことの報告で、狙いを並べない |

## 本文で言われたこと

| 作者の言葉（要旨） | 受け取ったこと |
|---|---|
| 地の文はト書きくらい（文体ルール） | 壮観な絵でも一行。全部説明しない |
| 地の文がもう一声。場所から動くことを伝えようとしすぎて、逆にわかりにくい（「背もたれにあごをのせてのぞきこむ」「並んでいた尻を背もたれからはがして」、背もたれに尻をつけてたみたいに読める）。「〇〇の前に並んだ」のほうがわかりやすい。バック・正常位・対面座位など体位がわかる言葉を入れる。「ソファの上から、まいの手が垂れてきていた……指をからめて」はイメージしにくい | 家具を基準に位置を細かく追わない。〇〇から見てどうか、誰が何の体位か、で一行で書く（「後ろから抱きついてきた」「四つん這いになる」「正常位で覆いかぶさる」）。読んで絵が浮かぶかを自分で確かめる |
| ガチヨガりは数ターンもってほしい | 入れてすぐイかせない。何往復もかけて崩れる |
| ガチヨガりの方向性が違う。何回もずっとイくってことじゃないし、一回だけでもない。ヨガってるんだよ | イった回数や「いく」の連打で見せない。気持ちよさに呑まれて、ずっと感じっぱなしになっている状態を書く。イくのはその流れの中で起きるもので、区切りにしない。甘いじゃれ合い（いじわる、わざとでしょ）もガチヨガりではない |
| エロ物語なのに、おちんちんとか直接的な言葉が出てこない（第1話から） | 直接の言葉を使っていい。ただし何でもかんでも入れればいいものではない |
| 〇〇のセリフが少ない／〇〇が一歩引いている、同じテンションじゃない | 〇〇も同じ熱で乱れる。「は、はい」「……え」「やめますか」「ここ、ですか」のような、余裕のある・従うだけの返しにしない |
| あすか：休んだら、と言われて、手とか口なら、そういうのじゃない、これがいいの、の方が我慢できない感が出る | あすかの一番の山。「……そういうのじゃないです」「これがいいの」 |
| あすかの「起きない」の言い回し | 「おっきくなんない」 |
| あすかの「おっきくなってよ」と、まなつの「あすか」が、エロ物語とはちょっと違う雰囲気になっている | 切ない・しんみりした空気で締めない。残念がるところでも、欲しくてたまらない熱のまま書く |
| 手首をつかんでおっぱいを触らせたのに、次の瞬間には移動してしゃぶっている。手、届いてんの？／書き直すより、そもそもそれをしなくてもよかったんじゃない？　指摘されたから書き直すのは言いなり | 食い違いを見つけたら、説明の一行を足して辻褄を合わせる前に、それが本当に要るかを考える。要らないなら消す。体が動いたら、さっきまでの手・口の位置がどうなったかを書く前に考える |
| 風呂を長くしてもいい。あすかはお預けを食らっていた。独り占めできるんだから、もっとよがり狂っていい。〇〇も一回だけじゃなく、いろんなことをさせてみたら／「寝た」は「寝ちゃった」のほうが感情がこもる。あすかはやりたい気持ちしかない | 待たされた人の場面は長く、いちばん狂わせる。〇〇も何度も出していい。体位とすることを変えていく。待っていた人の台詞は、やりたい気持ち以外を入れない |
| 白紙から考えたと言っても、流れが変わっていない | 「白紙から」と言うなら、前の稿の順番を使わない。言い回しを直しただけで白紙と言わない |
| 風呂上がりになった瞬間から距離ができている。なんで？ | 行為が終わったところで温度を下げない。場面が変わっても、直前の熱と体の近さを引き継ぐ。企画メモの「落ち着いて向き合う」を、終わったあとの冷めた空気に当てはめない。エロが終わったからといって、図鑑の淡々とした性格に戻さない |
| 口が切れているのは、ずれている | 甘い熱の場面に、けがや痛みの細かい事実を持ちこまない。リアルさのつもりで、空気から外れた細部を足さない |
| 倒置法みたいな表現ってAIの手法なの？ | 地の文で、文を言い切ったあとに「〜みたいに。」「今度は、もっと深く。」「何度も、何度も。」と断片を後ろに足す形を使わない（スキル `ai_tells.md` の「副詞句や体言止めの断片で区切る文」）。一文の中に入れる |
| 寝ているから、手の重なりなどはなくていい | 寝ている人に、細かい仕込み（握ったまま、重ねたまま）を持たせない。前の話の最後の小道具を、次の話の頭で回収しない |
| 朝ごはんは楽しく食べる感じで、そのあとに精力剤を渡す | 食事（緩）はちゃんと楽しく食べる。エロの仕掛けは食べ終わってから |
| 喘ぎ声もレベル4を使えば？ | ピークでは `aegigoe_skills.md` のレベル4（アヘ声実況、半角カナ、呂律崩し、卑語）まで使う。ピーク以外には広げない |
| 言われたことしかできないの？ | 言われたことを直すだけで出さない。直すついでに、話全体を読み直して、自分からもっとよくできるところ（体位、喘ぎの強さ、山の作り方）を足す |
| 声のかすれはなくていい | 声がかれる・かすれるを書かない（企画メモの2日目の「声がかすれていく」も使わない） |
| 会話劇の感じが薄れていない？ | 二人きりの場面でも、体位を変えるのを地の文の段取りでやらない。台詞で誘い、台詞で返して、変わる。一人が喘ぎつづけるだけにしない。〇〇も返す |
| 全員〇〇のちんこを知ってるから、キャラのままじゃなくていい。当たりってなってるんだから | 一度当たりを知ったあとのメンバーは、図鑑のキャラ（照れ、ごまかし、すまし）に戻さない。朝起きても、食事中でも、頭の中は〇〇のもので、手が伸びる。理由（精力剤を渡すなど）も、その欲しさから出す |
| その状態で並ぶの面白い、はエロの流れからそれている | 場をいじる笑いのコメント、ツッコミのかけ合いで流れを止めない |

## 前からあるもの（忘れやすいもの）

- `企画メモ.md`：当たりなので4人ともガチでヨガる。悦ばせたい自分と、ヨガってしまう自分が混ざる。主導権はアイドル側。誰がつながっていても、残りは〇〇の体のどこかにいる。〇〇はまいで初めて自分から動き、ななせでは反応を見て動きを変える。〇〇は推しが自分ので崩れていくのに酔う
- `文体ルール.md`：会話劇。段取りを書かない。地の文に〇〇をほとんど出さない。相手の体を実況させない。感触の報告をしない。順番に一言ずつ実況させない。見えていないことは言わせない
- スキル `ai_tells.md`：地の文で、直後の擬音や台詞と同じことを言い直さない。決め台詞で締めない。同じ言葉のくり返し
