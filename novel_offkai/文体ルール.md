# 文体ルール：裏オフ

> スキル `spicy_novel_writing_jp` を土台にする。ここには、この作品で選んだことと、スキルとの違いだけを書く。

| 項目 | この作品 |
|---|---|
| 作品の芯 | 当たりを引いた推しが、もてなしながら本気で崩れていく。甘ったるい空気。いい話にしない |
| 視点 | 三人称。地の文は〇〇に寄り添う。ただし地の文では〇〇の名前をほとんど出さない（下の「会話劇」） |
| 心の声 | 使わない。〇〇の感じたことは地の文で書く |
| 語り手の声 | なし |
| ♡・笑 | メンバーはよく使う。崩れるほど♡が増える。〇〇は♡を使わない |
| 喘ぎ声の強さ | 場面で固定しない。当たりなのでガチの声。ピークは濁点・♡♡まで |
| 擬音の表記 | 独立した行。地の文より一段下げる（全角スペース2つ）。台詞の中に混ぜてもいい。地の文の中で音を出してもいい（「むにゅ、と胸が沈む」） |
| 表記 | スキルの既定どおり（名前「」、台詞末の「。」なし、「（笑）」は使わず語尾の「笑」） |
| 〇〇の台詞 | メンバーには、です・ます。崩れていくと抜ける。名前は〇〇のまま |
| 呼び方 | 地の文ではメンバーを下の名前で書く（まい、ななせ、まなつ、あすか）。メンバー同士は、まいやん、なーちゃん、まなつ、あすか（秋元は愛称の「まなったん」ではなく「まなつ」と呼ぶ）。〇〇のことは「〇〇さん」。愛称は必ずそう呼ぶものではない（`../キャラクター/README.md` の「愛称の決まり」） |

## 会話劇（2026年11月、作者の直し）

> ドラマのように、台詞と声の芝居で場面を運ぶ。読んでいて、イメージがパッと入ってくること。地の文で説明されると、それを読んでイメージしている間に萎える。
> スキル `spicy_novel_writing_jp` の「行為中の地の文の量」より、さらに地の文を減らす。

| 項目 | この作品 |
|---|---|
| 運ぶもの | 台詞、喘ぎ声、行為音。何をしているかは、本人の台詞と、見ているメンバーの反応（実況、ツッコミ）でわかるようにする。四人いるので、見ている側がカメラの代わりになる |
| 地の文 | ト書きくらい。一行でパッと絵が浮かぶものだけ。説明しない |
| 段取りを書かない | 誰がどこへ動いて何をしたかを、順に追わない（×「まなつが立ち上がった。三人もそれに続いた。四人が〇〇の前に並んだ。」）。途中は飛ばして、感触と絵が立つ瞬間から書く |
| 一人一文で並べない | ×「まいが〜した。ななせは〜している。あすかは〜していた。」 |
| 地の文の〇〇 | 「〇〇は」「〇〇の」をほとんど使わない。〇〇の体に起きたことは主語なしで書く（○「手首をつかまれて、パーカーの裾から中へ引きこまれた。」） |
| 喘ぎ声と行為音 | 多く。一つの台詞の中に、声と音と言葉を混ぜて流す（○まなつ「んぐ……っ♡　んむ、ん゛……♡　ぷぁ、おっき……あご、はずれそ……♡　はむ、じゅる……♡」）。何人もが同時にしているときは、行為音の行に全員の音を重ねる |
| テンポ | 一行一行を短く切りすぎない。台詞の中で声と言葉を続けて、会話として流す |
| これからすることを告げない | ×まい「こっちも触ってて♡」、ななせ「じゃあ私、ここ」。先に体が動いて、台詞は自分が感じたことだけ |
| 決まり文句の質問をしない | ×ななせ「ちくび、好きなんですか？」 |
| 感触を言葉で報告しない | ×まい「手、あっつ……♡」（AIっぽい）。○声と、して欲しいこと |
| 呼び方を話題にしない | ×まい「まいやんって呼んでくれるんだ♡」 |
| 女の台詞に男っぽい言葉を使わない | ×まい「なーちゃん、えっろ笑」 |
| 何が、を落とさない | ×ななせ「かたくなってきた」→○「乳首かたくなってきた」 |

校閲の担当：会話劇の全体と段取り・地の文の量は文章と読者、喘ぎ声と行為音の量とテンポはエロ、台詞の項目はキャラ口調とAIっぽさ。
