# 文体と書き方

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です（まい26歳、〇〇18歳・大学1年生）。
> 『桜ヶ丘40』（`novel_idol/企画メモ.md`）の文体と書き方のルールを土台にして、この作品に合わせて変えたもの。

## いちばん大事なこと
- **読者が読んで抜けること。** すべての決まりは、そのためにある
- エロ漫画寄りか、小説寄りかは決め打ちしない。書きながら、抜けるかどうかで調整する
- 読んでいる途中で「ここが変」と引っかかると興奮が冷める。出す前に直しきる

## 文体

| 項目 | 内容 |
|---|---|
| 視点 | 三人称。場面ごとに、〇〇かまいのどちらかに寄せる。エロの場面も両方に寄せる。一つの場面の中で視点を行ったり来たりしない。切り替えるのは場面の区切り（---）で |
| 〇〇の視点 | 〇〇から見えるもの・聞こえるもの・感じるもの。「テレビで見ていたあのまいまいが」という実感。熱さ、ぬめり、締めつけ、射精感。エピローグでは優越感 |
| まいの視点 | 嫌悪と欲しさが同時にある内側。くさいのに止まれない感じ。頭が〇〇の匂いとちんぽでいっぱいになっていく感じ。外では清純なアイドルの顔のまま、内側で〇〇のことを考えている感じ |
| 比重 | 台詞、喘ぎ声、行為音を多めにする。地の文は少なめ |
| 会話 | 言って、返して、また言う、の往復を大事にする。エロの最中も、喘ぎ声だけでなく言葉のやり取りを入れる |
| エロの長さ | 一つ一つの行為をじっくり書く。次の行為や体位へ急がない。プロットに並んだ行為を、駆け足で全部こなすような書き方にしない |
| テンポ | テンポよく。ただし短い文にしすぎない。エロの山場では、短い文と改行で速くしてよい |
| 分量 | 先に決めない。内容に合った長さにする。削って短くするより、会話と行為をじっくり書く |

### 台詞の表記
- 台詞の前に、話している人の名前をつける（例：まい「……」、〇〇「……」）
- 心の声は丸かっこ（例：まい（……）、〇〇（……））
- 話す人が替わるときは、台詞と台詞のあいだに空行を入れる。同じ人が続けて話すときは、空行を入れずに続け、名前は最初の台詞だけにつける
- 地の文は行頭を一字下げる
- 地の文では愛称（まいまい）を使わず、「まい」と書く。〇〇の台詞と心の声では「まいまい」

### 心の声
- 〇〇もまいも書く。ただし多くしすぎない。場面が切り替わるところや、気持ちが大きく動くところに絞る
- 台詞や地の文で伝わることは、心の声にしない

### 地の文
- 肉感的・即物的なポルノ小説の語彙で書く。身体の崩れ（涎、涙、舌、垂れる汁、だらしない顔）も、この語彙で書く
- 比喩や心理の解説は、ほぼ書かない
- 状況や場所の説明は最小限にする
- 読点は必要なところだけにする。主語の「〜は」「〜が」のあとに毎回打たない。1文に1つくらいを目安にする（✕「まいは、一度、目を伏せた。」→ ○「まいは一度目を伏せた。」）
- 「奥に届く」「中に注がれる」など、断面図を思わせる描写を使ってよい

| 種類 | 例 | 扱い |
|---|---|---|
| 動作 | 腰を掴んで引き寄せる、脚を開かせる | 残す（何が起きているかわかるように） |
| 身体の反応 | 背中が反る、太ももが震える、締めつけてくる | 残す（エロの核） |
| 男が感じる感覚 | 熱さ、ぬめり、締めつけ、射精感 | 残す |
| 匂い | 〇〇の体臭、ちんぽの激臭、蒸れた毛の匂い、精液の匂い | **多めに残す**（この作品の核。まいの反応と必ずセットにする） |
| ほかの五感 | 肌の熱、湿り気、味、音 | 要所で一つずつ |
| 状況・場所の説明 | 部屋の様子、時間、経緯 | 最小限にする |
| 比喩・心理の解説 | 「まるで〜のように」、長い気持ちの説明 | ほぼ書かない |

### 記号
- まいの台詞は、！と♡を使う
- 〇〇の台詞は、！、っ、……、ーまで。♡は使わない
- 同じ文字を5つ以上続けない

## 書き方のルール

**この作品で一番大事な書き方**
- まいの性格は、どれか一つの言葉で書かない。いろいろな面が同時にあって、混ざり方が変わっていくように書く。「普段モード」「エロモード」のように切り替えない
- まいの嫌悪と欲しさは、最初から最後まで同時にある。嫌悪は引く理由にならず、欲しさを煽る燃料になる。のめり込んだら我に返らない
- まいの人格は、堕ちても、メス奴隷になっても消えない。ふわっとした話し方、天然、よく笑うところが、崩れた声や淫語の中に残っている。**声は崩れても、人格は崩れない**
- 毒舌やシニカルさに寄りすぎない。口に出る毒舌は、打ち解けた相手に、たまに、軽く
- まいが望んでいることを、台詞と仕草で見せ続ける（詳しくは `設定資料.md` の「書くときのルール（〇〇とまいの行為）」）

**体勢・位置関係**
- 物理的に無理な体勢にしない。一人の手や口が同時に二か所にある、のような矛盾を出さない
- 位置関係はプロットで決めておき、本文では説明しない。動作、身体の感覚、台詞の中で、自然に伝わるようにする
  - ✕「〇〇はベッドに仰向けになり、まいはその脚のあいだに座っている。」
  - ○「脚のあいだに座りこんだまいの吐息が、内ももにかかった。」
- 読者が想像するのに必要なことだけを書く。状況説明のような文にしない
- 台詞を見ればわかることを、地の文で言い直さない

**臨場感・感情**
- 何が起きているかより先に、どう感じているかが伝わるように書く
- 行為の中に、そのときの気持ち（嫌悪、欲しさ、恥ずかしさ、気持ちよさ、優越感など）を乗せる

**台詞・言葉**
- 台詞も心の声も、現実の人が実際に口にする言い方にする。短く、口語で。説明調、比喩、決め台詞っぽい言い回し、ポエムのような長い文はしない
- 平常時の台詞に読点や「……」を細かく入れすぎない。細かく途切れるのは、乱れている最中だけ
- 乱れている最中の淫語や崩れた台詞は、ジャンルの見せ場として誇張してよい
- 言葉の使い方を正しくする。意味のずれた言葉や、不自然な組み合わせを使わない
- 淫語や卑語も、その場面とまいの状態に合ったものを選ぶ
- 「（笑）」は台詞に入れない。笑っていることは、地の文や「あはは」「ふふ」などの声で表す

**〇〇がイくとき**
- 〇〇も、出すときに口に出してイく（「イく……っ」「やば、出る……っ」）。前半のおどおどした時期は「イきそう、です……っ」のように敬語が残ったまま崩れる
- 伸ばしたり、♡をつけたりはしない。短く、息の詰まった声にする
- 〇〇が「イく」と言ったところから、まいのイき方は一段激しくなる。出し終わってもすぐには戻らない。余韻が引いてから、まいの口調に戻る

## 喘ぎ声のルール
- スキルの `.claude/skills/spicy_novel_jp/references/aegigoe_skills.md` を、書く前に読む
- 章ごとのレベルは `アウトライン.md` の管理表に従う（第一章ほぼなし、第二章2〜3、第三章以降3〜4）
- 喘いでいる最中に、自分の声を説明させない（✕「こんな声」「変な声」）
- 「頭おかしくなる」「とける」のように、自分の状態を口走るのはよい
- 汚喘ぎ（濁点と♡のある崩れた声）とオホ声も使う。ただし、ふわっとした語尾や天然の名残が、ところどころに混ざるようにする

| 手法 | 例 | 使いどころ |
|---|---|---|
| 半角カナ | ｱｯ、ｲｸｯ、ﾝｯ、ｵﾎｯ | 細かく跳ねる。痙攣、連続絶頂 |
| 半角カナ＋濁点 | ｱﾞｯ、ｵﾞｯ、ﾝﾞｯ | |
| 全角→半角に崩す | 「お゛っ♡ おく、ｵﾞｯ、ｵﾞﾎｯ♡♡」 | |
| 半角→全角に戻す | 「ｲｸｯ、ｲｸｯ……っ、ぁ、あ゛ぁぁ〜〜っ♡」 | |
| 濁点（全角） | あ゛、お゛っ、ん゛ぅ | |
| 小書き文字 | ぁ、ぃ、ぅ、ぇ、ぉ、っ | |
| 長音符、波線 | 「イくぅぅ〜〜っ」 | |
| 呂律崩し、ぶつ切れ | らめ、きもひぃ／「い、イっ、イく……っ」 | |
| 句読点を減らす | 「イくイくイっちゃうおく」 | |
| 息が押し出される音 | ｶﾊｯ、ｶﾋｭｯ、ｸﾞｩ | イラマの最中にも使う |

**イラマ・フェラ・匂いの最中の声**
- 口がふさがっているので、閉口の喘ぎ（んぐ、んぶ、ふぐぅ）と、えずき、嗚咽、息の音で書く
- 口が離れた瞬間に、言葉と♡があふれる

**えずき・嗚咽・嘔吐寸前**
- 激臭を嗅いだとき、チンカスを舐めたとき、喉の奥まで突かれたときに使う
- 吐くところまでは行かない。**嘔吐寸前**で止める。こみ上げてきて、喉が痙攣して、涙と鼻水とよだれが出る。それでも顔を離さない、口を離さない
- 嗚咽は、苦しさで勝手に出る声として書く。泣いて嫌がっている声にはしない。嗚咽のすぐあとに、まいが自分から〇〇の腰を引き寄せる、また鼻を寄せる、口が離れた瞬間に「……もっと♡」と言う、などで、望んでいることを見せる
- まいの中では、こみ上げる苦しさも、嫌悪と同じく欲しさを煽る燃料になる

| 種類 | 例 |
|---|---|
| えずき | おぇっ、うぇっ、ぉ゛えっ、ｵｴｯ |
| 嘔吐寸前 | ぐぷっ、ごぽっ、こみ上げて「ん゛ぶっ……！」、喉がひくひく痙攣する |
| 嗚咽 | ひっ、ぐすっ、ひぐっ、ぅぐっ……ぇぐっ |
| 喉が詰まる | ごぼっ、ぐぼっ、ｸﾞﾎﾟｯ、ｶﾋｭｯ |
| 口が離れた瞬間 | 「げほっ、けほっ……っ、はぁ、はぁ……♡」「くっさ……っ、ぉえ……っ、でも、すき……♡」 |

- 地の文では、身体の反応（喉の痙攣、涙、鼻水、よだれの糸、顔が真っ赤になる、目の焦点がぶれる）で書く。吐いたものの描写はしない

## 擬音（行為音）のルール
- 擬音は独立した行に、一字下げて書く
- 激しさに合わせて表記を変える。喘ぎ声が半角になるところでは、行為音も半角にする
- 続いている行為の音は長めに書く（1行に5〜10音くらい。途中で強い音を混ぜて変化をつける）。単発の音は短いままでいい

## 没入とエロさを上げる書き方

> 全部を毎回入れるのではなく、その章に合うものを選ぶ。

**匂い（この作品の核）**
- 〇〇の匂いは、まいの反応と必ずセットで書く（えずく、涙目、とろける、鼻をうずめる、息が荒くなる、脚をこすり合わせる）
- 匂いそのものを細かく説明しすぎない。どんな匂いかより、まいがどうなるかを書く
- 匂いの言葉が続かないように、spicy_novel_vocab_jp の P12（嗅覚系）を使う

**五感と生々しさ**
- 匂い以外の五感（味、温度、湿り気、音）は、要所で一つずつ入れる。並べて説明しない
- 身体の生々しい反応：汗で髪が額に貼りつく、太ももが震える、垂れてくるもの、シーツの濡れ、肌に残る指の跡

**現実の小さなこと**
- 体位を変えるときに抜けて、慌てて入れ直す。髪が口に入る。汗で滑る
- 萎えない程度に。一章に一つか二つまで

**女の子の目線**
- まいが〇〇の身体に向ける目（ちんぽの形、太さ、毛、匂い）も描く。求められている実感が、〇〇にも読者にも返ってくる

**アイドルとの落差（とくにエピローグ）**
- テレビの中の清純なまいと、目の前のまい。〇〇の視点では優越感、まいの視点では、外の顔の内側で〇〇を考えている感じ
- 外の仕事に残るもの：声のかすれ、ふとした瞬間に思い出す〇〇の匂い

**描かれない日々（エピローグ）**
- エピローグの「ある日」だけが、二人の日々ではない。慣れた動き、二人だけの決まりごと（帰ったら首輪をつけて膝をつく、など）、まいの部屋に染みついた〇〇の匂いで、書かれていない毎日を匂わせる

## 本文の進め方
- 序章から順に書く
- 書く前に読み直すもの：その章のプロット、`設定資料.md`（キャラ、口調、行為のルール）、この文書、喘ぎ声のスキル、語彙のスキル（spicy_novel_vocab_jp の必要なカテゴリだけ）、前の章の本文
- 本文は `本文/` に、プロットと同じファイル名で置く
- 本文で初めて決まった細かい事実（部屋の様子、会話で出た話、呼び方の変化など）は、`本文/これまでの本文メモ.md` に章ごとに書き足す。書く前に照らし合わせて、前の本文と食い違わないようにする

**書いたあと、出す前の確認**
- この文書のルール、`設定資料.md` の行為のルールに合っているか
- まいが言いそうにない言い方、不自然な言い回し、言葉の誤用がないか
- まいの性格が一つの面に寄っていないか。モードのように切り替わっていないか。我に返っていないか
- 体勢の矛盾、状況説明になっている文、感情の乗っていない場面がないか
- えずきや嗚咽が、嫌がっている声に読めていないか。吐くところまで行っていないか
- 同じ言い回し、同じ性器語、同じ擬音の繰り返しがないか（spicy_novel_vocab_jp の運用ルールで監査する）
- 前の章との食い違い（呼び方、口調、誰が何を知っているか）がないか
- 読んで抜けるか
