# アウトライン

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> 全体の骨組み。各本の中身は `企画会議.md`、前提は `企画メモ.md` と `世界観設定.md`。

## 全体

```
序章：再会 → 〇〇が遅れて来る → 切り出し → 企画会議 → 1人ずつ軽く打ち合わせ → 解散
本編：20本（1本＝1章。それぞれ独立。時系列は関係なし）
終章：打ち上げ
```

## 序章：再会と企画会議

| 項目 | 内容 |
|---|---|
| きっかけ | 〇〇が、4人と自分だけのグループ（LINE）を新しく作って、一斉に連絡する。事務所の会議室に呼ぶ。文面ではAV撮影のことは伏せる（何の用かは会議室で明かす） |
| 連絡の文面（案） | 〇〇「みんな久しぶり。ちょっと話したいことがあって、来週の水曜14時、事務所の会議室に来てもらえないかな。たいした話じゃないです」。グループができたこと自体に4人が反応する（まなはすぐ「行く！なになに！？」、あすかは最後に少し遅れて「行けます」など） |
| 集まり方 | 4人そろって会議室に集まる。4人は遅刻しない。みんな時間どおりだが、着くタイミングは少しずつずれる。着く順番は特に決めない（書くときに適当に）。先に来た人と、あとから来た人との間で、1人ずつ小さな再会が起き、世間話をする |
| 着く順番 | あすか（一番に来て、端の席）→ まい（モデル同士で撮影現場の話）→ なな（3人で卒業後の生活の話）→ まな（時間ちょうどに駆け込む。バラエティの話でにぎやかに） |
| 〇〇 | 4人でしばらく世間話をしていると、遅れてくる。現役メンバーのマネージャーもしていて、相手もしているから。来たところで、4人と〇〇で軽口を言い合う。現役メンバーのことは悪く言わず、羨ましさがにじむくらい（「いいなあ、今の子たち」など） |
| 空気 | 4人は卒業時期がばらばらなので、4人同士も久しぶり。ちょっとした同窓会のよう。〇〇と久しぶりに会えた嬉しさ |
| 切り出し | 全員そろったところで、〇〇が「卒業記念AV撮影」を切り出す。卒業してからだいぶ経っているので、「卒業記念」より「記念」寄りの言い方（「卒業したとき、こっちは何もできなかったから、遅くなったけど、記念に」）。4人は「ヤバくない？」と軽口を言いながらも、前のめりで「いいかも」となる |
| 序章の分量 | 本編に入るための章なので、全体を軽く。世間話は近況をひと言ずつ。小ネタは1人1つまで |
| 企画会議 | 〇〇が「1人5本、組み合わせは自由」と言う。4人が選ぶところは、さっくり流す。〇〇が渡された紙で確認して、いくつかに軽く反応する。そのあと、「ちょっと聞いてみたい」くらいの軽さで1人ずつ少し聞く（「面接」という言い方はしない） |
| 企画会議の空気 | 4人とも興奮している。自分がやりたいことを自分で選べるから。それと、現役のころから何年か経って、久しぶりに〇〇とできるから |
| 企画会議での動き（案） | 4人とも、それぞれの人柄のまま興奮している。まな：やりたかったものを見つけて、素直に嬉しそうにする（卒業後のまなは落ち着いた大人。はしゃぎすぎない）。人の分にも勧める。まい：迷うのは、どれも捨てられないから。「え、待って、これも……これも」と欲張って、5本に収まらない。なな：普段は静かなのに、組み合わせを考えはじめると止まらなくなって、早口になる（夢中になると言葉が増える人）。あすか：黙っているようで、ペンが止まらない。「……これ、ずっとやってみたかった」と、珍しく自分からぼそっと言う。4人とも、ときどき〇〇の反応をうかがう。昔の〇〇とのことや、下ネタでも盛り上がる。決まったら紙を〇〇に見せ、〇〇が1本ずつ読んで台詞で反応する |
| 打ち合わせで聞く本 | まい：デート（一回も普通のデートをしたことがなかったから）、アナル（絶対無理と思っていたから、記念に）。なな：甘やかし搾精（いつも甘やかしてもらっていたから、最後くらい自分が）。まな：時間停止（反応しちゃだめなんて自分には一番無理だから、逆にやってみたい）、花嫁。あすか：メイド＋顔射（一番やらないことだから。顔射はメイクや髪が汚れるから本当は嫌、でも記念） |
| 終わり方 | 打ち合わせのあいだ、ほかの3人は外で待つ。全員が終わったら、〇〇が4人に「じゃあ、撮影の日は連絡するね」。4人が一緒に帰っていって、本編へ |
| 打ち合わせ | 企画会議のあと、〇〇が1人ずつと軽く話す。がっつり決めるのではなく、「なんでこれにしたの」などを聞く。聞くのは1人1〜2本（一番やりたいもの、やりたくない枠など） |
| 本編とのつながり | 本番（撮影）は、打ち合わせの数日後。本編の各章は、撮影当日から始まる |
| 流れ | 大まかな流れは、`文体サンプル.md` のサンプル1（序章）の感じ。ただし、サンプルの台詞や出来事は使わない |
