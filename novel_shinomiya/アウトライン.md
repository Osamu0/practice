# アウトライン

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> 全体の骨組み。各本の中身は `企画会議.md`、前提は `企画メモ.md` と `世界観設定.md`。

## 全体

```
序章：再会 → 〇〇が遅れて来る → 切り出し → 企画会議 → 1人ずつ軽く打ち合わせ → 解散
本編：20本（1本＝1章。それぞれ独立。時系列は関係なし）
終章：打ち上げ
```

## 序章：再会と企画会議

| 項目 | 内容 |
|---|---|
| きっかけ | 〇〇が、卒業した4人に一斉に連絡する。事務所の会議室に呼ぶ。連絡の文面では、AV撮影のことは伏せる（何の用かは会議室で明かす） |
| 集まり方 | 4人そろって会議室に集まる。4人は遅刻しない。みんな時間どおりだが、着くタイミングは少しずつずれる。着く順番は特に決めない（書くときに適当に）。先に来た人と、あとから来た人との間で、1人ずつ小さな再会が起き、世間話をする |
| 〇〇 | 遅れてくる。現役メンバーのマネージャーもしていて、相手もしているから |
| 空気 | 4人は卒業時期がばらばらなので、4人同士も久しぶり。ちょっとした同窓会のよう。〇〇と久しぶりに会えた嬉しさ |
| 切り出し | 全員そろったところで、〇〇が「卒業記念AV撮影」を切り出す。切り出し方は、「卒業のときに卒コンとかはやったけど、こっちはそういうのがなかったから、記念にどうかな」という感じ。4人は「ヤバくない？」と軽口を言いながら、乗り気になる |
| 企画会議 | 一覧を見ながら、4人で話し合ったり、「これいいかも」と言い合ったりしながら、それぞれ組み合わせを決めていく。決まったものを〇〇に見せる。ここで読者に、20本がどんな本かがわかる |
| 打ち合わせ | 企画会議のあと、〇〇が1人ずつと軽く話す。がっつり決めるのではなく、「なんでこれにしたの」などを聞く。聞くのは1人1〜2本（一番やりたいもの、やりたくない枠など） |
| 本編とのつながり | 本番（撮影）は、打ち合わせの数日後。本編の各章は、撮影当日から始まる |
| 流れ | 大まかな流れは、`文体サンプル.md` のサンプル1（序章）の感じ。ただし、サンプルの台詞や出来事は使わない |

**未定**
- 〇〇の連絡の文面（AV撮影は伏せる、という方針だけ決定）
- 企画会議で、誰が何を言うか

## 本編：20本

`企画会議.md` の20本。各章は独立した1本として読める。章の並びは読みやすさで決める（撮影の順番ではない）。

## 終章：打ち上げ

| 項目 | 内容 |
|---|---|
| 場面 | 撮影がすべて終わったあとの打ち上げ。撮った映像を本人に渡す |
| 空気 | 4人と〇〇で笑って終わる |
| 「たまには構ってほしい」 | 打ち上げの会話の中で、軽く出る一言。本気のお願いでも、締めの決め台詞でもない。「たまにはOGのことも構ってよ」くらいの温度。誰が言ってもいい |
| 場所 | どこでもいい（書くときに決める） |
| 締め方 | 打ち上げが盛り上がったまま、フェードアウトしていく |
