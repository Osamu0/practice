## 「相手」の業務

| 項目 | 内容 |
|---|---|
| 目的 | メンバーの性欲発散のため |
| 立場 | マネージャーの業務の一つ。運営公認 |
| 周りの認識 | メンバーにとって周知の事実 |
| 世間 | バレていない。ファン（オタク）に知られたら、アイドルを続けられない |
| 頼み方 | メンバーがムラムラしたら、〇〇に頼む |
| 場所 | 決まっていない。事務所の一室、ホテル、テレビ局の楽屋、大部屋の楽屋など、いろいろ |
| 中出し | している |
| 対象 | 卒業生4人だけでなく、現役メンバーも（この話には現役メンバーは出てこない） |

**裏設定**
- もともとは、アイドルのスキャンダル（外の男性との恋愛や関係）を防ぐために、上からの指示で始まった。
- 4人が「相手」をしてもらい始めた頃は、まだそのスキャンダル防止のためのものだった。
- 今は、メンバーの性欲発散のほうがメインになっている。そのため、スキャンダル防止という当初の目的は形骸化している。

## メンバーの受け止め方（空気）

- 「相手」の関係（現役中、そして今の現役メンバー）について、「世間一般の常識からすれば、よくないことだ」という客観的な事実は、メンバー全員（4人以外も）がわかっている。
- でも本音では、「誰かに迷惑をかけているわけでもないし、ぶっちゃけ悪いことだとは思っていない」。
- 「世間的にはダメでも、別にいいよね」という、緩い空気がある。
- これは、メンバーの自発的な欲求から来ている。

**書かないこと**
- 倫理観が麻痺している、極限のストレスでおかしくなっている、といった異常として書かない。
- 単なるメンテナンス（作業・処理）として扱っている、とも書かない。
- 罪悪感に苦しむ、葛藤する、といった重さも出さない。わかったうえで、軽く受け流している。

> 企画会議の「ヤバい（笑）」は、この話とは別。「相手」の関係の良し悪しではなく、「卒業記念にAVを撮る」という発想に対する、ちょっとした軽口。本気で引いているわけでも、深い意味があるわけでもない。

## 4人にとっての〇〇とのセックス

> ここに書くのは、主に現役中のこと。卒業後は担当から外れ、しばらく会っていない（撮影は、卒業してしばらく経ったあと）。

- 現役中から、ずっと〇〇に相手をしてもらっていた。セックス自体は慣れた日常。照れや抵抗はない。
- 「ヤバい（笑）」は、それを「卒業記念のAV」にするという発想へのツッコミ。企画会議のときに言う。撮影のたびには言わない。
- 撮影では、それぞれが自分で選んだ企画を楽しむ。初めての人のような緊張やためらいは書かない。
- 体の関係があるので、4人とも〇〇に多少は好意がある。
- 頼むのは気軽。「今日いい？」「いいよ」くらいで済む。申し訳なさや、ためらいは書かない。

## 女の性欲発散

- 「相手」の中心にあるのは、女の側の性欲。4人は、自分がしたいから求める。〇〇はそれに応える側。
- 性欲を発散する場なので、4人とも遠慮しない。気持ちいいことを素直に求め、喘ぎ声も我慢しない。
- 自分が気持ちよくなるだけではない。相手をしてくれている〇〇のことも、気持ちよくさせる。してもらうだけの一方通行にしない。
- 〇〇は気持ちよくさせられると、素直に「気持ちいい」と言う（`キャラクター設定.md`）。それが4人にとっても嬉しい。
- 喘ぎ声は、人柄ごとに出方を変える（各ヒロインの「〇〇との関係（現役中）」を参照）。作品全体は、喘ぎ声レベル2〜3を基本にする（`spicy_novel_jp` の `references/aegigoe_skills.md`）。
