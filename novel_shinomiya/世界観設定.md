## 「相手」の業務

| 項目 | 内容 |
|---|---|
| 目的 | メンバーの性欲発散のため |
| 立場 | マネージャーの業務の一つ。運営公認 |
| 周りの認識 | メンバーにとって周知の事実 |
| 頼み方 | メンバーがムラムラしたら、〇〇に頼む |
| 場所 | 決まっていない。事務所の一室、ホテル、テレビ局の楽屋、大部屋の楽屋など、いろいろ |
| 中出し | している |
| 対象 | 卒業生4人だけでなく、現役メンバーも（この話には現役メンバーは出てこない） |

**裏設定**
- もともとは、アイドルのスキャンダル（外の男性との恋愛や関係）を防ぐために、上からの指示で始まった。
- 今は形骸化していて、当初の目的としての意味はなくなっている。仕組みだけが残っている。

## 4人にとっての〇〇とのセックス

- 現役中から、ずっと〇〇に相手をしてもらっていた。セックス自体は慣れた日常。照れや抵抗はない。
- 「ヤバい（笑）」は、それを「卒業記念のAV」にするという発想へのツッコミ。企画会議のときに言う。撮影のたびには言わない。
- 撮影では、それぞれが自分で選んだ企画を楽しむ。初めての人のような緊張やためらいは書かない。
