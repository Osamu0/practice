## コンセプト

- 卒業コンサートなど、表の卒業はもう済ませた。
- でも、〇〇との「こっちの卒業式」は、まだしていなかった。
- だから、それをする。それが「卒業記念AV撮影」。
- ヒロインたちは「ヤバいよ（笑）」と言いながらも、乗り気。
  - 「ヤバい」の中身は、「卒業記念とはいえ、そんなことをするのってヤバくない？（笑）」ということ。企画そのものへの、ちょっとした軽口。本気で引いているわけでも、深い意味があるわけでもない。
  - 言うのは、会議室・企画会議のとき。撮影のたびに言うわけではない。
  - 4人とも、現役中から〇〇に相手をしてもらっている。〇〇とセックスすること自体は、慣れた日常（業務）。だから、セックスそのものへの照れや抵抗はない。ヤバいのは、それを「卒業記念のAV」にするという発想のほう。
  - 撮影では、それぞれが自分で選んだ企画を楽しむ。初めての人のような緊張やためらいは書かない。

## 書き方

| 項目 | 内容 |
|---|---|
| 視点 | 三人称 |
| AV撮影の扱い | 話のネタ・アイデアとしての設定。カメラや撮影を意識しすぎない。毎回カメラワークや画面の中を書かなくていい |
| 撮影の日程・場所 | 全体では決めない。本目ごとに、その本に合わせて決める |
| 〇〇の心の声 | 書かない。台詞と態度で見せる |
| 章の分け方 | 1本＝1章（4人×5本＝20章）。前後に序章（再会・会議室・企画会議）と終章 |
| 本編の時系列 | 関係なし。AVは1本ずつ撮るので、各章はそれぞれ独立した1本として読める。章の並びは、撮影した順番を表さない |
| 本編の1章 | それだけで1本のエロ作品。その章で抜けるようにする。読者は序章を読んでいる前提（本編どうしの時系列はないが、序章のあとの話）。〇〇とヒロインの関係や撮影の事情は、本編で描き直さなくていい |
| 文字数 | 決めない。その本の内容で、そのときに決まる |
| プロットや設定の台詞 | 草案。本文で必ず使わなくていい。本文を書くときに、流れに合わせて自由に変える・足す・消す。そのまま使いたい台詞は、プロットで「決め台詞」と書いたものだけ |

## 読後感・空気

- **読後感：「抜けた」。** 読み終わったとき、エロくて抜けた、が一番に残る作品にする。
- エロ描写を中心に置く。ただし、デートや会話などのエロ以外の場面も、それなりに長くていい。
- 気持ちの軸は、「卒業で関係が終わる」寂しさではなく、「卒業してから、久しぶりに〇〇と会えた」嬉しさ。
- 空気は、背徳感より楽しさと親しさ。「ヤバい」と笑い合いながら、本気で気持ちよくなる。
- 〇〇の「甘やかし上手」「素直さ」「プロの裏方」が、最後の仕事として出る。
