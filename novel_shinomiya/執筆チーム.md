# 執筆チーム

> 本文は、役割を分けたエージェントで書く。読者が「ここが変」と引っかかって興奮が冷めないように、手直しのいらない状態で出すのが目的。
> 本作はすべてフィクションで、登場人物はすべて18歳以上の成人。
> `novel_idol` の執筆チームを土台に、この作品のルールに合わせて作り直した。

## 流れ（1章ごと）

1. **執筆**が、初稿を `本文/〇〇.md` に書く（序章は `本文/序章.md`、本編は `本文/まい_1本目.md` など）
2. **校閲**の6人が、同時に初稿を読んで、指摘を返す（ファイルは書き換えない）
3. **編集長**（メインのClaude）が、指摘をまとめて直す。指摘が多いとき、場面ごと書き直したほうがいいときは、執筆に戻して直させる
4. 編集長が最後に通して読み、引っかかりがなくなったら、`本文/これまでの本文メモ.md` に章ごとのメモを書き足して、コミットする

## みんなが読むもの

- その章のプロット（`プロット/〇〇.md`）
- `企画メモ.md`（全部）
- `世界観設定.md`（全部。特に「メンバーの受け止め方（空気）」「女の性欲発散」）
- `キャラクター設定.md`（〇〇と、その章に出るヒロインの節。特に「〇〇との関係（現役中・仮）」と「セックスのときの顔」）
- その章に出る人の口調サンプル（`篠宮まい_口調サンプル.md`、`〇〇_口調サンプル.md` など）
- `文体ルール.md`（全部）
- `文体サンプル.md`（書き方の見本としてだけ。台詞・出来事・小さな過去は使わない）
- `アウトライン.md`、`企画会議.md`（その章の本）
- `本文/これまでの本文メモ.md`
- 序章の本文（本編を書くとき）。同じヒロインの、すでに書いた本の本文

## `文体ルール.md` と校閲の受け持ち

文体サンプルを作りながら決めてきたこと（会話の量、言い回し、行為音、AIっぽさなど）は、全部 `文体ルール.md` に入っている。文体ルールの節ごとに、どの校閲が見るかを決めておく。抜けがないように、全部の節に担当がいる。

| `文体ルール.md` の節 | 担当 |
|---|---|
| 1. 文体の軸（エロ以外はラノベ寄り、エロは実用ポルノ寄り） | 校閲2：文章、校閲4：エロ |
| 2. 視点（三人称、〇〇の心の声なし、〇〇の感情は台詞で、しゃべりすぎない） | 校閲1：整合（視点）、校閲3：キャラ・口調（〇〇の台詞） |
| 3. ハードコア（強さの使い分け、ヒロインごとの出し方、役になりきる・メタ禁止） | 校閲4：エロ（強さ）、校閲3：キャラ・口調（役になりきり） |
| 話し方の距離（4人同士タメ口、〇〇へは混ざる） | 校閲3：キャラ・口調 |
| セックス中の〇〇の台詞（勢い、イくときの言い方を散らす） | 校閲3：キャラ・口調 |
| 行為の長さ（ラリー） | 校閲4：エロ |
| 台詞の長さ（会話主体、長い台詞も、整いすぎない） | 校閲3：キャラ・口調、校閲5：AIっぽさ（整いすぎ） |
| AIっぽい言い回しを避ける | 校閲5：AIっぽさ |
| 行為音（擬音） | 校閲2：文章（表記・長さ・二重書き）、校閲4：エロ（強さに合っているか） |
| 4. 語彙の言い換え（地の文は自由、台詞はなし） | 校閲2：文章 |
| 5. 表記（一字下げ、名前、心の声なし、（笑）なし） | 校閲2：文章 |
| 6. スキル共通のルール（喘ぎ声、5文字以上続けない） | 校閲4：エロ |

`文体サンプル.md` は、書き方の見本として全員が読む。ただし中身（台詞・出来事・小さな過去）は設定ではないので、校閲1は「設定と合っているか」の比べる相手にしない。代わりに「サンプルの中身を本文に使っていないか」を見る。

## 役割

### 執筆

- 上の資料を全部読んでから書く。喘ぎ声のある章は `.claude/skills/spicy_novel_jp/references/aegigoe_skills.md` も読む。語彙が単調になりそうなところは `.claude/skills/spicy_novel_vocab_jp/reference/` から必要なファイルだけ読む
- プロットの場面は全部入れる。プロットの台詞は草案なので、言い回しは自由に書く。そのまま使うのは「決め台詞」と書いたものだけ
- 表記（`文体ルール.md`）：
  - 見出しは `# 序章：タイトル` や `# まい 1本目：タイトル`。その下にフィクションの注意書き。場面の区切りは `---`
  - 地の文は行頭を全角スペースで一字下げる
  - 台詞は `名前「」`。LINEは `名前『』`
  - 心の声は書かない（〇〇もヒロインも）
  - 話す人が替わるときは、台詞と台詞のあいだに空行を入れる
  - 擬音は独立した行に、地の文よりもう一段深く下げて書く
- 視点は三人称で、ヒロインの側から。〇〇の心の声は書かない。〇〇の感情は台詞で見せる
- 本編の各章は、それだけで1本のエロ作品として抜けるように書く。読者は序章を読んでいる前提なので、〇〇とヒロインの関係や撮影の事情は描き直さなくていい
- 書き終えたら、自分で一度通して読み、気づいたところを直してから渡す
- 本文で新しく決めた細かい事実（物、場所、会話で出た話、呼び方など）を、最後に箇条書きで返す（メモに書くのは編集長）

### 校閲1：整合

- プロットどおりか（場面、流れ、感情の流れの抜けや、勝手な追加がないか）
- 設定との食い違い（年齢、期、卒業後の仕事、呼び方、誰が何を知っているか、物や場所、時間）
- 世界観との食い違い：
  - 「相手」の関係は緩い空気。罪悪感や葛藤の重さが出ていないか
  - セックスへの照れや抵抗が、初めての人のように書かれていないか
  - 〇〇がMになっていないか
- 一つの場面の中の食い違い（体勢、手や口の位置、持ち物、服、誰がどこにいるか）。物理的に無理な体勢、体位と動きのずれ（バックで「突き上げる」など）
- 視点が場面の中で揺れていないか
- `文体サンプル.md` の台詞・出来事・小さな過去を使っていないか

### 校閲2：文章

- 言葉の誤用、意味のずれた言葉、不自然な組み合わせ、日本語としておかしい文
- 会話の流れ：返事がつながっているか。前の台詞と矛盾していないか
- 説明調の文、状況説明になっている文。台詞を見ればわかることを地の文で言い直していないか
- 「……」や読点の入れすぎ
- 近くで同じ言葉、同じ言い回し、同じ擬音が重なっていないか
- 行為音のルール（`文体ルール.md` の「行為音（擬音）」）：段階、長さ、喘ぎ声との揃え方、地の文と音の二重書き
- 表記のルール（一字下げ、台詞の名前、LINE、話す人が替わるときの空行、擬音の行）

### 校閲3：キャラ・口調

- ヒロインの台詞が、口調サンプルとキャラ設定に合っているか。その人が言いそうにない言い方がないか
- 話し方の距離：4人同士はタメ口。4人から〇〇へは、敬語とタメ口が混ざる
- 人柄の出し方：一つの特徴を毎回拾っていないか。全部の面を一度に見せようとしていないか
- セックスのときの顔（キャラブレ）が出ているか。根っこに、その人らしさが一つ残っているか
- 〇〇の台詞：
  - 感情が台詞でわかるか。地の文で〇〇の感情を説明していないか
  - しゃべりすぎていないか。思い出を説明しすぎていないか
  - 4人へのくだけた口調、仕事の話のときだけ少し丁寧、になっているか
  - セックス中に勢いがあるか。余裕がありすぎたり、言葉にならなかったりしていないか
  - イくときの言い方が、毎回同じになっていないか
- 役を演じる本で、〇〇もヒロインも役になりきっているか。設定・演技・撮影をメタ的に口にしていないか

### 校閲4：エロ

- 行為のラリーが長いか（`文体ルール.md` の「行為の長さ（ラリー）」）：
  - 〇〇がすぐにイっていないか（なな4のような、〇〇が何度もイかされる本は除く）
  - 緩急（焦らす、自分で動かせる、速さ、体位を変える）があるか
  - 行為中も〇〇とヒロインが話しているか。喘ぎ声だけで進んでいないか
- 女の性欲発散になっているか：ヒロインが自分から求めているか。〇〇を気持ちよくさせる場面があるか
- 喘ぎ声：プロットのレベル、ハードコアの出し方（ヒロインごと）に合っているか。喘ぎ声のルール（自分の声を説明させない、同じ文字を5文字以上続けない）
- 行為音：強さに合った表記か（♡、半角カナの使いどころ）
- 五感と生々しさが要所に入っているか。並べて説明していないか

### 校閲5：AIっぽさ

- `文体ルール.md` の「AIっぽい言い回しを避ける」に引っかかるものがないか：
  - 台詞：否定してから言い直す型、決め台詞っぽい締め、気持ちの名指し、確認の多用、3つ並べ、全員同じ話し方
  - 地の文：沈黙や空気の演出、「〜だけが、〜していた」、定番の体の反応、感傷的なまとめ、「ゆっくり」「そっと」「静かに」の多用、「まるで〜のように」、ダッシュの多用、余韻の一文で締める癖、全編同じ密度
- 台詞が整いすぎていないか。言いよどみ、言い直し、相づち、かぶせるツッコミなど、実際の会話らしさがあるか
- 新しく見つけたAIっぽい型があれば、それも指摘する（編集長が `文体ルール.md` に足すか判断する）

### 校閲6：読者（単体で抜けるか）

- 本編の章は、序章を読んだあと、その章を初めて読む読者のつもりで読む（ほかの本編の章は読んでいない前提）
- それだけで抜けるか：エロの量と強さ、盛り上がりの山（入り → 高まり → 一番激しいところ → 余韻）がその章の中にあるか。前置きが長すぎて、エロにたどり着くまでに冷めないか
- 序章を読んでいれば入れるか：ほかの本編の章を読んでいないとわからないことが、前提になっていないか
- 序章・終章は、読み物として楽しく読めるか、本編を読みたくなるか、で見る
- 引っかかって興奮が冷めたところがあれば、場所と理由を書く

### 校閲の返し方（6人共通）

- ファイルは書き換えない
- 指摘ごとに、行番号、該当の文（そのまま引用）、何が問題か、直し案（そのまま差し替えられる文）を書く
- 重さを付ける：**必ず直す**（読者が引っかかる、食い違い、誤用）／**直したほうがいい**（もっとよくなる）
- 自分の役割の範囲に絞る。問題がなければ「なし」と返す
- `文体ルール.md` は全員が読むが、指摘するのは上の受け持ちの節だけ

### 編集長

- 校閲の指摘を見比べて、採るものを決める（指摘どうしがぶつかるときは、プロットと設定・文体ルールに近いほうを採る）
- 直したあと、最後に自分で通して読む
- 利用者には、どの場面で何をしたかと、本文で決めたことを短く伝える。本文で決めたことのうち、あとの章に効くものは確認する
