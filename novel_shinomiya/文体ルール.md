# 文体ルール

> 読後感は「抜けた」（`企画メモ.md`）。それに合う文体にする。

## 1. 文体の軸

| 場面 | 文体 |
|---|---|
| エロ以外（再会、デート、企画会議、打ち上げなど） | ライトノベル寄り。会話が中心で、テンポよく。4人の人柄の違いと、緩い空気を台詞で見せる。それなりに長くていい |
| エロの場面 | 実用ポルノ寄り。地の文は短く、台詞・喘ぎ声・行為音（擬音）を多めに。語彙はぼかさず直接的に |
| ハードコアポルノ文体 | 使い方は検討中（下の「3. ハードコア」） |

## 2. 視点

- 三人称。ヒロインの側から描く。
- 〇〇の心の声は書かない。〇〇について分かるのは、台詞と行動と、ヒロインが感じたことだけ。

## 3. ハードコア（検討中）

- 汚喘ぎ・アヘ声（喘ぎ声レベル3〜4）、淫語の連発、局部や体液の細かい描写、理性が崩れていく描写。
- どこで使うかは未定。

## 4. 表記

- 台詞の前に、話している人の名前をつける。心の声も同じ（ヒロインのみ。〇〇の心の声は書かない）。

```
まい「〇〇さん、今日いい？」

〇〇「いいですよ。何時にします？」
```

- 台詞に「（笑）」は入れない。笑いは地の文や「あはは」「ふふっ」などの声で表す。

## 5. スキル共通のルール

- 喘ぎ声は、`spicy_novel_jp` スキルの `references/aegigoe_skills.md` を参照する。喘いでいる最中に、自分の声を説明させない。
- 同じ文字を5文字以上続けない（特に喘ぎ声）。
- 語彙が単調になったら、`spicy_novel_vocab_jp` スキルで言い換える。
