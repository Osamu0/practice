# 文体ルール

> 読後感は「抜けた」（`企画メモ.md`）。それに合う文体にする。

> 文体の土台は、スキル `spicy_novel_writing_jp`（`.claude/skills/spicy_novel_writing_jp/`）。作品をまたいで同じことはスキルに移した。ここには、この作品だけで決めたことを書く。節の名前は、口調サンプルや執筆チームから参照されているので残してあり、中身がスキルにある節は、スキルのファイルを指している。

## 1. 文体の軸

| 場面 | 文体 |
|---|---|
| エロ以外（再会、デート、企画会議、打ち上げなど） | ライトノベル寄り。会話が中心で、テンポよく。4人の人柄の違いと、緩い空気を台詞で見せる。それなりに長くていい |
| エロの場面 | 実用ポルノ寄り。地の文は短く、台詞・喘ぎ声・行為音（擬音）を多めに。語彙はぼかさず直接的に |
| ハードコアポルノ文体 | 各本のピーク、またはハード寄りの本の全体で使う（下の「3. ハードコア」）。AV撮影という設定なので、あっていい |

## 2. 視点

- 三人称。ヒロインの側から描く。
- 〇〇の心の声は書かない。〇〇について分かるのは、台詞と行動と、ヒロインが感じたことだけ。
- ただし、〇〇の感情は見せる。嬉しさ、照れ、興奮、懐かしさを、**台詞で**わかるようにする。地の文で〇〇の感情を説明しない（×「照れくさそうに笑った」「声が上ずっていた」）。読者が〇〇の台詞に乗れるようにするため。
- 〇〇の台詞は、ありきたりな言葉（「やば」「かわいすぎ」だけ）で済ませない。かといって、昔の思い出を説明しすぎない。2人の歴史は、短い一言ににじませる（「知ってる」「いつも一回で帰ってたじゃん」）。
- 〇〇が説明しすぎない。整いすぎた台詞にしない。口数を減らすことではない。温かく一言添えるのはよい（「〜だしね」「〜からね！」）。
- 〇〇の行動（なでる、抱きとめる など）は、地の文で書いてよい。

## 3. ハードコア

- 汚喘ぎ・アヘ声（喘ぎ声レベル3〜4）、淫語の連発、局部や体液の細かい描写、理性が崩れていく描写。

| 強さ | 使う場面 | 喘ぎ声 |
|---|---|---|
| 実用ポルノ（基本） | エロの場面の大部分 | レベル2〜3 |
| ハードコア | 各本のピーク。ハード寄りの本では全体に | レベル3〜4 |

- ハード寄りの本の例：まい3（アナル）、なな5（女捜査官）、あすか2（拘束）、まな3（時間停止の解除絶頂）。どの本をハード寄りにするかは、本ごとに決める。
- 甘めの本（デート、花嫁など）は、ピークだけにとどめる。
- ハードコアの出し方は、ヒロインごとに変える（書き方の見本は `文体サンプル.md` のサンプル3〜6。中身は本文と関係ない）。
  - まい：上品な人が下品な言葉でねだる落差。淫語の量で激しさを出す（レベル3）
  - なな：ノリノリの演技が、本気の快感に飲まれていく（レベル3〜4）
  - まな：止まっている間に溜めて、解除で一気に崩れる（解除の瞬間にレベル4）
  - あすか：表情を崩さない人が、理性ごと崩れる。呂律が回らなくなる（レベル4）。終わったあとに甘える

- 企画（役を演じる本）の最中は、〇〇もヒロインも役になりきる。設定・演技・撮影のことをメタ的に口にしない（×「設定、守るね」「捜査官なので」）。
- 役になりきるので、本人の人柄（ヒロインの「セックスのときの顔」と「根っこに残るもの」、〇〇の甘やかし上手など）は役に持ちこまない。役の性格で動く。本人から引き継ぐのは体（見た目、敏感なところ）だけ。
- 本の種類は三つ。どれにするかは、各本のプロットの「関係性」に書く。
  - **役なし**（まい1本目）：素の2人で、状況も本当のこと
  - **役あり**（まい2本目）：別人になりきる。本人の人柄は持ちこまない
  - **本人役**（まい4本目）：人柄・呼び方・関係は本人のまま、状況だけが作りもの（媚薬が本当に効く、など）。ドラマの本人役と同じ。作りものの状況を本当のこととして書き、「演技」「設定」は口にしない
- 役を演じない本もある（まい1本目のデートは、素の2人のまま）。どの本が役ありかは、各本のプロットの「関係性」に書く。

## 話し方の距離

- 4人は全員1期生（同期）。4人同士はタメ口。あすかも、年下だが同期なので敬語は使わない。
- 4人から〇〇へは、敬語とタメ口が混ざる。年上のマネージャーへの敬語が残りつつ、仲がいいのでタメ口も出る。

## セックス中の〇〇の台詞

- 余裕のある、落ち着いた言い方にしない。かといって、余裕がなくなりすぎて言葉にならないのも違う。
- 勢いを出す。〇〇も興奮していて、自分から求めている。息は上がっているが、言葉には押しの強さがある（「ほら、腰、逃げないで」）。
- イくときの言い方は、毎回同じにしない。場面や相手で変える。言葉そのものより、勢いがあるかどうかが大事。お伺いを立てるような、丁寧な確認にはしない。

| 言い方 | 例 |
|---|---|
| 出る | 「あ、出る、出る……っ」「奥、っ……奥に出る……っ！」 |
| 出そう | 「やば、もう出そう……っ」 |
| 出す | 「中に出す……っ」「全部、奥に出すから……っ」 |
| 出すよ | 「出すよ、っ、奥に……全部……っ！」（言い切りの勢いで） |
| イく | 「イく、っ……中、イく……っ」 |
| 名前を呼ぶ | 「まいちゃん、っ……まいちゃん……っ！」 |
| もう無理 | 「ごめん、もう無理……っ」 |

## 行為の長さ（ラリー）

- 〇〇はすぐにイかない（体力があり、長く続けられる）。ヒロインが何度かイってから。
- 行為の途中を長くする。台詞・喘ぎ声・行為音のやり取り（ラリー）を何往復も重ねる。
- 途中に緩急をつける：止まって焦らす、ヒロインに自分で動かせる、速さを変える、体位を変える、前も後ろもいじる、など。
- 行為中も〇〇が話す。ヒロインが返す。喘ぎ声だけで進めない。
- ヒロインがイっても、〇〇は止まらないことがある。イったあとの敏感なところを続けて責める。
- 〇〇がイくのは、一回で終わりとは限らない。1本の中で何回イってもいい（フェラやパイズリで一回、1回戦で一回、2回戦で一回、など）。ただし、どの一回も、そこまでにヒロインの側の盛り上がりを積んでから。すぐイく、にはしない。

## 台詞の長さ

- 会話を主体にする。〇〇もヒロインも、お互いが話す。どちらかが一方的に話し続けない。
- 話す量は、タイミング・内容・人によって変わる。短い往復のときもあれば、誰かがひと息に長く話すときもある（近況、好きなものの話、ずっと思っていたこと など）。長い台詞は〇〇にもヒロインにもある。長くても、説明くさくせず、言いよどみや話し言葉のまま。
- 整いすぎない。言いよどみ、言い直し、相づち、相手の言葉にかぶせるツッコミなど、実際の会話らしさを残す。

## 台詞は話し言葉で書く（全部の本で）

> スキル `spicy_novel_writing_jp` の `reference/dialogue.md`（話し言葉、台詞の温度、声の区別、♡と笑、「…」「、、、」）と `reference/author_edits.md`（まい1本目で作者が直した実例）のとおり。役を演じる本でも同じ（役の口調のまま、話し言葉にする）。

この作品だけのこと：
- 声の区別：くだけた語尾や「笑」「ー」を全員が同じように使わない。人ごとの語尾の癖を残す（例：まい「〜もん」「〜の！」「…かも」／〇〇「〜じゃん」「〜だしね」「〜からね」）。ほかのヒロインは、口調サンプルの空気から、その人の崩し方を決める
- まいの〇〇への敬語は、ほとんど出さない（照れたときの「会ってすぐ言います？笑」くらい）

## 会話と場面の組み立て（序章の見直しから）

> 序章の初稿を利用者が読んで出た直しを、本編でも気をつけるポイントとしてまとめた。

| ポイント | 中身 |
|---|---|
| 章の目的に合わせた分量 | エロ以外の場面は、目的（再会、前振り、打ち合わせ）が果たせたら次へ進む。本編なら、エロに入るまでを長くしすぎない。序章は本編に入るための章なので軽く |
| 小ネタを盛りすぎない | 思い出話や近況の小ネタは、場面に1〜2つまで。たくさん並べると、説明が長いのと同じになる |
| 回数・数字のくり返しで笑わせない | 「三回言った」「四回見た」「立ち読みしてから買った」のような、回数や言い直しを重ねるギャグにしない |
| 年相応の落ち着き | 4人は卒業した大人（25〜30歳）。現役アイドルのようなはしゃぎ方にしない。「！」の連発、大声、元気っ子の反応を控える |
| 役割を固定しない | 誰か1人を、いじられ役・ツッコミ役・止め役に固定しない |
| 現役メンバー・グループへの敬意 | 4人も現役のころはお世話になった側。悪く言わない。話題にするときは、懐かしさや羨ましさで |
| ヒロインは前のめり | 企画やエロに対して、笑いながらでも「やってみたい」「いいかも」が先に出る。驚いて笑い崩れる、のような大きな反応にしない |
| 〇〇の気持ちは「離れても気にしていた」 | 4人の近況を知っている、見ている、を自然に出す（「見たよ」「ちゃんと見てる」）。数や証拠を並べて見せない |
| 当たり前のことに驚かない | 自分で呼んだ・決めたことに、わざとらしく反応しない（×自分で呼んだのに「ほんとに四人いる」） |

## 5. 表記

- 地の文は、行頭を一字下げる（全角スペース）。台詞の行は下げない。
- 擬音は独立した行に置き、地の文よりもう一段深く下げる。

- 台詞の前に、話している人の名前をつける。
- 心の声（内心描写）は書かない。〇〇もヒロインも。気持ちは台詞と行動で見せる。

```
まい「〇〇さん、今日いい？」

〇〇「いいよ。何時にする？」
```

- 台詞に「（笑）」（かっこつき）は入れない。
- 台詞の語尾に「笑」「♡」をつけてよい（まい1本目で作者が直した形）。軽口・からかい・照れには「笑」（例：「早すぎ笑」「普通かあ笑」）。甘え・誘い・エロい場面の台詞には「♡」（例：「こっちにしよ♡」「わざとじゃないよ？♡」「まだ、カチカチ♡」）。〇〇の台詞にも使ってよい。♡はピークだけのものではなく、甘い場面なら会話の段階から使う（行為音の♡の使い分けは「行為音」の節のとおり）
- 台詞の頭や途中の「…」（三点）も使ってよい。「……」と混ざってかまわない
- 台詞の約物のそろえ方：
  - 台詞の最後に「。」はつけない（×「できないもんね。」）
  - 台詞の途中の「？」「！」のあとに続けるときは、全角スペースを一つ入れる（○「ほんと？　じゃあ、そうしよ！」）。「？、」にはしない
  - 「笑」「♡」のあとに「。」はつけない。台詞の途中なら全角スペースで区切る（○「早すぎ笑　ちゃんと覚えてたんだ」「気持ちよかった♡　奥、ずんずんって来て」）
