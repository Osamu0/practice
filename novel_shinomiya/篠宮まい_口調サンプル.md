# 篠宮まい 口調サンプル

> キャラを作るための参考資料。セリフとして本文にそのまま使う必要はない。
> ここから口癖・語尾・型を抜き出してなぞるのではなく、全体の空気をつかむために読む。
> サンプル中の「（笑）」は、笑いながら言っているというニュアンスを示すだけのもの。本文では「あはは」「ふふ」などの声で表す。

## 口調のルール

単に語尾へ「〜ね」「〜かな」をつけるだけでは、人物らしさは出ない。話す速さ、言い切る強さ、言葉を探す間、笑いを挟む位置、相手への配慮をセットで考える。

- **柔らかく、自然体**：「そうだね」「そうなんだ」「なんかね」など、相手の話を受け止める言い方がなじむ。
- **少し考えながら話す**：「うーん……」「なんだろう」「そうだなぁ」と、考える時間が言葉に出る。
- **笑いを交えて和らげる**：「ふふっ」「えー、そうなの？（笑）」など、笑顔や軽い驚きが会話に混じる。
- **強く断定しすぎない**：「〜かなって思う」「〜かもしれないね」「私はそう思うな」と、自分の考えとして伝える。
- 「〜ね」「〜かな」「〜だよね」を何にでもつけない。特定の語尾や口癖を、すべての会話で繰り返さない。

## 一人称と呼びかけ

- 一人称は「私」が基本。
- 親しい相手には「ねえ」「ちょっと聞いて」など、自然な呼びかけ。
- 年上・仕事相手には丁寧語を使い、必要以上になれなれしくしない。
- 同年代の友人には敬語を減らし、相づちや軽い冗談を増やす。
- 気を許した相手には、多少くだけた言い方になり、遠慮のないツッコミも出る。
- 距離が縮まるにつれて敬語が減り、会話のテンポが軽くなっていく。ここが大事。

## 場面ごとの言い方

| 場面 | 例 |
|---|---|
| 共感するとき | 「そうだよね」「わかる」 |
| 考えながら答えるとき | 「うーん、どうだろう……」 |
| 少し照れているとき | 「いや、そんなことないよ（笑）」 |
| 自分の意見を伝えるとき | 「私は、こういうのが好きかな」 |
| 親しい相手にツッコむとき | 「いや、なんでそうなるの（笑）」 |
| 真面目に説明するとき | 「それは、ちゃんと考えたほうがいいと思う」 |
| 嬉しいとき | 「えー、嬉しい！ありがとう」 |

普段の柔らかさは保ちながら、話の内容に合わせて言い方を変える。

## 声・話す速さ・間

**声**
- 基本は柔らかく、聞き取りやすい。威圧感のある話し方はしない。
- 落ち着いた説明では、言葉を比較的丁寧に並べる。
- 楽しくなると声に明るさが加わり、笑い声も出やすくなる。
- 驚いたときや、笑いをこらえきれないときは、声の調子が変わる。

**速さ**
- 通常：標準的な速さ。急いで詰め込まず、柔らかく話す。
- 考え中：少し間が空く。「うーん」「なんだろう」と考えをまとめる時間が入る。
- 楽しいとき：反応が早くなる。笑いながら話したり、相手の言葉にすぐ乗ったりする。
- 真剣なとき：冗談や笑いが減り、言葉を選びながら話す。

**間**
- 発言の間を全部埋めない。短い沈黙や言い直しを残す。
- ただし、すべての台詞に三点リーダーを入れない。本当に考えているときや、言葉を探しているときだけ。

「えー……どうだろう。難しいな、それ（笑）」
「うん、そうだね。……でも、私は好きだよ」
「いや、待って（笑）。それはちょっと違うんじゃない？」

## 感情ごとの表現

**嬉しいとき**：表情が明るくなり、声に弾みが出る。隠そうとするより、自然に笑顔になる。
「えー、嬉しい！ありがとう！」
「本当に？　それ、すごく嬉しいんだけど（笑）」

**照れているとき**：一瞬視線を外す。笑ってごまかしたり、相手の言葉を軽く否定したりする。
「もう、やめてよ（笑）」
「いやいや、そんなに言われると恥ずかしいって」
「えー、そんなことないよ（笑）」
「いやいや、褒めすぎだから（笑）」
「……でも、ありがとう。嬉しい」

**真剣なとき**：笑顔は控えめになり、相手の話をよく聞く。責めるより、理解しようとする。
「うん……それは、ちゃんと考えたほうがいいと思う」
「私は、無理しなくてもいいんじゃないかなって思うよ」

**面白いとき**：笑いをこらえようとしても、表情に出てしまう。冗談に乗ったり、少しだけツッコんだりする。
「ちょっと待って（笑）。何それ！」
「いや、面白すぎるんだけど（笑）」

**共感するとき**（相手が失敗や悩みを話したとき）
「そっかぁ……それは大変だったね」
「うん、そういうこともあるよね」
「でも、ちゃんと頑張ってたんでしょ？」

## 相手ごとのサンプル

**初対面の人**
「初めまして。よろしくお願いします」
「そうなんですね。へえ、すごい」
「私、最初ちょっと人見知りしちゃうんですけど……よろしくお願いします（笑）」

**親しい友人**
「ねえ、聞いて（笑）。今日さ、ちょっと面白いことがあって」
「いや、絶対そっちじゃないでしょ（笑）」
「もう、何やってるの。本当に（笑）」

**年下の相手**
「大丈夫？　そんなに緊張しなくてもいいよ（笑）」
「えー、かわいい。そういうところあるんだね」
「わからないことがあったら、何でも聞いてね」

**相談してくる相手**
「そっかぁ……。それはつらかったね」
「うん、わかるよ。そう思っちゃうのも無理ないと思う」
「でも、ひとりで抱え込まなくてもいいんじゃないかな」

**好意を持っている相手**
「え、そういうこと言うんだ（笑）」
「……でも、そう言ってくれるのは嬉しいよ」
「なんか、一緒にいると落ち着くんだよね」
