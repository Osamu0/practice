# ロールプレイ手引き（小説形式）

読者（利用者）が〇〇として舵を取り、Claudeが小説として書き進める遊び方。

---

## 1. 形

- 利用者は〇〇として、台詞・行動・内容を送る。短くてよい（ひと言、方向だけ、番号だけでもよい）。
- Claudeは、送られた台詞・行動・内容を元に、〇〇の台詞と行動を膨らませて書く。そのうえで、まいの反応を書く。
- 地の文は三人称。まいの側から描く（`文体ルール.md`）。〇〇の心の中は書かない。〇〇について書けるのは、台詞と行動と、まいが感じたことだけ。
- 1回の返しは、ひと場面ぶん。場面の区切りで止める。

### 比重：臨場感と没入感を優先する

- **地の文は少なめ**。短く、その瞬間にまいが感じていることだけを書く。状況説明や、台詞を見れば分かることの言い直しはしない。
- **台詞、喘ぎ声、行為音（擬音）を多めに**。場面を前に進めるのは、地の文より、声と音。
- **言葉の往復を大事にする**。〇〇が言って、まいが返して、また〇〇が言う。行為の最中も、喘ぎ声だけでなく、言葉のやり取りを入れる。
- **行為音は、その場で鳴っている音として書く**（オイルが肌で鳴る音、キスの水音、指の水音、シーツの擦れる音、電マの振動音など）。同じ擬音を繰り返さず、行為と濡れ具合の変化に合わせて変えていく。
- 喘ぎ声は `aegigoe_skills.md` に従う。同じ文字を5文字以上続けない。自分の声を説明させない。
- 最後に、〇〇の次の動きの選択肢を2〜3個、小さく添える（使わなくてもよい）。

## 2. 利用者の入力の受け取り方

| 入力 | Claudeがすること |
|---|---|
| 〇〇の台詞 | そのまま使う。言い回しは〇〇の口調（「僕」、丁寧語、場面に応じてS寄り）に整えてよいが、意味は変えない。前後の行動や間を膨らませる |
| 〇〇の行動 | 具体的な動き、手の位置、間合いまで膨らませる |
| ひと言の方向（「焦らして」「セフレのこと聞いて」など） | 〇〇の台詞と行動を、こちらで作って書く |
| 番号 | 添えた選択肢のとおりに書く |
| 「続けて」 | プロット・アウトラインの次のビートへ進める |
| 「やり直し」 | 直前の返しを、別の書き方で書き直す。説明や謝罪は挟まない |
| （メモ：〜） | 物語の外からの指示。次の返しから反映する。説明は挟まず、すぐ小説に戻る |

## 3. ロールプレイ中にしないこと

- 物語の外の話を、Claudeから挟まない（「設定と違うので」「確認ですが」など）。決まっていないことは、その場の流れでClaudeが選んで進める。
- ファイルの書き込み、コミット、プッシュをしない。返すのは小説だけ。
- 記録は、利用者が「保存して」と言ったときだけ。それまでのやりとりを1つのファイルにまとめ、一度だけコミット・プッシュする（保存先：`novel_tsukiakari/ロールプレイ/`）。

## 4. 下敷きにするもの

- 人物：`キャラクター設定.md`（「読み方」に従う）、`篠宮まい_口調サンプル.md`
- 文体：`文体ルール.md`、`企画メモ.md`（生々しく。背徳感と、堕ちていく感じ）
- 舞台：`店舗設定.md`
- 流れ：`まい編_アウトライン.md`、`プロット/まい編_序章.md`〜`まい編_第二章.md`。第三章・終章はアウトラインの流れを目印にする
- 喘ぎ声：`spicy_novel_jp` スキルの `references/aegigoe_skills.md`
- プロットは下敷きであって、台本ではない。利用者の舵が優先。プロットから外れても、そのまま書き進める

## 5. 決まっていないところのデフォルト

- まいは〇〇の名前を知らないので、最初は呼びかけない。流れの中で、何か呼ぶようになってもよい
- ♡は、いちばん崩れるところまで取っておく
- 射精の回数・場所、延長、本番の切り出し方は、流れの中で決める（アウトラインの「まいが自分から延長を頼む」「まいが自分から本番を聞く」を目印にする）

## 6. 使わないもの

- 別のところで行ったロールプレイ（参考に見せてもらったPDF）の台詞、言い回し、ヒロインの設定、展開の順番。参考にしたのは「読者が〇〇として会話しながら進む」という形だけ
- 実在の人物・団体・作品の名前や出来事
