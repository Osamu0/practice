# 文体ルール

最優先は、読者が没入できること。

---

## 1. 視点

- 三人称で、ヒロインの側から描く。
- 〇〇の心の中は書かない。〇〇について分かるのは、台詞と行動と、ヒロインが感じたことだけ。

## 2. 〇〇の描き方（読者が自分を重ねるため）

| 項目 | 扱い |
|---|---|
| 呼び名 | 〇〇のまま |
| 年齢 | 数字を出さない。ヒロインごとの感じ方（「思っていたより若い」など）で描く |
| 髪型・顔立ち | 書かない |
| 体格 | ヒロインが感じたことだけを書く（背が高い、手が大きい、指が長い など） |
| 服装 | 黒のシャツとスラックス程度 |
| 態度・口調 | 書く（読者が演じる役の台本になる） |
| 施術中の変化 | 書く |

## 3. 台詞

- 台詞は、実際にその場で口から出る言葉だけにする。
- 自分の気持ちや状態の説明・分析は、台詞にしない（×「笑えない……」「ごまかせない、かも」）。
- 文学的すぎる言い回しや、回りくどい言い回しは避け、喋り言葉にする。
- 心の変化は、地の文の仕草、息づかい、表情で描く。
- 「（笑）」は本文のセリフに入れない。笑いは「あはは」「ふふ」などの声で表す。

## 4. スキル共通のルール

- 喘ぎ声は、`spicy_novel_jp` スキルの `references/aegigoe_skills.md` を参照する。
- 同じ文字を5文字以上続けない（特に喘ぎ声）。
- 語彙が単調になったら、`spicy_novel_vocab_jp` スキルで言い換える。
