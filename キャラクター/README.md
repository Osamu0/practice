# キャラクター図鑑

> 登場人物はすべて架空で、18歳以上の成人です。実在の人物・グループとは一切関係ありません。

作品をまたいで使うキャラクターの「芯」を置く場所。作品ごとの「役」は、各作品のフォルダに置く。

## 年齢の決まり

グループには、中学生や高校生のときに加入したメンバーもいる。図鑑は官能小説で使うので、次を必ず守る。

1. 性的な場面・設定に出すのは、作品の時点で18歳以上のメンバーだけ。作品の時点で18歳未満のメンバーは、性的な場面に出さない。
2. 18歳未満の時期について書くのは、仕事・人柄・成長だけ。体つき、性的な経験、性的な恋愛の話は、図鑑の「時期ごとの変わり方」でも書かない。
3. 性的な経験の設定（初体験など）は、18歳以上の出来事にする。18歳未満の性的な出来事は、回想でも書かない。

## 2層の分け方

| 層 | 置き場所 | 中身 | 変えていいか |
|---|---|---|---|
| 芯 | この `キャラクター/` フォルダ | 名前、顔、髪、身長、人柄の根っこ、時期ごとの変わり方、口調と一人称、経歴の大枠、グループの中の立場 | 変えない。変えるときは図鑑を直し、全作品に効く |
| 役 | 各作品の `出演設定.md` | その作品の時点（年齢）、体の細かいところ、経験の量、性癖、敏感なところ、相手との関係、その作品での変化 | 作品ごとに決める。図鑑の「作品で変えていい範囲」の中で |

## メンバーの段階

全員を作り込まない。物語に要る人だけを作る。段階は、作品で必要になったときに上げる。

| 段階 | 誰 | 作るもの |
|---|---|---|
| 主要 | ヒロインになる人、期の中心の人 | 図鑑（下の「図鑑の1人ぶんに書くこと」すべて） |
| 脇役 | 楽屋や仕事の場面で名前が出る人 | カード1枚：名前、愛称、生まれ年と加入年、ひとことの人柄、口調の例を2〜3個、グループでの立ち位置 |
| 名前なし | 残りのメンバー | 人数だけ。グループ設定の期の人数に含める |

## 図鑑の1人ぶんに書くこと

1. 基本：名前、愛称、期、加入した年、基準の年齢、一人称、グループの中の立場
2. 外見（芯）
3. 生い立ち（芯）：加入前の事実。過去は過去として書く。今の人柄を、生い立ちで理由づけしない。「加入前はこうだった。グループに入ってこうなった」は、時期ごとの変わり方に書く
4. 人柄の根っこ（芯）：どの時期でも変わらないもの。一人の人物像として文章で書く。人柄は特徴を一つずつ並べたものではなく、全部が絡まりあって互いに作用している。一つの特徴だけを「その作品の役」に切り出さない。絡まり方の例（「迷うのは、どれも大事にしたいから」など）を「絡み合い」として書く
5. 時期ごとの変わり方（芯）：加入当初、グループでの立場が変わったころ、基準年、卒業後など。時期で変わるのは表面（自信、人前での振る舞い、後輩への接し方、敬語の量）で、根っこは変わらない
6. 口調（芯）：口調サンプルへのリンク。時期で変わるところがあれば、それも書く
7. 作品で変えていい範囲：胸の大きさ、髪色の時期など、作品ごとに選べるもの
8. これまでの役：どの作品で、どんな役をしたか。決め台詞や性的な面の設定もここに残す（次の作品で重ねないため）

## 作品の `出演設定.md` に書くこと

1. 作品の時点：グループ結成何年目か（年齢と、図鑑の「時期ごとの変わり方」のどの時期かは、ここから決まる）
2. 出るメンバーと、それぞれの役
3. 今回の見せどころ：その作品で、そのキャラのどこを見せるか
4. 今回使わないもの：ほかの作品で使った決め台詞や展開のうち、重ねたくないもの
