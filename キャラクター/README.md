# キャラクター図鑑

> 登場人物はすべて架空で、18歳以上の成人です。実在の人物・グループとは一切関係ありません。

作品をまたいで使うキャラクターの「芯」を置く場所。作品ごとの「役」は、各作品のフォルダに置く。

## 2層の分け方

| 層 | 置き場所 | 中身 | 変えていいか |
|---|---|---|---|
| 芯 | この `キャラクター/` フォルダ | 名前、顔、髪、身長、人柄の核、口調と一人称、経歴の大枠、グループの中の立場 | 変えない。変えるときは図鑑を直し、全作品に効く |
| 役 | 各作品の `出演設定.md` | その作品の時点（年齢）、体の細かいところ、経験の量、性癖、敏感なところ、相手との関係、その作品での変化 | 作品ごとに決める。図鑑の「作品で変えていい範囲」の中で |

## 図鑑の1人ぶんに書くこと

1. 基本：名前、愛称、期、加入した年、基準の年齢、一人称、グループの中の立場
2. 外見（芯）
3. 人柄（芯）：一人の人物像として文章で書く
4. 口調（芯）：口調サンプルへのリンク
5. 作品で変えていい範囲：胸の大きさ、髪色の時期など、作品ごとに選べるもの
6. これまでの役：どの作品で、どんな役をしたか。決め台詞や性的な面の設定もここに残す（次の作品で重ねないため）

## 作品の `出演設定.md` に書くこと

1. 作品の時点：グループ結成何年目か（年齢はここから決まる）
2. 出るメンバーと、それぞれの役
3. 今回の見せどころ：その作品で、そのキャラのどこを見せるか
4. 今回使わないもの：ほかの作品で使った決め台詞や展開のうち、重ねたくないもの
