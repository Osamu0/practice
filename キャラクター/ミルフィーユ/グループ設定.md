# ミルフィーユ グループ設定（たたき台）

> 架空のアイドルグループ。実在のグループ・メンバー・楽曲・出来事とは一切関係ありません。実在のグループの歴史・人数・期の分け方をなぞらない。
> メンバーは全員、加入した時点で18歳以上（`../README.md` の「年齢の決まり」）。
> 桜ヶ丘40とは別のグループ。両方の設定を混ぜない。

## 決まったこと

| 項目 | 内容 |
|---|---|
| グループ名 | ミルフィーユ（愛称：ミルフィ） |
| 結成 | 2015年 |
| 人数 | 9人。加入はオーディションとスカウトの両方で、「期」ではなく加入した年で呼ぶ |
| 人気 | 国民的アイドルグループ。年末の歌番組の常連 |
| 売れ方 | 2018年、ドラマの主題歌が配信で大きく当たって、一気に知られる |
| 事務所 | 中規模の芸能事務所（名前は未定） |
| リーダー | 未定 |

## イメージ

- 甘くて、重ねるほどおいしい。9人の色が層になる、という名前の由来。
- 衣装はパステルと白に、毎回一色の差し色を入れる。
- 曲は明るいポップスが中心。バラードは年に1曲くらい。
- ファンとの距離：ライブとサイン会、配信。テレビで毎週見る「知っている顔」。

## 歴史の流れ（たたき台）

| 年 | 中身 |
|---|---|
| 2015 | 5人で結成。ライブハウス中心 |
| 2017 | 4人が加入して9人に（与田ひなのはこの年） |
| 2018 | ドラマの主題歌が当たり、ブレイク |
| 2019〜2022 | ドームツアー。メンバーそれぞれにドラマ・バラエティ・モデルの仕事が増える |
| 2023〜 | 結成メンバーから1人が卒業。グループは8人に |
