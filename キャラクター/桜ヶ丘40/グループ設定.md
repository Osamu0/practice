# 桜ヶ丘40 グループ設定（たたき台）

> 架空のアイドルグループ。実在のグループ・メンバー・楽曲・出来事とは一切関係ありません。実在のグループの歴史をなぞらない。加入は中学生からでもよい。性的な場面・設定は、その時点で18歳以上のメンバーだけ（`../README.md` の「年齢の決まり」）。
> 既存作品の食い違いは `既存作品の調査.md`。
> ここに書くのは、どの作品でも同じ「表の歴史」だけ。裏の設定（`novel_shinomiya` の「相手」の業務、`novel_offkai` の裏オフなど）は、作品ごとの設定に書く。
> **（たたき台）** と付けたところは、こちらで仮に埋めたもの。

## イメージ

- 清楚で上品、清潔感がある。
- 華やかで美しく、透明感のある女性たち。
- お嬢様っぽさと、品の良さ。
- 儚さ、繊細さ、少しの憂い。
- 女性らしさと可憐さ。
- 都会的で、洗練された雰囲気。
- 親しみやすさの中にある、高嶺の花感。
- 青春、成長、仲間、絆。
- 華やかな芸能界らしさと、素朴な女の子らしさの共存。

**（たたき台）見た目に落とすと**
- 衣装：膝下丈のスカートを基本にした、制服風・ワンピース風の上品な衣装。白や淡い色が多い。肌の露出は控えめ。
- 曲：切なさや憂いのある、きれいなメロディの曲が代表曲に多い。明るい曲もあるが、はしゃぎすぎない。
- ファンとの距離：握手会やミート＆グリートで直接会える。会えるけれど、遠い。手が届きそうで届かない。

## センターの選び方

センター（表題曲の真ん中に立つ人）は、曲ごとに、次のことを考えて選ばれる。

| 考えること | 中身 |
|---|---|
| グループの顔 | その時期を象徴するメンバーを前に出す |
| 世代交代 | 新しく加入したメンバーや次の世代を起用して、新しい印象をつける |
| 個人の人気・実力 | 人気、パフォーマンス、表現力、知名度 |
| 楽曲との相性 | 曲の世界観、歌詞、MV、表現に合うメンバー |
| 新しい魅力の開拓 | これまで中心ではなかったメンバーを起用し、新しい一面を見せる |
| 運営の戦略・期待 | これからを担うメンバーに、経験や露出を積ませる |

## 歴史の流れ

人気は一つの瞬間で跳ねたのではなく、時期ごとに段階を踏んで大きくなった。

| 年 | 結成何年目 | 時期 | 中身 |
|---|---|---|---|
| 2011〜2013 | 1〜3年目 | 結成・模索期 | 結成。グループとして何を見せるかを探っている時期 |
| 2014〜2015 | 4〜5年目 | 独自路線の形成・成長期 | グループの方向性が見え始める。人気が広がり、ブランドが確立していく |
| 2016 | 6年目 | ブレイク期 | CDの売り上げだけでなく、メディア露出、モデル、ドラマ、映画、ライブと、活動の場が一気に広がる。メンバーによっては、個人の仕事も増える |
| 2017〜2018 | 7〜8年目 | 人気拡大・全盛期への突入 | 写真集ブーム |
| 2019〜2021 | 9〜11年目 | 黄金期の継続と世代交代の始まり | |
| 2022〜2024 | 12〜14年目 | 世代交代・新体制への移行 | 世代交代とは、1期生が全員卒業すること。1期生の最後の一人が卒業して、世代交代が終わる |
| 2025〜 | 15年目〜 | 新世代体制の再構築 | 2026年は結成16年目 |

## 期

### 加入の時期

| 期 | 加入の時期 | 年（たたき台） | 人数 | 加入したときのグループ |
|---|---|---|---|---|
| 1期 | 結成 | 2011年 | 30人 | 何もないところから始まる |
| 2期 | 模索期と成長期のあいだ | 2013年の終わりごろ | 9人 | 模索が終わりかけ、方向性が見え始める手前 |
| 3期 | ブレイク期の途中 | 2016年の半ば | 10人 | 活動の場が一気に広がっている最中 |
| 4期 | 世代交代期の前 | 2020年ごろ | 12人 | 黄金期が続いている。世代交代のための加入ではないが、結果として、次の時代への準備期間になる |
| 5期 | 世代交代が終わるころ | 2024年ごろ | 10人 | 1期生の最後の一人（まなつ）が卒業した直後 |

6期は入れない。5期が最後の期。合わせて71人。

### 世代の空気（たたき台）

加入の時期から出てくる空気。一期ずつ作り込むときに直す。

| 期 | 空気 |
|---|---|
| 1期 | 模索期をまるごと知っている唯一の世代。何を見せるグループなのかを、自分たちで探してきた。戦友の絆 |
| 2期 | 1期の模索を、少しだけ外から、少しだけ内側から見た世代。グループの方向性が形になっていくのを、先輩と一緒に作った側でもある。1期に近い |
| 3期 | ブレイクのさなかに入った世代。先輩たちが急に忙しくなり、外からの注目も急に大きくなった。入った瞬間から見られている |
| 4期 | 黄金期に入った世代。完成したグループに憧れて入った。本人たちに自覚はないまま、先輩たちが去ったあとを担う準備をしていた |
| 5期 | 1期を、ほとんど知らない世代。入ってすぐに、グループの最初の世代が全員いなくなる。新しい体制の最初の後輩 |

一期ぶんに決めること：

| 項目 | 中身 |
|---|---|
| 加入した年 | 歴史のどの時期に入ったか |
| 人数 | 加入時の人数 |
| 世代の空気 | どんなグループに入ったか。先輩との関係。その期にしかない経験 |
| 期の中の関係 | 仲のよさ、ライバル、まとめ役 |
| 中心のメンバー | センターや、期を代表するメンバー |
| 名前を出すメンバー | 図鑑を作るメンバー |
| その後 | 卒業の流れ、期として最後まで残る人 |
