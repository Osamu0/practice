## 一人の人間として（芯）

> グループに入る前のまいと、仕事の外のまい。人柄は、まずここから出てくる。グループでの立場は、この人がその環境に置かれたときに出てくるもの。
> 印のない行は決まったこと。**（たたき台）** はこちらで仮に埋めたもの。

| 項目 | 内容 |
|---|---|
| 出身 | 群馬 |
| 家族 | 姉が1人。まいは妹 |
| 家族との関係 | **（たたき台）** 仲のいい家族。姉には今でも甘えられる。実家では「アイドルの白瀬まい」ではなく、ただの妹に戻る |
| 子どもの頃 | 人前に出るのが苦手だった。**（たたき台）** 姉のあとをついて回る子で、姉がやることを何でも真似したがった |
| 高校時代 | 青春をしてきた。**（たたき台）** 部活、友達、放課後、地元の景色。アイドルとは関係のない、普通の高校生活 |
| 芸能界への関心 | 最初はなかった |
| 加入前 | 学生だった。**（たたき台）** 地元を出て、都内の大学に通いはじめたところ |
| オーディション | 学生時代に、人から勧められた。友達と一緒に受けた。アイドルになりたかったわけではなく、比較的楽な気持ちだった |
| 誰に勧められたか | 友達。勧めてくれた友達と一緒に受けた |
| 一緒に受けた友達 | 落ちた。まいだけが受かった。今も付き合いがあるかは未定 |
| 加入前の恋愛 | 恋愛していたかもしれない。恋人がいた、というところまで。性的なことには触れない。初めての経験がいつだったかは決めずに空けておく（「なかった」とも書かない）。性的な経験は、作品で必要になったら18歳以上の時点の話として書く（`../README.md` の「年齢の決まり」） |

**（たたき台）ここから出てくるもの**
- **アイドルを目指していなかった**：芸能界に関心もなく、友達に誘われて、楽な気持ちで受けた。受かってしまった、に近い。誘ってくれた友達は落ちて、自分だけが受かった。まわりには、ずっとアイドルになりたかった子がたくさんいる。その子たちの夢の場所に、楽な気持ちで来てしまった、という引け目が、模索期の気負いの底にある。人気が出ても「いやいや」と照れるのも、ここから。
- **人前に出るのが苦手だった子が、グループの顔になる**：もともと前に出たい人ではない。だから、前に立つことを望んでいる顔をしない。求められたから、そこに立っている。
- **青春をしてきた**：普通の高校生活を、ちゃんと知っている。アイドルになってから手放したものが何かを、わかっている。
- **妹として育った**：甘え方は、本当は知っている。家では姉に甘えて育った。だから、甘えを出せないのは性格ではなく、甘えられる場所がないだけ。気を許した相手の前では、妹の顔がふっと出る。
- **姉のあとを追う子だった**：自分で道を決めるより、誰かの背中を見て動くほうが楽だった。迷いやすさの根っこは、ここにある。

## 人柄（芯）

> 黄金期（2018〜2019年・27〜28歳）のまい。ほかの時期のまいは、下の「時期ごとの変わり方」を参照。

> **読み方**：ここに書いたことは、全部が同時に一人の中にある。どれか一つがこの人の正体なのではない。
> - 一つの特徴を、毎回の場面で拾って強調しない
> - 一つの場面で、全部の面を見せようとしない。その場の状況と相手との距離で、自然に出るものだけが出る
> - 書かれた言葉より、この人全体の手触りを優先する

遠くから見ると、華やかで大人っぽく、上品で落ち着いた美人。少し近寄りがたいくらいに見える【tsukiakari、shinomiya】。でも、近くで話してみると、思っていたよりずっと人間味がある。よく話し、よく笑い、笑いだすと止まらなくなることもある。きれいなお姉さんなのに、意外と無邪気で、お茶目なところがある【tsukiakari、shinomiya】。

初対面では、相手がどんな人かを自然に様子を見る。無愛想にはせず、笑顔と相づちで礼儀正しく接するけれど、いきなり自分の話をたくさんはしない【shinomiya】。仕事の場や初対面では、ちゃんとしようと意識して少し大人しくなる【tsukiakari】。打ち解けると、初対面からは想像できないほど気さくになり、楽屋では騒いだりもする【tsukiakari、shinomiya】。どれも作っている顔ではなく、相手や場面で表に出る部分が変わっているだけ。

人の話を楽しそうに聞く。好奇心が強く、気になることは自分から聞く【idol、tsukiakari】。話を途中で遮らず、すぐに正論で片付けない。相手が落ち込んでいれば、まず気持ちを受け止める【shinomiya】。面倒見がよく、年下が緊張していれば自分から話題を振る【idol、shinomiya】。慣れた相手には、反応を見ながら少しだけからかう。自分から大きくボケるより、場の流れに乗って面白さを出す【idol、shinomiya】。

穏やかだけれど、受け身なわけではない。呆れた顔をしたり、柔らかくツッコんだりするし、真剣な話になれば自分の考えを伝える。意見は持っているが、押しつけない【idol、tsukiakari】。

仕事には真面目で、謙虚。引き受けたことはきちんとやろうとして、多少無理もする。頑張っていることを大げさに見せない【idol、shinomiya】。ただし、何でも器用にこなす完璧な人ではない。服や食事を選ぶときは、どちらも捨てがたくて迷ってしまう。そんな自分を、少し笑いながら話す【shinomiya】。

褒められると、まず「いやいや」と照れて返す。でも、親しい相手からの言葉には、照れながらも嬉しさが出る【idol、shinomiya】。

いつも人を支える側にいて、自分の欲や甘えを出せる相手は、ほとんどいない。だから、気を許した相手には甘えるし、少し寂しがりなところがある【idol】。

遠くから見れば憧れの人で、近くにいると親しみやすい。その両方が、無理なく同居している【tsukiakari】。

### 絡み合い（たたき台）

> 人柄は、特徴を一つずつ並べたものではない。全部が絡まりあって、互いに作用している。ここに書くのは、その絡まり方の例。これが答えではなく、書くときの手がかり。

- **迷うことと、受け止めること**：どちらも捨てがたくて迷うのは、目の前のものをどれも大事にしたいから。人の話を遮らずに受け止めるのと、同じところから来ている。小さいころは、迷ったら姉の真似をすればよかった。今は、真似する背中がない。
- **妹であることと、甘えられないこと**：甘え方は知っている。家では妹だった。けれど、仕事の場では年上の側で、甘える相手がいない。甘えられないのではなく、甘える場所がない。気を許した相手の前では、妹の顔がふっと出る。
- **からかうことと、甘えること**：自分から「甘えたい」とは言えない。そのかわりに、慣れた相手をからかって、距離を縮める。姉にじゃれついていたのと、同じ距離の縮め方。
- **楽な気持ちで来たことと、真面目さ**：アイドルになりたくて来たわけではない。だからこそ、なりたかった子たちに恥ずかしくないように、きちんとやろうとする。頑張っていることを見せないのは、頑張って当たり前だと思っているから。
- **照れと、引け目**：褒められると照れるのは、謙遜だけではない。自分がここにいていいのか、まだどこかで思っている。
- **人見知りと、気さくさ**：初対面で様子を見るのは、相手をちゃんと受け止めたいから。相手がわかると、受け止め方がわかって、気さくになれる。

## 時期ごとの変わり方（芯・たたき台）

> 時期で変わるのは表面だけで、根っこは変わらない。
> この節は、既存作品にない部分をこちらで仮に埋めたもの。

**変わらない根っこ**：人の話を遮らずに聞く。相手の気持ちをまず受け止める。初対面では相手の様子を見る。仕事に真面目で、頑張りを見せない。褒められると照れて「いやいや」と返す。笑いだすと止まらない。どちらも捨てがたくて迷う。自分の甘えを出すのが下手で、慣れた相手をからかう。

| 時期 | 年齢 | 立場 | 表面に出るもの |
|---|---|---|---|
| 結成・模索期（2010〜2012） | 19〜21 | 30人の1期の一人。ファンの間では結成から人気があるが、世間にはまだ知られていない | 人見知りが強く出る。グループが何者なのかも、自分が何をすればいいのかもわからず、ちゃんとしなきゃと気負っていて、人前では固い。よく笑う顔はメンバーの前でだけ |
| 成長期（2013〜2014） | 22〜23 | グループの顔になる。2期の後輩ができる | 前に立つ場面が増え、仕事の場でも少しずつ素が出せるようになる。顔としての責任を、黙って背負いはじめる |
| ブレイク期（2015） | 24 | 個人の仕事（モデル、ドラマなど）が一気に増える。3期が入る | 忙しさの中で、人を支える側になっていく。自分の甘えを出せる相手が減りはじめる |
| 全盛期への突入（2016〜2017） | 25〜26 | 写真集ブーム。グループの顔として、いちばん露出の多い時期 | 仕事の場でも余裕が見えるようになる。支える側でいることが当たり前になり、そのぶん寂しさも深くなる【idol、fudeoroshi の時点】 |
| 黄金期（2018〜2019） | 27〜28 | 年長組。後輩に慕われる。4期が入る | 余裕が出て、慣れた相手を軽くからかえるようになる。初対面での人見知りは残っているが、表にはほとんど出さない【tsukiakari の時点】 |
| 卒業（2020ごろ） | 29 | 黄金期の終わりに卒業。世代交代の始まりを告げる卒業になる | |
| 卒業後（2021〜） | 30〜 | 卒業生。モデル・ドラマの仕事 | 「グループの顔」の責任が下りて、肩の力が抜ける。落ち着いた大人になる。きちんとした態度の中に、くだけた言葉が自然に混ざる【shinomiya の時点】 |
