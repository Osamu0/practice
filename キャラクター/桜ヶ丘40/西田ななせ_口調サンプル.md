# 西田ななせ 口調サンプル（たたき台）

> 架空の人物。実在の人物とは一切関係ありません。
> キャラを作るための参考資料。台詞として本文にそのまま使う必要はない。口癖・語尾・型を抜き出してなぞるのではなく、全体の空気をつかむために読む。
> 既存作品の口調サンプル（`novel_tsukiakari/西田ななせ_口調サンプル.md`、`novel_shinomiya/西田ななせ_口調サンプル.md`）をまとめたもの。ここに入れたのは普段の話し方（芯）だけ。作品の場面だけの口調は、各作品の口調サンプルに置く（下の「作品ごとの口調」）。
> 「（笑）」は、笑いながら言っているという合図。本文での書き方（「笑」「あはは」「ふふっ」、読点、話し言葉の崩し方）は、各作品の文体ルールに従う。
> 台詞は読みやすく整えてある。本文では、息の切れ目・助詞の抜け・伸ばし・言いさしのある話し言葉に崩す。

## 口調のルール

口癖をたくさん並べるより、どういう気持ちのときに、どんな言葉を選ぶかを大事にする。素に近いのは、さっぱりした話し方。

- **短い文をつなぐ**：長い説明を一気に話さない。質問には、まず短く答えてから補足する。
- **距離で切り替える**：初対面や仕事の場では、丁寧語の標準語。相手の話を受けて、短めに返す。気を許すと、飾らない短い返事が増える。
- **曖昧さを残す**：自信がないときや、感覚をうまく説明できないときは、「たぶん」「なんか」「かも」「うまく言えないんですけど」と断定を避ける。言い切るときは言い切る。
- **話しながら考える**：「うーん……どうだろう」「なんか、そういう感じではなくて……」と、すぐに正解を出そうとしない。
- **ツッコミは強くない**：笑いながら、短い疑問や率直な感想で、さらっと返す。
- **面白いことは、少し間を置いてから**：独特な表現で言葉にする。
- **照れや本心は、素っ気ないふりで**：少し間を置いたり、素っ気なく言ったりする（「……別に嫌じゃないですけど」）。
- 上品すぎる言い回しはしない。特定の語尾や口癖を、すべての会話で繰り返さない。

## 一人称と呼びかけ

- 一人称は「私」。
- 年上や初対面の相手には丁寧語。親しくなっても、無理に親しさを演出しない。

## 声・速さ・間

| | 中身 |
|---|---|
| 声 | 落ち着いていて、強くない |
| 普段の速さ | ゆっくりめ。短い文をつなぐ |
| 考えているとき | 間が空く。言葉の途中で考え直す |
| 好きなものの話 | 言葉が増え、速くなる。好きな理由が具体的になる |
| 本当に嫌なとき | 言葉数が減り、静かになる |

## 時期で変わるところ（たたき台）

> 図鑑の「時期ごとの変わり方」と合わせて読む。土台の話し方は変わらない。

| 時期 | 話し方 |
|---|---|
| 結成・模索期（17〜19歳） | 人前ではほとんど話さない。丁寧語で、短く、声が小さい |
| 成長期〜ブレイク期（20〜22歳） | メンバーの前では、さっぱりした素の言葉と、独特な一言が出はじめる |
| 全盛期〜卒業（23〜24歳） | 自分から話しかけることが増える。初対面でも、前より早く打ち解ける |
| 卒業後（24歳〜） | 落ち着いた自然体 |

## 場面ごとのサンプル

### 相づち・短い返事

「うん、そうなんですよね」
「あ、確かに」
「なんか、わかる気がする」
「えー、うそ。ほんとに？」

### 曖昧に言う・考えながら話す

「たぶんそうかも」
「なんて言うんだろう……」
「うまく言えないんですけど」
「うーん……どうだろう」

### ツッコむ・笑う

「え、なんで？」
「いや、ちょっと待って（笑）」
「それは違う気がする」
「いや、それはおかしいって」
「いや、それは面白い（笑）」

### 褒められたとき

大げさに喜ぶより、照れ笑いしながら受け止める。

「えっ、ほんとですか？」
「いやいや、そんなことないですよ（笑）」
「……でも、ありがとうございます。うれしいです」
「なんか、直接言われると恥ずかしいですね」

### からかわれたとき

冗談だとわかれば笑って返す。

「えー、なんでそうなるんですか（笑）」
「いや、それは言いすぎですって（笑）」
「……まあ、ちょっとだけ合ってるかもしれないですけど」

### 本当に嫌なことを言われたとき

笑ってごまかさず、表情が落ち着き、言葉数が減る。静かに線を引く。

「……それは、ちょっと嫌です」
「そういう言い方は、あんまり好きじゃないです」
「いや、私はそうは思わないです」

### 好きなものについて話すとき

「いや、これ、結構好きなんですよ」
「なんか、ここがいいんですよね。わかります？」
「最初はそんなに気にしてなかったんですけど、見てたら面白くなってきて」
「え、これ知らないですか？　結構おすすめなんですけど（笑）」

## 相手ごとのサンプル

### 初対面の相手

少し緊張していて、相手の様子をうかがう。無愛想にはならないが、無理に盛り上げようとはしない。

「あ、初めまして。よろしくお願いします」
「えっと……今日は、どちらから来たんですか？」
「私、最初ちょっと人見知りするんですけど……慣れたら大丈夫です（笑）」

### 仲良くなった友人・メンバー

気負いがなくなり、短い言葉や率直な感想が増える。会話が途切れても、あまり気にしない。

「なんか、わかる。私もそういうときある」
「うん、別にいいんじゃない？　私は好きだけどな」
「まあ、でも……わかるけどな」

### ファン（握手会など）

「今日、来てくれたんですか？　ありがとうございます」
「そんなふうに思ってくれてたんですね」
「また会えたらいいですね」

### 気になる相手と二人きり

急に恋愛上手になるのではなく、普段の自然さの中に、少し意識している様子が混ざる。

「え、今日ひとりなんですか？」
「そうなんだ。じゃあ、もうちょっと一緒にいてもいいですか？」
「……なんか、二人だと変な感じしますね（笑）」
「いや、嫌とかじゃないですよ。全然」
「……別に嫌じゃないですけど」
「また誘ってくれてもいいですよ（笑）」
