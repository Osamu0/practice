# 02 プリプロダクション

どう作るかを決める部門。面白さの骨組み、道具、見た目の方向、計画を決め、プロトタイプで確かめる問いを立てる。

## 仕事人と呼ぶ順

1. `game-preprod-designer`（デザインの柱、コアループ、スコープ、プロトの問い）
2. 柱ができたら、`game-preprod-tech` と `game-preprod-art` を**同時に**
3. 3人ぶんがそろったら `game-preprod-producer`（計画、リスク表、外部に頼むものの見通し＝依頼一覧の初版）
4. プロデューサーが4つを照らし、食い違い（技術で無理な見た目、計画に収まらないスコープ）を直す → ゲート02

## デザインの柱

- 3つまで。短い言葉で、迷ったときに「この機能は柱に合うか」で削れるもの
- よい例：「1秒で反応、10秒で一勝負」「失敗が笑える」「迷わない、でも単純じゃない」
- 悪い例：「面白い」「爽快」（どの機能も削れない）

## コアループとメタループ

```
コアループ（数秒〜数分）：見る → 決める → 動く → 結果 → また見る
メタループ（数十分〜）：遊ぶ → 報酬 → 強くなる・解放 → もっと難しい遊び
```

- それぞれのループで、プレイヤーがやめずに続ける理由を書く

## スコープ

| 機能 | 必須／あれば／入れない | 理由 | 柱 |
|---|---|---|---|

## ゲート02

- デザインの柱、コアループ、スコープの表がある
- 技術が決まり、最小の「動く」が確かめてある
- アートの方向に、色コードと制作の数値、形の言葉と比率の決めがある。方向の案を3つ以上比べてある
- 計画に、マイルストーンごとの終わりの条件と、削る順番がある
- プロトで確かめる問いが3つまである
- 依頼一覧の初版があり、外部に頼むものをオーナーが決めた（「あとで決める」は、決める時期を書く）

## この部門に加わる仕事人

中心の仕事人（上の「呼ぶ順」）に加えて、プロジェクトに要るときに呼ぶ。`開発チーム.md` で使わないと決めた仕事人は呼ばない。

| 仕事人 | 職種 | この部門でやること |
|---|---|---|
| `game-design-director` | ゲームディレクター、ディレクター | デザインの柱とコアループを決める場に立ち会い、判定する |
| `game-design-creative-director` | クリエイティブディレクター | 柱・アート・音・物語の方向がそろっているか |
| `game-design-systems` | システムデザイナー、ゲームプレイデザイナー | コアループを支える仕組みの一覧と、つながりの図 |
| `game-design-world` | ワールドデザイナー | 世界の全体図と地域の一覧 |
| `game-design-ux` | UXデザイナー、UIデザイナー、チュートリアルデザイナー | 体験の流れ（最初の5分）と、UIの方針 |
| `game-tech-director` | テクニカルディレクター | 技術選定とリスク表を判定する |
| `game-tech-engine` | エンジンエンジニア、システムプログラマー、物理演算プログラマー | 技術選定で、心臓部の試作（ループ、入力、当たり判定） |
| `game-tech-network` | ネットワークプログラマー | オンラインの方式（P2P、サーバー、ターン制など）の比較と試作 |
| `game-tech-platform` | プラットフォームエンジニア | 対象の端末ごとの技術要件と違いを調べる（出典つき） |
| `game-art-concept` | コンセプトアーティスト、キャラクターデザイナー、背景デザイナー、プロップデザイナー、イラストレーター | スタイルの見本（キャラ1体、背景1枚、小物数点）。方向の違う見本を3つ以上出して比べられるようにする |
| `game-art-technical` | テクニカルアーティスト、テクニカルアニメーター、リギングアーティスト | 資産の数値の決め（大きさ、ポリゴン、テクスチャ、コマ数）の案 |
| `game-story-director` | ナラティブディレクター、ナラティブデザイナー | 物語の伝え方の方針と、物語の全体の流れ |
| `game-story-lore` | 世界観設定担当、キャラクター設定担当、ロアライター | 世界観の骨組みと主要キャラ |
| `game-audio-director` | オーディオディレクター | 音の方向（楽器、テンポ、質感）を判定する |
| `game-pm-manager` | プロジェクトマネージャー、プロダクションマネージャー、制作進行担当、リソースマネージャー、アシスタントディレクター | 計画を、担当ごとの作業に分ける手伝い |
| `game-rnd-engineer` | 研究開発エンジニア、AI研究者、機械学習エンジニア | 技術選定で、新しい技術の候補を調べて試す |
