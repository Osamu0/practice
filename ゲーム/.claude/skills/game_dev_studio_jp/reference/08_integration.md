# 08 統合・演出制作

ばらばらに作ったものを1本につなぎ、手ざわりと見せ場の演出を入れる部門。

## 仕事人と呼ぶ順

1. `game-integ-integrator`（つなぐ、通しで遊べるか確かめる）
2. 通しで遊べるようになったら `game-integ-direction`（演出）
3. 演出を入れたあと、もう一度 `game-integ-integrator` で通しを確かめる
4. 返されたもの（仕様やデザインの食い違い）は、持ち主の部門（03、06、07）に戻す

## 演出の優先順

1. よく起きる操作の手ざわり（当てる、取る、跳ぶ、決定）
2. 状態がわかる演出（ダメージ、危険、成功、失敗）
3. 見せ場（ボス、クリア、物語の山）
4. 飾り（背景の動き、待ち時間の演出）

- 遊びを遅くする演出は入れない。長い演出は飛ばせるようにする
- 揺れ・点滅は設定で弱められるようにする

## ゲート

- タイトルからエンディングまで（いまある範囲で）止まらずに通る
- 一覧（アセット、サウンド、テキスト）とコード・データの食い違いが0

## この部門に加わる仕事人

中心の仕事人（上の「呼ぶ順」）に加えて、プロジェクトに要るときに呼ぶ。`開発チーム.md` で使わないと決めた仕事人は呼ばない。

| 仕事人 | 職種 | この部門でやること |
|---|---|---|
| `game-design-director` | ゲームディレクター、ディレクター | 通しのビルドで、体験の流れを見る |
| `game-design-creative-director` | クリエイティブディレクター | 演出が作品の印象を強めているか |
| `game-tech-graphics` | グラフィックスプログラマー | 演出のための描画の機能を足す |
| `game-tech-performance` | パフォーマンスエンジニア、パフォーマンステスト担当 | 演出を入れたあとの重さを測る |
| `game-art-director` | アートディレクター、リードアーティスト | 演出・光・効果を入れた画面を見る |
| `game-art-lighting` | ライティングアーティスト | 演出に合わせた光の変化、最終の色の調子 |
| `game-art-vfx` | エフェクトアーティスト、VFXアーティスト | 演出担当と組んで、手ざわりと見せ場のエフェクトを仕上げる |
| `game-art-ui` | UIアーティスト | 画面に組み込んだあとの見た目を詰める |
| `game-art-technical` | テクニカルアーティスト、テクニカルアニメーター、リギングアーティスト | シェーダーと見た目の最終の調整 |
| `game-anim-animator` | アニメーションディレクター、リードアニメーター、3Dアニメーター、モーションデザイナー、フェイシャルアニメーター | 演出に合わせた動きの仕上げ |

| `game-story-director` | ナラティブディレクター、ナラティブデザイナー | カットシーンと物語の場面の監修 |
| `game-audio-director` | オーディオディレクター | 演出と音の合わせを見る |
| `game-audio-engineer` | サウンドエンジニア、ミキシングエンジニア | 演出と合わせた音のつなぎ |
| `game-audio-voice` | ボイスディレクター、音声編集担当、多言語音声制作担当 | 声の入れ方（どの場面、口の動き、字幕） |
| `game-pm-manager` | プロジェクトマネージャー、プロダクションマネージャー、制作進行担当、リソースマネージャー、アシスタントディレクター | 統合の待ちと詰まりを見る |
