# 職種の名簿

現実のゲーム会社の職種のうち、**ゲームを作る仕事に直接関わる職種だけ**を、このスキルの仕事人（`.claude/agents/game/game-*`）に割り振った表。同じ仕事をする職種は1人の仕事人がまとめて兼ねる。部門をまたいで参加する仕事人もいる（「参加する部門」の列）。

このスキルは、ゲームを作るところまでを受け持つ。経営、財務・経理、法務、営業・販売、宣伝、外部への発注、配信の手続きはしない（下の「取り入れなかった職種」）。

この表と仕事人のファイルは `tools/gen_agents.py` と `tools/gen_roster.py` から作っている。職種や仕事人を足すときは `gen_agents.py` を直して、両方を流し直す。

## 職位の扱い

| 職位 | このスキルでの扱い |
|---|---|
| プロデューサー | メインのClaude。部門を回し、ゲートを判定し、進行表を書く |
| ディレクター職（ゲーム、クリエイティブ、テクニカル、アート、ナラティブ、オーディオ、QA、ローカライズ） | 監修・判定の担当。部門の終わり（ゲート）の前に呼ぶ |
| リード職（ゲームデザイン、プログラム、アート、アニメ、QA） | 部門の中で最初に呼んで方針を決める担当か、レビューの担当 |
| チームリーダー | 部門ごとの「呼ぶ順」の1番の担当 |
| シニアスタッフ／スタッフ | 作る担当。難しい仕事には、渡すときに観点を足す |

## 取り入れなかった職種

ゲームを作る仕事に直接関わらないため、仕事人にしていない。必要になったら、このスキルの外で扱う。

- **経営・事業・財務・経理**：代表取締役、エグゼクティブプロデューサー、事業責任者、経営企画担当、事業企画担当、財務担当、事業開発担当、経理担当
- **法務・知的財産・契約**：法務担当、知的財産担当、契約管理担当、著作権管理担当、商標管理担当、コンプライアンス担当、年齢レーティング担当
- **販売・営業・価格**：パブリッシャー、セールスマネージャー、営業担当、流通管理担当、価格戦略担当、ライセンス担当、商品企画担当
- **宣伝・広報・コミュニティ**：マーケティングディレクター、マーケティングプランナー、マーケティング担当、広告運用担当、SNSマーケター、PR担当、広報担当、ブランドマネージャー、コンテンツマーケター、インフルエンサーマーケター、コミュニティマネージャー、イベントプランナー、トレーラー監督、モーショングラフィックスデザイナー、グラフィックデザイナー、Webデザイナー、コピーライター、カメラマン
- **配信・ストア**：配信管理担当、ストア管理担当、データ管理担当
- **外部への発注・調達**：外注管理担当、購買担当、調達担当
- **サポート**：カスタマーサポート
- **人事・総務・社内IT**：人事担当、採用担当、教育担当、総務担当、施設管理担当、社内SE、ネットワーク管理者、情報セキュリティ担当
- **人が演じる・録る仕事（仕事人にできない。台本と指示は `game-audio-voice` などが書く）**：モーションキャプチャー担当、モーションキャプチャーアクター、ボイスキャスティング担当、ボイスアクター、声優、フォーリーアーティスト、レコーディングエンジニア
- **外部協力会社**：開発受託会社スタッフ、3D制作会社スタッフ、アニメーション制作会社スタッフ、イラスト制作会社スタッフ、音楽制作会社スタッフ、音響制作会社スタッフ、翻訳会社スタッフ、QA専門会社スタッフ、広告代理店スタッフ、PR会社スタッフ、映像制作会社スタッフ、サーバー事業者スタッフ、セキュリティ会社スタッフ、法律事務所スタッフ
