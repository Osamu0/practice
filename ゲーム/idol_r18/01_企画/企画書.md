# ヨルアキ（仮タイトル。「夜を空ける」から）

企画書（game-concept-planner、2026-11-24）。もとにした案：アイデア出しの 25（スケジュール帳の落ちもの）＋10（密会を隠す）＋26（昼と夜の釣り合い）。

前提（スタジオの守ること）：登場人物は全員20歳以上の成人で、見た目・言動・設定も成人として描く。事務所・グループ・番組・人物はすべて架空で、実在に似せない。関係は成人同士の合意を軸にする。仕事と引き換えに関係を迫る形（枕営業）と、同意のない性行為は軸にしないし、出さない。

---

## 一文の企画

**恋愛禁止の芸能事務所でマネージャーを務めるプレイヤーが、落ちてくる仕事の予定を縦の手帳に隙間なく詰め、人の目が届かない夜の空きを作って、担当の彼女との長い夜を自分の段取りで勝ち取る、そのやりくりが気持ちいいゲーム。**

- プレイヤーの立場は「未決」（下の未決1）。マネージャーは仮。立場が変わっても「予定を詰めて、見られない夜を空ける」の芯は変えない
- 一言でいうと：**昼をうまく詰めた分だけ、夜が長くなる**

## コアの面白さ

### プレイヤーの動詞
1. **詰める**：上から落ちてくる仕事の予定（収録、撮影、取材、レッスン、移動）を、縦の手帳の盤面に回して・ずらして置く。きれいに詰めるほど、手帳の上（夜）に空きが残る
2. **隠す**：記者・ファン・同じ事務所の人の「目」が、どの時間・どの場所を見るかが予告される。仕事の予定を壁にして目をさえぎり、目の届かない空きに「夜の約束」を置く
3. **選ぶ**：朝に、今日の山に入れる依頼を選ぶ。昼の仕事（評判とお金が増えるが、盤面を埋める）と夜の約束（関係が深まるが、バレる危険が増える）を、同じ手札から取り合う
4. **読む・応える**：夜の場面で、相手の表情・台詞・しぐさから、いまの気持ちを読み、昼に残った「話題」のカードや、触れる・言葉をかける・聞く・待つといった手で応える

### そのときの気持ち
- 詰める：形がはまった瞬間の「よし」。手帳の上に夜がぐっと伸びる気持ちよさ
- 隠す：目の通り道を読み切って、ぎりぎりの隙間に約束をすべり込ませる、ひやりとした楽しさ
- 選ぶ：「今日は仕事を取るか、彼女を取るか」の迷い。どちらを取っても何かが動く重さ
- 読む・応える：自分が昼に作った時間の中で、相手が少しずつ心をひらいていく手ごたえ。うまく読めた夜は、翌日の相手のふるまいで返ってくる

### 1回の遊び（1日＝3〜5分の見込み）
| 段 | 時間の見込み | すること |
|---|---|---|
| 朝 | 30秒〜1分 | 今日の依頼を選ぶ。目の予告（今日はどこが見られるか）と、相手の様子（表情、手帳への書き込み）を見る |
| 昼 | 1分半〜2分半 | 落ちもの。仕事の予定を手帳に詰め、夜の約束を置く |
| 夜 | 1〜2分（節目の日は長め） | 空いた時間の長さ＝場面の手数。相手を読んで応える |
| 結果 | 15〜30秒 | 信頼・バレる危険・疲れ・昼の評判が動き、翌日の盤面の条件が出る |

- 1日の終わりだけでなく、段の切れ目ごとに自動で保存する（途中でやめてよい）
- 時間の見込みは担当の見立てで、プロトタイプで測る

### 夜の場面が「遊びの結果」で「次の原因」になる仕組み

**入り口（結果として）**
- 夜の長さ＝昼の落ちもので手帳の上に残った空きの行数。長いほど場面の手数（段の数）が多く、先の段まで進める
- 場所と安全さ＝約束を置いたマスが目に近いほど、場面の途中で「外の気配」（物音、通知）が入り、落ち着いていられる手数が減る
- 手札＝その日に置いた昼の仕事が、夜の「話題カード」を残す（例：ロケで褒められた話、収録でうまくいかなかったこと、衣装合わせの話）。昼に何を取ったかで、夜に出せる手が変わる（26の「昼と夜が同じ手札」）

**場面の中の遊び方（案。どれにするかは未決4）**
- 案A（推し）**読んで応える**：場面は短い文の連なりで進み、相手の表情・台詞・息づかいが毎段変わる。プレイヤーは手札（話題カード／触れる／言葉をかける／聞く／待つ）から1枚出す。相手の気持ちに合った手なら場面が深まり、合わない手なら相手が少し引く（場面は続く）。「聞く」「待つ」は、相手の気持ちを確かめる手として、いつでも出せる強い手にする。合意の確認がそのまま色気と駆け引きになる形
- 案B **呼吸を合わせる**：縦のスワイプや長押しで、相手のリズムに間を合わせる操作の遊び。疲れが高いと合わせられる幅が狭くなる。腕前の要素が強く、文章量は少なくて済む
- 案C **AとBを混ぜる**：要所（段の切り替わり）だけBの操作を入れ、ほかはA
- どの案でも：相手が「今夜はやめておきたい」と言うことがあり、それに応じても罰にしない（信頼が上がることがある）。同意のない進め方はできない作り

**出口（次の原因として）**
| 動くもの | 何で動くか | 翌日の盤面がどう変わるか |
|---|---|---|
| 信頼 | 夜の長さ、読みの合い方、約束を守ったか | 高いと、相手が自分で予定の隙間を空けてくる（「この時間あけておいた」という予定が盤面に入る）。低いと、相手の列に気まずさの予定が入り、詰めにくくなる |
| バレる危険 | 目との近さ、夜の長さ（帰りが遅いほど上がる）、続けて会った日数 | 高いと、翌日の目が増える・目の通り道が広がる。上がりきると週刊誌の記事の日（大きな盤面の試練）が来る |
| 疲れ（相手と自分） | 昼の詰め込み、夜の長さ | 高いと、翌日の仕事の予定が大きく重くなる、落ちる速さが上がる、相手の列に勝手に休みが入る |
| 昼の評判 | 仕事の数と出来 | 高いと、形のよい（詰めやすい）大きな仕事の依頼が来る。夜に寄せすぎて下がると、仕事が減って隙間は増えるが、節目の公演に届かない |

## 売り（3つ）

1. **昼の詰め方が、夜の長さになる**：パズルの腕前と段取りが、そのまま二人の時間の長さと深さになる。場面は好感度が溜まったら開くご褒美ではなく、その日の自分のやりくりの結果。夜のあとで信頼・バレる危険・疲れが動いて、翌日の手帳の形が変わるので、同じ日は二度来ない（市場調査の不満「くり返しの作業」への答え）
2. **見られずに会う、を盤面で読む**：人の目の通り道が手帳の上に予告され、仕事の予定を壁にして隙間を守る。「恋愛禁止の中で会う」緊張が、文章ではなく自分の置き方から生まれる。ゴール（節目の公演、契約の更新）までの日数が決まっていて、隠し通すか、明かすかを最後に選ぶので、回り出しても目的が消えない（不満「回り出すと目的が消える」への答え）
3. **気持ちは数字でなく、手帳と表情で見せる**：相手の疲れや気分は、手帳への相手の書き込み（字の乱れ、落書き、付箋）、朝の表情、夜の台詞の変わり方で伝える。夜の場面ではそれを読んで応えることが遊びそのもの。節目の場面と話題カードの組み合わせで話が枝分かれする（不満「心の状態が見えない」「話が短く起伏がない」への答え）

## 遊ぶ人と場所

- 遊ぶ人：オーナー1人。成人。落ちものパズルと、関係が少しずつ深まる大人の恋愛ものの両方を楽しめる人。パズルが苦手でも夜まで届く易しめの設定を用意する
- プラットフォーム：iPhone の Safari、縦持ち、片手〜両手の親指。1人用・オフライン、保存は端末内（技術は 02 の技術選定で確定）。届け方は「オーナーだけが遊べる」形を流用する見込み
- 1回の遊ぶ時間：1日＝3〜5分。何日か続けて遊んでも、1日でやめてもよい
- クリアまで：MVP（14日）で1〜1.5時間、理想（相手ごとに30日）で1人あたり2〜3時間＋周回の見込み（担当の見立て。プロトタイプで測る）

## 見た目と音の第一印象

- **昼の手帳**：白い方眼の紙。下が朝、上が深夜の縦の時間軸。仕事の予定は、蛍光ペンで色を塗った付箋のような帯で、落ちてきて「ぺたり」と貼られる。目の予告は、手帳の端に赤い鉛筆で引かれた細い線と小さな目の印
- **昼から夜へ**：最後の予定が貼られると、手帳の紙が紺色に沈み、上に残った空きだけがランプのようにあたたかく灯る。その灯りの高さが今夜の長さ
- **夜の場面**：部屋の暗さの中に、相手の姿と短い文。文字は大きめで、縦持ちで片手で読める。表情の差分と、手や肩のしぐさの絵が中心。一枚絵は節目の夜だけ
- **相手の描き方**：成人の、仕事を持った大人の女性（または相手の性別は未決5）。舞台の上の華やかさと、部屋での素の顔の差で見せる。架空のグループの衣装は、実在のグループの色分け・人数・意匠に似せない
- **音**：昼はペンの擦れる音、付箋を貼る音、局の廊下のざわめき、軽いテンポの曲。予定がはまるたびに小さな音が重なる。目が近いときはシャッターの気配のような乾いた音。夜は曲が引いて、部屋の静けさ、息、衣ずれ。iPhone はマナーモードで遊ぶこともあるので、音がなくても読めるようにする

## 似た作品との違い

市場調査（`01_企画/市場調査.md` の1）にある、事務所の育成・経営に恋愛と成人向けの場面をつけた作品、事務所経営のシミュレーションとの違いを、遊びの言葉で書く。

- 好感度や数値を貯めて、決まった日に場面が開く形ではない。**その日の盤面をどう詰めたかで、夜の長さと中身が毎日変わる**
- 経営の数字を回す遊びではなく、**1日の手帳を手で組む遊び**。お金を増やしても盤面は楽にならない（仕事が増えるほど詰めにくくなる）ので、回り出したら終わり、にならない
- 場面のあとに、信頼・バレる危険・疲れが動いて、**翌日の盤面の形そのものが変わる**。場面が見て終わりの絵ではなく、次の判断の原因になる
- 心の体力を数字のゲージだけで見せず、**手帳の書き込みと表情で見せ、夜にそれを読むことが遊びになる**
- 題材は「大人の芸能界の、合意の恋愛を隠すこと」。仕事と引き換えに関係を迫る形を軸にしない（市場調査で、成人向けに広くみられる題材と、違いが出ない形とされたもの）
- 落ちものパズルとしては、固定の形のブロックで列を消す遊びではなく、**長さ＝時間、幅＝関わる人や場所の「予定」を詰めて、上に残る空きを作る遊び**。消すことより、残すことが目的

| リスク | 中身 | いまの手当ての案 |
|---|---|---|
| 保存が消える | iPhone Safari は、Safari を使った日数で7日そのサイトの操作がないと、端末内の保存（localStorage など）を消すおそれがある（市場調査、出典は WebKit のバグ票）。ホーム画面に追加した形は対象外という記述があるが確かめていない | ホーム画面への追加を前提にする案、保存の書き出し（バックアップの文字列やファイル）と読み込みを必ず入れる案を、02 の技術選定に渡す。段の切れ目ごとの自動保存 |
| 絵を外部に頼む | 成人向けの一枚絵・立ち絵は、この環境では作れない見込み。外部に頼むと、費用・時間・やり取りがオーナーの側にかかる | MVPは文章と仮の絵（シルエット、色面、手帳の意匠）で一周遊べる形にし、絵がなくても面白さを確かめられるようにする。依頼一覧は02で案を作りオーナーが決める。依頼書は成人であること（20歳以上、見た目も成人）と、実在に似せないことを明記 |
| パズルが苦手だと夜が短い | 腕前の差が、そのまま見られる場面の差になる。失敗が罰に感じると、遊ぶ気が下がる | 易しめの設定（落ちる速さ、先の予定が見える数、置き直し）。短い夜にも短い夜なりの良い場面を書く。夜が短い日が続くと、相手から空けてくる日が来る |
| 落ちものと物語の両立 | 毎日の夜の文の組み合わせ（片）と、節目の物語の両方が要り、文章量が大きい | MVPは相手1人・14日に絞る。片の組み合わせの仕組みを03の仕様で先に決め、04のプロトで「片の組み合わせで話が浅く見えないか」を確かめる |
| 縦持ちの操作 | 盤面を指で隠す、細かい置き直しが難しい | 盤面の下に操作の帯（ずらす・回す・落とす）を置く案。04のプロトで実機で確かめる |
| 実在に似る | 架空でも、グループの人数・衣装の色分け・名前の形・曲名の形が実在に似るおそれ（市場調査の5） | 設定・資産の段階ごとに確かめる（game-qa-compliance、game-loc-culturalize） |
| 同意と年齢の描き方 | 合意の関係を軸にしても、場面の書き方しだいで同意があいまいに読める。成人に見えない絵や言動になるおそれ | 場面の中で「聞く」「待つ」を常に出せる手にする。台詞監修（game-story-dialogue-review）と、絵の依頼書で年齢・見た目の決めを書く |
| 音の制約 | iPhone Safari は、ユーザーの操作まで音が止まっている（市場調査） | 最初のタップで音を始める（02に渡す）。音なしでも遊べる |
| 期間が決まっていない | MVPの量が、決まる期間で作れるかがわからない | 期間が決まったら、02で量を決め直す。削る順は「絵 → 相手の人数 → 日数」 |

## 未決（オーナーに決めてほしいこと）

1. **プレイヤーの立場**（案）
   - A マネージャー（仮に採用）：担当の彼女の手帳を組むのが自然。事務所の恋愛禁止を破る緊張がある。相手は担当のアイドル（成人）
   - B 芸能人本人：自分の手帳を組み、共演者・スタッフ（成人）との密会を隠す。視点が逆になり、昼の仕事の当事者になる
   - C 一般人の恋人：彼女の手帳は彼女が組み、プレイヤーは自分の予定を合わせて隙間に入る。手帳を組む理由が弱くなる
2. **期間**
3. **主な相手の人数**（案：MVPは1人、理想は3人。最初から2〜3人にすると、盤面の列と話の量が増える）
4. **夜の場面の遊び方**（案A 読んで応える／案B 呼吸を合わせる操作／案C 混ぜる。担当の推しはA）
5. **相手の性別と、プレイヤーの性別・見た目の出し方**（プレイヤーの姿を描くか、描かないか）
6. **相手の職種の幅**：アイドルだけか、俳優・モデル・歌手なども入れるか
7. **性的な場面の描き方の強さ**：文章だけでどこまで書くか、一枚絵をどの段で出すか
8. **ゴールと結末**：節目の公演で隠し通す／関係を明かす、の二択でよいか。恋愛禁止の事務所という設定でよいか
9. **絵を外部に頼むか、どこまで頼むか**（02で依頼一覧の案を作ってから）
10. **タイトル**（「ヨルアキ」は仮）

## 対案：29 縦ファインダー ＋ 13 グラビア（短く）

- **一文の企画**：縦の画面をそのままカメラのファインダーにして、昼はライブ中継やグラビアの撮影で彼女の決めの瞬間を抜き、夜は同じカメラで、彼女が二人きりのときだけ撮らせてくれる一枚を待つ、撮る瞬間を選ぶ気持ちよさのゲーム
- **動詞**：構える、待つ、抜く（シャッターを切る）、指示する（声のかけ方の強さで相手の乗り方が変わる）
- **本命との違い**
  - 画面の向きと動詞がいちばん一致していて、昼と夜が同じ操作でつながる。触って気持ちいい、は本命より強い
  - そのぶん腕前（タイミング）の遊びが中心で、「夜の結果が翌日の判断を変える」つながりは本命より弱い（市場調査の隙間への当たりが弱い）
  - 撮った一枚が見せ場なので、絵の量（一枚絵・差分）に強く頼る。外部に頼む絵のリスクが本命より大きい
