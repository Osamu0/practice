## まとめ

- **推す方向**：案C「台座のミニチュア」。ふつうのファンタジーの魔物と英雄を、上から少し斜めに見下ろした、小さな台座に立つ人形のような見た目で描く。形は単純な図形の組み合わせ、線は太めの暗い縁取り、色は面で2段（明るい面と影）
- **読み分けの芯**：味方は「白い台座の輪」、魔物は「ギザギザの暗い影と黄色い目」、パックは「縦の長方形＋光の柱＋レア度の点の数」、危険は「だいだいの三角＋！＋点滅」。どれも白黒にしても読める（`スタイル見本/戦場_白黒.svg`）
- **色の主な値**：草地 `#A9CB8C`、道 `#DCCBA4`、塔の石 `#C9C4B8`、英雄の青 `#2F6FD6`・台座の白 `#FFFFFF`・金 `#E8B730`、魔物の暗い赤 `#A8323E`・紫 `#7A5A8C`・灰 `#5E5A66`・目 `#FFE14D`、危険 `#FF5A1F`、UIの紺 `#1F2A44`、レア度 コモン `#F2EFE8`／レア `#4FA3FF`／エピック `#8A3FE0`／レジェンド `#FFC23A`
- **基準の画面**：縦 390×844 の論理ピクセル（以下 px。iOS の pt と同じ大きさ）。英雄 高さ約44px、ふつうの魔物 28〜36px、パック 26×38px、塔 56×96px（旗を除く）、攻撃の輪 半径28px（当たりは34px）を指の56px上
- **音**：軽いオーケストラ（弦のピチカート、木管、ホルン、軽い打楽器、パックはチェレスタ・鉄琴）。戦いは 120 BPM 前後で、ウェーブが進むと層が増える
- **外部に頼む候補**：BGM（層つき）とレア度のファンファーレ、キービジュアル・タイトル画面・ホーム画面のアイコン、図鑑・開封の瞬間に出す英雄の大きな絵（あれば）。戦場の絵はコードで描く。決めるのはオーナー

## 1. 方向の案と推す案

`開発チーム.md` の観点（遊びの流れが既存作『Booster Pack Heroes』と同じなので、見た目が似すぎていないか）について：その作品の画面は、この担当は確かめていない。だから「その作品はこうだから避ける」とは書けない。かわりに、このジャンル（スマホのカジュアルな防衛・放置もの）で**ありがちな方向**を2つ挙げ、それより少し外れた方向を推す。似ているかの最終の確認は、その作品の画面を実際に見られる人（オーナー、または `game-design-creative-director` が見られる資料）が、ゲート02の前に行う（未決 #1）。

| 案 | ことば | よいところ | 重いところ | ありがち度（担当の感触。数えてはいない） |
|---|---|---|---|---|
| A：太い縁取りのフラット（シール風） | 太く黒い縁取り、平たい色、大きな頭、つるっとした面 | コードで描きやすい。小さくても読める | スマホのカジュアルゲームでいちばん見かける方向。埋もれやすく、似ていると言われやすい | 高い |
| B：ドット絵 | 16〜32 マスの点で描く、少ない色、コマ送り | 数が多くても軽い。懐かしさ | このジャンルのインディーでとても多い。英雄16人・魔物8種の点の絵をコードで描くのは手間。iPhone の画面の倍率（2倍・3倍）で点がにじまない工夫が要る | 高い |
| **C：台座のミニチュア（推す）** | 小さな丸い台座に立つ人形、単純な図形の体、太めの暗い縁取り、面は2段の色、上から少し斜めの光 | 台座の輪で「味方」がひと目でわかる。台座と影で、たくさん並んでも1体ずつが地面から浮く。図形の組み合わせなのでコードで描ける。A・B より見かけにくい | 台座ぶん、1体の場所が少し大きくなる。「人形らしさ」に寄りすぎると、世界観の比喩に見えるおそれ（下の注意） | 中くらい |

**C を推す理由**
1. **読みやすさ（柱2）**：後半に物が多く出ても、「台座の輪がある＝味方」「ギザギザの影＝魔物」が、色でなく形で決まる。白黒でも、色覚の違いがあっても読める
2. **パックとの相性（柱1）**：カードパックが降ってくる遊びなので、卓の上に駒を並べるような手ざわりは、開けた場所に英雄が「立つ」見せ方と合う（英雄は台座ごと、とんと地面に置かれる）
3. **コードで描ける**：頭・胴・武器・台座の部品の組み合わせ。部品の位置と角度でコマを作れる
4. **ありがちな A・B から少し離れる**

**注意（オーナーの決めとの関係）**：オーナーは「凝った比喩の世界にしない、ふつうのファンタジー」と決めている。C は**絵の描き方**であり、世界の設定（「これは盤上の遊びだ」など）にはしない。台座は「立っている位置と味方の印」として使うだけで、駒やボードゲームを話の中で言わない。オーナーが「人形っぽいのは嫌」と言ったら、台座を「足もとの白い光の輪」に変えた A に寄せる。色と数値はそのまま使える。

## 2. スタイルの言葉

| 観点 | 使う言葉 | 使わない言葉 |
|---|---|---|
| 形 | 丸・四角・三角の組み合わせ、大きな頭（2〜2.5頭身）、ひと目でわかる影の形（シルエット）、太い部品 | 細い線の飾り、ふさふさの毛、細かい模様、写実の体つき |
| 線 | 暗い色（黒でなく、こげ茶・紺）のなめらかな縁取り、太さ一定、角は丸める | 線の強弱を付けた手描きの線、線なしの面だけ、まっ黒 `#000000` の縁 |
| 質感 | 平らな面、色は2段（明るい面＋影）、光るのは金属と魔法だけ | グラデーションだらけ、布や毛の質感、汚し、テクスチャ |
| 光 | 光は左上から1つ。影は右下へ、楕円の落ち影。昼の明るい光 | 夕焼け・夜の画面（戦場では）、強い逆光、ぼかしの多用 |
| 動き | はねる、つぶれて戻る（スクワッシュ）、短い構え→当て→戻り、コマ送りの小気味よさ | ぬるぬるの補間だけの動き、長いため、画面全体のゆれ |
| 色の気分 | 明るい、昼、晴れ、草と土、青と金（王国） | 暗い、ホラー、ネオン、パステルだけ |
| 雰囲気 | 王道、にぎやか、元気、わかりやすい | 皮肉、グロテスク、血、ダークファンタジー |

### 見え方（カメラ）
- 地面は真上から少し斜め（見下ろし）。地面の模様とタイルは平らに描く
- キャラ・塔・パックは正面を向いて立てて描く（地面に対して起こす）。画面の下にあるものほど手前に描く（y の順に重ねる）
- 塔は画面の中ほど。画面の高さの 48〜55% の位置（デザインの柱のプロトの問い1で見る）

### 4.2 見分けやすさの決まり
- **明るさの段**：地面は中の上（160〜205）。魔物は暗い（75〜100）＋目だけ明るい。英雄は服が中くらいでも、台座の白（255）と肌・金属（215〜233）で明るい点を持つ。パックは中が暗く（50前後）、枠と光の柱が明るい。これで「地面より暗い塊＝魔物」「足もとに白＝英雄」「光の柱＝パック」が白黒でも分かれる
- **縁取り**：キャラと塔とパックは必ず暗い縁取りを持つ。地面と同じくらいの明るさの色（塔の石など）も、縁で地面から浮く
- **効果は上に、短く、半透明**：攻撃と呪文の効果は、キャラの上に重ねるときは 60% までの濃さ。長く残る効果（燃える地面など）は地面の上・キャラの下に描く
- **地面に強い色を使わない**：地面と背景に、レア度・危険・味方の青・魔物の赤の色を使わない（意味のある色を意味のある物だけに残す）

### 4.3 色覚の違いへの配慮
- **色だけで意味を持たせない**。意味の決め手はいつも形か数：味方／魔物は台座と影の形、レア度は点の数と枠の形、危険は三角と「！」と点滅、塔の耐久はバーの長さと数
- 赤と緑で分けるものを作らない（耐久のバーの緑→危険のだいだいは、点滅と数で補う）
- 青（レア）と紫（エピック）は、赤の見え方が違う人には近く見えるおそれがあるので、明るさを 60 ほど離した（152 と 90）うえで、点の数と枠の二重で分ける
- 確かめ方：04 で、白黒（`スタイル見本/戦場_白黒.svg` と同じ彩度0のフィルタ）と、ブラウザの開発ツールの色覚のまねの表示で、戦場の画面を見る。確かめる問い：「魔物と英雄、4つのレア度、危険の印を、色を見ずに言えるか」

## 6. 画面の読みやすさ

### 6.1 目に入る順番（強い順）
1. 危険（だいだい・点滅・三角）：見落とすと負ける
2. 攻撃の輪：自分の指がどこを打っているか
3. パック（光の柱・レア度の色）：開けるかの判断（柱1）

地面 → 長く残る地面の効果 → 落ち影 → 光の柱 → キャラ・塔・パック（y の順） → 攻撃・呪文の効果 → ダメージの数・コイン → 攻撃の輪 → 危険の印 → HUD・置き場の板

### 6.3 白黒の確かめ（スタイル見本で見たこと）
`スタイル見本/戦場_白黒.svg` を、上の「白黒の明るさ」の計算で見た。この環境には画面に描いて見る道具がなく、ファイルをブラウザで開いての見た目の確認はできていない。SVG の中身は手で読み直しただけ。04 の前に、プロデューサーかオーナーがブラウザで開いて、崩れていないかを見る必要がある。
- 魔物（76〜100）は地面（184〜204）より大きく暗く、目（220）が光る → 読める
- 英雄の服（105）は魔物と同じくらい暗いが、台座（255）と肌・兜（215〜233）で分かれる → 読める。ただし台座を省くと読めなくなる。台座は必ず描く
- 塔の石（196）は道（204）と近い → 縁取り 3px と丘（164）と落ち影で分ける

## 7. UI の方向

### 7.1 字
| 用途 | 大きさ | 太さ |
|---|---|---|
| 最小（補助の字だけ） | 12px | ふつう |
| 本文・説明 | 15px | ふつう |
| ボタンの字 | 17px | 太字 |
| HUD の数 | 20px（コインは 17px） | 太字 |
| 見出し | 22px | 太字 |
| ウェーブの告知・結果の大きな数 | 32px | 太字 |
| 戦場のダメージの数 | 13px（会心 17px）、暗いふち 3px | 太字 |

- 書体は端末の書体（`-apple-system, "Hiragino Sans", sans-serif`）。読み込みが要らず、オフラインで使える。数は字の幅をそろえる（`font-variant-numeric: tabular-nums`）
- タイトルのロゴだけ、ゲームらしい書体を使ってよい（無料の書体を使うならライセンスを確かめる。外部に頼む候補）
- 字と地の明るさの比は 4.5:1 以上（Web の読みやすさの目安として広く使われる WCAG 2 の値。この作業では原文を開いて確かめていない）。白 `#FFFFFF` と板の紺 `#1F2A44` は約 14:1、補助の字 `#C9D3E6` と紺は約 9:1、主のボタンの字 `#2A1E10` と金 `#F2B33D` は約 9:1（この担当の計算）
- 数は 5〜6 文字に収める（「1.2万」「3.4億」。その先は 03）

### 7.2 押せる大きさ
- 押せる物は最小 48×48px（iOS の目安として広く知られる 44×44pt より少し大きく。44pt の出典は Apple Human Interface Guidelines だが、この作業では原文を開いて確かめていない）
- 主のボタン（買う、次のウェーブへ、前と同じものを買う）：高さ 56px、横は画面の幅から左右 16px ずつ引いた幅、または2列で幅 160px 以上
- 押せる物どうしのすき間 8px 以上
- 呪文の置き場：1枠 68×90px、2枠を横に並べて間 16px。枠の下のふちを、下の安全域の線より 28px 以上上に置く（基準の画面で y≈782）
- 置き場は半透明（80%）にし、下を通る魔物が透けて見えるようにする。カードが入ったら枠を光らせる（デザインの柱のとおり）
- 一時停止：HUD の右の端、44×44px（例外：上の端だが、めったに押さず、まちがえて押さないほうがよいので上に置く）

### 7.3 戦いの画面の情報の量
- 画面に常に出す字と数は HUD の3つだけ（塔の耐久、ウェーブの番号、コイン）＋一時停止。戦いの最中に説明の字は出さない（最初の5分の「1行だけ」の説明を除く）
- 英雄の名前・レベルは戦場に出さない（図鑑と強化画面で見る）。英雄の上に出すのは、強くなったときの小さな矢印 0.5 秒だけ
- 塔の耐久はバー＋数。減ったら塔のまわりが危険の色で一瞬光る

### 7.4 ショップ・強化画面・図鑑
- ショップ：戦場の上に下から板がせり上がる（戦場がうしろに見えて、「次のウェーブのため」とわかる）。上半分に「いまのコイン」と次のウェーブの番号、中ほどから下にパックの棚（2列のカード、1枚 160×120px 以上）、いちばん下に「前と同じものを買う」と「次のウェーブへ」（高さ 56px）
- パックの棚の絵：レア度の枠の色と点の数、その上に値段。開けた中身はここでは見せない（柱1）
- 強化画面：縦の一覧。1行 64px 以上、右に「強くする」ボタン（48px 以上）
- 図鑑：3列の升目。出会っていないものは影の形だけ（白黒の影）を見せる

### 7.5 擬似課金の店の見た目（方針だけ。中身はオーナーの確かめ待ち）
- 見た目は「課金の店のような棚」：「おすすめ」の帯（宝石の色 `#FF6FA8`。買う棚の見た目の品だけ。もらう棚の値札には付けない：2026-11-25 プロデューサー）、光る枠、まとめ買いの大きな札、棚の上の段ほど大きい品。地は夜の紺 `#1A1F3D` に金のふち `#FFC23A` で、ふつうのショップ（昼の紺の板）と一目で分ける
- ゲームの絵柄（木の棚、布の札、同じ縁取りと2段の色）で描く。端末の本物の買い物の確認画面、OS の決済の見た目、指紋・顔の確認に似た絵は使わない
- もらう棚の値札だけ、「¥」を小さく書く（宝石の色の札、「無料」の字とひし形と並べる）。買う棚の値段は宝石の数とひし形の印だけ。「$」は書かない（2026-11-25 擬似課金は案B寄り、プロデューサー。オーナーの確かめ待ち）
- 残り時間、「今だけ」、「残り○個」の札、急がせる点滅は使わない（柱3）
- 案Bの「ごっこ」の棚を足すことになった場合も、本物の買い物と見分けにくい見た目は作らない。その棚には「お遊び」とはっきり書く（文言は 07）

## 8. 音の方向
`game-audio-director` に判定してもらう前の案。

### 8.1 BGM
| 場面 | テンポ | 楽器と中身 |
|---|---|---|
| 戦い（ウェーブ） | 116〜124 BPM、長調 | 層で厚くする。第1〜4ウェーブ：弦のピチカート＋スネア・小さな太鼓／第5〜9：木管（フルート・クラリネット）のメロディを足す／第10〜：ホルンと金管の短い合いの手、ティンパニ／大物のウェーブ：全部＋低い弦 |
| ショップ | 92〜100 BPM | 戦いと同じ主題を、木管とハープ・チェレスタで軽く |
| 強化画面・図鑑 | 80〜88 BPM | 弦と木管、落ち着いた |
| タイトル | 自由 | 主題をホルンで |
| 結果（塔が壊された） | 3〜5 秒の短い曲 | 下がる3音のあと、明るく終わる（「もう一回」へ。暗くしない） |

- 各層の長さ 60〜90 秒で、つなぎ目なく回る。層はウェーブの区切りで足す（曲の途中で急に変えない）
- 使う言葉：軽い、はずむ、王道の行進、明るい金管の合いの手。使わない言葉：重厚な映画の予告編風、合唱、8ビットの電子音、ダンス音楽の低音、ホラーの不協和音

### 8.2 効果音
| 音 | 質感 | 長さ |
|---|---|---|
| タップ攻撃 | 乾いた軽い「トッ」。高さを毎回 ±5% ずらす。押さえ続けると続くので、音量は小さく、同時に 3 つまで | 0.08 秒 |
| 剣・槍・弓・魔法 | 剣は短い金属のこすれ、弓は「ひゅっ」、魔法は高い光の音。英雄の攻撃は指の音より小さく | 0.1〜0.2 秒 |
| 魔物が倒れる | 軽い「ぽん」。重い魔物ほど低い | 0.15 秒 |
| コインが入る | 小さな鈴。続くときは高さが少しずつ上がる | 0.1 秒 |
| パックを攻撃する | 紙と光の「パシッ」、ひびが増えるたびに少し高く | 0.1 秒 |
| パックが破れる | 紙の「ばりっ」＋レア度の響き。コモン：1音／レア：3音の上がる和音／エピック：5音＋きらめき／レジェンド：ホルンのファンファーレ 1.5 秒 | 0.3〜1.5 秒 |
| 英雄が立つ | 「とん」（台座が置かれる音）＋短い掛け声の代わりの楽器の1音（声は使わない） | 0.2 秒 |
| 呪文 | 火：「ごうっ」、雷：「ばちっ」、氷：「ぴきっ」、回復：上がる鐘 | 0.4〜0.8 秒 |
| ウェーブの始まり | 角笛 | 1.0 秒 |
| 塔が攻められる | 低い「ずん」。続くときは 0.5 秒に1回まで | 0.2 秒 |
| 危険（群れが近い） | 短い2音の警告。戦いの曲と同じ調 | 0.3 秒 |

- 音の大きさの順：危険・塔 ＞ 開封のレア度の響き ＞ 指の攻撃 ＞ 英雄の攻撃 ＞ 魔物が倒れる ＞ コイン。レジェンドのファンファーレの間は BGM を少し下げる（下げる量は 06・08 で `game-audio-engineer`）
- 同じ音は同時に 4 つまで（指の攻撃は 3 つ）
- 振動は使えないので（企画書）、手ごたえは音と絵で出す
- 仮の音：効果音は Web Audio の合成（音の波と雑音）で作れる。「ばりっ」の紙の音は合成だと安っぽくなりやすいので、本番は録音の素材か外部に頼む候補
- 気になる点：iOS の Safari・ホーム画面の Web アプリで音が鳴らない報告がある（企画書のリスク、市場調査 5）。最初のタップで音を鳴らせる状態にする作りは `game-preprod-tech`

## 10. 既存作に似すぎないために
- その作品の画面を、この担当は確かめていない。似ているかの確認は、画面を見られる人がゲート02の前に行う（未決 #1）
- 見る項目：主人公側の色の組み合わせ（この作品は青・白・金）、パックの形と色（この作品は縦長・星の印・上の破り口のギザギザ）、キャラの頭身と足もとの描き方（台座）、UI の板の色（紺）、タイトルのロゴ
- 似ていたら、変えやすい順に：パックの印（星→王国の紋）→ UI の板の色 → 主人公側の差し色。台座の描き方と形の言葉は読みやすさの芯なので、最後に変える
- 英雄・魔物の名前と姿は 07 で `game-art-concept` が作る。スライム・ゴブリンなどの一般的な魔物の種類は使ってよいが、特定の作品で知られた姿（色の組み合わせ、顔、決まった飾り）は写さない
