**この文書の読み方**
- GDD は目次と全体像。細かい動きは `03_仕様/機能仕様/` の各ファイルにある
- 数値は本文に書かない。`03_仕様/パラメータの名前.md` の名前（例 `tap.interval`）で書く。値と式の正は `03_仕様/パラメータ表.csv`（食い違ったら CSV を正とする）

- 用語は `開発チーム.md` の「表記」の言葉だけを使う（塔、魔物、タップ攻撃、コイン、ショップ、パック、開封、英雄、呪文カード、ウェーブ、ラン、名声、強化画面、図鑑、レア度）。既存作の固有の用語は使わない。特別な通貨は仮に「宝石」

## 2. コアループとメタループ

### コアループ（数秒〜1ウェーブ）
```
見る：四方の魔物、降ってきたパック（枠の色＝レア度）、塔の耐久、英雄の手が届かない方向
 ↓
決める：指でどこを受け持つか／いまパックを開けるか／呪文カードをいつ・どこに使うか
 ↓
動く：押さえ続けて攻撃の輪を当てる／パックに輪を向ける／呪文カードを使う
 ↓
結果：魔物が倒れてコインが入る／パックが破れて英雄が立つ・呪文カードが来る／塔が削られる
 ↓
また見る（英雄が増えたぶん、危ないところが変わる）
```
1ウェーブ：ウェーブ（守る・開ける・使う）→ 生き延びる → 名声とコイン → ショップ（次のウェーブのパックと品を買う）→ 次のウェーブで、買ったパックが降る。

### メタループ（ラン〜何時間）
```
ラン（第1ウェーブから、塔が壊されるまで）
 ↓ 塔が壊される
結果の画面（生き延びたウェーブ、前の記録まであと何ウェーブ、このランの名声）
 ↓
強化画面（名声で、タップ攻撃・英雄・呪文カード・塔・パックとコインを強くする。タップ攻撃の自動化、パックの種類を棚に並べるのもここ）
 ↓ （図鑑・宝石の店・設定もここから）
次のラン（前より強い → 登り直しが速い → 記録の先で、新しい魔物・パック・英雄に出会う）
```
- 数の伸びは2本立て：相場 `econ.market(n)`（コイン・値段・カードの力・タップ攻撃）と、魔物の耐久 `monster.hp.growth`。耐久のほうが速く伸びるので、ランはいつか終わる。名声の曲線は `fame.perWave(n)`（パラメータ表 1章・2章）
- 留守のあいだは何も進まない（仮決め。U5）

## 3. 操作（入力の一覧）

入力は指1本だけ（2本めの指は無視する）。連打は求めない。振動は使わない。

| 場面 | 入力 | 起きること | 仕様 |
|---|---|---|---|
| 戦場 | 押さえる・押さえ続ける | 指の上 `tap.ring.offset` に攻撃の輪が出て、`tap.interval` ごとに輪の中の魔物とパックを攻撃する | `タップ攻撃.md` |
| 戦場 | 押さえたまま動かす | 輪がついてくる | `タップ攻撃.md` |
| 戦場 | 離す／指が取られる（着信など） | 攻撃が止まる | `タップ攻撃.md` |
| 戦場（呪文 案S2 のとき） | 置き場のカードの上で押さえ始めて、戦場へ引いて離す | 離した輪の位置を中心に呪文が起きる | `呪文カード.md` |
| 戦場 | 右上の一時停止（押せる範囲 48×48） | 一時停止の板 | `戦場とウェーブ.md` |
| 板（ショップ・強化画面・図鑑・宝石の店・設定・結果） | ボタンを押す（最小 48×48、主のボタン 高さ 56） | それぞれの動き | 各仕様 |
| どこでも | ブラウザが裏に回る | 戦場：一時停止になり、戻ったら「タップで再開」の覆い。板の画面（ショップ・強化画面など）：覆いは出さずに戻り、最初のタップの中で音を起こす | `戦場とウェーブ.md`、`保存.md` |

## 4. ゲームの流れ（画面遷移）

```
起動
 └→ タイトル「タップで始める」（音を鳴らせる状態にする）
      ├ 保存なし → 戦場（第1ウェーブ。はじめの流れ）
      └ 保存あり → 保存した場面へ（ウェーブの始まり／ショップ／強化画面）

戦場（ウェーブ） ──生き延びた──→ ショップ ──「次のウェーブへ」──→ 戦場（次のウェーブ）
   │  └─ 一時停止 ⇄ 戦場（一時停止から「ランをやめる」→ 結果。仮決めで置く）
   └─ 塔が壊された ─→ 結果 ─→ 強化画面
                                ├→ 図鑑 → 強化画面
                                ├→ 宝石の店 → 強化画面
                                ├→ 設定（書き出し・読み込みを含む）→ 強化画面
                                └→「ランに出る」→ 戦場（第1ウェーブ）
```
- 最初に塔が壊されるまでは、強化画面・図鑑・宝石の店は開いていない（`はじめの流れと要素の解放.md`）。設定は一時停止の板から最初から開ける
- 終わり（エンディング）は置くか未決（オーナー）。置かない間は、ウェーブはどこまでも続く

## 6. キャラ・敵・アイテムの一覧

名前と姿は 07 で作る（`game-art-concept`・`game-story-lore`）。ここでは仮の ID と役だけ。数値はパラメータ表の名前（`パラメータの名前.md`）。

### 魔物（MVP 6〜8種＋大物。縦切りは 4種）
| 仮のID | 役 | 主なパラメータ |
|---|---|---|
| `slime` | ふつう | `monster.slime.*` |
| `wolf` | 速い | `monster.wolf.*` |
| `skeleton` | 硬い | `monster.skeleton.*` |
| `swarm` | 群れ（小さいのが固まって来る） | `monster.swarm.*`、`monster.swarm.groupSize` |
| `bat` | 飛ぶ | `monster.bat.*`、`monster.bat.flying` |
| `orc` | 大きい | `monster.orc.*` |
| `goblin` | ふつう（2種め。あれば） | `monster.goblin.*` |
| `boss` | 大物（節目のウェーブ） | `monster.boss.*`、`wave.boss.every` |

### 英雄（MVP 12〜16人。7役。縦切りは 6人）
| 役 | 攻撃のしかた（仮決め。`英雄.md`） | パラメータ |
|---|---|---|
| 剣士 | 近い1体を切る | `hero.<id>.*` |
| 弓使い | 遠い1体を射る | 同 |
| 魔法使い | 遠くの小さな範囲 | 同 |
| 僧侶 | 攻撃は弱い。塔の耐久を少しずつ戻す | 同 |
| 槍兵 | まっすぐの線で貫く | 同 |
| 盾の騎士 | 近くの魔物を遅くする | 同 |
| 斥候 | 速い連続攻撃、近い | 同 |
1つの役に、能力の違う英雄が1〜3人いる（例：同じ弓使いでも、飛ぶ魔物によく効く人、硬い魔物によく効く人）。個人の表は `game-design-combat` が作る。

### 呪文カード（MVP 8〜10種。縦切りは 3種）
仮の候補：火の玉（範囲の攻撃）、雷（つながって当たる）、氷（遅くする）、回復（塔の耐久を戻す）、突風（押し返す）、鼓舞（英雄の攻撃を速くする）など。表は `game-design-combat`。パラメータは `spell.<id>.*`。

### パック
- パックの種類は5つ（名前は仮）：見習い `novice`・鉄壁 `iron`・疾風 `wind`・秘術 `arcane`・王家 `royal`（`03_仕様/経済.md` 4.1）。縦切りは見習いと鉄壁の2つ。はじめのパックは、見習いを、はじめのランの初めだけコモン・英雄だけにしたもの。種類ごとに、値段・枚数・1枚めの種類・プール（出る英雄と呪文カードの ID と重み）・レア度の重みが違う。パラメータは `pack.<type>.*`
- レア度は 4段：コモン（白）・レア（青）・エピック（紫）・レジェンド（金）。縦切りは 3段（レジェンドなし）（仮決め。`パック.md`）。開いていない段を引いたら、開いている1つ下の段に落とす

### ショップのパック以外の品・強化画面の項目・宝石の品
- ショップの品：塔の修理・英雄の訓練・重ねの巻物・封の格上げ・呪文の巻物（S2 のとき）（`ショップ.md`、経済 3.2）
- 強化画面の項目（MVP は 12項目＋役ごと 7＋パックの種類を並べる 4、縦切り 6）：`強化画面.md`
- 宝石の品：見た目の品だけ（英雄の色違い・塔の見た目・パックの柄・開封の飾り・図鑑の飾り。`宝石の店.md`、経済 7.5）。がんばった証しは宝石で買えない「印」（記録の勲章・役の金の枠・レジェンドの記念の札。`強化画面.md`・`図鑑.md`）

## 7. ステージ・コンテンツの一覧
- 戦場は1つ（中心に塔、四方に道。北・東・南・西から魔物が来る）。章やステージには分けない
- ウェーブは式で作る（`wave.budget` など）。番号に上限はない。`wave.boss.every` ウェーブごとに大物の節目
- 新しい魔物は `monster.<type>.fromWave` から出る。新しいパックの種類・英雄・呪文カード・レア度は、記録や名声の強化で開く（`はじめの流れと要素の解放.md`）
- 縦切り（M3）の範囲：第1〜15ウェーブほど、魔物 4種、英雄 6人、呪文 3種、レア度 3段、強化 6項目（`02_プリプロ/計画.md` M3）

## 10. 保存（何を、いつ）
詳しくは `機能仕様/保存.md`。
- **いつ**：ウェーブが始まった瞬間、ショップが開いた瞬間、ショップで買ったとき、結果の画面が出たとき、強化画面で強くしたとき、宝石の店で宝石が動いたとき、設定を変えたとき
- **何を**：ランの状態（シード、ウェーブ、場面、コイン、塔の耐久、英雄と力、次に降るパックとその中身、置き場の呪文、ランの中の品の効き目と待っている封、不運よけの数、このランの名声、前と同じものを買うの記録）と、ランをまたぐもの（名声、強化、図鑑、記録、印、宝石と宝石の品、解放の状態、はじめの流れの進み、設定）
- **ウェーブの途中に書くとき**（設定・読み込み）：ランの部分はウェーブの始まりのもの、ランをまたぐ部分だけ今の値。ランの途中の書き出しは、そのウェーブの始まりの状態。ランの途中で読み込んだら、今のランは捨てて、読んだ保存の場面から
- **戻り方**：ウェーブの途中でやめたら、そのウェーブの始まりから（負けそうなときに閉じて戻るのも許す。仮決め）。魔物の位置は保存しない
- **形**：localStorage、1つ前の保存も残す、版の頭と指紋つき、書き出し・読み込み（文字・ファイル）
