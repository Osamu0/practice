# 機能仕様：HUD と数の表記（画面の帯、大きな数の短い表記、物の数の上限）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
画面の帯と大きさは `02_プリプロ/アートディレクション.md` 5章・7章、数の表記は `02_プリプロ/技術選定.md` 3.3 の確認版の形に合わせた。

- **目的（どの柱のためか）**：前提（縦持ちで読めて押せる、桁が伸びても数字がはみ出さない）。柱2（指と手のひらで隠れる下に大事なものを置かない）

## 画面の帯（基準の画面 390×844、論理 px）
| 帯 | 範囲 | 置くもの |
|---|---|---|
| 上の安全域 | 0〜`safe-area-inset-top`（基準 47） | 何も置かない |
| HUD | 52〜104 | 塔の耐久（バー＋数）、ウェーブの番号、コイン、一時停止（右の端） |
| 戦場の中心 | 104〜680 | 塔（高さ `field.tower.yRatio`）、魔物、英雄、パック |
| 押す帯 | 680〜790 | 呪文の置き場（案S2）。案S1 では空き（戦場） |
| 下の端 | 810〜844（下の安全域） | 何も置かない |
- 横幅に合わせて全体を拡大縮小する（横 375 なら 0.96 倍）。縦が足りない機種は戦場の上下を切る。塔はいつも見える
- 戦場の Canvas に数字（HUD）は描かない。HUD は DOM（技術選定 5.4 で見つけた重なり）

## HUD
- いつも出すのは3つと一時停止だけ：塔の耐久（バー＋数）、「第N ウェーブ」、コイン（印＋数）、一時停止
- 戦いの最中に説明の字を出さない（はじめの流れの1行を除く）。英雄の名前・段は戦場に出さない
- 字の大きさはアート 7.1（HUD の数 20px、コイン 17px）

## 数の表記
- 9999 まではそのまま（例 8,750 は「8750」）
- 1万から：単位（万・億・兆・京）で割った数を、有効数字3けたほど（`ui.num.sigDigits`）で出す。確認版 `num.ts` の形のとおり：10 より小さければ小数2けた、100 より小さければ小数1けた（どちらも四捨五入。末尾の 0 と小数点は消す）、100 以上は整数（切り捨て）
- `ui.num.expFrom` からは「1.2e20」の形（仮数は小数1けた、四捨五入。指数が3けたなら仮数は整数「2e308」）
- 例（確認版のテストと同じ）：0 →「0」、9999 →「9999」、12345 →「1.23万」、99999999 →「9999万」、1e8 →「1億」、3.4e12 →「3.4兆」、5.6e16 →「5.6京」、1.234e20 →「1.2e20」、1.79e308 →「2e308」、Infinity →「∞」
- どの数も **6文字以内**（`ui.num.maxChars`）。Infinity は「∞」。NaN は「?」と見せる（不具合の印。出たら不具合として直す）
- 確認版 `02_プリプロ/tech_check/src/core/num.ts` の形と同じ
- 数の字は幅をそろえる（tabular-nums）
- どこから e 表記にするか、字の形の最後の決めは `game-design-ux`

## ダメージの数
- 戦場に同時に `limit.damageText.max`（12）まで。こえたら、同じ場所（`ui.damageText.mergeRadius` の内）の数をまとめて合計を1つ出す
- `ui.damageText.time`（0.6秒）で消える

## 物の数の上限（技術選定 6章の目安。04 の実機で決め直す）
| 物 | 名前 |
|---|---|
| 魔物 | `limit.monster.max` |
| 大物 | `limit.boss.max` |
| 英雄 | `hero.field.max` |
| 弾 | `limit.projectile.max` |
| 粒（光・破片） | `limit.particle.max` |
| ダメージの数 | `limit.damageText.max` |
| パック | `limit.pack.max` |
| 開封の大きな光 | `limit.bigOpenFx.max` |
- こえたときの決まり：魔物は湧きを待つ（`魔物.md`）、英雄は重なる（`英雄.md`）、弾は当たりだけ（`英雄.md`）、粒は古いものから消す、数はまとめる、パックは買えない（`ショップ.md`）、大きな光は小さな光にする（`パック.md`）
- 上限をこえる伸びは、1体・1人・1つの強さで出す（`game-spec-balance`）

## 入力
HUD で押せるのは一時停止だけ（`戦場とウェーブ.md`）。HUD の上で押さえ始めてもタップ攻撃にならない。

## 状態と遷移
| 表示 | 状態 | きっかけ |
|---|---|---|
| 塔の耐久のバー | ふつう → 危険（点滅） | 耐久が `tower.hp.dangerRatio` を下回った |
| 塔の耐久のバー | 危険 → ふつう | 上回った |
| コイン | 数が増える（吸い込みのあと） | 魔物が倒れた |

## 数値
`ui.num.sigDigits`、`ui.num.expFrom`、`ui.num.maxChars`、`ui.damageText.time`、`ui.damageText.mergeRadius`、`limit.*`、`tower.hp.dangerRatio`

## 例外・境界
- **0**：「0」
- **負**：出さない（コインや名声が負になることはない。なったら 0 と見せ、記録に残す）
- **1e308 をこえる**：「∞」。計算は止めない。ふつうに遊べる範囲で 1e300 未満にとどめる（技術選定 T2、balance への条件）
- **小数**：耐久などは切り上げて整数で見せる。0 より大きく 1 より小さい耐久は「1」
- **縦が足りない機種**：HUD の帯は切らない（戦場の上下を切る）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| コインが入る | HUD のコインの印がはねる | 小さな鈴（続くと高さが上がる） |
| 塔が危険 | バーが危険の色で点滅 | — |

## 受け入れ条件
- [ ] 上の「例」の10個の数が、それぞれ例のとおりの字で出る（9999 →「9999」、12345 →「1.23万」、1e8 →「1億」、1.234e20 →「1.2e20」、1.79e308 →「2e308」など。`ui.num.expFrom` が既定の値のとき）
- [ ] 1 から 1e308 までのどの数も、6文字以内で出る
- [ ] Infinity は「∞」と出る
- [ ] iPhone 17 相当（402×681）と iPhone SE 相当（375×667）の両方で、HUD の3つの数と一時停止が上の端（HUD の帯）にあり、横スクロールがない
- [ ] 戦いの最中、HUD の3つと一時停止のほかに、字が常に出ていない（ダメージの数・はじめの1行・「保存できません。書き出してください」の1行を除く）
- [ ] 戦場のダメージの数が 12 個をこえない
- [ ] 下の端（下の安全域）に押せるものがない
- [ ] HUD の上で押さえ始めても、タップ攻撃は起きない
- [ ] 画面の物の数が `limit.*` のそれぞれをこえない（負荷の試しで、魔物・弾・粒を上限の倍の数だけ出そうとして確かめる）
