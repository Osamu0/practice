# 機能仕様：はじめの流れと要素の解放

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
もとは `02_プリプロ/デザインの柱.md` の「最初の5分の流れ」「最初の1時間」と企画書の「要素を開ける順番」。説明の文は 07。

- **目的（どの柱のためか）**：柱3（最初の数分は「倒す」だけ。読ませるより、起きたことで覚えさせる）と柱1（最初のパックで「開けると英雄が立つ」を必ず見せる）。序盤が苦しすぎるリスク（計画 G5）への手当て

## 説明の決まり
- 説明は1画面1行まで。戦いの最中は、下の表の「1行」だけ。読み終えるのを待たない（戦場は止めない）
- 同じ1行は二度出さない（はじめの流れの進みを保存する）

## 要素の解放（はじめのランのあと）
| 要素 | 開く条件（仮。値は balance・economy） | パラメータ |
|---|---|---|
| ショップ | 最初の第1ウェーブのあと | — |
| 呪文カード | はじめのランの第4ウェーブ | `intro.firstSpellWave` |
| レア度 レア | はじめのランの第3ウェーブ | `unlock.rare.fromWave` |
| レア度 エピック | 記録が `unlock.epic.record` に届いた | `unlock.epic.record` |
| レア度 レジェンド | 記録が `unlock.legend.record` に届いた | `unlock.legend.record` |
| 強化画面・図鑑 | 最初に塔が壊れた | — |
| タップ攻撃の自動化（強化の項目） | 最初に塔が壊れたあと、項目が見える。2〜3回めのランまでに名声で買える値段 | `unlock.tapAuto`、`upgrade.tapAuto.costBase` |
| 宝石の店 | 最初に塔が壊れた（economy が変えてよい） | `unlock.gemShop` |
| パックの種類 | 種類ごとの条件（記録・強化） | `pack.<type>.unlock` |
| 新しい魔物 | ウェーブ番号 | `monster.<type>.fromWave` |
| 英雄・呪文カード | そのカードが入っているパックの種類が開いた、かつそのカードのレア度が開いた | `pack.<type>.pool`、上のレア度の条件 |

- レア度の開く条件を満たす前は、パックのレア度の重みのうち、開いていない段は 0 として引く（`パック.md` の手順で、開いていない段の候補は無いものとして下の段へ）
- 解放は、ランの途中でも条件を満たした瞬間に効く（次に引くパックから）。ただし、すでに買ったパックの中身は変わらない

## 入力
はじめの流れのための特別な入力はない。説明の1行は押さなくても `ui.hint.time` 秒で消える。押すと早く消える。

## 例外・境界
- **はじめのランを途中でやめた**（ランをやめる）：最初に塔が壊れたのと同じ扱い（強化画面が開く）
- **はじめのランで、第4ウェーブより前に塔が壊れた**：呪文カードの必ず出る1枚は、次のランの第4ウェーブで出す（出るまで続ける）
- **最初のショップで何も買わなかった**：第2ウェーブにパックは降らない。「パックも攻撃すると開きます」は、初めてパックが降ったときに出す。最初のパックの1枚めは英雄、も初めて開けたパックで守る
- **第4ウェーブにパックが無い**：必ず出る呪文は、次に開けるパックの1枚に入れる
- **保存から読み込んだ**：はじめの流れの進みも戻る

## 受け入れ条件
- [ ] 保存がない状態で「タップで始める」を押したら、すぐ戦場の第1ウェーブが始まり、最初の魔物は東から来る
- [ ] 第1ウェーブの始まりに「押さえると攻撃」の1行が出て、戦場は止まらない
- [ ] 第1ウェーブのあとのショップに並ぶパックの種類は1つだけで、少なくとも1個は買える
- [ ] そのプレイヤーが初めて開けたパックの1枚めは英雄
- [ ] はじめのランの第4ウェーブで、開けたパックから呪文カードが少なくとも1枚出る
- [ ] はじめのランの第3ウェーブより前に、レアのパックは降らない
- [ ] 最初に塔が壊れる前は、強化画面・図鑑・宝石の店に行けない。壊れたあとの結果の画面から強化画面へ行ける
- [ ] 一度出た説明の1行は、アプリを開き直しても二度と出ない
- [ ] 記録が `unlock.epic.record` に届く前は、エピックのカードは出ない
- [ ] 説明の1行は、押さなくても `ui.hint.time` 秒で消える
