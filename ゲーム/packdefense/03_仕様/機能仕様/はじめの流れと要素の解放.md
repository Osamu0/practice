### 第1ウェーブの方向（`intro.wave1.dirOrder`）
- はじめのランの第1ウェーブだけ、湧きの予定の方向をこの並びで決める。**`spawn.packet.*` の「組の中はちがう方向」より優先**する（`魔物.md`）
- 予定の前の 1/4 は東だけ（同じ組の湧きも全部東から）。次の 1/4 は東と西を交互。そのあとは四方（同じ重み）

### 最初のショップのコイン（`intro.firstShop.coinMin`）
- はじめのランの最初のショップが開いたとき、コインが `intro.firstShop.coinMin` より少なければ、足りない分を足す（第1ウェーブで取りこぼしても1つは買える）

### 必ず出る呪文（`intro.firstSpellWave`）
- はじめのランで、第（`intro.firstSpellWave` − 1）ウェーブのあとのショップで**最初に買ったパックの2枚めを呪文にする**。決めるのは買った瞬間（ほかのカードと同じ。`パック.md`）
- そのショップで買わなければ、そのあと次に買うパックで同じことをする（このランでまだ渡していなければ、塔が壊れたあとの次のランにも続ける）
- 一度渡したら「済」になり、二度と働かない。「済／まだ」は保存する
- 呪文のレア度とカードは、ふつうの手順（`パック.md` の 2・3）で引く

### レアの出始め（`unlock.rare.fromWave`）
- `unlock.rare.fromWave` は「**そのパックが降るウェーブの番号**」。はじめのランでは、降るウェーブがこの番号より前のパック（＝第（`unlock.rare.fromWave` − 1）ウェーブより前のショップで買ったパック）は、全部コモンの英雄にする（買った瞬間に決める）
- 2回めのランからは、レアは最初から開いている

| レア度 レア | はじめのランで、第 `unlock.rare.fromWave` ウェーブに降るパックから | `unlock.rare.fromWave` |
| レア度 エピック | 記録が `unlock.epic.record` に届いた | `unlock.epic.record` |
| レア度 レジェンド | 記録が `unlock.legend.record` に届いた（MVP） | `unlock.legend.record` |
| 強化画面・図鑑 | 最初に塔が壊れた | — |
| タップ攻撃の自動化（強化の項目） | 最初に塔が壊れたあと、項目が見える | `unlock.tapAuto`、`upgrade.tapAuto.costBase` |
| 宝石の店 | 最初に塔が壊れたあと | `unlock.gemShop` |
| パックの種類（見習い以外） | **影**：その種類の `pack.<type>.unlock` のウェーブを生き延びたことがある（このランを含む）。**並ぶ**：強化画面の `packType.<type>` を名声で買った（MVP。`強化画面.md`）。縦切り（M3）では `packType` の項目を置かず、鉄壁は影の条件を満たしたら並ぶ | `pack.<type>.unlock`、`upgrade.packType.<type>.cost` |
| 新しい魔物 | ウェーブ番号 | `monster.<type>.fromWave` |
| 英雄・呪文カード | そのカードが入っているパックの種類が並んだ、かつそのカードのレア度が開いた | `pack.<type>.pool`、上のレア度の条件 |
| 印（宝石で買えない見た目） | 記録の節目・図鑑の役をそろえた・レジェンドの初開封（`図鑑.md`・`強化画面.md`） | `mark.*` |

- レア度の開く条件を満たす前に、その段を引いたら、**開いている1つ下の段に落とす**（`パック.md` の手順 2）
- 解放は、ランの途中でも条件を満たした瞬間に効く（次に買うパックから）。ただし、すでに買ったパックの中身は変わらない

## 入力
はじめの流れのための特別な入力はない。説明の1行は押さなくても `ui.hint.time` 秒で消える。押すと早く消える。

## 例外・境界
- **はじめのランを途中でやめた**（ランをやめる）：最初に塔が壊れたのと同じ扱い（強化画面が開く）
- **必ず出る呪文の前に塔が壊れた**：次のランの、第（`intro.firstSpellWave` − 1）ウェーブのあとのショップから同じ決まりで渡す（出るまで続ける）
- **最初のショップで何も買わなかった**：第2ウェーブにパックは降らない。「パックも攻撃すると開きます」は、初めてパックが降ったときに出す。最初のパックの1枚めは英雄、も初めて開けたパックで守る
- **必ず出る呪文のパックを開けずにランが終わった**：「済」のまま（買った瞬間に渡したので。開けなかったのはプレイヤーの選び）
- **パックの枚数が1枚のとき**：枚数は2枚より少なくならない（`pack.<type>.cards`）ので起きない。変えるなら、この決まりを直す
- **保存から読み込んだ**：はじめの流れの進み（1行・必ず出る呪文）も戻る

## 受け入れ条件
- [ ] 保存がない状態で「タップで始める」を押したら、すぐ戦場の第1ウェーブが始まり、最初の魔物は東から来る
- [ ] はじめのランの第1ウェーブで、湧きの予定の前の 1/4 は全部東から来る（同じ時刻の組も東から）
- [ ] 第1ウェーブの始まりに「押さえると攻撃」の1行が出て、戦場は止まらない
- [ ] 第1ウェーブのあとのショップに並ぶパックの種類は1つだけで、コインが `intro.firstShop.coinMin` 以上ある
- [ ] そのプレイヤーが初めて開けたパックの1枚めは英雄
- [ ] はじめのランで、降るウェーブが `unlock.rare.fromWave` より前のパックは、保存の中身で全部コモンの英雄になっている
- [ ] はじめのランの第（`intro.firstSpellWave` − 1）ウェーブのあとのショップでパックを買ったら、その直後の保存の中身で、そのショップで最初に買ったパックの2枚めが呪文カードになっていて、「必ず出る呪文」が済になっている
- [ ] そのショップで何も買わずに進んだら、次にパックを買ったショップの直後の保存で、最初に買ったパックの2枚めが呪文カードになっている
- [ ] 最初に塔が壊れる前は、強化画面・図鑑・宝石の店に行けない。壊れたあとの結果の画面から強化画面へ行ける
- [ ] 一度出た説明の1行は、アプリを開き直しても二度と出ない
- [ ] 記録が `unlock.epic.record` に届く前は、エピックのカードは出ない（引いたらレアに落ちる）
- [ ] 鉄壁の `pack.iron.unlock` のウェーブを生き延びる前は、ショップに鉄壁の札も影も出ない。生き延びたら影が出る（MVP）／並ぶ（縦切り）
- [ ] 説明の1行は、押さなくても `ui.hint.time` 秒で消える
