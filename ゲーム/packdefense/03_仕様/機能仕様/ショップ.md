# 機能仕様：ショップ（パックと、パック以外の買えるもの）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値の正は `03_仕様/パラメータ表.csv`。
品揃え・値段の形は `03_仕様/経済.md` 3.2・4章。この文書は、棚の形・買う流れ・決まりを書く。

- **目的（どの柱のためか）**：柱1（買ったパックは次のウェーブの戦場で開ける。ショップでは開かない）と柱3（待たない。前と同じものを買うボタンで、毎回の同じ買い物をさせない）。オーナーの構造⑥（コインで、パックと各種の買えるもの）

## プレイヤーから見た動き
- ウェーブ n を生き延びたら、戦場の上に下から板がせり上がる（戦場がうしろに見える）
- 板は3つの帯に分ける。**上の帯と下の帯は動かない。間の棚だけを縦になぞってスクロールする**
  - 上の帯（固定）：いまのコイン、次のウェーブの番号、塔の耐久、「次のウェーブに降るパック」の列
  - 間の棚（縦スクロール）：**パックの棚**（2列のカード、1枚 160×120 以上）。その下に**品の棚**
  - 下の帯（固定）：「前と同じものを買う」と「次のウェーブへ」（高さ 56）
- パックの札：枠の絵・名前・値段・「出るもの」（プールの顔ぶれ：英雄と呪文の小さな絵。図鑑で出会っていないものは影）と、**レア度ごとの割合の数を1行**（例「コモン 80% レア 18% エピック 2%」。いま開いていないレア度は、落ちた先の段に足した数で出す）
- 押して買う。買ったパックは上の帯の「次のウェーブに降るパック」の列に並ぶ（中身とパックのレア度は見せない）
- 制限時間はない。「次のウェーブへ」を押すまで待つ（残り時間の表示もない。柱3）
- コインはランの中だけのもの。ランが終わると消える
- **ショップの相場** ＝ `econ.market(n)`。パックと品の値段は、表の値 × この相場（品によっては、さらにランの中で買った回数の分だけ上がる）

## コインの入り
| いつ | 量 |
|---|---|
| ランの始め | `coin.start` ＋ `upgrade.startCoin.effect` × 段 |
| 魔物を倒した | `魔物.md` の式（重み × `wave.coin.base` × 相場 ÷ `wave.budget(n)`） |
| ウェーブを生き延びた | `wave.clear.coin` ＝ `wave.clear.coinRatio` × このウェーブで倒した魔物のコインの合計 |
| 強化 `coinGain`（MVP） | 上の2つ（倒した・生き延びた）に `upgrade.coinGain.effect`^段 をかける |
| はじめのランの最初のショップ | `intro.firstShop.coinMin` に足りない分を足す（`はじめの流れと要素の解放.md`） |

## 品の棚（パック以外。経済 3.2）
品は全部「ランの中だけ」。強化画面の項目（名声）とは別もの。
| 品（仮の名） | ID | 値段 | 効き目 | 決まり | 入る版 |
|---|---|---|---|---|---|
| 塔の修理 | `repair` | `shop.item.repair.price` × 相場 | 塔の耐久を最大の `shop.item.repair.effect` 戻す（最大はこえない） | 満タンなら押せない。1回のショップで `shop.item.repair.buyMax` まで | 縦切りから |
| 英雄の訓練 | `drill` | `shop.item.drill.price` × 相場 × `shop.item.drill.priceGrowth`^（このランで買った回数） | このランの英雄全員の威力に「1 ＋ `shop.item.drill.effect` × 回数」（足し算で重なる。`英雄.md`） | 戦場に英雄がいなくても買える（あとから立つ英雄にも効く） | MVP |
| 重ねの巻物 | `stack` | `shop.item.stack.price` × 相場 × `shop.item.stack.priceGrowth`^（買った回数） | 戦場の英雄のうち **`hero.power` がいちばん小さい英雄**（同じなら塔からいちばん遠い）の `hero.power` に「相場 × `hero.stack.dmgMul`」を足す。選ばせない | 戦場に英雄がいなければ押せない | MVP |
| 封の格上げ | `seal` | `shop.item.seal.price` × 相場 | **このあと次に買うパック1つの1枚めを、レア以上にする**（引き方は `パック.md` の不運よけと同じ）。中身もパックのレア度も見せない（わかるのは「最低がレア」だけ） | 1回のショップで `shop.item.seal.buyMax` まで。封を待っているあいだは、もう1つ買えない。パックがもう買えない（上限・コイン）ときは押せない | MVP |
| 呪文の巻物 | `spell` | `shop.item.spell.price` × 相場 | 置き場に、いま棚に並んでいるパックの種類のプールから呪文カード1枚（力はこのショップの相場） | 案S2 のときだけ置く。置き場がいっぱいなら押せない | MVP（S2 のとき） |
- 品の買える数は `shop.item.<id>.buyMax`、値上がりは `shop.item.<id>.priceGrowth`（1 なら上がらない）
- 封の格上げを買ったら、上の帯の「次に買うパック」の場所に封の印を出す（どのパックに効くかがわかるように）
- 宝石は、このショップでは使わない・もらえない（宝石の店は別。`宝石の店.md`）
- 入れない品（経済 3.2）：品揃えの入れ替え、中身を見る品、時間で値段が下がる品

## 入力
| 入力 | 起きること |
|---|---|
| パックの札を押す | コインが足りて、置ける数に空きがあれば1つ買う（中身はこの瞬間に決まる。`パック.md`） |
| 品の札を押す | 買える条件を満たせば1つ買い、すぐ効く（修理・訓練・重ね・呪文）か、次に買うパックで効く（封） |
| 「前と同じものを買う」 | 前のショップで買った組を、買える分だけ、前と同じ順に買う |
| 「次のウェーブへ」 | 板が下がり、次のウェーブの始まり |
| パックの札の「出るもの」を押す | そのパックの種類のプールの一覧（図鑑の小さな板）と割合の数。閉じると戻る |
| 間の棚を上下になぞる | 棚のスクロール（上下の帯は動かない） |

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 開く | 板がせり上がる（`shop.open.fxTime`）。保存する | 選ぶ | 演出の終わり |
| 選ぶ | 買う・見る | 選ぶ | 買った（保存する） |
| 選ぶ | — | 閉じる | 「次のウェーブへ」 |
| 閉じる | 板が下がる | ウェーブの始まり | 演出の終わり |

## 「前と同じものを買う」の決まり
- 「前のショップ」＝このランの1つ前のショップ。このランの最初のショップでは、前のランの最初のショップ
- 前に買った品とパックの並びを、上から1つずつ買う。コインが足りない・置ける数がない・買えない条件（満タンなど）・まだ並んでいない種類のものは飛ばす。値段は今の相場
- 買えなかったものがあれば、板に1行「買えなかったもの：〇〇」を出す
- 前の記録がない（そのプレイヤーの最初のショップ）・何も買えない とき、ボタンは押せない色
- 押したあと、さらに1つずつ買い足してよい

## 数値
`econ.market`、`pack.<type>.price`、`pack.<type>.priceGrowth`、`shop.pack.buyMax`（＋ `upgrade.packSlots` の段）、`limit.pack.max`、`shop.item.<id>.price`・`.priceGrowth`・`.buyMax`・`.effect`（`repair`・`drill`・`stack`・`seal`・`spell`）、`hero.stack.dmgMul`、`coin.start`、`upgrade.startCoin.effect`、`upgrade.coinGain.effect`、`wave.coin.base`、`wave.clear.coin`、`wave.clear.coinRatio`、`intro.firstShop.coinMin`、`pack.<type>.rarityWeights`（割合の数の表示）、`shop.open.fxTime`

## 例外・境界
- **0**：コインが 0 でも開く。何も買わずに「次のウェーブへ」を押せる
- **最大**：パックは「持ち越しの数＋このショップで買った数」が `limit.pack.max` に、または買った数が `shop.pack.buyMax`（`packSlots` の段を足した数）に達したら、パックの札が押せない色になる（理由を1行で）
- **コインが足りない**：札が押せない色。押すと「コインが足りません」を1行（音は小さく）
- **2回押し**：1回押すごとに1つ買う。0.2秒より短い間隔の2回めは無視（まちがいの連打を防ぐ）
- **返す**：買ったものを返す機能は置かない（仮決め。中身を買ったときに決めるので、返して買い直すと中身の引き直しになるため）
- **封を買ってパックを買わずに閉じた**：未決（下の表）。既定は、封は次のショップの最初のパックまで持ち越す
- **中断**：ショップで閉じたら、次は同じショップから（買ったもの・待っている封は保存済み）
- **一時停止**：ショップでは時間が進まないので要らない。裏に回っても覆いは出さない
- **ラン以外**：コインは結果の画面で消える。名声・宝石には変わらない（経済 2.1）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 開く | 下から板 | ショップの BGM（戦いと同じ主題を軽く） |
| 買った | 札が光り、パックが上の列へ飛ぶ。コインの数が減る | 小さな鈴の下がる音 |
| 封を買った | 上の帯に封の印 | 小さな鈴 |
| 買えない | 札が小さく揺れる | 小さな鈍い音 |
| 閉じる | 板が下がる | 角笛へつなぐ |

## 受け入れ条件
- [ ] ウェーブを生き延びたら、ショップの板が開き、いまのコインと次のウェーブの番号が見える
- [ ] 間の棚を上下になぞってスクロールしても、上の帯（コイン・次のウェーブ）と下の帯（「前と同じものを買う」「次のウェーブへ」）は動かず、いつも見えている（402×681 と 375×667 の両方で）
- [ ] ショップには制限時間がなく、何分待っても「次のウェーブへ」を押すまで閉じない
- [ ] 第 n ウェーブのあとのショップで、パックの値段が `pack.<type>.price × econ.market(n)` と出る
- [ ] コインが値段以上あるときにパックの札を押したら、コインが値段だけ減り、「次のウェーブに降るパック」の列に1つ増える
- [ ] コインが値段より少ないとき、札を押してもコインもパックも変わらない
- [ ] 買ったパックの中身とパックのレア度は、ショップのどこにも出ない
- [ ] パックの札に、その種類のレア度ごとの割合の数が1行で出る（いまの解放の状態で、合計 100%）
- [ ] 持ち越しのパックの数と買った数の合計が `limit.pack.max` になったら、パックの札は押せない
- [ ] 1回のショップで `shop.pack.buyMax`（`packSlots` の段を足した数）個買ったら、パックの札は押せない
- [ ] パックの札の「出るもの」を押したら、その種類のプールの英雄と呪文カードの一覧が出て、図鑑で出会っていないものは影で出る
- [ ] 「前と同じものを買う」を押したら、前のショップで買った組を前と同じ順に、買える分だけ買い、買えなかったものの名前を1行で出す
- [ ] このランの最初のショップで「前と同じものを買う」を押したら、前のランの最初のショップの組を買う
- [ ] 一度も買い物をしたことがないとき、「前と同じものを買う」は押せない
- [ ] 塔の修理は、塔の耐久が満タンのとき押せない。押せるときに買ったら、耐久が最大の `shop.item.repair.effect` 戻る（最大はこえない）
- [ ] 英雄の訓練を同じランで2回買ったら、2回めの値段が `shop.item.drill.price × econ.market(n) × shop.item.drill.priceGrowth` で、英雄の威力が「1 ＋ 2 × `shop.item.drill.effect`」倍になる
- [ ] 重ねの巻物を買ったら、戦場で `hero.power` がいちばん小さい英雄の `hero.power` が `econ.market(n) × hero.stack.dmgMul` 増える。英雄がいないときは押せない
- [ ] 封の格上げを買ってからパックを買ったら、その直後の保存の中身で、そのパックの1枚めのレア度がレア以上になっている。ショップの画面には、そのパックの中身もレア度も出ない
- [ ] 0.2秒より短い間隔で札を2回押したら、1つだけ買う
- [ ] 買ったら保存され、そのあとアプリを閉じて開くと、同じショップで同じコインと同じ買った列から始まる
- [ ] ランが終わったら、コインは 0 になり、次のランは `coin.start`（強化をかけた値）から始まる
- [ ] ショップの画面に、宝石の値段の品・宝石をもらう棚はない
