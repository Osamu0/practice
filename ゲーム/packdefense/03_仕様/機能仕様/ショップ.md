# 機能仕様：ショップ（パックと、パック以外の買えるもの）

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
**品揃え・値段・上がり方は `game-design-economy` が設計中**。この文書は、棚の形・買う流れ・決まりの骨を書く。

- **目的（どの柱のためか）**：柱1（買ったパックは次のウェーブの戦場で開ける。ショップでは開かない）と柱3（待たない。前と同じものを買うボタンで、毎回の同じ買い物をさせない）。オーナーの構造⑥（コインで、パックと各種の買えるもの）

## プレイヤーから見た動き
- ウェーブを生き延びたら、戦場の上に下から板がせり上がる（戦場がうしろに見える）
- 板の上半分：いまのコイン、次のウェーブの番号、塔の耐久
- 中ほど：**パックの棚**（2列のカード、1枚 160×120 以上）。種類ごとに、枠の絵・名前・値段・「出るもの」（プールの顔ぶれ：英雄と呪文の小さな絵。図鑑で出会っていないものは影）
- その下：**品の棚**（パック以外の買えるもの）
- いちばん下：「前と同じものを買う」と「次のウェーブへ」（高さ 56）
- 押して買う。買ったパックは板の上の「次のウェーブに降るパック」の列に並ぶ（中身とパックのレア度は見せない）
- 制限時間はない。「次のウェーブへ」を押すまで待つ（残り時間の表示もない。柱3）
- コインはランの中だけのもの。ランが終わると消える

## 品の型（パック以外）
品揃えは economy。仕様が受け持つ「型」：
| 型 | 中身の例（仮） | 決まり |
|---|---|---|
| 回復 | 塔の耐久を戻す | 最大はこえない。満タンなら買えない |
| ランの中の強化 | このランのあいだ、タップ攻撃の威力・英雄の攻撃・呪文の強さなどを上げる | ランが終わると消える。強化画面の項目（名声）とは別もの |
| 英雄を鍛える | 戦場の英雄1人の重ねを+1（どの英雄かは、重ねがいちばん少ない英雄。選ばせない） | 戦場に英雄がいなければ買えない |
| 呪文を足す | 置き場に呪文カード1枚（プールから引く。案S2 のときだけ） | 置き場がいっぱいなら買えない |
- 品にも、1回のショップで買える数 `shop.item.<id>.buyMax`、ランの中で買うたびに上がる値段 `shop.item.<id>.priceGrowth` を置ける
- 宝石は、このショップでは使わない・もらえない（宝石の店は別。`宝石の店.md`）

## 入力
| 入力 | 起きること |
|---|---|
| パックの札を押す | コインが足りて、置ける数に空きがあれば1つ買う |
| 品の札を押す | 買える条件を満たせば1つ買い、すぐ効く（回復など）か、次のウェーブから効く |
| 「前と同じものを買う」 | 前のショップで買った組を、買える分だけ、前と同じ順に買う |
| 「次のウェーブへ」 | 板が下がり、次のウェーブの始まり |
| パックの札の「出るもの」を押す | そのパックの種類のプールの一覧（図鑑の小さな板）。閉じると戻る |

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 開く | 板がせり上がる。保存する | 選ぶ | 演出の終わり |
| 選ぶ | 買う・見る | 選ぶ | 買った（保存する） |
| 選ぶ | — | 閉じる | 「次のウェーブへ」 |
| 閉じる | 板が下がる | ウェーブの始まり | 演出の終わり |

## 「前と同じものを買う」の決まり
- 「前のショップ」＝このランの1つ前のショップ。このランの最初のショップでは、前のランの最初のショップ
- 前に買った品と数の並びを、上から1つずつ買う。コインが足りない・置ける数がない・買えない条件（満タンなど）のものは飛ばす
- 買えなかったものがあれば、板に1行「買えなかったもの：〇〇」を出す
- 前の記録がない（そのプレイヤーの最初のショップ）・何も買えない とき、ボタンは押せない色
- 押したあと、さらに1つずつ買い足してよい

## 数値
`pack.<type>.price`、`pack.<type>.priceGrowth`、`shop.pack.buyMax`（1回のショップで買えるパックの数）、`limit.pack.max`、`shop.item.<id>.price`、`shop.item.<id>.priceGrowth`、`shop.item.<id>.buyMax`、`shop.item.<id>.effect`、`coin.start`（ランの始めのコイン）、`wave.clear.coin`、`shop.open.fxTime`

## 例外・境界
- **0**：コインが 0 でも開く。何も買わずに「次のウェーブへ」を押せる
- **最大**：パックは「持ち越しの数＋このショップで買った数」が `limit.pack.max` に、または買った数が `shop.pack.buyMax` に達したら、パックの札が押せない色になる（理由を1行で）
- **コインが足りない**：札が押せない色。押すと「コインが足りません」を1行（音は小さく）
- **2回押し**：1回押すごとに1つ買う。0.2秒より短い間隔の2回めは無視（まちがいの連打を防ぐ）
- **返す**：買ったものを返す機能は置かない（仮決め。中身を買ったときに決めるので、返して買い直すと中身の引き直しになるため）
- **中断**：ショップで閉じたら、次は同じショップから（買ったものは保存済み）
- **一時停止**：ショップでは時間が進まないので要らない。裏に回っても覆いは出さない
- **ラン以外**：コインは結果の画面で消える。名声・宝石には変わらない（economy が変えると決めたら直す）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 開く | 下から板 | ショップの BGM（戦いと同じ主題を軽く） |
| 買った | 札が光り、パックが上の列へ飛ぶ。コインの数が減る | 小さな鈴の下がる音 |
| 買えない | 札が小さく揺れる | 小さな鈍い音 |
| 閉じる | 板が下がる | 角笛へつなぐ |

## 受け入れ条件
- [ ] ウェーブを生き延びたら、ショップの板が開き、いまのコインと次のウェーブの番号が見える
- [ ] ショップには制限時間がなく、何分待っても「次のウェーブへ」を押すまで閉じない
- [ ] コインが値段以上あるときにパックの札を押したら、コインが値段だけ減り、「次のウェーブに降るパック」の列に1つ増える
- [ ] コインが値段より少ないとき、札を押してもコインもパックも変わらない
- [ ] 買ったパックの中身とパックのレア度は、ショップのどこにも出ない
- [ ] 持ち越しのパックの数と買った数の合計が `limit.pack.max` になったら、パックの札は押せない
- [ ] 1回のショップで `shop.pack.buyMax` 個買ったら、パックの札は押せない
- [ ] パックの札の「出るもの」を押したら、その種類のプールの英雄と呪文カードの一覧が出て、図鑑で出会っていないものは影で出る
- [ ] 「前と同じものを買う」を押したら、前のショップで買った組を前と同じ順に、買える分だけ買い、買えなかったものの名前を1行で出す
- [ ] このランの最初のショップで「前と同じものを買う」を押したら、前のランの最初のショップの組を買う
- [ ] 一度も買い物をしたことがないとき、「前と同じものを買う」は押せない
- [ ] 回復の品は、塔の耐久が満タンのとき押せない
- [ ] 0.2秒より短い間隔で札を2回押したら、1つだけ買う
- [ ] 買ったら保存され、そのあとアプリを閉じて開くと、同じショップで同じコインと同じ買った列から始まる
- [ ] ランが終わったら、コインは 0 になり、次のランは `coin.start` から始まる
- [ ] ショップの画面に、宝石の値段の品・宝石をもらう棚はない
