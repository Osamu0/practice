# 機能仕様：タップ攻撃（押さえ続ける・ずらした輪・隠れたパックの印・自動化の動き）

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
自動化を「開く・強くする」は `強化画面.md`。この文書は、自動化が戦場でどう動くかを書く。

- **目的（どの柱のためか）**：柱2（指は、いちばん危ないところへ）の芯。柱1（パックを開けるのも、この指）にもつながる。縦持ち・片手で、指が魔物を隠す問題と、指の疲れに手当てする

## プレイヤーから見た動き
- 戦場を押さえると、指の位置から上へ `tap.ring.offset` だけずれたところに、攻撃の輪が出る
- 押さえているあいだ、`tap.interval` 秒ごとに、輪の中（当たりの半径 `tap.ring.radius.hit`）の**すべての**魔物と**すべての**パックに、`tap.damage` の攻撃が1回ずつ当たる。連打は要らない
- 指を動かすと、輪がついてくる。離すと止まる
- 輪の見た目の半径は `tap.ring.radius.visual`。当たりはそれより大きい（小さな魔物を指先でぴったり狙わせない）
- **隠れたパックの印**：指の位置から `tap.hiddenMark.radius` の中にあるのに、輪の当たりの外にあるパックについて、輪のふちのそのパックの方向に、パックのレア度の色のひし形を出す（`tap.hiddenMark.max` 個まで。近い順）
- **自動化**（強化画面で開いたあと）：指とは別の「自動の輪」が、塔にいちばん近い魔物を狙って、`tapAuto.interval` 秒ごとに `tap.damage × tapAuto.ratio` の攻撃をする。**魔物だけ**を攻撃し、パックには当たらない。指で押さえているあいだも止まらない（両方当たる）

## 入力
| 入力 | 起きること |
|---|---|
| 1本めの指で戦場を押さえる（`pointerdown`） | 輪が出て、**すぐ1回**攻撃し（前の攻撃から `tap.interval` たっていれば）、その後 `tap.interval` ごとに攻撃。間隔の数えは離しても続くので、連打しても押さえ続けるより多くは当たらない |
| 押さえたまま動かす（`pointermove`） | 輪が指についてくる |
| 離す（`pointerup`）、`pointercancel`、`lostpointercapture` | 輪が消え、攻撃が止まる |
| 2本めの指 | 無視（輪は動かない、攻撃も増えない） |
| 置き場の呪文カードの上で押さえ始める（案S2 のとき） | タップ攻撃ではなく呪文の操作（`呪文カード.md`） |
| HUD・一時停止ボタンの上で押さえ始める | タップ攻撃にならない |

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 離している | 輪なし。自動の輪だけ動く（開いていれば） | 押さえている | 1本めの指が戦場で下りた |
| 押さえている | `tap.interval` ごとに攻撃。輪は指を追う | 離している | 指が上がった／取られた |
| 押さえている | — | 止まっている | 一時停止 |
| 止まっている | 攻撃しない。間隔の数えも止まる | 離している | 再開（再開のとき指は押さえていない扱い。押さえ直すと攻撃） |

自動の輪：
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 閉じている | なし | 待つ | 強化画面で自動化を開いた |
| 待つ | 狙う魔物がいない（戦場の魔物 0、または自動の輪の届く範囲 `tapAuto.range` に魔物なし） | 撃つ | 範囲に魔物が入った |
| 撃つ | 塔にいちばん近い魔物へ輪が動き、`tapAuto.interval` ごとに攻撃 | 待つ | 範囲に魔物がいない |

## 数値
`tap.interval`、`tap.damage`、`tap.ring.offset`（既定 `tap.ring.offset.default`、選べる値 `tap.ring.offset.options`）、`tap.ring.radius.visual`、`tap.ring.radius.hit`、`tap.ring.topLimit`、`tap.hiddenMark.radius`、`tap.hiddenMark.max`、`tapAuto.interval`、`tapAuto.ratio`（自動化の段ごと）、`tapAuto.ratio.max`、`tapAuto.range`、`tapAuto.ring.radius`、`tapAuto.ring.moveSpeed`

決まっていること（進行表 2026-11-25）：輪のずらしの既定は 56、設定で 0／40／56／72（プロトの問い1の実機で決め直す）。アートディレクションの見た目の半径 28・当たり 34 は `game-spec-balance` が値に入れる。
柱の決め：`tapAuto.ratio` はどの段でも `tapAuto.ratio.max` 以下、`tapAuto.ratio.max` は 1 より小さい（自動は指より弱い）。プロトの問い3の「指と同じ」の段は、比べるためのプロト専用の設定で、製品には入れない。

## 例外・境界
- **画面の上の端**：輪は `tap.ring.topLimit`（HUD の下の線）より上に行かない。指がそれより上へ行っても、輪はその線で止まる（輪と指の距離が縮む）
- **画面の左右と下**：輪は戦場の外に出ない（左右の端で止まる）。指が下の端（810〜844）にあっても、輪は上にずれるので戦場の中にある
- **ずらし 0**：輪は指の真下。隠れたパックの印は、指の下のパックにも出る
- **輪の中に何もない**：攻撃は空振り。音は鳴らす（押さえている手ごたえ）、ダメージの数は出さない
- **輪の中に魔物とパックの両方**：両方に当たる
- **同時に多くの魔物**：当たる数に上限はない（範囲のすべて）。ダメージの数の表示は `limit.damageText.max` まで（`HUDと数の表記.md`）
- **倒れかけの魔物**：耐久が 0 以下になったフレームで倒れる。同じ攻撃で2度倒れない
- **ポーズ・裏に回る**：攻撃と間隔の数えが止まる。再開したら押さえていない扱い
- **ショップ・板の画面**：タップ攻撃はない
- **自動化**：狙った魔物が倒れたら、次の攻撃のときに塔にいちばん近い魔物を選び直す。距離が同じなら、先に湧いたほうを選ぶ。自動の輪は描くが、指の輪と色・大きさで見分ける（アートの担当）
- **自動化とパック**：自動の輪の中にパックがあっても、パックには当たらない（柱1）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 押さえ始め | 輪が出る | — |
| 1回の攻撃が魔物に当たった | 魔物が白く光り 3px はじかれる、ダメージの数 | 「トッ」（高さを毎回 ±5%、同時に3つまで） |
| 空振り | 輪が小さく脈打つ | 「トッ」を小さく |
| パックに当たった | パックが揺れ、ひびが1段増える（`パック.md`） | 「パシッ」 |
| 隠れたパックの印 | 輪のふちにレア度の色のひし形 | — |
| 自動の輪の攻撃 | 自動の輪が光る | 指の音より小さい音 |

## 受け入れ条件
- [ ] 戦場を押さえたら、輪が指の位置から上へ `tap.ring.offset` の位置に出る（既定 56 のとき、指 y=400 なら輪の中心 y=344）
- [ ] 押さえた歩に1回、その後は押さえ続けるあいだ `tap.interval` 秒ごとに攻撃する（押さえてから60歩＝1秒のあいだに `1 / tap.interval` 回。0.1 なら 10回。確認版と同じ数え方）
- [ ] 離してすぐ押し直しても、前の攻撃から `tap.interval` 秒たつまでは次の攻撃が起きない（連打しても、押さえ続けるより多く当たらない）
- [ ] 輪の中心から `tap.ring.radius.hit` の内にいる魔物には当たり、外の魔物には当たらない（当たりは魔物の中心で見る）
- [ ] 輪の中の魔物が3体なら、1回の攻撃で3体とも `tap.damage` だけ耐久が減る
- [ ] 指の真下（輪から `tap.ring.offset` 離れた）魔物には、ずらしが 0 でないかぎり当たらない
- [ ] 離したら、次の間隔の攻撃は起きない
- [ ] 2本めの指を置いても、輪の位置と攻撃の回数は変わらない
- [ ] 指を `tap.ring.topLimit` より上へ動かしたら、輪はその線で止まる
- [ ] 設定でずらしを 0／40／56／72 にしたら、次に押さえたときから輪がその分だけ上に出る
- [ ] 指から `tap.hiddenMark.radius` の内にあり、輪の当たりの外にあるパックがあったら、輪のふちのその方向に、そのパックのレア度の色のひし形が出る
- [ ] 一時停止して再開したら、押さえ直すまで攻撃しない
- [ ] 置き場の呪文カードの上で押さえ始めたら（案S2）、タップ攻撃は起きない
- [ ] 自動化が開いていないとき、指を離していれば魔物の耐久は指の攻撃では減らない
- [ ] 自動化が開いていたら、指を離していても、`tapAuto.range` の内の塔にいちばん近い魔物に、`tapAuto.interval` ごとに `tap.damage × tapAuto.ratio` の攻撃が当たる
- [ ] 自動の輪の中にパックがあっても、パックのひびは増えない
- [ ] 指で押さえているあいだも、自動の輪の攻撃は止まらない
- [ ] どの自動化の段でも、`tapAuto.ratio` が `tapAuto.ratio.max` 以下で、`tapAuto.ratio.max` は 1 未満である（パラメータ表で確かめる）
