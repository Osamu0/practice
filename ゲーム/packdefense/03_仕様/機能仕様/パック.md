# 機能仕様：パック（降る・開封・プール・レア度）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値と式の正は `03_仕様/パラメータ表.csv`。
パックの種類・値段・プール・割合は `03_仕様/経済.md` 4章。この文書は、すべてのパックに共通の決まりを書く。

- **目的（どの柱のためか）**：柱1（開けるのも、戦いのうち）の芯。ショップで買い、次のウェーブの戦場に降り、魔物を攻撃している指をそちらに向けて開ける。開けた場所に英雄が立つ

## パックの種類とプール
- パックには**種類**がある。種類ごとに次を持つ（オーナーの構造④：種類ごとに出る英雄と呪文の顔ぶれが違う）
  | 持つもの | 名前 | 中身 |
  |---|---|---|
  | 値段 | `pack.<type>.price` × `econ.market(n)` | コイン（n はショップの前のウェーブ）。ランの中で買うたびには上げない（`pack.<type>.priceGrowth`） |
  | 枚数 | `pack.<type>.cards`（強化 `packCards` で +1／段） | 1つのパックから出るカードの数 |
  | 1枚めの種類 | `pack.<type>.firstCard` | 英雄か呪文か |
  | 2枚め以降の割合 | `pack.<type>.spellShare` | 2枚め以降の1枚が呪文になる割合 |
  | プール | `pack.<type>.pool` | 出る英雄と呪文カードの ID と、それぞれの重み。種類ごとに顔ぶれが違う。どのプールにも、英雄・呪文それぞれコモンの候補がある |
  | レア度の重み | `pack.<type>.rarityWeights` | コモン／レア／エピック／レジェンドの重み |
  | 棚に並ぶ条件 | `pack.<type>.unlock` | `はじめの流れと要素の解放.md` |
- **種類は5つ**（名前は仮。07 と creative-director で決める。中身は経済 4.1）：
  | 種類 | ID | 役 | 棚 |
  |---|---|---|---|
  | 見習いのパック | `novice` | 安い。剣士・弓使い・盾の騎士と基本の呪文。数で守る | 最初から |
  | 鉄壁のパック | `iron` | 盾の騎士・槍兵・剣士と守りの呪文。塔のまわりを固める | 記録で影、強化で並ぶ |
  | 疾風のパック | `wind` | 弓使い・斥候・槍兵と速さの呪文。遠く・速い魔物 | 同上（MVP） |
  | 秘術のパック | `arcane` | 魔法使い・僧侶。呪文が多い（1枚めも呪文） | 同上（MVP） |
  | 王家のパック | `royal` | 図鑑に載った英雄・呪文だけ（新しい顔は出ない）。全部の役。高い | 同上（MVP） |
- **はじめのパック**（`pack.starter.*`）は別の種類ではなく、見習いのパックを、はじめのランで降るウェーブが `unlock.rare.fromWave` より前のあいだだけ「コモン・英雄だけ」にしたもの
- 縦切り（M3）は見習いと鉄壁の2種類

## 1枚を決める手順（買った瞬間に、1枚めから順に）
1. **英雄か呪文か**：1枚めは `pack.<type>.firstCard`。2枚め以降は `pack.<type>.spellShare` の割合で呪文、残りは英雄
2. **レア度**：その種類の `pack.<type>.rarityWeights` でレア度を引く。引いたレア度が**まだ開いていなければ、開いているうちでいちばん高い、1つ下の段に落とす**（例：エピックが開いていなければレア、レアも開いていなければコモン）。不運よけ・封の格上げが効く1枚めは、下の決まりで引く
3. **カード**：プールのうち、1 の種類（英雄か呪文）で、2 のレア度のものから、プールの重みで1つ引く。候補が0なら、1つ下のレア度で引き直す（コモンまで下がる。コモンの候補が0のプールは作らない）
- 王家のパックの 3 は、図鑑に載ったものだけを候補にする。どのレア度まで下げても候補が0なら（例：図鑑に呪文が1枚も載っていない）、もう一方の種類（英雄なら呪文、呪文なら英雄）で 2・3 を引き直す
- **はじめの流れの決まりが先**（`はじめの流れと要素の解放.md`）：そのプレイヤーが最初に開けるパックの1枚めは英雄（`intro.firstPackHero`）。はじめのランで降るウェーブが `unlock.rare.fromWave` より前のパックは、全部コモンの英雄。必ず出る呪文は、2枚めを呪文にする

### 不運よけ（`pack.pity.after`）
- 同じランで、レア以上のカードが1枚も入っていないパックを `pack.pity.after` 個続けて買ったら、次に買うパックの1枚めはレア以上にする（**買った瞬間に決める**）
- レア以上にするとき：その種類のレア度の重みから、コモンを除いた重みで引く（そのあと手順 2 の「開いていなければ下の段」は、レアより下には落とさない）
- レア以上が1枚でも入ったパックを買ったら、数は 0 に戻る。数はランの中だけで、ランの始めに 0。**保存する**（`保存.md`）
- レアがまだ開いていないあいだ（はじめのランの初め）は働かない。数は数え続ける
- 見せない（札にも戦場にも出さない）

### 封の格上げ（ショップの品）
- ショップで「封の格上げ」を買うと、そのあと次に買うパック1つの1枚めを、不運よけと同じ引き方でレア以上にする（`ショップ.md`）。中身もパックのレア度も見せない。そのショップでパックを買わなければ、次のショップ以降の最初に買うパックに効く（ランの終わりで消える）

## レア度
- 4段：コモン（白）・レア（青）・エピック（紫）・レジェンド（金）。縦切りは 3段（`rarity.tiers`。レジェンドを出さない）。色と点の数と枠の形はアートディレクション 4.1
- 英雄と呪文カードは1つずつレア度を持つ（`hero.<id>.rarity`、`spell.<id>.rarity`）。カードの強さの倍率は `card.rarityPower`
- **パックのレア度は、中のいちばん高いカードのレア度**（仮決め）。戦場のパックの枠の色、隠れたパックの印の色はこれで出す。「金の枠が降ってきた」＝中にレジェンドがある、がわかり、「いま開けるか」の判断になる（柱1）。宝石の品（パックの柄）を使っても枠の色は変わらない（`宝石の店.md`）
- 開けるのに要る攻撃の回数は、パックのレア度で違う：`pack.hitsToOpen.common`・`.rare`・`.epic`・`.legend`。強化 `packHits` の段の倍率 `upgrade.packHits.effect` をかけて切り上げる。1回より少なくならない

## 中身を決める時
- **ショップで買った瞬間に**中身（カードの並びとパックのレア度）を決め、保存する（デザインの柱 #16）。ウェーブをやり直しても中身は変わらない
- 乱数はランのシードと「このランで買ったパックの通し番号」から作る
- カードの力（`英雄.md`・`呪文カード.md`）も、買ったショップの相場 `econ.market(n)` で決まる

## プレイヤーから見た動き
1. ショップで買う（`ショップ.md`）。ショップでは中身もパックのレア度も見せない（棚には種類と、顔ぶれ・割合の数だけ）
2. 次のウェーブで、買ったパックが降る（下の「降る時刻」）
3. 降る前に、落ちる場所に光の柱が `pack.drop.telegraph` 秒出る → 落ちる → はねる。枠の色でレア度が見える
4. タップ攻撃の輪がパックに当たるたびに、パックが揺れ、ひびが1段増える
5. 当たった回数が、そのパックの要る回数に達したら、破れて開く。カードが飛び出す
6. 英雄のカード → その場所に英雄が立つ（`英雄.md`）。呪文カードのカード → 案S1 ならその場所を中心にすぐ起きる／案S2 なら置き場へ飛ぶ（`呪文カード.md`）
7. 初めて出たカードは図鑑に載る（`図鑑.md`）

## 降る時刻（`pack.drop.times`）
- そのショップで買ったパックの数を k とする。買った順に、はじめの ceil(k ÷ 2) 個は湧きの時計の 0（ウェーブの始まり）、残りは湧きの時計で `wave.spawn.duration(n) × pack.drop.times の2つめ`
- 持ち越しのパックは、全部 0 に降る
- 時刻は湧きの時計（`魔物.md`）で数えるので、前倒しで湧きが早まると、途中のパックも早く降る。湧きの予定を出し終えたあとにまだ降っていないパックは、出し終えた時に降る

## 落ちる場所
- 塔を中心とした輪の上（塔からの距離 `pack.drop.ring.min`〜`pack.drop.ring.max`）
- 方向（北・東・南・西）は、英雄が少ない方向ほど選ばれやすい。方向の重み ＝ 1 ＋ `pack.drop.dirBias` ×（いちばん多い方向の英雄の数 − その方向の英雄の数）。角度は道の向きから `pack.drop.angleSpread` 度の内
- HUD の帯（52〜104）・呪文の置き場の帯（案S2 のとき 680〜790）・下の端（810〜844）・塔の当たりには落とさない。ほかのパック・英雄から `pack.drop.minGap` 以上離す
- 乱数はウェーブの流れ（同じウェーブをやり直せば同じ場所）

## 入力
| 入力 | 起きること |
|---|---|
| パックの中心が、輪の中心から `tap.ring.radius.hit` の内にある（魔物と同じく中心で見る） | 攻撃の1回ごとに、ひびが1段増える |
| 英雄の攻撃・自動化・呪文がパックに当たる | 何も起きない（柱1） |

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 買った | 中身が決まり、保存された。戦場にはない | 予告 | 次のウェーブで、そのパックの降る時刻になった |
| 予告 | 光の柱。まだ当たらない | 地面 | `pack.drop.telegraph` 秒たった |
| 地面 | タップ攻撃でひびが増える | 開く | 当たった回数 ≥ 要る回数 |
| 地面／予告 | — | 持ち越し | ウェーブを生き延びた（予告中なら、地面に着かずに持ち越し） |
| 持ち越し | 戦場から消え、次のウェーブの始まりに降る（新しい場所） | 予告 | 次のウェーブの始まり |
| 地面／予告／買った／持ち越し | — | 消える | ランが終わった（塔が壊れた・ランをやめた）。何にも変わらない |
| 開く | 破れる演出（レア度ごとの長さ `fx.open.time.<rarity>`）。カードを出す。ゲームは止めない | 終わり | 演出の終わり |

## 例外・境界
- **0**：ショップで1つも買わなかったら、そのウェーブにパックは降らない（持ち越しがあれば降る）
- **最大**：戦場のパックは同時に `limit.pack.max` まで。買えるのは「持ち越しの数＋買った数 ≤ `limit.pack.max`」まで（`ショップ.md` で止める）
- **同時**：1回の攻撃が2つのパックに当たったら、両方のひびが増える。2つ同時に開いたら、大きな光は `limit.bigOpenFx.max` まで、ほかは小さな光
- **はじめのパック**：そのプレイヤーが最初に開けるパックの1枚めは、必ず英雄（`はじめの流れと要素の解放.md`）
- **開けている途中で塔が壊れた**：英雄は立たない、呪文は起きない、図鑑には載せる（出会ったので）
- **開けている途中でウェーブを生き延びた**：演出を打ち切って開けたことにする（英雄は立ち、呪文は S1 なら起きずに消える／S2 なら置き場へ入る）。そのあとで保存する（`戦場とウェーブ.md` の「生き延びた」の確定）
- **開けている途中で一時停止**：演出も止まる。再開で続き
- **ウェーブの途中でアプリが閉じた**：ウェーブの始まりから。そのウェーブで開けたパックは「まだ開けていない」に戻る（中身は同じ）。ウェーブの途中では保存しないので、そのウェーブで図鑑に載ったものも載る前に戻る（もう一度開ければ載る。得も損もない）
- **予告中に湧いた魔物が同じ場所を通る**：魔物はパックを無視して通る（魔物はパックを狙わない。ひねりは入れない）
- **落ちる場所が見つからない**（込み合い）：`pack.drop.minGap` を半分にしてもう一度探す。それでもなければ、塔からいちばん近い空いた場所
- **ランの終わり**：開けていないパックは全部消える。名声・宝石・コインに変わらない（経済 2.1。GDD U8 を閉じた）

| きっかけ | 演出 | 音 |
|---|---|---|
| 予告 | 光の柱（レア度の色） | 小さなきらめき |
| 着地 | はねる2コマ、着地の光の楕円 | 軽い着地の音 |

| 初めてのカード | 「新しい！」の小さな札 | — |

## 受け入れ条件
- [ ] ショップで買った瞬間に中身が決まり、そのあとウェーブの始まりからやり直しても、開けたときの中身は同じ
- [ ] パックを買った直後の保存の中身に、そのパックのカードの並び（種類・ID・レア度）とパックのレア度が入っている
- [ ] 戦場のパックの枠の色は、中のいちばん高いカードのレア度の色になる
- [ ] パックはショップでは開かず、中身もパックのレア度も見えない
- [ ] 買ったパックの1枚めは `pack.<type>.firstCard` の種類（はじめの流れの決まりを除く）
- [ ] シード 1〜10 のそれぞれで見習いのパックを 300 個ずつ買ったとき（はじめのランを終え、必ず出る呪文も済んだ保存で）、2枚めが呪文だった割合の平均が `pack.novice.spellShare` の ±0.05 の内に入る
- [ ] はじめのランを終え、エピックが開いていない（記録が `unlock.epic.record` より前の）保存で、シード 1〜10 のそれぞれで見習いのパックを 300 個ずつ買ったとき、エピックのカードは1枚も出ず、レアの割合の平均が（レアの重み ＋ エピックの重み）÷ 重みの合計 の ±0.05 の内に入る
- [ ] 買ったパックは次のウェーブで、降る時刻に降る：3つ買ったら、2つは湧きの時計の 0 に、1つは `wave.spawn.duration(n) × pack.drop.times の2つめ` に。持ち越しは 0 に
- [ ] パックが落ちる前に、落ちる場所に光の柱が `pack.drop.telegraph` 秒出る。柱の間はタップ攻撃が当たらない
- [ ] パックの落ちる場所は、塔から `pack.drop.ring.min` 以上 `pack.drop.ring.max` 以下で、HUD の帯・置き場の帯（案S2）・下の端・塔の上にはない
- [ ] 戦場のパックどうし、パックと英雄は `pack.drop.minGap` 以上離れている（込み合いの例外を除く）
- [ ] 東に英雄が3人、ほかの方向に0人のとき、シード 1〜10 のそれぞれで 200回落としたら、どのシードでも東に落ちる回数がほかのどの方向より少ない
- [ ] パックの中心が輪の中心から `tap.ring.radius.hit` の内にあれば攻撃の1回でひびが1段増え、外なら増えない
- [ ] 図鑑に呪文が1枚も載っていない保存で王家のパックを買ったら、呪文になるはずの枚も英雄（図鑑に載ったもの）になっている
- [ ] レジェンドのパックの開封の演出中に最後の魔物が倒れてウェーブを生き延びたら、ショップが開いた直後の保存に、そのパックから出た英雄が戦場の英雄として入っている
- [ ] タップ攻撃がパックに当たった回数が `pack.hitsToOpen.<そのパックのレア度>`（`packHits` の段があればその倍率をかけて切り上げた数）に達したら、パックが開く
- [ ] 英雄の攻撃・自動化・呪文がパックに当たっても、ひびは増えず、開かない
- [ ] 開いたら、`pack.<type>.cards`（`packCards` の段を足した数）枚のカードが出る
- [ ] あるパックの種類で出るカードは、すべてその種類の `pack.<type>.pool` に入っているものだけ。王家のパックから出るカードは、すべて買った時に図鑑に載っていたもの
- [ ] 同じランでレア以上のないパックを `pack.pity.after` 個続けて買ったら、次に買ったパックの保存の中身で、1枚めのレア度がレア以上になっている。保存の中身の不運よけの数が、レア以上のパックを買ったら 0 に戻る
- [ ] ウェーブを生き延びたとき開けていなかったパックは、次のウェーブの始まりに、中身を変えずに降る
- [ ] 戦場のパックは `limit.pack.max` をこえない
- [ ] 開封の演出の間も、魔物・英雄・タップ攻撃は止まらない
- [ ] そのプレイヤーが最初に開けたパックの1枚めは英雄
- [ ] 強化 `upgrade.packHits` を買ったら、開けるのに要る回数が減る。どのレア度でも1回より少なくならない
- [ ] ランが終わったとき開けていなかったパックは、次のランに残らない
