# 機能仕様：保存（ウェーブの始まりとショップ、一時停止、書き出し・読み込み）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値の正は `03_仕様/パラメータ表.csv`。
形と手当ては `02_プリプロ/技術選定.md` 4.6〜4.7 に合わせた（確認版で動かして確かめた形）。版の移し替えは 05 で `game-prod-architect`。

- **目的（どの柱のためか）**：柱3（途中でやめても戻れる、何時間ものランと名声を失わない）。iPhone の Safari はタブがいつ閉じられるかわからず、保存領域が消える報告もあるので、書き出し・読み込みを必須にする

## 何を保存するか
| まとまり | 中身 |
|---|---|
| 頭 | 版、書いた時刻（表示用だけ。遊びには使わない） |
| ラン（ランの途中だけ） | ランのシード、ウェーブの番号、場面（ウェーブの始まり／ショップ）、コイン、塔の耐久、このランの名声、このランを始めたときの記録、戦場の英雄（ID・位置・`hero.power`）、次に降るパック（種類・中身・パックのレア度・持ち越しか）、置き場の呪文カード（案S2。力も）、ランの中の品の効き目（訓練の回数・待っている封の格上げ）、品の買った回数、このランで買ったパックの通し番号、不運よけの数（`pack.pity.after` まで数える数）、このランのショップの買い物の記録 |
| ランをまたぐ | 持っている名声、強化の段、図鑑（出会ったもの・出会った数・「新しい」の札）、記録 `record.bestWave`、前のランの最初のショップの買い物の記録、解放の状態（影・並んだパックの種類）、印、宝石の数と宝石の品（持っているもの・使っているもの）、はじめの流れの進み（出した1行、必ず出る呪文の済／まだ）、設定、最後に書き出したときのウェーブの通算 |
| 保存しないもの | 魔物・弾・粒の位置、ウェーブの途中の経過・湧きの時計、押さえている指 |

## いつ保存するか
| きっかけ | 書くもの |
|---|---|
| ウェーブが始まった瞬間（ショップを閉じた直後、ランの第1ウェーブの始まり） | 全部 |
| ショップが開いた瞬間 | 全部 |
| ショップで買った | 全部 |
| 結果の画面に入った（名声を足した直後） | 全部（ランの部分は消す） |
| 強化画面で強くした | 全部 |
| 宝石の店で宝石が増えた・減った・品を使った | 全部 |
| 設定を変えた | 下の「ウェーブの途中に書くとき」 |
| 読み込みが通った | 全部 |
- 書く前に、いまの保存を「1つ前の保存」に写す
- ウェーブの途中（魔物を倒した・パックを開けた・図鑑に載った）では、ゲームの進みのために書かない

### ウェーブの途中に書くとき（設定を変えた・読み込みの板）
- 一時停止の板から設定を変えたときなど、ウェーブの途中に保存を書くことがある。そのとき、**ランの部分は、そのウェーブの始まりのもの**（いまの保存にあるもの）をそのまま書き、**ランをまたぐ部分だけ今の値**にする
- ただし、ランをまたぐ部分のうち、このウェーブで増えた図鑑・はじめの流れの進み・印は、ウェーブの始まりの値のまま書く（ウェーブをやり直したときに二重にならないように。名声・記録はランの途中では変わらない）
- つまり、ウェーブの途中に何度書いても、閉じて開けば同じウェーブの始まりから、同じ中身で始まる

## 戻り方
- 起動して保存があれば：
  - 場面が「ウェーブの始まり」→ そのウェーブの始まりから（同じシード・同じ英雄・同じパック）
  - 場面が「ショップ」→ そのショップから
  - ランがない → 強化画面から（最初の塔が壊れる前なら、第1ウェーブの始まりから）
- 今の保存が読めない（こわれている）→ 1つ前の保存を読む。どちらも読めない → 「保存が読めませんでした」と1行出し、書き出した文字・ファイルからの読み込みを勧める。勝手に消さない（新しく始めるのは、プレイヤーが「新しく始める」を押したときだけ）
- 負けそうなときに閉じて、ウェーブの始まりから戻るのは許す（仮決め。プロデューサー 2026-11-25。GDD U14）。中身も湧きも同じシードなので、得も損もない

## 一時停止との関係
- ブラウザが裏に回ったら、保存はせずに一時停止する（`戦場とウェーブ.md`）。戻ったとき：戦場なら一時停止のまま「タップで再開」の覆いを出す。板の画面（ショップ・強化画面・図鑑・宝石の店・設定・結果）なら覆いは出さずにそのまま戻り、最初のタップ（そのタップのふつうの動きと同じ処理の中）で音を起こす（技術選定 4.4）。iOS がそのまま閉じても、戻るのはウェーブの始まりから（最大およそ `wave.duration.max` を失う）
- 留守のあいだは何も進まない（仮決め。GDD U5）

## 書き出し・読み込み
- 入口：設定（`設定.md`）の「書き出し・読み込み」
- 書き出し
  - 書き出す中身は、いまの保存と同じ（**ランの途中で書き出したら、そのウェーブの始まりの状態**。上の「ウェーブの途中に書くとき」と同じ形）。ランの途中なら、板に1行「ウェーブの途中の分は入りません（このウェーブの始まりから戻ります）」を出す
  - 「文字をコピー」：保存の文字を写す。写せなければ、文字を選べる枠に出して「長押しでコピー」を1行
  - 「ファイルに書き出す」：共有の板（「ファイルに保存」）を出す。使えなければダウンロード。ファイル名は英数字だけ（例 `packdefense-save-YYYYMMDD.txt`）
  - 書き出したら、最後に書き出したときのウェーブの通算を記録する
- 読み込み
  - 「文字を貼って読む」：貼った文字を照らす
  - 「ファイルから読む」：ファイルを選ぶ
  - 照らして通ったら、確かめの板「いまの保存を上書きします。よいですか」→「読む」で上書きし、保存の場面から始める
  - **ランの途中（一時停止の板の設定から）で読み込んだら、今のランは捨てて、読んだ保存の場面から始める**（今のウェーブの続きにはしない）。確かめの板の文にも「いまのランは消えます」を足す
  - 通らなかったら、「読めない文字です（版が違う／こわれている）」を1行。いまの保存は変えない
- **書き出しを勧める1行**（技術選定 T5）：最後に書き出してから `save.exportRemind.waves` ウェーブ以上進んだら、ショップと強化画面の上に「保存を書き出しておくと安心です」の1行と「書き出す」の小さなボタン。閉じられる。急かす点滅はしない

## 形（技術選定 4.6 のとおり）
- localStorage、1つのキー（`save.key`）＋1つ前のキー
- `PD1.<JSON を base64url>.<指紋>`。読み込みで、頭の版と指紋を照らす
- Infinity・NaN をこわさずに往復させる

## 入力
| 入力 | 起きること |
|---|---|
| 書き出し・読み込みのボタン | 上のとおり |
| 「新しく始める」（設定の奥。確かめの板を2回） | すべての保存を消して、はじめの流れから |

## 状態と遷移（起動）
| 状態 | 次へ | きっかけ |
|---|---|---|
| タイトル | 読む | 「タップで始める」 |
| 読む | ウェーブの始まり／ショップ／強化画面／はじめの流れ | 保存の場面 |
| 読む | 読めない板 | 今のも1つ前のも読めない |
| 読めない板 | 書き出し・読み込み／新しく始める（確かめ2回） | ボタン |

## 数値
`save.exportRemind.waves`、`save.key`（キーの名前。数ではないが設定の値として置く）、`ui.toast.time`（1行の知らせを出す時間）、`pack.pity.after`（数の上限の確かめ）

## 例外・境界
- **書けない（容量オーバーなど）**：ゲームは止めない。HUD・板の上に「保存できません。書き出してください」を出す（消えない。次に書けたら消える）
- **読み込みで、ランの途中の保存を読む**：その場面（ウェーブの始まり／ショップ）から
- **同じ保存を2回読む**：同じ結果。名声などが二重に増えない
- **やり直しで得をしない**：パックの中身は買ったときに決めて保存しているので、ウェーブをやり直しても同じ。ウェーブの湧きも同じシードの流れ
- **大きな数**：名声などが Infinity になっても、保存・読み込み・表示がこわれない
- **ほかのタブで同時に開いた**：あとから書いたほうが残る（対策は置かない。1人用。05 で見直す）
- **ホーム画面のアプリと Safari**：保存の場所が別になることがある（技術選定 R2）。書き出し・読み込みで移す。設定に1行の説明

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 保存した | 何も出さない（毎ウェーブ出るとうるさい） | なし |
| 書けなかった | 1行の知らせ（消えない） | 小さな警告 |
| 書き出した・読み込んだ | 「書き出しました」「読み込みました」の1行 | 小さな音 |

## 受け入れ条件
- [ ] ウェーブが始まった瞬間に保存され、ウェーブの途中でアプリを閉じて開き直すと、同じウェーブの始まりから、同じ英雄（位置・力）・同じパック（中身）・同じコイン・同じ塔の耐久で始まる
- [ ] ショップが開いた瞬間に保存され、ショップでアプリを閉じて開き直すと、同じショップから同じコインで始まる
- [ ] ショップで買ってすぐ閉じても、開き直すと買ったものが残っている
- [ ] 同じウェーブの始まりから2回やり直したとき、指を使わなければ、魔物の湧きとパックの中身が2回とも同じ
- [ ] ウェーブの途中で魔物を倒しても、保存は書かれない（保存の文字が変わらない）
- [ ] ウェーブの途中で魔物を倒し、パックを開けて図鑑に新しいカードが載ったあと、一時停止の板から設定を変えたら、書かれた保存のランの部分（コイン・塔の耐久・英雄・パック）と図鑑は、そのウェーブの始まりのものと同じで、設定だけが今の値になっている
- [ ] ウェーブの途中で書き出した文字を読み込んだら、そのウェーブの始まりから始まる
- [ ] ランの途中で、別の保存（強化画面の場面のもの）を読み込んで「読む」を押したら、今のランは消え、強化画面から始まる
- [ ] ブラウザが裏に回ったら一時停止になり、保存は書かれない
- [ ] ショップの画面で裏に回って戻ったら、覆いは出ず、最初のタップでそのタップの動き（買うなど）が起き、そのあと音が鳴る
- [ ] 保存の文字を1文字変えて読み込んだら、断られ、いまの保存は変わらない
- [ ] 違う版の頭の文字を読み込んだら、断られる
- [ ] いまの保存がこわれていたら、1つ前の保存から始まる
- [ ] 「文字をコピー」で写した文字を、保存を消したあとで「文字を貼って読む」と、元の状態に戻る
- [ ] 「ファイルに書き出す」で作ったファイルを「ファイルから読む」と、元の状態に戻る
- [ ] 読み込みが通ったとき、上書きの確かめの板が出て、「読む」を押すまで、いまの保存は変わらない
- [ ] 名声が Infinity でも、書き出し→読み込みで Infinity のまま戻り、表示は「∞」
- [ ] 保存が書けなかったとき、ゲームは止まらず、「保存できません」の1行が出る
- [ ] 最後に書き出してから `save.exportRemind.waves` ウェーブ以上進んだら、ショップに「書き出しておくと安心です」の1行が出る
- [ ] 保存の中身に、不運よけの数と、はじめの流れの「必ず出る呪文」の済／まだが入っている
- [ ] 外への通信が1つもない（書き出し・読み込みも端末の中だけ）
