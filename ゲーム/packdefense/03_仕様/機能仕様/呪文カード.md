# 機能仕様：呪文カード（案S1 開けた瞬間に起きる／案S2 置き場に持つ）

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
置き場の有無はプロトの問い2（Q2）で決める（進行表 2026-11-25）。それまで**両方の形を作り、プロトの切り替え `proto.spellMode`（S1／S2）で選ぶ**。共通の部分を先に、形ごとの違いを後に書く。

- **目的（どの柱のためか）**：柱1（パックから出たものがその場で効く）と柱2（指を、パック・呪文・危ないところのどれに使うか）。ユニットとして戦わず、特別な魔法の効果を起こす（オーナーの構造⑤）。群れを一度にひっくり返す見せ場

## 共通
- 呪文カードはパックから出る。戦場に立たない
- 1枚は1回だけ起きる。起きたら消える
- 起きるとき、まず効く範囲の輪を `spell.preview.time` 秒出し、それから効果（アート 5.4）
- 効果の型（骨・仮決め。個々のカードの表は `game-design-combat`）
  | 型 | 中身 | パラメータ |
  |---|---|---|
  | 範囲の攻撃（例：火の玉） | 中心から `spell.<id>.radius` の内の魔物すべてに `spell.<id>.power` | `.radius`、`.power` |
  | つながる攻撃（例：雷） | 中心にいちばん近い魔物から、近い順に `spell.<id>.chain` 体へ | `.chain`、`.power` |
  | 遅くする（例：氷） | 範囲の魔物の速さを `spell.<id>.slow` 倍に `spell.<id>.duration` 秒 | `.radius`、`.slow`、`.duration` |
  | 回復（例：回復） | 塔の耐久を `spell.<id>.power` 戻す（範囲はない） | `.power` |
  | 押し返す（例：突風） | 範囲の魔物を塔から遠ざける向きに `spell.<id>.push` px | `.radius`、`.push` |
  | 英雄を強める（例：鼓舞） | 範囲の英雄の攻撃の間隔を `spell.<id>.haste` 倍に `spell.<id>.duration` 秒 | `.radius`、`.haste`、`.duration` |
- 呪文の強さ ＝ `spell.<id>.power` × 強化画面の倍率（`upgrade.spellPower`）。重ねはない
- 呪文はパックに当たらない（パックを開けない。柱1）

## 案S1：開けた瞬間に起きる
### プレイヤーから見た動き
- パックから呪文カードが出たら、そのパックがあった場所を中心に、すぐ（`spell.preview.time` のあと）起きる
- 置き場は無い。押す帯（680〜790）は空いている
### 入力
なし（パックを開ける入力だけ）。
### 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 出た | カードが一瞬大きく見える | 予告 | すぐ |
| 予告 | 範囲の輪 | 効く | `spell.preview.time` 秒 |
| 効く | 効果 | 消える | 効果の終わり（続く効果は `duration` のあと） |

## 案S2：置き場に持っておき、好きなときに使う
### プレイヤーから見た動き
- 呪文カードが出たら、画面の下の置き場（`spell.slot.count` 枠。アート 7.2：1枠 68×90、2枠を横に並べて間 16、下のふちは y≈782）へ飛んで入り、枠が光る
- 置き場のカードの上で押さえ始めて、戦場へ引くと、カードが指についてきて、効く範囲の輪が「指から上へ `tap.ring.offset`」の位置に出る（タップ攻撃の輪と同じずらし）
- 戦場で離すと、その輪の位置を中心に起きる
- 置き場の帯の中で離すと、取りやめ（カードは元の枠に戻る）
- 置き場がいっぱいのときに新しい呪文カードが出たら、いちばん古いカードが塔を中心にその場で自動で起き、新しいカードが入る（置き場がふさがって損をしない。デザインの柱 #7）
- 置き場は 80% の半透明。下を通る魔物が透けて見える
### 入力
| 入力 | 起きること |
|---|---|
| 置き場のカードの上で押さえ始める | 呪文を引く状態。タップ攻撃は起きない |
| 引いたまま動かす | カードと範囲の輪がついてくる |
| 戦場（置き場の帯の外）で離す | 輪の位置を中心に起きる |
| 置き場の帯の中で離す、`pointercancel` | 取りやめ、カードは枠へ戻る |
| 空いた枠の上で押さえ始める | タップ攻撃（ふつうの戦場と同じ） |
### 状態と遷移（1枠ごと）
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 空き | — | 入っている | 呪文カードが出た |
| 入っている | 枠が光る | 引いている | 枠の上で押さえ始めた |
| 入っている | — | 自動で起きる | 置き場がいっぱいで新しいカードが出た（いちばん古い枠だけ） |
| 引いている | 範囲の輪が指の上に出る。タップ攻撃は止まる | 予告 | 戦場で離した |
| 引いている | — | 入っている | 置き場の帯で離した／取られた／一時停止 |
| 予告 | 範囲の輪 | 効く | `spell.preview.time` 秒 |
| 効く | 効果 | 空き | すぐ（枠は空く。続く効果は戦場で続く） |
| 自動で起きる | 塔を中心に予告→効く | 空き | 効果の始まり |

## 数値
`spell.<id>.rarity`、`.power`、`.radius`、`.chain`、`.slow`、`.push`、`.haste`、`.duration`、`spell.preview.time`、`spell.slot.count`、`upgrade.spellPower`、`proto.spellMode`

## 例外・境界
- **0**：範囲に魔物がいなくても起きる（空振り。カードは消える）。回復は塔が満タンでも起きる（あふれは捨てる）
- **最大**：置き場は `spell.slot.count` 枚まで（案S2）。同じ1歩で2枚以上出たら、出た順に入れ、あふれは古い順に自動で起きる
- **同時**：遅くする効果が重なったら、強いほうの倍率と、長いほうの残り時間を採る（掛け合わせない）。英雄を強めるも同じ
- **引いている途中で一時停止・裏に回る**：取りやめにして枠へ戻す
- **引いている途中にパックが開いて新しい呪文が来る**：引いているカードは古さの数に入れない（自動で起きない）。あふれるなら、引いていないうちでいちばん古いもの。それもなければ、新しいカードがその場で自動で起きる
- **塔が壊れた**：置き場のカードは消える。予告中の呪文は起きない
- **ウェーブを生き延びた**：置き場のカードは次のウェーブへ持ち越す（案S2）。保存する
- **ウェーブの途中でアプリが閉じた**：置き場は、そのウェーブの始まりの状態に戻る
- **輪の位置の上下の限り**：タップ攻撃と同じ（`tap.ring.topLimit` より上に行かない）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 置き場に入った（S2） | カードが飛んで入る、枠が光る | 小さなきらめき |
| 引き始め（S2） | カードが少し大きくなる、範囲の輪 | — |
| 予告 | 範囲の輪 0.2秒 | — |
| 効く | 型ごとの効果（0.4〜0.8秒）。キャラの上は 60% までの濃さ | 火「ごうっ」、雷「ばちっ」、氷「ぴきっ」、回復「上がる鐘」 |
| あふれて自動で起きた（S2） | 塔のまわりに効果、小さな「あふれた」の印 | 型の音 |

## 受け入れ条件
### 共通
- [ ] 範囲の攻撃の呪文が起きたら、中心から `spell.<id>.radius` の内の魔物すべての耐久が `spell.<id>.power`（強化の倍率をかけた値）減り、外の魔物は減らない
- [ ] 呪文が起きる前に、範囲の輪が `spell.preview.time` 秒出る
- [ ] 呪文の範囲にパックがあっても、パックのひびは増えない
- [ ] 遅くする効果が2つ重なったら、魔物の速さは強いほうの倍率になる（掛け合わせない）
- [ ] 1枚の呪文カードは1回起きたら無くなる
### 案S1
- [ ] `proto.spellMode` が S1 のとき、パックから呪文カードが出たら、そのパックの位置を中心に `spell.preview.time` 秒のあと起きる
- [ ] S1 のとき、画面に置き場は出ない
### 案S2
- [ ] `proto.spellMode` が S2 のとき、パックから呪文カードが出たら、空いている置き場の枠に入る
- [ ] 置き場のカードの上で押さえ始めて戦場で離したら、離したときの「指の位置から上へ `tap.ring.offset`」を中心に起きる
- [ ] 置き場のカードを引いているあいだ、タップ攻撃は起きない
- [ ] 置き場の帯の中で離したら、呪文は起きず、カードは元の枠に戻る
- [ ] 置き場が `spell.slot.count` 枚でいっぱいのときに呪文カードが出たら、いちばん古いカードが塔を中心に起き、新しいカードが置き場に入る
- [ ] 空いた枠の上で押さえ始めたら、タップ攻撃が起きる
- [ ] ウェーブを生き延びたら、置き場のカードは次のウェーブに残る
- [ ] 置き場のカードを引いているときに一時停止したら、カードは枠に戻る
