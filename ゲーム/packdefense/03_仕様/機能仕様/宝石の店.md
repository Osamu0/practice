# 機能仕様：宝石の店（擬似課金）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値の正は `03_仕様/パラメータ表.csv`、品揃えは `03_仕様/経済.md` 7.4・7.5。
**擬似課金の形は経済の案B1 で書く**（宝石で買えるのは見た目だけ。特別パック・英雄を連れていく品は置かない。がんばった証しは宝石で買えない「印」に分ける）。これはプロデューサーの仮決め（2026-11-25）で、**オーナーの確かめ待ち**。通貨の名前「宝石」も仮（オーナー、M6 まで）。

- **目的（どの柱のためか）**：オーナーの決め「擬似課金あり」（案B寄り、2026-11-25）。課金する気分（値札、おすすめの帯、まとめの大きな札、もらった演出）を、本物のお金なしで遊びとして置く。柱1〜3 を壊さない（強さ・名声・強化・割合につながない）

## 守ること（どの品揃えになっても変えない）
1. **本物の支払いの仕組みは一切入れない**。決済の API、外部の店、アプリ内課金、カード番号・パスワード・顔や指紋の確かめ、外への通信は使わない
2. **本物の買い物と見分けがつく**。店の上に、いつも見える帯で「**これはゲーム内の遊びです。本物のお金はかかりません**」（文はこれに統一。もらったあとの演出の板にも同じ1行）
3. 端末の本物の買い物の確認画面・OS の決済の見た目に似た絵は使わない（アート 7.5）。下からせり上がる支払いの板、指紋・顔の確かめのまね、カード番号の欄、確かめの2段（「本当に〜しますか」と聞き直す確認の板。品の板は品を見せる板なので、これに当たらない）、実在の支払いの仕組み・店の名前・印は使わない。店はゲームの絵柄（夜の紺 `#1A1F3D` に金のふち）で描く
4. 「購入」「お支払い」「決済」の言葉は使わない。「もらう」「受け取る」「交換する」を使う
5. 宝石で、名声・強化画面の項目・タップ攻撃の自動化・コイン・パック・パックの割合・英雄・印は買えない。中身の見えない宝石のくじは置かない
6. 期間限定・残り時間・「今だけ」・「残り○個」・割引の時計・「◯人が買いました」・急がせる点滅は置かない（柱3）
7. 「おトク」「お得」「割安」「おまけ多め」など、量や値段の得を言う札は置かない
8. 不便を消す機能（前と同じものを買う など）は売らない。最初から無料

## 画面の形
- 入口：強化画面の「宝石の店」ボタン（`unlock.gemShop`：最初の塔が壊れたあと）。もらう棚と買う棚は最初から全部見える（解放で引っぱらない）
- 上の帯（固定、いつも見える）：「これはゲーム内の遊びです。本物のお金はかかりません」。持っている宝石（ひし形の印＋数）
- 間（縦スクロール）：
  - **もらう棚**：経済 7.4 の札（`gem.offer.<id>.amount`・`gem.offer.<id>.label`）。札は宝石の色 `#FF6FA8` の札で、「宝石 ×N」と、値札（`gem.offer.<id>.label`。**「¥」の字はほかの数字より小さく**書く）、ひし形の印、「無料」の字を並べる。**もらう棚の札には飾りの札を付けない**（経済 7.4、アートディレクション 7.5）。棚の上の段ほど大きい札
  - **買う棚（見た目の品だけ）**：経済 7.5 の品。値段は宝石の数とひし形の印だけ（`gem.item.<id>.price`。「¥」「$」は書かない）。「おすすめ」の帯は、買う棚の見た目の品にだけ付けてよい
- 下の帯（固定）：「もどる」

### 買う棚の品（経済 7.5。数と値段はそちら）
| 種類 | 中身 | 変えないもの |
|---|---|---|
| 英雄の色違い（役ごと） | 役の英雄の色を替える | 役が見分けられる色にとどめる。敵の色（赤・紫・灰）を使わない |
| 塔の見た目 | 塔の形・飾りを替える | 塔の耐久の見え方（バー、ひび、危険の色）を変えない |
| パックの柄 | 枠の内側の柄を替える | **パックの枠の色（レア度）と、隠れたパックの印の色を変えない** |
| 開封の飾り | 紙吹雪の形など | レア度ごとの光の大きさ・音の段を変えない |
| 図鑑の飾り | 図鑑の背景・枠 | 図鑑の「出会っていない影」を変えない |
- **置かない品**：特別パック、英雄を次のランへ連れていく品、ランの始めの選択肢、強さ・時間・割合に触れるもの全部（経済 B1）
- 買う棚の品は縦切り（M3）には入れない（経済 7.5）

## プレイヤーから見た動き（もらう）
1. もらう棚の札を押す
2. **確かめの板は出さない**。その場で宝石が光って持っている宝石へ飛び、数が `gem.offer.<id>.amount` 増え、「もらった！」の演出が `gem.getFx.time` 秒出る。演出はタップで飛ばせる。保存する
3. 押してから宝石が出るまでの待ちは入れない
- 押せる回数の上限は置かない（`gem.offer.cap` は「なし」）
- 二重押しは `ui.press.guard` 秒より短い2回めを無視する（演出の途中の札の押しも同じ）
- もらうと `gem.max` をこえるときは、`gem.max` で止め（こえた分は捨てる）、「これ以上は持てません」の1行を出す。すでに `gem.max` なら、宝石は増えず1行だけ

## プレイヤーから見た動き（交換する）
1. 買う棚の品を押す → 品の板（絵、説明、値段、「この品は見た目だけを変えます」の1行）
2. 「交換する」→ 宝石が値段だけ減り、品が手に入る。保存する
3. 持っている品は、品の板で「使う／使わない」を切り替える。同じ種類の品（塔の見た目どうし、同じ役の色違いどうし、など）は1つだけ使える。使うと前のは外れる（仮決め）
- 全部持っていたら、買う棚の上に「全部持っています」の1行

## 入力
| 入力 | 起きること |
|---|---|
| もらう棚の札 | その場で宝石が増え、「もらった！」の演出 |
| 演出の上をタップ | 演出を飛ばす |
| 買う棚の品 | 品の板 |
| 品の板「交換する」 | 宝石が足りれば交換 |
| 品の板「使う」「使わない」 | 見た目を切り替える。保存 |
| 品の板の外・「閉じる」 | 一覧へ |
| 「もどる」 | 強化画面 |

## 状態と遷移
| 状態 | 次へ | きっかけ |
|---|---|---|
| 一覧 | もらった演出（宝石が増えた、保存） | もらう札（`gem.max` 未満のとき） |
| もらった演出 | 一覧 | `gem.getFx.time` 秒・タップ |
| 一覧 | 品の板 | 買う品 |
| 品の板 | 一覧（宝石が減った、品を得た、保存） | 「交換する」（足りるとき） |
| 品の板 | 品の板（使う品が替わった、保存） | 「使う」「使わない」 |
| 品の板 | 一覧 | 閉じる |
| 一覧 | 強化画面 | もどる |

## 数値
`gem.offer.<id>.amount`、`gem.offer.<id>.label`、`gem.offer.cap`（なし）、`gem.item.<id>.price`、`gem.item.<id>.effect`（見た目だけ）、`gem.earn.*`（なし：遊びでは宝石は入らず、印が入る）、`gem.max`、`gem.getFx.time`、`unlock.gemShop`、`ui.press.guard`

## 例外・境界
- **0**：宝石が 0 でも店は開く。買う棚の品の「交換する」は押せない色
- **足りない**：「宝石が足りません」を1行。もらう棚へ誘う一文は出さない（急かさない）
- **2回押し**：`ui.press.guard` 秒より短い2回めは無視。1回押すごとに1回だけ増える
- **最大**：宝石は `gem.max` まで。表記は6文字以内
- **ランの途中**：店は開けない（強化画面からだけ）
- **通信**：店のどの操作でも外への通信を1つもしない
- **保存**：宝石が増えた・減った・品を使ったときに書く。書けなければ「保存できません」（`保存.md`）

|---|---|---|
| もらった | 宝石が飛ぶ、数が増える、「もらった！」と帯の1行（`gem.getFx.time` 秒、飛ばせる） | きらめき |
| 交換した | 品が光る | 明るい音 |
| 帯 | いつも出ている。点滅しない | — |

## 受け入れ条件
- [ ] 宝石の店の画面のどの位置にスクロールしても、「これはゲーム内の遊びです。本物のお金はかかりません」の帯が見えている
- [ ] もらう棚の札それぞれに、ひし形の印と「無料」の字があり、値札の「¥」の字がその札の数字より小さい
- [ ] 買う棚の値段に「¥」「$」の字がない（宝石の数とひし形だけ）
- [ ] もらう棚の札を押したら、確かめの板を出さずに、持っている宝石が `gem.offer.<id>.amount` 増え、「もらった！」の演出が出る。演出はタップで飛ばせ、飛ばさなくても `gem.getFx.time` 秒で消える
- [ ] `ui.press.guard` 秒より短い間隔で札を2回押したら、宝石は1回分だけ増える
- [ ] 持っている宝石が `gem.max` のとき札を押したら、宝石の数は変わらず、「これ以上は持てません」の1行が出る。`gem.max` より少ないが、もらうとこえるときは、宝石が `gem.max` ちょうどになり、同じ1行が出る
- [ ] もらう棚の札に「おすすめ」などの飾りの札がない
- [ ] 店の画面と演出のどこにも、「購入」「お支払い」「決済」の字がない（画面の文の一覧で確かめる）
- [ ] 店のどの操作でも、下からせり上がる支払いの板・指紋や顔の確かめの絵・カード番号の欄・「本当に〜しますか」の確認の板が出ない（品の板は除く）
- [ ] 店に入ってから出るまで、どの札・品・ボタンを押しても、外への通信が0件（Playwright で通信を記録して確かめる）
- [ ] コードに、決済の API（Payment Request API など）・外部の店への道・カード番号やパスワードの入力の欄がない
- [ ] 宝石が品の値段以上のとき「交換する」を押したら、宝石が値段だけ減り、品が手に入る
- [ ] 宝石が足りないとき「交換する」を押しても、宝石も品も変わらない
- [ ] 宝石の品をどれ使っても、パックの枠の色・隠れたパックの印の色・塔の耐久の見え方・図鑑の影は変わらない（品を全部使った状態と使わない状態で、同じ場面の画面を比べる）
- [ ] 店のどの品も、名声・強化画面の項目・自動化・コイン・パック・パックの割合・英雄・印を変えない（品の表で確かめる）
- [ ] 買う棚に、特別パック・英雄を連れていく品・強さに触れる品がない
- [ ] 店に、残り時間・期間限定・「今だけ」・「残り○個」・「おトク」「お得」「割安」「おまけ多め」の表示がない
- [ ] もらったあとすぐアプリを閉じて開き直しても、宝石の数が残っている
- [ ] 最初の塔が壊れる前は、宝石の店に行けない
