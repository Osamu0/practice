# 機能仕様：宝石の店（擬似課金。画面と流れの骨）

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
**この文書は画面と流れの骨だけ**。宝石で何が買えるか、宝石がどこからどれだけ入るか、値札の数と品揃えは、`game-design-economy` が同時に設計しているので、その結果を待つ。通貨の名前「宝石」は仮（オーナー、M6 まで）。

- **目的（どの柱のためか）**：オーナーの決め「擬似課金あり」（案B寄り、2026-11-25）。課金する気分を、本物のお金なしで遊びとして置く。柱3を壊さない（待たずに前より先へ。名声・強化を通貨で越えさせない）

## 守ること（オーナーの決めと柱。どの品揃えになっても変えない）
1. **本物の支払いの仕組みは一切入れない**。決済の API、外部の店、アプリ内課金、カード番号・パスワード・顔や指紋の確かめ、外への通信は使わない
2. **本物の買い物と見分けがつく**。店の上に、いつも見える帯で「これはゲーム内の遊びです。本物のお金はかかりません」。値札のそれぞれにも「お金はかかりません」の小さな字
3. 端末の本物の買い物の確認画面・OS の決済の見た目に似た絵は使わない（アート 7.5）。店はゲームの絵柄（夜の紺 `#1A1F3D` に金のふち）で描く
4. 宝石で名声・強化画面の項目・タップ攻撃の自動化・パックの割合を上げる権利は買えない。中身の見えない宝石のくじは置かない（デザインの柱）
5. 期間限定・残り時間・「今だけ」・「残り○個」・急がせる点滅は置かない（柱3）
6. 不便を消す機能（前と同じものを買う など）は売らない。最初から無料

## 画面の形
- 入口：強化画面の「宝石の店」ボタン（最初の塔が壊れたあと。開く条件は `unlock.gemShop`、economy が変えてよい）
- 上：いつも見える帯「これはゲーム内の遊びです。本物のお金はかかりません」。持っている宝石（ひし形の印＋数）
- **宝石をもらう棚**（案B の形）：札ごとに「宝石 ×N」と値札（例「¥120」）。値札の下に「お金はかかりません」。並びと数は `gem.offer.<id>.amount`・`gem.offer.<id>.label`（economy）。「おすすめ」の帯、まとめの大きな札を置いてよい
- **宝石で買う棚**：品ごとに絵、名前、宝石の値段（ひし形＋数）。品揃えは economy（候補：見た目の品、1ランに1つの特別パック など）
- 下：「もどる」

## プレイヤーから見た動き（もらう）
1. もらう棚の札を押す
2. ゲームの絵柄の小さな板が出る：「宝石 ×N をもらいます（お金はかかりません）」と「もらう」「やめる」
3. 「もらう」→ 宝石が光って持っている宝石に飛び、数が増える。保存する
- 確かめの板は、本物の買い物の確認画面と違う見た目にする（ゲームの板。OS の板や、Apple・Google のマークに似せない）
- 1回にもらえる量・回数の上限（`gem.offer.dailyCap` など）を置くかは economy。置くとしても、時間で待たせる形（残り時間の表示）にはしない

## プレイヤーから見た動き（買う）
1. 買う棚の品を押す → 品の板（絵、説明、値段）
2. 「交換する」→ 宝石が値段だけ減り、品が手に入る。保存する
3. 見た目の品は、その場で「使う／使わない」を切り替えられる（強化画面・図鑑から変えるかは economy・UX）

## 入力
| 入力 | 起きること |
|---|---|
| もらう棚の札 | 確かめの板 |
| 確かめの板「もらう」 | 宝石が増える |
| 確かめの板「やめる」・板の外 | 何も起きない |
| 買う棚の品 | 品の板 |
| 品の板「交換する」 | 宝石が足りれば交換 |
| 「もどる」 | 強化画面 |

## 状態と遷移
| 状態 | 次へ | きっかけ |
|---|---|---|
| 一覧 | もらう確かめ | もらう札 |
| もらう確かめ | 一覧（宝石が増えた、保存） | 「もらう」 |
| もらう確かめ | 一覧 | 「やめる」 |
| 一覧 | 品の板 | 買う品 |
| 品の板 | 一覧（宝石が減った、品を得た、保存） | 「交換する」（足りるとき） |
| 品の板 | 一覧 | 閉じる |
| 一覧 | 強化画面 | もどる |

## 数値
`gem.offer.<id>.amount`、`gem.offer.<id>.label`（値札の文字。例「¥120」）、`gem.offer.dailyCap`（置くなら）、`gem.item.<id>.price`、`gem.item.<id>.effect`、`gem.earn.*`（遊びで入る量。置くなら）、`unlock.gemShop`、`ui.gem.press.guard`。どれも economy が決める。

## 例外・境界
- **0**：宝石が 0 でも店は開く。買う棚の品は押せない色
- **足りない**：「宝石が足りません」を1行。もらう棚へ誘う一文は出さない（急かさない）
- **2回押し**：確かめの板があるので二重にもらわない。「もらう」の連続押しは1回だけ
- **最大**：宝石の数の上限は economy（置くなら `gem.max`）。表記は6文字以内
- **ランの途中**：店は開けない（強化画面からだけ）
- **通信**：店のどの操作でも外への通信を1つもしない
- **保存**：宝石が増えた・減った・品を使ったときに書く。書けなければ「保存できません」（`保存.md`）

## 受け入れ条件
- [ ] 宝石の店の画面のどの位置にスクロールしても、「これはゲーム内の遊びです。本物のお金はかかりません」の帯が見えている
- [ ] もらう棚の値札それぞれの下に「お金はかかりません」が出ている
- [ ] もらう棚の札を押して「もらう」を押したら、持っている宝石が `gem.offer.<id>.amount` 増え、ほかに何も起きない（外への通信なし、端末の支払いの画面が出ない）
- [ ] 確かめの板で「やめる」を押したら、宝石の数は変わらない
- [ ] 宝石の店のどの操作をしても、ブラウザの開発ツールで見て、外への通信が0件
- [ ] コードに、決済の API（Payment Request API など）・外部の店への道・カード番号やパスワードの入力の欄がない
- [ ] 宝石が品の値段以上のとき「交換する」を押したら、宝石が値段だけ減り、品が手に入る
- [ ] 宝石が足りないとき「交換する」を押しても、宝石も品も変わらない
- [ ] 店のどの品も、名声・強化画面の項目・自動化・パックの割合を変えない（品の表で確かめる）
- [ ] 店に、残り時間・期間限定・「今だけ」・「残り○個」の表示がない
- [ ] もらったあとすぐアプリを閉じて開き直しても、宝石の数が残っている
- [ ] 最初の塔が壊れる前は、宝石の店に行けない
