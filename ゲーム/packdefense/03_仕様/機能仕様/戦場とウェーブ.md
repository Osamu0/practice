# 機能仕様：戦場とウェーブ

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値と式の正は `03_仕様/パラメータ表.csv`。

- **目的（どの柱のためか）**：遊びの器。柱2（指は、いちばん危ないところへ）の舞台になる。ウェーブの区切りでショップへつなぎ、柱1（次のウェーブでパックが降る）と柱3（区切りで保存し、待たずに続く）を支える

## プレイヤーから見た動き
- 画面全体が戦場。中心（高さ `field.tower.yRatio`）に塔が1本。四方（北＝上、東＝右、南＝下、西＝左）に塔へ向かう道がある
- ウェーブが始まると、画面の上 1/3 に「第N ウェーブ」が `wave.announce.time` 秒だけ出る。戦場は止めない。角笛が鳴る
- 四方から魔物が湧いて塔へ向かう（`魔物.md`）。前のショップで買ったパックが降る（`パック.md`）
- **湧きが終わり**（その湧きの予定を全部出し終えた。`魔物.md`）、戦場の魔物が 0 になったら、そのウェーブを生き延びた。名声とコインが入り（`ランの終わりと名声.md`）、ショップが下からせり上がる（`ショップ.md`）
- 戦場の魔物が 0 で湧きの予定が残っているあいだは、次の組が前倒しで来る（`spawn.pullForward`。`魔物.md`）。強い守りのウェーブは早く終わる
- 塔の耐久が 0 になったら、ランが終わる（結果の画面へ）
- 塔の耐久はウェーブをまたいで持ち越す。ウェーブを生き延びたとき、最大の耐久の `tower.regen.waveEnd` の割合だけ戻る（最大はこえない）
- 塔の最大の耐久 ＝ `tower.hp.base` × `upgrade.towerHp.effect`^段（`upgrade.towerHp.maxLevel` 段まで）
- 右上の一時停止ボタンで止められる。ブラウザが裏に回っても止まる

## 入力
| 入力 | 起きること |
|---|---|
| 戦場を押さえる | タップ攻撃（`タップ攻撃.md`） |
| 一時停止ボタン（右上。見た目 44×44、押せる範囲 48×48） | 一時停止の板を出す |
| 一時停止の板：「再開」 | 戦場に戻る（すぐ動き出す） |
| 一時停止の板：「設定」 | 設定（`設定.md`）。閉じると一時停止の板に戻る |
| 一時停止の板：「ランをやめる」→ 確かめの板で「やめる」 | ランを終える（塔が壊されたときと同じ結果の画面へ） |
| 裏から戻ったあとの「タップで再開」の覆いをタップ | 戦場が動き出す（音もここで起こす。`技術選定.md` 4.4） |

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| ウェーブの始まり | 保存する（`保存.md`）。告知を出す。湧きの予定とパックの降る予定を組む。湧きの時計を 0 に | 戦い | すぐ（同じフレーム） |
| 戦い | 魔物が湧く（前倒しを含む）。パックが降る。タップ攻撃・英雄・呪文 | 片付け | 湧きの予定を全部出し終えた |
| 片付け | 湧きはない。残りの魔物と戦う。パックはまだ開けられる | 生き延びた | 戦場の魔物が 0 |
| 戦い／片付け（急ぐ） | ウェーブの経過（告知から）が `wave.duration.max` をこえた。残りの魔物の速さが `monster.rush.speedMul` 倍、塔への攻撃の速さが `monster.rush.atkMul` × 2^floor（こえた秒 ÷ `monster.rush.doubleEvery`）倍、1回の攻撃が max（ふつうの攻撃, 塔の最大 × `monster.rush.hitRatio`）になる | 生き延びた | 湧きを出し終え、戦場の魔物が 0 |
| 生き延びた | まず途中のものをすべて確定させる（下の「生き延びたときの確定」）。名声・コインを足す。塔を戻す。開けていないパックは次のウェーブへ持ち越す | ショップ | 演出（`wave.clear.fxTime`）のあと |
| ショップ | `ショップ.md` | ウェーブの始まり（番号+1） | 「次のウェーブへ」 |
| 塔が壊れた | 魔物・英雄・パックの動きを止める | 結果 | 演出（`tower.destroyed.fxTime`）のあと |
| 一時停止 | 計算の歩みを止める。音を止める | 前の状態 | 「再開」／覆いのタップ |

- 「戦い」「片付け」のどちらでも、塔の耐久が 0 になったら「塔が壊れた」へ
- 急ぐのは「戦い」の途中でも起きる（湧きの予定が残っていても、湧いている魔物は急ぐ。あとから湧く魔物も急いだ状態で来る）
### 生き延びたときの確定
生き延びた（ショップへ移る前、保存の前）に、途中のものをすべて確定させる。そのあとで保存する。
1. 開封の途中のパックは、演出を打ち切って開けたことにする：英雄は立ち（`英雄.md`）、呪文は S1 なら起きずに消える／S2 なら置き場へ入り、あふれは古い順に自動で起きる（`呪文カード.md`）。図鑑にも載る
2. 倒れる演出中の魔物は、倒れた瞬間にコインと名声を足してある（`魔物.md`。演出は見た目だけ）。吸い込み中のコインも、HUD の数にはもう入っている
3. 起きている途中の呪文（予告中・続く効果）は、ウェーブの終わりで打ち切る（S1 の予告中のものは起きずに消える）

- 一時停止は「戦い」「片付け」「生き延びた」の演出中に入れる。ショップ・板の画面では、時間が進まないので一時停止は要らない

## 数値
`field.tower.yRatio`、`tower.hp.base`、`upgrade.towerHp.effect`、`upgrade.towerHp.maxLevel`、`tower.hitRadius`、`tower.hp.dangerRatio`、`tower.regen.waveEnd`、`wave.announce.time`、`wave.spawn.duration`（`wave.spawn.first`・`.perWave`・`.cap`）、`wave.duration.max`、`monster.rush.speedMul`、`monster.rush.atkMul`、`monster.rush.doubleEvery`、`monster.rush.hitRatio`、`spawn.pullForward`、`spawn.pullForward.minGap`、`wave.clear.fxTime`、`tower.destroyed.fxTime`、`wave.boss.every`

前提の決め（計画 6章 #5）：第1ウェーブは短く、どのウェーブも告知から終わりまでおよそ `wave.duration.max` まで（保存の形の前提）。

## 例外・境界
- **0**：塔の耐久はちょうど 0 で壊れる。小数の残りは切り上げて見せる（0.4 は「1」と見せ、壊れていない）
- **最大**：ウェーブの番号に上限はない（終わりは未決 U4）。塔の回復で最大をこえない
- **同時**：同じ1歩で「最後の魔物が倒れる」と「塔の耐久が 0」が起きたら、塔が壊れたほうを採る。1歩の終わりに、まず塔の耐久を見て（0 以下ならラン終わり）、そのあとでウェーブの終わりを見る
- **生き延びた瞬間に途中のものがある**：開封の途中のパック・倒れる演出中の魔物は、上の「生き延びたときの確定」で確定させてから保存する（保存に途中の状態を残さない）
- **湧きを待っている**：画面の魔物が `limit.monster.max` で予定が待っているあいだは、湧きは終わっていない。魔物が 0 になってもショップは開かない（待っていた予定を出してから）
- **中断**：ウェーブの途中でアプリが閉じられたら、次に開いたとき、そのウェーブの始まりから（`保存.md`）。負けそうなときに閉じて戻るのも許す（仮決め。プロデューサー 2026-11-25。GDD U14）
- **ポーズ**：一時停止中は、湧き・湧きの時計・移動・攻撃・パックの降り・演出・経過の時間がすべて止まる。押さえている指の攻撃も止まる
- **裏に回る**：`visibilitychange` で隠れたら一時停止にする。戻ったら「タップで再開」の覆い。覆いは、ほかの板（設定など）が開いているときは出さず、板を閉じたときに出す（技術選定 5.4 で見つけた重なり）。留守のあいだは何も進まない（仮決め。GDD U5）
- **湧きの長さを過ぎても魔物が残り続ける**：`wave.duration.max` で急ぐので、必ず塔に着き、倒されるか塔を壊す。止まったままのウェーブはない
- **はじめのラン**：第1ウェーブは `はじめの流れと要素の解放.md` の順

| きっかけ | 演出 | 音 |
|---|---|---|
| ウェーブの始まり | 「第N ウェーブ」の告知 | 角笛 |
| 塔が攻撃された | 塔のまわりが危険の色で一瞬光る | 低い「ずん」（0.5秒に1回まで） |
| 塔の耐久が `tower.hp.dangerRatio` を下回った | 耐久のバーが危険の色になり点滅 | — |
| 急ぎ始めた | 魔物の足元に小さな土ぼこり（04 のあと） | — |

| 塔が壊れた | 塔が崩れる | 結果の短い曲（暗くしない） |
| 一時停止 | 戦場を暗くして板 | BGM・効果音を止める |

## 受け入れ条件
- [ ] ウェーブが始まったら、「第N ウェーブ」が画面の上 1/3 に `wave.announce.time` 秒出て、その間も魔物は動いている
- [ ] 湧きの予定（`wave.budget(n)` の点と大物）を全部出し終えたら、そのウェーブではそれより後に新しい魔物は湧かない
- [ ] 戦場の魔物が 0 で湧きの予定が残っているあいだは、前の湧きから `spawn.pullForward.minGap` 秒あけて、次の組が前倒しで湧く
- [ ] 画面の魔物が `limit.monster.max` に達して湧きを待っている予定があるあいだは、戦場の魔物が 0 になってもショップは開かない
- [ ] 湧きを出し終え、戦場の魔物が 0 になったら、ショップが開く
- [ ] レジェンドのパックの開封の演出中に最後の魔物が倒れたら、ショップが開いた直後の保存に、そのパックから出た英雄が戦場の英雄として入っている
- [ ] 最後の魔物を倒してすぐショップが開いたとき、ショップのコインにその魔物のコインが入っている（吸い込みの演出の途中でも）
- [ ] 経過が `wave.duration.max` をこえても魔物が残っていたら、残りの魔物の速さが `monster.rush.speedMul` 倍になり、塔への攻撃の間隔が `atkInterval ÷ (monster.rush.atkMul × 2^floor(こえた秒 ÷ monster.rush.doubleEvery))` になり、1回の攻撃が塔の最大 × `monster.rush.hitRatio` より小さくならない
- [ ] 塔の耐久が 0 になったら、`tower.destroyed.fxTime` 秒のあと結果の画面になる
- [ ] 同じ1歩で最後の魔物が倒れ、塔の耐久も 0 になったら、結果の画面になる（ショップは開かない）
- [ ] ウェーブを生き延びたら、塔の耐久が最大の `tower.regen.waveEnd` の割合だけ戻り、最大はこえない
- [ ] 塔の耐久が `tower.hp.dangerRatio` を下回ったら、耐久のバーが危険の色で点滅する
- [ ] 一時停止ボタンを押したら、湧き・移動・攻撃・経過の時間が止まり、10秒待って再開しても経過は押す前と同じ
- [ ] 一時停止ボタンは、見た目の外側 2px（48×48 の範囲）を押しても反応する
- [ ] ブラウザが裏に回ったら一時停止になり、戻ると「タップで再開」が出て、タップするまで時間が進まない。裏にいたあいだに、コイン・名声・湧き・塔の耐久は何も変わらない
- [ ] 設定を開いているあいだに裏に回って戻っても、「タップで再開」は設定の板の上にかぶさらない。設定を閉じたら出る
- [ ] 一時停止の板で「ランをやめる」→「やめる」を押したら、結果の画面になる。「やめない」を押したら一時停止の板に戻る
- [ ] 同じシード・同じウェーブ番号なら、指を使わずに放っておいたとき、湧きの時刻・場所・種類が毎回同じになる（技術選定 4.2）
