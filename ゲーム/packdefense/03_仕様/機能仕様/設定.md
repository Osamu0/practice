# 機能仕様：設定（輪のずらし、音）

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。

- **目的（どの柱のためか）**：柱2（縦持ち・片手で、自分の指と持ち方に合わせて攻撃の輪の位置を変える）と前提（音を自分で止められる）

## プレイヤーから見た動き
- 開く場所：一時停止の板（ランの途中、最初から）と強化画面（ランのあいだ）
- 並ぶもの（上から）
  | 項目 | 選べる値 | 既定 | メモ |
  |---|---|---|---|
  | 攻撃の輪のずらし | `tap.ring.offset.options`（0／40／56／72） | `tap.ring.offset.default`（56） | 選ぶと、下に「ここを押して試す」の小さな試しの場所が出て、押すと輪がその位置に出る |
  | BGM | 切る／小／中／大 | `audio.bgm.default` | |
  | 効果音 | 切る／小／中／大 | `audio.se.default` | |
  | （マナーモードでも鳴らす） | — | — | **置かない**（仮決め。プロデューサー 2026-11-25、GDD U6）。この行は出さない |
  | コモンの開封を短く | 入／切 | 切 | あれば。04 のあと |
  | 書き出し・読み込み | → 板 | | `保存.md` |
  | 新しく始める | → 確かめの板を2回 | | `保存.md` |
  | 版の番号・クレジット | 表示だけ | | |
- 変えたらすぐ効き、保存する。ランの途中（一時停止の板から）で変えたときの保存は、ランの部分をウェーブの始まりのままにして設定だけを書く（`保存.md` の「ウェーブの途中に書くとき」）

## 入力
| 入力 | 起きること |
|---|---|
| 値のボタン（どれも 48 以上） | その値にする。保存 |
| 試しの場所を押さえる | その場所の上にいまのずらしの輪が出る（攻撃はしない） |
| 「閉じる」 | 開いた元（一時停止の板／強化画面）へ |

## 数値
`tap.ring.offset.options`、`tap.ring.offset.default`、`audio.bgm.default`、`audio.se.default`、`audio.volume.steps`（切る／小／中／大の音量の値）

## 例外・境界
- **ランの途中で変えた**：ずらしは次に押さえたときから効く（押さえている途中では変わらない。設定を開いている間は一時停止なので、押さえていない）
- **音を切っている**：音の情報は絵でも出しているので遊べる（アートの決め）。音を切っても AudioContext の手当て（技術選定 4.4）はそのまま
- **マナーモード**：マナーモードなら鳴らない（ふつうのゲームと同じ。仮決め）
- **保存が書けない**：設定は効くが、次に開いたときは前の値（保存できませんの1行は `保存.md`）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 効果音の大きさを変えた | — | その大きさで「トッ」を1回 |
| BGM を変えた | — | その大きさで BGM（一時停止の中でも小さく鳴らしてよいかは audio） |

## 受け入れ条件
- [ ] 一時停止の板と強化画面の両方から設定を開ける
- [ ] 輪のずらしを 72 にして閉じ、戦場を押さえたら、輪が指の 72 上に出る
- [ ] 輪のずらしを 0 にしたら、輪が指の真下に出る
- [ ] 試しの場所を押さえたら、いまのずらしの位置に輪が出て、魔物・パックには当たらない
- [ ] 効果音を「切る」にしたら、タップ攻撃・開封の音が鳴らない。BGM は BGM の設定のまま
- [ ] 設定を変えてアプリを閉じ、開き直しても、変えた値のまま
- [ ] 設定のボタンはどれも押せる範囲が 48×48 以上
- [ ] iPhone をマナーモードにしたら、BGM も効果音も鳴らない（実機で確かめる）
- [ ] ウェーブの途中に一時停止の板から設定を変えて閉じ、アプリを閉じて開き直したら、そのウェーブの始まりから、変えた設定で始まる
