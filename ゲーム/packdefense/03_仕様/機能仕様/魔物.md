# 機能仕様：魔物の出現と進み方

game-spec-writer、2026-11-25（第1版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。
個々の魔物の表（名前・姿・細かい癖）は 04 のあと `game-design-combat`・`game-design-ai` と 07 で作る。この文書は、すべての魔物に共通の決まりと、型ごとの違いの骨を書く。

- **目的（どの柱のためか）**：柱2。四方から来る魔物が「どこがいちばん危ないか」を作り、指の向け先を決めさせる。時間とウェーブで、より危険な魔物になる（オーナーの構造②）

## プレイヤーから見た動き
- 魔物は、四方（北・東・南・西）の画面の外の入口の帯から湧き、塔へ向かってまっすぐ進む（道に沿う見た目にするかは絵の担当。当たりと進みは塔へのまっすぐの線）
- 縦長の画面なので、北と南（上下）は塔から遠く、東と西（左右）は近い。左右から来る魔物はすぐ着き、上下から来る魔物は着くまで時間がある
- 塔の手前（塔の当たり `tower.hitRadius` ＋ `monster.attackRange`）に着くと止まり、`monster.<type>.atkInterval` ごとに塔へ `monster.<type>.atk` の攻撃をする
- 倒すとコインが落ち、`coin.flyTime` 秒で HUD のコインへ自動で吸われる（拾う操作は要らない）。名声も少し入る（`ランの終わりと名声.md`）
- **英雄は攻撃しない**：魔物は塔だけを狙う（仮決め。英雄は倒されない）
- ウェーブが進むほど、湧く量（`wave.budget(n)`）と、1体の耐久・攻撃・コイン（`monster.hp.growth` など）が伸び、新しい型（`monster.<type>.fromWave`）が混じる
- `wave.boss.every` ウェーブごとに、大物が1体来る（節目）
- 群れや大物が来る方向には、`spawn.telegraph.time` 秒前から、画面の端に危険の三角（！つき、点滅）が出る

## 型ごとの違い（骨）
| 仮のID | 役 | 決まり | 主なパラメータ |
|---|---|---|---|
| `slime` | ふつう | 基準 | `monster.slime.hp`・`.speed`・`.atk`・`.atkInterval`・`.coin`・`.fame`・`.cost`・`.fromWave` |
| `wolf` | 速い | 速い、耐久が低い | 同じ並び |
| `skeleton` | 硬い | 遅い、耐久が高い | 同じ並び |
| `swarm` | 群れ | 1回の湧きで `monster.swarm.groupSize` 体が固まって来る。1体は弱い | 同じ並び＋`monster.swarm.groupSize`、`monster.swarm.spread` |
| `bat` | 飛ぶ | 近い攻撃の英雄（剣士・盾の騎士・斥候）の攻撃が当たらない（仮決め）。タップ攻撃・自動化・遠い攻撃・呪文は当たる | 同じ並び＋`monster.bat.flying` |
| `orc` | 大きい | 耐久と攻撃が高い、遅い、体が大きい | 同じ並び |
| `goblin` | ふつう2（あれば） | 未定。04 のあと | 同じ並び |
| `boss` | 大物 | 節目のウェーブに1体。同時に `limit.boss.max` 体まで | 同じ並び＋`wave.boss.every` |

## 湧き方（ウェーブの中）
- ウェーブ n の湧きの量は「点」で数える：`wave.budget(n)`。1体の型ごとに点 `monster.<type>.cost` を使う
- そのウェーブで出せる型は、`monster.<type>.fromWave ≤ n` のもの
- 方向は `spawn.dirWeight.n／e／s／w` の重みで選ぶ。南（下）は親指と手のひら、呪文の置き場に隠れるので、重みを低くするか遅い型を寄せる（計画 6章 #9。値は `game-spec-balance`・`game-design-combat`）
- 湧く時刻は、湧きの長さ `wave.spawn.duration(n)` に散らす。群れは `spawn.groupGap` 秒の間隔をあけてまとめて出す
- 乱数はウェーブごとの流れ（`シード/w番号`）。同じシード・同じ番号なら同じ湧き（技術選定 4.2）
- 画面に出ている魔物が `limit.monster.max` に達したら、次の湧きは、数が減るまで待つ（湧きの点は捨てない）。上限をこえる伸びは、1体の強さで出す（`game-spec-balance`）

## 入力
魔物を直接動かす入力はない。攻撃はタップ攻撃・自動化・英雄・呪文カードから。

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 予告 | 群れ・大物なら、危険の三角を出す | 進む | `spawn.telegraph.time` 秒たった（ほかの型は予告なしで進む） |
| 進む | 塔へまっすぐ `speed` で進む | 攻める | 塔の手前に着いた |
| 進む／攻める | — | 倒れる | 耐久が 0 以下 |
| 攻める | 止まって `atkInterval` ごとに塔を攻撃 | 倒れる | 耐久が 0 以下 |
| 進む／攻める（遅く） | 呪文・盾の騎士で遅くなっている。速さに `slow` の倍率 | 元に戻る | 効果の時間が切れた |
| 倒れる | 演出 0.3 秒、コインと名声を足す | 消える | 演出の終わり |

## 数値
`monster.<type>.hp`、`.speed`、`.atk`、`.atkInterval`、`.coin`、`.fame`、`.cost`、`.fromWave`、`.size`（当たりの半径）、`monster.hp.growth`、`monster.atk.growth`、`monster.coin.growth`、`monster.fame.growth`、`monster.attackRange`、`monster.rush.speedMul`、`monster.swarm.groupSize`、`monster.swarm.spread`、`monster.bat.flying`、`wave.budget`、`wave.boss.every`、`spawn.dirWeight.n`・`.e`・`.s`・`.w`、`spawn.groupGap`、`spawn.telegraph.time`、`spawn.entry.margin`、`limit.monster.max`、`limit.boss.max`、`coin.flyTime`

技術選定の条件：数はふつうに遊べる範囲で 1e300 未満（T2）。弾の速さの上限（R12）は英雄の弾に関わる（`英雄.md`）。

## 例外・境界
- **0**：そのウェーブで出せる型の点が `wave.budget(n)` より大きいときは、出せる中でいちばん安い型で埋める（湧きが0のウェーブを作らない）
- **最大**：画面の魔物が `limit.monster.max` のとき湧きを待たせる。待っている点が残っているあいだは、湧きは終わっていない（ショップは開かない）
- **同時**：同じ魔物に同じ1歩で何度当たっても、倒れるのは1回、コインと名声も1回
- **塔が壊れた**：魔物は止まる。そのあと倒れても、コイン・名声は足さない
- **ポーズ**：すべて止まる
- **急ぐ**：`wave.duration.max` をこえたら、残りの魔物の速さが `monster.rush.speedMul` 倍
- **画面の外**：入口の帯（画面の外 `spawn.entry.margin`）から入るまでは、タップ攻撃で当たらない（見えないものは打てない）。英雄の攻撃も画面の中の魔物だけ
- **縦が足りない機種（375×667 など）**：戦場の上下が切れる（アート 5.1）。入口の帯は見えている画面の外に置く（切れた分だけ近くなる。04 で SE の大きさを見る）

## 演出と音のきっかけ
| きっかけ | 演出 | 音 |
|---|---|---|
| 群れ・大物の予告 | 画面の端に危険の三角＋！、点滅 | 短い2音の警告 |
| 当たった | 白く光る、はじかれる | タップ攻撃・英雄の音（各仕様） |
| 倒れた | つぶれる→はじける→粒→消える、コインが出て HUD へ飛ぶ | 「ぽん」（重いほど低い）、コインの鈴 |
| 塔を攻撃 | 塔が光る | 「ずん」 |
| 大物の登場 | 大きな影 | 低い音（04 のあと） |

## 受け入れ条件
- [ ] ウェーブ n では、`monster.<type>.fromWave` が n より大きい型は湧かない
- [ ] 1ウェーブで湧いた魔物の点（`monster.<type>.cost` の合計）が `wave.budget(n)` をこえない
- [ ] 湧いた魔物は、塔の中心へまっすぐ `speed` で進む（1秒で `speed` px 近づく）
- [ ] 魔物が塔の手前に着いたら止まり、`atkInterval` 秒ごとに塔の耐久が `atk` 減る
- [ ] 魔物を倒したら、HUD のコインが `monster.<type>.coin`（ウェーブの伸びをかけた値）だけ、`coin.flyTime` 秒のうちに増える。指で拾う操作は要らない
- [ ] 魔物は英雄を攻撃しない（英雄の数は魔物のせいで減らない）
- [ ] 飛ぶ魔物（`bat`）には、剣士・盾の騎士・斥候の攻撃が当たらず、タップ攻撃・自動化・弓使い・魔法使い・呪文は当たる
- [ ] 群れ（`swarm`）が湧いたら、`monster.swarm.groupSize` 体が `monster.swarm.spread` px の内にまとまって出る
- [ ] 群れか大物が湧く `spawn.telegraph.time` 秒前に、その方向の画面の端に危険の三角が出る
- [ ] ウェーブ番号が `wave.boss.every` の倍数のウェーブで、大物が1体湧く
- [ ] 画面の魔物が `limit.monster.max` に達したら、それ以上湧かず、数が減ったら残りが湧く
- [ ] 同じシード・同じウェーブ番号なら、湧く型・方向・時刻の並びが毎回同じ
- [ ] 塔が壊れたあとに魔物が倒れても、コインと名声は増えない
- [ ] 画面の外の魔物には、タップ攻撃が当たらない
