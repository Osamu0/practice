# 機能仕様：魔物の出現と進み方

game-spec-writer、2026-11-25（第2版）。数値はすべて `03_仕様/パラメータの名前.md` の名前。値と式の正は `03_仕様/パラメータ表.csv`。
個々の魔物の表（名前・姿・細かい癖）は 04 のあと `game-design-combat`・`game-design-ai` と 07 で作る。この文書は、すべての魔物に共通の決まりと、型ごとの違いの骨を書く。

- **目的（どの柱のためか）**：柱2。四方から来る魔物が「どこがいちばん危ないか」を作り、指の向け先を決めさせる。時間とウェーブで、より危険な魔物になる（オーナーの構造②）

## プレイヤーから見た動き
- 魔物は、四方（北・東・南・西）の画面の外の入口の帯（`spawn.entry.margin`）から湧き、塔へ向かってまっすぐ進む（道に沿う見た目にするかは絵の担当。当たりと進みは塔へのまっすぐの線）
- 縦長の画面なので、北と南（上下）は塔から遠く、東と西（左右）は近い。左右から来る魔物はすぐ着き、上下から来る魔物は着くまで時間がある
- 塔の手前（塔の中心から `tower.hitRadius` ＋ `monster.<type>.size` ＋ `monster.attackRange`）に着くと止まり、`monster.<type>.atkInterval` ごとに塔へ攻撃する（1回の攻撃 ＝ `monster.<type>.atk` × `monster.atk.growth`）
- 倒すとコインが落ち、`coin.flyTime` 秒で HUD のコインへ自動で吸われる（拾う操作は要らない）。名声も少し入る（`ランの終わりと名声.md`）。コインと名声は倒れた瞬間に足す（吸い込みは見た目だけ）。倒れる演出の途中でウェーブを生き延びても入っている（`戦場とウェーブ.md` の「生き延びたときの確定」）
- **英雄は攻撃しない**：魔物は塔だけを狙う。英雄は倒されない（仮決め。プロデューサー 2026-11-25。04 とオーナーの返事で見直す）
- ウェーブが進むほど、湧く量（`wave.budget(n)`）と1体の耐久（`monster.hp.growth`）が伸び、新しい型（`monster.<type>.fromWave`）が混じる。攻撃は伸ばさない（`monster.atk.growth`）
- `wave.boss.every` ウェーブごとに、大物が1体来る（節目。MVP から）
- 群れや大物が来る方向には、湧く `spawn.telegraph.time` 秒前から、画面の端に危険の三角（！つき、点滅）が出る

## コイン（1体ぶん）
- `monster.<type>.coin` は**重み**（コインそのものではない）。ウェーブ n で1体を倒したときのコイン：
  **コイン ＝ `wave.coin.base` × `econ.market(n)` × `monster.<type>.coin` ÷ `wave.budget(n)` × `upgrade.coinGain.effect`^段**（`coinGain` は MVP。段0 なら 1）
- 湧きの予定を全部倒すと、合計がおよそ `wave.coin.base × econ.market(n)`（× `coinGain`）になる。魔物の数が増えてもウェーブのコインは増えない（相場だけで伸びる）
- 大物の重みは `wave.budget(n)` の点の外で足す（大物を倒すと、そのぶん多い）
- 名声（1体ぶん）の式は `ランの終わりと名声.md`

## 湧き方（ウェーブの中）
### 湧きの予定を組む（ウェーブの始まりに1回）
1. **点**：ウェーブ n の湧きの量は `wave.budget(n)` 点
2. **型**：`monster.<type>.fromWave ≤ n` で、点 `monster.<type>.cost` が残りの点以下の型から、`spawn.typeWeight.<type>` の重みで1つ引き、残りの点から引く。残りの点がいちばん安い型の点より少なくなるまでくり返す（大物は別に足す）
3. **組**：引いた湧きを、引いた順に「いっぺんに来る組」にまとめる。1組の数 ＝ `min(spawn.packet.cap, spawn.packet.base + floor((n−1) ÷ spawn.packet.perWaves))`。1つの組の中の湧きは、ちがう方向から来る（方向は、組でまだ使っていない方向から `spawn.dirWeight.n／e／s／w` の重みで引く）
4. **時刻**：組の数を G とすると、g 番め（0 から）の組の時刻は、湧きの時計で `wave.spawn.duration(n) × (g + 0.5) ÷ G`
5. **大物**：節目のウェーブは、大物1体を予定に足す（時刻は未決。下の表）
- 群れ・大物の湧きどうしは `spawn.groupGap` 秒以上あける（あかないときは後ろの湧きを遅らせる）
- 乱数はウェーブごとの流れ（`シード/w番号`）。同じシード・同じ番号なら同じ予定（技術選定 4.2）
- **はじめのランの第1ウェーブ**だけは、方向を `intro.wave1.dirOrder` で決め、3 の「組の中はちがう方向」より優先する。予定の前の 1/4 は東だけ（組の全員が東から）、次の 1/4 は東と西を交互、そのあとは四方（同じ重み）（`はじめの流れと要素の解放.md`）

### 湧きの時計と前倒し
- **湧きの時計**：ウェーブの始まりで 0。ふつうは時間と同じ速さで進む。予定の時刻は、この時計で数える（パックの降る時刻も同じ時計。`パック.md`）
- **前倒し**（`spawn.pullForward` が入のとき）：戦場の魔物が 0 で、予定がまだ残っていて、前の湧きから `spawn.pullForward.minGap` 秒たったら、湧きの時計を次の組の時刻まで進める（すぐ次の組が湧く。そのあとの予定もいっしょに早まる）
- 前倒しでも、群れ・大物は危険の三角を `spawn.telegraph.time` 秒出してから湧く
- **湧きの終わり**：その湧きの予定（`wave.budget(n)` の点と大物）を全部出し終えた時。湧きの時計が `wave.spawn.duration(n)` に達したかどうかでは決めない
- 画面に出ている魔物が `limit.monster.max` に達したら、次の湧きは、数が減るまで待つ（予定は捨てない。待っているあいだは湧きは終わっていない）。上限をこえる伸びは、1体の強さで出す（`game-spec-balance`）

## 入力
魔物を直接動かす入力はない。攻撃はタップ攻撃・自動化・英雄・呪文カードから。

## 状態と遷移
| 状態 | 中で起きること | 次へ | きっかけ |
|---|---|---|---|
| 予告 | 群れ・大物なら、危険の三角を出す | 進む | `spawn.telegraph.time` 秒たった（ほかの型は予告なしで進む） |
| 進む | 塔へまっすぐ `speed` で進む | 攻める | 塔の手前に着いた |
| 進む／攻める | — | 倒れる | 耐久が 0 以下 |
| 攻める | 止まって `atkInterval` ごとに塔を攻撃 | 倒れる | 耐久が 0 以下 |
| 進む／攻める（遅く） | 呪文・盾の騎士で遅くなっている。速さに `slow` の倍率 | 元に戻る | 効果の時間が切れた |
| 進む／攻める（急ぐ） | ウェーブの経過が `wave.duration.max` をこえた。速さ・攻撃が強まる（`戦場とウェーブ.md`） | 倒れる | 耐久が 0 以下 |
| 倒れる | 倒れた瞬間に、コインと名声を足す（演出 0.3秒と `coin.flyTime` は見た目だけ）。当たりはもうない | 消える | 演出の終わり |

## 例外・境界
- **0**：そのウェーブで出せる型の点がどれも `wave.budget(n)` より大きいときは、出せる中でいちばん安い型を1つ出す（湧きが0のウェーブを作らない）
- **最大**：画面の魔物が `limit.monster.max` のとき湧きを待たせる。待っている予定が残っているあいだは、湧きは終わっていない（魔物が 0 になってもショップは開かない）。大物は同時に `limit.boss.max` 体まで。前の大物が残っていたら次の大物は待つ
- **同時**：同じ魔物に同じ1歩で何度当たっても、倒れるのは1回、コインと名声も1回
- **塔が壊れた**：魔物は止まる。そのあと倒れても、コイン・名声は足さない
- **ポーズ**：すべて止まる（湧きの時計も）
- **急ぐ**：`wave.duration.max` をこえたら、残りの魔物の速さ・攻撃が強まる（`戦場とウェーブ.md` の「片付け（急ぐ）」）
- **画面の外**：入口の帯から画面の中に入るまでは、タップ攻撃で当たらない（見えないものは打てない）。英雄の攻撃も画面の中の魔物だけ
- **縦が足りない機種（375×667 など）**：戦場の上下が切れる（アート 5.1）。入口の帯は見えている画面の外に置く（切れた分だけ近くなる。04 で SE の大きさを見る）

| きっかけ | 演出 | 音 |
|---|---|---|
| 群れ・大物の予告 | 画面の端に危険の三角＋！、点滅 | 短い2音の警告 |

## 受け入れ条件
- [ ] ウェーブ n では、`monster.<type>.fromWave` が n より大きい型は湧かない
- [ ] 1ウェーブで湧いた魔物の点（大物を除く `monster.<type>.cost` の合計）が `wave.budget(n)` をこえない
- [ ] ウェーブ n の組は、`min(spawn.packet.cap, spawn.packet.base + floor((n−1) ÷ spawn.packet.perWaves))` 個の湧きが同じ時刻に、たがいにちがう方向から来る（はじめのランの第1ウェーブを除く）
- [ ] はじめのランの第1ウェーブでは、予定の前の 1/4 の湧きが全部東から来る（同じ組の湧きも東から）
- [ ] 湧いた魔物は、塔の中心へまっすぐ `speed` で進む（1秒で `speed` px 近づく）
- [ ] 魔物が塔の手前に着いたら止まり、`atkInterval` 秒ごとに塔の耐久が `atk × monster.atk.growth` 減る（急いでいないとき）
- [ ] ウェーブ n で魔物を倒したら、HUD のコインが `wave.coin.base × econ.market(n) × monster.<type>.coin ÷ wave.budget(n)`（`coinGain` の段があれば `upgrade.coinGain.effect`^段 をかけた値）だけ増える（保存の中身では倒れた瞬間に、HUD の見た目は `coin.flyTime` 秒のうちに）。指で拾う操作は要らない
- [ ] 最後の魔物を倒してすぐショップが開いたとき、ショップのコインにその魔物のコインが入っている
- [ ] 第1ウェーブ（強化なし）の湧きの予定を全部倒したら、そのウェーブで倒して入ったコインの合計が `wave.coin.base` になる（小数の誤差 1% の内）
- [ ] 魔物は英雄を攻撃しない（英雄の数は魔物のせいで減らない）
- [ ] 飛ぶ魔物（`bat`）には、剣士・盾の騎士・斥候の攻撃が当たらず、タップ攻撃・自動化・弓使い・魔法使い・槍兵・僧侶・呪文は当たる
- [ ] 群れ（`swarm`）が湧いたら、`monster.swarm.groupSize` 体が `monster.swarm.spread` px の内にまとまって出る
- [ ] 群れか大物が湧く `spawn.telegraph.time` 秒前に、その方向の画面の端に危険の三角が出る（前倒しのときも）
- [ ] ウェーブ番号が `wave.boss.every` の倍数のウェーブで、大物が1体湧く（MVP）
- [ ] 戦場の魔物が 0 で予定が残っていたら、前の湧きから `spawn.pullForward.minGap` 秒で次の組が湧く（予定の時刻を待たない）
- [ ] 湧きの予定を全部出し終えたら、そのウェーブではもう新しい魔物は湧かない
- [ ] 画面の魔物が `limit.monster.max` に達したら、それ以上湧かず、数が減ったら残りの予定が湧く
- [ ] 同じシード・同じウェーブ番号なら、湧く型・方向・時刻（湧きの時計）の並びが毎回同じ
- [ ] 塔が壊れたあとに魔物が倒れても、コインと名声は増えない
- [ ] 画面の外の魔物には、タップ攻撃が当たらない
