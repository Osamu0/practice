# プロト q123：1つの戦場で問い1〜3を切り替えて遊ぶ

捨てる前提のプロト（`02_プリプロ/計画.md` M2）。問いは `02_プリプロ/デザインの柱.md` の3つ。
値は `03_仕様/パラメータ表.csv` をそのまま読む（ビルドのときに中に入る。CSV を直したら作り直す）。CSV に無い、プロトだけの値は `src/core/proto.ts` の先頭にまとめた。

## 起動

```
cd ゲーム/packdefense/04_プロト/q123_戦場
npm install
npm run dev        # 手で触る。http://localhost:5173/
npm run build      # dist/ に作る（相対の住所なので、どこに置いても開ける）
npm run preview    # dist/ を http://localhost:4173/ で開く
npm test           # 計算の芯（Node）
npm run e2e        # 画面の確かめ（build のあとに。Playwright、iPhone のまね3つ。screenshots/ に撮る）
npm run typecheck
npm run calib      # 遅い／速い自動の指で、序盤の圧・開封のコスト・ショップの目安を出す（数分）
```

### 同じ Wi-Fi の iPhone で開く
1. パソコンで `npm run dev`（`--host` つき）。出てくる `Network: http://192.168.x.x:5173/` を見る
2. iPhone をパソコンと同じ Wi-Fi につなぎ、Safari でその住所を開く
3. 「共有」→「ホーム画面に追加」すると、上下のバーのない大きさ（390×844 など）で遊べる（Safari のままだと縦が短い。両方試すとよい）
- パソコンの防火壁（ファイアウォール）が 5173 を止めていたら開けない。そのときはパソコン側で許す
- http なので、音の手当てや保存のふるまいが https と違うことがある（実機未確認）

## 遊び方
はじめの画面の「タップで始める」。戦場を押さえると、指の少し上に輪が出て、輪の中の魔物とパックを攻撃する（押さえ続ける。連打は要らない）。右上の Ⅱ で一時停止 → つまみ・記録・やり直し。

| 遊び方 | 中身 | 終わり |
|---|---|---|
| Q1 第1ウェーブ | はじめのランの第1ウェーブだけ。指だけ（英雄・自動なし）。方向は東→東西→四方 | 生き延びる／塔が壊れる → Q1 の結果の板（もう一度） |
| Q2 第2〜4ウェーブ | 第1のショップで見習いのパックを2つ買った状態から。第2〜4、ショップ2回 | 第4を生き延びる／塔が壊れる → Q2 の結果の板 |
| Q3 ラン | 第1から塔が壊れるまで。強化を3つ買った状態（指・英雄・塔 各1段）から。HUD に経過時間。10分で知らせる（止めない） | 結果（名声）→ 強化画面（自動化・指・英雄・塔）→ ランに出る |

### 目安（`npm run calib`、8シード。自動の指の数で、人の目安ではない）
遅い指＝見直し 0.4秒ごと・指の速さ 900px/秒。速い指＝毎歩、瞬時に合わせる。

| 第1ウェーブ | 遅い指の塔の傷（傷を受けた数） | 速い指 | 秒（遅い指） | 同時の魔物の最大 |
|---|---|---|---|---|
| CSV のまま（16・2・×1・前倒し入） | 0（0/8） | 0 | 21.3 | 2.0 |
| **やや強い**（28・3・×1.5・前倒し切） | **9.0（7/8）** | 0 | 34.3 | 6.1 |
| 強い（32・4・×2・前倒し切） | 36.5（8/8） | 0 | 38.7 | 9.0 |

Q2（第2〜4、遅い指）：CSV の圧ではどの組み合わせでもパックを無視して塔の傷 0.4 と、開けないことの損が出ない。「やや強い・B・×2・山に合わせる・S1b・群れ第2」で、開ける指は塔の傷 5.3、パックを無視する指は 21.3（開けるまで平均 1.5秒、呪文の空振り 0）。ただし「やや強い」の上書きは全ウェーブにかかり、群れ第4のままだと遅い指は第2〜4で 4/8 壊れる（群れを早めると slime が減って軽くなる）。
ショップ（第1〜4のショップで見習いを買えた数）：CSV 2.0／0.9／0.9／1.8、最初15・×0.7 で 3.0／2.6／1.8／1.8、最初25・×0.5 で 3.0／2.6／2.6／2.6。

## 記録（プレイテストの材料）
一時停止 → 記録（またはどの結果の板からでも）。「ひとこと」に感じたことを書くと記録に入る。「コピー」して貼る（だめなら長押しで選ぶ）、「ファイル」は iPhone では共有シート。
1ウェーブ1行：ウェーブ、秒、結果、押さえた回数と秒、指の当たり、空振り、**置き間違い**（＝一度も当たらなかった押さえ＋何にも当たらなかった呪文）、呪文（使った・取りやめ・あふれ）、パック（降った・開けた・持ち越し・**開けるまでの秒**）、**傷の割合（指・自動・英雄・呪文）**、塔の傷（北・東・南・西）。設定が変わるたびに設定の行が入る。Q3 はランの行（届いたウェーブ・分・名声）も。

## 中身（縦切りより小さい）
魔物3種（slime・wolf・swarm。fromWave は CSV）、英雄4役（剣士・弓使い・盾の騎士・槍兵。レア度3段）、呪文2種（火の玉・氷）、パック2種（見習い・鉄壁）、ショップ（パックを買うだけ）、結果と名声、強化画面4項目。大きさはアートディレクション 5.2・7.2（塔 56×96、パック 26×38、輪 28／当たり 34、置き場 68×90×2、押せる物 48 以上、主のボタン 56）。

## 仕様から外したところ
- 鉄壁のパックは最初から棚にある（本来は第8を生き延びてから）。レアの出始め（`unlock.rare.fromWave`）・不運よけ（`pack.pity.after`）・回復の呪文・ショップのパック以外の品・前と同じものを買う・図鑑・宝石・保存（ウェーブの始まりから戻る）・書き出しの保存の形は入れていない
- 呪文の顔ぶれは見習い＝火の玉3：氷1、鉄壁＝氷2：火の玉1（経済.md 4.1 を2種に縮めた）
- パックの枠の色（レア度）は中身のいちばん高いレア度。開封の演出の間もゲームは止めず、英雄はすぐ立つ
- 物はふつうのオブジェクトの配列（SoA にしていない）。`src/core` は DOM・時間・Math.random を使わない決まりは守っている
- 裏に回ったら一時停止して「タップで再開」。保存はつまみ・名声・記録だけ（ランの途中は残らない）
