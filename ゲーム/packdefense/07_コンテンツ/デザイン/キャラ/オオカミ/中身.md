# オオカミの中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、魔物 `wolf` の「中身」。形は `剣士/中身.md` にそろえ、魔物なので「振る舞いの印象」と「プレイヤーに覚えさせること（1つ）」を書いた。
もとにした資料：`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.4・4.1・5.2・5.4）、`03_仕様/機能仕様/魔物.md`（第3版）、`03_仕様/パラメータ表.md`・`パラメータ表.csv`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：「速いのが来た、先にこいつを」とプレイヤーの指を動かす魔物が、湧いた瞬間に形と動きで「速い」と読める中身を決める。

## 0. この文書で言う「オオカミ」

- 魔物の型 `wolf`（速い）。第3ウェーブから湧く（`monster.wolf.fromWave`。レアのパックと同じころ）

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 魔物（速い） | 魔物.md |
| 出るころ | 第3ウェーブから。はじめての「ふつうでない」魔物 | パラメータ表 |
| 進み方 | 塔へまっすぐ。**スライムの2倍の速さ**（東西なら2秒あまりで塔に着く） | パラメータ表 |

### 振る舞いの印象
**低く、速く、迷わない**。湧いたと思ったら、もう塔のそば。足音が軽い。

### プレイヤーに覚えさせること（1つ）
**「速いやつから先に倒す」**
ほかの魔物を押さえていても、オオカミが見えたら指をそちらへ。柱2「指は、いちばん危ないところへ」を、最初に体で覚えさせる魔物。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **魔物**（暗い体、黄色の目、ギザギザの影）
2. **速い**（横に長く低い体、前へ伸びた形、速い足の動き）
3. **弱いが、ほうっておけない**（細い体。硬そうなものを持たない）

## 2. 振る舞いの芯

| | |
|---|---|
| 振る舞いを3語 | **すばしこい**／**まっしぐら**／**せわしない** |
| 動く理由 | 群れの先を争って、いちばんに塔へ着きたい |
| 嫌がるもの | 足を止められること（盾の騎士の「遅くする」が効く、の図鑑の一言） |

### 遊びとのつながり
- **速い** ← いちばん乗りを争う
- **耐久が低い** ← 体が細く軽い。速さのために、身を守るものを持たない
- **遅くする攻撃がよく効く** ← 足を止められるのが嫌い（数値の決まりではなく、遅くする倍率は全員に同じ。図鑑の文で「盾の騎士と相性がよい」をほのめかすだけ）

### 出どころ（短く）
森の奥の、影の濃いところから出てくる灰色のオオカミ。ふつうのオオカミとちがい、目が黄色く光る。人里の犬や家畜とは関わりがない（暗い話にしない）。

## 3. 見た目に出すところ

ふつうの魔物の大きさ（28〜36）。横に長いので、高さは低め（スライムより低く、幅は少し広く）。

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **横に長く低い体、頭を低く前へ突き出す** | まっしぐら | 影の形の決め手（アート 3.4）。魔物の「前かがみ・横向きの線」（アート 3.1） |
| 2 | **とがった耳と、後ろへまっすぐ流れる尾** | 速い（尾が流れる） | 耳は2つ、とがり。尾は横向きの線で、速さの向きを見せる |
| 3 | **背中の毛のギザギザ**（3つほどの山） | 魔物の印 | 影のギザギザと合わせて、ふつうの動物でなく魔物に見せる |
| 4 | **黄色の光る目**（横向きでも1つは見える） | 魔物の印 | 必ず（アート 3.1） |
| 5 | **細い4本の脚**（走るコマで前後に大きく開く） | 軽い、速い | 脚が細すぎて小さな絵で消えるなら、脚は2本ずつ重ねた形でよい |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 歩く（走る） | 4コマを12コマ/秒（アート 5.4：速い魔物）。体がほとんど上下しない、すべるような走り | 速いのに体がぶれないと「迷わない」が出る |
| 湧く | 画面に入るとき、低く身をかがめて飛びこむ（1コマ） | あれば |
| 塔を攻撃 | 前足で塔を引っかく | |
| 倒れる | 横に転がって、黒い粒 | |

### 3.3 大きな絵でだけ
- 灰色のぼさぼさの毛並み、耳のふちのちぎれ（血は描かない）
- 黄色の目に、瞳孔は描かない（光だけ）
- 口は閉じ気味。牙は小さく1本のぞく程度（アート 4.1 の歯の色で小さく）
- 足もとの土ぼこり

### 3.4 色の決め
- 決まっている：灰 `#4E4A52`、影 `#38343C`、目 `#FFD84A`、縁 `#140E16`（アート 3.4・4.1）
- 使わない：明るい段の面、茶色（ふつうの動物の色に寄る。また英雄の革の色）

## 4. 図鑑の説明（魔物は話さない）

- 森の奥から来る、目の光るオオカミ。いちばん乗りを争って、まっすぐ塔へ駆ける。
- 速いが、体は細く、打たれ弱い。見えたら先に倒すこと。
- 足を止められるのが、何より嫌いらしい。

（推しは1行め＋2行め。2行めが「覚えさせること」）

## 5. 種の呼び名

| 用途 | 呼び名 |
|---|---|
| 図鑑・画面の表記 | **オオカミ** |
| ID | `wolf` |

「魔狼」などの造語にはしない（ふつうのファンタジーの言葉で）。

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 覚えさせることは「速いやつから先に」 | 速い魔物はこの1種だけ。柱2をいちばん早く体で覚えられる |
| 体がぶれないすべる走り | 「速い」を脚の速さで、「迷わない」を体の静けさで、同時に出せる |
| 茶色を使わない灰 | アート 3.4 の決め。ふつうの動物に見えすぎないため |
