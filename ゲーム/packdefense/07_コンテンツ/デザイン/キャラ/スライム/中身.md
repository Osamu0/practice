# スライムの中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、魔物 `slime` の「中身」。形は `剣士/中身.md` にそろえ、魔物なので「性格」の代わりに「振る舞いの印象」と「プレイヤーに覚えさせること（1つ）」を書いた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.4・4.1・4.2・5.2・5.4）、`03_仕様/機能仕様/魔物.md`（第3版）、`03_仕様/パラメータ表.md`・`パラメータ表.csv`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：プレイヤーが最初に指で倒す相手が、一目で「魔物だ、塔に来る、押さえれば倒れる」とわかる、いちばん基本の形を決める。

## 0. この文書で言う「スライム」

- 魔物の型 `slime`（ふつう。ほかの魔物の基準）。第1ウェーブから湧く（`monster.slime.fromWave`）
- 小さなスライムが固まって来る「群れ」（`swarm`）は別の型（`../群れ/中身.md`）。見た目は同じ種の小さいもの

## 1. 遊びでの役割（仕様の決めから。数値は書き写さない）

| 項目 | 決め | 出どころ |
|---|---|---|

### 振る舞いの印象
**のそのそ、まっすぐ、何も考えていない**。わき目もふらず塔へ這ってくる。怖くはないが、放っておくと塔をかじられる。

### プレイヤーに覚えさせること（1つ）
**「魔物は塔へまっすぐ来る。指で押さえれば倒れる」**
はじめのランの第1ウェーブで、この1体がゲームの約束をまるごと教える。だから形は**いちばんわかりやすく**、変わったところを足さない。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **魔物（敵）**（暗い体、黄色の光る目、ギザギザの暗い影、紋の輪がない）
2. **塔へ向かってくる**（目と体の傾きが、進む方向を向く）
3. **やわらかい、押せば倒れる**（しずくの形、硬いものを持たない）

## 2. 振る舞いの芯（性格の代わり）

| | |
|---|---|
| 振る舞いを3語 | **のろい**／**ひたむき**／**しつこい** |
| 動く理由（望みの代わり） | 塔の石の、湿った苔を食べたい（だから塔へまっすぐ） |
| 嫌がるもの（恐れの代わり） | 日の光が強くなること（遊びには出さない。図鑑の文だけ） |

### 遊びとのつながり
- **塔へまっすぐ** ← 塔の足もとの苔が好物（アート 4.1 の塔の足もとに苔がある。絵と話がつながる）
- **英雄を攻撃しない** ← 苔しか見ていない
- **倒すとコイン** ← 体の中に、どこかで飲みこんだコインが残っている（図鑑の文で一言。なぜ魔物からコインが出るかの、軽い答え）

### 出どころ（短く）
塔の四方の、森の湿った窪地から湧く。どこにでもいる、いちばんありふれた魔物。

## 3. 見た目に出すところ

ふつうの魔物の大きさ（スライム 32×28。アート 5.2）。上ほど大事。

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **半円のしずくの形、下のふちが波** | やわらかい、這う | 影の形の決め手（アート 3.4）。丸すぎると「かわいい」に寄るので、上をすこしとがらせた**しずく**にする（とがりは進む方向へ少し倒す） |
| 2 | **黄色の光る目を2つ**。目は体の前寄り（進む方向） | 塔しか見ていない | 必ず（アート 3.1）。目は白黒でいちばん明るい点。瞳は描かない（感情を読ませない） |
| 3 | **ギザギザのふちの暗い影**（輪なし） | 魔物の印 | 必ず（アート 3.1・4.2） |
| 4 | **体の中に、うっすら沈んだ丸い粒（コイン）1つ** | 倒すとコインが出る | 小さな絵で見えなくてよい（あれば）。見せるなら暗い真鍮色で小さく。コインの印の色 `#FFD24A` は使わない（落ちたコインと混ざる） |
| 5 | 照り（暗い赤の照り `#A54B53`）を体の左上に1つ | ぬめり | 明るい段（155以上）にしない（魔物は明るい面を持たない） |

### 3.2 動きで出す癖（コマ数はアートディレクション 5.4 の内で）

| 場面 | 癖 | メモ |
|---|---|---|
| 歩く | 下のふちの波が、後ろから前へ流れる（はねない）。4コマ | アート 2「はねる・つぶれて戻るを使わない」に合わせ、這う動きにする |
| 塔を攻撃 | 体を前に伸ばして、塔にべたりと張りつき、戻る | 「かじる」に見える |
| 倒れる | 崩れて広がり、黒い粒になって消え、コインが残る | アート 5.4 の4コマ |

### 3.3 大きな絵でだけ（図鑑の大きな絵）
- 体の中の、溶けかけた葉っぱや小石
- 体の表面の、苔の小さな切れはし
- ぬめった照りと、地面に残る濡れた跡
- 口はない（目だけ）。怖くしすぎない、かわいくもしすぎない

### 3.4 色の決め
- 決まっている：暗い赤 `#7A2A30`、影 `#561C22`、照り `#A54B53`、目 `#FFD84A`、縁 `#140E16`（アート 3.4・4.1）
- 使わない：明るい段の面、緑（苔の色を体の面に使うと地面に溶ける）、レア度の色

## 4. 図鑑の説明（魔物は話さない）

- 森の湿った窪地に湧く、どこにでもいる魔物。塔の石の苔が好物らしい。
- のろいが、まっすぐ塔へ来る。指で押さえれば、すぐにつぶれる。
- 体の中には、どこかで飲みこんだコインが残っていることがある。

（推しは1行め＋2行め。2行めが「覚えさせること」と同じ）

## 5. 種の呼び名

| 用途 | 呼び名 |
|---|---|
| 図鑑・画面の表記 | **スライム** |
| ID | `slime` |
| 英雄が話すとき | 剣士「あいつら」、弓使い「あれ」など、各英雄の呼び方の表のとおり。種の名で呼ぶときは「スライム」 |

一般的な種類の名前なので、固有の名前は付けない。特定の作品で知られたスライムの姿（目と口のある、上がとがった水色の玉など）は写さない。色は暗い赤、口なし、しずくは進む方向へ倒す、で離した。

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 覚えさせることは「まっすぐ来る、押さえれば倒れる」 | 最初の魔物なので、ゲームの約束そのものにした |
| 苔が好物、だから塔へ来る | 「なぜ英雄を無視して塔へ」に軽く答えるため。塔の足もとの苔（アートの絵）とつながる |
| 体の中のコイン | 「なぜ魔物からコイン」に軽く答えるため。読まなくても困らない |
| 歩きは這う（はねない） | アート 2 の動きの言葉 |

## 8. 気になっていること

- 魔物.md の演出の表は「倒れた：つぶれる→はじける」、英雄.md の「立つ：つぶれて戻る」とある。アートディレクション第2版は「つぶれて戻る動きは使わない」。どちらに合わせるかは art と仕様の担当の間の話で、この文書はアートディレクションに合わせて書いた
