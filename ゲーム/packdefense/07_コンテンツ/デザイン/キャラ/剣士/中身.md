# 剣士の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が `設計書.md`（visual_design.md 段階0）を書くための、剣士の「中身」。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（3.1・3.2・4.1・5.2）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/パック.md`（第3版）、`03_仕様/パラメータ表.md` 6章、`03_仕様/機能仕様/図鑑.md`、`02_プリプロ/スタイル見本/戦場_色.svg`。

**この仕事の目的**：プレイヤーがいちばん最初に、いちばん長く見る味方の英雄が、44px でも「この子が塔の前で踏ん張ってくれている」とわかり、図鑑で開くと少しだけ好きになれる、という中身を決める。

## 0. この文書で言う「剣士」

- 剣士は**役**（`role = sword`）。剣士の役の英雄は複数いる。縦切りの仮の顔ぶれでは `sword1`（コモン）と `sword2`（エピック）（パラメータ表.md 6章）
- この文書の剣士は **`sword1`（コモンの剣士）**。見習いのパック（`novice`）と鉄壁のパック（`iron`）のプールに入っていて、はじめのランから出る。スタイル見本に描かれた英雄はこの子にあたる
- `sword2`（エピックの剣士）は**別の人**として作る（下の「ほかの剣士との分け方」）

## 1. 遊びでの役割（仕様の決めから。数値は書き写さない）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 見習いのパック・鉄壁のパックのプール。コモン | パック.md、パラメータ表.md 6章 |
| 立つ場所 | パックを開けた場所に台座ごと立つ。そのランの終わりまで動かない。プレイヤーも動かせない | 英雄.md |
| 狙い | 射程 `hero.<id>.range` の内で**塔にいちばん近い**魔物 | 英雄.md |
| 攻撃 | 近い1体に、すぐ当たる一撃。`hero.<id>.interval` ごと。威力は `hero.<id>.dmg`（役の基準 `hero.base.sword.*` × `card.rarityPower`）× `hero.power` ほか | 英雄.md |
| 苦手 | **飛ぶ魔物に当たらない**（近い攻撃。`monster.bat.flying`） | 英雄.md、魔物.md |
| 倒されるか | 倒されない（仮決め）。魔物は塔だけを狙う | 英雄.md |
| 重なり | 同じ剣士がもう1枚出て `hero.sameMax` に達していれば、近くの同じ剣士に重なって強くなる（`hero.stack.dmgMul`）。上に小さな矢印 0.5 秒 | 英雄.md |
| 状態 | 立つ → 待つ（射程に魔物がいない）→ 構える → 攻撃（構え・当て・戻りの3コマ、0.3 秒）→ 待つ／構える | 英雄.md、アートディレクション 5.4 |
| 能力の例 | 2体に当たる、硬い魔物によく効く（個々の能力は `game-design-combat` が 04 のあと） | 英雄.md |

**遊びでの意味**：剣士は「塔の手前の最後の壁」。射程は短く、塔に張り付きかけた魔物を切る（`pack.drop.ring.min` の注記「塔の手前で張り付いた魔物に剣士が届く」）。空からの魔物には手が出ないので、プレイヤーの指か弓・槍の仲間が受け持つ。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方で、塔の前で踏ん張っている**（退かない、まっすぐ立つ）
2. **近くを切る**（剣が見える。射程が短いのが体つきから感じられる）
3. **まだ若い・最初の仲間**（見習い。これから強くなる余地）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **まっすぐ**／**負けず嫌い**／**ほがらか** |
| 望み | 一人前の剣士として、「うちの塔」を最後まで守りきること |
| 恐れ | 間に合わないこと。自分の目の前を抜けて、魔物が塔に届くこと |
| どう話すか | 短く言い切る。元気。強がるが、いやみはない。一人称「わたし」 |

### 遊びとのつながり（設定は遊びに出るものから）
- **塔にいちばん近い魔物から切る** ← 恐れが「間に合わないこと」だから。いちばん危ないやつから
- **立った場所から動かない** ← まっすぐ・負けず嫌い。「一度立ったら一歩も退かない」
- **飛ぶ魔物に当たらない** ← 剣が届かないのが悔しい（図鑑の文で一言だけ触れる。弱点の説明を兼ねる）
- **重なって強くなる** ← 負けず嫌い。「まだ振れる」と張り切る
- **コモン・見習い** ← まだ若い。装備がお下がり

### 短い身の上（遊びに出ないので短く）
塔のふもとの村の、石工の家の子。家は代々、塔の石を積み直してきたので、塔のことを「うちの塔」と呼ぶ。剣は村の自警団で習いはじめたばかり。兜は、昔塔の番兵だった母のお下がりで、まだ頭に大きい。
（暗い話は付けない。家族は元気。アートディレクションの「皮肉、ダークファンタジー」を使わない、に合わせた）

### 書かないこと（オーナーの決め）
- 台座を、話の中で駒・盤・ボードゲーム・人形として扱わない。台座は絵の描き方で、この子の設定には出てこない
- 英雄がなぜパックから出てくるかは、この文書では説明しない（世界全体の決めなので未決 U3 に回した）

## 3. 見た目に出すところ

表示は高さ約 44px（台座と飾りを入れて）、体の幅 18、頭の直径 16、台座 30×12、2〜2.5頭身（アートディレクション 5.2）。この節で「3.1」「3.2」「5.4」と番号だけ書いたものは、アートディレクションの節。**44px で読めるもの**と**大きな絵でだけ**に分けた。上ほど大事。

### 3.1 44px で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **斜め上を向いた剣**。体の割に少し長い片手剣 | 背伸び（負けず嫌い）。剣だけは自分で買った一本 | 影の形の決め手（3.2）。必ず。長さは槍兵の槍より短く（槍兵が「いちばん背の高い縦の線」） |
| 2 | **王国の青の上着** | 自警団の支給の上着 | 差し色 `#2F6FD6`（3.2）。差し色は役ごとに1色まで |
| 3 | **頭に大きすぎるお下がりの兜**。つばが目の上ぎりぎり、少し傾いている | 母のお下がり。「見習い」がひと目でわかる | 推す。丸い頭（3.1）を崩さない丸い兜にする。目（小さな暗い点）は兜のつばの下に残す。盾の騎士の兜と形を分ける（騎士は顔を覆う・四角、こちらは丸くて顔が出る、など） |
| 4 | **足を肩幅に開いて踏ん張る立ち方**、胸を張る | まっすぐ・退かない | 英雄は「まっすぐ立つ」（3.1）。前かがみにしない（前かがみは魔物の形の言葉） |
| 5 | **上着に当て布が1枚**（ひざか肩に四角） | 服はつぎはぎだが、きれいに洗ってある。剣はぴかぴか（手入れの具合の差） | 44px で出せるかは 04 の実寸で見る。出せなければ大きな絵へ回す。当て布の色にレア度の色（特にレア `#4FA3FF`）と魔物の色を使わない。生成りか薄い茶を推す |

### 3.2 動きで出す癖（コマ数はアートディレクション 5.4 の内で）

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ（開封のあと） | とんと置かれたあと、ずれた兜を片手で押し上げる | 立つ演出（`hero.spawn.fxTime`）の内に収めるか、立った直後の1回だけ。足すかは `game-anim-animator` |
| 待つ | 1〜2px はねる。兜がほんの少し遅れてはねる | 立っているの2コマ（5.4）の範囲 |
| 重なった | 剣を一度高く上げる（矢印 0.5 秒と同じ時） | 「まだ振れる！」 |
| 構え・当て | 大きく横に払う一振り | 近い1体に当たる、の見た目 |

**提案（入れるかは art・design）**：「待つ」（射程に魔物がいない）とき、剣先を地面に下ろして柄に両手を置く姿にすると、「この方向は今は空いている」がプレイヤーに読める。ただし剣が上を向く影の形の決め手（3.2）が崩れるので、影の形を保てる案があるときだけ。

### 3.3 大きな絵でだけ（図鑑・開封の大きな絵、設定画の注記）
- 手の豆、頬の小さなすり傷（血は描かない）
- 兜の内側に刻まれた母の名前（読める字にしない。模様で）
- 腰の小さな布袋。中に石工のノミが1本（家の道具をお守りに）
- 剣の柄に巻いた青い布（自分で巻き直している）
- 表情：口を結んで笑う。目はつり目にしない（怒って見えない、ほがらか）
- 髪：兜からはみ出る短い髪。色は茶か黒茶を推す（赤・紫は魔物の側の色に寄るので避ける）

### 3.4 色の決め
- 決まっている：上着の青 `#2F6FD6`、台座の白とふち、縁取り `#1B2233`、金属 `#E6E9EF`・`#D9DEE6`、金 `#E8B730`（飾りに少しだけ）
- 使わない：魔物の暗い赤・紫・灰を大きな面に使わない、レア度の色を服の面に使わない（パックや隠れたパックの印と混ざる）、危険のだいだい `#FF5A1F`
- 肌の色はアートディレクションに1つだけ（`#F3D2B3`）。ほかの肌色は 07 で足すことになっている（アートディレクション 未決 #11）。この子の肌は既定のままでよい。英雄の顔ぶれ全体で肌の色を散らすかは art で

### 3.5 ほかの剣士との分け方（`sword2` などを作るときに）
同じ役なので、斜めの剣と青は共通（3.2 の決め）。そのうえで、`sword1` は「若い・お下がり・踏ん張る」、エピックの剣士は「慣れた・自分に合った装備・落ち着いた立ち方」と、**持ち物の合い方**と**立ち方**で分けるのを推す。顔ぶれの表ができたら、ここに書き足す。

## 4. 口調サンプル（戦場では声も字も出さない。図鑑と開封の一言の用）

### 図鑑の説明（1〜2行。地の文）
- 塔のふもとの、石工の家の子。お下がりの兜は、まだ頭に大きい。
- 塔にいちばん近い魔物から切る。空を飛ぶ相手には剣が届かず、いつも悔しそうだ。
- 一度立った場所からは、一歩も退かない。

（図鑑の板は「説明1〜2行」（図鑑.md）。上の3行から2行を選んで使う。推しは1行め＋2行め。2行めで狙い方と苦手が読めるので、読めば遊びに効き、読まなくても困らない）

### 開封の一言（本人の言葉。出すかどうかは未決 U1）
- 「来たよ！ ここから先は通さない。」
- 「うちの塔に、指一本ふれさせないから。」
- 「空のやつは……任せた！ 地面のは全部わたしが切る。」
- 重なったとき：「まだまだ振れる！」
- 初めて出たとき：「見習いだけど、腕はたしかだよ。」

### 呼び方の表

| 相手 | 呼び方 |
|---|---|
| 自分 | わたし |
| 塔 | うちの塔／塔 |
| 魔物 | あいつら／魔物 |
| 仲間の英雄 | 役で呼ぶ（「弓の人」「騎士さん」）。名前が決まったら名前に「さん」 |
| プレイヤー | 呼びかけない（プレイヤーがこの世界の誰なのかを決めていないため。未決 U2） |
| 母 | 母さん |

## 5. 名前

条件：ふつうのファンタジーで通る、カタカナ3〜4文字で図鑑の枠に収まる、iPhone の小さな字で読み違えにくい、既存の作品で知られたキャラの名前と重ならない、実在の人で有名な名前と重ならない。

| 案 | 読みの感じ | よいところ | 気になるところ |
|---|---|---|---|
| **ミルテ（推す）** | 明るく、やわらかい | 3文字で短い。「ミ」で始まる英雄の名前とかぶりにくい。ほがらかさと、少しの素朴さ（村の子）が出る | 洋の植物の名（ギンバイカ）の響きに近い。悪い意味はない |
| ネラ | 短く、きりっとする | 2文字でいちばん短い。負けず嫌いの感じ | 短すぎて、図鑑の一覧でほかの名前に埋もれやすい |
| ユッタ | 元気、素朴 | 村の子らしさがいちばん出る | 小さい「ッ」が 12px の字で読みにくいおそれ |

**推すのはミルテ**。呼びやすさと、44px の主役らしい明るさがいちばん合う。
ほかの作品・実在の人と重ならないかは、この担当の記憶で避けたが、調べてはいない。`game-design-creative-director` の確かめで重なりが見つかったら、ネラにする。

避けた案（記録のため）：有名なゲーム・アニメ・児童書の剣の主人公や仲間の名前と重なるもの、実在の人で有名な名前と重なるもの、宗教の名前に近いもの。

## 6. 決めたことと理由（この担当の持ち場の中）

| 決めたこと | 理由 |
|---|---|
| この剣士は `sword1`（コモン）とした | はじめのランから出る剣士はこの子で、スタイル見本の英雄にあたる |
| 少女、16歳くらいとした | 剣の主人公は少年がいちばんありがち（visual_design 段階1「最初に浮かぶ案はありがち」）。お下がりの大きな兜とも合う。44px では性別はほぼ出ないので、絵の重さは変わらない。少年に変えるなら、一人称を「ぼく」にすれば口調サンプルはほぼそのまま使える |
| 「塔にいちばん近い魔物を狙う」「動かない」「飛ぶ魔物に届かない」を、性格と恐れから説明した | 遊びに出る決まりを、設定で覚えやすくするため。図鑑の文を読めば狙い方と苦手がわかる |
| お下がりの大きい兜を推した | 「見習い」がいちばん大きな形で出せる（44px で見える）。顔は出るので図鑑の大きな絵でも表情が見える |
| 暗い身の上を付けない | アートディレクションの雰囲気（王道・明るい、ダークファンタジーにしない） |

## 8. 気になっていること

- **剣士は「主人公」として必ず最初に出るわけではない**。はじめに必ず出るのは「最初のパックの1枚めは英雄」（`intro.firstPackHero`）だけで、見習いのパックのコモンには剣士・弓使い・盾の騎士がいる（経済.md 4.1、パラメータ表.md 6章）。最初の仲間が弓使いのこともある。剣士を作品の顔（キービジュアル、アイコン、スタイル見本）として扱うなら、提案 P1 を参照
- 設定の正本 `07_コンテンツ/シナリオ/設定.md` はまだない。この文書の世界の決め（塔のふもとの村、自警団、王国の青）は、正本ができたらそちらに移し、ここからは参照にする

## 9. 提案（頼まれていないが要るもの。入れていない）

- **P1**：最初に開けるパックの1枚めを「剣士 `sword1`」に決めると、作品の顔と最初の仲間が一致する（最初に覚えた顔が、そのまま図鑑の1番め・キービジュアルの主役になる）。変えるのは仕様（`はじめの流れと要素の解放.md`、`intro.firstPackHero` のまわり）なので、`game-design-systems`・`game-spec-writer` の判断
- **P2**：`sword2`（エピックの剣士）を、この子の自警団の師匠にすると、図鑑で2人を並べたときに「この子がいつかああなる」が見える。関係は図鑑の説明の1行だけで足りる
- **P3**：英雄の顔ぶれ（12〜16人）の表ができたら、全員の「性格3語・望み・44px の決め手」を1枚に並べた表を作り、似た性格・似た持ち物がかぶらないかを先に見る（並べ図の前の、中身の並べ図）
