# 剣士 `sword1`（コモン）設計書（visual_design 段階0）

game-art-concept、2026-11-27（第1版）。
もとにした資料：`07_コンテンツ/デザイン/キャラ/剣士/中身.md`（game-story-lore 第1版）、`02_プリプロ/アートディレクション.md`（2・3.1・3.2・4.1・4.2・5.2・5.3・5.4・10）、`02_プリプロ/スタイル見本/戦場_色.svg`、`進行表.md`、`開発チーム.md`。

**このデザインの目的（1行）**：プレイヤーがいちばん長く見る味方が、44px で「塔の前で踏ん張ってくれている見習い」と読めて、図鑑で開いたとき少し好きになれる姿にする。

## 1. 遊びでの役割

| 項目 | 中身 |
|---|---|
| 立場 | 味方の英雄。役は剣士（`role = sword`）、コモン。見習いのパック・鉄壁のパックから出る |
| 何をするか | 射程の内で塔にいちばん近い魔物を、近くで1体ずつ切る。飛ぶ魔物には当たらない |
| どこに出るか | パックを開けた場所に台座ごと立ち、ランの終わりまで動かない。塔のまわり（塔の手前の最後の壁） |
| 状態 | 立つ（落ちる・つぶれる・戻る 3コマ）→ 待つ（2コマ、1〜2px はねる）→ 攻撃（構え・当て・戻り 3コマ 0.3秒）。重なると上に矢印 0.5秒 |
| 同じ画面に並ぶもの | 塔（56×96）、ほかの英雄（同じ台座、44px）、魔物（28〜36px、群れ・コウモリ 16〜20px）、パック 26×38、攻撃の輪 半径28、ダメージの数 |

## 2. プレイヤーに一目で伝えたいこと（3つ）

1. **味方で、塔の前で踏ん張っている**：足を開いて立つ。前かがみにしない（前かがみは魔物の形の言葉）
2. **近くを切る**：剣が体から離れて見える（影で剣が消えない）。剣は槍より短い
3. **まだ若い見習い**：持ち物が体に合っていない（お下がり）。強そうに見せすぎない（エピックの剣士 `sword2` と分けるため）

この3つで、ラフを選ぶ（段階2）。好みでは選ばない。

## 3. 中身（中身.md から）

- 性格3語：**まっすぐ**／**負けず嫌い**／**ほがらか**
- 望み：一人前の剣士として「うちの塔」を最後まで守りきる。恐れ：間に合わないこと
- 見た目に出すところ（44px で、優先順）：①斜め上の剣（体の割に少し長い片手剣）②王国の青の上着 ③頭に大きすぎるお下がりの兜（つばが目の上、少し傾く。丸い。顔が出る）④足を肩幅に開いて踏ん張る、胸を張る ⑤上着の当て布1枚（見えなければ大きな絵へ）
- 大きな絵でだけ：手の豆、頬のすり傷、兜の内側の模様、腰の布袋とノミ、柄に巻いた青い布、口を結んで笑う顔、兜からはみ出る短い茶の髪
- 性別・年・名前：オーナーの未決（中身.md U4・U5）。仮に少女・16歳くらい・ミルテで進める。**44px では性別に頼らない**（長い髪、スカートの形、胸の形で性別を見せない。顔と動きの癖で人柄を見せる）

## 4. 表示の条件

| 項目 | 値 |
|---|---|
| 大きさ | 高さ 約44px（台座の下の端から兜の上まで。剣の先は兜より少し上に出てよいが、槍兵の槍より低く） |
| 体 | 体の幅 18 前後、頭の直径 16（15〜16）、2〜2.5頭身 |
| 台座 | 30×12 の白い楕円 `#FFFFFF`＋青いふち `#2F6FD6` 2.5px（必ず） |
| 縁取り | `#1B2233`、2〜2.5px。中の線 1.3〜1.5px |
| カメラ | 地面は上から少し斜め、キャラは正面向きで立てる。光は左上から1つ、影は右下 |
| 後ろの色 | 草地 `#A9CB8C`（白黒 191）、市松 `#A2C585`、丘 `#8DB06F`、道 `#DCCBA4`（204） |
| 端末 | iPhone 縦 390×844 論理px。画素の倍率 2〜3 |
| 描き方 | Canvas の基本図形（四角、円、楕円、直線、2次・3次の曲線、円弧）だけ。部品（頭・兜・胴・腕と剣・足・台座）に分けて、位置と角度でコマを作れる形 |

## 5. 形の言葉をこのデザインでどう使うか

| 決め（アートディレクション 3.1） | このデザインでの使い方 |
|---|---|
| 丸い頭 | 兜も丸く（どんぶり・半球）。四角い兜は盾の騎士の言葉なので使わない |
| まっすぐ立つ | 胸を張り、足を開いて台座に踏ん張る。背中を丸めない |
| 上向きの線 | 剣を斜め上（水平から50〜70度）。剣が頭や胴の影に隠れない向きにする |
| 白い台座＋青いふち | 変えない |
| 目は小さな暗い点 | 兜のつばの下に、点の目2つ。口は大きな絵と4倍でだけ見える細い線 |

## 6. 色

- 決まっている：上着 `#2F6FD6`、台座 `#FFFFFF`＋ふち `#2F6FD6`、縁 `#1B2233`、肌 `#F3D2B3`、金属 `#E6E9EF`・`#D9DEE6`、金 `#E8B730`（帯・つば・つばの飾りに少しだけ）
- 新しく足す必要がある色（影の段、ズボン、靴、髪、当て布）：段階3で案を出す（`絞り込み.md` の色の表）。決めるのは `game-art-director`
- 使わない色：魔物の暗い赤 `#A8323E`・紫 `#7A5A8C`/`#6B3FA0`・灰 `#5E5A66` を大きな面に、レア度の色（特にレア `#4FA3FF`、エピック `#8A3FE0`、レジェンド `#FFC23A`）を服の面に、危険 `#FF5A1F`、ほかの役の差し色（弓の緑 `#3FA34D`、魔法の `#4B5BD6`、槍の赤茶 `#B5653A`、斥候の深緑 `#2E7A5E`）を大きな面に
- 白黒で：服（青 105）が魔物（76〜100）に近いので、台座（255）と兜・顔（215〜233）の明るい点で味方と読ませる（4.2 の決め）。兜が大きいほど明るい点が大きくなり、白黒で有利

## 7. 似せてはいけないもの

- 既存作『Booster Pack Heroes』（この担当は画面を見ていない。最終の確かめは画面を見られる人。中身.md U7、アートディレクション 未決 #1）
- よく知られたゲームの剣の主人公の型：とがった髪の少年＋大剣、緑の帽子と服、赤いマント、長いスカーフ、頭の羽根飾り、勝ちどきで剣を高く掲げる立ち姿。ラフでは「ありがち」の印を付けて外す
- 同じゲームのほかの英雄：盾の騎士（四角い兜・大きな盾）、槍兵（いちばん背の高い縦の線）、斥候（フードのとがり、低い姿勢）。剣士はこれらと影で分ける
- エピックの剣士 `sword2`：同じ斜めの剣と青。`sword1` は「体に合わない持ち物・踏ん張る立ち方」、`sword2` は「体に合った装備・落ち着いた立ち方」で分ける（中身.md 3.5）

## 8. 見るときの問い（段階2・3・6 で使う）

1. 1倍で、影だけで「剣を持った味方」と言えるか。剣が体から離れて見えるか
2. 1倍で、「見習い（若い・お下がり）」が何か1つの形で見えるか
3. 白黒で、台座・兜・顔の明るい点が、魔物の暗い塊と分かれるか
4. 草地と道の両方の上で、溶けないか
5. 盾の騎士・槍兵・斥候の影と取り違えないか（並べ図は段階4）
6. Canvas の基本図形だけで描けるか、部品に分けて動かせるか
