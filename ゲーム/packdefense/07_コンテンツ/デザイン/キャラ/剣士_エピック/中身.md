# 剣士（エピック）の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、`sword2` の「中身」。形は `剣士/中身.md` にそろえた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.2・3.3・4.1）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/パック.md`、`03_仕様/パラメータ表.md` 6章、`../剣士/中身.md`（3.5、提案 P2）、`../剣士/監修_段階2.md`（P4：`sword2` の仮）、`../剣士/絞り込み.md`（ラフ1）、`../剣士/監修_段階7.md`（「sword2 への申し送り」）。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：エピックを引いたときに「すごいのが来た」と一目でわかり、コモンの剣士と影だけで別人に見え、図鑑で並べると「あの見習いがいつかああなる」と見える中身を決める。

## 0. この文書で言う「剣士（エピック）」

- 役は剣士（`role = sword`）。この文書は **`sword2`（エピックの剣士）**。見習いのパックと鉄壁のパックのプールに入る
- 同じ役の `sword1`（コモン）は `../剣士/中身.md`。**`sword1` の自警団の師匠**とする（剣士の中身 提案 P2 を採った）
- 監修の申し送り（段階7）：「`sword2` の仮は、影だけ・1倍で `sword1` とつばの幅の差しかなく近すぎる。影で分かれる大きな部品を1つ入れる」。→ **長いマント**を一目で伝えたいことに入れた（3.1 の1）

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 見習い・鉄壁のパックのプール。エピック（縦切りでいちばん高いレア度の英雄） | パラメータ表.md 6章 |
| 狙い | 射程の内で塔にいちばん近い魔物 | 英雄.md |
| 攻撃 | 近い1体に、すぐ当たる一撃。威力は役の基準 × エピックの倍率 | 英雄.md |
| 苦手 | 近い攻撃なので、飛ぶ魔物に当たらない | 英雄.md |
| 能力の例 | 2体に当たる、硬い魔物によく効く（04 のあと） | 英雄.md |

**遊びでの意味**：`sword1` と同じ「塔の手前の最後の壁」を、ずっと厚く受け持つ。縦切りで紫の枠が降ってくる、いちばんの当たり。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方の剣士で、格上**（同じ斜めの剣と藍。そのうえで、肩から裾まで広がる長いマント）
2. **落ち着いて、揺るがない**（足をそろえた立ち方、体に合った装備）
3. **見習いの剣士の、先にいる人**（同じ藍、同じ剣の角度。兜は頭に合っている）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **落ち着いている**／**厳しい**／**不器用にやさしい** |
| 望み | 自警団の若い者を一人も欠けさせず、次の守り手に育てて渡すこと |
| 恐れ | 自分が教えた子が、自分より先に倒れること |
| どう話すか | 低く、短く、命令の形。ほめるのが下手で、ほめるときは目をそらす。一人称「おれ」 |

### 遊びとのつながり
- **塔にいちばん近い魔物から切る** ← `sword1` と同じ。この教えは団長から来ている（「いちばん危ないやつから」）
- **立った場所から動かない** ← 「持ち場を離れるな」が口ぐせ
- **飛ぶ魔物に当たらない** ← 剣士はそういうもの、と割り切っている（`sword1` は悔しがる。差が出る）
- **エピック** ← もと王国の騎士。いまは村の自警団の団長
- **重なって強くなる** ← 黙って、もう一段構えが低くなる

### 短い身の上
もと王国の騎士団の騎士。けがで前に出る役を退いてから、塔のふもとの村に移り、自警団を一から作った。団員はほとんどが十代の子ども。`sword1` には剣の握り方から教えた。
騎士団にいたころのマントを、いまも着ている。裾はすり切れているが、つくろいは自分でする。
（けがは古いもので、いまは困っていない。暗い話にはしない）

### 書かないこと
- 英雄がなぜパックから出てくるか（剣士の中身 U3）
- 台座・紋の輪を駒や盤として扱う言い方
- けがの中身（どこを、どうして）。書かなくても足りる

## 3. 見た目に出すところ

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **両肩から足もとまで落ちる、長い藍のマント**。裾が広がって左右対称の台形の影になる。裾のふちに真鍮の細い線 | 騎士団のころのマント | **影で `sword1` と分かれる決め手**（監修 段階7 の申し送り）。マントは体の**後ろ**に広がる（盾の騎士の盾は体の**前**）。裾の幅は盾の騎士の盾より狭く（盾が「いちばん横に広い」のを守る） |
| 2 | **斜め上を向いた剣**。`sword1` と同じ角度（水平から画面の右上へ60°） | 同じ教え。同じ剣の持ち方 | 役の影の決め手（アート 3.3）。剣の先は槍兵の槍の先より低く（剣士の監修 段階8） |
| 3 | **頭に合った兜**。鉢が小さく、つばが狭い。頬当てつき | 体に合った自分の装備 | `sword1` の「大きすぎる丸い鉢＋広いつば」と分かれる（監修 段階2 P4）。顔は出す（目の暗い点を残す） |
| 4 | **足をそろえた、落ち着いた立ち方**。空いた手は体の横に下ろす | 揺るがない | `sword1` のがに股・腰に手と分ける。腰に手は `sword1` の印なので使わない |
| 5 | **両肩そろった鋼の肩当てと胸当て**、腰の帯に真鍮の留め金 | 本職の騎士の装備 | 金・真鍮は留め金とマントのふちだけ（目の流れを散らさない） |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ | 降り立って、マントの裾が一拍おくれて落ちる | マントの遅れは2コマで足りる。足すかは `game-anim-animator` |
| 待つ | ほとんど動かない。マントの裾だけがかすかにゆれる | |
| 構え・当て | 小さな構えから、短く鋭い一振り（`sword1` の大きな払いと対比） | 当てのコマで1コマ止まる（アート 5.4） |
| 重なった | 剣を一度胸の前に立てる（騎士の礼に近いが、宗教の印は作らない） | |

### 3.3 大きな絵でだけ
- 口ひげはなし。灰色まじりの短い髪、こめかみが白い
- 目の下の深いしわと、あごの古い傷あと（血は描かない）
- マントの裾のつくろいの跡（色の少し違う糸）
- 胸当てに、王国の紋の刻印（騎士団のころのもの。読める字にしない）
- 剣の柄に、`sword1` と同じ巻き方の藍の布（`sword1` が団長のまねをしている）
- 表情：口を一文字に結ぶ。目はまっすぐ前

### 3.4 色の決め
- 差し色：藍（マント・上着）。`sword1` と同じ藍を使う。マントの面が大きいので、藍の面がいちばん大きい剣士になる
- 鋼は兜・肩当て・胸当て・剣。真鍮は留め金とマントのふち
- エピックの紫 `#8A3FE0` は服にも装備にも使わない（パックの印と混ざる）。格上であることは**マントと装備のそろい方**で出す
- 髪：灰色まじりの茶
- 肌：既定（顔ぶれ.md 3章）

### 3.5 `sword1` との分け方（剣士の中身 3.5 への答え）

| | `sword1`（コモン） | `sword2`（この人） |
|---|---|---|
| 影でいちばん効く差 | 大きすぎる丸い兜（上に大きい） | 長いマント（下に広い台形） |
| 兜 | 大きすぎる、つばが広い、傾く | 頭に合う、つばが狭い、まっすぐ |
| 立ち方 | がに股、腰に手、胸を張る | 足をそろえる、手を下ろす |
| 振り方 | 大きく横に払う | 小さく鋭く |
| 共通 | 斜め上の剣（同じ角度）、藍、柄の藍の布 | 同じ |

## 4. 口調サンプル

### 図鑑の説明（1〜2行）
- 村の自警団の団長。もとは王国の騎士だった。
- 塔にいちばん近い魔物から切れ、と弟子に教えた本人。空の相手は仲間に任せる。
- すり切れたマントは、騎士団のころのもの。

（推しは1行め＋2行め。2行めで狙い方と苦手が読める。図鑑で `sword1` の2行めと並べると、同じ教えだとわかる）

### 開封の一言（出すかは未決）
- 「持ち場を離れるな。おれもここにいる。」
- 「いちばん近いやつから切れ。教えたとおりだ。」
- 「空は任せる。地面は通さん。」
- 「……悪くない構えになったな。」（`sword1` がいるとき。出せる仕組みがあれば。目をそらして言う）
- 重なったとき：「まだだ。」
- 初めて出たとき：「自警団の団長だ。塔は守る。」

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| `sword1` の師匠（自警団の団長） | 剣士の中身 P2 を採った。図鑑で2人を並べたときに「同じ剣の角度、同じ藍、同じ教え」で師弟がわかる。関係は図鑑の説明の2行めだけで出る |
| 長いマントを影の決め手に | 監修 段階7 の申し送り。絞り込み.md でラフ1（マント）が「`sword2` 向き」とされていた。上に大きい `sword1` と、下に広い `sword2` で、影だけで分かれる |
| マントは両肩から、左右対称 | 槍兵の片方だけの肩当て（左右非対称）と印をかぶらせないため。どっしりした台形は「落ち着いている」とも合う |
| 男性、48歳くらい（案） | 10体の割り振り（顔ぶれ.md 2章）。`sword1` の母を師匠にする案は、剣士の中身で「母はもと番兵」と決めているので取らなかった（親子の師弟は話が重くなる） |
| 一人称「おれ」 | 6人の一人称を全部ちがうものにした（顔ぶれ.md 4章） |
| もと騎士、けがで退いた | 「なぜ強いのに村にいるのか」に1行で答えるため。けがの中身は書かない |

## 8. 気になっていること

- マントは「強い主人公・騎士」のいちばんありがちな持ち物（剣士の設計書のありがちの例に「赤いマント」）。この人は**藍で、裾がすり切れて、つくろってある**ことで、ありがちから少しずらした。片方の肩からだけのマントも考えたが、槍兵の「片方だけの肩当て」と「左右非対称」の印がかぶるので、両肩からの左右対称にした（非対称は槍兵に残す。顔ぶれ.md 5章）。ずらしが小さいのは承知のうえで、影の強さを優先した
- 剣の長さは `sword1` と同じを推す（剣の先の高さの決めを崩さないため）。「エピックだから大きな剣」にはしない
