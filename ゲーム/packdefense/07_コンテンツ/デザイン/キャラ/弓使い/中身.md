# 弓使い（コモン）の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、`archer1` の「中身」。形は `剣士/中身.md` にそろえた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.2・3.3・4.1・4.2）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/パック.md`、`03_仕様/パラメータ表.md` 6章・`パラメータ表.csv`、`07_コンテンツ/デザイン/キャラ/剣士/中身.md`。
10体に共通の前提（表示の大きさ、頭身の食い違い、色の禁止、性別・年の割り振り）は `../顔ぶれ.md` の 0章。

**この仕事の目的**：遠くの魔物を先に落としてくれる味方が、戦場の小さな絵でも「弓の子だ」とわかり、図鑑で読むと「怖がりだから遠くから撃つんだ」と腑に落ちる中身を決める。

## 0. この文書で言う「弓使い」

- 弓使いは**役**（`role = archer`）。縦切りでは `archer1`（コモン）と `archer2`（レア）の2人（パラメータ表.md 6章）
- この文書は **`archer1`（コモンの弓使い）**。見習いのパック（`novice`）のプールに入る。はじめのランから出る（最初の仲間がこの子のこともある）
- `archer2` は別の人（`../弓使い_レア/中身.md`）。分け方は 3.5

## 1. 遊びでの役割（仕様の決めから。数値は書き写さない）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 見習いのパックのプール。コモン | パック.md、パラメータ表.md 6章 |
| 立つ場所 | パックを開けた場所に立ち、ランの終わりまで動かない | 英雄.md |
| 狙い | 射程の内で**塔にいちばん近い**魔物 | 英雄.md |
| 攻撃 | 遠い1体へ矢（弾）。`hero.<id>.projSpeed` で飛ぶ。射程は剣士のおよそ2.5倍（`hero.base.archer.range`） | 英雄.md、パラメータ表 |
| 得意 | **飛ぶ魔物にも当たる**（剣士・盾の騎士が手を出せない相手） | 英雄.md、魔物.md |
| 能力の例 | 飛ぶ魔物によく効く、速く撃つ（個々は `game-design-combat` が 04 のあと） | 英雄.md |
| 倒されるか | 倒されない（仮決め） | 英雄.md |

**遊びでの意味**：弓使いは「遠くの見張り」。東西の道ならほぼ全部に届き、魔物が塔に着く前に数を減らす。剣士が塔の手前の最後の壁なら、この子はその前の一枚。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方で、遠くを撃つ**（弓の弧が体の横に大きく見える）
2. **まだ子どもで、ちょっと怖がり**（肩をすくめた立ち方、体に比べて大きな矢筒）
3. **よく見ている**（顔が上がり、遠くを見る目）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **怖がり**／**目ざとい**／**やさしい** |
| 望み | 魔物がいなくなって、また畑で鳥を数える毎日に戻ること |
| 恐れ | 魔物が**近くまで**来ること |
| どう話すか | 小さな声で、言いよどむ。でも見えたものは正確に言う。一人称「ぼく」 |

### 遊びとのつながり（設定は遊びに出るものから）
- **射程が長い** ← 近くに来られるのが怖いから、遠いうちに撃つ。この子の弱さが、そのまま強みになっている
- **飛ぶ魔物にも当たる** ← 鳥追いの仕事で、空を飛ぶものを見るのに慣れている
- **塔にいちばん近い魔物から撃つ** ← 怖がりだが、やさしい。いちばん危ないところ（塔のそば）を先に助ける
- **重なって強くなる** ← 仲間がいると少し勇気が出る（「……もう少しなら、がんばれる」）
- **コモン** ← 村の子。弓は自分で削った素朴なもの

### 短い身の上（遊びに出ないので短く）
塔のふもとの村の、農家の末っ子。畑の作物をついばむ鳥を追い払う「鳥追い」が仕事で、弓はそのために自分で削った。鳥を傷つけたくないので、もとは音だけ鳴る矢を射っていた。魔物を撃つのは、これが初めて。
（剣士 `sword1` とは同じ村。歳も近い。仲がいいかは決めない。剣士の中身の世界の決めを引きつぐ）

### 書かないこと
- 英雄がなぜパックから出てくるか（剣士の中身 U3）
- 台座・紋の輪を駒や盤として扱う言い方

## 3. 見た目に出すところ

戦場の小さな絵（高さはアートディレクションの英雄の値。第2版は52px）で**読めるもの**と、**大きな絵でだけ**に分けた。上ほど大事。左右は画面から見た向き。

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **体の横の弓の弧**。素朴な木の弓で、弧の高さは体と同じくらい（頭の上は越えない） | 自分で削った弓 | 影の形の決め手（アート 3.3）。必ず。`archer2` の弓より**小さく**（3.5）。弓の上端は槍兵の槍の先より低い |
| 2 | **兜も帽子もない、ふくらんだ明るい亜麻色の髪**。房は丸く3つほど | 村の子。頭に何もかぶらない（怖がりなのに、兜が重くて嫌い） | 頭の明るい面（170以上）をこの髪で持たせる（アート 3.1）。房を**とがらせない**（ギザギザは魔物の形の言葉）。赤・紫の髪にしない |
| 3 | **腰の横に、体に比べて大きな矢筒**。白い矢羽が5本ほどのぞく | 怖いから、矢をたくさん持ってきた | 体の片側に出っぱる影になる。矢羽の白は小さく（照りより目立たせない） |
| 4 | **肩をすくめた立ち方**。足は開くが、肩が上がって首が短く見える | 怖がり | 英雄は「まっすぐ立つ」（アート 3.1）を守る。前かがみにはしない（魔物の形の言葉）。背筋は伸びていて、肩だけが上がっている |
| 5 | **苔の緑の上着**、首に生成りの布 | 鳥追いの野良着 | 差し色は苔の緑 `#4F6B3A`（アート 3.3）。首の布はレア度の色にしない |

### 3.2 動きで出す癖（コマ数はアートディレクション 5.4 の内で）

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ（開封のあと） | 降り立ってすぐ、きょろきょろと左右を見る（頭だけ1コマずつ） | 足すかは `game-anim-animator` |
| 待つ | 遠くを見るように、あごが少し上がる | 立っているの2コマの内 |
| 構え・放つ | 弓を引くとき、目を細める。放ったあと、矢の行方を見送る（戻りのコマで頭が少し前） | 構え・当て・戻りの3コマ |
| 重なった | 弓を胸に抱えて、小さくうなずく | 矢印 0.5 秒と同じ時 |

### 3.3 大きな絵でだけ（図鑑・開封の大きな絵）
- 顔のそばかす。目はたれ目ぎみで大きい（怖がりだが、やさしい）
- 弓の握りに巻いた、色あせた布（母が縫ったもの）
- 矢筒の中に、先が丸い「音の鳴る矢」が1本だけ混じっている（鳥追いの名残り）
- 上着のひじに土のしみ（畑の子）。汚しは描きすぎない
- 表情：口がへの字で、眉が下がっている。でも目は遠くをまっすぐ見ている

### 3.4 色の決め
- 差し色：苔の緑 `#4F6B3A`（上着）。ほかはアートディレクション 4.1 の英雄の側（革、ズボン、肌）
- 髪：明るい亜麻色を推す（白黒で170以上になる色。色コードは art で）
- 鋼はほとんど持たない（コモン、村の子）。弓の金具もなし。鋼の明るい面がないぶん、**髪が頭の明るい面の頼り**になる
- 使わない：レア度の色を服の面に、魔物の暗い赤・紫・灰を大きな面に、危険のだいだい
- 肌：既定より少し明るめ＋そばかすを案に（顔ぶれ.md 3章の肌の散らし方の案。決めるのは art）

### 3.5 ほかの弓使いとの分け方（`archer2`）
同じ役なので、体の横の弓の弧と苔の緑は共通。そのうえで：

| | `archer1`（この子） | `archer2` |
|---|---|---|
| 頭の影 | 丸くふくらんだ髪（上に広い） | 白い髭が下に伸びる（下に長い） |
| 弓 | 小さめ、素朴な明るい木 | 大きい（頭から足まで）、暗い古い木に真鍮 |
| 立ち方 | 肩をすくめる | 足を肩幅に開き、背筋がまっすぐで動かない |
| 矢筒 | 腰の横に大きく | 背中。肩の上に矢羽が出る |

## 4. 口調サンプル（戦場では声も字も出さない。図鑑と開封の一言の用）

### 図鑑の説明（1〜2行。地の文）
- 塔のふもとの村の鳥追い。弓は自分で削った。
- 魔物が近くに来るのが怖いから、遠いうちに撃つ。空を飛ぶものも見逃さない。
- 怖がりなのに、いちばん危ないところから先に撃つ。

（推しは1行め＋2行め。2行めで「射程が長い」「飛ぶ魔物に当たる」が読める）

### 開封の一言（本人の言葉。出すかは剣士の中身 U1 と同じく未決）
- 「う、うわ、もう来てる……。でも、あそこなら届く。」
- 「近くは、こわいから……遠いうちに、ね。」
- 「あの空のやつ、ぼくが撃つよ。」
- 「見えた。北から三つ。」
- 重なったとき：「……みんながいるなら、もう少しがんばれる。」
- 初めて出たとき：「鳥追いだけど……当てるのは、得意なんだ。」

## 5. 名前

条件は剣士の中身 5章と同じ（ふつうのファンタジーで通る、カタカナ3〜4文字、小さな字で読み違えにくい、既存の作品の有名なキャラ・実在の有名な人と重ならない）。加えて、10体の名前の頭の字がかぶらないようにした（顔ぶれ.md 4章）。

| 案 | 読みの感じ | よいところ | 気になるところ |
|---|---|---|---|
| **トリル（推す）** | 軽く、小鳥のさえずりのよう | 鳥追いの子に合う。3文字 | 音楽の言葉（トリル）と同じ。悪い意味はない |
| ウィム | やわらかく、小さい | 2文字で短い。気の弱さが出る | 「ィ」の小さい字が 12px で読みにくいおそれ |
| オスカ | 素朴、少し古風 | 村の子らしい | 実在の名前（オスカー）に近い |

**推すのはトリル**。重なりはこの担当の記憶で避けたが、調べてはいない（`game-design-creative-director` の確かめ）。

避けた案（記録）：弓の名手として有名な伝説・物語の人物の名前、森の神の名前、有名な作品の弓使いの名前。

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 少年、14歳くらい（案） | 10体の性別・年の割り振り（顔ぶれ.md 2章）。剣士 `sword1`（少女16）と同じ村の若い組にして、もう一方の性にした |
| 「怖がりだから遠くから撃つ」 | 射程が長い決まりを、性格から覚えられるようにするため。弱さが強みになる形は、剣士の「負けず嫌い」とかぶらない |
| フード・兜なし、明るい髪 | アート 3.3「フードのない頭」。フードの弓使いはありがちで、斥候（フードのとがり）とも分ける |
| 鳥追い（猟師ではない） | 狩人の弓使いはありがち。「鳥を傷つけたくない子が、塔のために初めて魔物を撃つ」で、やさしさが出る。暗い話にはしない |
| とがった耳・森の民にしない | 弓使いのありがちな型（森の長命の民）を避け、ふつうの村の人にした |

## 8. 気になっていること

- 頭の明るい面を**髪だけ**で持たせる英雄はこの子が初めて。髪の色が暗くなると、混んだ所で魔物と見分ける手がかりが紋の輪だけになる（アート 4.4）。髪の白黒の明るさを art で必ず確かめる
- 「怖がり」が強すぎると、プレイヤーが頼りなく感じる。口調サンプルでは「怖いけど、やる」を必ず入れた

- **P1**：飛ぶ魔物（コウモリ）が縦切りに入らないので、縦切りではこの子の「空も撃てる」が見えない。図鑑の2行めは MVP まで出しても困らないが、縦切りの図鑑では1行め＋3行めにするほうが嘘にならない（`game-design-ux`）
