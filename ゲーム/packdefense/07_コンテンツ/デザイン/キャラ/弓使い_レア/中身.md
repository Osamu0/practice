# 弓使い（レア）の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、`archer2` の「中身」。形は `剣士/中身.md` にそろえた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.2・3.3・4.1）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/パック.md`、`03_仕様/パラメータ表.md` 6章、`../弓使い/中身.md`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：レアを引いたときに「当たりだ、頼れる人が来た」と感じられ、コモンの弓使いと影だけで別人とわかる中身を決める。

## 0. この文書で言う「弓使い（レア）」

- 役は弓使い（`role = archer`）。この文書は **`archer2`（レアの弓使い）**。見習いのパックのプールに入る
- 同じ役の `archer1`（コモン）は `../弓使い/中身.md`。分け方は 3.5
- レアはコモンより強い（`card.rarityPower`）。攻撃のしかたは弓使いの役と同じ

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 見習いのパックのプール。レア | パック.md、パラメータ表.md 6章 |
| 立つ場所 | 開けた場所に立ち、ランの終わりまで動かない | 英雄.md |
| 狙い | 射程の内で塔にいちばん近い魔物 | 英雄.md |
| 攻撃 | 遠い1体へ矢（弾） | 英雄.md |
| 得意 | 飛ぶ魔物にも当たる | 英雄.md、魔物.md |
| 能力の例 | 飛ぶ魔物によく効く、速く撃つ（個々は 04 のあと） | 英雄.md |

**遊びでの意味**：`archer1` と同じ「遠くの見張り」を、ずっと強く受け持つ。レアのパックの「当たり」のひとつ。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方で、遠くを撃つ**（大きな弓の弧）
2. **年季の入った名手**（白い髭、背筋の伸びた動かない立ち方）
3. **コモンの弓の子とは別の、格上の人**（大きく古い弓、背中の矢筒）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **気長**／**とぼけている**／**正確** |
| 望み | 森から魔物を追い出して、また静かな森で鳥の声を聞くこと |
| 恐れ | 目が衰えて、遠くが見えなくなること |
| どう話すか | ゆっくり、短く。冗談をまじめな顔で言う。年下にも命令はしない。一人称「わし」 |

### 遊びとのつながり
- **射程が長く、塔にいちばん近い魔物から撃つ** ← 長い森番の勘で「どれがいちばん先に着くか」がわかる
- **飛ぶ魔物にも当たる** ← 森の上を飛ぶものを、何十年も見てきた
- **立った場所から動かない** ← 気長。一度決めた場所で、いくらでも待てる
- **レア** ← 王国に雇われた本職の森番。弓は若いころから同じ一本

### 短い身の上
王国の森番。塔の北の森の小屋に、一人で四十年あまり住んでいる。森に魔物が増えて小屋にいられなくなり、塔まで下りてきた。腕は衰えていないが、本人は少し気にしている。
（暗い話は付けない。家族は町に住む娘夫婦がいて、ときどき手紙が来る、くらいで足りる）

### 書かないこと
- 英雄がなぜパックから出てくるか（剣士の中身 U3）
- 台座・紋の輪を駒や盤として扱う言い方

## 3. 見た目に出すところ

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **頭から足もとまでの大きな弓の弧**。暗い古い木、両端に真鍮の金具 | 若いころからの一本 | 影の形の決め手（アート 3.3）。`archer1` の弓より明らかに大きく。上端は槍兵の槍の先より低く |
| 2 | **長い白い髭と白い髪**。髭は胸まで、下にとがらず四角く切りそろえる | 年季。手入れはきちんとする人 | 頭の明るい面（アート 3.1）を白い髪と髭で持つ。頭の影が下に長くなり、`archer1`（上に広い髪）と影で分かれる。髭の先を**とがらせない**（下向きの三角は魔物の形の言葉に近い） |
| 3 | **背中の矢筒から、肩の上に矢羽が3〜4本出る** | 本職の装備 | 頭の横の小さな出っぱり。槍兵の縦の線とは長さで分かれる（肩の上で止める） |
| 4 | **足を肩幅に開き、背筋をまっすぐにした動かない立ち方**。弓を引く腕だけが動く | 気長・正確 | 英雄の「まっすぐ立つ」。肩はすくめない（`archer1` との差）。足をそろえる立ち方は `sword2` の印なので使わない（顔ぶれ.md 5章） |
| 5 | **苔の緑の上着に、短い茶色の革の肩掛け** | 森番の仕事着。肩掛けは雨よけ | 差し色は苔の緑 `#4F6B3A`（役の色）。肩掛けは革 `#6B4F36`。毛皮にしない（灰の毛はオオカミ＝魔物の色に寄る） |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ | 降り立って、片手で髭をひとなでする | 足すかは `game-anim-animator` |
| 待つ | ほとんど動かない。2コマの差は、まばたき1つと髭のゆれだけ | 「動かない」がこの人の癖。ほかの英雄より待つ動きを小さく |
| 構え・放つ | 引いてから放つまでの間が、ほかの弓使いより1コマ長く見える（引き絞って止める） | 間隔は変えない（見た目だけ）。できるかは animator |
| 重なった | 弓を少し持ち上げて、目を細めて笑う | |

### 3.3 大きな絵でだけ
- 目尻の深いしわ。片目をすがめるくせ（遠くを見るとき）
- 弓の握りに刻んだ小さな印（獲物の数ではなく、森で見つけた鳥の種類の数。読める字にしない）
- 胸に、王国の森番の真鍮の小さな記章（王国の紋。宗教の印は使わない）
- 腰の小さな角笛（森番の道具）
- ブーツに乾いた泥と落ち葉
- 表情：口元は髭で隠れ、目だけが笑っている

### 3.4 色の決め
- 差し色：苔の緑（上着）。肩掛けは革。真鍮は弓の金具と記章だけ
- 髪・髭：白〜明るい灰（白黒で190以上を推す）。黄ばませない
- レアだが、レアの青 `#4FA3FF` は服にも装備にも使わない（パックの印と混ざる）。格上であることは**弓の大きさと真鍮の金具**で出す
- 肌：日焼けした濃いめを案に（顔ぶれ.md 3章）。頭の明るい面は髪と髭が持つので、肌を濃くしても読める

### 3.5 ほかの弓使いとの分け方
`../弓使い/中身.md` 3.5 の表のとおり。いちばん効くのは**頭の影**（丸く上に広い髪／白く下に長い髭）と**弓の大きさ**の2つ。

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 男性、67歳くらい（案） | 10体の年を散らす（顔ぶれ.md 2章）。いちばん年上を一人置くと、顔ぶれに幅が出る。白い髭が頭の明るい面と影の決め手を兼ねる |
| `archer1` の師匠にはしない | 剣士2人を師弟にする案（剣士の中身 P2）と同じ形がくり返されるのを避けた。`archer1` は一方的にあこがれているだけ |
| 森番 | 狩人より、森を守る人のほうが「魔物から森を取り戻したい」という望みとつながる |
| 一人称「わし」 | 6人の一人称を全部ちがうものにした（顔ぶれ.md 4章）。年寄りの言葉づかいとしてはありがちなので、語尾は「〜とる」「〜んでいい」くらいに抑え、それ以上の決まった型（「〜じゃ」の連発）は使わない |

## 8. 気になっていること

- 白い髭の老人の弓使いは、ありがちの側に寄る。ありがちを外すのは「とぼけた冗談」と「鳥の種類を数える弓の印」の小さなところで、影そのものはふつう。影の強さ（髭で下に長い頭）のほうを優先した
- 白い髪と髭は、骸骨の兵士の骨（明るめの灰）と色が近い。骸骨は暗い兜と黄色の目と輪なしで分かれる決め（アート 3.4）なので取り違えない見込みだが、並べ図で見てほしい
