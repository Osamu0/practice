# 槍兵（レア）の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、`spear1` の「中身」。形は `剣士/中身.md` にそろえた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.2・3.3・4.1）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/パック.md`、`03_仕様/パラメータ表.md` 6章、`../剣士/監修_段階7.md`（剣の先と槍の先の高さの差）。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：道に並んだ魔物を一突きでまとめて貫く味方が、戦場でいちばん背の高い縦の線として目に入り、図鑑で読むと「豪快で、でも借りは返す人」だとわかる中身を決める。

## 0. この文書で言う「槍兵」

- 役は槍兵（`role = spear`）。縦切りでは `spear1`（レア）1人。**鉄壁のパックだけ**のプールに入る。見習いのパックからは出ない
- 鉄壁のパックが棚に並んでから出会う英雄なので、プレイヤーが最初に見る槍兵がこの人になる

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 鉄壁のパックのプール。レア | パラメータ表.md 6章 |
| 狙い | 射程の内で塔にいちばん近い魔物 | 英雄.md |
| 攻撃 | 自分からその魔物への**線の上の、幅 `lineWidth` の内すべて**（射程の長さまで） | 英雄.md |
| 得意 | 一列に並んだ魔物。**飛ぶ魔物にも当たる**（近い攻撃の役と違う） | 英雄.md、魔物.md |
| 攻撃の間隔 | 弓使い・剣士より長め（`hero.base.spear.interval`） | パラメータ表 |
| 能力の例 | 貫く数が増える（04 のあと） | 英雄.md |

**遊びでの意味**：槍兵は「道の串刺し役」。魔物は塔へまっすぐ進むので、道の上に一列になる。そこへ一突き。間隔は長いが、当たると一度に何体も。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方で、長い槍**（いちばん背の高い縦の線）
2. **まっすぐ貫く**（大きく前後に開いた足、突きの構え）
3. **よそから来た腕利き**（不揃いの装備、片方だけの大きな肩当て）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **豪快**／**せっかち**／**義理がたい** |
| 望み | 昔この塔の兵に助けられた借りを、きっちり返して旅に戻ること |
| 恐れ | 借りを返せないまま終わること |
| どう話すか | 声が大きく、言い切る。笑う。細かい話は飛ばす。一人称「あたし」 |

### 遊びとのつながり
- **線の上をまとめて貫く** ← せっかち。「一体ずつなんて待ってられない。並んでるなら一度に」
- **攻撃の間隔が長い** ← 一突きに全部のせる豪快さ。小刻みには突かない
- **飛ぶ魔物にも当たる** ← 槍は長いので、低く飛ぶものにも届く
- **立った場所から動かない** ← 義理がたい。借りを返すと決めたら、その場を離れない
- **レア・鉄壁のパック** ← 王国の兵ではない。塔の守りを固める側に、自分から名乗り出た傭兵

### 短い身の上
渡りの傭兵。南の国境の町の生まれで、十代から槍一本で旅をしてきた。子どものころ、旅の途中で魔物に襲われたところを、この塔の兵に助けられたことがある。その兵の顔は覚えていない。塔が攻められていると聞いて、頼まれもしないのに来た。
（暗い話は付けない。助けてくれた兵は、どこかで元気にしているはず、くらいで足りる）

### 書かないこと
- 英雄がなぜパックから出てくるか（剣士の中身 U3）
- 台座・紋の輪を駒や盤として扱う言い方

## 3. 見た目に出すところ

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **体の横にまっすぐ立てた長い槍**。暗い木の柄、鋼の穂先、穂先の根に錆びた赤茶の房 | 槍一本で旅をしてきた | 影の形の決め手（アート 3.3：いちばん背の高い縦の線）。槍の先は、剣士の重なりのポーズ（剣を高く上げる）の剣の先より上（剣士の監修 段階8 で守った決め。数値は第1版の案C のもの。いまの方向の比率で art が決め直す）。10体でいちばん高い点はこの槍の先 |
| 2 | **片方の肩だけの大きな鋼の肩当て**（槍を持たない側） | 旅のあいだに拾い集めた不揃いの装備 | 左右が非対称な影。盾の騎士・`sword2` の左右そろった肩と分かれる |
| 3 | **頭の後ろで高く結んだ髪の房**と、**鋼の額当て** | 動きやすさ優先 | 頭の明るい面は額当て（鋼の明るい面）。房は上向きに跳ねる線にする（下・横に垂らすと魔物の形の言葉に寄る）。房は槍の線より短く |
| 4 | **足を大きく前後に開いた構え** | 突きの姿勢 | まっすぐ立つ（アート 3.1）の範囲で、足を前後に開く。前かがみにしない。腰に手（剣士の印）は使わない |
| 5 | **錆びた赤茶の腰布** | 旅の服 | 差し色 `#8A4A2E`（アート 3.3）。魔物の暗い赤に近いので、紋の輪と額当てで味方と分かるのを守る（アート 3.3 の注） |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ | 降り立って、槍の石突き（柄の下の端）で地面を一度突く | 足すかは `game-anim-animator` |
| 待つ | 槍を肩にもたせかけて、つま先で地面をとんとん（せっかち） | 2コマの内。槍の縦の線は保つ |
| 構え・当て | 後ろに大きく引いて、狙う方向へまっすぐ突く。突きの線が攻撃の線と重なる | 線の上すべて、の見た目 |
| 重なった | 槍をくるりと回して立て直す（1コマで）、歯を見せて笑う | |

### 3.3 大きな絵でだけ
- 腕と頬に日焼け。鼻の頭に小さな傷あと
- 肩当てに、元の持ち主のものらしい、知らない国の削れた紋（読めない模様で）
- 腰に、旅の小さな道具袋とすり切れた地図の筒
- 穂先の根の房は、もとは赤だったものが日に焼けて赤茶になった
- 表情：口を大きく開けて笑う。眉は太く、まっすぐ

### 3.4 色の決め
- 差し色：錆びた赤茶（腰布、房）。鋼は穂先・額当て・片方の肩当て
- 髪：黒を推す（明るい面は額当てが持つ）
- レアの青は使わない。腕利きであることは**槍の長さと穂先の照り**で出す
- 肌：オリーブ寄りの小麦色を案に（顔ぶれ.md 3章）
- 気をつけること：赤茶の腰布・暗い髪・濃いめの肌が重なると、頭と体がまとめて暗い段に寄る。**額当ての鋼を大きめに**して、頭の明るい面を必ず保つ

## 4. 口調サンプル

### 図鑑の説明（1〜2行）
- 渡りの傭兵。子どものころ、この塔の兵に命を助けられた。
- 並んだ魔物は、一突きでまとめて貫く。低く飛ぶものにも穂先が届く。
- 頼まれもしないのに来て、借りを返すまで帰らないと言う。

（推しは1行め＋2行め）

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 女性、24歳くらい（案） | 10体の割り振り（顔ぶれ.md 2章）で、20代を一人置いた。豪快な女性の傭兵は、男性の槍兵よりは見かけにくい |
| 傭兵（王国の兵ではない） | 鉄壁のパックだけから出る、よそから来た腕利き、を中身にした。顔ぶれの出身が全部「塔と村」に寄らないように |
| 片方だけの肩当て | 小さな絵で左右非対称の影が出て、ほかの英雄と分かれる。「拾い集めた装備」の中身と合う |
| 「借りを返す」 | 立った場所から動かない決まりを、性格で説明するため。暗い過去にしない形にした |

## 8. 気になっていること

- 差し色の赤茶は魔物の暗い赤（スライム `#7A2A30`）に近い。アート 3.3 の注のとおり、紋の輪と頭の明るい面で守るが、この人は髪も暗いので、ほかの英雄より頭の明るい面が小さい。並べ図の白黒で必ず見てほしい
