# 盾の騎士（コモン）の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、`shield1` の「中身」。形は `剣士/中身.md` にそろえた。
もとにした資料：`01_企画/企画書.md`（第3版）、`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.2・3.3・4.1）、`03_仕様/機能仕様/英雄.md`（第3版）、`03_仕様/機能仕様/魔物.md`、`03_仕様/機能仕様/パック.md`、`03_仕様/パラメータ表.md` 6章、`../剣士/中身.md`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：まわりの魔物をまとめて足止めしてくれる味方が、戦場でいちばん「どっしりした壁」に見え、図鑑で読むと「この人がいれば大丈夫」と安心できる中身を決める。

## 0. この文書で言う「盾の騎士」

- 役は盾の騎士（`role = shield`）。縦切りでは `shield1`（コモン）1人。見習いのパックと鉄壁のパックのプールに入る（はじめのランから出る）

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 味方の英雄 | 英雄.md |
| 出どころ | 見習い・鉄壁のパックのプール。コモン | パラメータ表.md 6章 |
| 狙い | **射程の内すべて** | 英雄.md |
| 攻撃 | 射程の内の魔物すべてに弱く当て、**遅くする**（`hero.<id>.slow`・`slowTime`） | 英雄.md |
| 苦手 | 近い攻撃なので、飛ぶ魔物に当たらない | 英雄.md、魔物.md |
| 能力の例 | 遅くする幅が広い（04 のあと） | 英雄.md |

**遊びでの意味**：盾の騎士は「足止め役」。倒すのは得意ではないが、まわりを全部遅くして、ほかの英雄とプレイヤーの指に時間をくれる。速いオオカミや、固まって来る群れに効く。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **味方で、体の前に大きな盾**（いちばん横に広い影）
2. **まわりをまとめて止める**（盾で押し出す、低く重い構え）
3. **大人で、頼れる**（大きな体、使い込まれた装備）

## 2. キャラの芯

| | |
|---|---|
| 性格を3語 | **どっしり**／**面倒見がいい**／**口数が少ない** |
| 望み | 交代の鐘が鳴るまで門の前を誰も通さず、夜はみんなで温かいものを食べること |
| 恐れ | 自分の後ろにいる人が、けがをすること |
| どう話すか | ひとこと、ふたこと。語尾がやわらかい。自分のことは言わない。一人称「わたし」（ほとんど言わない） |

### 遊びとのつながり
- **射程の内すべてに当てる** ← 一人ずつ相手にするのではなく、「ここから先」をまとめて押しとどめる門番の仕事
- **遅くする** ← 倒すより、止める。後ろの仲間が仕事をする時間を作る（面倒見）
- **威力は弱い** ← 盾は武器ではない。本人もそれでいいと思っている
- **飛ぶ魔物に当たらない** ← 盾は上には届かない（図鑑では触れなくてよい。剣士の図鑑の文で説明している）

### 短い身の上
塔の守備隊の騎士。17の歳から20年あまり、塔の門の前に立っている。騎士といっても位は低く、本人は「門番」と名乗る。村のパン屋の夫と、子どもが二人。
剣士 `sword1` の母（もと塔の番兵）とは、若いころの同僚。剣士の大きすぎる兜を見て、すぐに誰のお下がりかわかった。
（暗い話は付けない）

### 書かないこと
- 英雄がなぜパックから出てくるか（剣士の中身 U3）
- 台座・紋の輪を駒や盤として扱う言い方

## 3. 見た目に出すところ

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **体の前の大きな四角い盾**。鋼のふち、藍の地、真ん中に縦の真鍮の帯1本。**右上の角が1つ欠けている** | 20年の門番。直さずに使っている | 影の形の決め手（アート 3.3：いちばん横に広い）。欠けた角は影の形に出る印。盾は胸から膝までを隠すが、**顔と兜は必ず盾の上に出す**（頭の明るい面を隠さない） |
| 2 | **箱型の兜。顔の前の面頬（めんぼお）を上げている** | 門の前で、来る人の顔を見るため | 四角い頭の影。剣士の「丸い鉢＋広いつば」と分かれる。面頬を上げて顔を出す（目の暗い点を残す） |
| 3 | **大きな体。肩幅いっぱい、腰を落とした低い重心**。盾の下から厚いブーツ | どっしり | 身長の比は剣士の 1.0〜1.05（アート 3.2）。高さでなく**幅**で大きく見せる |
| 4 | **盾を持たない手は、盾のふちに添える**（両手で盾を構える） | 押しとどめる | 腰に手（剣士の印）は使わない |
| 5 | **鋼の肩当てと、藍の腰布** | 守備隊の支給 | 差し色は鋼 `#8E949C`＋藍（アート 3.3）。藍の面は盾と腰布だけにして、剣士の藍の上着と面の大きさで分ける |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 立つ | 降り立って、盾を地面に「どん」と下ろす（土ぼこりを少し大きめに） | 足すかは `game-anim-animator` |
| 待つ | 盾の上から、左右をゆっくり見回す | 2コマの内 |
| 構え・当て | 盾を前に突き出して押す（体ごと半歩分前に傾き、戻る） | まわりすべてに当たる、の見た目。効果の輪（遅くする）は art-vfx |
| 重なった | 面頬を一度下ろして、また上げる | |

### 3.3 大きな絵でだけ
- 盾の表の、たくさんの小さなへこみと引っかき傷
- 盾の裏に、子どもが描いた塔の落書き（大きな絵の、盾の裏が見える角度のときだけ。ふだんは見えなくてよい）
- 兜の面頬の、すり減った蝶番
- 首もとに見える、生成りの厚い詰め物の服
- 腰に、パンを包んだ布の包み
- 表情：目尻が下がった穏やかな顔。口は閉じている。頬に昔の小さな傷あと（血は描かない）

### 3.4 色の決め
- 差し色：鋼（盾のふち・兜・肩当て）＋藍（盾の地・腰布）。真鍮は盾の帯だけ
- 盾の地の藍は、剣士の上着の藍と同じ色を使う（王国の色）。盾が大きいので、藍の面がいちばん大きい英雄になる。影の側の色にして、紋の輪の藍と溶けないか art で見る
- 肌：濃い褐色を案に（顔ぶれ.md 3章）。頭の明るい面は兜が持つ
- 使わない：レア度の色、魔物の色を大きな面に

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 女性、38歳くらい（案） | 大きな盾の騎士は大柄な男性がいちばんありがち。10体の割り振り（顔ぶれ.md 2章）で、大人の女性を一人置いた。体の大きさは性別でなく幅で出す |
| 面頬を上げて顔を出す | 頭の明るい面と目の暗い点を残すため（アート 3.1）。顔が出るので大きな絵で表情が読める |
| 盾の角の欠け | 小さな絵で影に出る、ただ1つのこの人だけの印。「使い込まれた」（アート 2）が形で出る |
| 剣士の母の同僚 | 図鑑で並べたとき、世界が少しつながる。説明の1〜2行には入れない（読まなくてよい） |

## 8. 気になっていること

- 盾が体の前の大部分を隠すので、**藍と鋼の盾がこの人の見た目のほとんど**になる。盾が暗い藍の大きな面だと、白黒で魔物の暗い体（40〜95）と同じ段に入る。盾のふちの鋼（明るい）と兜で、明るい点を必ず持たせる（アート 4.2）
- `sword2` のマントも「下に広い影」を作る。盾（体の前の四角）とマント（体の後ろの台形）で分かれる見込みだが、顔ぶれ.md 5章で見比べた
