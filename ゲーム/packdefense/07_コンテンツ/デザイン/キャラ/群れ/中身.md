# 群れの中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、魔物 `swarm` の「中身」。形は `剣士/中身.md` にそろえ、魔物なので「振る舞いの印象」と「プレイヤーに覚えさせること（1つ）」を書いた。
もとにした資料：`02_プリプロ/アートディレクション.md`（第2版：3.4・4.1・5.2・5.3）、`03_仕様/機能仕様/魔物.md`（第3版）、`03_仕様/パラメータ表.md`・`パラメータ表.csv`、`../スライム/中身.md`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：危険の三角のあとに固まって来る小さな魔物が、「まとめて、輪の1回で」とプレイヤーに読める中身を決める。

## 0. この文書で言う「群れ」

- 魔物の型 `swarm`（群れ）。1回の湧きで `monster.swarm.groupSize` 体（いまは4）が固まって来る。第4ウェーブから
- 見た目は**小さなスライムの固まり**（アート 3.4）。中身もスライムの種の、生まれたての小さいものとする

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 魔物（群れ） | 魔物.md |
| 出るころ | 第4ウェーブから | パラメータ表 |
| 来る前に | その方向の画面の端に、危険の三角（！つき、点滅） | 魔物.md |
| 進み方 | 4体が `monster.swarm.spread` の内に固まって、塔へ。スライムより少し速い | 魔物.md、パラメータ表 |
| 1体の耐久 | とても低い（タップ2回）。4体を攻撃の輪1回の場所で2回押さえれば全部倒れる＝指の見せ場 | パラメータ表 |
| コイン | 1体ぶんの重み。点は群れ1つで1つぶん | 魔物.md |

### 振る舞いの印象
**ころころ、ひとかたまり、にぎやか**。一体ずつは頼りないが、固まって押し寄せる。

### プレイヤーに覚えさせること（1つ）
**「固まっているやつは、輪の1回でまとめて倒せる」**
攻撃の輪の広さを生かす気持ちよさを教える魔物。だから**ばらけて見えない**ことがいちばん大事。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **魔物で、たくさん**（小さな体が4つ、黄色の目が8つ）
2. **固まっている**（体どうしが触れ合う。影もひとつながり）
3. **一体ずつは弱い**（スライムよりずっと小さい）

## 2. 振る舞いの芯

| | |
|---|---|
| 振る舞いを3語 | **ちょこまか**／**くっつきたがり**／**にぎやか** |
| 動く理由 | 大きなスライムのあとを追って塔へ（生まれたてで、ひとりでは動けない） |
| 嫌がるもの | ひとりになること（だから固まる） |

### 遊びとのつながり
- **固まって来る** ← ひとりになるのが嫌い
- **一体ずつ弱い** ← 生まれたて
- **危険の三角が先に出る** ← にぎやかな音が先に聞こえる、という気持ちで読める（設定には書かない。絵と音の担当への手がかり）

### 出どころ（短く）
森の窪地で生まれたばかりのスライムの子。大きくなるとスライムになる（遊びには出ない。群れを倒してもスライムに変わったり分かれたりはしない）。

## 3. 見た目に出すところ

1体はスライムの 0.45 倍（13〜20px。アート 5.2）。4体の固まりの全体で、ふつうの魔物ほどの大きさ。

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **小さなスライム4つが触れ合った固まり**。並びは菱形かつぶれた三角（1列にしない） | くっつきたがり | 影の形の決め手（アート 3.4）。輪1回で全部入る見た目（`monster.swarm.spread` の内）。4つの大きさを少しずつ変える（同じ大きさだと模様に見える） |
| 2 | **1体ずつに黄色の目2つ** | 魔物の印 | 必ず。小さいので目は1体に点2つ（各1〜1.5px）。目が並ぶと「たくさん」が読める |
| 3 | **ひとつながりのギザギザの暗い影** | 固まり | 影を4つに分けず、1つの影にすると「ひとかたまり」に見える |
| 4 | **しずくのとがりが、みんな同じ向き（進む方向）** | 大きなスライムを追っている | スライムの形の言葉を引きつぐ |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 歩く | 4体の波の動きを1コマずつずらす（ちょこまか） | 体ごとの位置は固まりの中で 1〜2px ゆれる程度。ばらけて見えないように |
| 1体が倒れる | 残りが一瞬すき間を詰める（あれば） | 当たりの位置が変わらないなら見た目だけ。できるかは `game-design-ai` |
| 倒れる | スライムと同じ、小さく | |

### 3.3 大きな絵でだけ
- 4体の表情のちがい（目の大きさ・間隔を少しずつ変える）。口はない
- いちばん小さい1体が、少し遅れてついてくる
- 体はスライムより透けて、薄い（生まれたて）

### 3.4 色の決め
- 決まっている：スライムと同じ暗い赤 `#7A2A30`（アート 3.4）、目 `#FFD84A`、縁 `#140E16`
- 縁の太さは 0.45 倍で 1px を下回る（アート 5.3・未決 #6）。1px に固定するのを推す（小さな体の形が地面に溶けないため）

## 4. 図鑑の説明（魔物は話さない）

- 生まれたばかりのスライムの子。ひとりになるのが嫌いで、いつも固まっている。
- 一体ずつはとても弱い。固まっているうちに、まとめて押さえること。
- 来る前には、そちらの空がなんだか騒がしい。

（推しは1行め＋2行め。3行めは危険の三角をほのめかす。仕様で「三角はなぜ出るか」を世界の中で言わないなら使わない）

## 5. 種の呼び名

| 用途 | 呼び名 |
|---|---|
| 図鑑・画面の表記 | **スライムの群れ**を推す（「群れ」だけだと、何の群れか図鑑で読めない）。1体を指すときは「小さなスライム」 |
| ID | `swarm` |
| アートディレクション・仕様の中の呼び名 | 「群れ」のまま（型の名前） |

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 覚えさせることは「輪の1回でまとめて」 | パラメータの注記（群れ4体を輪1回で2回＝指の見せ場）そのもの |
| スライムの子とした | アート 3.4 の「小さなスライムが3〜5つ固まる」に中身を合わせた。種を増やさない |
| 倒してもスライムに変わらない、と明記 | 「大きくなるとスライム」という設定から、分裂や成長の仕組みがあると読まれないため |
| 図鑑の表記を「スライムの群れ」 | 図鑑で単語1つ「群れ」は名前に見えない。決めるのは `game-design-ux`・`game-design-creative-director` |

## 8. 気になっていること

- スライムと同じ色なので、**1体だけ残った群れ**はスライムを遠くに置いたのと見分けにくい。大きさの差（0.45倍）で分かれる見込み。地面との差は、縁の 1px の固定に頼る
