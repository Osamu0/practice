# 骸骨の兵士の中身（設計書の元）

game-story-lore、2026-11-27（第1版）。`game-art-concept` が設計書と外部への依頼書を書くための、魔物 `skeleton` の「中身」。形は `剣士/中身.md` にそろえ、魔物なので「振る舞いの印象」と「プレイヤーに覚えさせること（1つ）」を書いた。
もとにした資料：`02_プリプロ/アートディレクション.md`（第2版：2・3.1・3.4・4.1・4.2・6.3）、`03_仕様/機能仕様/魔物.md`（第3版）、`03_仕様/パラメータ表.md`・`パラメータ表.csv`。
10体に共通の前提は `../顔ぶれ.md` の 0章。

**この仕事の目的**：遅いが硬く、指をとどめてくる魔物が、湧いた瞬間に「これは硬い、指だけでは時間がかかる」と読める中身を決める。

## 0. この文書で言う「骸骨の兵士」

- 魔物の型 `skeleton`（硬い）。第6ウェーブから湧く（最初に塔が壊れるころの、新しい手ごわさ）

## 1. 遊びでの役割（仕様の決めから）

| 項目 | 決め | 出どころ |
|---|---|---|
| 立場 | 魔物（硬い） | 魔物.md |
| 出るころ | 第6ウェーブから | パラメータ表 |
| 進み方 | 塔へまっすぐ。**遅い**（スライムの3分の2ほど） | パラメータ表 |
| 耐久 | **高い**（スライムの4倍。タップだけなら2秒あまり押さえ続ける） | パラメータ表 |
| 英雄との関係 | 遅いので英雄の射程に長くいる。英雄に任せやすい | パラメータ表の注記 |

### 振る舞いの印象
**がしゃり、がしゃりと、遅いが止まらない**。叩いてもひるまない。

### プレイヤーに覚えさせること（1つ）
**「硬いやつは時間がかかる。指を取られすぎるな」**
指で全部倒そうとすると、そのあいだに別の方向が塔に着く。硬いのは英雄の前に長くいてもらう、の判断を覚えさせる魔物。

### プレイヤーに一目で伝えたいこと（設計書の「3つまで」への案）
1. **魔物**（暗い兜と鎧、黄色の目、ギザギザの影、紋の輪がない）
2. **硬い**（四角い兜、鎧、重そうな足どり）
3. **遅い**（背の高い体を前かがみにして、1歩ずつ）

## 2. 振る舞いの芯

| | |
|---|---|
| 振る舞いを3語 | **重い**／**しぶとい**／**無口** |
| 動く理由 | 何かの命令の続きを、まだ果たそうとしている（何の命令かは誰も知らない） |
| 嫌がるもの | ない（何もこわがらない、ひるまない） |

### 遊びとのつながり
- **硬い** ← 錆びた鎧を着ている。骨の体は痛みを感じない
- **遅い** ← 鎧が重く、骨がきしむ
- **塔だけを狙う** ← 古い命令が「塔へ」だけだった

### 出どころ（短く）
荒れ地の古い塚から起きてくる、名もない骨の兵士。鎧はどこの国のものか、紋が削れてわからない。王国の昔の兵ではない（王国の兵が敵になる話にしない。暗い話にしない）。

## 3. 見た目に出すところ

ふつうの魔物の大きさ（28〜36）。4種の中ではいちばん背が高い（英雄の 0.7 まで。アート 3.2）。

### 3.1 戦場の小さな絵で出すもの（優先の順）

| # | 出すもの | 中身との結びつき | 決まりとの関係・気をつけること |
|---|---|---|---|
| 1 | **四角い暗い兜**。目の穴の奥に黄色の光 | 古い兵士 | 影の形の決め手（アート 3.4）。剣士の丸い兜・盾の騎士の箱型の兜とは、**色（暗い）と目（黄色の光）**で分かれる。兜の形が盾の騎士と近いので、こちらは**頭のてっぺんがとがった山形**か、**横に角のような飾り**を推す（形でも分ける） |
| 2 | **暗い鎧の胴**（胸から腰まで） | 硬い | 暗い段 `#2C2830`（アート 3.4）。骨の明るさが道と同じなので、鎧と兜の暗い面で地面から切りはなす（アート 3.4 の注） |
| 3 | **骨の手足**（細い棒と関節の丸） | 骸骨 | 骨 `#9C9484`（白黒149）。150 をこえない |
| 4 | **錆びた剣を下へ向けて持つ** | 古い兵士 | 魔物の「下向きの線」（アート 3.1）。英雄の剣（上向き）と逆。剣先が地面をひきずる |
| 5 | **前かがみの、背の高い体** | 遅い、重い | 魔物の形の言葉 |

### 3.2 動きで出す癖

| 場面 | 癖 | メモ |
|---|---|---|
| 歩く | 1歩ごとに一瞬止まる（4コマのうち1コマを長く） | 遅さと重さ。速さの数値は変えない |
| 攻撃を受ける | ほとんどはじかれない（ほかの魔物の 2px より小さく 1px） | 「ひるまない」＝硬い、の見た目。できるかは `game-anim-animator` |
| 塔を攻撃 | 錆びた剣を振り上げて、ゆっくり振り下ろす | |
| 倒れる | 骨がばらばらに崩れて、兜が最後に転がり、黒い粒 | 血は描かない。こわくしすぎない |

### 3.3 大きな絵でだけ
- 鎧の削れた紋（読めない模様）
- 骨のひび、関節にからんだ枯れ草
- 兜の中の暗がりと、黄色の2つの光だけ（頭骨の歯は小さく、あるいは見せない）
- 錆びた剣の刃こぼれ

### 3.4 色の決め
- 決まっている：骨 `#9C9484`、暗い鎧 `#2C2830`、目 `#FFD84A`、縁 `#140E16`（アート 3.4・4.1）
- 骨が道と溶けるなら、骨を `#8A8274` に下げる（アート 6.3）
- 使わない：骨を白くする（明るい段は英雄の側）、赤い色（血に見える）

## 4. 図鑑の説明（魔物は話さない）

- 荒れ地の古い塚から起きてくる、名もない骨の兵士。鎧の紋は削れて読めない。
- 遅いが、硬い。指で叩き続けるより、仲間の前を歩かせたほうがいい。
- 何の命令を守っているのかは、本人にもわからないらしい。

（推しは1行め＋2行め。2行めが「覚えさせること」）

## 6. 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| 覚えさせることは「指を取られすぎるな」 | パラメータの注記（指をとどめる重さ、英雄の射程に長くいる）。柱2の裏側（危なくないところに指を置かない）を教える |
| 王国の昔の兵にしない | 味方の側と同じ王国の兵が敵になると話が暗く重くなる。アートの「ダークファンタジーにしない」 |
| 兜の形を盾の騎士と分ける（山形・角の飾り） | アート 3.4 は「四角い暗い兜」、盾の騎士の中身は「箱型の兜」で、形が近い。色と目で分かれるが、白黒・影だけの段でも分けたい |
| 攻撃を受けてもほとんどはじかれない | 「硬い」を数字でなく動きで見せる |

## 8. 気になっていること

- 骸骨は子ども向けにはやや怖い題材。崩れる演出（骨がばらばら、兜が転がる）はこわくしすぎず、すぐ黒い粒にする。血・頭骨の大写しは使わない
