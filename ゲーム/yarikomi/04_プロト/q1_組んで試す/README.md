# Q1 組んで試す（プロトタイプ・捨てる前提）

問い（デザインの柱 Q1）：組んで試すのが、スマホ縦持ち片手で2〜4分で気持ちいいか。初めての人が親指だけで組み、予行で外れ、理由が分かって直し、解くまでが2〜4分に収まるか。指で部品が隠れて置き間違えないか。

本番には持ち込まない前提のコード。絵は四角と線、音はなし。

## 動かし方

```sh
cd ゲーム/yarikomi/04_プロト/q1_組んで試す
npm install            # 初回だけ（typescript と vite）
npm run dev            # 開発用。表示された Network の URL を同じ Wi-Fi のスマホで開く
# または
npm run build && npm run preview   # dist/ を配る形で確かめる
```

- 公開はしない。スマホで見るときは同じ LAN の中だけで開く（届け方は未決：進行表）
- 遊び方：タイトルで「はじめる」（ここから時間を測る）→ 見る → 工房へ → 組む ⇄ 試す → 組み上げる → 挑む

## 確かめ方

```sh
python3 tools/check_challenge.py   # 課題の作りを rules_sim.py の写しで確かめる（約1分）
npm run cases                      # rules_sim.py で照合用のケースを作る → test/cases.json
npm test                           # TS の規則が rules_sim.py と同じ結果か（515 ケース・3598 手）
npm run typecheck
npm run build && npm run e2e       # Chromium で最初から解くまでタッチで操作。screenshots/ に画像
```

e2e は環境の Playwright（`require('playwright')`、なければ `/opt/node-tools/node_modules/playwright`）と Chrome を使う。

## 作った範囲

- 作業台 4×4（`bench.size.firstGen`、マス 72px）。棚の部品 8 種（杭なし）：板×4、鉄の棒、ばね、強いばね、石の重り、鉄の重り、小石×2、砂袋
- 置く：ドラッグ（部品を指の上 56px に浮かせ、浮かせた部品の下のマスに枠）／棚をタップ→マスをタップ。置いた部品をタップで選ぶ、もう一度でばねの向き。ドラッグで動かす、棚へドラッグで外す。ひとつ戻す
- 規則 3 つ：落ちる・弾む・ずれる（rules_sim.py と同じ結果）
- 試し場：平ら・崖・割れ目。人形・試しの重り、道具を ◀▶ で動かす、送る（1手）・続けて・最初へ。次の1手の印（動く先の影）
- 挑む：ターン制。手の札（進む・置く・拾う・待つ）と候補、盤面のマスのタップでも選べる。次の1手の印、危険な手は確定が朱。確定した手は戻せない。1手の再生（段ごと 300ms、間 120ms。盤面のタップで飛ばす）
- 記録：メニュー（≡）→「記録」。はじめてから解けるまでの時間、画面ごとの時間、置いた回数、置き間違い、予行の回数（試し場を開いた・送る・続けて・最初へ）、挑んだ回数、死んだ回数。文字（JSON）で書き出し・ファイルに保存

## 置き間違いの数え方（目安）

置いてから 8 秒以内（`MISTAKE_WINDOW_MS`）に「ひとつ戻す」した／動かした／棚に戻した回数。
置く先の決まり：ドラッグなら枠が出ていたマス（つまみ `DRAG_TARGET`：指の上＝浮かせた部品の下（既定）／指の下）、タップなら指の下のマス。枠どおりに置けたものは間違いに数えない。
部品のあるマスに置こうとした・作業台の外で離した回数は「置けなかった」として別に数える（間違いには入れない）。
「指で隠れて違うマスに置いた」かは自動では分からないので、プレイテストで見て聞く。

## 1回目のプレイテストのあとの直し（2026-11-19）

1. 本番で道具の部品が谷底へ落ちた・待つしかできないとき、この先 8 手で解ける手がなければ「外れた」を出し、手の札の場所に「引き返して組み直す」を出す。ふだんも手の札の下に「引き返す」がある（押すと道具をばらして工房へ）
2. 試し場の地形に「課題の形」（課題の地形だけ。当主・印・敵・仕掛けは入れない）。つまみ `TRIAL_SHOW_CHALLENGE_TERRAIN`（既定：出す）
3. 置き間違いの数え方を上のとおりに直した。つまみで置くマスを「指の上／指の下」に切り替えられる
4. 説明の帯を2行にし、2行目に「東へ倒す ●●●● ＞ 戻す ●」を切れずに出す。つり合いは「＝ つり合い」、押さえられているときは「＜ … 余裕 ●●」
5. 置くの候補は、選んでいる1つだけを描く（置く位置は山吹の枠、落ちて止まる先は点線の影）。ほかは「前・次」で送る
6. 部品を選ぶと、働きの一言を帯の2行目に出す。ばねのある道具を試すと「重り落とし」で試せると出す
7. メニューに「作業台をまっさらにする」（ひとつ戻すで戻せる）。メニュー・記録・つまみの画面の「閉じる」は上に固定
