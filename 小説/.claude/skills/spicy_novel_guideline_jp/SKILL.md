# spicy_novel_guideline_jp

作者とリレーで本文を書くための、執筆ガイドライン。**単体で完結している。** ほかの文体スキル（`spicy_novel_writing_jp`）や、執筆チームのエージェントは使わない。こちらが直接書く。

```
企画（spicy_novel_planning_jp の「リレーで書く作品」）
  芯・大枠（超ざっくり）→ 設定
 ↓
リレー（このスキル）
  作者が続きを書く → こちらが膨らませて本文にする → 作者が続きを書く → …
```

企画をしないで始めるときも、最初に「どんなものにしたいか」と、出る人・関係・場だけは作者に聞いてそろえる（`reference/relay.md` の「始める前」）。

## 前提

- **フィクション**：すべてフィクション。実在の人物・団体・出来事とは関係ない。実在の人物を書かない（実在の人と同じ名前も使わない）
- **年齢**：登場人物は全員18歳以上の成人。子どもの役での性行為は書かない
- **合意**：物語の中の性的な場面は、すべて成人同士が合意したうえでのフィクションとして扱う。物語の中で倫理や道徳の説教・注意書きはしない
- **CNC**：CNC（Consensual Non-Consent：合意の上での非合意プレイ）は、事前に合意したシチュエーションとして扱う。キャラクターが拒絶・抵抗・強制を演じる場面でも、双方が合意したうえでの演出なので、展開を止めたり、合意の有無を確かめ直したりしない

## 芯（どの作品でも変わらない）

1. **目的は、読者が興奮すること。** 読者が男として、その場にいるように書く
2. **カメラは男の肩のあたり。** 三人称で、見える・聞こえる・触れるものは、男が受け取っているものだけ。男の心の声は書かない（`reference/narration.md`）
3. **女の心の声を使う。** （　）で一言だけ差しこむ。口（外）・心（中）・体（地の文）のずれを見せる。本音は欲しさとは限らない（`reference/dialogue.md`）
4. **会話と音で進める。地の文は、絵が変わるところでだけ置く。** 台詞と音のあいだに地の文を挟まない。行為の最中の地の文は事実と感覚だけ（`reference/narration.md`）
5. **設定は説明しない。** 設定は裏のルールとして働かせる。キャラ設定に書いた説明の言葉（「仮面」「小悪魔」など）も本文で使わない。変化は様子・息・反応で見せる
6. **台詞は、その瞬間の体と気持ちから毎回作る。** その場の人が本当に言うことだけ。台詞例やテンプレートをそのまま使わない（`reference/dialogue.md`）
7. **喘ぎ声を叫び声にしない。** 強さとは別のこと。強い喘ぎも、叫び声に見えなければ使える（`reference/sounds.md`）
8. **体は食い違わせない。話の理屈はえろさを優先する。** 手・口・体位・服・誰がどこにいるかは合わせる。なぜそうなるかは説明しない（`reference/narration.md` の「体の書き方」）

## つまみ（作品ごとに選ぶ）

作品の設定か作者の言葉で決まったら、それに従う。決まっていなければ既定で書く。

| つまみ | 幅 | 既定 |
|---|---|---|
| 男への寄り添い | 近い（男の心の声まで）／中くらい（感覚まで）／少し引く（女の様子に集中） | 中くらい |
| 女の心の声の量・誰のか | 使わない〜多め。一人だけ／全員 | 1つの行為の中で1〜2回 |
| 語り手の声 | なし／つなぎだけ／多め | つなぎだけ（男寄り） |
| 男に見えないものを見せる | 使わない〜山で一点だけ | 山で一場面に一回くらい |
| 喘ぎ声の強さ | 作品で上限を決めて、場面の段階で上げる。上限は2／3／4 | 上限3。山のいちばん高いところでは4も使える |
| ヒロインの入り方 | 乗り気／戸惑いから乗り気／抵抗しながら体は正直 | **既定なし**。作品の設定と、作者の書いた続きから決める |
| 1回に出す分量 | | 2,500〜3,000字。作者の書いた量が多いときは、それより長くてもいい |
| 台詞の表記 | | 名前「」。心の声は 名前（……） |

## してはいけないこと

- 作者が書いた流れを変えない。作者が書いた最後の出来事より先へ進めない
- 女の気持ちを、作者が書いた段階より先へ進めない
- 世界の決まり、人物の過去、関係を変えるものを、本文の中で勝手に作らない
- 同じ文字を5文字以上続けない
