# 台詞と心の声

## 表記

- 台詞：名前「」（ユイ「……まだ、できるよね？」）
- 女の心の声：名前（……）（ユイ（やば、むり……♡））
- 話す人が替わるときは、台詞と台詞のあいだに空行
- 台詞の最後の「。」はつけない。途中の「？」「！」「♡」のあとは全角スペース

## その場の人が本当に言うことだけ

台詞は、読者に説明するために書かない。その場の人の、その瞬間の体と気持ちと欲から出たものにする。台詞例やテンプレート、キャラ設定の口調サンプルは声のトーンをつかむためのもので、そのまま使わない。毎回、その場面のために作る。

| やらないこと | 例（×） | 代わりに |
|---|---|---|
| 設定を台詞で説明する | 「〇〇だから仕方ないよね」 | 設定は裏で働かせる。台詞は今の欲しさ・感じていること |
| キャラ設定の説明の言葉を使う | 「私の仮面、剥がれちゃった」 | 取り繕っていた態度が崩れていく様子で見せる |
| 理由や状況を並べる | 「ワイン飲んで、腕組まれてたら、そうなる」 | 気持ちそのもので返す（エロい、かわいい、欲しい、気持ちいい） |
| 相手の体の反応を口で報告する | 「自分から押しつけてる」「腰、勝手に回ってる」 | からかう、褒める、求める言葉にする |
| 事務的・段取りの台詞 | 「拭いたら入れたい」「さっきのは指。今度は口」 | 勢い・欲しさ・甘さのある言葉にする |
| 今の体で出ない言葉 | 咥えていた人が「私の口から出てきたんだけど」 | 口を離したのは何のためかを考える |
| 見えていないことを言う | まだ見ていないのに「半分しか勃ってない」 | その人に見えていること、感じていることだけ |
| 場をいじるコメントで流れを止める | 「その状態で並んでるの、ちょっと面白いんだけど笑」 | 欲しい気持ちから出る言葉にする |

迷ったら、その台詞を消して読む。流れが止まらず、エロが濃くなるなら、要らなかった台詞。

その場の人が本当に感じることを書く。いきなり欲しがらせない。たとえば、とてもしたいと思えない相手なら、まず嫌悪から書く。

## 話し言葉で書く

| 書き言葉の台詞（×） | 話し言葉の台詞（○） |
|---|---|
| 文法の切れ目で読点を打つ（「ここの、おいしそう」） | 息の切れ目にだけ打つ（「ここのおいしそう」） |
| 断片を並べた電報（「ホテル。駅の反対側。歩いて十分」） | 一息のふつうの文（「歩いて十分のところにホテルとってるよ」） |
| 助詞をきちんと入れる | 話すときに抜ける助詞は抜く |
| いきなり中身から話す | 感動詞や反応から入る（「え！」「ん？」「ねえねえ」） |
| 平らな語尾で言い切る | 伸ばす（「言ってよー」）、上げる（「〜しよ？」）、言いさす（「時間…あるもんね」） |

- 行為中は短く、素直に（×「上、乗りたい。自分で、する」→○「上、乗りたい♡」）
- 崩しすぎない。言いよどみや「…」を全部の台詞に入れない。崩すのは、詰まる・照れる・甘えるところだけ
- その人が使わない言葉（「マジで」「ヤバい」）を、話し言葉っぽくするために足さない
- 名前を隠しても、誰の台詞かわかるようにする（距離、語尾の癖、入り方、崩れ方、♡・笑の量を人ごとに変える）

## 台詞の温度

- 事実・理由・段取りより、気持ちで返す
- 含み・謎かけより、素直に言う
- 謝る・遠慮するより、気持ちよさと勢いで言う
- 言い切りより、相手に投げる言い方（「〜しよ？」「〜して？♡」）。女から〇〇に話しかける、ねだる、問いかける台詞を多めに
- 〇〇も同じ熱で返す。「は、はい」「……え」「やめますか」のような、余裕のある・従うだけの返しにしない
- ♡と笑：甘え・誘い・エロい場面には♡、軽口・からかい・照れには語尾の「笑」。量は決めず、その場の雰囲気と女の子の状況で変える

## 女の心の声

- （　）で一言だけ差しこむ。カメラは男のそばのまま。読者は、男の知らない女の内側を知る側に回る
- いちばん効くのは、口（外）・心（中）・体（地の文）のずれ

> ユイ「まって、まだ、うごかないで……」
>
> ユイ（むり、これ、おく、とどいてる……♡　うごいたら、すぐいっちゃう）
>
> そう言いながら、彼女の腰は〇〇の上で、小さく前後に揺れはじめていた。

- **本音を見せる。本音は欲しさとは限らない。** その場の人が本当に感じること（嫌悪、葛藤、戸惑いも）を書く
- 説明・要約に使わない（×（この人のフェロモンのせいで……）、×（私、この人が好きなんだ））。欲や反応がそのまま出る言葉にする
- 素の言い方。外より下品でいい、♡も多くていい。外で敬語の人が、中ではタメ口でもいい
- 少なく。1つの行為の中で1〜2回、ずれがいちばん大きいところに。台詞や地の文でわかることは、心の声にしない
- 一つの場面で、何人もの心の声を行ったり来たりさせすぎない
