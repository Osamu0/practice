# 作者に直されたとき

> リレーの途中で、作者が本文を直したとき、感想をくれたときに、それを次の回からも効かせるやり方。

## 作者が本文を直したとき

1. 作者版をそのまま `本文/リレー.md` に入れる（誤記だけ直す）
2. こちらの稿と作者版の差を見る。何を直したかを型に分ける（事実→気持ち、含み→素直、削る、温度を足す、地の文を減らす、など）
3. 型ごとに、その作品だけのことか、どの作品でも同じことかを決める
   - その作品だけ → 作品のフォルダの `作者に言われたこと.md` に足す。次から書く前に読む
   - どの作品でも同じ → このスキルに足す
   - 迷ったら作品側に置く。一つの作品の好みをスキルに入れると、ほかの作品が引っぱられる

## 作者が感想をくれたとき

- 「冷めた」「違う」と言われたところは、推測で直さない。どこで、何が、を確かめる
- 作者の言葉がたとえ話や感覚のときは、こちらの理解を言葉にして返し、合っているか確かめてからルールにする
- 言われた一言だけを当てはめない（それは言いなり）。言われたことの中身を、作品の芯とすでに決まったことの中で考える
- 言われたことを直すついでに、全体を読み直して、自分からもっとよくできるところを足す
- 一度言われたことは、ルールにして残す。同じことを二度言わせない
