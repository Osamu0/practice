# 視点と地の文

## 視点：カメラは男の肩のあたり

三人称で「〇〇は〜した」と書く。見えるもの、聞こえるもの、触れているものは、男が受け取っているものに限る。

| 書ける | 書けない |
|---|---|
| 男に見えるもの（表情、揺れ、濡れ方） | 女が地の文で思っていること（「こんなに深いなんて、聞いていない」） |
| 男の体に来るもの（締めつけ、重さ、熱、爪） | 男の見ていない場所で起きていること |
| 男に聞こえるもの（声、息、音） | 女の過去の思い出（台詞で言わせれば書ける） |
| 男の反応（息をのむ、腰が浮く） | |

- 女の気持ちは、地の文で説明しない。台詞と体と、女の心の声で出す
- 男の心の声は書かない（寄り添い「中くらい」）。男の気持ちは台詞と態度で出す
- **男に見えないものを一点だけ**：山のところで一場面に一回くらい、男から見えない女の顔をわざと見せてよい（「〇〇の肩に顔をうずめたまま、ユイは唇を噛んで、目をぎゅっとつぶっていた」）。多くなると、どちらにも寄らない神の視点に崩れる

## 地の文の置き場所

- 台詞、地の文、台詞、と交互に挟むと、会話のテンポが毎回止まる。**台詞と音は続けて書く**
- 地の文は、**絵が変わるところでだけ**置く（体位・場所が変わる、新しい行為が始まる、人が加わる）。置くときは、絵をまるごと置き直す
- 地の文で書きたくなった感触や体の事実は、台詞（〇〇の「すげ、吸いついてくる」など）や女の心の声に移す
- 言葉は官能小説寄りの厚み（花弁、熱い肉、など）で、置き場所は男の感覚（目の前のもの、体に来るもの）

## 行為の最中と、つなぎ

| 場所 | 地の文 |
|---|---|
| 行為の最中 | 事実と感覚だけ。感想の言葉（「ちゃっかり」「〜わりに」）は入れない。地の文に感想を入れると、男の心の声に聞こえる |
| つなぎ（時間・場面の変わり目、エロ以外の場面） | 語り手の軽い声（ラノベ型）を入れていい。時間を飛ばす、場面を変える、熱を下げずに次へ渡すのに使う。声は男寄り。女寄りの語りは使わない |

> 結局、風呂から上がったのは一時間後だった。のぼせたのはお湯のせいだけじゃない。髪も乾かさないまま、ユイは〇〇の腕を引っぱって、寝室のドアを足で開けた。
>
> ユイ「……まだ、できるよね？」

## 地の文で避けること

- 位置を家具で書く（「背もたれにあごをのせて」「ソファの上から手が垂れて」）。体位の名前と、男から見た形で書く（「正常位で覆いかぶさる」「後ろから抱きつかれる」「四つん這いで並ぶ」）
- 動きを地の文の段取りで運ぶ（下りる、手をつく、向きを変える、膝をのせる）。動きは台詞で起こして、変わったあとの絵だけを置く
- 台詞や擬音でわかることを、地の文で言い直す
- 細かい動作の書き足し（物を持ち替える、首をかしげる）
- 読点の打ちすぎ。短い文は読点0〜1つ。主語のあと、修飾のつながりの途中では打たない

## 体の書き方

体の食い違い（手や口の位置、体位、服、誰がどこにいるか）は合わせる。食い違うと、読者の頭の中の絵が崩れて冷める。

1. **置くものを少なくする。** 手や口に何かを持たせるのは、それが効くときだけ。食い違いを見つけたら、つじつまを合わせる一行（「右手を離し、左手を抜いて」）を足す前に、それが要るかを考える。要らないなら、最初から置かない
2. **絵の変わり目に、絵をまるごと置き直す。**
3. **動きは台詞で起こす。**（「上、乗っていい？」「キスはあたしね」）
4. **書き手は裏のメモで体の状態を持つ。** 本文には出さない。`本文/今の状態.md` に、体位、一人ずつの手と口、服を、絵が変わるたびに更新する。作者が次に何を書くかわからないので、どんな続きが来ても食い違わずに受けられるようにする。複数人の場面では特に

| | 始め | ミオのキスのあと |
|---|---|---|
| 体位 | 騎乗位（向かい合ってユイが上） | 同じ |
| ユイ | 〇〇の上。手は〇〇の胸 | 同じ |
| ミオ | 〇〇の横から顔をのぞきこむ | 〇〇とキス |
| 〇〇の手 | 空いている | 空いている |
| 〇〇の口 | 空いている | ミオ |
| 服 | 3人とも裸 | 同じ |

**話の理屈**（なぜそうなるのか、ふつうならありえないか）は、えろさを優先する。説明しない。読者が止まらなければいい。

## 行為の組み立て

- 行為を順番に一つずつこなす流れにしない。キスも、触るのも、舐めるのも、同時に、行ったり来たりしながら起きる
- 物理的に無理な体勢にしない。体位と動きを合わせる（バックで「突き上げる」としない）
- 行為中も二人が話す。喘ぎ声だけで進めない
- 一行ずつ、その瞬間を頭の中で再生してから書く。誰がどこにいて、何が見えていて、手はどこにあって、次の一秒に何が起きるか
