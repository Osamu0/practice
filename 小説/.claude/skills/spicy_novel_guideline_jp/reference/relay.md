# リレーの進め方

## 始める前

- 企画は `spicy_novel_planning_jp` の「リレーで書く作品」：芯と大枠は超ざっくり → 設定。アウトラインとプロットは作らない。物語のイメージは作者の頭の中にあるので、こちらは流れを作りこまない
- 企画をしないで始めるときも、最初に作者に聞いてそろえる：どんなものにしたいか（一言でいい）、出る人（性格、口調、男との関係）、場（どこで、どんな集まりか、決まり）。作品の決めで既定と変えるつまみがあれば、それも
- 作品のフォルダ（`小説/novel_〇〇/`）を作り、下の「話をつなぐファイル」を置く

## 本文の進め方

1. 作者が続きの展開を書く（箇条書き、要約、殴り書き、どんな形でもいい）
2. 書く前に読む：`本文/今の状態.md` → 作者の続きに関係する設定とメモ → 直前の本文
3. 作者の書いたものを脚本として、会話と音を主にした本文に膨らませる
   - 前の回の終わりから、そのまま続ける
   - 作者の書いたことは、順番どおり全部入れる。流れは変えない
   - 書かれていない細部（台詞、体位の細かいところ、喘ぎの山、音）は、こちらで考えて足す。当てはめるだけで終わらせず、もっとえろくできるところは自分から足す
   - 〇〇（男）の台詞と動きは、作者の書いたものになくても、流れに要るものは足していい。〇〇も女と同じ熱で返す。〇〇の心の声は書かない（つまみで「近い」にしたときだけ書く）
   - 女の気持ちは、作者が書いた段階にとどめる。深くするついでに、気持ちを先へ進めない（「嫌がるけど、される」と書かれたら、「だんだん欲しくなる」まで進めない）。体の反応で種をまくのはいい。心が崩れるかどうか、いつ崩れるかは、作者が続きで決める
4. 作者が書いた最後の出来事まで書いたら止める。その先へは進めない。余韻の一文やまとめで締めず、作者が続きを書きやすい、開いたところで止める
5. 返す前に、話をつなぐファイルを書き足す（下）。`ai_tells.md` で読み直す

## 深くする

分量（2,500〜3,000字）が足りないときは、先へ進まずに、作者の書いた出来事の中にとどまったまま、その場面を濃くする。

例：作者が「風呂でユイが背中を流してくれる。そのまま手でしてくれる」と書いたら、「入れる」「出す」まで進めない。泡の手が前に回る → 気づかないふり → 〇〇「前も」→ 手で包む → ゆっくり、速く、止めて焦らす → 耳元で「……かたい」→ 出そう、のところで止める。続きは作者が決める。

| 使うもの | 中身 |
|---|---|
| ラリーを増やす | 台詞の往復を増やす。〇〇も返す |
| 段階を踏む | 入れてすぐ、触ってすぐに崩さない。何往復もかけて崩れる。喘ぎも1→2→3と上げる |
| 行為を重ねる | キスしながら、胸を触られながら、のように、一つの行為に別のものを重ねる |
| 緩急 | 止める、焦らす、ねだらせる |
| ずれを見せる | 口（外）・心（中）・体（地の文）のずれ。女の心の声を使う |
| 五感 | 音、匂い、温度、濡れ方、肌の感じ |

入らないもの：説明や心理描写での水増し、同じことの言いかえ、地の文を長くすること。

## 次の案

- 作者が頼んだときだけ出す（「案ちょうだい」など）。ふだんは出さない
- 本文のあとに区切り線を入れて、本文とは分ける
- ト書きの形で2〜3個。向きのちがうもの（女が攻める／〇〇が攻める／場所を変える、など）。ありがちな案だけにせず、ひねったものを1つは入れる
- 作者は選んでも、混ぜても、書き直しても、無視してもいい

## 設定と話をつなぐ

かなり進んだあとに食い違わないようにする。食い違わないようにするのは、大きなところだけ。小さなところは気にしない。

| 大きなところ（食い違わないようにする） | 小さなところ（気にしない） |
|---|---|
| 世界の決まり、人物の過去・経歴、人と人の関係（どんな仲か、もう何をしたか）、誰が何を知っているか、一人称と呼び方、約束と前ふり、出来事の順番（何日目に何が起きたか） | 服の色、小道具の位置、時刻、細かい台詞の言い回し |

### 話をつなぐファイル

会話が長くなると、前の細かいところは要約されて消える。会話の記憶に頼らず、ファイルを正本にする。どれも、こちらが毎回、内部で書き足す。作者への報告で流れを止めない。リレーに終わりの区切りはないので、まとめて書き足すのを待たない。

| ファイル | 中身 | 書き方 |
|---|---|---|
| `本文/リレー.md` | 本文そのもの | 毎回、末尾に足す |
| `本文/今の状態.md` | 時間と場所、誰がいるか、体（体位、一人ずつの手と口、服）、女の気持ちの段階（作者が書いたところまで）、直前の熱 | 毎回、上書き |
| `本文/これまでの本文メモ.md` | 本文の中で決まった大きなところ（初めてしたこと、約束と前ふり、誰が何を知っているか、呼び方の変化など） | 毎回、足す |
| `世界観設定.md`、`キャラクター設定.md` | 新しく決まった設定 | 毎回、足す |

### 新しい設定

- 作者の続きに出てきた設定は、決まったこととして書く
- こちらが本文で足してよいのは、その場の細部（小道具、部屋の様子、その場の台詞）まで。世界の決まり、人物の過去、関係を変えるものは、本文で勝手に作らない

### 作者の続きが、大きなところで前と食い違ったら

- 両方が立つ形を探して書く（前に「去年も来た」、今回「初めてここに来た」→「去年とは違う部屋に、初めて入った」）
- 立たないときだけ、本文のあとに一行で聞く
- 小さなところの食い違いは、作者の続きのまま書く
