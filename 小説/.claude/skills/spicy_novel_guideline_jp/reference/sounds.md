# 擬音と喘ぎ声

## 擬音の置き方

- 行為音（抽送、水音、挿入、射精、体がぶつかる音、道具、潮、きしみ）は、説明の文をつけずに、擬音そのものを独立した行に置く
- 口でする行為の音（キス、舐める、吸う、咥える、フェラ）は、台詞の中に混ぜてよい（ユイ「んっ……ちゅぱ、れろ……♡　おいし……♡」）
- 音のニュアンスで、語尾に♡をつけてよい
- 続いている行為の音は長めに（1行に5〜10音。途中で強い音を混ぜる）。単発の音（びくんっ、ぷしゃっ）は短く
- 同じ場面の中で段階を上げる（ゆっくり → ふつう → 激しい → 連打）
- 地の文で、行為音を説明しない。音と地の文で同じことを二度書かない（×「透明な汁が噴き出した。」＋「ぷしゃっ」）
- 同じ文字を5文字以上続けない（伸ばしの「〜」や「ッ」も4つまで）

## 行為音のレパートリー

| 行為 | 例 |
|---|---|
| 抽送 | ゆっくり：ぬちゅ……　ぬぷ……／ふつう：ずちゅっ、ずちゅっ／激しい：ぱんっ、ぱんっ、パンッ／もっと激しい：ばちゅっばちゅっばちゅんっ／山：ばちゅっ♡　どちゅっ♡♡ |
| 水音 | 濡れ始め：くちゅ……／濡れている：ぐちゅっ、ぬちゅっ／ぐしょぐしょ：ぐぢゅっぐぢゅぢゅっ／泡立つ：ぶちゅっ、ぐぽっ |
| 挿入 | ゆっくり沈める：ずぷ……ずぷぷ……／一気に奥まで：ずぶぶっ！　ごりゅっ／きつい：みち……っ、みちみちっ |
| キス・口 | ちゅ、ちゅぷ、ちゅる、れろ、ちゅぱっ |
| フェラ | じゅぷ、じゅるっ、ちゅぽっ／激しい：じゅぽっじゅぽっ／喉奥：ごぽっ、ぐぽっ、んぐっ |
| 手コキ | しこしこ、しゅこしゅこ／濡れている：にちゅっにちゅっ、ぬちゅぬちゅっ |
| パイズリ・素股 | むにゅっ、たぷんっ、ぱちゅんっ／ぬるっ、ずりゅっ |
| 胸・乳首 | むにゅ、もみゅっ／ちゅうっ、れろっ／きゅっ、くりっ |
| クンニ・指 | ぴちゃっ、れろれろ、じゅるっ／くちゅくちゅ、ぐちゅぐちゅっ |
| 射精 | びゅるっ、びゅくっ／大量：びゅるるっ！　どぷっ、どぷっ |
| 抜く・あふれる | ぬぽっ、ちゅぽんっ／とろっ……、どろぉ…… |
| 体の反応 | びく、びくんっ、ぴくん、がくん、ふるふる、ごくり |
| そのほか | 潮：ぷしゃっ、ぶしゃっ／きしみ：ぎしっ、ぎしぎしっ／服：しゅるっ、ビリッ／電マ：ヴヴヴヴッ |

表記で激しさを出す：ひらがな（やわらかい）→ カタカナ（硬い、強い）→ 濁点を増やす、読点を消してつなげる（速い）→ ♡をつける（甘く崩れる）→ 半角カナ（限界。山のいちばん高いところだけ。喘ぎ声が半角になったら、行為音も半角にする）。

## 喘ぎ声の形：叫び声にしない

喘ぎ声が叫び声に見えると冷める。強さとは別のこと。

| 叫び声に見える（使わない） | 喘ぎ声に見える（使う） |
|---|---|
| 同じ母音を長くのばす（「あああああ」） | 息で切れる。短い音が重なる（「あっ、あ、ぁ……っ」） |
| 悲鳴・怒号の音（「ひぎゃあ」「うおお」「んぎゃあ」） | 息と声のあいだの音（「ん」「ふ」「は」「ぁ」「ひぅ」） |
| 大きい字だけで、ずっと同じ高さ | 小さい字（ぁ、ぅ、っ）や「……」で揺れる。高さが変わる |
| 言葉がなく、音だけが続く | 音のあいだに言葉の切れはしが混ざる（「そこ」「だめ」「いく」） |

同じ強さでも形で変わる。
- 叫び声：「ああああああっ！　ひぎゃあああっ！」
- 喘ぎ声：「あっ、あ゛っ、そこ、ぉ゛……っ♡　んぃ、いく、いっ……♡」

ほかに：
- 喘いでいる最中に、自分の声を説明させない（×「こんな声」「変な声」「声、漏れちゃう」）。「あたまおかしくなる」「とける」のように自分の状態を口走るのはいい
- イくときの声を毎回同じ組み立てにしない。強い形は山に絞り、ほかは途切れる・低く落ちる・抑える、などに散らす

## 喘ぎ声の強さ

作品で上限を決めて、場面の段階で上げる。既定の上限は3。山のいちばん高いところでは4も使える。

| レベル | 形 | 例 |
|---|---|---|
| 1 | 「あ」が基本。吐息 | あっ、あんっ……　ふ、ぁ…… |
| 2 | 息と言葉の途切れで乱れる。濁点・♡なし | っは、そこ……ん、いい……ッ |
| 3 | 濁点・♡ありで崩れる | あ゛っ、そこ、ぉ゛……っ♡　んぃ、いく、いっ……♡ |
| 4 | 理性が飛ぶ。呂律が崩れる、卑語が混ざる、半角カナ | らめ、おく、ごりゅごりゅ、きてりゅ……っ♡　い゛く、ｲｸｯ……♡♡ |

| 段階 | 強さ |
|---|---|
| 前戯 | 1〜2 |
| 本番 | 2〜3 |
| 山 | 作品の上限まで |

### 状況ごとの声の形

| 状況 | 声の形 | 例 |
|---|---|---|
| 気持ちよさが漏れはじめる | 息だけの短い声 | ふぅ　はぁ　ん…… |
| 声を抑えて、小さくイく | 頭に小さい「ぁ」「ぃ」。息が言葉より先に漏れる | ぁぃく……いく……ぁっ、ぃく…… |
| 一番奥まで届いた瞬間 | 低く詰まった声 | ぐ、ぅぅっ |
| 浅く小刻みに突かれる | 短い「お」「あ」の連打に、訴えが混ざる | おっ　おっ　あっ　だめっ |
| 本気で感じはじめる | 母音に濁点。音が濁って詰まる | ん゛ん゛ッ　あ゛っ　お゛っ |
| 言葉まで崩れる | 言葉の一文字ずつに濁点 | き゛も゛ち゛ぃ　ま゛って |
| 呂律が回らない | 音が別の音にすり替わる | や゛へ゛て（やめて）　ひんじゃう（死んじゃう） |
| 焦らされる | 細く高い声 | ひぃっ　んい…… |
| 口がふさがっている | 閉じた口の、濁った「ん」 | ん゛ん゛ッ！？　ん゛〜〜っ |
| 深くイく（声も出ない） | 途切れ途切れ。間が長い | ……あっ……ぐッ、……ぃぐ……いっ……ぐ |
| イったあと | 重い息のくり返し | はふ……ふぅ……はっ、はっ |

喘ぎの中に混ざる言葉：訴え（「まって」「だめ」「イったばっか」）、体で起きていること（「おくつぶれる」「あたまばかになる」）、甘え（「やだぁ」「もっとぉ」「抜かないで」）、限界（「ゆるして」「しんじゃう」）。
