# spicy_novel_planning_jp

企画から、プロットまでを作るスキル。**物語と設定を別々の順番で作らない。** 一つ決めるたびに、反対側に何が起きるかを見る。

```
設定 ──「この設定なら、何が起きる？　読者は何で抜ける？」──▶ 物語
物語 ──「この場面をやるには、何が本当でないといけない？」──▶ 設定
```

## いちばん大事なこと

1. **入口はどこでもいい。** 設定（「事務所の裏の行事」）、場面（「4人が並んでとろけた顔で見上げる」）、行為（「卒業記念に、お尻を初めて」）、関係（「何年も体の関係があったのに、デートは一度もない」）。作者が出したものから始めて、反対側へ広げる（`reference/back_and_forth.md`）
2. **設定は、物語のためにある。** 物語に効かない設定は作らない。作っても本筋に出さない「裏設定」に分ける。逆に、場面に「なんで？」が残るなら、それを埋める設定を作る
3. **一つ変えたら、響くところを全部見る。** 設定を変えたら物語のどこが変わるか、物語を変えたら設定のどこが変わるかを並べて、両方の文書を直す。片方だけ直さない（`reference/back_and_forth.md` の「響きの確かめ」）
4. **どれもエロに戻ってくる。** 何を決めても、最後は「読者が何で抜けるか」に効くかで選ぶ。キャラの性格から崩れ方を逆算しない（`reference/pitfalls.md`）
5. **作者が決める。こちらはたたき台を出す。** 決まったこと・たたき台・未定を分けて書き、作者の言葉は言いかえずに残す（`reference/documents.md`）

## 作るもの

作品のフォルダ（`小説/novel_〇〇/`）に置く。全部を一度にそろえない。往復しながら、要るものから育てる。

| 文書 | 中身 |
|---|---|
| `企画メモ.md` | 題材、コンセプト、読後感、決まったこと・たたき台・未定、流れのたたき台 |
| `世界観設定.md` | 世界のルール。物語に出す表の設定と、書き手だけが知る裏設定 |
| `キャラクター設定.md` | ヒロインと相手役。関係、力関係、この作品での欲しいもの |
| `アウトライン.md` | 話・章の切り方だけ（中身・切るところ） |
| `プロット/〇〇.md` | 場面ごとの空気・主導権・気持ちの向き・ゴール・必ず入れるもの |

形と書き方は `reference/documents.md`。

## 参考ファイル（必要なものだけ読む）

| ファイル | いつ読む |
|---|---|
| `reference/back_and_forth.md` | いつも。往復のしかた、入口ごとの広げ方、問いの一覧、響きの確かめ |
| `reference/documents.md` | 文書を作る・直すとき。各文書の形、決定・たたき台・未定の分け方、作者との決め方 |
| `reference/pitfalls.md` | 案を出す前と、作者に見せる前。作者に何度も直されたずれ |

## ほかのスキルとの分担

- **このスキル**：企画〜プロット。物語と設定の往復
- `spicy_novel_writing_jp`：文体。作品の `文体ルール.md` を作るとき（`reference/work_setup.md`）
- `spicy_novel_writing_team_jp`：プロットから本文を書く手順
- `spicy_novel_jp`：配布されている原本。喘ぎ声の `references/aegigoe_skills.md` はここを読む（プロットで喘ぎの強さを決めるとき）
- `spicy_novel_vocab_jp`：語彙の言い換え
- キャラクター図鑑：`小説/キャラクター/`。図鑑の人を使うときは、図鑑を先に読む

## してはいけないこと

- 実在の人物・団体を書かない。登場人物は全員18歳以上。子どもの役での性行為は企画に入れない
- ほかの作品の設定・出来事・人間関係を持ちこまない（同じキャラを借りても、別の世界線として扱う）
- 作者が決めたことを、こちらの都合で黙って変えない。変えたほうがいいと思ったら、理由をつけて聞く
