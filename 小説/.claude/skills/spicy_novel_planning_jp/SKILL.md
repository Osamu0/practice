# spicy_novel_planning_jp

企画から、プロットまでを作るスキル。本文は別に書く（`spicy_novel_writing_team_jp`）。

**「どんなものにしたいか」から膨らませる。** 設定の表を埋めてから物語を考えるのでも、場面を並べてから理由をつけるのでもない。最初にある大雑把な枠を芯にして、物語と設定を一緒に、外へ外へと育てる。

```
芯        どんなものにしたいか（何の話か・読後感・いちばん見たい絵）
 ↓
大枠      始まり・山・終わりの大雑把な流れ　＋　それが成り立つ大きな設定（世界・場・関係）
 ↓
中くらい  話・章の切り方、人ごとの欲しいもの　＋　仕組みの中身、決まり、時間と場所
 ↓
細部      場面、小道具、数字　＋　裏設定
```

## いちばん大事なこと

1. **芯を先につかむ。** 作者の「こんな感じ」を、作者の言葉のまま芯に置く。芯がぼやけていたら、膨らませる前にそこを一緒に詰める（`reference/expand.md` の「芯」）
2. **物語と設定は、同じ芯から一緒に出てくる。** 大枠の流れを考えると、それに要る設定が出てくる。設定を一つ決めると、流れが一段はっきりする。どちらかを先に仕上げない
3. **大枠から、「設定はこうした方が良さそう」を考える。** 設定は、大枠（山、欲しさ、落差、主導権）がもっと効くかで選ぶ。足すだけでなく、変える・削るも出す。出すときは、大枠のどこが良くなるかと、代わりに変わるところを並べる（`reference/settings_from_frame.md`）
4. **一段ずつ細かくする。** 大枠が決まらないうちに細部を作りこまない。細部は、大枠と芯に効くものだけ
5. **迷ったら芯に戻る。** 案を選ぶとき、食い違ったとき、作者に直されたときは、「これは、どんなものにしたいかに効くか」で決める。エロの作品なら、最後は「読者が何で抜けるか」（`reference/pitfalls.md`）
6. **作者が決める。こちらはたたき台を出す。** 決まったこと・たたき台・未定を分けて書き、作者の言葉は言いかえずに残す（`reference/documents.md`）

## 作るもの

作品のフォルダ（`小説/novel_〇〇/`）に置く。全部を一度にそろえない。膨らんだところから書く。

| 文書 | 中身 | 主にどの段 |
|---|---|---|
| `企画メモ.md` | 芯（コンセプト・読後感・空気）、決まったこと・たたき台・未定、流れのたたき台 | 芯・大枠 |
| `世界観設定.md` | 世界のルール。物語に出す表の設定と、書き手だけが知る裏設定 | 大枠〜細部 |
| `キャラクター設定.md` | ヒロインと相手役。関係、力関係、この作品での欲しいもの | 大枠〜中くらい |
| `アウトライン.md` | 話・章の切り方だけ（中身・切るところ） | 中くらい |
| `プロット/〇〇.md` | 場面ごとの空気・主導権・気持ちの向き・ゴール・必ず入れるもの | 細部 |

形と書き方は `reference/documents.md`。

## ほかのスキルとの分担

- **このスキル**：企画〜プロット
- `spicy_novel_writing_jp`：文体。作品の `文体ルール.md` を作るとき（`reference/work_setup.md`）
- `spicy_novel_writing_team_jp`：プロットから本文を書く手順
- `spicy_novel_jp`：配布されている原本。喘ぎ声の `references/aegigoe_skills.md` はここを読む（プロットで喘ぎの強さを決めるとき）
- `spicy_novel_vocab_jp`：語彙の言い換え
- キャラクター図鑑：`小説/キャラクター/`。図鑑の人を使うときは、図鑑を先に読む

## してはいけないこと

- 実在の人物・団体を書かない。登場人物は全員18歳以上。子どもの役での性行為は企画に入れない
- ほかの作品の設定・出来事・人間関係を持ちこまない（同じキャラを借りても、別の世界線として扱う）
- 作者が決めたことを、こちらの都合で黙って変えない。変えたほうがいいと思ったら、理由をつけて聞く
