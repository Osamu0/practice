# 物語と設定の往復

> 企画は、設定の表を埋めてから物語を考える、の順にしない。一つ決めたら、反対側に何が起きるかを見る。それをくり返して、両方を一緒に育てる。

## 往復の一回

1. **今決まったものを一つ取る。**（設定でも、場面でも、行為でも、関係でもいい）
2. **反対側に投げる。**
   - 設定 → 物語：「この設定なら、どんな場面が起きる？　いちばん抜ける場面はどれ？」
   - 物語 → 設定：「この場面が成り立つには、何が本当でないといけない？　読者が『なんで？』と思うところはどこ？」
3. **出てきたものを、たたき台として作者に見せる。** 案は一つに決め打ちせず、向きの違うものを2〜3。ただし、こちらの一押しには理由をつける
4. **決まったら、響くところを確かめる。**（下の「響きの確かめ」）
5. **両方の文書を直す。** 設定は `世界観設定.md`・`キャラクター設定.md`、物語は `企画メモ.md` の流れ・`アウトライン.md`・`プロット/`

一回で大きく進めない。作者が「それ」と言ったものから、次の一回を始める。

## 入口ごとの広げ方

作者が最初に出すものは、作品ごとにちがう。どこから入っても、反対側へ広げる。

| 入口 | 例 | 最初に反対側へ投げる問い |
|---|---|---|
| 設定 | 事務所の裏の恒例行事で、ファンをもてなす | この場で、いちばん抜ける瞬間は何？　誰が主導権を持つ？　初めて来た男は、何に驚く？ |
| 場面 | 4人が並んで、とろけた顔で「誰からがいい？」と見上げる | なぜ4人は最初からとろけている？　なぜ男に選ばせる？　この場面の前に何があれば、いちばん効く？ |
| 行為・やりたいこと | 「お尻は絶対無理」と言っていた人が、卒業記念にやる | なぜ今ならやる？　誰とならやる？　その人が嫌々ではなく、やりたいと思える前提は何？ |
| 関係 | 何年も体の関係があったのに、デートは一度もない | なぜデートをしなかった？　何が変わって、今日はデートになる？　体は慣れているのに、慣れていないものは何？ |
| 人 | 図鑑のメンバー4人 | この4人が一緒にいて、いちばんエロくなる場は？　その場で、4人それぞれ何が欲しい？ |

## 問いの一覧

### 設定から物語へ

- この設定で、読者がいちばん抜ける瞬間はどこ？　その瞬間は、この設定でしか起きない？
- この設定があると、誰が何を欲しがる？　欲しいものが、場面の動きになる
- 主導権はどちらにある？　途中で動く？　動くなら、何がきっかけ？
- 初めての人と、慣れている人の差は何？　その差が、どの場面で見える？
- 決まり・制限は何？（「口外しないこと」「1人ずつ撮る」など）。制限があると、どんな場面が生まれる？
- 時間・場所の区切りは？（2泊3日、四半期に1回、卒業後）。区切りから、山場・緩む時間・終わりの位置が決まる
- この設定は、本筋に出す？　書き手が補うための裏設定にする？

### 物語から設定へ

- この場面で、読者が「なんで？」と止まるところは？　それを埋める理由は、設定にある？
- この行為・この台詞に、人物が乗り気でいられる前提は何？（同意、慣れ、記念、仕事、欲しさ）
- この道具・この場所は、なぜそこにある？（例：精力剤は、メンバーが当たりと知らずに来ているので、自分たちで持ってきたものではない。別荘に用意してあった）
- この人は、なぜこれを知っている／知らない？（例：中を知っているのは、もうつながったまなつだけ。だからまなつだけが「わかっている顔」をする）
- 次の作品・次の回につなげたいなら、どんな仕組みがいる？（例：3期の回にも同じ男を出したい → 「メンバーの推薦で、抽選の外で招く」仕組みを作る。ただし1期の回の中には、つなぐ含みを入れない）
- 時代・年齢・経歴の数字は、物語と食い違っていない？（例：卒業生の話なので全員2歳上げる。18歳になるまで仕組みに入らない、から加入年と合わせる）

## 響きの確かめ

一つ決まったら、反対側のどこに響くかを書き出してから直す。響きを見ずに片方だけ直すと、あとで食い違う。

| 変えたもの | 確かめる先 |
|---|---|
| 世界のルール・仕組み | その仕組みを前提にした場面、台詞、人物の知っている・知らない |
| 人物の関係・過去 | 照れ・慣れ・ためらいの有無（慣れている関係なら、初めての緊張は書かない）、呼び方、主導権 |
| 年齢・時期・数字 | 経歴の年、ほかの人物との年の差、時代の小道具 |
| 場面の順番 | 体の回復（出せる回数）、時間帯と光、誰がもう知っているか、前の場面の熱を引き継げるか |
| 場面を足す・消す | その場面でしか決まっていなかった設定（宙に浮く）、その場面に頼っていた次の場面 |
| 山場の位置 | 緩む時間（食事・風呂・眠り）の置き場所、話の切るところ |

確かめたら、作者に「これを変えると、ここも変わります」と短く見せる。作者が知らないうちに、反対側を書きかえない。

## 往復の実例（このリポジトリの作品から）

> 書き方の参考。作品の中身はほかの作品に持ちこまない。

**裏オフ（`novel_offkai`）**
- 設定「事務所の裏の行事。口外しないこと以外は何をしてもいい」→ 物語「男は最初、ドッキリか罠だと疑う。疑っているうちに、4人が目の前に並ぶ」
- 設定「男が当たりだった理由はちんこ」→ 物語「下着を下ろした瞬間に4人が騒いで、顔を寄せる。『去年の人の倍ある』」→ 設定に戻る「毎回あるから、前の男と比べられる」「当たりは久しぶりだったので、ガチでヨガる」
- 物語「2日目を山場にしたい。でも男の出せる回数に話が寄ってしまう」→ 設定「別荘に精力剤が用意してある」→ さらに「4人は当たりと知らずに来ているので、自分たちで持ってきたものではない」と食い違いをふさぐ
- 物語「作者が3期の回も読みたい」→ 設定「推薦の仕組み」。1期の回の物語には響かせない、と決めて書いておく

**卒業記念AV撮影（`novel_shinomiya`）**
- 関係「現役中から、マネージャーの〇〇が性欲発散の相手をするのは、運営公認の業務」→ 物語「セックスそのものへの照れや抵抗は書かない。ヤバいのは、卒業記念のAVにするという発想のほう」
- 設定「卒業生なので、全員2歳上げる」→ 物語「表の卒業はもう済ませた。〇〇との『こっちの卒業式』をまだしていない」
- 行為の一覧（4人が自分で選んだ「やりたいこと」）→ 設定「『やりたくない枠』も本人が選んだもの。嫌々ではない」→ 1本ごとのコンセプトと見どころ
