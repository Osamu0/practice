# 文書の形と、作者との決め方

## どの文書にも共通すること

- 頭に注意書きを置く：「本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。」
- **決まったこと・たたき台・未定を分ける。**
  - 印のない行：作者が決めたこと
  - **（たたき台）**：こちらが仮に決めたこと。あとで変えてかまわない
  - **（未定）**：まだ誰も決めていないこと
- 作者の言葉は、なるべくそのまま残す。こちらの言葉に言いかえると、意味がずれる
- 一つのことは一つの文書にだけ書き、ほかの文書からは「`世界観設定.md` の〇〇」と指す。同じことを二か所に書くと、片方だけ直って食い違う
- 決めた理由がある設定は、理由も書く（「精力剤は別荘に用意してある。4人は当たりと知らずに来ているので」）。理由がないと、あとで別の場面と食い違ったときに直せない

## 企画メモ.md

作品の芯と、決まったことの一覧。最初に芯を書き、膨らむたびに育てる。

| 節 | 中身 |
|---|---|
| 決まったこと | 題材、ヒロイン、相手役、人数、主導権、視点、舞台、分量（決めないなら「決めない」と書く）など。表にする |
| コンセプト | なぜこの話なのか。数行で |
| 読後感・空気 | 読み終わったとき一番に残るもの（例：「抜けた」）。気持ちの軸、空気（背徳か、楽しさと親しさか） |
| まだ決めていないこと | タイトル、結末、発表先など。たたき台があればそれも |
| 流れのたたき台 | 番号つきで、出来事を並べる。各場面に相手役の目線（何を感じているか）を添えると、物語と気持ちが一緒に流れる |

タイトルは中身が決まってから、最後につける。先にタイトルを決めて、流れをタイトルに合わせない。

## 世界観設定.md

物語が成り立つための、世界のルール。

- **表の設定**：物語の中で出てくる、または人物が知っていること
- **裏設定**：書き手が頭の中で補うためのもの。本筋には出さない。節を分けて「本筋には出さない」と書く
- 表にする（項目・内容）。長い説明は書かない
- 現代でも、性に関するところだけ例外になるなら、その例外を書く（「世間の常識は現実と同じ。事務所の裏側だけが例外」）
- 用語（呼び名）を決めたら、ここに置く

## キャラクター設定.md

- 図鑑（`小説/キャラクター/`）の人を使うなら、図鑑を写さない。この作品での違い（年齢、立場、関係）と、この作品で何が欲しいかだけ書く
- 相手役：人物像、立場、読者が自分を重ねるか（名前を伏せるか）、台詞の温度
- 二人（または全員）の関係：何年の関係か、何に慣れていて何に慣れていないか、主導権、呼び方
- エロでどう崩れるかは、ここで決めきらない。性格から崩れ方を逆算しない（`pitfalls.md`）

## アウトライン.md

> リレーで書く作品では作らない（`SKILL.md` の「リレーで書く作品」）。

話・章の切り方だけを書く。中身は企画メモの流れを指す。

| 話 | 中身 | 切るところ |
|---|---|---|

- 切るところは、読者が次を読みたくなるところ。緩む時間（食事など）で終わる回を作らない
- 1章だけで抜けるように作るなら、そう書く（オムニバス、AVの1本のように）
- 分量は先に決めない。内容で決まる
- 話の数がまだ仮なら、（たたき台）と書く

## プロット/〇〇.md

> リレーで書く作品では作らない。作者が毎回書く続きが、プロットの代わりになる。

1話・1章ずつ作る。**台詞を書きこまない。** 台詞は本文で、場面を頭の中で流しながら作る。プロットは、本文を書く人が迷わないための骨だけ。

**全体**（その話を通して）
- 時間と光、空気（どう濃くなっていくか）
- 相手役の変わり方、ヒロインの気持ちの向き
- 切るところ

**場面ごと**
- 場面の名前（何をしている場面か、体位、明るさ）
- 空気、主導権、気持ちの向き
- 必ず入れるもの（作者が決めたこと、前の話から引き継ぐもの）
- 入れないもの（作者に直されたことなど）
- ゴール（この場面で何が起きたら次へ行くか）
- 喘ぎの強さ（どこがピークか。`spicy_novel_jp` の `references/aegigoe_skills.md` のレベル）

どうしても残したい台詞は「決め台詞」と書く。それ以外の台詞の案は「草案。本文で変えてよい」と書く。

## 作者との決め方

- **聞く前に、たたき台を出す。** 「どうしますか？」だけで返さない。案と、こちらの一押しと、理由を出す
- 作者の答えが要ることだけを聞く。作品の中で決められることは、たたき台にして進める
- 一度に聞くのは少なく。大きな向き（何の話か）から先に聞く
- 作者の一言を受けたら、その一言だけを当てはめない。企画の根っこと、すでに決まったことの中で考える（`pitfalls.md`）
- わからないことは、推測で決めない。自分の受け取り方を言葉にして返して、確かめる
- 決まったら、すぐ文書に書く。（たたき台）を外す
