# 「どんなものにしたいか」から膨らませる

> 最初にあるのは、大雑把な枠。「国民的アイドルの裏オフに当選したら、メンバーが本気でおもてなししてきた」「卒業した子たちと、こっちの卒業式をする」くらいのもの。そこから、物語と設定を一緒に、一段ずつ細かくしていく。

## 芯：どんなものにしたいか

膨らませる前に、芯をつかむ。作者の「こんな感じ」を、作者の言葉のまま置く。

| 芯の中身 | 例 |
|---|---|
| 何の話か（一文） | 卒業してから、久しぶりに〇〇と会えて、「こっちの卒業式」をする |
| 読後感 | 「抜けた」が一番に残る／甘く幸せ／堕ちる |
| 空気 | 背徳感より楽しさと親しさ。「ヤバい」と笑い合いながら、本気で気持ちよくなる |
| いちばん見たい絵 | 4人が並んで、とろけた顔で「誰からがいい？」と見上げる |
| 気持ちの軸 | 「終わる」寂しさではなく、「会えた」嬉しさ |

- 全部そろっていなくていい。作者が言ったものだけでいい
- 芯がぼやけていたら、膨らませる前に作者と詰める。聞くときは、芯の候補を2〜3出して「どれに近いですか」と聞く
- 芯は `企画メモ.md` の頭（コンセプト・読後感・空気）に書く。あとの段は、いつもここに戻って確かめる

## 大枠：流れと、それが成り立つ大きな設定

芯から、大雑把な流れを考える。流れを考えると、それが成り立つための大きな設定が一緒に出てくる。

- **流れ**：始まり（どう入るか）、山（いちばん抜けるところ）、終わり（どこで切るか・読後に何が残るか）
- **大きな設定**：世界（現代か、例外はどこか）、場（どこで、どんな集まりか）、関係（二人・全員は、どういう間柄か）、主導権（誰が誘う側か）

流れを一つ置くたびに「これが成り立つには、何が本当でないといけない？」を見る。設定を一つ置くたびに「これで、流れはどう動く？」を見る。

大枠が見えてきたら、「この大枠なら、設定はこうした方が良さそう」を考える。見るところと出し方は `settings_from_frame.md`。

**大枠で決めないこと**：細かい場面、台詞、小道具、数字。大枠が揺れているうちに作りこむと、あとで全部やり直しになる。

## 中くらい：切り方と、仕組みの中身

> リレーで書く作品では、大枠（超ざっくり）と設定まででリレーに渡す。中くらい・細部の物語は作らない（`SKILL.md` の「リレーで書く作品」）。設定は、この段の「設定」まではそろえてよい。

大枠が決まったら、もう一段細かくする。

- **物語**：話・章の切り方（`アウトライン.md`）、人ごとの欲しいもの、相手役の変わり方、緩急（緩む時間をどこに置くか）
- **設定**：仕組みの中身（どう選ばれるか、決まりは何か）、時間と場所の区切り（2泊3日、1本ずつ）、人物の立場と経歴

ここでも、片方を決めると、もう片方が一段はっきりする。山を2日目にすると、そこまでもたせる仕掛けが要る。「1本ずつ撮る」と決めると、各章はそれだけで抜ける1本になる。

## 細部：場面と、裏設定

最後に、場面（`プロット/`）、小道具、数字、裏設定。

- 細部は、芯と大枠に効くものだけ作る。効かないものは作らない
- 場面を流していて「なんで？」と引っかかったところだけ、理由を設定に足す。本筋に出さないなら、裏設定に分ける
- 数字（年齢、年、回数）は、ほかの設定と食い違わないか見る

## 戻るとき

- 作者に直された、食い違いが出た、案が選べない → 芯に戻って、「どんなものにしたいか」に効くほうを選ぶ
- 細部を変えて大枠が揺れるなら、先に大枠を作者と決め直す
- 一つ変えたら、同じ段と上の段に響くところを見る。片方の文書だけ直さない

| 変えたもの | 確かめる先 |
|---|---|
| 世界のルール・仕組み | その仕組みを前提にした場面、人物の知っている・知らない |
| 人物の関係・過去 | 照れ・慣れ・ためらいの有無、呼び方、主導権 |
| 年齢・時期・数字 | 経歴の年、ほかの人物との年の差、時代の小道具 |
| 場面の順番 | 体の回復（出せる回数）、時間帯と光、誰がもう知っているか、前の場面の熱 |
| 場面を足す・消す | その場面でしか決まっていなかった設定、その場面に頼っていた次の場面 |
| 山場の位置 | 緩む時間の置き場所、話の切るところ |

## 段ごとに使える問い

考えに詰まったときに使う。順に全部答えるものではない。

- **芯**：読み終わったとき、何が残ってほしい？　いちばん見たい絵は？　この話は、ほかの話と何がちがう？
- **大枠**：いちばん抜けるのはどこ？　それは、この場・この関係でしか起きない？　主導権はどちらにある？　始まりで読者は何を知っている？
- **中くらい**：どこで切ると次を読みたくなる？　人ごとに何が欲しい？　決まり・制限から、どんな場面が生まれる？　緩む時間はどこ？
- **細部**：この場面で読者が「なんで？」と止まるところは？　この道具はなぜそこにある？　この人はなぜそれを知っている／知らない？

## 実例（このリポジトリの作品から）

> 膨らみ方の参考。作品の中身はほかの作品に持ちこまない。

**裏オフ（`novel_offkai`）**
- 芯：国民的アイドルの裏オフに当選したら、メンバーが本気でおもてなししてきた。読後感は「抜けた」。主導権はアイドル側
- 大枠：招待状 → 別荘 → 「何をしてもいい」 → 当たり → 2泊3日。設定は「事務所の裏の恒例行事。口外しないこと以外は何をしてもいい」「男は当たり（ちんこ）」。当たりだから、メンバーはもてなしたい自分と、ガチでヨガる自分が混ざる
- 中くらい：1日目・2日目（山場）・3日目（帰る日）の切り方。設定は抽選とメンバーのOK、迎えの車の同意書、四半期に1回だから「去年の人の倍ある」と比べられる
- 細部：2日目に出せる回数が足りなくなる → 別荘に精力剤が用意してある。4人は当たりと知らずに来ているので、自分たちで持ってきたものではない

**卒業記念AV撮影（`novel_shinomiya`）**
- 芯：表の卒業は済ませた。〇〇との「こっちの卒業式」をまだしていない。空気は背徳感より楽しさと親しさ。読後感は「抜けた」
- 大枠：会議室で〇〇が言い出す → 企画会議 → 1人ずつ撮る。設定は「〇〇が相手をするのは運営公認の業務」「全員卒業生」。慣れた関係なので、セックスへの照れは書かない。ヤバいのは「卒業記念のAVにする」発想のほう
- 中くらい：1本＝1章、各章はそれだけで抜ける1本。4人が5本ずつ「やりたいこと」を出す（1本は「やりたくない枠」。それも本人が選んだもの）
- 細部：卒業生なので全員2歳上げる。本ごとに日程・場所・コンセプトを決める
