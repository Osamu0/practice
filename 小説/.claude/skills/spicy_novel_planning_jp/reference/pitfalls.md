# 企画でずれやすいところ

> このリポジトリの作品で、作者に何度も直されたこと（`小説/novel_offkai/作者に言われたこと.md` など）のうち、企画とプロットに効くもの。案を出す前と、作者に見せる前に読む。

## 考え方

| ずれ | 直し方 |
|---|---|
| 設定の表を順に埋めて、物語はそのあと。または、場面を並べてから理由をつける | 「どんなものにしたいか」を芯にして、物語と設定を一緒に、一段ずつ膨らませる（`expand.md`）。項目を埋めることが目的にならないようにする |
| 大枠が決まらないうちに、細部を作りこむ | 芯 → 大枠 → 中くらい → 細部の順に細かくする。細部は芯と大枠に効くものだけ |
| 「こういう性格の人だから、エロではこうなる」と逆算する | 図鑑や設定の性格は、ふだんの人。エロでどうなるかは決まっていない。読者が抜けるかで考える |
| 確かめることを、作ることだと思う | 食い違いの点検や手直しは、物語を考えたことにならない。先に「この話は何の話で、読者は何で抜けるか」を考える |
| 言われた一言を、そのまま全部に当てはめる | それは言いなり。言われたことの中身を、企画の根っこと決まったことの中で考える |
| 言われたことを直すだけで出す | 直すついでに、全体を見直して、自分からもっとよくできるところ（山の作り方、体位、場面の順番）を出す |
| 「白紙から考えた」と言って、前の案の順番を使う | 白紙なら、前の案の並びを使わない |
| 食い違いを、説明の一行を足してふさぐ | その場面・その設定が、本当に要るかを先に考える。要らないなら消す |
| 狙いや「こう直しました」の筋道が、そのまま案に透ける | 読者に見せるのは物語。直した理由の説明を、場面や台詞に持ちこまない |

## 設定

| ずれ | 直し方 |
|---|---|
| 物語に効かない設定を、たくさん作る | 本筋に出さないものは裏設定に分ける。裏設定も、場面の「なんで？」を埋めるためのものだけ |
| 読者がもう知っていることを説明する（アイドルの表の顔、ポスター、テレビ） | 読者は知っている前提で読む。説明の場面を作らない |
| 慣れている関係なのに、初めての緊張やためらいを入れる | 関係の設定から、照れ・抵抗の有無を決める（`expand.md` の「戻るとき」） |
| 人物が乗り気でいられる前提がない | 同意、慣れ、記念、欲しさなど、その人がやりたいと思える前提を設定で用意する。嫌々やる形にしない（作品がそれを狙う場合を除く） |
| 本当は効くものを、思い込みやどんでん返しにする | 作者が「本当に効く」と決めたら、ひっくり返す仕掛けを入れない |
| 実在のもの（薬の名前、手に入れ方、量）を書く | 架空のものにする。仕組みと効き方だけを書く |

## 物語

| ずれ | 直し方 |
|---|---|
| 行為が終わったところで温度が下がる。場面が変わると距離ができる | 場面が変わっても、直前の熱と体の近さを引き継ぐ流れにする |
| 切ない・しんみりした空気で締める | エロ物語として、欲しくてたまらない熱のまま切る（作品の読後感がそうでない場合を除く） |
| 一人ずつ順番に待つ形になる（複数のとき） | 誰がつながっていても、残りは相手役の体のどこかにいる |
| 相手役が一歩引いて、従うだけ | 相手役も同じ熱で乱れる。変わり方（受け身 → 自分から → わかってやる）を流れに置く |
| 山が早すぎる、すぐ終わる | 入れてすぐ崩さない。何往復もかけて崩れる。いちばんの山を話ごとに一つ決める |
| 緩む時間（食事・風呂・眠り）がない、または緩む時間で話を切る | 緩急の緩は、話の途中や頭に置く。緩む時間はちゃんと楽しく、エロの仕掛けはそのあとに |
| 場をいじる笑い、ツッコミの掛け合いで流れを止める | 笑いはエロの流れの中で。流れからそれる笑いは入れない |
| 企画の根っこが、話ごとに抜ける | 企画メモのコンセプト・読後感を、プロットの全体の節に毎回書く |
| AVの企画のような作品で、チャプターで場面を区切る | 作品の決めに合わせる。途切れずにつながる（シームレス）と決めたら、区切らない |
