# 大枠から、設定を考える

> 「大枠はこんな感じ。だから、設定はこうした方が良さそう」を考えて、作者に出す。設定を足すだけでなく、変える・削るも入る。設定のよしあしは、設定だけを見ても決まらない。大枠（と芯）がもっと効くかで決まる。

## 見るところ：この設定で、大枠のどこが良くなるか

| 観点 | 問い |
|---|---|
| 山が強くなる | いちばん抜けるところが、この設定でもっと抜けるか。この設定でしか起きない山になるか |
| 欲しさが生まれる | 誰が、何を、なぜ欲しがるか。人物が乗り気でいられる前提があるか |
| 落差が生まれる | ふだんの顔と、崩れた顔の差が大きくなるか。きちんとした人、慣れている人、上の立場の人が崩れるか |
| 主導権がはっきりする | 誰が誘う側か、が設定から自然に決まるか |
| 決まり・制限が場面を生む | 決まりや区切り（口外しない、1本ずつ、2泊3日）から、場面が生まれるか |
| 「なんで？」が消える | 大枠の流れで、読者が止まるところがなくなるか |
| 読者がすぐ入れる | 説明しなくても伝わるか。読者がもう知っていること（アイドル、AV、オフ会）を使えるか |
| 熱が続く | 場面が変わっても、熱が下がらない前提になっているか |

一つの設定で、全部が良くならなくていい。大枠のいちばん大事なところ（たいてい山と欲しさ）が良くなるものを選ぶ。

## やめた方がいい設定

- 大枠に効かない。あってもなくても流れが変わらない（作るなら、本筋に出さない裏設定に）
- 説明が要る。本文で設定を説明する場面が要るなら、もっと伝わりやすいものにできないか考える
- 空気を冷やす。しんみり、けが、痛み、罪悪感（作品の芯がそれを狙う場合を除く）
- 人物が嫌々やる形になる（同上）
- ほかの設定と食い違う。食い違いを説明の一行でふさぐ前に、どちらかが要らないかを考える
- 流れをエロからそらす。理由のない場面が生まれる（例：裏オフで「シアタールームでライブ映像を流す」はやめた。4人がオフにわざわざ流す理由がない）

## 作者への出し方

一度に出すのは3〜5個まで。大枠に効く大きいものから。

| 今の設定（なければ「なし」） | こうした方が良さそう | 大枠のどこが良くなる | 代わりに変わるところ |
|---|---|---|---|
| | | | |

- 「代わりに変わるところ」を必ず書く。すでに決まった場面や設定が動くなら、それを先に見せる（`expand.md` の「戻るとき」）
- 案は向きのちがうものを2〜3。こちらの一押しと理由をつける
- 作者が決めた設定を変える案は、「変えた方がいい」と言い切らず、理由をつけて聞く
- 決まったら、設定は `世界観設定.md`・`キャラクター設定.md`、流れは `企画メモ.md` に書く。（たたき台）を外す

## 実例：設定が大枠に効いているところ（このリポジトリの作品から）

> 考え方の参考。作品の中身はほかの作品に持ちこまない。

**裏オフ（`novel_offkai`）**　大枠：当選した男を、メンバーが本気でもてなす。主導権はアイドル側

| 設定 | 大枠のどこに効いているか |
|---|---|
| 事務所が抽選し、メンバーがOKを出したら決定 | メンバーが自分で選んだ相手なので、乗り気でもてなせる（欲しさ・主導権） |
| 口外しないこと以外は何をしてもいい | 説明一つで何でも起きる場になる。男がドッキリを疑う入りが生まれる（読者がすぐ入れる・場面） |
| 四半期に1回。毎回、出るメンバーは一部 | 前の男と比べられる（「去年の人の倍ある」）。当たりは久しぶりなので、ガチでヨガる（山） |
| 当たりの理由はちんこ。本人は意識していなかった | 下着を下ろした瞬間の反応が山になる。男は、4人の顔で自分が特別だと知る（落差・山） |
| 精力剤は別荘に用意してある | 2日目の山場までもつ。4人は当たりと知らずに来ているので、自分で持ってきたものではない（「なんで？」が消える） |

**卒業記念AV撮影（`novel_shinomiya`）**　大枠：卒業した4人と、「こっちの卒業式」として1本ずつ撮る

| 設定 | 大枠のどこに効いているか |
|---|---|
| 〇〇が相手をするのは、現役中から運営公認の業務 | セックスへの照れがいらない。「ヤバい」のは卒業記念のAVにする発想のほう、と笑える（空気・熱が続く） |
| 全員卒業生 | 表の卒業は済んで、「こっちの卒業式」がまだ、という芯がそのまま立つ |
| 「やりたくない枠」も本人が選んだもの | 普段やらないことをやっても、嫌々にならない（欲しさ・落差） |
| AV撮影は話のアイデア。カメラを意識しすぎない | 撮影の段取りより、エロに集中できる（流れをそらさない） |
