# 第3部 あすか編 4話：もっと

あすか編の山場。3話の終わり（まいとななせが、あすかの目の前でちんぽに頬ずりしている）から続く。あすかが思わず手を伸ばし、2人はタイミングを見て帰っていく。あすかは、自分の家で、ファンと2人きりで残される。2人きりで、〇〇がトドメを刺し、あすかが照れずに本音を言って、ほぼ完堕ちに届く。

- **あすか**：お酒で少しゆるんでいるが、状況はわかっていて、自分で手を伸ばす。最後の一言は、あすか自身のもの。崩れたあと、口調の反転（照れずに、甘く下品にとろける）がほんの少しだけ顔を出す。事後は、まだ気だるさと「かも」で濁す感じが残る
- **〇〇**：敬語とタメ口が混じる。あすかの「なにその顔」のようなツッコミは、まだ完堕ちしていないあすかだけのもの
- **まいとななせ**：完堕ち。あすかが手を伸ばしたら、タイミングを見て、2人きりにする
- **呼び方の語彙**：「おちんちん」「おちんぽ」「ちんぽ」を混ぜる

## 場面1：手を伸ばす

- **流れ**：まいとななせが、あすかの目の前で頬ずりしている。ななせが「あすかちゃんの顔と、おんなじくらいあるで」と言う。まいが「乗せてみよっか」と、〇〇のちんぽを、あすかの顔にそっと乗せる。根元が顎に当たって、先が頭のてっぺんまで届く。あすかは「……は？　うそでしょ」と笑いかけるが、すぐに笑いが消える。鼻のすぐ上に、熱くて重いものが乗っている。匂いが、まっすぐ入ってくる。頭がぼうっとして、さらに疼く。あすかは目を閉じて、もう一度、匂いを吸ってしまう。気づいたら、あすかの手が伸びている。指先で触れる。熱い。硬い。脈打っている。あすかは何も言わずに、握る
- **決め台詞**：なし
- **エロの中身**：ちんぽをあすかの顔に乗せる（顎から頭のてっぺんまで。小顔との比較）。匂いを嗅いで、さらに疼く。あすかが自分から手を伸ばして、触れて、握る
- **位置関係**：〇〇はソファの前に立つ。まいとななせがその前にしゃがむ。あすかはソファに浅く座り直して、身を乗り出す。〇〇のちんぽが、あすかの顔に乗る
- **感情の流れ**：（あすか）……顔と同じとか、ありえない → 笑いが消える → 匂いで頭がぼうっとする → さらに疼く → もう一度、嗅いでしまう → 気づいたら手が伸びていた → 熱い

## 場面2：2人が帰る

- **流れ**：あすかが握ったのを見て、まいとななせは顔を見合わせる。まいがあすかの耳元で「あとは、2人でね」とささやき、ななせと一緒に立ち上がって、バッグを持つ。「じゃあ、私ら帰るね」「あすかちゃん、明日オフやし、ゆっくりな」。玄関のドアが閉まる音。自分の家のリビングに、あすかと〇〇が2人きりで残る。あすかは「……え、ほんとに帰るの」と言うが、手は離さない。〇〇が「……さわって、くれますか」と頼む。あすかは小さく笑って、手を動かしはじめる
- **決め台詞**：なし
- **エロの中身**：あすかの手コキ。〇〇の敬語のお願い
- **位置関係**：あすかはソファに座ったまま、前に立つ〇〇のちんぽを握る。まいとななせは帰っていて、もういない
- **感情の流れ**：（あすか）2人が帰って、ちょっとだけ我に返る → 自分の家に、ファンと2人きり → でも、手が離れない → まあ、いいか （〇〇）あすかちゃんの家で、あすかちゃんと、2人きり

## 場面3：口で、そして崩れる

- **流れ**：あすかは手で触っているうちに、顔を近づけて、口に含む。小さな口に収まりきらない。〇〇はソファの前に膝をつき、あすかのスカートの中に手を入れる。あすかはパイパンで、もうとろとろに濡れている。〇〇が「やば……」と言うと、あすかは目を逸らして「……見ないでよ」。〇〇が調子に乗りかけて「あすかちゃん、もうこんなに」と言うと、あすかは「……なにその顔」と返そうとするが、匂いと疼きで頭がぼうっとしていて、声に力がない。言い終わる前に、〇〇の指が入って、ツッコミが続かなくなる（まだ完堕ちしていないあすかだけのツッコミだが、もう弱い）。控えめな声が抑えきれなくなり、〇〇への敬語も崩れる
- **決め台詞**：あすか「……なにその顔」（方向。弱く、言い切れない。言い回しは本文で調整する）
- **エロの中身**：フェラ（小さな口に収まりきらない）→ 下着を脱がせる（パイパン）→ クンニ → 手マンで初めて潮を噴く。喘ぎ声はレベル1 → 2。控えめな声が、少しずつ抑えきれなくなる
- **位置関係**：あすかはソファに浅く座る。〇〇は床に膝をつき、正面から
- **感情の流れ**：（あすか）咥えてみたかった → 見られて恥ずかしい → ツッコもうとするが、力が入らない → ツッコめなくなる → 噴いてしまった恥ずかしさ

## 場面4：〇〇がトドメを刺す

- **流れ**：〇〇が、そのままの体勢で挿入する。大きすぎて、あすかは息が止まる。細い腰が浮く。ゆっくり奥まで入る。あすかの控えめな声が抑えきれなくなる。〇〇への敬語も、完全に崩れる。どこかで、あすかの力がふっと抜ける。「まあ、いいか」と、取り繕うのをやめる
- **決め台詞**：なし
- **エロの中身**：ソファでの正常位（〇〇は床に膝立ち）。あすかの片脚を〇〇が抱える。喘ぎ声はレベル2〜3
- **位置関係**：あすかはソファに浅く座り、背もたれに背中を預ける。〇〇は床に膝立ちで、正面から、あすかの片脚を抱えて
- **感情の流れ**：（あすか）入らない → 入った → 抑えたい → 抑えきれない → 力が抜ける → まあ、いいか

## 場面5：本音を言う

- **流れ**：床のラグに移り、〇〇が上から深く突く。あすかは、照れも冗談もなしで、正面から〇〇を見て、本音を言ってしまう。ここで、ほぼ完堕ちに届く。そこから、何度もイく。崩れた口から、甘くとろけた声がほんの少しだけこぼれる（口調の反転の最初の芽）
- **決め台詞**：あすか「……もっと、して」
- **エロの中身**：正常位 → 〇〇があすかの脚を肩にかけて、深く。中出し。連続絶頂。喘ぎ声はレベル3 → 4
- **位置関係**：ラグの上に、あすかが仰向け。〇〇が上から
- **感情の流れ**：（あすか）照れ隠しが追いつかない → 正面から言ってしまう → ほぼ完堕ち

## 場面6：事後

- **流れ**：ラグの上で、あすかは息が上がったまま、蕩けている。〇〇が「……大丈夫？」と聞く。あすかは一瞬だけ照れて目を逸らすが、すぐに、蕩けたまま素直に言う。気だるさと、「かも」で少しだけ濁す感じは残っている。ローテーブルの上で、あすかのスマホが光る。同期3人のグループLINEに、まい『どうだった？♡』、ななせ『あすかちゃん、生きてる？』。あすかはそれを見て、ふっと笑って、返事をせずにスマホを伏せ、〇〇のちんぽに手を伸ばす

- **位置関係**：あすかの家のリビングのラグの上。あすかと〇〇の2人だけ。あすかは仰向けのまま、〇〇は横に寄り添う
