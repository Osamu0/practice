# 世界観設定

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。
> 印のない行は作者が決めたこと。**（たたき台）** はこちらで仮に決めたもので、変えてかまわない。**（未定）** はまだ誰も決めていない。

## 世界

| 項目 | 内容 |
|---|---|
| 時代 | 現代。世間の常識は現実と同じ |
| 年代 | 気にしない。図鑑の歴史（何年の話か、卒業）は使わない |
| ご都合 | 理由は説明しない。話がすいすい進み、女の子がすぐその気になる（`企画メモ.md` の「ご都合主義の意味」） |
| 妊娠・避妊 | **（たたき台）** 物語の中で気にしない。生でも中でも、誰も心配しない（男の願望「全部許される」のため） |

## グループ

| 項目 | 内容 |
|---|---|
| グループ | {桜ヶ丘|さくらがおか}40。国民的トップアイドルグループ。表の顔は図鑑の `小説/キャラクター/桜ヶ丘40/グループ設定.md` の「イメージ」（清楚で上品、高嶺の花） |
| メンバー | 図鑑のメンバーは全員在籍している。性的な場面に出るのは18歳以上だけ（この作品では全員18歳以上にしている。`キャラクター設定.md`） |
| ファンとの距離 | 握手会、ライブで会える。会えるけれど遠い |

## 事故と両腕

| 項目 | 内容 |
|---|---|
| 事故 | 男が女（メンバー）を車から助けて事故にあい、両腕を骨折する |
| 両腕 | **（たたき台）** ギプスで、両手がまったく使えない。治るまで2か月くらい。食べる、着替える、お風呂、トイレ、性処理まで、全部だれかの手が要る |
| 場所 | **（たたき台）** はじめは病院の個室。退院したあとは、〇〇の実家の2階の部屋 |
| 事故の扱い | **（たたき台）** 表には出さない。メンバーが恩人の世話に通うのは内緒。運営は、表立っては知らない |
| 増える入口 | **（たたき台）** 「恩人へのお礼」が、どの子にとっても来る理由になる。どう増えるかはリレーで書く |
