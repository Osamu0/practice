# 企画メモ

> 本作はすべてフィクションであり、実在の人物・団体とは一切関係ありません。登場人物はすべて18歳以上の成人です。実在のグループやメンバーの名前・特徴は使いません。
> 2026-11 に全部白紙から作り直した。前の企画は `小説/novel_idol/旧/` にあるが、新しい設定には混ぜない。

## 芯（作者の言葉）

> 性的エロ話。国民的アイドルグループとエロエロハーレム。ご都合主義というか、エロ漫画っぽい感じ。
>
> 男の願望を詰めたエロ話にしたいんだよね。

迷ったら「これは男の願望か」で決める。読者（男）が「こうされたい」と思うものを選ぶ。

## 詰めたい男の願望（たたき台）

リレーで「次に何をするか」を選ぶときの引き出し。順番も、全部入れるかも決めない。作者が選ぶ。

| 願望 | 両腕骨折で効くところ |
|---|---|
| 推しに尽くされる | ご飯を「あーん」、着替え、歯みがき。手が使えないので断れない |
| 何もしなくていい、全部してもらえる | お風呂で全身を洗ってもらう。トイレも。性処理も「手が使えないから」で始まる |
| 自分にだけ見せる顔 | テレビの清楚な顔のまま、〇〇の部屋でだけ乱れる |
| 取り合われる | 増えた子たちが、お世話の当番や「次は私」を取り合う。でも揉めない |
| 大きさ・強さを褒められる | 「こんなの初めて」「すごい」と本気で言われる |
| 全部許される | 生で、中で、何回でも。嫌がられない |
| 衣装で | ステージ衣装、制服風の衣装、私服のまま |
| 秘密の特別扱い | 握手会やライブで、ほかのファンの前で自分にだけ合図をくれる |
| 何人も同時に | 両手が使えないぶん、何人もが体のあちこちにいる |
