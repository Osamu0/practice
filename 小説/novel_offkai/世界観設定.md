## 裏オフとは

| 項目 | 内容 |
|---|---|
| 呼び名 | 裏オフ。メンバーも事務所の人間も、この名前で呼ぶ |
| 正体 | 事務所の裏の行事。公には存在しない |
| 公認 | 事務所公認。運営の一部の人間だけが知っている |
| 主催 | メンバー。当日のもてなしは、すべてメンバーが自分たちで考える |
| 唯一の決まり | **口外しないこと。それ以外は何をしてもいい** |
| 頻度 | 四半期に1回（年4回）。回数が多いぶん、当たり外れも多い。毎回、出るメンバーは一部 |
| 参加できる人 | 現役のメンバーと、卒業したメンバー。卒業しても参加できる |
| 始まり | 2014〜2015年ごろ、グループの人気が出てきたころ、メンバーの1人がスキャンダルを週刊誌に撮られた。事務所は、恋愛を禁止して抑えつけるのをやめて、メンバーの性欲を事務所の中で管理することにした。裏オフは、そのうちの、ファンを相手にする、四半期に一度の場。撮られたのは、図鑑で作っていない1期生の1人（名前は出さない。当時18歳以上）。相手は誰か、その後どうなったか（卒業など）は **（未定）** |
| スキャンダルのあと | 人気が出てきたさなかの出来事だったので、ほかのメンバーには、撮られたメンバーへの怒りや、許せないという気持ちがあった。同時に、自分たちも性欲を発散したくなっていた |
| 運営の決定 | メンバーから不満をぶつけられた運営が、当時の全メンバーに向けて、そういうことをする（事務所の中で性欲を管理する）と告げた。当時未成年だったメンバーも、その場にいて、仕組みがあること自体は知っている。加わるのは18歳になってから |
| 始まりを知っている人 | 1期生は、裏オフが始まったときからいる。2018年の4人は、始まりを知っている当事者 |
| メンバーにとっての裏オフ | ふだんの相手は、仕事として抱くマネージャーや、年上のお偉いさん。裏オフは、四半期に一度、自分たちで選んだ若いファンを相手にできる場。毎回の楽しみにしている。だから、外れの回が続くと不満がたまるし、当たりの回は特別になる **（たたき台）** |

## 事務所の裏側（裏設定）

> 書き手が頭の中で補うための裏設定。本筋には出さない。上の「始まり」「スキャンダルのあと」「運営の決定」も同じ。

裏オフは、事務所がメンバーの性欲を管理する仕組みの一つ。ほかにもある。

| 項目 | 内容 |
|---|---|
| 仕込み | マネージャーや事務所のお偉いさんが、メンバーの相手をする。メンバーは、テクニックや男の悦ばせ方を仕込まれている |
| メンバーの性欲 | 全員、性欲が強め |
| 仕込みのあと | 仕組みに入った成人メンバーは、すっきりして、色っぽくなっていった |
| 年齢 | この仕組みに入るのは、18歳になってから。18歳未満で加入したメンバーは、18歳になるまで外にいる（あすかは2016年から。3期は2017〜2018年から） |
| ふだんの相手と、〇〇の違い | **（たたき台）** マネージャーは仕事として抱く。お偉いさんは年上で、メンバーが悦ばせる側に回る。だから、若いファンの体で、しかも当たりを引くことはめったにない |
| 誰が知っているか | **（未定）** 運営の一部。仕込みの相手になるマネージャーやお偉いさんは誰か |

## 〇〇が選ばれるまで

| 段階 | 内容 |
|---|---|
| 1. 事務所の抽選 | 事務所が抽選する |
| 2. メンバーのOK | 抽選で選ばれたファンに、メンバーがOKを出したら決定 |
| 抽選の対象 | **（たたき台）** ファンクラブの会員のうち、成人で、一定のファン歴がある人。本人は抽選の対象になっていることを知らない |
| メンバーが見るもの | **（たたき台）** 事務所が作った簡単な資料（写真、ファン歴、握手会やイベントでの様子）。握手会で顔を覚えているメンバーもいる |
| OKの出し方 | **（たたき台）** 参加するメンバー全員のOKが必要。1人でも嫌と言えば、抽選をやり直す |
| 〇〇への知らせ | **（たたき台）** 事務所から、封書で招待状が届く。表向きは「ごく少数の会員だけを招く特別オフ会」。「メンバーが心を込めておもてなしする」とだけあり、何が行われるかは書いていない。あとは日時と迎えの場所、「口外しないこと」の一文（第1話の本文に合わせた） |
| 迎え | 運営の人間が、車で迎えに来る。メンバーは同乗しない |
| 〇〇の同意 | **（たたき台）** 迎えの車の中で、運営の人間から同意書を渡されて署名する。ここで帰ることもできる。裏オフが何なのかは、車の中では詳しく聞かされない |
| 裏オフの説明 | 別荘に着いてから、その回の説明役のメンバーが〇〇に話す。1期の回はまなつ |
| 推薦 | 抽選のほかに、メンバーの推薦で招かれることがある。前の回のメンバーが「当たりだった」と感じたファンを事務所に推薦しておくと、事務所が次の回に、抽選の外で招く。めったにない |

## 世界観がエロスにどう効くか

- **ステージの上の存在が、手の届く距離にいる**：テレビやライブで見ていた本人たちが、同じ屋根の下で〇〇だけをもてなす。
- **何をしてもいい**：唯一の決まりが「口外しない」なので、行為に上限がない。何をするかは、メンバーそれぞれの「やりたいこと」で決まる。
- **メンバーが主催で、主導権もアイドル側**：〇〇は招かれた客。メンバーがもてなしを考え、誘い、甘やかし、からかう。
- **いつもの行事**：四半期ごとに何回もやってきたので、メンバーにとっては「いつものこと」。もてなしにも見送りにも決まった形がある。だから、当たりを引いたときの崩れ方が際立つ。
- **2泊3日**：3日目は帰る日なので、2日目が山場になる。
