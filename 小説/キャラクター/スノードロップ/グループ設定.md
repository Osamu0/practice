# スノードロップ グループ設定（たたき台）

> 架空のアイドルグループ。実在のグループ・メンバー・楽曲・出来事とは一切関係ありません。実在のグループの歴史・人数・期の分け方をなぞらない。
> メンバーは全員、加入した時点で18歳以上（`../README.md` の「年齢の決まり」）。
> 桜ヶ丘40とは別のグループ。設定を混ぜない。
> 以前あった架空のグループ「ミルフィーユ」はなくし、そのメンバーだった与田ひなのをこのグループに移した（2026年11月）。

## 決まったこと

| 項目 | 内容 |
|---|---|
| グループ名 | スノードロップ（愛称：スノド）**（たたき台）** |
| 人気 | 国民的トップアイドルグループ |
| 規模 | 大所帯 |
| 恋愛 | 禁止。運営いわく「バレたら打首獄門」。本当にそこまでの処分があるのかは、メンバーも誰も知らない |

## たたき台

| 項目 | 内容 |
|---|---|
| 結成 | 2017年 |
| 人数 | 結成時は24人。その後の加入と卒業で、2023年の時点で30人前後 |
| 加入 | オーディションとスカウトの両方。「期」ではなく、加入した年で呼ぶ（「2017年組」など） |
| 売れ方 | 2019年、CMソングが話題になって一気に知られる |
| 事務所 | 大手の芸能事務所（名前は未定） |
| リーダー | 未定 |

## イメージ（たたき台）

- 名前の由来は、雪の中で最初に咲く白い花。
- 清楚で、白が似合う。衣装は白が基本。
- 可愛らしさと、芯の強さ。
- テレビで毎週見る「知っている顔」。

## 歴史の流れ（たたき台）

| 年 | 中身 |
|---|---|
| 2017 | 24人で結成。オーディション組とスカウト組がいる。白石飛鳥（18歳）と与田ひなの（19歳）は、このときの結成メンバー |
| 2019 | CMソングが当たって、ブレイク |
| 2020〜2022 | ドームツアー。メンバーそれぞれにドラマ・バラエティ・CM・モデルの仕事が増える。新しいメンバーの加入もある |
| 2023 | 年末の歌番組の常連に。国民的トップアイドルグループと呼ばれる |
