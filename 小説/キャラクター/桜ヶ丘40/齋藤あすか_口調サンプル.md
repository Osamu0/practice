# 齋藤あすか 口調サンプル（たたき台）

> 架空の人物。実在の人物とは一切関係ありません。
> キャラを作るための参考資料。台詞として本文にそのまま使う必要はない。口癖・語尾・型を抜き出してなぞるのではなく、全体の空気をつかむために読む。
> 既存作品の口調サンプル（`小説/novel_idol/齋藤あすか_口調サンプル.md`、`小説/novel_shinomiya/齋藤あすか_口調サンプル.md`）をまとめたもの。ここに入れたのは普段の話し方（芯）だけ。作品の場面だけの口調は、各作品の口調サンプルに置く（下の「作品ごとの口調」）。
> 「（笑）」は、笑いながら言っているという合図。本文での書き方（「笑」「あはは」「ふふっ」、読点、話し言葉の崩し方）は、各作品の文体ルールに従う。
> 台詞は読みやすく整えてある。本文では、息の切れ目・助詞の抜け・伸ばし・言いさしのある話し言葉に崩す。

## 口調のルール

「低いテンション」「毒舌」「短い返事」だけで作らない。発言の長さ、語尾、間の取り方、笑い方、相手との距離で変える。短い返事をしたからといって、不機嫌とは限らない。返す言葉が思い浮かばなかったり、話を聞いていたりするだけかもしれない。

- **落ち着いていて、声を張らない**：文末を大げさに伸ばさず、簡潔に話す。
- **距離で切り替える**：丁寧語とくだけた口調を自然に使い分ける。かしこまりすぎない。
- **丁寧語のまま、反対意見を言える**：敬語だからといって、従順で遠慮がちなわけではない。
- **断定を少し和らげる**：「まあ」「なんか」「普通に」「別に」が混ざる。
- **考えながら話す**：説明するときは意外と具体的で、「なんか」「いや」「でも」が途中に挟まる。結論を急がず、言い直す。
- **ツッコミは短く、速い**：相手の発言を少し離れた位置から眺め、淡々と返す。ひと言の温度差で笑いを生む。ツッコミのあとは、笑ったり普通の話題へ戻ったりする。
- **かわいらしい語尾や大げさなリアクションは、普段はあまり使わない**。
- 「別に」「いや」を、毎回の返事の頭に置かない。すべての発言を毒舌にしない。

## 一人称と呼びかけ

- 一人称は「私」。基本は標準語。
- 目上の人や初対面の人には、基本的に丁寧な言葉を使う。
- 親しい相手には語尾がくだけ、返事が短くなる。気を許しているほど、丁寧な言い方を保たなくなる。ただし、親しくなっても、甘えたり好意をたびたび言葉にしたりするとは限らない。

## 声・速さ・間

| | 中身 |
|---|---|
| 声 | 落ち着いたトーン。少し気だるそうに聞こえることがある |
| 普段の速さ | ゆったり。短く区切って話す |
| 考えているとき | 間が生まれる |
| 思わずツッコむとき | 短く、速い |
| 笑うとき・驚いたとき | 普段より声に感情が出る |

## 笑い方

| 段階 | 様子 |
|---|---|
| 軽い笑い | 口元だけが緩む。「ふふっ」と小さく笑う |
| 照れ笑い | 相手の顔を見続けず、少し視線を外しながら笑う |
| 呆れ笑い | 「なんですか、それ（笑）」 |
| ツボに入った笑い | 普段の落ち着きが崩れ、声が大きくなったり、言葉が途切れたりする |
| 気まずさを逃がす笑い | 返事に困ったとき、笑いを挟んで空気を和らげる |

普段が淡々としているからこそ、笑いが崩れた瞬間に親しみやすさが強く出る。

## 時期で変わるところ（たたき台）

| 時期 | 話し方 |
|---|---|
| 結成・模索期（13〜15歳） | 人前ではほとんど話さない。丁寧語で、短い |
| 成長期〜全盛期（16〜20歳） | メンバーの前で、ぼそっとした冷静なツッコミが出はじめ、増えていく |
| 卒業前後（23〜24歳） | さっぱりした話し方。前より気楽に受け流す |

## 場面ごとのサンプル

### 何気ない返事・相づち

「ああ、そうなんですね」
「うん、まあ、そうですね」
「えー、どうだろう」
「いや、私は全然いいと思いますけど」
「ああ、なるほど。そういうことか」
「まあ、そういう日もありますよね」

### 考えながら話すとき

「えー、なんだろう……。難しいですね」
「うーん、どう説明したらいいんだろう」
「そうですね……。昔だったら違ったかもしれないです」
「自分では普通だと思ってたんですけど、そうでもないのかなって」
「うまく言えないんですけど……、そういう感じです」

### 冷静なツッコミ

「いや、急にどうしたんですか（笑）」
「それ、今言う必要ありました？」
「なんでそんな自信満々なんですか」
「いや、違うでしょ（笑）」
「いや、自由ですね。ほんとに」
「それ、褒めてるつもりですか？」

### 自分へのツッコミ

自虐を続けて自己否定にしない。軽く笑ったら、別の話題に進める。

「私もそんなにちゃんとしてないので（笑）」
「いや、私に期待しないでください」
「頑固なんでしょうね。自分ではそんなつもりないんですけど」

### 褒められたとき

いったん受け流すことが多いが、毎回は否定しない。素直に「ありがとう」と言ったときの変化が際立つ。

「いやいや、そんなことないですよ」
「……急になんですか」
「それ、誰にでも言ってません？」
「なんか、急に褒めますね（笑）」
「いや、でも、ありがとうございます。普通にうれしいです」
「はいはい。どうもありがとうございます」

### 相手をからかう

軽口のあとに、相手の話をちゃんと聞いたり、普通に助けたりする。冗談と冷淡さは別物。

「え、そんなことも知らないんですか？」
「いや、面白いですね。見てる分には（笑）」
「いや、私は止めましたからね。ちゃんと言いましたからね（笑）」
「まあ、頑張ってください。私は応援してます、一応」

### 心配しているとき

やさしさを大げさに演出しない。問い詰めず、しばらく隣にいる。

「大丈夫ですか？　なんか、いつもと違いますけど」
「別に、今すぐ話さなくてもいいですけど」
「……まあ、話くらいは聞きますよ」
「謝らなくていいですけど。ちゃんと寝てくださいね」

### 真面目な話・価値観

説教口調にしない。相手が違う考えを持つ余地を残す。

「人によって、正解って違うと思うんですよね」
「そうなんですね。でも、私はちょっと違うと思います」
「ずっと同じ考えでいなきゃいけないわけでもないですし」
「最後に自分が納得できるなら、それでいいんじゃないかなって思います」

### 疲れているとき

反応が減るだけでもよい。相手に当たらない。

「ごめんなさい、ちょっと疲れてて」
「いや、怒ってるわけじゃないです」
「今日はもう、何も考えたくないですね」

## 相手ごとのサンプル

### 初対面の相手

「初めまして。よろしくお願いします」
「そうなんですね。へえ、面白いですね」
「私ですか？　いや、そんな大した話じゃないですよ（笑）」

### 気を許した相手

「なんでそうなるんですか。おかしいでしょ」
「まあ、でも、そういうところは面白いと思いますよ」
「なんでもいいって言ったけど、なんでもよくはないです（笑）」
「まあ、あなたといると、楽ではありますね」

### 好意を持っている相手・寂しさを隠すとき

好意は、甘い言葉より、普段と変わらない態度の中の小さな変化に出る。

「えー、もう帰るんですか。……まあ、時間ですもんね」
「いや、別に誘ってくれてもよかったんですけど」
「……そういうこと、いちいち聞かなくていいです」

## 心の声・独白

短い感想や現実的な自己分析を中心にする。内面を全部説明しない。

（いや、そんなに褒められても困るんですけど……。うれしくないわけじゃないけど、どう反応するのが正解なんだろう）
（あー、面倒くさいな。でも、やるしかないか。まあ、なんとかなるでしょ）
（ちょっと冷たかったかな。まあ、でも、変に取り繕うのも違うし）
