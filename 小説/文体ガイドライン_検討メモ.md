# 文体ガイドライン：検討メモ

> どの作品でも使える本文の文体ガイドラインを、作者と一から考えている途中のメモ。決まったら、スキル（`spicy_novel_writing_jp` を組み直すか、別に作るか）に移す。
> 元にしたもの：作者が持ってきた「【最終確定版】執筆ガイドライン」（作品の設定が入っていたので、芯・つまみ・作品の設定に分けて考え直している）。

## 考え方

- **芯**：どの作品でも変わらないもの
- **つまみ**：どの作品にもあるけれど、強さや向きを作品ごとに選ぶもの。既定を決めておく
- **作品の設定**：その作品だけのもの。ガイドラインからは外す

### 女の心の声（決定）

- 本音を見せる。本音は欲しさとは限らない。その場の人が本当に感じること（嫌悪、葛藤、戸惑いも）を書く
- 説明・要約に使わない（×（この人のフェロモンのせいで……）、×（私、この人が好きなんだ））。欲や反応がそのまま出る言葉にする
- 素の言い方。外より下品でいい、♡も多くていい。外で敬語の人が、中ではタメ口でもいい
- 少なく。1つの行為の中で1〜2回、ずれがいちばん大きいところに

### 地の文の置き場所（決定）

- 台詞、地の文、台詞、と交互に挟むと、会話のテンポが毎回止まる。台詞と音は続けて書く
- 地の文は、絵が変わるところでだけ置く。置くときは、絵をまるごと置き直す（前の手や口を置き去りにしない。体の食い違いも減る）
- 地の文で書いていた感触や体の事実は、台詞（〇〇の「すげ、吸いついてくる」など）や女の心の声に移す
- 地の文に感想の言葉を入れると、男の心の声に聞こえる（寄り添いが「近い」になる）。地の文は事実と感覚だけ
- 言葉は官能小説寄りの厚み（花弁、熱い肉、など）で、置き場所は男の感覚（目の前のもの、体に来るもの）

**行為の最中とつなぎで分ける（決定）**

| 場所 | 地の文 |
|---|---|
| 行為の最中 | 事実と感覚だけ。感想の言葉は入れない |
| つなぎ（時間・場面の変わり目、エロ以外の場面） | 語り手の軽い声（ラノベ型）を入れていい。時間を飛ばす、場面を変える、熱を下げずに次へ渡すのに使う。声は男寄り。女寄りの語りは使わない |

つなぎの例：

>
> ユイ「……まだ、できるよね？」

> ずぷっ、ぬぷぷ
>
> ユイ「あっ、あ、ぁ……っ、おく、ぅ゛……♡」

> 〇〇「すげ、吸いついてくる……」

### 体の書き方（決定）

体の食い違い（手や口の位置、体位、服、誰がどこにいるか）は合わせる。食い違うと、読者の頭の中の絵が崩れて冷める。そのための書き方：

1. **置くものを少なくする。** 手や口に何かを持たせるのは、それが効くときだけ。食い違いを見つけたら、つじつまを合わせる一行（「右手を離し、左手を抜いて」）を足す前に、それが要るかを考える。要らないなら、最初から置かない
2. **絵の変わり目に、絵をまるごと置き直す。**（「地の文の置き場所」）体位の名前と、男から見た形で書く。家具を基準にしない
3. **動きは台詞で起こす。**（「上、乗っていい？」「キスはあたしね」）地の文の段取りで運ばない
4. **書き手は裏のメモで体の状態を持つ。** 本文には出さない。体位、一人ずつの手と口、服を、絵が変わるたびに更新する。リレーでは作者が次に何を書くかわからないので、どんな続きが来ても食い違わずに受けられるようにする。複数人の場面では特に

裏のメモの例（本文には出さない）：

| | 始め | ミオのキスのあと |
|---|---|---|
| 体位 | 騎乗位（向かい合ってユイが上） | 同じ |
| ユイ | 〇〇の上。手は〇〇の胸 | 同じ |
| ミオ | 〇〇の横から顔をのぞきこむ | 〇〇とキス |
| 〇〇の手 | 空いている | 空いている |
| 〇〇の口 | 空いている | ミオ |
| 服 | 3人とも裸 | 同じ |

### 喘ぎ声の形（決定）

昔のAIが「あああああ」「ひぎゃああああ」のような、喘ぎ声ではなく叫び声に見えるものを出していたので、それを避ける。

| 叫び声に見える（使わない） | 喘ぎ声に見える（使う） |
|---|---|
| 同じ母音を長くのばす（「あああああ」）。同じ文字は5文字以上続けない | 息で切れる。短い音が重なる（「あっ、あ、ぁ……っ」） |
| 悲鳴・怒号の音（「ひぎゃあ」「うおお」「んぎゃあ」） | 息と声のあいだの音（「ん」「ふ」「は」「ぁ」「ひぅ」） |
| 大きい字だけで、ずっと同じ高さ | 小さい字（ぁ、ぅ、っ）や「……」で揺れる。高さが変わる |
| 言葉がなく、音だけが続く | 音のあいだに言葉の切れはしが混ざる（「そこ」「だめ」「いく」） |

同じ強さでも形で変わる。叫び声：「ああああああっ！　ひぎゃあああっ！」／喘ぎ声：「あっ、あ゛っ、そこ、ぉ゛……っ♡　んぃ、いく、いっ……♡」

### リレーの進め方

- 作者が続きの展開を書く（箇条書き、要約、殴り書き、どんな形でもいい）。こちらがそれを脚本として、会話と音を主にした本文に膨らませる。作者がその続きを書き、くり返す
- 前の回の終わりから、そのまま続ける
- 作者の書いたことは、順番どおり全部入れる。流れは変えない
- 書かれていない細部（台詞、体位の細かいところ、喘ぎの山、音）は、こちらで考えて足す。当てはめるだけで終わらせず、もっとえろくできるところは自分から足す
- 女の気持ちは、作者が書いた段階にとどめる。深くするついでに、気持ちを先へ進めない（「嫌がるけど、される」と書かれたら、「だんだん欲しくなる」まで進めない）。体の反応で種をまくのはいい。心が崩れるかどうか、いつ崩れるかは、作者が続きで決める（**決定**）
- 〇〇の台詞と動きは、作者の書いたものになくても、流れに要るものは足していい（**決定**）。〇〇も女と同じ熱で返す。〇〇の心の声は書かない
- 作者が書いた最後の出来事まで書いたら止める。その先へは進めない。余韻の一文やまとめで締めず、作者が続きを書きやすい開いたところで止める
- 分量が足りないとき：先へ進まずに、今の場面を深くする（**決定**。下の「深くする」）
- 次の案：作者が頼んだときだけ出す（「案ちょうだい」など）。ふだんは出さない（**決定**。下の「次の案の出し方」）

### 深くする（決定）

作者の書いた出来事の中にとどまったまま、その場面を濃くする。先の出来事を足して長くしない。

例：作者が「風呂でユイが背中を流してくれる。そのまま手でしてくれる」と書いたら、「入れる」「出す」まで進めない。泡の手が前に回る → 気づかないふり → 〇〇「前も」→ 手で包む → ゆっくり、速く、止めて焦らす → 耳元で「……かたい」→ 出そう、のところで止める。続きは作者が決める。

| 使うもの | 中身 |
|---|---|
| ラリーを増やす | 台詞の往復を増やす。〇〇も返す |
| 段階を踏む | 入れてすぐ、触ってすぐに崩さない。何往復もかけて崩れる。喘ぎも1→2→3と上げる |
| 行為を重ねる | キスしながら、胸を触られながら、のように、一つの行為に別のものを重ねる |
| 緩急 | 止める、焦らす、ねだらせる |
| ずれを見せる | 口（外）・心（中）・体（地の文）のずれ。女の心の声を使う |
| 五感 | 音、匂い、温度、濡れ方、肌の感じ |

入らないもの：説明や心理描写での水増し、同じことの言いかえ、地の文を長くすること。

### 次の案の出し方（決定）

- 作者が頼んだときだけ。本文のあとに区切り線を入れて、本文とは分ける
- ト書きの形で2〜3個。向きのちがうもの（女が攻める／〇〇が攻める／場所を変える、など）。ありがちな案だけにせず、ひねったものを1つは入れる
- 作者は選んでも、混ぜても、書き直しても、無視してもいい
