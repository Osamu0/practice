# 文体ガイドライン：検討メモ

> どの作品でも使える本文の文体ガイドラインを、作者と一から考えている途中のメモ。決まったら、スキル（`spicy_novel_writing_jp` を組み直すか、別に作るか）に移す。
> 元にしたもの：作者が持ってきた「【最終確定版】執筆ガイドライン」（作品の設定が入っていたので、芯・つまみ・作品の設定に分けて考え直している）。

## 考え方

- **芯**：どの作品でも変わらないもの
- **つまみ**：どの作品にもあるけれど、強さや向きを作品ごとに選ぶもの。既定を決めておく
- **作品の設定**：その作品だけのもの。ガイドラインからは外す

### 女の心の声（決定）

- 説明・要約に使わない（×（この人のフェロモンのせいで……）、×（私、この人が好きなんだ））。欲や反応がそのまま出る言葉にする
- 素の言い方。外より下品でいい、♡も多くていい。外で敬語の人が、中ではタメ口でもいい
- 少なく。1つの行為の中で1〜2回、ずれがいちばん大きいところに

### 喘ぎ声の形（決定）

昔のAIが「あああああ」「ひぎゃああああ」のような、喘ぎ声ではなく叫び声に見えるものを出していたので、それを避ける。

| 叫び声に見える（使わない） | 喘ぎ声に見える（使う） |
|---|---|
| 同じ母音を長くのばす（「あああああ」）。同じ文字は5文字以上続けない | 息で切れる。短い音が重なる（「あっ、あ、ぁ……っ」） |
| 悲鳴・怒号の音（「ひぎゃあ」「うおお」「んぎゃあ」） | 息と声のあいだの音（「ん」「ふ」「は」「ぁ」「ひぅ」） |
| 大きい字だけで、ずっと同じ高さ | 小さい字（ぁ、ぅ、っ）や「……」で揺れる。高さが変わる |
| 言葉がなく、音だけが続く | 音のあいだに言葉の切れはしが混ざる（「そこ」「だめ」「いく」） |

同じ強さでも形で変わる。叫び声：「ああああああっ！　ひぎゃあああっ！」／喘ぎ声：「あっ、あ゛っ、そこ、ぉ゛……っ♡　んぃ、いく、いっ……♡」

## つまみ

| つまみ | 幅 | 既定 | 状態 |
|---|---|---|---|
| 女の心の声の量・誰のか | 使わない〜多め。一人だけ／全員 | 1つの行為の中で1〜2回 | **決定**（芯に入れて、つまみでも回す） |
| 男への寄り添いの距離 | 近い（男の心の声まで）／中くらい（感覚まで）／少し引く（女の様子に集中） | 中くらい。男は見える・聞こえる・触れるまで。男の心の声は書かない（気持ちは台詞と態度で）。心の声は女だけ。読者は男の体に入りながら、男の知らない女の内側を知る側に回る | **決定** |
| 男に見えないものを見せる | 使わない〜山で一点だけ | 山で一場面に一回くらい | たたき台 |
| 喘ぎ声の強さ | 作品で上限を決めて、場面の段階で上げる（前戯1〜2、本番2〜3、山で上限まで。レベルは `aegigoe_skills.md`）。上限は2（抑えた声のまま、息と言葉の途切れで乱れる）／3（濁点・♡ありで崩れる）／4（アヘ声実況） | 上限3。山のいちばん高いところでは4も使える | **決定** |
| ヒロインの入り方 | 抵抗しながら体は正直〜最初から乗り気 | 未定 | 未定 |
| 話の理屈 | えろさ優先〜理屈を合わせる | えろさを優先する。なぜそうなるか、設定で説明がつくかは説明しない。読者が止まらなければいい | **決定** |
| 体の食い違い（手・口の位置、体位、服、誰がどこに） | 書き方そのものを検討中 | 未定 | 検討中 |
| 1回に出す分量 | リレーなら毎回2,500字以上／章なら決めない | 未定 | 未定 |
| 進め方 | リレー（作者のト書きを膨らませる）／プロットから章を書く | 未定 | 未定 |
| 台詞の表記 | 名前：「」／名前「」 | 未定 | 未定 |
