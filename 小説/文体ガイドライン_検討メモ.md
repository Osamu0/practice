# 文体ガイドライン：検討メモ

> どの作品でも使える本文の文体ガイドラインを、作者と一から考えている途中のメモ。決まったら、スキル（`spicy_novel_writing_jp` を組み直すか、別に作るか）に移す。
> 元にしたもの：作者が持ってきた「【最終確定版】執筆ガイドライン」（作品の設定が入っていたので、芯・つまみ・作品の設定に分けて考え直している）。

## 考え方

- **芯**：どの作品でも変わらないもの
- **つまみ**：どの作品にもあるけれど、強さや向きを作品ごとに選ぶもの。既定を決めておく
- **作品の設定**：その作品だけのもの。ガイドラインからは外す

## 芯

| 項目 | 中身 | 状態 |
|---|---|---|
| 目的 | 読者が興奮すること | たたき台 |
| 没入 | 読者が男として、その場にいる | たたき台 |
| 視点 | 三人称。カメラを男の肩のあたりに置く。見える・聞こえる・触れるものは、男が受け取っているもの | たたき台 |
| 女の心の声 | 使う。（　）で一言だけ差しこみ、カメラは男のそばのまま。口（外）・心（中）・体（地の文）のずれを見せる | **決定** |
| 進め方 | 会話と音で進める。地の文は少なく | たたき台 |
| 設定 | 裏のルールとして働かせ、説明しない。設定の言葉（「仮面」「小悪魔」など）も本文で使わない。変化は様子・息・反応で見せる | たたき台 |
| 台詞 | その瞬間の体と気持ちから毎回作る。台詞例・テンプレートをそのまま使わない | たたき台 |
| 語彙 | 台詞は直接的な口語。地の文は文学寄りの言葉も使える | たたき台 |

### 女の心の声（決定）

- 説明・要約に使わない（×（この人のフェロモンのせいで……）、×（私、この人が好きなんだ））。欲や反応がそのまま出る言葉にする
- 素の言い方。外より下品でいい、♡も多くていい。外で敬語の人が、中ではタメ口でもいい
- 少なく。1つの行為の中で1〜2回、ずれがいちばん大きいところに
